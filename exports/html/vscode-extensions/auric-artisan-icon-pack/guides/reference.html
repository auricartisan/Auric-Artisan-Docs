Icon Pack reference

The extensions included in Auric Artisan Icon Pack 0.1.0, its requirements and what it does and does not contain.

This reference describes version 0.1.0 as published on the Visual Studio Marketplace.

Included extensions

ExtensionIDWhat it adds
Auric Icons: Modernauric-artisan.auric-artisan-modern-icon720 Modern and Sharp library icons, plus the Modern Explorer file icon theme.
Auric Icons: Playfulauric-artisan.auric-icons-playful1,225 emoji-style icons in Color, Outline, Filled and Small.
Auric Artisan Emojiauric-artisan.auric-artisan-emojiEmoji Studio: 1,914 emoji, skin tones, shortcodes and editor insertion.
Auric Icons: Drawnauric-artisan.auric-icons-drawn480 hand-drawn icons in Color, Mono, Outline and Duotone.

The pack uses the current publishing IDs. It does not install the retired auric-artisan-icons or auric-artisan-svg-icons extensions.

What the pack itself contains

ItemPresent
CommandsNone
SettingsNone
Views or keybindingsNone
Background service or installerNone
Telemetry or workspace editsNone
Embedded copies of member extensionsNo; members are downloaded from the marketplace

Requirements

RequirementValue
VS Code1.85 or later
NetworkMarketplace access to download members
CategoryExtension Packs

Not included

ExtensionWhy you might want it
Auric Artisan Icon StudioThe separate all-in-one catalog: the three Auric collections, emoji and seven open-source sets.
Auric Artisan File IconsExplorer file and folder themes in Facet, Playful and Modern styles.
Auric Artisan Icon HubSeven open-source sets with colour controls and export.

Licence

The pack is covered by the Auric Artisan Free Use Licence. Each included extension and its artwork keep their own licence and attribution. Installing the pack grants no extra rights to redistribute artwork.
