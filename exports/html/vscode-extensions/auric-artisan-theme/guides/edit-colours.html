VS Code extensions › Auric Artisan Theme

Edit individual colours

Override any of the 107 colour slots on the Colours tab using the custom colour picker, and revert them.

The theme is built from 107 colour slots. A slot is one named colour, such as Canvas (bg.base) or Keyword (syntax.keyword), that many parts of the workbench or syntax highlighting draw from. On the Colours tab you can override any slot. An override wins over whatever the dials produced.

Open the Colours tab

  1. Open Theme Studio (Ctrl + Alt + ;).
  2. Select the Colours tab, press 3, or select Explore colours → in the introduction.

Find a slot

Slots are grouped into 12 collapsible cards:

GroupContents
SurfacesThe planes the workbench is built from, deepest to nearest (8 slots).
TextForeground ramp, from body copy to disabled (6).
LinesEvery border, divider and focus ring (7).
AccentThe accent fills, emphasis and washes derived from it (7).
StatesHover, active, selected and drop feedback (5).
SelectionEditor selection, find, word and range highlights (10).
SemanticsError, warning, info and success, quiet and loud (8).
Semantic washesTinted backdrops behind semantic messages (4).
TerminalThe 16 ANSI colours (16).
Source controlFile decoration colours in source control views (9).
SyntaxToken colours shared by semantic and TextMate highlighting (26).
EffectsThe shadow colour (1).
  • Select a group heading to expand or collapse it. The Studio remembers which groups are open.
  • Each group shows a count. When you have overrides in a group, the count reads like "2/26".
  • Type in Filter by name or path — press / to jump here to filter across all groups. Matching groups open automatically. Press Escape in the filter to clear it.
  • If nothing matches, the tab shows "No slots match that filter."

Override a slot

  1. Find the slot row. It shows the slot label, its path (for example syntax.string) and a colour field.
  2. Type a hex value into the field, or select the swatch to open the colour picker.
  3. The editor updates live as you drag in the picker, and again when you commit the value.

The colour field accepts #rgb, #rrggbb or #rrggbbaa. Any other value shows "Needs #rgb, #rrggbb or #rrggbbaa".

The colour picker

ControlWhat it does
Hex fieldType an exact value.
Saturation and brightness planeDrag to set saturation and brightness. Arrow keys nudge the value.
Hue sliderRotate the hue.
Opacity sliderShown for slots that allow transparency (washes, selections, states).
RGB channelsNumeric Red, Green and Blue inputs, plus opacity where allowed. Values are range-checked.
Recent coloursUp to eight colours you picked in this panel session. They are not saved after the panel closes.
Clear / inheritRemoves the value so the slot follows the dials again.

Slots are one of three kinds: solid (no transparency), alpha (transparency allowed) or either.

Revert an override

When a slot is overridden, its row shows Shipped with the original colour and hex value, and a revert button. Select the revert button to return the slot to the shipped colour.

To remove every override and dial change at once, use Reset all in the footer. It asks for confirmation: the button changes to Reset everything? and you must select it again within four seconds.

Things to know

  • Overrides are stored per variant. An override on Obsidian Gold does not affect Parchment Gold.
  • The contrast guard still runs after your overrides. If a colour you chose would fail your minimum contrast, the guard adjusts its lightness. Turn off Enforce contrast in the Accessibility dials if you want your exact value, and check the Audit tab afterwards.
  • Changing a slot triggers a full recompute of the theme, so dragging in the picker sends updates at a limited rate.

Result

The overridden slots show your colours in the editor, each row shows the shipped colour for comparison, and the group counts show how many overrides each group holds.
