Browse the Icon Library

Search the 720-icon Modern library, filter by category, style and library, switch variants and preview surfaces, and use the smart guide and recommendations.

The Icon Library holds 720 original icons: 420 Simple Modern and 300 Sharp Modern, across 33 categories such as Coding and development, Data and databases, Cybersecurity, Accessibility and Space and Astronomy. Every icon comes in four variants: Color, Mono, Outline and Duotone.

Open the library

  • Sidebar: select Auric Icons: Modern in the Activity Bar to open the Icon Library view.
  • Editor tab: run Auric Icons: Modern: Open Icon Library, select the ↗ button (Open full explorer) in the view, or select the open-preview icon in the view's title bar. The tab is called Icon Studio — Library.

Search

Type a name, concept or synonym; results are ranked as you type. For example, delete finds trash icons. Press / to focus the search from anywhere in the view, and Escape to clear it. Search is also personalised by what you like and use.

Variants and Auto

The Variant buttons change the artwork shown on every card and used for insert, copy and save.

Auto follows the file you are editing. It shows the resolved variant, for example "Auto · outline".

Editing inAuto variant

HTML, PHP, Handlebars, Vue, Svelte, Astro, Markdown, MDX, XML, SVGColor
CSS, SCSS, Less, JSON, YAML, PythonMono
Anything elseColor

The default variant for Command Palette actions is set by auricIcons.library.defaultVariant (auto, color, mono, outline or duotone).

Preview surface

Light and Dark show every card on a light or dark backdrop, so you can judge the artwork for either kind of page. Auto follows your VS Code theme. The view remembers your choice.

Recommendations

The ✦ Recommended for this file rail shows icons that match words in the file you are editing, icons you like or used recently, and icons that fit your style. Each card shows why, for example Matches this file, In your likes, Used recently, Fits your style or Popular in your catalog. Selecting a rail card inserts it. Select Refresh to recompute.

SettingDefaultEffect
auricIcons.library.recommendations.enabledtrueShow recommendations.
auricIcons.library.recommendations.limit12How many icons the rail shows (4 to 24).

Cards

Each card shows the artwork, a heart, the name and the category (and a collection badge when libraries are merged).
