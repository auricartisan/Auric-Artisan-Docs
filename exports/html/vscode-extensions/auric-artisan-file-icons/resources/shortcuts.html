Shortcuts and commands

Commands, context menus and in-Studio keys in Auric Artisan File Icons.

File Icons has no default keybindings. Open Preferences: Open Keyboard Shortcuts, search for "Auric Artisan File Icons" and assign keys to the commands you use most, such as Insert Icon into Code… or Open File Icon Studio.

Keys inside File Icon Studio

KeyAction
/Focus the icon search
Arrow Up / Arrow DownMove through picker options
Home / EndFirst or last option
EscapeClose an open picker or the inspector
