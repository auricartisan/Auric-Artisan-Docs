Release notes

User-facing history of Auric Icons: Playful.

0.12.1

The current Marketplace version.

  • Now covered by the Auric Artisan Free Use Licence 2.0 instead of MIT. It stays free to install and use for any purpose; redistribution, republishing to any marketplace, resale and derivative releases are no longer permitted.

0.12.0

  • Marketplace README images now display correctly.
  • Future Auric icon collections can join the shared library without every extension being updated.
  • The library view, palette entries and shared shortcuts are disabled while another icon collection or Auric Artisan Icon Studio hosts the library.

0.11.0

  • The catalog grew from 1,220 to all 1,225 icons after five pieces of artwork were repaired.
  • New Marketplace artwork.
  • The shared library gained keyboard and pointer enlargement and a remembered Auto, Light or Dark preview surface.

0.1.0

  • Initial release: 1,220 icons in four variants (Color, Outline, Filled, Small) and 24 categories, with the Icon Library, smart search, smart insert (Ctrl + Alt + I), nine copy formats, hover previews, likes and recents (Ctrl + Alt + R) and per-file recommendations.
  • Cooperates with Auric Icons: Modern and Drawn in one merged library.
  • Succeeds the retired, never-published "Auric Artisan Icons" gallery extension. Its file icon theme is replaced by Auric Icons: Modern's.
