# Auric Accessibility docs — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | The guides and reference pages for Auric Accessibility. |
| [getting-started.html](getting-started.html) | Install Auric Accessibility, read your first WCAG finding, inspect an element, scan the project and find everything it adds to VS Code. |
| [audit-profiles-and-contrast.html](audit-profiles-and-contrast.html) | Choose which WCAG version the audit targets, and choose between WCAG 2.x contrast ratios and APCA. |
| [check-space.html](check-space.html) | Filter every finding in the Studio's Findings tool, and preview failing contrast next to its accessible repair in the Preview tool. |
| [editor-linting.html](editor-linting.html) | Where Auric Accessibility checks your code as you type, how to read its diagnostics and hovers, and which fixes it can apply for you. |
| [inspect.html](inspect.html) | Use Inspect to see any element's or CSS rule's accessible name, role, colours, contrast, colour-vision impact and WCAG issues, with a before-and-after preview. |
| [manual-evidence.html](manual-evidence.html) | The eight manual test procedures in Auric Accessibility's knowledge database, what each asks you to do, and how to record evidence for what automation cannot decide. |
| [project-issues-view.html](project-issues-view.html) | Browse, group, search and act on every finding from the last scan in the Project Issues tree view. |
| [project-scans.html](project-scans.html) | Scan the whole project with Auric Accessibility, read the result, and keep the score up to date. |
| [rules.html](rules.html) | Every WCAG rule Auric Accessibility checks, grouped by success criterion, with its impact, what it catches and how to fix it. |
| [reference.html](reference.html) | Every command, keybinding, setting, view, menu entry and theme colour Auric Accessibility contributes. |
| [troubleshooting.html](troubleshooting.html) | Symptoms, causes and fixes for Auric Accessibility's diagnostics, Inspect, scans and Project Issues view. |
| [faq.html](faq.html) | Short answers about Auric Accessibility. |
