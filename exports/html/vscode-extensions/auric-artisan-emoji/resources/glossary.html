Glossary

Definitions of the terms used in Auric Artisan Emoji.

TermMeaning
Click actionWhat happens when you select an emoji or press Enter on it: insert, copy, or both.
Code pointThe Unicode number of a character, written like U+1F680.
Copy formatThe text form used when copying: emoji, shortcode, Unicode, HTML, JavaScript or CSS.
CSS escapeA backslash form such as \1F680, valid inside CSS strings.
CuratedA hand-picked selection of commonly useful emoji.
HTML entityA form such as &#x1F680; that HTML turns into the character.
InspectorThe panel showing an emoji's details and every output format.
JavaScript escapeA form such as \u{1F680}, valid inside JavaScript and TypeScript strings.
SequenceA list of up to 50 emoji collected to insert or copy together.
ShortcodeA text name between colons, such as :rocket:.
Skin toneA modifier changing the skin colour of emoji that support it.
YellowThe standard, unmodified appearance of tone-capable emoji.
