Commands

Type "Auric Artisan Emoji" in the Command Palette: Open Emoji Studio, Quick Insert Emoji, Insert Recent Emoji, Insert Favorite Emoji, Copy Last Emoji Again, Replace Emoji Shortcodes in Selection, Clear Emoji History, Focus Emoji Search, Choose Interface Language….

With VS Code's display language set to Hindi, these titles appear in Hindi.
