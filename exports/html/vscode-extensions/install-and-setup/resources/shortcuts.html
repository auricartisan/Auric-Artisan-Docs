VS Code extensions › Install and setup

Shortcuts and commands

The VS Code keys and commands you use to install, configure and manage the Auric Artisan extensions.

These are VS Code's own default keys on Windows and Linux. On macOS, use Cmd in place of Ctrl. Each extension's own shortcuts are listed in that extension's folder.

Keys

KeysWhat they do
Ctrl + Shift + XOpen the Extensions view
Ctrl + Shift + POpen the Command Palette
Ctrl + ,Open the Settings editor

Commands

CommandUse it to
Extensions: Install from VSIX…Install from a downloaded .vsix file

Developer: Reload WindowReload after installing, updating or changing a language
Configure Display LanguageChange VS Code's own display language
Workspaces: Manage Workspace TrustTrust or restrict the open folder

Preferences: Open Workspace Settings (JSON)Edit workspace settings directly
Preferences: Open Keyboard ShortcutsFind and change shortcuts, and spot conflicts
