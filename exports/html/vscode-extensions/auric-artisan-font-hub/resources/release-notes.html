Release notes

What changed in each published version of Auric Artisan Font Hub.

0.1.0 (24 September 2026)

The first release under the name Auric Artisan Font Hub, with the new extension ID auric-artisan.auric-artisan-font-hub.

A shared Auric workspace

  • Renamed from Font Library to Auric Artisan Font Hub, with matching typography icons in the Marketplace and the Activity Bar.
  • A redesigned studio and compact sidebar with editorial typography, gold accents, sticky navigation and responsive cards.
  • Add to code and Preview buttons directly on font cards.
  • Editor context-menu actions grouped under Auric Fonts.
  • Custom drop-downs, the shared colour picker, keyboard navigation, collapsible filters and native scrolling kept.

CDN insertion you can review

  • Automatic, non-duplicating CDN setup for HTML, CSS-family files and JavaScript and TypeScript.
  • Reusable font classes that do not change existing styles or replace selected text.
  • A native diff preview with Apply and Cancel, stale-document checks, and undoable, unsaved edits.
  • A clipboard fallback for framework and other file types.
  • Safe insertion of several families at once.
  • Live CDN diagnostics for availability, content types and browser font CORS.
  • Variable weight ranges kept in generated @font-face snippets.

Typography tools

  • 2,023 library families, 547 variable, with bundled metadata.
  • Search, filters, specimens, waterfalls, axes, features, glyphs, charset and licence inspection.
  • Four-family comparison, recommendations, favourites, recents and selection.
  • Manual embed formats, design tokens and licence-aware self-hosting kits.
  • A bounded cache, network controls, validated HTTPS CDN access and offline metadata.

Compatibility

  • Requires VS Code 1.85 or newer.
  • Existing auricFontLib.* settings and command IDs are kept.
  • Disable the old Font Library extension before enabling Font Hub. Its favourites and cache are not moved automatically.
  • Browser delivery needs correct CORS headers from the CDN; the extension does not change hosting settings or bypass browser restrictions.
