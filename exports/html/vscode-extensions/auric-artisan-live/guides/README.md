# Auric Artisan Live guides — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |

| [inspect-requests.html](inspect-requests.html) | See every request the Auric Live server handles, find slow or failing ones, and copy, replay or export them. |
| [network-simulation.html](network-simulation.html) | Slow down every client of the Auric Live server, including a phone, to test how your site behaves on slow connections. |
| [php-and-cgi.html](php-and-cgi.html) | Run .php pages in Auric Live through php-cgi or the PHP built-in server, and run other CGI scripts. |
| [preview-and-devices.html](preview-and-devices.html) | Preview your served site beside the editor at device sizes, and open it on a real phone with a locally generated QR code. |

| [run-targets-and-backends.html](run-targets-and-backends.html) | Let Auric Live run your project's backend or framework dev server (PHP, Python, Ruby, Go, Java, Node.js and more), or connect to one already running, and serve it through one address. |
| [serve-and-live-reload.html](serve-and-live-reload.html) | Start the Auric Live server, choose what it serves and where, and control how and when connected pages update. |
| [reference.html](reference.html) | Every Auric Artisan Live command, keyboard shortcut, menu entry, view and setting, with types, defaults and ranges. |
| [troubleshooting.html](troubleshooting.html) | Symptoms, causes and fixes for common Auric Artisan Live problems, from pages that do not update to phones that cannot connect. |
| [faq.html](faq.html) | Short answers to common questions about Auric Artisan Live. |
