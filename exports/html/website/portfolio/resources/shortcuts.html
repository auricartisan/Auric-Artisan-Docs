Portfolio shortcuts

Keys and pointer actions in the Portfolio Builder, on published portfolios and in the Portfolio Index.

Builder

Keys or actionEffect
Ctrl + K or the command fieldOpens the list of builder commands; type, then Enter.
EnterFinishes a one-line field you are typing in the preview.
EscapeFinishes editing in the preview; closes the templates dialog, the section picker, full-screen preview and the publish dialog.
Enter in the section picker's searchAdds the first matching section type.
Double-click the avatarChoose a picture.
Drag a card's handle (⠿)Reorder sections.

The Undo and Redo buttons show Ctrl + Z and Ctrl + Shift + Z in their tooltips; if the keys do not respond, use the buttons or the Undo and Redo commands.

Published portfolio

Keys or actionEffect
Right-clickCopy link to this portfolio, Save this portfolio as PDF, Email the owner, Reading mode, Make your own portfolio.
Alt + RReading mode.

Portfolio Index

KeysEffect
/Focus the search box.
EscapeClear the search box, or close an open filter menu.

See also Site features for site-wide shortcuts.
