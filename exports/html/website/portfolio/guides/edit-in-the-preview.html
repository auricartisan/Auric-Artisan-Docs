Edit in the preview

Type directly into the live preview, use the section rail and row controls, and add sections in place.

The live preview is not only a picture of your page: you can write in it. Click a heading and type; the change is saved and appears everywhere the portfolio goes.

Type into the page

  1. Hover over text in the preview. Editable text shows a faint outline.
  2. Click it. A coloured outline shows you are editing.
  3. Type. Empty fields show grey example text until you fill them.
  4. Finish:
    • Enter finishes a one-line field (a heading, a name, a button label).
    • In longer fields (quotes, descriptions, code, Markdown), Enter starts a new line; click elsewhere to finish.
    • Escape finishes too.

Pasting into a plain field pastes text only, without formatting.

What can be typed in the page

SectionEditable in the page
HeadingThe heading text
Text / MarkdownThe whole text (kept as Markdown)
Two columnsEach column (kept as Markdown)
QuoteThe quote and the attribution
TestimonialThe quote, name and role
CalloutThe text (kept as Markdown)
ButtonThe label
Call to actionThe heading, text and button label
ImageThe caption
CodeThe code
Skills / TagsThe title
TimelineThe title, and each entry's date, title, subtitle and description
StatsThe title, and each metric's value and label
Feature listThe title, and each feature's title and description
StepsThe title, and each step's title and description
FAQ / AccordionThe title, and each question and answer

Everything else — image addresses, embeds, tables, links, alignment, tone, columns, which palettes to show — is a choice rather than words, so it lives on the section's card. Clicking such a section in the preview selects it and opens its card in the Content column, ready to edit.

Buttons and links in the preview do not navigate while you are building; clicking one means "edit this".

The section rail

When you select a section in the preview, a small rail of buttons appears beside it:

ButtonWhat it does
Add a section belowOpens a searchable list of section types and inserts your choice after this section.
Open this section in the panelOpens its card in the Content column.
Move this section up / Move this section downReorders it.
Hide from the pageHides the section (it stays in your draft).
Remove this sectionDeletes it (undoable).

Row controls

In Timeline, Stats, Feature list, Steps and FAQ sections, selecting a row shows row controls instead:

ButtonWhat it does
Add an entry after this oneInserts a new row below.
Move this entry up / Move this entry downReorders the row.
Remove this entryDeletes the row.

In a timeline sorted Newest first or grouped by year, rows appear in the displayed order; moving and adding still act on the entry you selected.

Add a section at the end

At the bottom of the page, a dashed Add a section button opens the same searchable list. Type to narrow it, press Enter to add the first match, or Escape to close.

Result

You can build most of the page by typing into it, and reach every other option through the section's card.
