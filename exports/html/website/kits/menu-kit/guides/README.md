# Menu Kit guides — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | Contents of the Menu Kit guides: getting started, browsing, searching, reference, troubleshooting and FAQ. |
| [getting-started.html](getting-started.html) | Open the Menu Kit, learn the parts of its screen, and open your first page from it. |
| [find-a-page.html](find-a-page.html) | Browse the Menu Kit's tabs and sections, use Recommended and Most Used, and collapse sections you do not need. |
| [search-and-quick-actions.html](search-and-quick-actions.html) | Search every page in the Menu Kit with forgiving matching, and run quick actions such as copying the page URL. |
| [reference.html](reference.html) | Every control, tab, section, state and message in the Menu Kit. |
| [troubleshooting.html](troubleshooting.html) | Fixes for Menu Kit problems, such as a missing tab, a tool that does not appear, or a shortcut that does nothing. |
| [faq.html](faq.html) | Short answers to common questions about the Menu Kit. |
