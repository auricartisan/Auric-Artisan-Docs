Menu Kit glossary

Terms used in the Menu Kit guides.

Start menu — The Menu Kit's role: one panel that lists the site's pages, like the start menu of a desktop computer.

Tab — One of the seven top-level groups: Tools, Design, Analyze, Account, Library, Company, Trust.

Section — A collapsible group of tiles inside a tab, such as Start Here or Utility Labs.

Tile — One page in the menu, shown as an illustration and a name.

Recommended — Eight entry points picked for first-time visitors, at the top of the Tools tab.

Most Used — Up to eight Tools-tab pages you open most often from the Menu Kit.

Results list — The ranked list that replaces the tiles while you search. It works like a command palette.

Fuzzy matching — Search that matches the letters you type in order, allowing other letters in between.

Quick action — A command in the results list that does something on the current page, such as Copy current URL.

Status chip — The label next to the kit's title showing the site's release status, such as Beta.

Tool visibility mode — The site-wide choice of Basic, Advanced, Everything or Custom tools, set in the Advanced Kit. The Menu Kit shows only tools the mode allows.
