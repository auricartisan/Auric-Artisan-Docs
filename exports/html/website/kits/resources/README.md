# Reference material for all kits — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | Contents of the shared reference pages for all kits: glossary, shortcuts, privacy and related pages. |
| [shortcuts.html](shortcuts.html) | Every keyboard shortcut for opening, closing and using the kits, in one table. |
| [glossary.html](glossary.html) | Terms used across the kit guides, from launcher and Focus mode to tool visibility mode. |
| [privacy.html](privacy.html) | What each kit keeps in your browser, what it sends over the network, and how to clear it. |
| [related.html](related.html) | Site features, tools and pages that work alongside the kits. |
