Related to the kits

Site features, tools and pages that work alongside the kits.

Site features next to the kits

The page utilities bar also launches two site features that are not kits:

  • Navigate opens the page navigation dock (back, forward, reload, outline, split view, jump to top or bottom).
  • Settings opens the site settings panel (theme, accent colour, text size, motion, ads and more).

Both, along with the site-wide search (Ctrl + K), the right-click menu and the eye-rest reminder, are documented in Site features.

Tools that work with the kits

  • Every tool with a Save to Library button saves into the Library Kit.
  • The URL Analyzer, the Vision Simulation lab and the Colour Science Lab have mode switches that change the same site-wide setting as the Advanced Kit.
  • The Basic Colour Tools workspace uses floating panels of its own, separate from the kits.
