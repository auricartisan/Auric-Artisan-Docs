Organise your library

Favourite, rename, describe, tag, duplicate, collect, archive and delete saved items, one at a time or in bulk.

Favourite an item

  • Hover over the tile and select the star (Favourite), or
  • right-click the tile and choose Favourite.

A star appears on the tile and the item joins the Favorites tab. Do the same again (Remove favourite) to unstar it.

Rename an item

  1. Right-click the tile and choose Rename….
  2. In Rename item, change the Name and select Rename.

A message confirms Renamed. You can also rename an item in its details; see Restore and reuse.

Add a description and tags

  1. Hover over the tile and select the pencil (Open details).
  2. Type a Description, and Tags (comma-separated), for example brand, spring, web.
  3. Select Save changes.

Search matches descriptions and tags, and the command palette offers filters for your most-used tags.

Duplicate an item

Right-click the tile and choose Duplicate (in list view, the copy icon on the row does the same). The copy is named after the original with " copy" added, and starts neither favourited nor archived.

Collections

A collection is a folder of saved items. Each item can be in one collection at a time. Grouping by project uses collections as its headings.

Create a collection

  • On the Collections tab, select the New collection tile ("Group saved items"), or
  • type > and choose New collection, or
  • right-click empty space in the panel and choose New collection.

Type a Collection name (it starts as Untitled collection) and select Create. A message confirms Created and the name.

Put items in a collection

  1. Right-click a tile and choose Add to collection….
  2. In the Add to collection chooser, select a collection, or New collection… to create one and add the item to it, or No collection to take the item out of its collection.

A message confirms, for example "Moved 1 item to" and the collection's name. You can also choose the Collection in the item's details.

Open a collection

On the Collections tab, each collection tile shows its name, Collection and the number of items. Select it to see its items on the All tab, with a Collection: filter chip. Select the chip to remove the filter.

Projects

Select New project in the footer (or type > and choose New project). Type a Project name (it starts as Untitled project) and select Create. An empty item of the Project type is created and the Projects tab opens.

Some tools save projects of their own, which also appear on this tab. The Library Kit does not add existing items to a project; to group items together, use a collection.

Archive an item

Archiving hides an item without deleting it.

  • Right-click the tile and choose Archive.
  • To bring it back, open the Archive tab, right-click it and choose Restore from archive.

Archived items appear only on the Archive tab and do not count towards your plan's saved-item allowance.

Empty the archive

Right-click empty space in the panel and choose Empty the archive, or type > and choose Empty the archive. Confirm Delete in the dialog, which says how many items will be removed. This cannot be undone. The option is disabled when the archive is empty.

Delete an item

  • Hover over the tile and select the bin (Delete), or right-click and choose Delete, or focus the tile and press Delete.
  • The dialog Delete item? warns that the item "will be permanently removed. This cannot be undone." Select Delete to confirm or Cancel to keep it.

Work with several items at once

  1. Select Select in the toolbar (or type > and choose Multi-select items). Tiles show a tick box and a bulk bar appears reading Pick items to act on them.
  2. Select tiles to add or remove them. The bar shows 3 selected, for example.
  3. Choose a bulk action:
ButtonWhat it does
AllSelects every item in the current view; selecting it again when all are selected clears the selection
FavoriteStars the selected items; if all are already starred, unstars them
CollectOpens the collection chooser for all selected items
ArchiveArchives the selected items; if all are archived already, restores them
ExportDownloads each selected item as its own file
DeleteAsks to confirm, then deletes them all permanently

Ctrl + A (Cmd + A on a Mac) selects all while multi-select is on. Press Esc or select Select again to leave multi-select; the selection is cleared.

When several items are selected, right-clicking one of them offers Favourite all, Archive all, Add all to collection…, Export all and Delete all.

To select one item from its right-click menu, choose Select this item. Multi-select turns on with just that item selected.
