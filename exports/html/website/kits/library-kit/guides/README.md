# Library Kit guides — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | Contents of the Library Kit guides, from browsing and organising to comparing, sharing, syncing and reports. |
| [getting-started.html](getting-started.html) | Save your first item from a tool, open the Library Kit, and learn the parts of its screen. |
| [browse-and-find.html](browse-and-find.html) | Find saved items in the Library Kit with tabs, search, sorting, grouping, grid or list view, density and filters. |
| [commands-and-right-click-menus.html](commands-and-right-click-menus.html) | Run any Library Kit action from the > command palette or from the right-click menus for items and for the panel. |
| [compare-items.html](compare-items.html) | Compare two saved items in the Library Kit: palettes by colour difference and contrast, images side by side or as a heatmap, settings field by field, and audits by score. |
| [organise-your-library.html](organise-your-library.html) | Favourite, rename, describe, tag, duplicate, collect, archive and delete saved items, one at a time or in bulk. |
| [restore-and-reuse.html](restore-and-reuse.html) | Reopen saved items in the tool that made them, open them in other tools, edit their details and download them in many formats. |
| [settings-sync-and-reports.html](settings-sync-and-reports.html) | Every option on the Library Kit's Settings tab: preferences, reporting, sync destinations, report generation and storage. |
| [share-export-and-import.html](share-export-and-import.html) | Share a saved item as a link, download items as files, back up the whole library and import it again. |
| [reference.html](reference.html) | Every control, tab, option, dialog and message in the Library Kit. |
| [troubleshooting.html](troubleshooting.html) | Fixes for Library Kit problems, from missing items and full storage to share links that are too large and sync failures. |
| [faq.html](faq.html) | Short answers to common questions about the Library Kit and your saved work. |
