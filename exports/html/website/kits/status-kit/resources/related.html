Related to the Status Kit

Kits, tools and pages related to the Status Kit.

  • Menu Kit — shows the site's overall status chip, and supplies page names and categories for scans.
  • Library Kit — manage the saved items that use your browser storage.
  • Update Kit — update the site's cached files when a new release is out.
  • URL Analyzer — audit any website, not just this one.
  • Download and offline use — installing the site as an app and using it offline, which the App mode and Service worker readings reflect.
  • Release history: https://auricartisan.com/library/changelog/ (see Changelog).
  • Help — contact support, using the System status readings in your report.
