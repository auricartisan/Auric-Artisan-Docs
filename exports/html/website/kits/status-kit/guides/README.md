# Status Kit guides — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | Contents of the Status Kit guides: page status, section scans, system status, reference, troubleshooting and FAQ. |
| [getting-started.html](getting-started.html) | Open the Status Kit and learn its three parts: the This page card, System status and the page scanner. |
| [check-page-status.html](check-page-status.html) | Read the status of the page you are on in the Status Kit, and what each status label means. |
| [scan-a-section.html](scan-a-section.html) | List every page under a path with its status, then summarise, filter, search and repeat the scan. |
| [system-status.html](system-status.html) | Every live reading in the Status Kit's System status panel, what it means and when it shows a dash. |
| [reference.html](reference.html) | Every control, reading, filter and message in the Status Kit. |
| [troubleshooting.html](troubleshooting.html) | Fixes for Status Kit problems, such as empty readings, slow scans or a kit that closes on its own. |
| [faq.html](faq.html) | Short answers to common questions about the Status Kit. |
