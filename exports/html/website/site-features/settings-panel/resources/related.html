Related to the Settings panel

Site features, kits and tools that work with the Settings panel.

Features the panel controls

  • Theme — light, dark and system themes and every other way to switch them.
  • Language — English and Hindi.
  • Eye rest — the reminders scheduled in Comfort.
  • Screen saver — the idle screen scheduled in Comfort.
  • Custom cursor — the pointer switched in Comfort.
  • Info bars and notices — the bars, notices, chips and clock strip switched in Highlights.
  • Accessibility aids — reading mode and the other comfort settings, alongside the site's other aids.

Other ways in

  • Context menu — Site › Settings and Keyboard shortcuts.
  • Search and Spotlight — the > command Open settings.
  • Header and navigation — the page utilities bar and the mobile drawer's theme and language switches.
  • Kits — the floating kits share the panel's title-bar controls and follow your accent colour.

Tools for checking colour properly

  • Contrast Checker — check any two colours.
  • Analyzer — audit a whole page.
