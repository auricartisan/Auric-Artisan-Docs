Settings panel guides

Contents of the Settings panel guides, from opening the panel to backing up and resetting every setting.

This folder explains how to use the Settings panel: how to open it and find your way around, how to change each group of settings, and how to back up, restore and reset them. The reference lists every control with its values and default.
