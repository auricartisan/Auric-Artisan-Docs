Split view glossary

Terms used in the split view guides.

TermMeaning
Live paneThe pane that starts with the page you were on. Closing split view follows it.
Companion paneThe second pane, for any other page.
DividerThe bar between the panes that you drag to resize them.
ViewportThe width a pane's page is laid out for: desktop, tablet (820 px) or phone (400 px).
ResponsiveA page that rearranges itself to fit the width it is given.
Compare modeAn overlay of both panes in which identical areas turn black and differences show.
Route linksA mode in which links clicked in the live pane open in the companion.
Scroll syncScrolling one pane scrolls the other to the same relative position.
Eco modeAutomatic low-performance mode that turns off decorative effects when the panes run slowly.
FPSFrames per second: how smoothly the screen is updating.
