Keyboard

KeysAction
Ctrl + Shift + DOpen or close split view
EscClose a More menu; else close split view
Alt + 1 / Alt + 2Focus the live / companion pane
Alt + VToggle layout
Alt + SSwap panes
Alt + EEqual split
Alt + click a linkOpen it in the other pane (or open split view with it)

Alt + V, Alt + S and Alt + E are ignored while you type in an address bar.
