Accessibility aids glossary

Terms used in the accessibility aids guides.

TermMeaning
Reading modeA distraction-free layout with a narrow, large-text column and no floating controls.
Reduced motionFewer and shorter animations; also a device setting the site follows.
TransparencySee-through, blurred panel backgrounds; turned solid by Reduce transparency.
ContrastThe difference in lightness between text and its background.
Skip linkA link at the start of the page that jumps past the header to the main content.
FocusThe control that keyboard input currently goes to, shown with an outline.
Screen readerSoftware that reads the screen aloud or in braille.
Live announcementA message a screen reader reads without moving focus.
Modal dialogA panel that keeps keyboard focus inside it until closed.
