Reading mode

Turn reading mode on and off, and understand what it changes on the page.

Reading mode is a distraction-free layout with comfortable typography, for articles, documentation and other long pages.

Turn it on or off

  • Press Alt + R (not while typing in a field).
  • Or Settings › Comfort › Reading mode.
  • Or right-click the page, choose View, then Reading mode (Leave reading mode when it is on).
  • Or, on card pages, right-click a card and select the Reading pill.

To leave it, you can also select the Reading mode ✕ chip at the bottom centre of the screen.

Reading mode stays on as you move between pages until you turn it off.

What changes

AreaIn reading mode
Text columnCentred and limited to a comfortable line length (about 68 to 76 characters)
Body textLarger, with generous line spacing
HeadingsClear sizes and spacing, kept to a readable width
LinksUnderlined for scanning
Images and mediaKept within the column
HeaderScrolls away with the page instead of staying pinned
Floating controlsKit launchers, the library launcher and the right-edge menu line are hidden
Info bars and clock stripHidden
PointerYour system pointer replaces the custom cursor
Decorative animationStopped
ProgressA thin bar across the top of the window fills as you scroll
ExitReading mode ✕ chip at the bottom of the screen

What does not change

Tools keep working normally. The Settings panel, Spotlight (Ctrl + K), the guide (?) and the right-click menu remain available.
