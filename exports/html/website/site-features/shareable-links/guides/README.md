# Shareable links guides — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | Contents of the shareable links guides. |
| [getting-started.html](getting-started.html) | How the page keeps its state in the address, how that state is restored, and how to share or clear it. |
| [other-link-options.html](other-link-options.html) | Add ?lang=, ?color= or #split= to an address to open a page in a language, inspect a colour, or restore a split view. |
| [reference.html](reference.html) | Exactly what is and is not saved in a page's address, and how it is restored. |
| [troubleshooting.html](troubleshooting.html) | Fixes for common problems with page links and their saved state. |
| [faq.html](faq.html) | Short answers about page links and their saved state. |
