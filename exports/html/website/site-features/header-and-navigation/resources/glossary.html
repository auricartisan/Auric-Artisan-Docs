Header and navigation glossary

Terms used in the header and navigation guides.

TermMeaning
HeaderThe strip at the top of every page with the brand, menus, quick tools and sign-in.
Menu (header)The Company, Tools or Learn list that opens below its button.
Quick toolsThe row of icon buttons in the header: app, extension, VS Code, search, guide, library, language, theme.
DrawerThe sliding sheet that holds the header's contents on narrow screens.
BreakpointA window width at which the layout changes. The header's is 960 pixels.
Group chipA button in the drawer's Tools section that shows one group of tools at a time.
Page utilities barThe launcher bar at the bottom-left for the kits, the navigation dock and Settings.
KitA floating panel of extra tools, such as the Feature Kit or Library Kit.
Navigation dockThe slim floating rail with Back, Forward, Reload, outline and scroll controls.
FooterThe section at the end of every page with directory links, contact details and social links.
PWAProgressive web app: a website you can install and run like an app, with offline support.
