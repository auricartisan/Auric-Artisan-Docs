Get started with the header and navigation

Find your way around the header, the page utilities bar and the footer on any page.

A tour of the page frame

Every page has the same frame around its content:

  1. Header (top). The Auric Artisan name on the left returns you to the homepage. The rest depends on the width of your window:
    • 960 pixels wide or more: the Company, Tools and Learn menus, the quick-tools icons and Sign in.
    • Narrower than 960 pixels: a Search button and the three-line menu button, which opens the drawer.
  2. Info bars (below the header, homepage by default). Optional strips such as the announcements bar and the clock strip. See Info bars and notices.
  3. Page content.
  4. Floating controls. The page utilities button at the bottom-left, and the navigation dock on the left or right edge.
  5. Footer (bottom).

Open a tool from the header

  1. Select Tools in the header.
  2. The menu lists All Tools under Overview, then the tools under group headings: Core tools, Creative utilities, Colour science, Gamut & rendering, Perception, Spectral and Utilities.
  3. Scroll the menu if needed. While there is more below, a SCROLL DOWN hint shows at its foot.
  4. Select a tool.

Result: the tool page opens. The menu closes by itself.

Open a tool on a phone

  1. Tap the three-line button at the top right. The drawer opens.
  2. Under Browse, tap Tools. The section opens in place and shows a row of group chips, each with a count.
  3. Tap a chip, for example Utilities. Only that group's tools are listed, with All Tools always at the top.
  4. Tap a tool.

Result: the tool page opens and the drawer closes.

Get back to where you were

  • Select the Auric Artisan name to go to the homepage.
  • Use the navigation dock's Back button, your browser's back button, or Alt + Left.
  • Right-click the page and use Back in the quick bar.

Find something without the menus

  • Select Search in the header, or press Ctrl + K, and type what you want. See Search and Spotlight.
  • Select Guide (the question mark), or press ?, for a map of the page and its tour. See Guide and page outline.
