Troubleshooting themes

Fixes for common theme problems.

The site does not follow my device any more

Why: a light/dark toggle (the header button, the right-click menu, Spotlight or the card menu) fixes the theme and leaves System mode.

What to do: choose System in Settings › Appearance, or Auto in the mobile drawer.

The site is dark but my device is light (or the other way round)

Possible causes:

  • You chose Light or Dark at some point, so System mode is off. Open Settings and check Theme.
  • Your browser has its own theme setting that overrides the device. In some browsers you can set the website appearance separately from the operating system.

One panel is in a different theme from the page

Why: kits remember their own theme once you use their theme button, and split-view panes can be forced light or dark.

What to do: use the kit's own theme button to match the page. For split view, set the pane's theme back to Auto.

My theme changed after I opened a link someone sent me

Why: page links copied from the site can carry the sender's appearance settings, including the theme mode. See Shareable links.

What to do: set your theme again in Settings.

The theme resets every time I close the browser

Why: you are using a private window, or your browser clears site data on exit.

What to do: use a normal window, or allow auricartisan.com to keep site data.
