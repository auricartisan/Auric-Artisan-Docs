Spotlight shortcuts

Keys for opening and using Spotlight.

KeysAction
Ctrl + K (Cmd + K on a Mac)Open or close Spotlight
Up / DownMove through results
EnterOpen the highlighted result or run the command
Ctrl + Enter (Cmd + Enter)Open the highlighted result in a new tab
TabNext scope tab
Shift + TabPrevious scope tab
EscClear the box, then close Spotlight
> as the first characterCommand mode

In some kits, Ctrl + K moves to the kit's own search field while that kit is open. See Kits and Keyboard shortcuts.
