Get started with feedback

When the feedback prompt appears, and how to answer it, postpone it or stop it.

When the prompt appears

The automatic prompt can appear when all of these are true:

  • you have spent 20 minutes with the page visible in front of you (time in a background tab does not count);
  • you are not on a sign-in, checkout, payment or legal page;
  • you have not been asked, and have not answered, in the last week or more on this device (see the quiet periods below);
  • you have not chosen Don't ask again.

The prompt is a small panel titled Feedback. It does not block the page.

Answer it

Select a star rating, optionally type a comment, and select Continue. Then choose Send anonymously or Add contact details. The full flow is in Rate, survey and report a bug.

Put it off or stop it

ChoiceWhat happens
Maybe laterCloses the panel; no automatic prompt for at least 7 days
Close (×) or EscCounts as dismissed; no automatic prompt for 14 days
Don't ask againNo automatic prompt ever again on this device
Sending feedbackNo automatic prompt for 90 days

Even if you close the page while the prompt is open, the site waits at least 7 days before asking again.

Give feedback at any time

The automatic prompt is not the only way. Open the Feature Kit (Ctrl + Shift + K, or Feature in the page utilities bar) and choose Feedback. See Kits.
