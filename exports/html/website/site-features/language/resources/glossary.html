Language glossary

Terms used in the language guides.

TermMeaning
DevanagariThe script used to write Hindi (हिन्दी).
TransliterationWriting a name in another script by its sound, not its meaning, such as ऑरिक आर्टिज़न for Auric Artisan.
Translation in placeReplacing the text of a page that is already open, without loading it again.
LocaleThe language and region conventions used to write dates, times and numbers, such as Hindi (India).
Query parameterA part of a web address after ?, such as ?lang=hi, that passes a setting to the page.
