Screen recorder glossary

Terms used in the screen recorder guides.

TermMeaning
SourceWhat the recorder captures: a screen or window, this tab, a region, or a tool canvas.
TakeOne recording, from start to stop.
Frame rate (fps)How many images per second a video holds. Higher is smoother and larger.
Resolution capThe largest width a recording is allowed; bigger sources are scaled down.
CanvasA drawing surface that tools use for graphics and animation.
RegionA rectangle of the page, or one element, that a recording is cropped to.
MP4, WebMVideo file formats. MP4 plays almost everywhere; WebM is widely supported by browsers.
GIFAn animated image format that plays in most apps and web pages without a player.
Re-encodeTo play a video and record it again, which is how trimming makes a new file.
Sharing dialogThe browser's own window asking which screen, window or tab to share.
