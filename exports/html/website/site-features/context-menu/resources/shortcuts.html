Right-click menu shortcuts

Keyboard shortcuts for opening the right-click menu, moving around it, and running its site-wide actions.

Opening and switching menus

KeysAction
Right-clickOpen the site menu (or the browser's, if you made it the default)
Shift + right-clickOpen the other menu: the browser's by default
Menu key or Shift + F10Same as a right-click

Inside the menu

KeysAction
Type any letterFilter the actions
Up / DownMove between rows
RightOpen a group's submenu, or move to a row's pin star
LeftLeave a pin star, or close a submenu
Enter / SpaceRun the focused action
EscClose a submenu, clear the filter, or close the menu, in that order

Site-wide shortcuts the menu offers

These work anywhere on the site, with or without the menu open.

KeysAction
Ctrl + Shift + COpen the colour tools menu. If you have selected a hex code, it is loaded.
Ctrl + Shift + UCheck for and apply a website update
Ctrl + Shift + DOpen or close split view
Ctrl + KOpen Spotlight search
Alt + RReading mode on or off

The full list for the site is in Keyboard shortcuts.
