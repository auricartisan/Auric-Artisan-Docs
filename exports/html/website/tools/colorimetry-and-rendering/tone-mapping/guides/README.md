# Tone Mapping documentation — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |

| [compare-operators.html](compare-operators.html) | Compare all nine operators by what they return for chosen inputs, where they reach white, and how their curves look. |
| [export-a-lut.html](export-a-lut.html) | Export the tone curve as a 1D .cube or CSV, the whole pipeline as a 3D .cube, a link to the view, and map a list of colours. |

| [read-the-scopes.html](read-the-scopes.html) | Use the histogram, waveform, vectorscope, false-colour map and A/B split to judge a mapped frame. |
| [reference.html](reference.html) | Every control, readout, option and export in the Tone Mapping lab. |
| [troubleshooting.html](troubleshooting.html) | Fixes for common problems in the Tone Mapping lab. |
| [faq.html](faq.html) | Short answers to common questions about the Tone Mapping lab. |
