# Illuminants documentation — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | The guides, reference and help pages for the Standard Illuminants lab. |
| [getting-started.html](getting-started.html) | Open the Standard Illuminants lab, learn its eight tabs and take your first reading of a light source. |
| [adapt-between-white-points.html](adapt-between-white-points.html) | Use the chromatic adaptation panel to move a 24-colour chart from one white point to another and read the transform matrix. |
| [compare-light-sources.html](compare-light-sources.html) | Overlay two illuminants, read their CCT, CRI and white points side by side, and judge metamerism risk with the surface samples. |
| [estimate-uncertainty.html](estimate-uncertainty.html) | Propagate a spectroradiometer uncertainty budget into x, y, CCT and Duv with the Monte Carlo view. |
| [query-console.html](query-console.html) | Use the Console tab's query language to tabulate, sort, plot and export readings for many illuminants. |
| [reference.html](reference.html) | Every control, readout, option and export in the Standard Illuminants lab, tab by tab. |
| [troubleshooting.html](troubleshooting.html) | What to do when a reading, chart, export or shortcut in the Standard Illuminants lab does not behave as expected. |
| [faq.html](faq.html) | Short answers to common questions about the Standard Illuminants lab. |
