Open the Colour Tools and manage their panels

Every way to open the 14 floating Colour Tools, how the launcher works, and how to move, arrange, pin and close the panels they open in.

The Colour Tools are 14 small colour tools that open in floating panels over the page you are on. You do not have to leave an article, a tool page or the home page to check a contrast ratio or look up a colour's name. The panel opens on top, you work in it, and you close it when you are done.

This page covers everything the 14 tools share: the ways to open them, the Color Tools launcher, the floating panel window and the control bar that appears while panels are open. Each tool has its own page in this folder.

Where the Colour Tools are available

The Colour Tools load on almost every page of the site, a moment after the page finishes loading. The Basic Color Tools page (https://auricartisan.com/tool/basic-tools/) is their home page.

A few pages do not load them, for example the Analyzer. On those pages the right-click menu has no Colour tools group, and Ctrl + Shift + C takes you to the Basic Color Tools page instead of opening the launcher.

Ways to open a tool

From the right-click menu

Right-click anywhere on a page (outside a text field) to open the site's menu. The Colour tools row opens a submenu:

The other seven tools are always one step away through All colour tools….

Tip: While the menu is open you can type to filter it. Typing part of a tool's name finds it, even inside a submenu.

To use the browser's own menu instead, hold Shift while you right-click.

Right-click a colour value

When the thing you right-click is a colour, the menu header changes to Colour and shows the hex code and its RGB value. The menu recognises a colour when:

  • you have selected text that is a hex code starting with # (3 or 6 digits), or six hex characters that include at least one digit, and you right-click on that selection;
  • you right-click a swatch or chip that the site marks with its colour (the colour cards in many tools and libraries do this);
  • you right-click a short piece of text that is only a hex code, such as #D3AF37.

The colour section then offers:

ItemWhat it does

The Colour tools row is still there too, and every tool you open from it starts with the colour you right-clicked.

The keyboard shortcut

Press Ctrl + Shift + C on any page that loads the Colour Tools to open the launcher. It opens where you last right-clicked, or near the top-left corner if you have not right-clicked yet.

If you have text selected that is exactly a hex code (3 or 6 digits, with or without #), the tool you then pick in the launcher opens with that colour. Select #1E40AF in an article, press the shortcut, choose Contrast System, and the pair is ready to check.

A ?color= link

Add ?color= and a colour to the address of any page on the site, and the Color Inspector opens over that page with the full read-out for the colour. For example:

https://auricartisan.com/?color=CEA1B5
https://auricartisan.com/library/?color=1E40AF&on=FFFFFF&ctab=contrast
ParameterWhat it doesAccepted values
color, colour or hexThe colour to inspect. If you list several, the first is inspected and the rest appear as comparison colours.See the forms below. Separate several colours with a comma, a semicolon or a vertical bar.
on, bg, against or vsOne or more comparison colours. They appear under Compare and as extra rows in the Contrast and Vision tabs.Same forms as color.
ctabThe Inspector tab to open on.overview, formats, contrast, vision, harmony, names, mind (the Psychology tab), scales, science, export

The colour can be written as:

  • a hex code with 3, 4, 6 or 8 digits: CEA, CEA1B5, CEA1B5CC (the 4- and 8-digit forms carry transparency);
  • rgb() or rgba(), hsl() or hsla(), hwb(), for example rgb(206 161 181);
  • three numbers separated by spaces, read as red, green and blue: 206+161+181;
  • a CSS colour name such as rebeccapurple or tomato;
  • a fragment of a hex code. One digit is read as a grey (C becomes #CCCCCC), two digits are repeated (CE becomes #CECECE), five or seven digits are padded with the last digit, and anything longer than eight digits keeps the first six. The Inspector then shows a small tag saying which text it started from.

Important: Leave out the #, or write it as %23. In an address, # starts the page fragment, so ?color=#CEA1B5 reaches the site without a colour.

In an address bar, a space can be typed as + or %20. When a value contains brackets, such as rgb(206 161 181), separate several colours with ; or |, because a comma is then read as part of the colour.

When the Inspector was opened by a link, it keeps the address bar in step with what you see: change the colour or the tab and the color and ctab values update, so copying the page address shares the current read-out. If you open a second ?color= link, or go back and forward between two, the open Inspector switches colour instead of opening another panel. An Inspector opened from the launcher leaves the address bar alone.

From other tools

  • The Color Inspector's Open in list opens eight other Colour Tools with the colour you are inspecting. See Color Inspector.
  • The Design Engine can open Colour Tools with your system's primary colour. See Design Engine.

The launcher

The launcher is a small dark card titled Color Tools, with "Auric Artisan · Tools" in small capitals above the title. It lists all 14 tools in four groups, each heading followed by the number of tools in it.

  • Essentials (6): Color Inspector (INSP), Accessibility Lab (A11Y), Contrast System (CR), Color Name Finder (NAME), Animation Contrast (ANIM), Type Readability Sim (TYPE).
  • Explore (3): Color Library (LIB), Color Psychology (PSY), Pantone & Named Lookup (PMS).
  • Design (3): Harmony Studio (HARM), Gradient Library (GRAD), CMYK Soft-Proof (CMYK).
  • Deep dive (2): Color Formulation (FORM), Color Space Converter (SPACE).

Each row shows an icon, the tool's name and its short tag. Hover over a row to see a tooltip with a one-line description of the tool.

Search

The search box at the top says "Search 14 tools…". Type to filter the list as you go. The search matches words in the tool names and in their descriptions, so apca, video, pantone or print all find the right tool. Groups with no match disappear. If nothing matches, the launcher says "No tools match your search."

Keyboard use

Moving, resizing and closing

  • Move: drag the launcher by its header.
  • Resize: drag its bottom-right corner. On a narrow screen the tools stack in one column instead of two.
  • Close: select the close button (×), press Esc, click anywhere outside the launcher, or open a tool. Opening a tool closes the launcher.

The footer has two links that leave the page: View all tools ("Browse the complete toolkit") and Open dashboard ("Your tools & recent activity").

The panel window

Every tool opens in the same kind of floating window.

The title bar

The title bar shows a grip, the tool's name and the label "Color Tools", then six icon buttons. Hover over one to see its tooltip.

Button (tooltip)What it does
Chain icon ("Link — sync controls with other linked panels")Turns linking on or off for this panel (see below).
Two squares ("Open another instance of this simulation")Opens a second copy of this tool, offset slightly from the first.
Pin icon ("Pin — prevent auto-replacement when over the panel limit")Keeps the panel open when the panel limit is reached.
Dash ("Minimize to dock")Hides the panel. Bring it back from its tab on the control bar.
Square ("Maximize / restore")Fills the browser window, leaving a small margin. Select it again to go back.
Cross ("Close")Closes the panel.

Linking. When two or more panels are linked, changing a control in one changes the matching control in the others. This is most useful with two copies of the same tool, made with the two-squares button. Tools that share a control, such as a background colour field, follow each other too. A pinned panel is also skipped by Close all but pinned on the control bar.

Moving, resizing and focus

  • Drag the title bar to move a panel. You cannot drag a maximised panel.
  • Double-click the title bar to maximise or restore.
  • Drag the corner handle at the bottom right to resize. On a computer a panel is at least 520 by 420 pixels, and it always stays inside the browser window.
  • Click anywhere in a panel to bring it to the front.
  • Each tool remembers the size and position you last gave it, and whether it was pinned, and reopens there next time.

While a tool loads, the panel shows a small card with the tool's name and a progress bar. If a tool cannot open, the panel says "Couldn't open" with the tool's name and a short reason.

Keyboard in a panel

KeyWhat it does
EscLeaves full-window view if the panel is maximised. Otherwise it closes the panel that has focus.

Note: Esc closes the panel even when your cursor is in one of its fields. If you only meant to dismiss a dropdown list, click outside the list instead.

How many panels can be open

Up to five panels can be open at once. If you open a sixth, the oldest panel that is not pinned closes to make room. If all five are pinned, the new tool does not open until you unpin or close one.

Opening a tool that is already open brings its panel to the front (and restores it if it was minimised) instead of opening a second one. The panel keeps the colour it already has. Use the two-squares button in the title bar when you want two copies side by side.

Theme and small screens

The launcher, the panels, their dropdown lists and the control bar keep the same dark look whichever site theme you use, so the tools look the same on a light page and a dark page.

When a panel is narrow (under roughly 780 pixels wide), its sidebar moves above the main area. On a phone, a panel takes the full width of the screen and buttons grow to a comfortable touch size.

The control bar

While at least one panel is open, a slim bar appears at the bottom-right of the window. Drag it by its grip (the dotted handle at its left end) to move it; its position is remembered.

From left to right the bar holds five layout buttons, one tab per open panel, a count and a menu button.

Part (tooltip)What it does
Grid icon ("Tile in a grid")Tiles the panels to fill the window: 1 fills it, 2 side by side, 3–4 in 2 × 2, 5 in 3 × 2.
Split icon ("Split left and right")Places the panels side by side at full height.
Split icon ("Split top and bottom")Stacks the panels at full width.
Cascade icon ("Cascade with an offset")Gives each panel the same size and staggers them diagonally.
Stack icon ("Stack them centred")Centres every panel in the same place, the last one in front.
Panel tabsSelect a tab to bring that panel to the front and restore it if minimised.
CountHow many panels are open out of five, for example 2/5.
Three dots ("More panel actions")Opens the menu below.

The layout buttons act on panels that are neither minimised nor maximised. Small icons on each tab show whether that panel is pinned, synced, minimised or maximised, and its tooltip spells the state out.

On a phone the bar runs along the bottom edge and shows the panel tabs, the count and the three-dots button; the layout buttons are hidden.

What all 14 tools share

  • Colour fields. Most tools use the same colour field: a colour swatch that opens your browser's colour picker, a text box for a hex code, and a dice button (Random color tooltip) that picks a random colour. The text box accepts 3, 4, 6 or 8 hex digits, with or without #. The tool updates as soon as the text is a valid code.
  • Live results. There is no "calculate" button. Every change updates the results at once.
  • Copying. When you copy a value, a short message such as "Copied: #D3AF37" appears at the bottom of the screen.
  • Dropdowns. Select a dropdown to open its list, then select an option. Esc, a click outside, or scrolling closes the list.
  • Tooltips. Many buttons and controls explain themselves when you hover over them.
  • Vision simulations. The tools that preview colour-vision deficiency use the same set of filters, so a result in one tool matches the others. See Accessibility Lab for what each filter simulates and its limits.
  • A fresh start each time. A tool starts from its default colours, or from the colour you opened it with. Colours and settings are not kept after you close a panel; only the panel's size, position and pin state are.
  • Everything runs in your browser. Colours, images and videos you use in the tools are not uploaded.
