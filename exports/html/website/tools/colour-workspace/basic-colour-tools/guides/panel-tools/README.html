Panel tools

The seven tools that open as panels in the Basic Color Tools workspace, with a guide for each.

These are the seven tools you open from the Basic Color Tools workspace. Each opens as a floating panel with a controls sidebar and a main area. The level column shows whether the tool appears under Basic or Advanced in the Catalogue's level switch.

GuideCategoryLevelIn one line
palette-studio.mdGenerateBasicLive palette generator with harmony, WCAG and accessibility modes, locking, OKLCH editing, image extraction and eight exports.
palette-remix.mdGenerateAdvancedTurns seed colours into four styled variant palettes; copy CSS, JSON or all HEX codes.
gradient-maker.mdGenerateBasicLinear, radial and conic gradients with any number of stops, perceptual interpolation, easing and CSS, SVG, PNG, JSON and Tailwind export.
colour-picker.mdPickBasicOne colour in eight formats, with harmonies, colour-vision previews, chromaticity and contrast notes.
colour-battle.mdPickAdvancedScores two palettes against each other for contrast, separation and colour-vision resilience.
collage-maker.mdComposeAdvancedArranges your images in one of 29 layouts and exports a 4K PNG.
quick-converter.mdConvertBasicConverts one colour into fourteen notations and compares two colours.

For how panels open, move and close, see Workspace and panels. Every control is also listed in the Reference.
