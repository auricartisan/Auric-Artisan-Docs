Related tools and reading

Tools and services that go with the Icon Library.

Services

  • Icon CDN: the service that serves these icons, with its loader, embedding, export and licences.
  • Font CDN: the matching service for fonts.

Tools

  • Font Library: the same kind of browser for 2,213 font families.
  • Basic Color Tools: pick and test colours for your icons.
  • Contrast Checker: check that an icon colour stands out from its background.
  • Design System Generator: build the colours and type your icons sit among.
