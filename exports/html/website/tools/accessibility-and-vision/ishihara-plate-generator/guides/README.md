# Ishihara Plate Generator documentation — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | The list of Ishihara Plate Generator guides with one line on each. |
| [getting-started.html](getting-started.html) | Open the Ishihara Plate Generator, learn the screen, and generate and inspect your first plates. |
| [build-the-standard-38.html](build-the-standard-38.html) | Generate the fixed 38-plate set, the composition a printed plate book uses, from a single seed. |
| [export-plates.html](export-plates.html) | Download plates as PNG or SVG, export every plate as a ZIP, save a seeds file, and rebuild a plate from its seed. |
| [generate-plates.html](generate-plates.html) | Use the Lab to choose a plate type, palette and difficulty, generate single plates or batches, make custom plates, fine-tune the dots, and read the plate cards. |
| [read-the-diagnostics.html](read-the-diagnostics.html) | Understand each plate's quality score, its four weighted components, and how well it hides from each colour-vision deficiency. |
| [reference.html](reference.html) | Every control, option, default and output of the Ishihara Plate Generator. |
| [troubleshooting.html](troubleshooting.html) | Common problems with the Ishihara Plate Generator, why they happen, and what to do. |
| [faq.html](faq.html) | Short answers to common questions about the Ishihara Plate Generator. |
