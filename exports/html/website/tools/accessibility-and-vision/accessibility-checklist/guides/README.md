# Accessibility Checklist documentation — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | The list of Accessibility Checklist guides with one line on each. |
| [getting-started.html](getting-started.html) | Open the Accessibility Checklist, learn the screen, and mark your first check. |
| [attach-evidence.html](attach-evidence.html) | Add screenshots to a check and annotate them with the pen, highlighter, arrows, boxes, redaction and numbered callouts. |
| [export-your-results.html](export-your-results.html) | Use the Export tab to print your findings, copy them as Markdown for an issue tracker, or clear your work. |
| [laws-by-jurisdiction.html](laws-by-jurisdiction.html) | The Reference tab of the Accessibility Checklist: what the WCAG levels mean and what the law asks for in 15 jurisdictions. |
| [the-50-checks.html](the-50-checks.html) | Every check in the Accessibility Checklist, area by area, with its WCAG criterion, level and how much the Analyzer can decide. |
| [work-through-the-checklist.html](work-through-the-checklist.html) | Select checks, mark them Pass, Fail or N/A, filter the list, fold areas, read the meter, and use the one-check view on a phone. |
| [reference.html](reference.html) | Every control, label, message and stored item of the Accessibility Checklist. |
| [troubleshooting.html](troubleshooting.html) | Common problems with the Accessibility Checklist, why they happen, and what to do. |
| [faq.html](faq.html) | Short answers to common questions about the Accessibility Checklist. |
