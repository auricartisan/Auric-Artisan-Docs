# Using Perception and Vision — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | Contents of the how-to documentation for the Perception Vision tool. |
| [getting-started.html](getting-started.html) | Open Perception Vision, learn the layout of the Lab tab and run a first colour vision simulation over the test card and your own image. |
| [check-a-palette-and-export.html](check-a-palette-and-export.html) | Run a list of hex colours through the active simulation, find colours that become indistinguishable, and export CSV, clipboard text, the frame, the settings and links. |
| [read-the-checks.html](read-the-checks.html) | Understand the grey-ramp test, every readout under the frame, the renderer agreement check, and the Simulation and Modes tabs. |
| [simulate-a-design.html](simulate-a-design.html) | Choose a source, run any of the eight simulations with its settings, relight the scene, apply adjustments and presets, and compare the result. |
| [reference.html](reference.html) | Every tab, control, readout, message and file format in Perception Vision, with ranges and defaults. |
| [troubleshooting.html](troubleshooting.html) | Symptoms, causes and fixes for the camera, WebGL2, uploads, readouts that say n/a, links and copying in Perception Vision. |
| [faq.html](faq.html) | Short answers to common questions about Perception Vision. |
