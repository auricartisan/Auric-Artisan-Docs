Psychophysics Bench glossary

Psychophysics and display terms used in the Psychophysics Bench, each explained briefly.

TermMeaning
2AFC (two-interval forced choice)A task with two intervals, one holding the stimulus; the observer must pick one, so chance is 50%
Adaptive staircaseA procedure that sets each trial's stimulus from the previous answers so trials cluster near threshold
AliasA false pattern that appears when a screen is asked to draw a frequency above its Nyquist limit
Background (mean luminance)The grey the contrast swings around; given as an 8-bit code and converted to relative luminance
Bayesian trackerA procedure that keeps a probability distribution over the threshold and updates it after each answer
BootstrapEstimating the uncertainty of a result by refitting many resampled copies of the data
Constant stimuliA method that tests at fixed contrasts rather than adapting; here, at the starting contrast only
Criterion (c) and βSignal-detection measures of an observer's willingness to say "yes"
d′ (d-prime)A signal-detection measure of sensitivity that separates seeing from willingness to say "yes"; needs stimulus-absent trials
Decibel stepA step size given as a ratio: 20 × log₁₀(ratio); 2 dB multiplies or divides contrast by about 1.26
Degrees per pixelThe visual angle one pixel covers: atan(pixel pitch ÷ viewing distance)
Envelope σThe width of a Gabor's Gaussian envelope, in degrees of visual angle
Gabor patchA sine-wave grating multiplied by a Gaussian, fading smoothly into the background
Geometric meanThe average of values on a logarithmic scale; used because the staircase steps by ratios
Guess rateThe proportion correct expected by chance: 50% in two-interval forced choice
Lapse rateThe small proportion of errors an observer makes even on easy trials
Michelson contrast(Lmax − Lmin) ÷ (Lmax + Lmin), where L is luminance
Nyquist limitThe finest frequency a pixel grid can show: half a cycle per pixel
OrientationThe angle of the grating's stripes, in degrees
Psychometric functionThe curve relating stimulus strength to the probability of a correct or "yes" response
Relative luminanceThe lightness-related quantity Y from 0 (black) to 1 (white), obtained from a screen value through the sRGB curve
ReversalA trial at which the staircase changes direction
Spatial frequencyHow many stripe cycles fall within one degree of visual angle (c/deg)
sRGB transfer curve (EOTF)The standard curve relating a screen code value to light output
ThresholdThe stimulus strength at which the observer is correct a stated proportion of the time
Transformed up-down (Levitt)Staircases that step down after n correct in a row and up after an error, converging at p where pⁿ = 0.5
Warm-up reversalsThe first two reversals, discarded because the staircase is still approaching threshold
Yes / no detectionA task with one interval, stimulus present on some trials, where the observer says whether it was seen
