Material Under Light shortcuts

Keyboard and pointer actions in the Material Under Light tool.

The tool has no keyboard shortcuts of its own beyond these. Site-wide shortcuts are described in Site features.

ActionWhereResult
Select a cardThe five lobe cards under the sampleChooses that lobe
Drop a fileThe spectrum plot on the Lab tab, or Drop a reflectance file on the Data tabLoads a measured reflectance
ClickThe spectrum plot or Drop a reflectance fileOpens a file chooser
Enter or SpaceFocused Drop a reflectance file areaOpens a file chooser
Enter or SpaceA focused row on the Data tabExpands or collapses the row
Click a tab name in the page textNote strip and hintsSwitches to that tab
TabAnywhereMoves between controls; sliders then respond to the arrow keys
