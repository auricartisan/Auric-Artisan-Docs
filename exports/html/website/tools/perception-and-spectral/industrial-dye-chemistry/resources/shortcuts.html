Dye in Solution shortcuts

Keyboard and pointer actions in the Dye in Solution tool.

The tool has no keyboard shortcuts of its own beyond these. Site-wide shortcuts are described in Site features.

ActionWhereResult
Drop a fileThe spectrum plot on the Lab tab, or Drop a spectrum on the Data tabLoads a measured spectrum into the form chosen on the Data tab
ClickThe spectrum plot or Drop a spectrumOpens a file chooser
Enter or SpaceFocused Drop a spectrum areaOpens a file chooser
Enter or SpaceA focused row on the Data tabExpands or collapses the row
Click a tab name in the page textNote strip and hintsSwitches to that tab
TabAnywhereMoves between controls; sliders then respond to the arrow keys
