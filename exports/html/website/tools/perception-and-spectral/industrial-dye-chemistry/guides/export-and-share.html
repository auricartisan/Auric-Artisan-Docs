Export and share

Download the 81-row spectrum CSV and the whole-bath JSON, and copy a link that rebuilds the bath.

Open the Export tab. What to take switches the preview between The spectrum (the first lines of the CSV), The whole bath (the first part of the JSON) and A link to this; the note above it gives the row count. Nothing leaves the page until you press a button. Exports are never gated on a tick-box.

ButtonResult
Download the spectrumSaves dye-in-solution-spectrum.csv
Download the bathSaves dye-in-solution-bath.json
Copy a link to this bathCopies a link; the message Link copied confirms it, or the link is shown if the clipboard is unavailable

The spectrum CSV

The file starts with # header lines that state everything a reader needs to compare it with another spectrum:

  • the time; the sampling (380–780 nm at 5 nm, 81 samples); the observer (CIE 1931 2°, not interpolated); the illuminant;
  • the bath's pH and path length;
  • for each component: name (and "(disabled)" if muted), concentration, pKa, both forms' λmax and ε, whether the band shape is MEASURED or SYNTHESISED, the base fraction at this pH and the isosbestic point;
  • the peak absorbance and whether it is inside the Beer–Lambert linear range;
  • which white point the swatch and the L*a*b* use;
  • the colour inconstancy (ΔE₀₀) to each other illuminant;
  • statements that the file is not a metamerism index, that F11 is not held, that it is not a fastness test, and that it holds no hazard data;
  • the tolerance sweep's median and 95th percentile, if you ran one.

Then 81 rows with these columns:

ColumnMeaning
wavelength_nm380 to 780 in steps of 5
absorbanceThe whole bath's absorbance
transmittance10 to the power of minus the absorbance
eps_acid, eps_baseThe selected dye's two forms, molar absorptivity
observer_x, observer_y, observer_zThe CIE 1931 2° colour-matching functions

spectrumWavelengths, absorbance and transmittance arrays

Links

A link rebuilds the bath: ph, path, ill (d65, d50, a or e) and dyes, a comma-separated list of id:pKa:concentration-in-µM, for example:

https://auricartisan.com/tool/general/spectral-tools/industrial-dye-chemistry/?ph=3.50&path=1.00&ill=d65&dyes=weak-acid:3.50:34.00,anthraquinone-blue:11.80:40.00

Dye identifiers: weak-acid, mid-range, high-range, azo-red, anthraquinone-blue, yellow. A link does not carry muted state, measured spectra or sweep tolerances.

You should now have a file that anyone can read without the page, with its light, observer and data sources stated.
