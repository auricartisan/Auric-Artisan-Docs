# Using Dye in Solution — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | Contents of the how-to documentation for the Dye in Solution tool. |
| [getting-started.html](getting-started.html) | Open Dye in Solution, learn the layout of the Lab tab and read the default bath. |
| [build-a-bath.html](build-a-bath.html) | Add, select, mute and remove dyes, set concentration and path length, and understand absorbance and the Beer–Lambert law. |
| [compare-lights.html](compare-lights.html) | Choose the illuminant, read the colour readouts, compare the bath under every light, and understand colour inconstancy, metamerism, dominant wavelength and purity. |
| [export-and-share.html](export-and-share.html) | Download the 81-row spectrum CSV and the whole-bath JSON, and copy a link that rebuilds the bath. |
| [run-a-titration.html](run-a-titration.html) | Change the pH, understand pKa, the base fraction and the two forms of a dye, animate a titration and find the isosbestic point. |
| [run-a-tolerance-sweep.html](run-a-tolerance-sweep.html) | Estimate how far a bath's colour moves when concentration, path length and molar absorptivity vary within stated tolerances. |
| [use-a-measured-spectrum.html](use-a-measured-spectrum.html) | Replace a drawn dye band with a measured UV–Vis molar absorptivity spectrum, and go back to the drawn bands. |
| [reference.html](reference.html) | Every tab, control, readout, message and file format in Dye in Solution, with ranges and defaults. |
| [troubleshooting.html](troubleshooting.html) | Symptoms, causes and fixes for Dye in Solution: flags, refused spectra, component limits, the plot and links. |
| [faq.html](faq.html) | Short answers to common questions about Dye in Solution. |
