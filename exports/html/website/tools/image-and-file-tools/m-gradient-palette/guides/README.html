M-Gradient Palette documentation

The list of guides, the concept page, the reference, troubleshooting and FAQ for the M-Gradient Palette.

This folder holds the task guides for the M-Gradient Palette, a concept page on colour spaces, interpolation and gamut mapping, the full reference, and the troubleshooting and FAQ pages. Read Interpolation and gamut if you want to know why the same two colours give different ramps.
