SVG Recolour glossary

Definitions of the terms used in SVG Recolour.

TermMeaning
Active contentParts of an SVG that run code: scripts, event handlers and javascript: links
APCAAdvanced Perceptual Contrast Algorithm; lightness contrast in Lc units, signed by polarity
CIEDE2000 (ΔE₀₀)The CIE's standard formula for how different two colours look
Closest pairThe two colours in the file with the smallest CIEDE2000 difference
Contrast ratioThe WCAG 2 measure of luminance difference, from 1:1 to 21:1
CSS colour nameOne of the 148 named colours of CSS, such as red or rebeccapurple
currentColorA value that takes the colour from the page the SVG is placed in
Custom propertyA CSS variable, such as --colour-01, holding a colour
DichromacyColour vision with one of the three cone types missing
HarmonyA set of colours at fixed angles round the colour wheel
Left aloneA value with no colour the tool can change, listed but not written
OKLCHA perceptual colour space of lightness, chroma and hue, used for the harmonies
OccurrenceOne place in the file where a colour value is written
Paint propertyA property that sets colour, such as fill or stroke
Presentation attributeAn SVG attribute that sets a style directly, such as fill="#E5484D"
Protanopia, deuteranopia, tritanopiaColour vision missing the long (red), medium (green) or short (blue) wavelength cones
Source formThe way a colour was written: hex, shorthand, rgb(), hsl() or a name
Style attributeAn SVG style="…" attribute holding CSS declarations
Style sheetCSS inside a <style> element in the SVG
SVGScalable Vector Graphics: an XML format for drawings
TargetThe colour an original colour will become
WCAGThe Web Content Accessibility Guidelines; version 2.2 defines the contrast ratio used here
Well-formedXML that follows the syntax rules, so it can be parsed
WrittenAn occurrence the tool actually rewrote
