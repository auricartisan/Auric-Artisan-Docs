Collage Maker glossary

Definitions of the terms used in the Collage Maker.

TermMeaning
ArrangementA grid of equal cells, given as columns × rows, into which the visible pictures are placed in stacking order
CanvasThe rectangle the collage is drawn on; always 1200 pixels wide, with a height set by the shape
Canvas coveredThe share of canvas pixels that pictures paint, found by drawing with and without them and counting differences
CellOne rectangle of a grid arrangement, sized from the canvas, padding, gap and grid
ChequerboardThe on-screen pattern behind the canvas that shows transparency; never exported
Corner radiusHow far the canvas corners are rounded, in pixels; exports are clipped to the rounded shape
Export scaleThe factor, 0.25× to 4×, by which the canvas size is multiplied when an image is saved or copied
FillScaling a picture so it covers its whole cell; in this tool the excess is not trimmed away
FitScaling a picture so all of it lies inside its cell, leaving part of the cell empty if the shapes differ
GapThe space between neighbouring cells of a grid arrangement
GuidesThe thirds lines across the canvas and the dashed lines through the selected picture's centre; screen only
History stepOne recorded change that Undo can reverse; the history holds up to 60
JPEGA lossy image format that makes small files from photographs and cannot store transparency
LayerOne picture in the stack; the layers list shows them top first
Off-canvas areaThe share of total picture area outside the canvas, which will not appear in an export
OpacityHow solid a picture is drawn, from 0% (invisible) to 100% (solid)
OverlapThe share of the canvas painted by two or more pictures
PaddingThe margin between the canvas edge and the block of grid cells
PNGA lossless image format that can store transparency
ReadingA small JSON file recording what was measured about the collage
Rule of thirdsA composition guide dividing the canvas into three equal parts across and down
Session fileA JSON file with the canvas settings and each picture's placement, but no image data
SnapRounding a dragged picture's centre to the nearest multiple of 10 px
