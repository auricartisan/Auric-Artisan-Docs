Pick exact colours

Use the live eyedropper to read any pixel, pin exact colours, and copy them.

The palette is made of averages. When you need the exact colour of one spot, such as a logo's red or a product's trim, use the eyedropper and pins.

Read a pixel

  1. Load a picture on the Workbench tab.
  2. Hover the Preview. The readout beside the swatch under it shows the colour under the pointer:
#C0392B
RGB(192,57,43) · HSL(6°,63%,46%) · L=0.1431 · px(212,88)
PartMeaning
#C0392BThe hex value
RGB(…)Red, green and blue, 0 to 255
HSL(…)Hue in degrees, saturation and lightness in percent
L=Relative luminance, 0 (black) to 1 (white), as used by WCAG
px(…)The pixel's position in the working copy of the picture, not in the original

When the pointer leaves the preview, the readout returns to Hover the image to preview.

The eyedropper reads the working copy, which is shrunk to fit 800 × 500. On a large photograph each working pixel stands for several original pixels.

Pin a colour

  1. Hover the spot you want.
  2. Click. The exact colour is added to Pinned on the right.
RuleDetail
LimitUp to 24 pins. Adding a 25th removes the oldest
DuplicatesA colour already pinned is not added again
Transparent pixelsNearly transparent pixels cannot be pinned
CounterThe heading reads Pinned with the count, for example 3 of 24

Clicking directly on the preview is the reliable way to pin. The Pin button beside the readout pins the colour under the pointer, but moving the pointer onto the button clears the readout first, so it usually has nothing to pin.

Use your pins

  • Select a pin to copy its hex value.
  • Pins are included when you copy or download the palette as JSON, in a picks list. The Hex, CSS, SVG and CSV exports contain the extracted palette only.
  • Reset clears the pins along with the picture.

Copy a palette colour

Select any swatch under Extracted palette to copy its hex value.

The page shows no confirmation when something is copied. Paste it to check.
