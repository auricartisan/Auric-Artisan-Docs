Collections shortcuts

Keyboard and mouse actions on the Collections page.

Mouse

ActionResult
Select a cardOpens the tool and counts one open towards Most used.
Select a card's pin buttonPins or unpins the tool.
Right-click a cardOpens the card menu.
Right-click elsewhereOpens the site's usual right-click menu.
Hover a cardShows a tooltip with category, mode, address and tags.
Hover the Start here sliderPauses autoplay.

Keyboard

KeysWhereResult
TabAnywhereMoves between links, buttons and filter boxes.
Left / RightStart here slider, when focusedPrevious or next featured tool.
Context-menu key, or Shift + F10A focused cardOpens the card menu.
EscapeCard menuCloses the menu.
EscapeFloating search panelCloses the panel and returns focus to its button.
SpaceA focused tick boxTicks or unticks a category or topic.

The site-wide shortcuts, such as Alt + R for reading mode and Alt + T to switch theme, also work here. See Site features.
