Collections docs

The task guides and reference pages for the Collections tool catalogue.

This folder holds the working guides for the Collections page at https://auricartisan.com/collections/. Start with the getting-started tour, then use the task guides for specific jobs. The reference lists every control and every tool in the catalogue.
