# Collections docs — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | The task guides and reference pages for the Collections tool catalogue. |
| [getting-started.html](getting-started.html) | Tour the Collections page and find your first tool. |
| [browse-search-and-filter.html](browse-search-and-filter.html) | Narrow the tool catalogue with search, category and topic filters, sort orders and layout options. |
| [card-menu.html](card-menu.html) | Right-click any tool card to pin, open or copy it, and to change the grid's view, density, columns and sort order. |
| [pin-and-recommendations.html](pin-and-recommendations.html) | Pin the tools you rely on, see your most used tools first, understand the Recommended order, and reset all of it. |
| [show-basic-or-advanced-tools.html](show-basic-or-advanced-tools.html) | Understand why Collections may show fewer than 30 tools, and switch between Basic, Advanced, Everything and a custom set. |
| [reference.html](reference.html) | Every control, filter, sort order and menu item on the Collections page, and the full catalogue of 30 tools. |
| [troubleshooting.html](troubleshooting.html) | Fix common problems on the Collections page, from missing tools to lost pins. |
| [faq.html](faq.html) | Short answers to common questions about the Collections tool catalogue. |
