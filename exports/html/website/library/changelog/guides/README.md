# Changelog: docs — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | Guides to the changelog page and a summary of every release. |
| [getting-started.html](getting-started.html) | Use the changelog page to find a release, search every change, filter by type and by what was touched, and link to a release. |
| [releases.html](releases.html) | A user-facing summary of every release in the Auric Artisan changelog, newest first. |
| [faq.html](faq.html) | Short answers about the Auric Artisan changelog. |
