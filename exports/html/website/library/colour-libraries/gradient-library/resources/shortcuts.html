Gradient Library shortcuts

Keyboard and pointer actions in the Gradient Library.

Keyboard

KeysWhereResult
/Anywhere, when not typingFocuses Search by name, hex or scheme….
TabGridMoves between cards and their buttons.
Enter or SpaceA focused cardOpens it on Inspect.
EscapeShare link or design tokens dialogCloses it.

Pointer

ActionResult
Select a cardOpens it on Inspect.
Select CSS on a cardCopies its CSS.
Select a stop's hex on InspectCopies the hex.
Select a value on TagsFilters the Library by it (except Banding).
Select a card heading on Vision, Accessibility, Pair, Tags, Stats or ExportFolds or unfolds the card.

The site-wide shortcuts also work here. See Site features.
