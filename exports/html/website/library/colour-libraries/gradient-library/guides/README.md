# Gradient Library documentation — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | The task guides, reference, troubleshooting and FAQ for the Gradient Library. |
| [getting-started.html](getting-started.html) | Open the Gradient Library, learn what each part of the screen does, and check, pick and export a first gradient. |
| [browse-search-and-filter.html](browse-search-and-filter.html) | Narrow 8,192 gradients by search, method, scheme, complexity, stops, interpolation, easing, score and banding, and sort the results. |
| [check-your-gradient.html](check-your-gradient.html) | Enter your gradient's stops in "Will your gradient band?", read the verdict, find the worst step and fix it. |
| [copy-export-and-share.html](copy-export-and-share.html) | Copy a gradient's CSS, download it as a CSS class, JSON, SVG, PNG or Tailwind token, export design tokens, share a link, and export whole filtered sets. |
| [inspect-a-gradient.html](inspect-a-gradient.html) | Read the Inspect tab: the preview, twelve quick facts, the CSS, the colour stops, the generator metrics and quick exports. |
| [save-gradients.html](save-gradients.html) | Save gradients, find them on the Saved tab, and reach them from your Library. |
| [tags-and-statistics.html](tags-and-statistics.html) | Browse the collection by tag on the Tags tab, and read distributions for your filtered set on the Stats tab. |
| [test-vision-contrast-and-text.html](test-vision-contrast-and-text.html) | Use the Vision, Accessibility and Pair tabs to see a gradient under colour vision deficiencies, measure its contrast along the ramp, and test a text colour on it. |
| [reference.html](reference.html) | Every control, filter, sort order, tab, output, file name and message in the Gradient Library. |
| [troubleshooting.html](troubleshooting.html) | Symptoms, causes and fixes for problems in the Gradient Library. |
| [faq.html](faq.html) | Short answers to common questions about the Gradient Library. |
