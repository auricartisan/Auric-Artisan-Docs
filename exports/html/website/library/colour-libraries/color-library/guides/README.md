# Color Library documentation — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | The list of task guides, the reference, troubleshooting and FAQ for the Color Library. |
| [getting-started.html](getting-started.html) | Open the Color Library, learn what each section and tab does, and look up your first colour. |
| [browse-search-and-filter.html](browse-search-and-filter.html) | Narrow the 8,192-colour atlas with the two search boxes, eight filters and six sort orders, and move around the grid. |
| [choose-by-requirement.html](choose-by-requirement.html) | Use the seven requirement chips to narrow the atlas by what a colour has to do, and read what each requirement costs. |
| [copy-and-export.html](copy-and-export.html) | Copy one colour in six formats, download it as JSON, SVG or PNG, and download every matching colour in seven formats. |
| [find-nearest-colours.html](find-nearest-colours.html) | Paste a colour in any CSS format and read the five catalogued colours closest to it, with their distance and contrast. |
| [read-a-colour.html](read-a-colour.html) | Everything on The colour tab: the contrast verdict, the colour-blindness values, every notation and metric, and the nearest neighbours. |
| [read-the-statistics.html](read-the-statistics.html) | Use the four histograms on the Stats tab to see how hue, lightness, chroma and contrast are spread across the colours you have filtered. |
| [save-colours.html](save-colours.html) | Save colours with the star, find them on the Saved tab, and reach them again from your Library. |
| [reference.html](reference.html) | Every control, filter, sort order, tab, output, file name and message in the Color Library. |
| [troubleshooting.html](troubleshooting.html) | Symptoms, causes and fixes for problems in the Color Library. |
| [faq.html](faq.html) | Short answers to common questions about the Color Library. |
