# Harmony Library documentation — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | The task guides, reference, troubleshooting and FAQ for the Harmony Library. |
| [getting-started.html](getting-started.html) | Open the Harmony Library, learn the screen, and identify, inspect and export a first harmony. |
| [analyse-the-collection.html](analyse-the-collection.html) | Use the Theory, Accessibility and Stats tabs to see how schemes, families, adherence and contrast are distributed across the harmonies you have filtered. |
| [browse-search-and-filter.html](browse-search-and-filter.html) | Jump to a harmony by id, search, filter by hue, chroma, lightness and family, and sort the collection. |
| [copy-export-and-share.html](copy-export-and-share.html) | Copy a harmony as hex, CSS, SCSS or Tailwind with role-named variables, download JSON, ASE, SVG or PNG, export design tokens, share a link, and export many harmonies. |
| [identify-your-colours.html](identify-your-colours.html) | Use "What harmony is this?" to find which of the 23 schemes your colours form, how closely, and which schemes it cannot tell apart. |
| [inspect-a-harmony.html](inspect-a-harmony.html) | Read the Inspect tab: colour roles and names, the harmony summary, the colour-theory scheme, pair contrast and each colour's values. |
| [save-harmonies.html](save-harmonies.html) | Save harmonies, find them on the Saved tab, and reach them from your Library. |
| [reference.html](reference.html) | Every control, filter, sort order, tab, output and message in the Harmony Library. |
| [troubleshooting.html](troubleshooting.html) | Symptoms, causes and fixes for problems in the Harmony Library. |
| [faq.html](faq.html) | Short answers to common questions about the Harmony Library. |
