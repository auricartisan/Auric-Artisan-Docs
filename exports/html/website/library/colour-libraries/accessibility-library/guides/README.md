# Accessibility Library documentation — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | The task guides, reference, troubleshooting and FAQ for the Accessibility Color Pair Library. |
| [getting-started.html](getting-started.html) | Open the Accessibility Library, learn the screen, and find passing text colours for a background. |
| [check-your-own-colours.html](check-your-own-colours.html) | Paste your palette into "Or bring your own" to place each colour on the map and see how much lightness each failing colour needs. |
| [look-up-and-browse-the-index.html](look-up-and-browse-the-index.html) | Look up any of five million scored colour pairs by record id, read its WCAG, APCA and Auric SD scores, and browse pairs that pass. |
| [read-the-contrast-map.html](read-the-contrast-map.html) | Choose a ground and a target, explore the contrast map by pointer or keyboard, and read the ratio, APCA value, vision margin and distance to the line. |
| [use-the-picks.html](use-the-picks.html) | Take up to twelve passing foreground colours for your ground, preview them, and copy them as CSS custom properties. |
| [reference.html](reference.html) | Every control, output and message in the Accessibility Color Pair Library. |
| [troubleshooting.html](troubleshooting.html) | Symptoms, causes and fixes for problems in the Accessibility Library. |
| [faq.html](faq.html) | Short answers to common questions about the Accessibility Library. |
