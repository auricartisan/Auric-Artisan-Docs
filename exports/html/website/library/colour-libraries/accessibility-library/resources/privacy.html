Privacy

What the Accessibility Library computes locally and what uses the network.

Computed in your browser

Everything the page shows — the map, the lines, the picks, your pasted colours, the index records and the browse grid — is computed in your browser. The colours you paste and the grounds you try are not sent anywhere and are not remembered after you leave. This page has no saved list.

The only thing it remembers is whether you dismissed the Automate this note, so it stays hidden.

What uses the network

  • The page itself and a small description of the corpus are downloaded from auricartisan.com. If the description does not arrive, the page uses the same built-in values and carries on.
  • Copy as CSS writes only to your clipboard.
  • The API section links to other pages; an API key is only needed if you call the API yourself.

Advertising and analytics follow your consent choices. See Company and legal.
