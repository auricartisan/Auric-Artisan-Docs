Palette Library shortcuts

Keyboard and pointer actions in the Palette Library.

Keyboard

KeysWhereResult
/Anywhere, when not typing in a fieldFocuses Search by id or hex….
TabGridMoves between swatches and buttons.
Enter or SpaceA focused swatchOpens its palette on Inspect.
EscapeShare link or design tokens dialogCloses the dialog.

Pointer

ActionResult
Select a swatch in the gridCopies its hex code.
Select a column on InspectCopies its hex code.
Select a card outside its buttonsOpens the palette on Inspect.
Select a card heading on InspectFolds or unfolds the card.
Select outside a dialogCloses it.

The site-wide shortcuts also work here. See Site features.
