Getting started

Open the Shade Library, learn the screen, and find, check and export a first shade scale.

Open the page

  1. Go to https://auricartisan.com/library/shades/, or open the Learn menu in the site header and select Shade Library under Libraries.
  2. While the collection loads, the grid shows Loading shade library....
  3. The grid fills and the counter reads, for example, 1–24 of 8,192 scales.

If loading fails you see Could not load shade library. See Troubleshooting.

A tour of the screen

The heading

Kicker Auric Artisan · Shades; headline Eight thousand ramps, and 8% of them even.; facts Collection 8,192, 10 methods and Measured in OKLab; and Read the API guide → to the Shade Library's API guide.

A note starting Automate this may appear: browsing is also available through the site's REST API — 3 API credits per call to GET /v1/shade/library — with API docs. Select × to dismiss it.

Browse the collection

A search box (Search by id, hex, token or method…), Shuffle, Open a random scale, and Filter inside results with its own box and Clear.

The tabs

TabWhat it shows
LibraryFilters, sort and the grid. The badge shows how many scales match.
InspectThe scale you last opened.
HarmonyDistributions of methods, hues, profiles and token counts.
AccessibilityWhich scales' tokens can carry text.
StatsFive histograms.
ExportExports for the open scale and for every matching scale.
SavedScales you have saved.

A card

Each card shows the scale as a strip of swatches, each labelled with its token and hex (for example 500 #FF724C), then the scale's id (such as shade_000000), its method (such as Material Like) and Inspect, Copy and Save.

Your first task: a blue scale for a design system

  1. Set Base hue to Blue.
  2. Set Method to Tailwind Like to get the familiar 50–950 token names.
  3. Select Inspect on a scale you like.
  4. Read the Shade summary: Tokens, Auto AA tokens and Min adjacent contrast.
  5. Read the Token contrast ladder: each step's contrast with the better of black or white text.
  6. Under Quick export, select Copy CSS vars. The page confirms CSS variables copied.
  7. Paste the block into your stylesheet and use the variables for surfaces, borders and text.

Result: a full blue scale as CSS custom properties, with the steps that can carry text identified.
