Learn reference

Every control and label on the Learn page and on Learn article pages.

The Learn page (https://auricartisan.com/library/learn/)

ElementWhat it does or shows
Heading lineNumber of articles and total reading time.
Pick up where you left off / Next in the courseYour most recent unfinished article, or the first unread one; with number, title, category, minutes. Shown only after you have opened an article.
Progress barN of 113 read · time left.
Search titles and topicsFilters as you type; every word must match the number, title, summary or category.
Category chipsAll, Foundations, Physics, Vision, Colorimetry, Digital, Design, Print, each with a count. Select again to clear.
Count lineN of 113 · time, shown only when filtered.
Course rowNumber, title (link), category, minutes, tick when read, summary.
Nothing in the course matches that.No results; Show all articles clears the search and category.
FootLinks to the blog and changelog.

If the course list cannot be built (for example, offline), the page shows a plain list of All articles instead.
