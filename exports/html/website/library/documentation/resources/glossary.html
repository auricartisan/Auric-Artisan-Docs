Documentation glossary

Terms used in the documentation library.

TermMeaning
SubjectA tool or topic in the documentation index, such as "Gamut Map".
User guideA document that explains how to use a tool.
Developer referenceA document that explains how a tool works and what it computes.
PairA subject's user guide and developer reference together.
AudienceWhich kind of document the index shows: Both, Guides or References.
API guideA guide to getting a tool's results from your own code through the site's REST API.
Endpoint referenceThe list of the REST API's endpoints and their parameters.
RSSA feed format for following new documents in a news reader.
