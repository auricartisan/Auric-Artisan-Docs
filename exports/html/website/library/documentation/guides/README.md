# Documentation: docs — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| --- | --- |

| [getting-started.html](getting-started.html) | Use the documentation index to find a tool's user guide or developer reference. |
| [all-subjects.html](all-subjects.html) | Every subject in the documentation library, with links to its user guide and developer reference. |
| [read-a-guide.html](read-a-guide.html) | Find your way around a documentation article: the subject list, breadcrumb, pair switch, contents, code blocks and pager. |
| [reference.html](reference.html) | Every control and label on the documentation index and on documentation articles. |
| [troubleshooting.html](troubleshooting.html) | Symptoms, causes and fixes when using the documentation library. |
| [faq.html](faq.html) | Short answers to common questions about the documentation library. |
