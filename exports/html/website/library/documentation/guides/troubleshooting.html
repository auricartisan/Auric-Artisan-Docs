Troubleshooting

Symptoms, causes and fixes when using the documentation library.

A subject disappeared when I chose Guides or References

Why: The subject has only the other kind of document. Hiding it avoids showing a row with nothing to open.

What to do: Select Both.

"No subject matches that. Try a tool name."

Why: No subject name or description contains your text.

What to do: Use a shorter word, or the tool's name as it appears in the site's menus. Descriptions use US spelling ("color").

The guide does not match what I see in the tool

Why: Guides are dated. Some tools have been redesigned since their guide was written — for example the Accessibility Library and the Palette Library.

What to do: Trust the tool. Check the date on the guide, and see this documentation set for current behaviour.

The side list or the pair switch is missing

Why: The article could not load the list of subjects, for example because the connection dropped. The article itself is still complete.

What to do: Reload the page. Use the breadcrumb or your browser's back button to reach the index.

"Press Ctrl C" appears instead of "Copied"

Why: Your browser blocked clipboard access.

What to do: The code is selected for you; press Ctrl + C (on a Mac, the equivalent copy command).
