All documentation subjects

Every subject in the documentation library, with links to its user guide and developer reference.

The documentation library at https://auricartisan.com/library/documentation/ lists 54 subjects and 89 documents. 35 subjects have both a user guide and a developer reference; the rest have one of the two. This page lists them all, in the order the index shows them, with the index's own one-line description.

Note: Some guides describe an earlier version of their tool. Where a guide and the tool disagree, the tool is right. The guides for the Accessibility Library and the Palette Library, for example, describe earlier layouts.

  • Accessibility Gen — User guide · Developer reference. Check foreground and background color pairs against WCAG 2.1, WCAG 2.2, WCAG 3.0 APCA, Auric SD Flexible and Strict.
  • Accessibility Library — User guide · Developer reference. Browse 5,000,000 deterministic foreground/background color pairs, search by id and HEX, filter by WCAG 2.1, WCAG 2.2.
  • Analyzer API — Guide. The URL Analyzer as three REST endpoints: ask what it can check, audit one page from its source with the scope you want.
  • ASCII Art Generator — User guide · Developer reference. Image, text, webcam input, character sets, dithering, Sobel edge detection, render modes, charts, and exports.
  • Auric Artisan Browser Extension — User guide · Developer reference. Install in Chrome, Edge, Brave, Firefox and Safari conversion workflows, use the command palette, pick colors, read HEX, RGB.
  • Auric Artisan Plugins — User guide · Developer reference. Plugins suite across Figma, Penpot, Sketch, VS Code, Alfred, Raycast, Slack.
  • Basic Color Tools — User guide · Developer reference. Floating panels, Palette Studio, Palette Remix, Gradient Maker, Color Picker, Color Battle, Collage Maker.
  • Chromatic Adaptation Dynamic — User guide · Developer reference. Eight CAT methods, 12 illuminants, exponential adaptation timeline, image previews, state maps, LMS and SPD charts.
  • Collage Maker — User guide. Multi-image upload, drag, resize, rotate, layer ordering, lock and visibility controls, smart grid auto-layout.
  • Collage Measurement — Developer reference. A developer reference for how the Collage Maker measures coverage and overlap.
  • Color Atlas Gen — User guide · Developer reference. Generate colour atlas datasets from a command line or a configuration file, and choose colour spaces and metadata.
  • Color Contrast Checker — User guide · Developer reference. Enter a text and background colour as hex or with the native swatch, read the exact WCAG 2.1 ratio to two decimals.
  • Color Science Lab — User guide · Developer reference. 45 floating-panel tools, eight color science domains, linked controls, Compare, Analytics, exports, and library saves.
  • Design System Generator — User guide · Developer reference. How to use the Auric Artisan Design System Generator at /tool/design-engine/: pick an industry.
  • Dye in Solution — Developer reference. A developer reference for the dye-in-solution simulation and the colour science behind it.
  • Font Library — User guide · Developer reference. How to use the Auric Artisan Font Library at /tool/font/: preview 2,213 families with your own text, filter by weight.
  • Gamut Lab — User guide · Developer reference. Standard and custom RGB color spaces, CIE xy and u-prime v-prime diagrams, RGB to XYZ matrices, transfer curves.
  • Gamut Map — User guide · Developer reference. Five RGB color spaces, CIELAB L* slices, ICC rendering intents, sampling, overlays, probe analysis, Delta E playground.
  • Gradient Gen — User guide · Developer reference. Create handmade multi-stop gradients, procedural aurora, nebula, spectral, terrain, thermal, golden, analogous.
  • Gradient Library — User guide · Developer reference. Browse 8,192 generated gradients across 12 methods, 2 to 46 stops, OKLCH metadata, interpolation spaces, easing curves.
  • Gradient Ramp — Developer reference. A developer reference for the gradient ramp tool and its interpolation methods.
  • Harmony Gen — User guide · Developer reference. Generate complementary, split complementary, triadic, tetradic, square, analogous, monochromatic, hexadic, neutral.
  • Harmony Library — User guide · Developer reference. Browse 8,192 deterministic color harmonies across 23 canonical color-theory schemes, search by harmony id, HEX and scheme.
  • HDR Gamut Plot — User guide · Developer reference. Rec.709, Display-P3, and Rec.2020 overlays, CIE xy and u-prime v-prime axes, PQ and HLG tone curves, peak-nit controls.
  • ICC Profile Parser — User guide. Load ICC and ICM files, inspect ICC v2/v4 headers, tag tables, profile IDs, TRC curves, RGB primaries, white points.
  • ICC Profile Reading — Developer reference. A developer reference for how ICC profiles are read, following ISO 15076-1:2010.
  • Illuminants — User guide · Developer reference. CIE standard illuminants, blackbody CCT, SPD charts, CRI Ra and R1-R14, TM-30 interpretation, metamerism index.
  • Image Picker — User guide · Developer reference. Upload images, load image URLs, extract palettes with K-means++, use the canvas eyedropper, pin colors.
  • Industrial Dye Chemistry — User guide · Developer reference. Spectral dye recipes, Beer-Lambert absorbance, Kubelka-Munk K/S mode, pH titration, temperature broadening, turbidity.
  • Ishihara Plate Generation — User guide. Comprehensive guide to generating Ishihara-style color plates: theory, algorithm, parameters.
  • LUT Lab — User guide · Developer reference. Upload 1D and 3D .cube LUTs, use built-in cinematic looks, preview before, after and split views.
  • M-Gradient Palette — User guide. Build color ramps in sRGB, linear RGB, HSL and OKLCH, tune easing and step count, inspect luminance, CIEDE2000 uniformity.
  • Material & Lighting Lab — User guide. Comprehensive user guide for the Material & Lighting Lab: spectral BRDF, pigment reflectance, illuminant configuration.
  • Material Under Light — Developer reference. A developer reference for the material-under-light simulation and the colour science behind it.
  • Neuroscience — User guide · Developer reference. LMS cone responses, DKL opponent channels, retinal ganglion DoG, LGN pathways, V1 Gabor filters, V2 texture boundaries.
  • Palette Gen — User guide · Developer reference. Generate harmony, mathematical, scientific, evolutionary and random color palettes, inspect RGB, HEX, Lab, OKLCH, Delta E.
  • Palette Library — User guide · Developer reference. Browse 5,000,000 deterministic scientific color palettes, search by palette id and HEX, filter by hue, chroma.
  • Perception and Vision — User guide · Developer reference. WebGL2 color vision deficiency simulation, scotopic and mesopic vision, age lens yellowing, macular degeneration.
  • Personalization Generator — User guide · Developer reference. Preference color pools, tune controls, chunked generation, palettes, gradients, typography, UI pairs, posters.
  • Psychophysical Experiment Engine — User guide · Developer reference. 2AFC and yes/no paradigms, Gabor, grating, patch, blob, noise and flicker stimuli, adaptive staircases, QUEST, PEST.
  • REST API — Developer reference. The reference for the site's public REST API: API keys from the account dashboard, authentication and the /v1 endpoints.
  • Shade Gen — User guide · Developer reference. Generate OKLCH shade scales from base colors, create brand-system, accessible-ui, neutral-system, material-like.
  • Shade Library — User guide · Developer reference. Browse 8,192 generated OKLCH shade systems, search by method, token, HEX and name, filter by hue, chroma.
  • SVG Recolour — Developer reference. A developer reference for how SVG Recolour rewrites colours in a file.
  • The Accessibility Corpus API — User guide. How to use the accessibility corpus and contrast map from your own code: browse and page five million pairs under a filter.
  • The Gradient Library API — User guide. How to use the gradient collection from your own code: filter 8,192 generated ramps by whether they band.
  • The Harmony Library API — User guide. How to use the harmony collection from your own code.
  • The Palette Library API — User guide. How to use the palette collection from your own code: five million palettes computed from a 660-byte manifest rather than stored.
  • The Shade Library API — User guide. How to use the shade collection from your own code: 8,192 token ramps each measured for whether it runs one way.
  • Tonal Steps Tints Shades — User guide · Developer reference. HSL, luminance-equal and contrast-driven ramp engines, OKLab, CIELab, sRGB-linear and HSL mixing, tints, shades, tones.
  • Tone Mapping — User guide · Developer reference. Reinhard, Hable, ACES, BT.2446, Uchimura, Log and custom tone mapping, source encoding, color spaces, white points, exposure.
  • Understanding Your Accessibility Report — User guide. A plain guide to reading an accessibility report: what the score means and why it is deliberately hard to raise.
  • URL Analyzer — User guide · Developer reference. Simple and advanced modes, audit workflow, SEO review, accessibility fixes, site scans, reports, and exports.
  • Vision Simulation — User guide · Developer reference. 78 simulations, 11 categories, Basic and Advanced modes, floating panels, linked controls, metrics, Verify, Analytics, exports.
