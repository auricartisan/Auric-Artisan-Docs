Glossary

Plain-language definitions of the account, billing, security and API terms used in the Auric Artisan account area.

Account chip — The photo, first name and plan shown in the site header when you are signed in. Selecting it opens the account menu.

Allowance (included) — The tokens or API credits that come with a plan for each billing month. Included allowances do not roll over.

Annual term — A plan pass bought for twelve months, costing ten times the monthly price.

API credit — The unit that meters REST API calls. One credit is one standard request; heavier endpoints cost more. Separate from tokens.

API key — A secret string that lets your code call the REST API as your account. Shown once when created; begins with aa_live_.

Apprentice — The free plan. Every tool, 100 one-time starter tokens, no API access.

Artisan — The paid plan on sale today: ad-free browsing, watermark-free Pro exports, 250 tokens a month and higher limits.

Auric human check — A short test on the sign-in page (repeat a sequence of three marks) that proves a person is signing in. Each proof works once.

Backup code — One of ten single-use codes, in the form XXXX-XXXX-XXXX-XXXX, that replaces an authenticator code at sign-in.

Billing period — The month (or the twelve months) a plan pass covers. Monthly allowances refresh at the start of each billing month.

Chargeback — A payment reversed by your bank rather than refunded by Auric Artisan. Shown as a row type in payment history.

Danger zone — The locked panel at the bottom of Security & Privacy holding the two irreversible actions: erasing this browser's workspace and deleting the account.

Device code — The short code (ABCD-EFGH) the command-line tool shows so you can approve it in a browser.

Device sign-in — Signing in the command-line tool by approving its code in a browser where you are already signed in.

Hard ceiling — A limit of ten times the included API allowance per month, applied to every account whatever its settings.

Industrial Pro — The highest plan: 10,000,000 API credits and 2,500 tokens a month. Marked coming soon.

Invoice — The printable record of one payment, refund or chargeback, opened from Invoices & Payment History. Currently a payment receipt, not a GST tax invoice.

Limited workspace — The account before its email address is verified: usable, but with billing, promotions, API keys and device approval locked.

Order reference — The identifier of a purchase, starting with order_. Quote it in any payment question.

Overage (paid overage) — Letting API calls continue past the included allowance by spending prepaid credits. Off by default.

Plan pass — A one-time purchase of a paid plan for a fixed term. It does not renew.

Prepaid credits — API credits you have bought. They do not expire at the end of a period.

Proration — Adjusting a price for part of a period. Not automatic on Auric Artisan.

Rate limit — The most API requests allowed per minute: 300 on Specialist, 3,000 on Industrial Pro.

Razorpay — The payment company that processes every payment on Auric Artisan.

Session — One signed-in browser or device. Listed under Signed-in devices.

Specialist — The plan that adds the REST API with 1,000,000 credits a month and 1,000 tokens a month. Marked coming soon.

Spend cap — A monthly limit, in US dollars, on how much paid overage can spend.

Starter grant — The 100 tokens the free plan includes once. They do not expire and do not renew.

Token — The unit that meters server-backed work you start in a website tool. Sized at about $0.10 of work. Separate from API credits.

TOTP — Time-based one-time password: the six-digit codes an authenticator app shows, changing every 30 seconds.

Two-step verification (2FA) — Asking for an authenticator code as well as your password when you sign in.

Username (handle) — Your public name on the site, shown as @name. It is the address of your public portfolio and can be used to sign in.

Verification link — The one-time link emailed to prove your address is yours. Valid for 24 hours.
