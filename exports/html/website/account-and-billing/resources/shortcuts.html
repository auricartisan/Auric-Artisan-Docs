Keyboard shortcuts

Keyboard keys that work on the Auric Artisan sign-in page, the account dashboard and the related dialogs.

The account pages can be used entirely from the keyboard. These are the keys with special behaviour; everything else follows normal browser conventions (Tab to move, Enter or Space to press).

Sign-in page

KeysWhereWhat it does
Left / Right or Up / DownSign In and Create Account tabsSwitch tab
Home / EndThe tabsFirst or last tab
EnterAny form fieldSubmits the form

Dashboard

KeysWhereWhat it does
Left / RightSection railMove to the previous or next section
Home / EndSection railJump to Overview or Security & Privacy
Enter or SpaceProfile photo strip in ProfileChoose a photo file
EscPhoto viewerCloses it
EscYour account is nearly there panelDismisses it for a week

Dialogs

KeysWhereWhat it does
EscUpgrade dialogCloses it
