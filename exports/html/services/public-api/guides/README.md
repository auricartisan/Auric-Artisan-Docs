# Public API documentation — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | The contents of the public API documentation, from creating a key to every endpoint, error and limit. |
| [getting-started.html](getting-started.html) | Get an API key from your dashboard, make a first request, and read the response and its usage headers. |
| [authentication.html](authentication.html) | How to authenticate with the Auric Artisan API — API keys, the CLI's OAuth bearer token, keeping keys safe, and revoking them. |
| [errors.html](errors.html) | The Auric Artisan API's error format, every error code with its HTTP status, what each means, and how to respond. |
| [examples.html](examples.html) | Ready-to-run requests for common tasks with the Auric Artisan API. |
| [plans-credits-and-quotas.html](plans-credits-and-quotas.html) | What each plan includes, how credits are charged per endpoint, rate limits, overage, spend caps, the hard ceiling, and the headers that report usage. |
| [sdks-and-tooling.html](sdks-and-tooling.html) | The official clients and integrations for the Auric Artisan API — JavaScript, Python, the CLI, an MCP server, a Postman collection and GraphQL. |
| [reference.html](reference.html) | Every customer endpoint of the Auric Artisan REST API with its method, authentication, credit cost and purpose, plus the headers, input formats, plans and limits. |
| [troubleshooting.html](troubleshooting.html) | Common problems with the Auric Artisan API — keys, plans, limits, credits, inputs, collections and the analyzer — and how to fix them. |
| [faq.html](faq.html) | Short answers to common questions about the Auric Artisan REST API. |
