Browser extension

Related tools

Website tools, VS Code extensions and other Auric Artisan products that pair with the browser extension.

The browser extension brings the most frequent checks to any page. The full-size tools on auricartisan.com go deeper, and the VS Code extensions bring the same checks to your code.

Website tools

ToolUse it whenDocs
AnalyzerYou want a full report on any URL, not just the tab you have openAnalyzer
Contrast CheckerYou need more contrast detail than the popup offersContrast Checker
Vision SimulationYou want to simulate vision on images and designs, with more controlsVision Simulation
Accessibility ChecklistYou need the manual checks an automated audit cannot makeAccessibility Checklist
Ishihara Plate GeneratorYou want colour-vision test platesIshihara plates
Basic Colour ToolsYou want the colour tools in a larger workspaceBasic Colour Tools
Colour Science LabYou want to explore colour spaces and modelsColour Science Lab
Image PickerYou want to pick colours from images in detailImage Picker

The extension's On the web list and Home links open these and other pages directly.

Libraries and learning

  • The colour, palette, gradient, harmony and shades libraries on auricartisan.com; see the colour libraries docs.
  • Learn articles on colour science and accessibility; see the Learn docs.

VS Code

The Auric Artisan Studio extensions bring colour and accessibility checks to your source code, so you can fix what the browser extension finds where the code lives.

Services

  • Font CDN and Icon CDN, for fonts and icons on your own sites.
  • Public API, for colour and accessibility checks from your own code.

Policies
