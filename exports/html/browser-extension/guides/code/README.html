Code tools

The tools in the Code space — Inspect, Tokens and Snippets — and every code format the extension can export.

The Code space is for developers. Inspect reads one element in depth and lets you try CSS on it live. Tokens reads a site's design tokens. Snippets keeps the code you want to reuse. Every colour tool also exports code; the formats are collected in one reference.
