# Code tools — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | The tools in the Code space — Inspect, Tokens and Snippets — and every code format the extension can export. |
| [code-export.html](code-export.html) | Every format the extension can copy or download, which tool produces it, and what the output looks like. |
| [inspect.html](inspect.html) | Select an element on the page and read its full snapshot in the popup — box model, styles, matched rules, accessibility, DOM, locators — and try CSS on it live. |
| [snippets.html](snippets.html) | Keep reusable code in the extension's on-device vault — save from tools or paste your own, search, filter by site, copy and export. |
| [tokens.html](tokens.html) | Read a web page's design tokens — CSS custom properties, font families and type scale — and export them as CSS, W3C tokens, a Tailwind @theme block or JSON. |
