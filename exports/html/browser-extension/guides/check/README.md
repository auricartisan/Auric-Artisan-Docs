# Check tools — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | The tools in the Check space — Contrast, Vision, Audit and Findings — and the rules the audit applies. |
| [all-findings.html](all-findings.html) | One list of everything the tools found — accessibility, contrast and inspection problems — ordered by severity, with actions for each. |
| [audit-rules.html](audit-rules.html) | Every rule in the extension's accessibility engine, grouped by category, with its impact, WCAG 2.2 success criteria and whether the audit runs it. |
| [audit.html](audit.html) | Audit the current page against WCAG 2.2 A and AA, read the contrast results, outline problems on the page, and export the results. |
| [contrast.html](contrast.html) | Check a text and background colour pair against WCAG 2.2 and APCA, read the verdict and size guidance, and fix the pair to the nearest passing colour. |
| [vision.html](vision.html) | See the live page through eight colour-vision deficiency and four low-vision simulations, compare side by side, and capture the result. |
