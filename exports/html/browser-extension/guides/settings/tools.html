Browser extension › Settings

Tools settings

Set how colours are copied and named, whether APCA is shown, history and sound, and how deep the page audit goes.

Settings › Tools changes how the tools behave.

ControlChoicesDefaultWhat it does
Copy colours asHEX, RGB, HSL, OKLCHHEXThe format used when you click a colour in History or Library, and the Picker's starting format
Colour namesCSS names, XKCD, OffCSS namesThe nearest colour name shown in colour details. Off hides names. XKCD currently gives the same names as CSS names.
Show APCA beside WCAGOn or offOnShows the APCA Lc score, tiers and readable sizes in Contrast
Keep a colour historyOn or offOn"The last 50 colours you picked or copied." Off stops recording new colours.
Sound on pickOn or offOff"A short tick when the eyedropper lands." Also plays on copy.
Deep page auditOn or offOnContrast scan limits: 3 500 elements and 160 issues on; 1 800 and 80 off. Slower on large pages.
Outline issues after an auditOn or offOff"Marks failing elements on the page as soon as the audit finishes."
