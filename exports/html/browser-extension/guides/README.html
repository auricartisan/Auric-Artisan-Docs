Browser extension

Browser extension documentation

The contents of the browser extension's how-to documentation, from installing to every tool and setting.

This folder explains how to install the Auric Artisan browser extension and use every part of it: the popup and side panel, each tool in the Colour, Check, Code and Saved spaces, the features that work on websites, and every setting. Start with Getting started if you are new, or go straight to the tool you need.

Folders

  • install/: Installing on Chrome and other Chromium browsers, Edge, Opera, Firefox and Safari; loading from a ZIP; updating and removing
  • surfaces/: The popup, Home, search, the side panel, what the extension draws on a page, and the element inspector
  • colour/: Picker, Page palette, Image, Gradient, Mix, Harmony, Scale and Convert
  • check/: Contrast, Vision, Audit, the audit's rules, and Findings
  • code/: Inspect, Tokens, Snippets, and every code format the extension exports
  • saved/: Library, History and On the web
  • on-websites/: Website pickers, the colour picker on pages, the right-click menu, the items in the browser's own menu, and notes for site owners
  • workflows/: End-to-end tasks that use several tools together
  • settings/: Appearance, Pickers, Right-click, Tools, Data and Shortcuts
