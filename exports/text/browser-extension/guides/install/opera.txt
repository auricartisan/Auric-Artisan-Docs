==============================================================================
INSTALL ON OPERA
==============================================================================
Install Auric Artisan in Opera from the Chrome Web Store listing, or load the
Opera package from a ZIP.
Area: Browser extension › Install   Updated: 2026-09-25

Opera is a Chromium browser. It can install Auric Artisan from the Chrome Web
Store listing, and the product page also offers an Opera-named ZIP that is an
identical copy of the Chromium package.

INSTALL FROM THE CHROME WEB STORE
=================================

  1. In Opera, open
     https://chromewebstore.google.com/detail/auric-artisan/bpmkaljljnlmbjfbmkbbbgiinlbpcocp
  2. If Opera asks you to add its helper for Chrome Web Store extensions,
     follow its prompt, then return to the listing.
  3. Choose the store's add button and confirm the permission prompt.
  4. Pin Auric Artisan from Opera's extensions menu.
  5. Open a normal web page and click the icon, or press `Alt` + `Shift` +
     `A`.

INSTALL FROM THE OPERA ZIP INSTEAD
==================================

  1. Download the Opera package from https://auricartisan.com/extension. Its
     name starts with `auric-suite-opera-`.
  2. Unzip it into a folder you will keep.
  3. Open `opera://extensions`.
  4. Turn on Developer mode.
  5. Choose Load unpacked and select the unzipped folder, the one with
     `manifest.json` at its top level.

A copy loaded this way does not update itself. See Update and remove
[update-and-remove.txt].

SIDE PANEL AND SHORTCUTS
========================

  - Open the side panel in the popup's header docks the workspace in Opera's
    side panel.
  - The default shortcuts are the same as in Chrome: `Alt` + `Shift` + `A`,
    `C`, `E` and `V`. Change them in Opera's extension shortcuts settings;
    Settings › Shortcuts › Change them in the browser tries to open that page
    for you.
