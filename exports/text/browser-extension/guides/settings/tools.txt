==============================================================================
TOOLS SETTINGS
==============================================================================
Set how colours are copied and named, whether APCA is shown, history and
sound, and how deep the page audit goes.
Area: Browser extension › Settings   Updated: 2026-09-25

Settings › Tools changes how the tools behave.

  Control:      Copy colours as
  Choices:      HEX, RGB, HSL, OKLCH
  Default:      HEX
  What it does: The format used when you click a colour in History or Library,
                and the Picker's starting format

  Control:      Colour names
  Choices:      CSS names, XKCD, Off
  Default:      CSS names
  What it does: The nearest colour name shown in colour details. Off hides
                names. XKCD currently gives the same names as CSS names.

  Control:      Show APCA beside WCAG
  Choices:      On or off
  Default:      On
  What it does: Shows the APCA Lc score, tiers and readable sizes in Contrast

  Control:      Keep a colour history
  Choices:      On or off
  Default:      On
  What it does: "The last 50 colours you picked or copied." Off stops
                recording new colours.

  Control:      Sound on pick
  Choices:      On or off
  Default:      Off
  What it does: "A short tick when the eyedropper lands." Also plays on copy.

  Control:      Deep page audit
  Choices:      On or off
  Default:      On
  What it does: Contrast scan limits: 3 500 elements and 160 issues on; 1 800
                and 80 off. Slower on large pages.

  Control:      Outline issues after an audit
  Choices:      On or off
  Default:      Off
  What it does: "Marks failing elements on the page as soon as the audit
                finishes."
