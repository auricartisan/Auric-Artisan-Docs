==============================================================================
KEYBOARD SHORTCUTS
==============================================================================
Every keyboard shortcut in the Auric Artisan browser extension — browser-level
shortcuts, the popup, the element inspector and the right-click menu.
Area: Browser extension   Updated: 2026-09-25

BROWSER-LEVEL SHORTCUTS
=======================

These work from any page. Change them on the browser's shortcuts page:
`chrome://extensions/shortcuts` in Chromium browsers, or `about:addons` › gear
› Manage Extension Shortcuts in Firefox. Settings › Shortcuts › Change them in
the browser opens it.

  Keys:                    `Alt` + `Shift` + `A`
  Action:                  Open the extension on the active tab
  Name on the shortcuts page:Open Auric Artisan

  Keys:                    `Alt` + `Shift` + `C`
  Action:                  Open the contrast checker
  Name on the shortcuts page:Open contrast checker

  Keys:                    `Alt` + `Shift` + `E`
  Action:                  Open Page palette and read the page's colours
  Name on the shortcuts page:Extract page palette

  Keys:                    `Alt` + `Shift` + `V`
  Action:                  Turn the deuteranopia simulation on or off
  Name on the shortcuts page:Toggle deuteranopia simulation

  Keys:                    Unassigned
  Action:                  Start the element inspector
  Name on the shortcuts page:Inspect an element on the page

  Keys:                    Unassigned
  Action:                  Open Audit and run it
  Name on the shortcuts page:Run a full accessibility audit

No macOS-specific keys are documented; use your browser's shortcuts page to
check or change them.

IN THE POPUP AND SIDE PANEL
===========================

  Keys:   `/`
  Action: Focus search (when not typing in a field)

  Keys:   `Ctrl` + `K`
  Action: Focus search from anywhere; closes Settings

  Keys:   `Up` / `Down`
  Action: Move through search results

  Keys:   `Enter`
  Action: Run the selected search result

  Keys:   `Esc`
  Action: Close an open colour picker, then Settings, then clear the search,
          then return to Home

  Keys:   `Left` / `Right`, `Home` / `End`
  Action: Move between spaces, or between Settings sections (`Up` and `Down`
          also work there)

  Keys:   `Delete` or `Backspace`
  Action: Remove the focused colour in Library

ELEMENT INSPECTOR (ON THE PAGE)
===============================

  Keys                   | Action
  -----------------------+---------------------------
  `Up`                   | Parent element
  `Down`                 | First child
  `Left` / `Right`       | Previous / next sibling
  `P`                    | Pin or unpin
  `C` or `Enter`         | Copy CSS
  `S`                    | Copy the selector
  `J`                    | Copy JSON
  `Esc`                  | Unpin; press again to stop
  Arrow keys on the grip | Move the pinned card

CUSTOM RIGHT-CLICK MENU (ON THE PAGE)
=====================================

  Keys                | Action
  --------------------+------------------------------------------------------------
  Type                | Filter every action
  `Up` / `Down`       | Move between the quick bar and the rows
  `Right`             | Open a group, or reach a row's star
  `Left`              | Close a group, or leave the star
  `Enter`             | Run the row; in the field, run the first result
  `1` to `6`          | Choose a search engine in Search the web
  `Esc`               | Clear the filter, then close a submenu, then close the menu
  Shift + right-click | Open the browser's own menu
