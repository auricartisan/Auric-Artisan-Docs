==============================================================================
RELATED TOOLS
==============================================================================
Website tools, VS Code extensions and other Auric Artisan products that pair
with the browser extension.
Area: Browser extension   Updated: 2026-09-25

The browser extension brings the most frequent checks to any page. The
full-size tools on auricartisan.com go deeper, and the VS Code extensions
bring the same checks to your code.

=============

  Tool:        Analyzer
  Use it when: You want a full report on any URL, not just the tab you have
               open
  Docs:        Analyzer
               [../../website/tools/accessibility-and-vision/analyzer/README.txt]

  Tool:        Contrast Checker
  Use it when: You need more contrast detail than the popup offers

VS CODE
=======

The Auric Artisan Studio
[../../vscode-extensions/auric-artisan-studio/README.txt] extensions bring
colour and accessibility checks to your source code, so you can fix what the
browser extension finds where the code lives.

SERVICES
========

  - Font CDN [../../services/font-cdn/README.txt] and Icon CDN
    [../../services/icon-cdn/README.txt], for fonts and icons on your own
    sites.
  - Public API [../../services/public-api/README.txt], for colour and
    accessibility checks from your own code.
