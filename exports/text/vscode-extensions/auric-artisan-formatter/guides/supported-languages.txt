==============================================================================
SUPPORTED LANGUAGES
==============================================================================
Every language Auric Artisan Formatter formats, grouped by how much it can
change.
Area: VS Code extensions › Auric Artisan Formatter   Updated: 2026-09-25

The formatter recognises 253 languages by file extension, exact file name,
shebang line and VS Code language id. What it does with each depends on its
tier; see The safety gate and formatting tiers [safety-gate-and-tiers.txt].

  Tier:         Native
  Languages:    33 registry entries; 31 verified native modes
  What changes: Anything layout-related: the file is rebuilt from a real parse

  Tier:         Universal: reindent and spacing
  Languages:    104
  What changes: Indentation and spacing

  Tier:         Universal: spacing only
  Languages:    60
  What changes: Spacing between tokens; indentation untouched

  Tier:         Universal: whitespace only
  Languages:    60
  What changes: Trailing whitespace, blank lines, line endings, final newline

The two native entries that are not yet verified are JavaScript React (`jsx`)
and TypeScript React (`tsx`): a file containing JSX elements falls back to the
universal tier in version 0.1.0.

To see the list yourself, run `auric-format --list-languages` (see Command
line and CI [command-line.txt]). Formatter Studio's Lang drop-down groups
languages into Native printers and Universal engine.

Files identified by name
------------------------

Some formats share an extension with another, and a few files are recognised
by name. For example, `docker-compose.yml`, `compose.yaml`, `openapi.yaml`,
`swagger.json`, `asyncapi.yaml`, `Pulumi.yaml`, `playbook.yml` and
`kustomization.yaml` get their own native handling. Ambiguous extensions are
resolved to one language by default: `.h` is C, `.m` is Objective-C, `.pl` is
Perl, `.sql` is SQL and `.ts` is TypeScript. Set `auricFormatter.parser` or a
`languages` entry if you need a different interpretation.
