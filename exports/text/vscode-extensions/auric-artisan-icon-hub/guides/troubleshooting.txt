==============================================================================
TROUBLESHOOTING
==============================================================================
Symptoms, causes and fixes for common problems with Auric Artisan Icon Hub.
Area: VS Code extensions › Auric Artisan Icon Hub   Updated: 2026-09-25

  Symptom:        The catalog gained no new icons after Refresh.
  Why it happens: Refresh updates compatible metadata only.
  What to do:     Install an extension update for new artwork.

  Symptom:        The badge says Offline · using local catalog.
  Why it happens: The metadata check could not reach or validate the website.
  What to do:     Local browsing still works. Check your connection or try
                  Refresh later; automatic retries wait for the interval.

  Symptom:        Material names such as `4k_plus` appear as text on my page.
  Why it happens: The Material font is not loaded, often from an older
                  insertion that used a local font.
  What to do:     Reinsert the icon with the current version so it uses a CDN
                  placeholder, save the source, and reload the page with
                  network access. Old spans are not rewritten automatically.

  Symptom:        CDN icons appear blank on my site.
  Why it happens: The page has no network access, your content security policy
                  blocks the CDN, the bridge file is not served, or the CDN
                  does not yet allow cross-origin access to its catalog and
                  fonts.
  What to do:     Check network access, CSP and that the bridge is deployed.
                  For self-contained artwork, use Copy as SVG or Export ZIP.

  Symptom:        Insert says the workspace must be trusted.
  Why it happens: Creating the CDN bridge needs a trusted workspace.
  What to do:     Trust the workspace, or use Copy.

  Symptom:        Insert says to save the file first.
  Why it happens: CDN insertion needs a saved local or remote file.
  What to do:     Save the file, then insert again.

  Symptom:        Insert refuses because of a `<base>` URL or an external
                  component script.
  Why it happens: The bridge path could be wrong in those files.
  What to do:     Connect the bridge yourself, or use Copy.

  Symptom:        Insert cannot use the editor.
  Why it happens: No writable editor, or the editor is read-only.
  What to do:     Focus a writable text file, then return to the Hub. Copy is
                  always available.

  Symptom:        A Material icon cannot be inserted into my file.
  Why it happens: Material insertion needs HTML or a web-framework file.
  What to do:     Use Copy with HTML, JSX, React component, CSS or CDN format.

  Symptom:        Stroke has no effect.
  Why it happens: The icon is filled, not stroke-based.
  What to do:     This is expected; choose an outline style.

  Symptom:        Export ZIP includes a text list instead of Material SVGs.
  Why it happens: Material icons are font-backed.
  What to do:     This is expected; they are listed in `MATERIAL_ICONS.txt`.

  Symptom:        I also have Icon Studio. Which should I use?
  Why it happens: They are separate products with separate settings and views.
  What to do:     Icon Hub: seven open-source sets, colour tools, sprite and
                  ZIP export, CDN insertion. Icon Studio: Auric artwork, emoji
                  and open-source sets, fully offline.

If the problem continues, note your VS Code version, the Hub version (0.1.0),
the icon ID and the steps to reproduce, remove private code from screenshots,
and contact support at https://auricartisan.com/company/contact/.
