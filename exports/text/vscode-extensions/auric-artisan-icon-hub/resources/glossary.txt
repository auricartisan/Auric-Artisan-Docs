==============================================================================
GLOSSARY
==============================================================================
Definitions of the terms used in Auric Artisan Icon Hub.
Area: VS Code extensions › Auric Artisan Icon Hub   Updated: 2026-09-25

  Term:    Bridge
  Meaning: The small `icons.auricartisan.com.js` loader file Icon Hub creates
           next to your source on the first CDN Insert.

  Term:    Catalog metadata
  Meaning: The data describing icons (names, terms, counts), separate from the
           artwork itself.

  Term:    CDN
  Meaning: A content delivery network: a web service that serves icon data and
           fonts to your pages.

  Term:    CDN placeholder
  Meaning: An element such as `<span data-icon="set:name" …>` that the CDN
           script turns into an icon.

  Term:    Content security policy
  Meaning: A website rule listing which sources may load scripts, fonts and
           data.

  Term:    `currentColor`
  Meaning: A CSS keyword meaning "use the surrounding text colour".

  Term:    Data URI
  Meaning: Text that embeds a file directly, starting `data:`.

  Term:    Font-backed icon
  Meaning: An icon drawn from a font glyph (Material), not an SVG file.

  Term:    Indexed variant
  Meaning: One style of one icon. Icon Hub indexes 32,802.

  Term:    Selection
  Meaning: Icons you ticked for export. Up to 200 per export.

  Term:    Smart Finder
  Meaning: A local panel of recent icons and a rotating sample of the catalog.

  Term:    SVG sprite
  Meaning: One SVG file containing several icons as reusable symbols.
