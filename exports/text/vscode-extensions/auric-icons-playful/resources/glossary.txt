==============================================================================
GLOSSARY
==============================================================================
Definitions of the terms used in Auric Icons: Playful.
Area: VS Code extensions › Auric Icons: Playful   Updated: 2026-09-25

  Term:    Auto variant
  Meaning: A variant choice that follows the language of the file you are
           editing.

  Term:    Catalog path
  Meaning: The relative location of an icon file inside the bundled catalog.

  Term:    Data URI
  Meaning: Text that embeds a file directly, starting `data:image/svg+xml,`.

  Term:    Emoji-style icon
  Meaning: Expressive SVG artwork in the spirit of emoji. Not a Unicode emoji
           character.

  Term:    Filled
  Meaning: A variant drawn with solid shapes.

  Term:    Host
  Meaning: The one extension that shows the shared library when several Auric
           collections are installed.

  Term:    Icon ID
  Meaning: The unique name of an icon, such as `abstract-balance-0001`.

  Term:    Icon Studio
  Meaning: The heading of the shared library view, and also the name of the
           separate Auric Artisan Icon Studio extension.

  Term:    Outline
  Meaning: A variant drawn in lines.

  Term:    Preview surface
  Meaning: The light, dark or automatic backdrop behind library cards.

  Term:    Small
  Meaning: A simplified redrawing for 16 to 24 pixels.

  Term:    Smart guide
  Meaning: Tip cards at the top of the library that react to your file and
           usage.

  Term:    Smart insert
  Meaning: Choosing the output format from the language of the file you are
           editing.

  Term:    Variant
  Meaning: One rendering of an icon: Color, Outline, Filled or Small.
