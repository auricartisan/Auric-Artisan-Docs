==============================================================================
FREQUENTLY ASKED QUESTIONS
==============================================================================
Short answers to common questions about Auric Icons: Playful.
Area: VS Code extensions › Auric Icons: Playful   Updated: 2026-09-25

ARE THESE EMOJI?
================

No. They are emoji-style SVG icons: real vector artwork you can insert, style
and ship, not Unicode emoji characters. For Unicode emoji, see Auric Artisan
Emoji [../../auric-artisan-emoji/README.txt].

WHAT IS THE SMALL VARIANT FOR?
==============================

Small is a separate, simplified drawing for 16 to 24 pixels. Details that
would blur at small sizes are removed.

IS THIS THE SAME AS THE PLAYFUL STYLE IN FILE ICONS?
====================================================

No. File Icons' Playful style is a set of 500 Explorer file and folder icons.
This extension is a 1,225-icon library for your code and has no Explorer
theme.

WHY IS THERE NO FILE ICON THEME?
================================

Playful's earlier gallery theme did not meet the 16-pixel silhouette,
folder-pair and mapping standards of Auric Icons: Modern, which is the family
theme. Install Modern alongside Playful for the Explorer theme.

DO I NEED MODERN OR DRAWN TOO?
==============================

No. Playful works alone. Installing them together gives you one merged
library.

IS IT FREE AND OFFLINE?
=======================

Yes. Free to use for any purpose (redistribution and resale are not
permitted), with no network access or telemetry.

CAN I CHANGE ICON SIZE OR COLOUR ON INSERT?
===========================================

Not in this extension. Auric Artisan Icon Studio has size and colour output
settings and includes the Playful collection.
