What Auric Icons: Drawn can and cannot do.
Area: VS Code extensions › Auric Icons: Drawn   Updated: 2026-09-25

  - The library contains 480 icons at the installed version; new icons come
    with updates.
  - There is no Explorer file icon theme.
  - Icons are inserted as drawn: there are no size, colour or stroke controls
    for output.
  - Smart insert picks a format from the file's language, not the exact cursor
    position. Check quotes and surrounding code.
  - Recommendations are local rankings from the file you are editing and your
    likes and use, not an AI service.
  - Hover previews recognise only Drawn icon IDs (a hyphenated name ending in
    four digits).
  - Personalisation built up in the retired "Auric Artisan Drawing Icon"
    preview extension does not transfer; each extension keeps its own storage.
  - Licence: free to use for any purpose; redistribution, republishing, resale
    and derivative releases are not permitted.
