==============================================================================
GLOSSARY
==============================================================================
Definitions of the terms used in Auric Icons: Modern.
Area: VS Code extensions › Auric Icons: Modern   Updated: 2026-09-25

  Term:    Association
  Meaning: A rule that maps a file extension, filename or folder name to an
           icon.

  Term:    Auto variant
  Meaning: A variant choice that follows the language of the file you are
           editing.

  Term:    Catalog path
  Meaning: The relative location of an icon file inside the bundled catalog.

  Term:    Data URI
  Meaning: Text that embeds a file directly, starting `data:image/svg+xml,`.

  Term:    Duotone
  Meaning: A variant drawn in two tones.

  Term:    Explorer arrows
  Meaning: The chevrons beside folders in the Explorer that expand and
           collapse them.

  Term:    File icon theme
  Meaning: The set of icons VS Code shows beside files and folders. Only one
           is active at a time.

  Term:    Framework pack
  Meaning: Extra file icons for one framework's file types, such as Angular
           components or Vue composables.

  Term:    Host
  Meaning: The one extension that shows the shared library when several Auric
           collections are installed.

  Term:    Icon ID
  Meaning: The unique name of an icon. Library IDs end in a four-digit number,
           such as `analytics-bar-chart-0042`; theme IDs are short names such
           as `typescript`.

  Term:    Icon Studio
  Meaning: The heading of the shared library view, and also the name of the
           separate Auric Artisan Icon Studio extension.

  Term:    Mono
  Meaning: A single-colour variant.

  Term:    Preview surface
  Meaning: The light, dark or automatic backdrop behind library cards.

  Term:    Semantic colour
  Meaning: A colour that identifies a file type, such as the TypeScript blue.

  Term:    Sharp Modern
  Meaning: One of the two style families in the library (300 icons), shown as
           Sharp in the Style filter.

  Term:    Simple Modern
  Meaning: The other style family (420 icons), shown as Modern in the Style
           filter.

  Term:    Smart guide
  Meaning: Tip cards at the top of the library that react to your file and
           usage.

  Term:    Smart insert
  Meaning: Choosing the output format from the language of the file you are
           editing.

  Term:    Variant
  Meaning: One rendering of an icon: Color, Mono, Outline or Duotone.
