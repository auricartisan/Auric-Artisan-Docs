What Auric Icons: Modern stores, where, and confirmation that it makes no
network requests.
Area: VS Code extensions › Auric Icons: Modern   Updated: 2026-09-25

Auric Icons: Modern runs entirely inside VS Code. It has no telemetry, no
account and no network access at runtime.

WHAT IS STORED
==============

  Data:  Theme and library settings
  Where: Your VS Code settings under `auricIcons.*`.

  Data:  A rebuilt copy of the theme when you customise it
  Where: Inside the extension's own installation folder. The original artwork
         is never changed.

  Data:  Likes (up to 500), recent icons (up to 60), learned preferences and
         dismissed guide tips
  Where: VS Code's extension storage on this machine.

  Data:  "Don't ask again" for workspace detection
  Where: VS Code's storage for that workspace.

  Data:  Library search, filters, variant and preview surface
  Where: The view's saved state in VS Code.

WHAT THE EXTENSION READS
========================

  - To offer the theme in Auric Artisan workspaces, it checks whether
    `.auric-artisan` or `.auricignore` exists at the top of each local
    workspace folder. It does not read their contents or walk your folders.
  - For recommendations and smart insert, it reads the language, file name and
    up to about 60 lines around the cursor in the active editor. This stays in
    memory.

WHAT THE EXTENSION WRITES
=========================

  - Inserting changes your editor content. Copying writes to the clipboard.
    Saving writes a file only where you choose in a save dialog.
  - Its own commands update your user settings.
