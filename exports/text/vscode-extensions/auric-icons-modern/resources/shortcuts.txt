SHORTCUTS AND COMMANDS
==============================================================================
Keybindings, in-view keys and every command in Auric Icons: Modern.
Area: VS Code extensions › Auric Icons: Modern   Updated: 2026-09-25

KEYBINDINGS
===========

  Action             | Windows and Linux    | macOS
  -------------------+----------------------+--------------------
  Smart Insert Icon  | `Ctrl` + `Alt` + `I` | `Cmd` + `Alt` + `I`
  Insert from Recent | `Ctrl` + `Alt` + `R` | `Cmd` + `Alt` + `R`

Both need a focused text editor, and are only active while Modern hosts the
library (they step aside when Auric Artisan Icon Studio or a sibling
collection hosts).

KEYS IN THE ICON LIBRARY
========================

  Key                       | Action
  --------------------------+-------------------------------
  `/`                       | Focus search
  `Escape`                  | Clear search; close a dropdown
  `Arrow Up` / `Arrow Down` | Move between dropdown options
