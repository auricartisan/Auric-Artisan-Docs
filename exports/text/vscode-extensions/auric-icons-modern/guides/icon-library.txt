==============================================================================
BROWSE THE ICON LIBRARY
==============================================================================
Search the 720-icon Modern library, filter by category, style and library,
switch variants and preview surfaces, and use the smart guide and
recommendations.
Area: VS Code extensions › Auric Icons: Modern   Updated: 2026-09-25

The Icon Library holds 720 original icons: 420 Simple Modern and 300 Sharp
Modern, across 33 categories such as Coding and development, Data and
databases, Cybersecurity, Accessibility and Space and Astronomy. Every icon
comes in four variants: Color, Mono, Outline and Duotone.

OPEN THE LIBRARY
================

  - Sidebar: select Auric Icons: Modern in the Activity Bar to open the Icon
    Library view.
  - Editor tab: run Auric Icons: Modern: Open Icon Library, select the ↗
    button (Open full explorer) in the view, or select the open-preview icon
    in the view's title bar. The tab is called Icon Studio — Library.

THE SCREEN
==========

  Area:         Header
  What it does: "Icon Studio", Icon Library, a count line such as "720 icons ·
                72 loaded", and the ↗ button.

  Area:         Smart guide
  What it does: Up to four tip cards, such as "TypeScript detected" or "Like
                icons you reuse". Dismiss a tip with its × button. Turn the
                guide off with `auricIcons.library.showGuide`.

  Area:         Search
  What it does: Placeholder "Search 720 icons — try “empty state” or “auth”".

  Area:         Library
  What it does: Only shown when several collections are merged. All libraries
                or one collection.

  Area:         Category
  What it does: All categories or one category.

  Area:         Style
  What it does: All styles, Modern or Sharp.

  Area:         Variant
  What it does: Auto, Color, Mono, Outline, Duotone.

  Area:         Preview surface
  What it does: Auto, Light, Dark.

  Area:         Chips
  What it does: All, ✦ For you, ♥ Likes (count) and ↺ Recent (count).

  Area:         Recommended rail
  What it does: ✦ Recommended for this file, with Refresh.

  Area:         Grid
  What it does: Icon cards that load as you scroll.

SEARCH
======

Type a name, concept or synonym; results are ranked as you type. For example,
`delete` finds trash icons. Press `/` to focus the search from anywhere in the
view, and `Escape` to clear it. Search is also personalised by what you like
and use.

VARIANTS AND AUTO
=================

The Variant buttons change the artwork shown on every card and used for
insert, copy and save.

Auto follows the file you are editing. It shows the resolved variant, for
example "Auto · outline".

  Editing in                                                         | Auto variant
  -------------------------------------------------------------------+-------------
  JavaScript, TypeScript, React JSX and TSX                          | Outline
  HTML, PHP, Handlebars, Vue, Svelte, Astro, Markdown, MDX, XML, SVG | Color
  CSS, SCSS, Less, JSON, YAML, Python                                | Mono
  Anything else                                                      | Color

The default variant for Command Palette actions is set by
`auricIcons.library.defaultVariant` (`auto`, `color`, `mono`, `outline` or
`duotone`).

PREVIEW SURFACE
===============

Light and Dark show every card on a light or dark backdrop, so you can judge
the artwork for either kind of page. Auto follows your VS Code theme. The view
remembers your choice.

THE VIEWS
=========

  Chip      | Shows
  ----------+-----------------------------------------------------------------------
  All       | Every icon that matches the search and filters.
  ✦ For you | Icons recommended for the file you are editing and your likes and use.
  ♥ Likes   | Icons you liked with the heart.
  ↺ Recent  | Icons you inserted, copied, saved or opened, newest first (up to 60).

RECOMMENDATIONS
===============

The ✦ Recommended for this file rail shows icons that match words in the file
you are editing, icons you like or used recently, and icons that fit your
style. Each card shows why, for example Matches this file, In your likes, Used
recently, Fits your style or Popular in your catalog. Selecting a rail card
inserts it. Select Refresh to recompute.

  Setting: `auricIcons.library.recommendations.enabled`
  Default: true
  Effect:  Show recommendations.

  Setting: `auricIcons.library.recommendations.limit`
  Default: 12
  Effect:  How many icons the rail shows (4 to 24).

CARDS
=====

Each card shows the artwork, a heart, the name and the category (and a
collection badge when libraries are merged).

  Control | Action
  --------+---------------------------------------
  Artwork | Opens the SVG source in an editor tab.
  Heart   | Adds to or removes from Likes.
  Insert  | Inserts into the editor.
  Copy    | Copies raw SVG.
  Save    | Saves an `.svg` file through a dialog.
  JSX     | Copies as a JSX element.
  URI     | Copies as a data URI.
  Source  | Opens the SVG source.

DENSITY AND BATCH SIZE
======================

  Setting                       | Values                   | Default
  ------------------------------+--------------------------+--------------
  `auricIcons.library.density`  | `comfortable`, `compact` | `comfortable`
  `auricIcons.library.pageSize` | 24 to 240                | 72

The grid streams more cards as you scroll, with a line such as "144 of 720 —
keep scrolling".

RESULT
======

You can find any Modern icon quickly, preview it in the right variant on the
right background, and act on it from its card.
