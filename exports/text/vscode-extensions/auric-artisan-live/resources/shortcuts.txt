==============================================================================
SHORTCUTS
==============================================================================
Every keyboard shortcut Auric Artisan Live provides in VS Code, the control
panel, the preview and the in-page dashboard.
Area: VS Code extensions › Auric Artisan Live   Updated: 2026-09-25

VS CODE
=======

These work whenever a folder is open. Change them in Preferences: Open
Keyboard Shortcuts by searching for `auricLive`.

  Windows and Linux: `Ctrl` + `Alt` + `L`
  macOS:             `Cmd` + `Alt` + `L`
  Command:           Auric Live: Go Live

  Windows and Linux: `Ctrl` + `Alt` + `Shift` + `L`
  macOS:             `Cmd` + `Alt` + `Shift` + `L`
  Command:           Auric Live: Stop All Servers

  Windows and Linux: `Ctrl` + `Alt` + `K`
  macOS:             `Cmd` + `Alt` + `K`
  Command:           Auric Live: Open Preview Beside

  Windows and Linux: `Ctrl` + `Alt` + `Shift` + `K`
  macOS:             `Cmd` + `Alt` + `Shift` + `K`
  Command:           Auric Live: Open Live Menu

  Windows and Linux: `Ctrl` + `Alt` + `J`
  macOS:             `Cmd` + `Alt` + `J`
  Command:           Auric Live: Select Run Target…

  Windows and Linux: `Ctrl` + `Alt` + `U`
  macOS:             `Cmd` + `Alt` + `U`
  Command:           Auric Live: Reload Connected Pages

  Windows and Linux: `Ctrl` + `Alt` + `Shift` + `I`
  macOS:             `Cmd` + `Alt` + `Shift` + `I`
  Command:           Auric Live: Open Control Panel

The other 47 commands have no default shortcut. Assign one in the Keyboard
Shortcuts editor if you use them often.

CONTROL PANEL
=============

  Keys                            | What they do
  --------------------------------+--------------------------------------------------------------
  `Ctrl` + `F` (`Cmd` + `F`)      | Focus the search box in the Requests section
  `Escape`                        | Close request details and return focus, or close an open menu
  Arrow keys, type-ahead, `Enter` | Move through and choose from drop-down menus

PREVIEW
=======

  Keys                       | What they do
  ---------------------------+-----------------------
  `Enter` in the address box | Load the typed address

IN A SERVED PAGE
================

  Keys:         `Alt` + `Shift` + `D`
  What they do: Open the developer dashboard (change with
                `auricLive.dashboard.shortcut`)

  Keys:         `Escape`
  What they do: Close an open dashboard menu, then the dashboard

  Keys:         Left and right arrows, `Home`, `End` (tab focused)
  What they do: Move between dashboard tabs

  Keys:         Up and down arrows, `Page Up`, `Page Down`, `Home`, `End`
  What they do: Scroll the dashboard

  Keys:         `Space`, `Shift` + `Space` (content focused)
  What they do: Page down and up
