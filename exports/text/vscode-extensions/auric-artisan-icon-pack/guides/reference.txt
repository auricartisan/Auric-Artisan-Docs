==============================================================================
ICON PACK REFERENCE
==============================================================================
The extensions included in Auric Artisan Icon Pack 0.1.0, its requirements and
what it does and does not contain.
Area: VS Code extensions › Auric Artisan Icon Pack   Updated: 2026-09-25

This reference describes version 0.1.0 as published on the Visual Studio
Marketplace.

INCLUDED EXTENSIONS
===================

  Extension:    Auric Icons: Modern
  ID:           `auric-artisan.auric-artisan-modern-icon`
  What it adds: 720 Modern and Sharp library icons, plus the Modern Explorer
                file icon theme.

  Extension:    Auric Icons: Playful
  ID:           `auric-artisan.auric-icons-playful`
  What it adds: 1,225 emoji-style icons in Color, Outline, Filled and Small.

  Extension:    Auric Artisan Emoji
  ID:           `auric-artisan.auric-artisan-emoji`
  What it adds: Emoji Studio: 1,914 emoji, skin tones, shortcodes and editor
                insertion.

  Extension:    Auric Icons: Drawn
  ID:           `auric-artisan.auric-icons-drawn`
  What it adds: 480 hand-drawn icons in Color, Mono, Outline and Duotone.

The pack uses the current publishing IDs. It does not install the retired
`auric-artisan-icons` or `auric-artisan-svg-icons` extensions.

WHAT THE PACK ITSELF CONTAINS
=============================

  Item                                 | Present
  -------------------------------------+------------------------------------------------
  Commands                             | None
  Settings                             | None
  Views or keybindings                 | None
  Background service or installer      | None
  Telemetry or workspace edits         | None
  Embedded copies of member extensions | No; members are downloaded from the marketplace

REQUIREMENTS
============

  Requirement | Value
  ------------+---------------------------------------
  VS Code     | 1.85 or later
  Network     | Marketplace access to download members
  Category    | Extension Packs

NOT INCLUDED
============

  Extension:             Auric Artisan Icon Studio
                         [../../auric-artisan-icon-studio/README.txt]
  Why you might want it: The separate all-in-one catalog: the three Auric
                         collections, emoji and seven open-source sets.

  Extension:             Auric Artisan File Icons
                         [../../auric-artisan-file-icons/README.txt]
  Why you might want it: Explorer file and folder themes in Facet, Playful and
                         Modern styles.

  Extension:             Auric Artisan Icon Hub
                         [../../auric-artisan-icon-hub/README.txt]
  Why you might want it: Seven open-source sets with colour controls and
                         export.
