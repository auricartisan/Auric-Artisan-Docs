What the Auric Artisan Icon Pack does with your data.
Area: VS Code extensions › Auric Artisan Icon Pack   Updated: 2026-09-25

The pack itself runs no code. It adds no telemetry, background service or
workspace edits, and stores nothing.

VS Code contacts the extension marketplace to download the four members, as it
does for any extension.
