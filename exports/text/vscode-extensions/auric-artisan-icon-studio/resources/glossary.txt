==============================================================================
GLOSSARY
==============================================================================
Definitions of the terms used in Auric Artisan Icon Studio.
Area: VS Code extensions › Auric Artisan Icon Studio   Updated: 2026-09-25

  Term:    Catalog entry
  Meaning: One icon or emoji in the bundled catalog. Its styles or tones are
           not counted separately.

  Term:    Collection
  Meaning: A set of icons from one source, such as Auric Drawn or Tabler. Icon
           Studio has 11.

  Term:    `currentColor`
  Meaning: A CSS keyword meaning "use the surrounding text colour", so an icon
           follows light and dark themes.

  Term:    Data URI
  Meaning: A way to embed a file's content directly in text, starting
           `data:image/svg+xml,`.

  Term:    Font-backed icon
  Meaning: An icon drawn from a font glyph (Material), not an SVG file. It
           needs the font loaded to display.

  Term:    For you
  Meaning: A view of icons ranked for the file you are editing and your likes
           and use.

  Term:    Host (collections)
  Meaning: The one extension that shows the shared library when several Auric
           collection extensions, or Icon Studio, are installed.

  Term:    Icon ID
  Meaning: The unique catalog name of an icon, such as `tabler-rocket` or
           `files-blank-document-drawn-0001`.

  Term:    JSX
  Meaning: The HTML-like syntax used in React components.

  Term:    Ligature name
  Meaning: The word that a Material icon font turns into a glyph, such as
           `home`.

  Term:    Likes
  Meaning: Icons you marked with the heart.

  Term:    Quick Pick
  Meaning: VS Code's searchable pop-up list at the top of the window.

  Term:    Recent
  Meaning: Icons you inserted, copied or saved, newest first.

  Term:    Shortcode
  Meaning: A text name for an emoji between colons, such as `:rocket:`.

  Term:    Skin tone
  Meaning: A modifier that changes the skin colour of emoji that support it.

  Term:    Smart insert
  Meaning: Choosing the output format from the language of the file you are
           editing.

  Term:    Style
  Meaning: A visual variant of an icon, such as Outline or Filled. Also called
           a variant.

  Term:    SVG
  Meaning: Scalable Vector Graphics, a text format for vector images.
