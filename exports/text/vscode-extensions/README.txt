==============================================================================
VS CODE EXTENSIONS
==============================================================================
Every Auric Artisan extension for Visual Studio Code, what each one does, its
Marketplace ID and minimum VS Code version, and where its documentation lives.
Area: VS Code extensions   Updated: 2026-09-25

Auric Artisan publishes seventeen free extensions for Visual Studio Code under
the publisher auric-artisan. They bring the same design system as the website
into your editor: colour and accessibility linting, a theme with a live Theme
Studio, icon and emoji libraries, file icon themes, a live server, a file
workspace, a font hub and a formatter. None of them sends telemetry.

Two of them are packs that install a set in one step: the Icon Pack installs
Modern, Drawn, Playful and Emoji, and the Studio Full Pack installs Color,
Accessibility and Code Health. Every member stays its own extension that you
can disable on its own.

New to installing extensions? Start with Install and set up
[install-and-setup/README.txt].

INSTALL IN ONE LINE
===================

Run this in a terminal, replacing the ID with any from the tables above:

    code --install-extension auric-artisan.auric-artisan-icon-pack
    code --install-extension auric-artisan.auric-artisan

Those two lines install both packs — five extensions. The install guide
[install-and-setup/README.txt] covers the Extensions view, VSIX files, forks
such as Cursor, Windsurf and VSCodium, updating, and removing extensions.

WHICH EXTENSION DO I NEED?
==========================

  You want to…: Give the whole editor a new look
  Install:      Auric Artisan Theme [auric-artisan-theme/README.txt]

  You want to…: Put icons on files and folders in the Explorer
  Install:      File Icons [auric-artisan-file-icons/README.txt] or Modern
                [auric-icons-modern/README.txt]

  You want to…: Insert icons into your code
  Install:      Icon Studio [auric-artisan-icon-studio/README.txt], a
                collection, or Icon Hub [auric-artisan-icon-hub/README.txt]
                for open-source sets

  You want to…: Insert emoji by shortcode
  Install:      Emoji [auric-artisan-emoji/README.txt]

  You want to…: Check colour contrast as you type
  Install:      Auric Color [auric-artisan-studio/color/README.txt]

  You want to…: Lint markup for WCAG 2.2
  Install:      Auric Accessibility
                [auric-artisan-studio/accessibility/README.txt]

  You want to…: Catch secrets and risky code before they ship
  Install:      Auric Code Health
                [auric-artisan-studio/code-health/README.txt]

  You want to…: Preview a site with live reload
  Install:      Live [auric-artisan-live/README.txt]

  You want to…: Rename and organise files in bulk
  Install:      File System [auric-artisan-file-system/README.txt]

  You want to…: Add a web font to a project
  Install:      Font Hub [auric-artisan-font-hub/README.txt]

  You want to…: Format code without surprises
  Install:      Formatter [auric-artisan-formatter/README.txt]
