OTHER AURIC ARTISAN VS CODE EXTENSIONS
======================================

  Extension:      Auric Artisan File Icons
                  [../../auric-artisan-file-icons/README.txt]
  How it relates: File and folder icons for the Explorer, in Facet, Playful
                  and Modern styles. Pairs with the theme for a complete look.

  Extension:      Auric Artisan Icon Studio
                  [../../auric-artisan-icon-studio/README.txt]
  How it relates: Search and insert icons and emoji into code.

  Extension:      Auric Artisan Emoji [../../auric-artisan-emoji/README.txt]
  How it relates: Emoji Studio with the same English and Hindi interface
                  switch.

  Extension:      Auric Artisan Studio [../../auric-artisan-studio/README.txt]
  How it relates: Colour, accessibility and code-health tools for your project
                  files.

  Extension:      Auric Artisan Live [../../auric-artisan-live/README.txt]
  How it relates: Live server and preview; Theme Studio's layout follows the
                  same workspace design.

For installing and managing any of these, see Install and set up
[../../install-and-setup/README.txt].
