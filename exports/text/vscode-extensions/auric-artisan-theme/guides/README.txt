==============================================================================
AURIC ARTISAN THEME GUIDES
==============================================================================
Contents of the Auric Artisan Theme guides folder, with one line on each
guide.
Area: VS Code extensions › Auric Artisan Theme   Updated: 2026-09-25

This folder holds the task guides and the complete reference for the Auric
Artisan Theme extension. Start with Getting started if you are new, then use
the task guides for each workflow. The reference lists every command, setting,
keybinding, dial, colour slot and option.

  File:           getting-started.md [getting-started.txt]
  What it covers: Install, switch to an Auric theme, tour Theme Studio and
                  make a first change.

  File:           choose-a-theme.md [choose-a-theme.txt]
  What it covers: The six families, 54 variants, high-contrast builds and
                  every way to switch.

  File:           looks-and-dials.md [looks-and-dials.txt]
  What it covers: The 11 looks and the 37 dials, with search, filters and
                  resets.

  File:           edit-colours.md [edit-colours.txt]
  What it covers: Override any of the 107 colour slots with the custom colour
                  picker.

  File:           check-contrast.md [check-contrast.txt]
  What it covers: Read the Audit tab and contrast report; tune the contrast
                  guard.

  File:           compare-and-preview.md [compare-and-preview.txt]
  What it covers: Compare shipped and current palettes; copy colours as CSS.

  File:           save-share-and-export.md [save-share-and-export.txt]
  What it covers: Presets, customisation JSON, clipboard and standalone theme
                  files.

  File:           theme-sidebar.md [theme-sidebar.txt]
  What it covers: Every part of the Auric Theme view in the Activity Bar.

  File:           interface-language.md [interface-language.txt]
  What it covers: Switch Theme Studio and the sidebar between English and
                  Hindi.

  File:           reference.md [reference.txt]
  What it covers: Every command, setting, keybinding, dial, slot, look, accent
                  and palette.

  File:           troubleshooting.md [troubleshooting.txt]
  What it covers: Symptoms, causes and fixes.

  File:           faq.md [faq.txt]
  What it covers: Short answers to common questions.
