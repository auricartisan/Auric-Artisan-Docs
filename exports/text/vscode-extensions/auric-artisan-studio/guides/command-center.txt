==============================================================================
THE COMMAND CENTER
==============================================================================
Open the Command Center with one shortcut, understand each of its sections,
and learn the six deterministic rules behind its suggestions.
Area: VS Code extensions › Auric Artisan Studio   Updated: 2026-09-25

The Command Center is a searchable list of everything the installed Studio
extensions can do right now: suggested next steps, actions, recent colours,
the worst findings and the files the Studio has written. It is a native VS
Code quick pick, so it looks and behaves like the Command Palette.

OPEN IT
=======

  - Press `Ctrl` + `Alt` + `.` (`Cmd` + `Alt` + `.` on macOS). The shortcut
    works anywhere in VS Code.
  - Or run Auric Artisan: Workstation: Command Center from the Command Palette
    (`Ctrl` + `Shift` + `P`).

The list is titled Auric Artisan — Command Center. Type to filter; the filter
matches titles and their descriptions. Press `Enter` to run the highlighted
item, or `Escape` to close.

When several Studio extensions are installed, the shortcut opens the host's
Command Center, which covers every installed capability. See The Workstation
[workstation.txt].

SECTIONS
========

Sections appear in this order, and only when they have something in them.

Suggested
---------

The same deterministic suggestions the Overview shows, up to three. Each shows
its title and, as its description, the reason it fired. See The suggestion
rules.

Actions
-------

Only actions for installed capabilities are listed.

  Action:            Scan project
  Description shown: WCAG + contrast + CVD (uses cache)
  Needs:             Auric Accessibility

  Action:            Rescan project
  Description shown: force-refresh the scan cache
  Needs:             Auric Accessibility

  Action:            Open Studio: …
  Description shown: none; one entry per Studio tool (listed below)
  Needs:             The tool's extension

  Action:            Open rulebook & knowledge database
  Description shown: rules, standards, manual checks, policies, and articles
  Needs:             Any

  Action:            Build workspace knowledge database
  Description shown: knowledge.json + rulebook.md + validated team overrides
  Needs:             Any

  Action:            Open unified Icon Studio
  Description shown: how many icon collections are installed and through which
                     provider, or install an Auric Icons provider to enable
                     the combined library
  Needs:             Any

  Action:            Pick / edit color
  Description shown: inline picker on the token under the cursor
  Needs:             Auric Color

  Action:            Check contrast of selection
  Description shown: -
  Needs:             Auric Color

  Action:            Fix all contrast in file
  Description shown: recolor every failing pair (one undo)
  Needs:             Auric Color

  Action:            Project health report
  Description shown: Markdown + JSON, written locally
  Needs:             Auric Code Health

  Action:            Write health record
  Description shown: health.json + SARIF for CI
  Needs:             Auric Code Health

  Action:            Open data folder
  Description shown: .auric-artisan workspace store
  Needs:             Auric Code Health

  Action:            Generate AI remediation plan
  Description shown: agent-ready fix plan with a design-token draft
  Needs:             Auric Accessibility or Auric Code Health

The Open Studio entries are, in order and for installed capabilities only:
Scan (the Studio's Home space), Code Health, Preview, Contrast, Brand,
Palette, Shades, Vision and Settings.

Recent colors
-------------

Up to eight colours you applied recently with a Studio picker (Auric Color).
Select one to open the colour picker on that value. If an editor is open, a
colour you then apply from the picker is inserted at the cursor.

Findings
--------

Up to eight of the worst findings from the last scan, each with its file name
and line. Select one to open the file at that line. Contrast rows read like
`#999999 on #FFFFFF · 2.32:1`; other rows show the finding's message.

Artifacts
---------

Files the Studio has written to the workspace's `.auric-artisan` folder. Only
files that exist are listed.

  File                                                 | Description shown
  -----------------------------------------------------+---------------------------------------
  `health.json` (or the name set in `health.fileName`) | unified health record
  `knowledge.json`                                     | searchable rules and guidance database
  `rulebook.md`                                        | generated engineering rulebooks
  `knowledge-overrides.json`                           | reviewed workspace knowledge overrides
  `ai-remediation-plan.md`                             | agent-ready remediation plan
  `project-health.md`                                  | project health report

THE SUGGESTION RULES
====================

Suggestions are produced by a fixed set of six rules. They are not generated
by AI or machine learning, and nothing is sent anywhere: each rule checks one
fact from your last scan or your open file. Rules are checked in the order
below, at most three suggestions are shown, and a suggestion you dismiss is
never offered again.

  #:          1
  Suggestion: N possible secrets detected
  Pill:       Critical
  Shown when: The last scan found at least one possible hardcoded secret
  Action:     Open health report (with Auric Code Health), otherwise Review in
              Studio

  #:          2
  Suggestion: N fixable contrast pairs in this file
  Pill:       High
  Shown when: Auric Color is installed and the active file has at least two
              contrast pairs that can be fixed automatically
  Action:     Fix all in file, plus Review, which opens the first pair in the
              Contrast Studio

  #:          3
  Suggestion: "rule-id" appears in N files
  Pill:       High
  Shown when: Auric Accessibility is installed and one WCAG rule fires in
              three or more files
  Action:     Open the findings (Check › Findings)

  #:          4
  Suggestion: Scan is N hours old
  Pill:       Workflow
  Shown when: Auric Accessibility is installed and the loaded scan is older
              than `scan.cache.maxAgeMinutes`
  Action:     Rescan

  #:          5
  Suggestion: Scanned X of Y files
  Pill:       Workflow
  Shown when: Auric Accessibility or Auric Color is installed and the last
              scan stopped at the `scan.maxFiles` limit
  Action:     Scan settings (Studio › Settings)

  #:          6
  Suggestion: N color values repeat 4+ times
  Pill:       Tip
  Shown when: At least six colour values are each used four or more times, and
              Auric Accessibility or Auric Code Health is installed
  Action:     Draft tokens (generates the remediation plan, which includes a
              design-token draft)

Each suggestion states a detected fact in its title and gives a one-line
reason, for example the code-health scan found hardcoded credentials or one
rule firing across files usually shares a single fix.

Dismissing suggestions
----------------------

  - In the Overview, select ✕ on a suggestion card. It disappears and is not
    offered again, even after later scans.
  - VS Code remembers the dismissal across sessions. The Studio keeps the 40
    most recent dismissals.
  - There is no command to bring a dismissed suggestion back.

The Colour workbench layout of the Overview shows only suggestion 2, because
it has no project score. The Command Center itself always evaluates all six
rules for the installed capabilities.
