==============================================================================
AURIC ARTISAN STUDIO DOCS
==============================================================================
The shared guides and reference pages that apply to every Auric Artisan Studio
extension.
Area: VS Code extensions › Auric Artisan Studio   Updated: 2026-09-25

This folder holds the guides that apply to the Studio as a whole: the screens
every extension shares, how installed extensions combine into one Workstation,
scanning, scores, reports and the CI gate. Features that belong to one
extension are documented in that extension's folder: Auric Color
[../color/README.txt], Auric Accessibility [../accessibility/README.txt] and
Auric Code Health [../code-health/README.txt].

Start with Getting started [getting-started.txt]. If you are deciding what to
install, read Choose what to install [choosing-an-install.txt] first.
