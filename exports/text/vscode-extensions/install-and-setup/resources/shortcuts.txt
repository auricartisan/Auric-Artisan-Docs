==============================================================================
SHORTCUTS AND COMMANDS
==============================================================================
The VS Code keys and commands you use to install, configure and manage the
Auric Artisan extensions.
Area: VS Code extensions › Install and setup   Updated: 2026-09-25

These are VS Code's own default keys on Windows and Linux. On macOS, use `Cmd`
in place of `Ctrl`. Each extension's own shortcuts are listed in that
extension's folder.

KEYS
====

  Keys                   | What they do
  -----------------------+-------------------------
  `Ctrl` + `Shift` + `X` | Open the Extensions view
  `Ctrl` + `Shift` + `P` | Open the Command Palette
  `Ctrl` + `,`           | Open the Settings editor

COMMANDS
========

  Command:   Extensions: Install from VSIX…
  Use it to: Install from a downloaded `.vsix` file

  Command:   Extensions: Check for Extension Updates
  Use it to: Check for new versions now

  Command:   Developer: Reload Window
  Use it to: Reload after installing, updating or changing a language

  Command:   Configure Display Language
  Use it to: Change VS Code's own display language

  Command:   Workspaces: Manage Workspace Trust
  Use it to: Trust or restrict the open folder

  Command:   Preferences: Open User Settings (JSON)
  Use it to: Edit user settings directly

  Command:   Preferences: Open Workspace Settings (JSON)
  Use it to: Edit workspace settings directly

  Command:   Preferences: Open Keyboard Shortcuts
  Use it to: Find and change shortcuts, and spot conflicts

EXTENSION SHORTCUTS AT A GLANCE
===============================

These are the default shortcuts the four workspace-tool extensions declare.
The full lists are in each extension's folder.

  Extension:               Auric Artisan Live
  Keys (Windows and Linux):`Ctrl` + `Alt` + `L`
  Command:                 Auric Live: Go Live

  Extension:               Auric Artisan Live
  Keys (Windows and Linux):`Ctrl` + `Alt` + `K`
  Command:                 Auric Live: Open Preview Beside

  Extension:               Auric Artisan File System
  Keys (Windows and Linux):`Alt` + `Enter` (Explorer focused)
  Command:                 Auric Files: File Properties

  Extension:               Auric Artisan Font Hub
  Keys (Windows and Linux):`Ctrl` + `Alt` + `F`
  Command:                 Auric Artisan Font Hub: Open Font Hub

  Extension:               Auric Artisan Font Hub
  Keys (Windows and Linux):`Ctrl` + `Alt` + `T`
  Command:                 Auric Artisan Font Hub: Quick Pick Font

  Extension:               Auric Artisan Formatter
  Keys (Windows and Linux):`Ctrl` + `Alt` + `Shift` + `F` (editor focused)
  Command:                 Auric Formatter: Preview Formatting as a Diff

  Extension:               Auric Artisan Formatter
  Keys (Windows and Linux):`Ctrl` + `Alt` + `Shift` + `P`
  Command:                 Auric Formatter: Open Formatter Studio

These four extensions document `Cmd` in place of `Ctrl` on macOS for the
combinations above.
