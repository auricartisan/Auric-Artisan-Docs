IDs that are easy to get wrong
------------------------------

  - The Studio Full Pack is the bare `auric-artisan.auric-artisan`.
  - Icon Hub's ID is `auric-artisan.auric-artisan-icon-lib`, not `…-icon-hub`.
  - Auric Icons: Modern is `auric-artisan.auric-artisan-modern-icon`, while
    Drawn and Playful are `auric-artisan.auric-icons-drawn` and
    `auric-artisan.auric-icons-playful`.
  - File Icons is `auric-artisan.auric-artisan-file-icon` (singular).
  - Font Hub is `auric-artisan.auric-artisan-font-hub`. The older Font Library
    extension had a different ID.

WHAT EACH ONE IS
================

  Extension:   Studio — Full Pack
  In one line: Installs Auric Color, Auric Accessibility and Auric Code Health
               together

  Extension:   Auric Color
  In one line: Inline colour picker, swatches and hover readouts, WCAG and
               APCA contrast, palettes and OKLCH scales

  Extension:   Auric Accessibility
  In one line: Accessibility linting against WCAG 2.0, 2.1 and 2.2 for HTML,
               JSX, Vue, Svelte, Astro, PHP and CSS

  Extension:   Auric Code Health
  In one line: Scans for hardcoded secrets, TODO and FIXME markers, debug
               leftovers, risky APIs and oversized files

  Extension:   Theme
  In one line: Colour themes with Theme Studio for customising them

  Extension:   File Icons
  In one line: Facet, Playful and Modern file and folder icon themes for the
               Explorer

  Extension:   Icon Pack
  In one line: Installs Auric Icons: Modern, Drawn and Playful and Auric
               Artisan Emoji together

  Extension:   Auric Icons: Modern
  In one line: A file and folder icon theme plus an SVG icon library

  Extension:   Auric Icons: Drawn
  In one line: A hand-drawn style SVG icon library

  Extension:   Auric Icons: Playful
  In one line: An emoji-style SVG icon library in colour, outline, filled and
               small variants

  Extension:   Emoji
  In one line: Emoji Studio for finding and inserting emoji, with English and
               Hindi

  Extension:   Icon Studio
  In one line: One offline studio for every Auric icon collection, emoji and
               seven open-source icon sets

  Extension:   Icon Hub
  In one line: Search open-source icons across seven collections, customise
               SVG and export sprites or ZIPs

  Extension:   Live
  In one line: Local development server with live reload, preview, HTTPS, API
               proxy and mocks, and request inspection

  Extension:   File System
  In one line: A file workspace in the Explorer: batch rename, templates,
               related files, tags, Properties and workspace trash

  Extension:   Font Hub
  In one line: Discover and compare fonts, add them from the Auric font CDN,
               and export self-hosting kits

  Extension:   Formatter
  In one line: Code formatter with native diff previews, Formatter Studio,
               workspace scans and a command-line check

ADDRESSES
=========

  What:            Marketplace page
  Address pattern: `https://marketplace.visualstudio.com/items?itemName=<extension
                   ID>`

  What:            VSIX download
  Address pattern: `https://marketplace.visualstudio.com/_apis/public/gallery/publishers/auric-artisan/vsextensions/<name>/<version>/vspackage`

  What:            Auric Artisan VS Code page
  Address pattern: https://auricartisan.com/vscode/

  What:            Support
  Address pattern: https://auricartisan.com/company/contact/

In the VSIX address, `<name>` is the part of the ID after `auric-artisan.`.

COMMAND-LINE FLAGS
==================

  Command:      `code --install-extension <id>`
  What it does: Install the latest version

  Command:      `code --install-extension <id>@<version>`
  What it does: Install a specific version

  Command:      `code --install-extension <id> --force`
  What it does: Update to the latest version without a prompt

  Command:      `code --install-extension <file>.vsix`
  What it does: Install from a VSIX file

  Command:      `code --uninstall-extension <id>`
  What it does: Remove an extension

  Command:      `code --list-extensions --show-versions`
  What it does: List installed extensions with versions

  Command:      `code --profile "<name>" --install-extension <id>`
  What it does: Install into a named VS Code profile

VS CODE COMMANDS USED IN THESE GUIDES
=====================================

  Command:      Extensions: Install from VSIX…
  What it does: Install an extension from a `.vsix` file

  Command:      Extensions: Check for Extension Updates
  What it does: Look for newer versions now

  What it does: Reload the window after installing or updating

  Command:      Configure Display Language
  What it does: Change VS Code's own display language

  Command:      Workspaces: Manage Workspace Trust
  What it does: Trust or restrict the open folder

  Command:      Preferences: Open User Settings (JSON)
  What it does: Edit user settings as JSON

  Command:      Preferences: Open Workspace Settings (JSON)
  What it does: Edit workspace settings as JSON

  Command:      Preferences: Open Keyboard Shortcuts
  What it does: Review and change shortcuts

  Command:      Shell Command: Install 'code' command in PATH
  What it does: macOS: make the `code` launcher available in terminals

SETTINGS THAT CONTROL INSTALLATION
==================================

These are VS Code settings, not Auric settings.

  Setting:      `extensions.autoUpdate`
  What it does: Whether VS Code installs extension updates automatically

  Setting:      `extensions.autoCheckUpdates`
  What it does: Whether VS Code checks for updates automatically

  Setting:      `settingsSync.ignoredExtensions`
  What it does: Extension IDs that Settings Sync should not install or remove
                on other machines

  Setting:      `settingsSync.ignoredSettings`
  What it does: Setting IDs that Settings Sync should not copy
