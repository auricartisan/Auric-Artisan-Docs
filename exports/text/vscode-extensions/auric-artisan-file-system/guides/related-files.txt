==============================================================================
RELATED FILES
==============================================================================
Jump between a file and its test, style, story, component and documentation,
create missing companions, and teach Auric Files your own conventions.
Area: VS Code extensions › Auric Artisan File System   Updated: 2026-09-25

Most source files come with companions: a component has a test, a stylesheet
and a story; a module has documentation and type declarations. Auric Files
knows the usual conventions for each framework preset, so it can open a file's
companion in one step, show which ones are missing and create them.

GO TO A COMPANION
=================

With a file open in the editor:

  Command:       Auric Files: Go to Related File…
  Opens:         A list of every companion that exists
  Deck shortcut: `Ctrl` + `Alt` + `R`

  Command:       Auric Files: Open Matching Test
  Opens:         The file's test
  Deck shortcut: `Ctrl` + `Alt` + `A`, then `Q`

  Command:       Auric Files: Open Matching Style
  Opens:         The file's stylesheet
  Deck shortcut: `Ctrl` + `Alt` + `A`, then `S`

  Command:       Auric Files: Open Matching Story
  Opens:         The file's story
  Deck shortcut: `Ctrl` + `Alt` + `A`, then `W`

  Command:       Auric Files: Open Matching Component
  Opens:         The component a test, style or story belongs to
  Deck shortcut: `Ctrl` + `Alt` + `A`, then `I`

  Command:       Auric Files: Open Matching Documentation
  Opens:         The file's documentation
  Deck shortcut: `Ctrl` + `Alt` + `A`, then `Shift` + `D`

The shortcuts need `auricFiles.keyboard.enableDefaultShortcuts`. The same
commands are in Auric Files › Navigate and Paths on a file's context menu, and
in the Inspect & navigate group of the panel.

Navigation works in both directions: from `Button.tsx` to `Button.test.tsx`,
and from the test back to the component.

SEE THE WHOLE GROUP
===================

Show Related File Group lists every companion the rules expect for the file,
marking which exist and which are missing. It runs from the panel's Inspect &
navigate group.

The Properties view also lists up to six related files that exist. See
Properties, compare and export [properties-compare-export.txt].

CREATE MISSING COMPANIONS
=========================

  - Auric Files: Create Related Files… (`Ctrl` + `Alt` + `A`, then `R` with
    the deck) — choose which companions to create from a list.
  - Auric Files: Generate Missing Companion Files — create every missing
    companion at once. If none is missing: Every companion file already
    exists.

New companions are created from the rule's template, using the preset's style
language and test framework (`auricFiles.create.componentStyleLanguage`,
`auricFiles.create.testFramework`).

RELATIONSHIP KINDS
==================

The built-in rules use these kinds: Component, Test, Style, Story, Template,
Types, Snapshot, Schema, Documentation, Barrel (an index file that re-exports)
and Config. Which ones apply depends on the active preset.

SETTINGS
========

  Setting:      `auricFiles.related.enabled`
  Default:      `true`
  What it does: Resolve companions for the active file

  Setting:      `auricFiles.related.testDirectories`
  Default:      `__tests__`, `tests`, `test`, `spec`
  What it does: Folders searched when tests live apart from the source

  Setting:      `auricFiles.related.storyExtensions`
  Default:      `.stories.tsx`, `.stories.jsx`, `.stories.ts`, `.stories.js`,
                `.stories.svelte`, `.stories.mdx`
  What it does: Story file suffixes, tried in order

  Setting:      `auricFiles.related.rules`
  Default:      none
  What it does: Your own relationships (below)

ADD YOUR OWN RULES
==================

A rule connects a source pattern to one or more target patterns. Add rules for
conventions the presets do not know, such as a repository layer or a generated
client.

    {
      "auricFiles.related.rules": [
        {
          "id": "api-client",
          "kind": "client",
          "label": "Generated API client",
          "from": "{dir}/{name}.service.ts",
          "to": ["{dir}/generated/{name}.client.ts"],
          "presets": []
        }
      ]
    }

  Field:    `id`
  Required: Yes
  Meaning:  Identifier; a built-in rule with the same id is replaced

  Field:    `kind`
  Required: Yes
  Meaning:  The relationship name shown beside the companion: one of the kinds
            above, or your own

  Field:    `from`
  Required: Yes
  Meaning:  Pattern matching the source file

  Field:    `to`
  Required: Yes
  Meaning:  Candidate targets in priority order. Navigation opens the first
            that exists; generation writes the first

  Field:    `label`
  Required: No
  Meaning:  Wording in related-file lists

  Field:    `presets`
  Required: No
  Meaning:  Presets the rule belongs to; empty applies everywhere

  Field:    `templateId`
  Required: No
  Meaning:  Template used when the companion is generated

Pattern tokens
--------------

  Token:   `{dir}`
  Meaning: Zero or more leading folders, captured

  Token:   `{name}`
  Meaning: The file name without extensions, so `Button.test.tsx` is read as
           `Button`

  Token:   `{ext}`
  Meaning: The extension without its dot; defaults to the source file's own

  Token:   `{testDir}`
  Meaning: Each configured test folder, in order

  Token:   `{storyExt}`
  Meaning: Each configured story extension, in order

  Token:   `{mirrorDir}`
  Meaning: The source folder relocated under a test root (`src/ui` becomes
           `tests/ui`), and back again in reverse

  Token:   `{a,b}`
  Meaning: A brace set, expanded into alternatives

Rules are read backwards too: a file matching a `to` pattern resolves back to
its `from` file. Relation rules come from workspace settings, so they only
apply in a trusted workspace.

INDEX
=====

Related files are found through the workspace index. Until the index is built,
Properties says Not indexed yet; run Auric Files: Refresh to build it.

With a component open, Go to Related File… lists its companions, and choosing
one opens it.
