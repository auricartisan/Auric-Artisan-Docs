==============================================================================
GETTING STARTED WITH SEARCH
==============================================================================
A tour of the Auric Artisan search page and a first search, step by step.
Area: Website › Search   Updated: 2026-09-25

BEFORE YOU START
================

You need nothing but a browser. Searching the site needs no account and no
sign-in. The first time you open the page it prepares its index; the status
line then reads Index ready with the number of items indexed.

A TOUR OF THE PAGE
==================

Before you type, the page shows a start screen:

  - The search field at the top, with the placeholder Search Auric Artisan. A
    clear button appears once you type, and the globe button beside it
    switches to web search.
  - A privacy line: Indexed on this device — nothing you type leaves the
    browser. Your recent searches sit on the same line, with Clear.
  - Three example cards that run real queries when you select them:
    - Paste a hex — a colour with its contrast against black and white.
    - Give it two — a pair of colours judged for contrast.
    - Narrow by section — the query `type:learn contrast`, with how many pages
      it matches.
  - A ribbon of sections with how many pages each holds (for example Learn,
    Documentation, Tools), and the total number of pages in the index. Each
    section links to its own page.
  - More ways to ask — buttons for the operators `type:learn`, `"a phrase"`,
    `-word` and `tag:oklch`. Select one to put it in the field.
  - A line about the globe: it searches a second index, Auric Artisan's own
    crawl of the web, with a link to Put your site in it.

YOUR FIRST SEARCH
=================

  1. Open https://auricartisan.com/search/.
  2. Type `contrast`. After the second character, results start to appear.
  3. Because `contrast` is also the name of a tool, a Tool card leads the page
     with Open the tool. The results list follows.
  4. Add a word: `contrast charts`. The tool card goes away, because a tool
     card appears only when the whole query names the tool.
  5. Look at the line under the field. It shows how your query was read: each
     word as a chip, and related words, shown dashed, that were matched at
     reduced weight.
  6. Select the Learn tab to see only Learn articles. The number on each tab
     is how many results it holds.
  7. Press the down arrow to highlight the first result. A panel shows why it
     ranks there.
  8. Press `Enter` to open it.

TRY A COLOUR
============

  1. Clear the field with the clear button or `Escape`.
  2. Type `#777777 #ffffff`.
  3. A Contrast pair card shows the ratio 4.48:1 and a table of AA and AAA
     results. Grey `#777777` on white just misses AA for body text, although
     it passes for large text.
  4. Select Swap them to put the background first, or Open the checker to
     continue in the Contrast Checker.
