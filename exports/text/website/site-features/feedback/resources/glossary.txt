==============================================================================
FEEDBACK GLOSSARY
==============================================================================
Terms used in the feedback guides.
Area: Website › Site features › Feedback   Updated: 2026-09-25

  Term:    Automatic prompt
  Meaning: The feedback panel the site shows by itself after 20 minutes of
           active use.

  Term:    Active time
  Meaning: Time with the page visible on screen; time in a background tab does
           not count.

  Term:    Quiet period
  Meaning: The time after a prompt during which the site does not ask again.

  Term:    Anonymous feedback
  Meaning: Feedback sent without a name or email.

  Term:    Bug report
  Meaning: A description of something that went wrong, sent with details of
           the page.

  Term:    Severity
  Meaning: How badly a bug affects you: Minor, Normal or Blocking.

  Term:    Draft
  Meaning: Text you have typed but not sent, kept on your device.
