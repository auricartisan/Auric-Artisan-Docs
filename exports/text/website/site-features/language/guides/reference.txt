==============================================================================
LANGUAGE REFERENCE
==============================================================================
Every language control, what it does, and how the language choice is kept.
Area: Website › Site features › Language   Updated: 2026-09-25

CONTROLS
========

  Control:      Globe button (Language / भाषा)
  Where:        Header, wide screens
  What it does: Switches English ⇄ Hindi

  Control:      English / हिन्दी
  Where:        Settings › Appearance › Language
  What it does: Picks a language

  Control:      English / हिन्दी
  Where:        Drawer › Preferences › Language
  What it does: Picks a language

  Control:      Switch language
  Where:        Spotlight, command mode (`>`)
  What it does: Switches English ⇄ Hindi; shows the current language

  Control:      `?lang=hi` / `?lang=en`
  Where:        Any page address
  What it does: Opens the page in that language and remembers it

BEHAVIOUR
=========

  Item:      Languages
  Behaviour: English (`en`), Hindi (`hi`)

  Item:      Default
  Behaviour: English

  Item:      Switching to Hindi
  Behaviour: Translates the page in place, then every page after

  Item:      Switching to English
  Behaviour: Reloads the page

  Item:      Remembered
  Behaviour: In this browser, for every page, until you switch

  Item:      Page language
  Behaviour: Marked as Hindi while in Hindi, so screen readers and translation
             tools know

  Item:      Date and time format
  Behaviour: Hindi (India) while in Hindi; English (United States) style in
             English, except where your Clock settings choose a format

  Item:      Fonts
  Behaviour: Devanagari system fonts such as Nirmala UI, Noto Sans Devanagari,
             Mukta, Hind or Kohinoor Devanagari, depending on your device

  Item:      In the settings export file
  Behaviour: No

  Item:      Offline
  Behaviour: Hindi text is included in the offline download when you prepare
             it while the site is in Hindi

OPTING PARTS OF A PAGE OUT
==========================

Some elements are deliberately never translated: the language buttons, code,
keyboard keys, and the header detail lines of the right-click menu that show
addresses, hex codes and quoted text.
