==============================================================================
SETTINGS PANEL REFERENCE
==============================================================================
Every control in the Settings panel, with what it does, its values and its
default, plus the settings file format and messages.
Area: Website › Site features › Settings panel   Updated: 2026-09-25

All settings apply immediately, are kept in this browser, and are shared by
every tab of the site you have open.

PANEL FRAME
===========

  Control:      Title Your Settings
  What it does: Drag to move the panel. The position is remembered.

  Control:      Focus mode
  What it does: Kit-style focus button. Tooltip: "Keep Settings open through
                navigation and while opening other kits."

  Control:      Resize
  What it does: Switches between normal width and a wider panel (up to 980
                px). The choice is remembered.

  Control:      Minimize / Restore
  What it does: Collapses the panel to its title bar. Select the bar or the
                button to restore.

  Control:      Close settings (X)
  What it does: Closes the panel. Focus returns to the control that opened it.

  Control:      Section list
  What it does: Appearance, Comfort, Highlights, Clock, Tooltips, Ads,
                Shortcuts, each with a control count

  Control:      Export
  What it does: Downloads `auric-settings.json`

  Control:      Import
  What it does: Loads a settings file

  Control:      Reset all
  What it does: Resets every setting after a confirmation (saved colours are
                kept)

  Control:      `Ctrl` `,` hint
  What it does: Reminder of the open and close shortcut

SHORTCUTS
=========

The Shortcuts section lists the panel's own keyboard shortcuts. It has no
settings.

  Keys         | Action
  -------------+---------------------------------------------
  `Ctrl` + `,` | Open or close settings
  `Alt` + `R`  | Toggle reading mode
  `Alt` + `T`  | Switch theme (light, then dark, then system)
  `Alt` + `+`  | Increase text size
  `Alt` + `-`  | Decrease text size
  `Alt` + `0`  | Reset text size
  `Alt` + `M`  | Toggle reduced motion
  `Esc`        | Close the dialog

The `Alt` shortcuts do nothing while you are typing in a text field. On a Mac,
`Cmd` + `,` also opens the panel. The whole site's shortcuts are in Keyboard
shortcuts [../../keyboard-shortcuts/README.txt].

THE SETTINGS FILE
=================

Export writes a JSON file named `auric-settings.json`. It starts with two
marker fields and then lists every setting:

    {
      "_aa": "auric-settings",
      "v": 1,
      "accent": "sapphire",
      "savedColors": ["#2e8b57"],
      "themeMode": "system",
      "textScale": 1.12,
      "reduceMotion": false,
      "customCursor": true,
      "eyeRest": true,
      "eyeRestInterval": 35,
      "time24": true,
      "clockTz": "",
      "dateFormat": "dmy"
    }

The example is shortened. A real export also includes the remaining switches:
`reduceTransparency`, `contrast`, `underlineLinks`, `reading`, `screenSaver`,
`screenSaverDelay`, `showWelcome`, `showAnnouncements`, `showQuickLinks`,
`showTimeStrip`, `showHeroNotice`, `showDemoBadges`, `showSeconds`,
`showDate`, `tipEnabled`, `tipDetails`, `tipAdvanced`, `adsEnabled`,
`adsDensity` and `adsInPanels`, plus `recentColors`, an older colour history
that is only read to fill Saved colors once.

  Field:           `accent`
  Accepted values: A preset name (`gold`, `champagne`, `rose-gold`, `silver`,
                   `platinum`, `bronze`, `copper`, `espresso`, `maroon`,
                   `rose`, `emerald`, `sapphire`, `amethyst`) or a `#rrggbb`
                   colour

  Field:           `savedColors`
  Accepted values: Up to 18 `#rrggbb` colours

  Field:           `themeMode`
  Accepted values: `light`, `dark`, `system`

  Field:           `textScale`
  Accepted values: `0.9`, `1`, `1.12`, `1.25`

  Field:           `eyeRestInterval`
  Accepted values: `20`, `35`, `45`, `60`

  Field:           `screenSaverDelay`
  Accepted values: `1`, `5`, `10`, `20`, `30`

  Field:           `dateFormat`
  Accepted values: `long`, `dmy`, `mdy`

  Field:           `clockTz`
  Accepted values: Empty for auto-detect, or a time zone name such as
                   `Europe/London`

  Field:           `showWelcome`, `showAnnouncements`, `showQuickLinks`
  Accepted values: `true`, `false` or `"home"`

  Field:           `adsDensity`
  Accepted values: `standard`, `reduced`

  Field:           Other switches
  Accepted values: `true` or `false`

The preset names in the file are fixed identifiers: `espresso` is the Brown
swatch, `rose` is Pink, and `platinum` is Platinum Grey. The language is not
part of the file; it is kept separately (see Language
[../../language/README.txt]).

MESSAGES
========

  Message:         Settings exported
  When it appears: After Export

  Message:         Couldn’t export settings
  When it appears: The browser refused the download

  Message:         Settings imported
  When it appears: After a successful Import

  Message:         That file isn’t valid settings
  When it appears: The chosen file is not valid JSON

  Message:         Couldn’t read that file
  When it appears: The browser could not read the chosen file

  Message:         Appearance / Comfort / Highlights / Clock restored to
                   defaults
  When it appears: After that section's restore

  Message:         Section restored to defaults
  When it appears: After the Tooltips or Ads restore

  Message:         All settings reset to defaults
  When it appears: After a confirmed Reset all

  Message:         Theme: Light / Dark / System
  When it appears: After `Alt` + `T`

  Message:         Text size: Small / Default / Large / X-Large
  When it appears: After `Alt` + `+`, `Alt` + `-` or `Alt` + `0`

  Message:         Reduced motion on / Reduced motion off
  When it appears: After `Alt` + `M`
