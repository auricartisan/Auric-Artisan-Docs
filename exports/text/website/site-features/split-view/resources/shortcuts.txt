==============================================================================
SPLIT VIEW SHORTCUTS
==============================================================================
Keyboard shortcuts for split view.
Area: Website › Site features › Split view   Updated: 2026-09-25

  Keys:   `Ctrl` + `Shift` + `D`
  Action: Open or close split view

  Keys:   `Esc`
  Action: Close an open More menu; otherwise close split view

  Keys:   `Alt` + `1`
  Action: Focus the live pane

  Keys:   `Alt` + `2`
  Action: Focus the companion pane

  Keys:   `Alt` + `V`
  Action: Side by side or stacked

  Keys:   `Alt` + `S`
  Action: Swap panes

  Keys:   `Alt` + `E`
  Action: Equal split

  Keys:   `Alt` + click on a link
  Action: Open the link in the other pane; with split view closed, open split
          view with it

  Keys:   `Enter` in an address bar
  Action: Load the address or highlighted destination

  Keys:   `Ctrl` + `Enter` in an address bar
  Action: Open the typed address in a new browser tab

  Keys:   `Esc` in an address bar
  Action: Close the destination list, then restore the address

See Keyboard shortcuts [../../keyboard-shortcuts/README.txt] for the whole
site.
