==============================================================================
HEADER AND NAVIGATION GLOSSARY
==============================================================================
Terms used in the header and navigation guides.
Area: Website › Site features › Header and navigation   Updated: 2026-09-25

  Term:    Header
  Meaning: The strip at the top of every page with the brand, menus, quick
           tools and sign-in.

  Term:    Menu (header)
  Meaning: The Company, Tools or Learn list that opens below its button.

  Term:    Quick tools
  Meaning: The row of icon buttons in the header: app, extension, VS Code,
           search, guide, library, language, theme.

  Term:    Drawer
  Meaning: The sliding sheet that holds the header's contents on narrow
           screens.

  Term:    Breakpoint
  Meaning: A window width at which the layout changes. The header's is 960
           pixels.

  Term:    Group chip
  Meaning: A button in the drawer's Tools section that shows one group of
           tools at a time.

  Term:    Page utilities bar
  Meaning: The launcher bar at the bottom-left for the kits, the navigation
           dock and Settings.

  Term:    Kit
  Meaning: A floating panel of extra tools, such as the Feature Kit or Library
           Kit.

  Term:    Navigation dock
  Meaning: The slim floating rail with Back, Forward, Reload, outline and
           scroll controls.

  Term:    Footer
  Meaning: The section at the end of every page with directory links, contact
           details and social links.

  Term:    PWA
  Meaning: Progressive web app: a website you can install and run like an app,
           with offline support.
