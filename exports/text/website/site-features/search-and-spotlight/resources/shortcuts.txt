==============================================================================
SPOTLIGHT SHORTCUTS
==============================================================================
Keys for opening and using Spotlight.
Area: Website › Site features › Search and Spotlight   Updated: 2026-09-25

  Keys                                | Action
  ------------------------------------+-----------------------------------------------
  `Ctrl` + `K` (`Cmd` + `K` on a Mac) | Open or close Spotlight
  `Up` / `Down`                       | Move through results
  `Enter`                             | Open the highlighted result or run the command
  `Ctrl` + `Enter` (`Cmd` + `Enter`)  | Open the highlighted result in a new tab
  `Tab`                               | Next scope tab
  `Shift` + `Tab`                     | Previous scope tab
  `Esc`                               | Clear the box, then close Spotlight
  `>` as the first character          | Command mode

In some kits, `Ctrl` + `K` moves to the kit's own search field while that kit
is open. See Kits [../../../kits/README.txt] and Keyboard shortcuts
[../../keyboard-shortcuts/README.txt].
