==============================================================================
ACCESSIBILITY AIDS GLOSSARY
==============================================================================
Terms used in the accessibility aids guides.
Area: Website › Site features › Accessibility aids   Updated: 2026-09-25

  Term:    Reading mode
  Meaning: A distraction-free layout with a narrow, large-text column and no
           floating controls.

  Term:    Reduced motion
  Meaning: Fewer and shorter animations; also a device setting the site
           follows.

  Term:    Transparency
  Meaning: See-through, blurred panel backgrounds; turned solid by Reduce
           transparency.

  Term:    Contrast
  Meaning: The difference in lightness between text and its background.

  Term:    Skip link
  Meaning: A link at the start of the page that jumps past the header to the
           main content.

  Term:    Focus
  Meaning: The control that keyboard input currently goes to, shown with an
           outline.

  Term:    Screen reader
  Meaning: Software that reads the screen aloud or in braille.

  Term:    Live announcement
  Meaning: A message a screen reader reads without moving focus.

  Term:    Modal dialog
  Meaning: A panel that keeps keyboard focus inside it until closed.
