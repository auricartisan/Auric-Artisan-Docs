==============================================================================
EVERY WAY TO SWITCH THE THEME
==============================================================================
All the places you can change the theme, and how each one behaves.
Area: Website › Site features › Theme   Updated: 2026-09-25

All of these change the same site-wide setting, except the last two, which
affect only one panel.

HEADER BUTTON
=============

The sun or moon at the right of the header (tooltip Theme: "Switch between
light and dark mode").

  - It shows a moon while the page is light (select it to go dark) and a sun
    while the page is dark.
  - It always switches to the opposite of what you see, and fixes that choice
    (it leaves System mode).

SETTINGS PANEL
==============

Settings (`Ctrl` + `,`) › Appearance › Theme: Light, Dark, System. This is the
only place, with the drawer, that can set System.

MOBILE DRAWER
=============

On narrow screens, open the drawer and use Preferences › Theme: Auto, Light,
Dark. Auto is the same as System. The highlighted button shows your current
choice.

KEYBOARD
========

`Alt` + `T` anywhere on the site (not while typing in a field) moves one step
through Light, Dark and System, in that order, and shows a message such as
"Theme: Dark".

RIGHT-CLICK MENU
================

Right-click the page, open View, and choose Switch theme. The row shows the
current theme (Light or Dark). It works like the header button. You can pin it
to the quick bar with its star, and filter for it by typing `dark` or `light`.

SPOTLIGHT COMMAND
=================

Press `Ctrl` + `K`, type `>`, and choose Toggle light and dark. The row shows
the current theme. It works like the header button.

CARD MENU
=========

On pages with card grids, right-click a card and select the Theme pill under
System. It works like the header button.

A KIT'S OWN THEME BUTTON
========================

Each kit has a sun or moon button in its title bar, labelled for example
"Switch Status Kit to light mode". It changes the theme of that kit only and
is remembered for it. Until you use it, a kit follows the site theme. See Kits
[../../../kits/README.txt].

A SPLIT-VIEW PANE
=================

In split view, each pane has a Theme control in its More menu that cycles
Auto, Light and Dark for that pane only, so you can compare the two themes
side by side. It does not change your setting. See Split view
[../../split-view/README.txt].
