==============================================================================
THEME GLOSSARY
==============================================================================
Terms used in the theme guides.
Area: Website › Site features › Theme   Updated: 2026-09-25

  Term:    Theme
  Meaning: The overall colour scheme of the site's interface: light or dark.

  Term:    Light theme
  Meaning: Light backgrounds with dark text.

  Term:    Dark theme
  Meaning: Dark backgrounds with light text.

  Term:    System mode
  Meaning: A setting that follows your device's light or dark preference.
           Called Auto in the drawer.

  Term:    Toggle
  Meaning: A control that switches between two states, here light and dark.

  Term:    Override
  Meaning: A theme set for one panel (a kit or a split-view pane) that differs
           from the site's theme.
