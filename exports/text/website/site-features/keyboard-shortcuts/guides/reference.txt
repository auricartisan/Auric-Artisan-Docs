==============================================================================
KEYBOARD SHORTCUT REFERENCE
==============================================================================
Every keyboard shortcut on the Auric Artisan website, grouped by where it
works.
Area: Website › Site features › Keyboard shortcuts   Updated: 2026-09-25

"Ctrl or Cmd" means `Ctrl` on Windows, Linux and ChromeOS, and `Cmd` on a Mac.
On a Mac, `Alt` is the `Option` key.

ANYWHERE ON THE SITE
====================

  Keys:   `Ctrl` + `K` (Ctrl or Cmd)
  Action: Open or close Spotlight search
  Notes:  Search and Spotlight [../../search-and-spotlight/README.txt]

  Keys:   `Ctrl` + `,` (Ctrl or Cmd)
  Action: Open or close Settings
  Notes:  Settings panel [../../settings-panel/README.txt]

  Keys:   `?`
  Action: Open the page guide
  Notes:  Guide and page outline [../../guide-and-page-outline/README.txt]

  Keys:   `Alt` + `R`
  Action: Reading mode on or off
  Notes:  Not while typing

  Keys:   `Alt` + `T`
  Action: Theme: Light, Dark, System
  Notes:  Not while typing

  Keys:   `Alt` + `+` (or `Alt` + `=`)
  Action: Text one size larger
  Notes:  Not while typing

  Keys:   `Alt` + `-`
  Action: Text one size smaller
  Notes:  Not while typing

  Keys:   `Alt` + `0`
  Action: Default text size
  Notes:  Not while typing

  Keys:   `Alt` + `M`
  Action: Reduced motion on or off
  Notes:  Not while typing

  Keys:   `Ctrl` + `Shift` + `D`
  Action: Open or close split view
  Notes:  Split view [../../split-view/README.txt]

  Keys:   `Alt` + click a site link
  Action: Open split view with that page
  Notes:  —

  Keys:   `Alt` + `Shift` + `R`
  Action: Open the recorder; while recording, stop and save
  Notes:  Screen recorder [../../screen-recorder/README.txt]

  Keys:   `Alt` + `Shift` + `P`
  Action: Pause or resume a recording
  Notes:  —

  Keys:   `Ctrl` + `Shift` + `U`
  Action: Check for and apply a website update
  Notes:  Kits [../../../kits/README.txt] (Update Kit)

  Keys:   `Ctrl` + `Shift` + `C`
  Action: Open the colour tools menu (with a selected hex code, if any)
  Notes:  Uses `Shift`, so it is not the browser's copy

  Keys:   `Shift` + right-click
  Action: Your browser's right-click menu (or the site's, if you swapped them)
  Notes:  Context menu [../../context-menu/README.txt]

  Keys:   `Esc`
  Action: Close the open panel, menu, dialog or bar
  Notes:  —

KITS
====

  Keys:   `Ctrl` + `Shift` + `K` (Ctrl or Cmd)
  Action: Open or close the Feature Kit

  Keys:   `Ctrl` + `1` to `Ctrl` + `6` inside the Feature Kit
  Action: Calculator, Converter, Feedback, Notes, Date and time, Developer
          tools

  Keys:   `Ctrl` + `M` (Ctrl or Cmd)
  Action: Open the Menu Kit

  Keys:   `Ctrl` + `Shift` + `A` (Ctrl or Cmd)
  Action: Open or close the Advanced Kit

  Keys:   `Ctrl` + `Shift` + `L` (Ctrl or Cmd)
  Action: Open or close the Library Kit

  Keys:   `Ctrl` + `K` inside an open Menu Kit or Status Kit
  Action: Jump to the kit's own search field

  Keys:   `/` inside an open Menu Kit or Status Kit
  Action: Jump to the kit's own search field

  Keys:   `Esc`
  Action: Close the open kit

  Keys:   `Esc`
  Action: Close the page utilities bar

Details are in Kits [../../../kits/README.txt].

HEADER MENUS AND DRAWER
=======================

  Keys                                         | Action
  ---------------------------------------------+--------------------------------
  `Enter` / `Space` on Company, Tools or Learn | Open or close the menu
  `Down` / `Up` on a menu button               | Open at the first or last entry
  `Down` / `Up` / `Home` / `End` in a menu     | Move between entries
  `Esc`                                        | Close the menu, then the drawer
  First `Tab` on a page                        | Show Skip to main content

SPOTLIGHT
=========

  Keys                           | Action
  -------------------------------+-----------------------
  `Up` / `Down`                  | Move through results
  `Enter`                        | Open or run
  `Ctrl` + `Enter` (Ctrl or Cmd) | Open in a new tab
  `Tab` / `Shift` + `Tab`        | Next or previous scope
  `>` first                      | Command mode
  `Esc`                          | Clear, then close

SETTINGS PANEL
==============

  Keys                                 | Action
  -------------------------------------+---------------------------------------------------------
  `Left` / `Right` on the section list | Previous or next section
  `Esc`                                | Close a drop-down, then the confirmation, then the panel

RIGHT-CLICK MENU
================

  Keys              | Action
  ------------------+------------------------------------------
  Type              | Filter actions
  `Up` / `Down`     | Move
  `Right`           | Open a submenu, or reach a row's pin star
  `Left`            | Leave the pin star, or close a submenu
  `Enter` / `Space` | Run
  `Esc`             | Close submenu, clear filter, close menu

GUIDE AND TOURS
===============

  Keys                           | Action
  -------------------------------+-----------------------------------
  `Up` / `Down` / `Home` / `End` | Move through the guide
  `Enter`                        | Open the focused item or top match
  `Left` / `Right` on a tab      | Change tab
  `Right` / `Left` in a tour     | Next or previous stop
  `Esc`                          | Close the guide or leave the tour

SPLIT VIEW
==========

  Keys:   `Alt` + `1` / `Alt` + `2`
  Action: Focus the live or companion pane

  Keys:   `Alt` + `V`
  Action: Side by side or stacked

  Keys:   `Alt` + `S`
  Action: Swap panes

  Keys:   `Alt` + `E`
  Action: Equal split

  Keys:   `Enter` / `Ctrl` + `Enter` in an address bar
  Action: Load, or open in a new tab

  Keys:   `Esc`
  Action: Close a menu, restore an address, or close split view

SCREEN RECORDER
===============

  Keys                          | Action
  ------------------------------+------------------------------------------------
  Arrow keys on the dialog grip | Move the dialog (`Shift` for finer steps)
  `Esc`                         | Close the dialog, list, player or region picker

OTHER PLACES
============

  Where:  Any tooltip
  Keys:   `Alt`
  Action: Expand its details (when Advanced tooltips is off)

  Where:  Feedback panel
  Keys:   `1` to `5`
  Action: Set the star rating

  Where:  First-visit welcome
  Keys:   `Esc`, `Enter`, `Space`
  Action: Skip it

  Where:  Site date picker
  Keys:   Arrows, `Page Up` / `Page Down`, `Shift` + those, `Home` / `End`,
          `Enter` / `Space`, `Esc`
  Action: Day and week, month, year, week edges, choose, close

  Where:  Navigation dock
  Keys:   `Tab` into it
  Action: Opens the collapsed dock
