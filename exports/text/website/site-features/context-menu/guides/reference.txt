RIGHT-CLICK MENU REFERENCE
==============================================================================
Every part, action, shortcut, preference and message of the site's right-click
menu.
Area: Website › Site features › Right-click menu   Updated: 2026-09-25

WAYS TO OPEN
============

  Method: Right-click (not in a text field)
  Opens:  The menu for what is under the pointer

  Method: `Shift` + right-click
  Opens:  The browser's menu (or the site menu, if you made the browser's menu
          the default)

  Method: Rest the pointer on the gold line at the right edge
  Opens:  The menu for the page, beside the line

  Method: Menu key or `Shift` + `F10`
  Opens:  The same as a right-click

HEADER
======

  What you clicked:     Page
  Kind and detail line: Page · page address
  Label:                Page title

  What you clicked:     Link
  Kind and detail line: Link · This site or Another site
  Label:                Link address

  What you clicked:     Image
  Kind and detail line: Image · width × height · file type
  Label:                File name

  What you clicked:     Selection
  Kind and detail line: Selection · word count · character count
  Label:                The quoted text, shortened to about 70 characters

  What you clicked:     Colour
  Kind and detail line: Colour · `rgb(r g b)` (with a colour swatch icon)
  Label:                Hex code

SECTIONS OF THE LIST
====================

  Section:    Context actions
  Shown when: Always
  Contents:   This page, Link, Image, Selection or Colour actions

  Section:    More
  Shown when: Focused layout
  Contents:   One row per group: Page (not for a page), Colour tools, View,
              Site

  Section:    Group headings
  Shown when: Everything layout
  Contents:   Every group listed in full under its heading

  Section:    Browser
  Shown when: Always
  Contents:   Browser’s own menu

  Section:    Website update banner
  Shown when: An update is available, running or failed
  Contents:   Update available, Updating website or Retry update

The shortcut column shows what the menu displays on each row. The navigation
shortcuts, `Ctrl` + `P`, `F5`, `F11`, `Ctrl` + `C` and the click combinations
are your browser's own; the menu shows them as reminders.

PREFERENCES (GEAR)
==================

  Setting                  | Options                       | Default
  -------------------------+-------------------------------+--------------------------------------
  Quick bar                | Pinned chips with X; Reset    | Back, Forward, Reload, Home, Copy URL
  Layout                   | Focused, Everything           | Focused
  Row height               | Standard, Compact             | Standard
  Right-click on this site | This menu, The browser’s menu | This menu

Quick bar maximum: 6 actions.

FOOTER HINTS
============

`↑↓` move · `↵` run · `→` submenu · star pin. After an action, the hints are
replaced for about two seconds by a confirmation with a tick.

MESSAGES
========

  Message                                                    | When
  -----------------------------------------------------------+------------------------------------
  Copied                                                     | A selection was copied
  Copied as plain text                                       | Copy as plain text
  Page URL copied / Page title copied / Markdown link copied | The Page copy actions
  Link copied                                                | Share fell back to copying
  Link address copied / Link text copied                     | The Link copy actions
  Image copied                                               | Copy image succeeded
  Image address copied (the image itself can’t be copied)    | Copy image fell back to the address
  Image address copied / Alt text copied / Palette copied    | The other Image copy actions
  `#HEX` copied / RGB copied / HSL copied / OKLCH copied     | The Colour copy actions
  Could not copy                                             | The clipboard refused the copy
  Reading mode on / Reading mode off                         | Reading mode from the menu
  Reading aloud is not available                             | Speech failed
  Checking for updates…                                      | Update website started
  Update failed. Try again.                                  | The update could not run
  Right-click again for the browser’s menu                   | Browser’s own menu was chosen
  Pinned to the quick bar / Unpinned from the quick bar      | A star was toggled
  The quick bar holds 6: unpin one first                     | A seventh pin was attempted
  Quick bar reset                                            | Reset in preferences
  Saved                                                      | A preference changed
  Right-click now opens the browser’s menu                   | The browser’s menu was chosen
  No actions match "…"                                       | The filter found nothing
