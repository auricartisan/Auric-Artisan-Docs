==============================================================================
COLLECTIONS SHORTCUTS
==============================================================================
Keyboard and mouse actions on the Collections page.
Area: Website › Library › Collections   Updated: 2026-09-25

MOUSE
=====

  Action                      | Result
  ----------------------------+-------------------------------------------------------
  Select a card               | Opens the tool and counts one open towards Most used.
  Select a card's pin button  | Pins or unpins the tool.
  Right-click a card          | Opens the card menu.
  Right-click elsewhere       | Opens the site's usual right-click menu.
  Hover a card                | Shows a tooltip with category, mode, address and tags.
  Hover the Start here slider | Pauses autoplay.

KEYBOARD
========

  Keys:   `Tab`
  Where:  Anywhere
  Result: Moves between links, buttons and filter boxes.

  Keys:   `Left` / `Right`
  Where:  Start here slider, when focused
  Result: Previous or next featured tool.

  Keys:   Context-menu key, or `Shift` + `F10`
  Where:  A focused card
  Result: Opens the card menu.

  Keys:   `Escape`
  Where:  Card menu
  Result: Closes the menu.

  Keys:   `Escape`
  Where:  Floating search panel
  Result: Closes the panel and returns focus to its button.

  Keys:   `Space`
  Where:  A focused tick box
  Result: Ticks or unticks a category or topic.

The site-wide shortcuts, such as `Alt` + `R` for reading mode and `Alt` + `T`
to switch theme, also work here. See Site features
[../../../site-features/README.txt].
