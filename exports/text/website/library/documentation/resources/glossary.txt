==============================================================================
DOCUMENTATION GLOSSARY
==============================================================================
Terms used in the documentation library.
Area: Website › Library › Documentation   Updated: 2026-09-25

  Term:    Subject
  Meaning: A tool or topic in the documentation index, such as "Gamut Map".

  Term:    User guide
  Meaning: A document that explains how to use a tool.

  Term:    Developer reference
  Meaning: A document that explains how a tool works and what it computes.

  Term:    Pair
  Meaning: A subject's user guide and developer reference together.

  Term:    Audience
  Meaning: Which kind of document the index shows: Both, Guides or References.

  Term:    API guide
  Meaning: A guide to getting a tool's results from your own code through the
           site's REST API.

  Term:    Endpoint reference
  Meaning: The list of the REST API's endpoints and their parameters.

  Term:    RSS
  Meaning: A feed format for following new documents in a news reader.
