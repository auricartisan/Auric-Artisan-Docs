==============================================================================
GETTING STARTED
==============================================================================
Use the documentation index to find a tool's user guide or developer
reference.
Area: Website › Library › Documentation   Updated: 2026-09-25

OPEN THE INDEX
==============

Go to https://auricartisan.com/library/documentation/, or open the site
header's Learn menu and choose Documentation.

THE PAGE
========

  - The kicker Documentation and the heading Every tool, twice, with the line
    "35 of 54 subjects carry both a user guide and a developer reference. Pick
    the subject, then pick which of the two you are."
  - A search box, Search 54 subjects….
  - An audience switch: Both, Guides, References.
  - A count, for example 54 subjects · 89 documents.
  - The list of subjects, alphabetical. Each row has the subject's name (a
    link to its first document), a one-line description, and one or two
    buttons: Guide and Reference.

FIND A GUIDE
============

  1. Type part of the tool's name or a word from its description into the
     search box, for example `gamut`.
  2. The list narrows as you type, and the count updates, for example 3
     subjects · 6 documents.
  3. Select Guide for the user guide, or Reference for the developer
     reference.

If nothing matches, the page says No subject matches that. Try a tool name.

SHOW ONLY GUIDES OR ONLY REFERENCES
===================================

Select Guides to hide every Reference button, or References to hide every
Guide button. Subjects that have only the other kind disappear, and the count
changes to match. Select Both to show everything again.

You can link straight to a filtered view: add `?audience=guide` or
`?audience=reference` to the address, for example
https://auricartisan.com/library/documentation/?audience=reference.

WHICH SHOULD I READ?
====================

  - User guide — how to use a tool: what each control does, workflows, exports
    and good practice.
  - Developer reference — how the tool works: the formulas, data and methods
    behind it. Useful when you need to know exactly what a number means.
  - API guides (the subjects whose names end in "API") — how to get the same
    results from your own code.

RESULT
======

You are on the right document for the tool and for the kind of help you need.
See Read a guide [read-a-guide.txt] for finding your way around it.
