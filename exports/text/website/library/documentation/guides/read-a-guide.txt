==============================================================================
READ A GUIDE
==============================================================================
Find your way around a documentation article: the subject list, breadcrumb,
pair switch, contents, code blocks and pager.
Area: Website › Library › Documentation   Updated: 2026-09-25

Documentation articles share a three-column layout on wide screens: every
subject on the left, the article in the middle, and its contents on the right.
On narrow screens the columns stack.

THE PARTS OF THE PAGE
=====================

  Part:         Subject list (left)
  What it does: Headed Documentation. Every subject, alphabetically; the
                current one is highlighted and scrolled into view. Select a
                subject to open its first document.

  Part:         Breadcrumb
  What it does: Documentation › the subject's name. Select Documentation to
                return to the index.

  Part:         Pair switch
  What it does: User guide and Developer reference. The current document is
                highlighted; select the other to switch. If a subject has only
                one document, the missing half is shown greyed out, with the
                tooltip "No user guide for this subject yet" or "No developer
                reference for this subject yet".

  Part:         Title and introduction
  What it does: The subject's name and a short introduction.

  Part:         Author and dates
  What it does: Who wrote the document and when it was published or updated,
                where the article states them.

  Part:         On this page (right)
  What it does: The article's numbered sections. Select one to jump to it. On
                narrow screens it is a collapsible list.

  Part:         Sections
  What it does: The article itself.

  Part:         Code blocks
  What it does: Each has a Copy button. After copying it reads Copied; if your
                browser blocks the clipboard it reads Press Ctrl C so you can
                copy by hand.

  Part:         Tables
  What it does: Wide tables scroll sideways rather than stretching the page.

  Part:         Pager (end)
  What it does: The pair — a link to the other document for this subject — and
                Next subject, the next subject alphabetically.

TIPS
====

  - Read the user guide first, then the developer reference when you need to
    know exactly what a figure means.
  - Guides were written for the tool as it was on their stated date. If a
    guide and the tool disagree, trust the tool, and check this documentation
    set for the current behaviour.
  - The API guides include ready-made requests; the full endpoint list is at
    https://auricartisan.com/library/documentation/api/.

RESULT
======

You can move from any guide to its reference, to the next subject, or back to
the index without losing your place.
