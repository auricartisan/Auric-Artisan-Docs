==============================================================================
TROUBLESHOOTING
==============================================================================
Symptoms, causes and fixes when using the documentation library.
Area: Website › Library › Documentation   Updated: 2026-09-25

A SUBJECT DISAPPEARED WHEN I CHOSE GUIDES OR REFERENCES
=======================================================

Why: The subject has only the other kind of document. Hiding it avoids showing
a row with nothing to open.

What to do: Select Both.

"NO SUBJECT MATCHES THAT. TRY A TOOL NAME."
===========================================

Why: No subject name or description contains your text.

What to do: Use a shorter word, or the tool's name as it appears in the site's
menus. Descriptions use US spelling ("color").

THE GUIDE DOES NOT MATCH WHAT I SEE IN THE TOOL
===============================================

Why: Guides are dated. Some tools have been redesigned since their guide was
written — for example the Accessibility Library and the Palette Library.

What to do: Trust the tool. Check the date on the guide, and see this
documentation set for current behaviour.

THE SIDE LIST OR THE PAIR SWITCH IS MISSING
===========================================

Why: The article could not load the list of subjects, for example because the
connection dropped. The article itself is still complete.

What to do: Reload the page. Use the breadcrumb or your browser's back button
to reach the index.

"PRESS CTRL C" APPEARS INSTEAD OF "COPIED"
==========================================

Why: Your browser blocked clipboard access.

What to do: The code is selected for you; press `Ctrl` + `C` (on a Mac, the
equivalent copy command).
