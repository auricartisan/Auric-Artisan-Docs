==============================================================================
ACCESSIBILITY LIBRARY GLOSSARY
==============================================================================
Definitions of the terms used in the Accessibility Library.
Area: Website › Library › Colour libraries › Accessibility Library   Updated: 2026-09-25

  Term:    AA, AAA
  Meaning: WCAG conformance levels. For normal text, AA needs 4.5:1 and AAA
           needs 7:1.

  Term:    APCA (Lc)
  Meaning: Advanced Perceptual Contrast Algorithm; its lightness contrast
           value Lc runs from about −108 to 106. Larger absolute values are
           more readable.

  Term:    Auric SD
  Meaning: Auric Artisan's combined 0–100 score for a pair (WCAG, APCA, vision
           separation, lightness gap, hue gap), graded S, A, B, C, D or F.

  Term:    Caret
  Meaning: The marker on the map showing the current foreground.

  Term:    Contrast ratio
  Meaning: The WCAG 2 measure of the luminance difference between two colours,
           from 1:1 to 21:1.

  Term:    Corpus
  Meaning: The five million scored pairs behind the index.

  Term:    Foreground
  Meaning: The text or icon colour.

  Term:    Gamut
  Meaning: The range of colours a colour space or screen can show. The map
           shows the sRGB gamut.

  Term:    Ground
  Meaning: The background colour you are testing against.

  Term:    Large text
  Meaning: At least 18 point (24 CSS pixels), or 14 point (about 18.7 CSS
           pixels) bold.

  Term:    OKLCH
  Meaning: A perceptual colour space: lightness (0 to 1), chroma and hue.

  Term:    Pick
  Meaning: One of up to twelve suggested passing foregrounds.

  Term:    Record id
  Meaning: `acc_` followed by a record's number in base 36.

  Term:    Seed
  Meaning: The fixed number (9001) from which every record is derived.

  Term:    Target
  Meaning: The contrast threshold you are testing: 3:1, 4.5:1 or 7:1.

  Term:    Territory
  Meaning: The share of the map that clears the target on the current ground.

  Term:    Vision margin
  Meaning: Worst-case separation of the two colours under ten simulated vision
           conditions, 0 to 1.

  Term:    WCAG
  Meaning: Web Content Accessibility Guidelines.
