==============================================================================
COLOR LIBRARY GLOSSARY
==============================================================================
Definitions of the colour terms used in the Color Library.
Area: Website › Library › Colour libraries › Color Library   Updated: 2026-09-25

  Term:    AA, AAA
  Meaning: WCAG contrast levels. For normal-size text, AA needs a contrast
           ratio of at least 4.5:1 and AAA at least 7:1.

  Term:    Atlas
  Meaning: The fixed set of 8,192 colours the Color Library holds.

  Term:    Atlas id
  Meaning: A colour's number in the atlas, from 0 to 8,191.

  Term:    Chroma
  Meaning: How colourful a colour is, compared with a grey of the same
           lightness. The page uses OKLCH chroma, which runs from 0 (grey) to
           about 0.4 for the most vivid screen colours.

  Term:    CIE L*a*b* (Lab)
  Meaning: A colour space designed so that equal distances look roughly like
           equal differences. L is lightness (0 to 100); a runs from green to
           red; b from blue to yellow.

  Term:    CIE76
  Meaning: The simplest ΔE formula: the straight-line distance between two
           colours in Lab.

  Term:    CMYK
  Meaning: Cyan, magenta, yellow and black: the four inks of process printing.
           The values are a simple conversion, not a print profile.

  Term:    Colour vision deficiency (CVD)
  Meaning: Reduced ability to tell some colours apart, often called colour
           blindness.

  Term:    Contrast ratio
  Meaning: The WCAG 2 measure of how much two colours differ in brightness,
           from 1:1 (none) to 21:1 (black on white).

  Term:    Deuteranopia
  Meaning: A form of colour blindness with no working green-sensitive cones
           ("green-blind").

  Term:    ΔE (delta E)
  Meaning: A number for how different two colours look. Under about 2.3 is
           usually invisible.

  Term:    Hue
  Meaning: The kind of colour — red, yellow, blue and so on — given as an
           angle from 0° to 360°.

  Term:    HSL
  Meaning: Hue, saturation and lightness: a simple rearrangement of RGB used
           in CSS.

  Term:    Lightness
  Meaning: How light or dark a colour looks. The page uses CIE L* (0 to 100)
           for the Lightness filter and OKLCH L (0 to 1) for sorting.

  Term:    OKLab, OKLCH
  Meaning: A modern perceptual colour space (2020). OKLCH expresses OKLab as
           lightness, chroma and hue, and is supported in CSS as `oklch()`.

  Term:    Protanopia
  Meaning: A form of colour blindness with no working red-sensitive cones
           ("red-blind").

  Term:    Relative luminance
  Meaning: How much light a colour gives off, from 0 (black) to 1 (white),
           weighted for human vision. Contrast ratios are built from it.

  Term:    Requirement chip
  Meaning: One of the seven buttons under Or from what it has to do, such as
           Readable on white.

  Term:    sRGB
  Meaning: The standard colour space of the web and most screens. Every atlas
           colour is inside it.

  Term:    Tritanopia
  Meaning: A rare form of colour blindness with no working blue-sensitive
           cones ("blue-blind").

  Term:    WCAG
  Meaning: The Web Content Accessibility Guidelines, the international
           standard for accessible web content.
