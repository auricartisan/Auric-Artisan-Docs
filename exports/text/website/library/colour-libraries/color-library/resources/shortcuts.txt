==============================================================================
COLOR LIBRARY SHORTCUTS
==============================================================================
Keyboard and pointer actions in the Color Library.
Area: Website › Library › Colour libraries › Color Library   Updated: 2026-09-25

KEYBOARD
========

  Keys:   `/`
  Where:  Anywhere, when you are not typing in a field
  Result: Moves the cursor to Search by hex (#a6e223) or id….

  Keys:   `Enter` or `Space`
  Where:  A focused tile in the grid
  Result: Opens the colour on The colour tab.

  Keys:   `Tab`
  Where:  Anywhere
  Result: Moves between controls, chips and tiles.

POINTER
=======

  Action: Select a tile
  Result: Opens the colour.

  Action: Select a tile's star
  Result: Saves or unsaves the colour without opening it.

  Action: Select a neighbour under Start from a colour you already have
  Result: Opens that colour.

  Action: Select a card heading on Stats
  Result: Folds or unfolds the card.

  Action: Pause typing in the colour field
  Result: Updates the nearest matches without pressing Find its neighbours.

The site-wide shortcuts also work on this page. See Site features
