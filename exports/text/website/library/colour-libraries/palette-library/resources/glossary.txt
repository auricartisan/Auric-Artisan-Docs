==============================================================================
PALETTE LIBRARY GLOSSARY
==============================================================================
Definitions of the terms used in the Palette Library.
Area: Website › Library › Colour libraries › Palette Library   Updated: 2026-09-25

  Term:    ASE
  Meaning: Adobe Swatch Exchange, a swatch file format read by Adobe apps and
           other design tools.

  Term:    Base 36
  Meaning: Writing numbers with the digits 0–9 and the letters a–z. Palette
           ids use it: `pal_a` is palette 10.

  Term:    Chroma
  Meaning: How colourful a colour is compared with a grey of the same
           lightness. The page uses OKLCH chroma.

  Term:    Contrast ratio
  Meaning: The WCAG 2 measure of the lightness difference between two colours,
           from 1:1 to 21:1. 4.5:1 is the AA level for body text; 7:1 is AAA.

  Term:    Derived
  Meaning: Worked out on the spot from the palette's number rather than read
           from storage.

  Term:    Design tokens
  Meaning: Named colour values in a format a design system or platform reads,
           such as CSS variables, a Tailwind config or an Android
           `colors.xml`.

  Term:    Dominant hue
  Meaning: A palette's overall hue: the average of its five hues, weighted
           towards the more colourful colours.

  Term:    Entropy
  Meaning: On Inspect: how many 36° hue bands the five colours fall in,
           divided by 5. 1.00 means five different hue families.

  Term:    Hue span
  Meaning: The widest angle between any two of a palette's five hues, from 0°
           to 180°.

  Term:    Method
  Meaning: The generation-method label a palette carries, such as `triadic`.

  Term:    Mutually legible
  Meaning: A set of colours that all reach a contrast threshold against each
           other, so any one can be text on any other.

  Term:    OKLCH
  Meaning: A modern perceptual colour space: lightness (0 to 1), chroma and
           hue angle.

  Term:    Palette id
  Meaning: `pal_` followed by the palette's number in base 36, for example
           `pal_abc`.

  Term:    Sample
  Meaning: The set of palettes the analysis tabs and the bulk export use: up
           to 2,000 palettes.

  Term:    Scan
  Meaning: Looking through the collection from the start, in chunks, to find
           palettes that match a filter.

  Term:    Seed
  Meaning: The fixed starting number from which every palette is worked out.
           It is why palettes never change.

  Term:    WCAG
  Meaning: Web Content Accessibility Guidelines, the international standard
           for accessible web content.
