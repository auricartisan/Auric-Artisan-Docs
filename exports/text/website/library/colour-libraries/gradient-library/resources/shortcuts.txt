==============================================================================
GRADIENT LIBRARY SHORTCUTS
==============================================================================
Keyboard and pointer actions in the Gradient Library.
Area: Website › Library › Colour libraries › Gradient Library   Updated: 2026-09-25

KEYBOARD
========

  Keys:   `/`
  Where:  Anywhere, when not typing
  Result: Focuses Search by name, hex or scheme….

  Keys:   `Tab`
  Where:  Grid
  Result: Moves between cards and their buttons.

  Keys:   `Enter` or `Space`
  Where:  A focused card
  Result: Opens it on Inspect.

  Keys:   `Escape`
  Where:  Share link or design tokens dialog
  Result: Closes it.

POINTER
=======

  Action: Select a card
  Result: Opens it on Inspect.

  Action: Select CSS on a card
  Result: Copies its CSS.

  Action: Select a stop's hex on Inspect
  Result: Copies the hex.

  Action: Select a value on Tags
  Result: Filters the Library by it (except Banding).

  Action: Select a card heading on Vision, Accessibility, Pair, Tags, Stats or
          Export
  Result: Folds or unfolds the card.

The site-wide shortcuts also work here. See Site features
[../../../../site-features/README.txt].
