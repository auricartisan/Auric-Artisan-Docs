==============================================================================
COLOUR LIBRARIES
==============================================================================
An overview of the six Auric Artisan colour libraries and a map of their
documentation.
Area: Website › Library › Colour libraries   Updated: 2026-09-25

Auric Artisan has six colour libraries. Each is a large, searchable collection
of generated colour data that you can browse, filter, inspect and copy or
export. They share one idea: every item carries its measurements with it, so
you can choose colours by what they do — how they contrast, how they step, how
they read to people with colour vision deficiencies — and not only by how they
look in a thumbnail.

The libraries are free to use and need no account. They open in any modern
browser.

THE SIX LIBRARIES
=================

  Library:       Color Library [color-library/README.txt]
  What it holds: 8,192 measured colours, each in seven colour spaces with
                 contrast and colour-blindness data.
  Address:       https://auricartisan.com/library/color/

  Library:       Palette Library [palette-library/README.txt]
  What it holds: 5,000,000 generated palettes, filterable by hue, lightness,
                 chroma, harmony method and WCAG.
  Address:       https://auricartisan.com/library/palette/

  Library:       Gradient Library [gradient-library/README.txt]
  What it holds: 8,192 gradients with OKLCH metadata, 2 to 46 stops, and a
                 measured verdict on banding.
  Address:       https://auricartisan.com/library/gradient/

  Library:       Harmony Library [harmony-library/README.txt]
  What it holds: 8,192 colour harmonies across 23 colour-theory schemes, plus
                 a tool that names the scheme your own colours form.
  Address:       https://auricartisan.com/library/harmony/

  Library:       Shade Library [shade-library/README.txt]
  What it holds: 8,192 OKLCH shade scales with tint and shade tokens and
                 contrast checks.
  Address:       https://auricartisan.com/library/shades/

  Library:       Accessibility Library [accessibility-library/README.txt]
  What it holds: 5,000,000 foreground and background pairs scored against
                 WCAG, APCA and colour vision deficiency.
  Address:       https://auricartisan.com/library/accessibility/

WHICH LIBRARY DO I NEED?
========================

  - One colour, with its numbers: the Color Library.
  - A set of colours that work together: the Palette Library, or the Harmony
    Library if you want a named colour-theory scheme.
  - A smooth blend between colours: the Gradient Library.
  - One colour taken from light to dark for a design system: the Shade
    Library.
  - Text and background colours that pass contrast rules: the Accessibility
    Library.
