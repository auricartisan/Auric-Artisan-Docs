==============================================================================
LIBRARY KIT
==============================================================================
The Universal Library as a floating panel: browse, search, restore, organise,
compare, share, export and sync everything you save from the site's tools.
Area: Website › Kits › Library Kit   Updated: 2026-09-25

The Library Kit is where everything you save from Auric Artisan's tools lives.
When you select Save to Library in a tool, the palette, gradient, type scale,
preset, plate, report or image lands in your library, and the Library Kit
shows it as a tile you can find, reopen and reuse from any page.

The kit is a floating panel, so you can open it without leaving what you are
doing. Select a tile to restore that item into the tool that made it, or open
it in another tool that can use it. Organise items with favourites,
collections and the archive; compare two versions side by side with
colour-difference figures; share an item as a link; export it, or the whole
library, as files; and generate reports in seven formats.

Your library is stored in your browser on this device. It is not uploaded to
your account. You can export it as a single file, import it elsewhere, and
optionally push it to web addresses you control.

WHO IT IS FOR
=============

  - Anyone who saves work from the site's tools and wants to find it again.
  - Designers who iterate on palettes and gradients and want to compare
    versions.
  - Teams that want to share a palette or gradient as a link, or back up and
    move a library between browsers.
  - Developers who want their library pushed to their own systems as JSON,
    NDJSON, CSV or reports.

WHERE TO FIND IT
================

  - On any page of https://auricartisan.com, select Page utilities in the
    bottom-left corner, then Library.
  - Select the Library button in the site header.
  - Press `Ctrl` + `Shift` + `L` (`Cmd` + `Shift` + `L` on a Mac).
  - Add `#library` to any page address, or `#library=favorites`,
    `#library=recent`, `#library=projects`, `#library=collections`,
    `#library=archive`, `#library=compare` or `#library=settings` to open a
    particular tab.
  - Visit https://auricartisan.com/library/workspace/, which opens the panel.

QUICK START
===========

  1. Open a tool, for example Basic Color Tools, make a palette and select
     Save to Library. Give it a name and select Save to Library in the dialog.
  2. Press `Ctrl` + `Shift` + `L`. The Library Kit opens on the All tab with
     your palette as a tile.
  3. Type part of its name in Search your library… to find it.
  4. Right-click the tile to see everything you can do with it.
  5. Select Favourite from that menu. A star appears on the tile and it joins
     the Favorites tab.
  6. Select the tile. The palette opens again in the tool that made it.
  7. Back in the Library Kit, select Export in the footer to download a backup
     of your whole library.

WHAT YOU CAN DO
===============

  - Browse by tab: All, Recent, Favorites, Projects, Collections, Archive, and
    one tab per type of item you have saved.
  - Search, sort, group by project or type, switch between grid and list, and
    change density.
  - Restore an item into its tool, or open it in another tool that accepts it.
  - Rename, describe, tag, favourite, duplicate, collect, archive and delete
    items, one at a time or in bulk.
  - Compare two items: palettes with ΔE2000 colour differences and contrast,
    images side by side, with a wipe or a difference heatmap, settings field
    by field, audits by score.
  - Share an item as a self-contained link.
  - Download an item as JSON, NDJSON, CSV, XML, HTML, Markdown, text, PNG or
    SVG.
  - Export and import the whole library as a JSON file, including by drag and
    drop.
  - Generate library reports in seven formats.
  - Push your library automatically to web addresses you configure.
  - Run any action from a command palette (type `>`) or a right-click menu.
