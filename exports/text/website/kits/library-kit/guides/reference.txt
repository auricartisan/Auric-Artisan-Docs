==============================================================================
LIBRARY KIT REFERENCE
==============================================================================
Every control, tab, option, dialog and message in the Library Kit.
Area: Website › Kits › Library Kit   Updated: 2026-09-25

WAYS TO OPEN THE KIT
====================

  Entry point:  Library launcher
  What it does: Opens or closes the kit. Shows a badge with the item count (up
                to 99+) once the kit has loaded

  Entry point:  Library button in the site header
  What it does: Opens the kit

  Entry point:  `Ctrl` + `Shift` + `L` (`Cmd` + `Shift` + `L` on a Mac)
  What it does: Opens or closes the kit

  Entry point:  `#library` at the end of a page address
  What it does: Opens the kit on that page

  Entry point:  `#library=all`, `recent`, `favorites` (or `favourites`),
                `projects`, `collections`, `archive`, `compare`, `settings`
  What it does: Opens the kit on that tab

  Entry point:  https://auricartisan.com/library/workspace/
  What it does: Opens the kit; links to this page elsewhere on the site open
                the kit in place

TITLE BAR
=========

  Control:      Six-dot grip
  What it does: Drag, or focus it and use arrow keys (12 px; `Shift` for 1
                px), to move the panel ("Move library panel")
  Default:      Bottom-left corner

  Control:      Your Library
  What it does: Title; the title bar is also a drag handle
  Default:      —

  Control:      Item count
  What it does: N items (not counting archived items). Hidden on narrow phone
                screens
  Default:      —

  Control:      Panel options
  What it does: Opens Keep open, Theme, Panel size, Minimize, Reset position
  Default:      —

  Control:      Close
  What it does: Closes the kit ("Close Library Kit.")
  Default:      —

Panel size: normal 680 px wide, expanded up to 940 px wide.

TABS
====

All, Recent (last 7 days), Favorites, Projects, Collections, Archive, Compare,
Settings, and one tab per saved item type. Counts show on all but Compare and
Settings. Default: All; the last tab is remembered.

SEARCH AND TOOLBAR
==================

  Control:      Search your library…
  What it does: Filters items by name, description, tool, type and tags; `>`
                switches to commands
  Values:       Text
  Default:      Empty

  Control:      Clear (cross)
  What it does: Clears the search
  Values:       —
  Default:      —

  Control:      Item count
  What it does: N items in [tab]
  Values:       —
  Default:      —

  Control:      Sort
  What it does: Order of items
  Values:       Newest, Oldest, Name A–Z, Name Z–A, Type
  Default:      Newest

  Control:      Group
  What it does: Cycles grouping
  Values:       By project, by type, none
  Default:      By project

  Control:      View
  What it does: Grid or list
  Values:       Grid, list
  Default:      Grid

  Control:      Select
  What it does: Multi-select on or off
  Values:       —
  Default:      Off

  Control:      Filter chips
  What it does: Collection:, Tool:, Tag: and Clear all
  Values:       —
  Default:      None

TILES
=====

  Part:    Preview
  Meaning: Image, gradient, up to 8 swatches, a text sample, or a coloured
           plate with initials

  Part:    Star
  Meaning: A favourite

  Part:    Tick box
  Meaning: Shown in multi-select

  Part:    Name
  Meaning: The item's name, or Untitled

  Part:    Meta line
  Meaning: Type, tool and age

  Part:    Hover actions (grid)
  Meaning: Favourite or Remove favourite, Open details, Share, Delete

  Part:    Hover actions (list)
  Meaning: The same plus Duplicate and Export JSON

Select a tile to restore it; in multi-select, to select it. A tile's tooltip
reads its name followed by "right-click for actions".

COLLECTIONS TAB
===============

  Tile                                        | What it does
  --------------------------------------------+-------------------------------
  New collection ("Group saved items")        | Creates a collection
  A collection (name, Collection, item count) | Shows its items on the All tab

With no collections: No collections yet — "Collections group saved items into
folders. Create one above, or from any item's right-click menu."

BULK BAR (MULTI-SELECT)
=======================

Pick items to act on them or N selected, then All, Favorite, Collect, Archive,
Export, Delete.

FOOTER
======

  Control        | What it does
  ---------------+-------------------------------------------------------------------
  New project    | Creates an empty project item
  Import         | Merges a library `.json` file
  Export         | Downloads `auric-library-backup.json`
  Storage figure | Space the library uses; tooltip gives the number of stored entries
  Settings       | Opens the Settings tab
  Keys           | Shows the keyboard shortcuts sheet

DIALOGS
=======

  Dialog:             Rename item
  Fields and buttons: Name; Cancel, Rename

  Dialog:             New collection
  Fields and buttons: Collection name (starts Untitled collection); Cancel,
                      Create

  Dialog:             New project
  Fields and buttons: Project name (starts Untitled project); Cancel, Create

  Dialog:             Add to collection (or Add N items to collection)
  Fields and buttons: New collection…, each collection, No collection

  Dialog:             Delete item? / Delete N items? / Delete N archived
                      items?
  Fields and buttons: Cancel, Delete

  Dialog:             Item details
  Fields and buttons: Name, Description, Collection, Tags (comma-separated),
                      Use in buttons, Saved option values, Download PNG,
                      Download SVG, Other format and Download, Open in tool,
                      Cancel, Save changes

  Dialog:             Share link
  Fields and buttons: Link, Copy, Share via… (where supported), Open in new
                      tab, Close

  Dialog:             Keyboard shortcuts
  Fields and buttons: List of keys; close button

In the text dialogs, `Enter` confirms and `Esc` cancels.

COMPARE TAB
===========

Before and After pickers, Swap sides, per-side summaries and the comparison.
Image comparisons offer Side, Wipe and ΔE heatmap. See Compare items
[compare-items.txt].

SETTINGS TAB
============

Preferences, Reporting, Sync & auto-update, Generate reports, Storage. See
Settings, sync and reports [settings-sync-and-reports.txt] for every option
and default.

MESSAGES
========

  Message: Nothing saved here yet — "Save a palette, gradient, type scale or
           report from any tool and it lands here."
  Meaning: The current tab is empty

  Message: Nothing matched — "Try a different word, or clear the search to see
           everything."
  Meaning: A search found nothing

  Message: Renamed
  Meaning: An item was renamed

  Message: Created "[name]"
  Meaning: A collection was created

  Message: Moved N items to "[name]" / Removed from its collection
  Meaning: Collection changes

  Message: N colours copied, Name copied
  Meaning: Copy actions

  Message: This item has no colours to copy.
  Meaning: The item has no colours

  Message: Could not copy to the clipboard.
  Meaning: The browser blocked copying

  Message: Library snapshot downloaded
  Meaning: Export finished

  Message: Imported [file] / That file could not be imported.
  Meaning: Import result

  Message: Archive emptied
  Meaning: Archive emptied

  Message: Library returned to its default position.
  Meaning: Panel position reset

  Message: That item could not be shared., That project could not be created.
  Meaning: An action failed

  Message: Sync is switched off — turn it on in Library settings., No sync
           destinations configured yet., Synced to N destinations, Synced N of
           M destinations — check settings., Sync could not complete.
  Meaning: Sync results

  Message: Library storage is full. Some image data couldn't be saved.
  Meaning: The browser's storage for the site is full

  Message: Settings could not be loaded., Comparison could not be loaded.
  Meaning: A part of the kit failed to load
