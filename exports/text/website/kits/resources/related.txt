SITE FEATURES NEXT TO THE KITS
==============================

The page utilities bar also launches two site features that are not kits:

  - Navigate opens the page navigation dock (back, forward, reload, outline,
    split view, jump to top or bottom).
  - Settings opens the site settings panel (theme, accent colour, text size,
    motion, ads and more).

Both, along with the site-wide search (`Ctrl` + `K`), the right-click menu and
the eye-rest reminder, are documented in Site features
[../../site-features/README.txt].

TOOLS THAT WORK WITH THE KITS
=============================

  - Every tool with a Save to Library button saves into the Library Kit
    [../library-kit/README.txt].
  - The URL Analyzer
    [../../tools/accessibility-and-vision/analyzer/README.txt], the Vision
    Simulation
    [../../tools/accessibility-and-vision/vision-simulation/README.txt] lab
    and the Colour Science Lab
    [../../tools/colour-workspace/colour-science-lab/README.txt] have mode
    switches that change the same site-wide setting as the Advanced Kit
    [../advanced-kit/README.txt].
  - The Basic Colour Tools
    [../../tools/colour-workspace/basic-colour-tools/README.txt] workspace
    uses floating panels of its own, separate from the kits.
