THE STATUS KIT AS OF 24 SEPTEMBER 2026
======================================

  - A This page card with the current page's status and title.
  - A collapsible System status panel with Network, Hardware, Memory, Display
    and Runtime tabs, refreshing every two seconds, including a live
    frame-rate sparkline.
  - A page scanner with summary cards, status filters, results search,
    category groups and the last eight scans.
  - Shared kit controls: Focus mode, per-kit theme, Resize, Minimize, Close,
    and a labelled Status launcher in the page utilities bar. The page status
    is shown only inside the kit, not as a floating badge on the page.

Changes not recorded in the public history are not listed here.
