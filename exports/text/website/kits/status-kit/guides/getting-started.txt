==============================================================================
GETTING STARTED WITH THE STATUS KIT
==============================================================================
Open the Status Kit and learn its three parts: the This page card, System
status and the page scanner.
Area: Website › Kits › Status Kit   Updated: 2026-09-25

OPEN THE KIT
============

Select Page utilities (bottom-left corner) > Status. The launcher's tooltip
reads "View the current page status and scan page status entries." There is no
keyboard shortcut to open it.

The kit opens with the cursor in the path box, ready for a scan.

THE SCREEN, TOP TO BOTTOM
=========================

  1. Title bar. Status Kit and the buttons Focus mode, Theme, Resize, Minimize
     and Close.
  2. This page. The status badge of the page you are on and a link with the
     page's title. See Check a page's status [check-page-status.txt].
  3. System status. A collapsible panel with an Online or Offline pill and
     five tabs: Network, Hardware, Memory, Display, Runtime. See System status
     [system-status.txt].
  4. Path box and Scan button. The box shows `https://auricartisan.com` as a
     placeholder. See Scan a section [scan-a-section.txt].
  5. Results search. Appears after a scan: Search pages....
  6. Recent scans. Your last scans, once you have run one.
  7. Summary cards and filter chips. Appear after a scan.
  8. Results. Before your first scan this area shows "Scan a path for page
     statuses" with the hint "Enter a URL or path (for example /tool/) and
     press Scan to list every page and its status."

TRY IT
======

  1. Open the Status Kit on the home page.
  2. The This page card shows the home page's title and the badge Beta.
  3. In System status, select Display. You see your screen resolution, window
     size, pixel ratio and colour depth.
  4. Type `/legal/` in the path box and select Scan.
  5. A loader shows Scanning pages and a count such as `3 / 12`. Then the
     results appear, grouped under Trust.

OPENING ANOTHER KIT CLOSES THE STATUS KIT
=========================================

Unlike the other kits, the Status Kit closes whenever another kit opens, even
when its Focus mode is on. Focus mode still makes it open again on the next
page you load.

CLOSE THE KIT
=============

Press `Esc`, select Close, or select the Status launcher again.
