==============================================================================
FEATURE KIT GLOSSARY
==============================================================================
Terms used in the Feature Kit guides, from ans and derivative to UUID and
cron.
Area: Website › Kits › Feature Kit   Updated: 2026-09-25

ans — The result of your last calculation. Type `ans` or select Ans to reuse
it.

Expression — A calculation written as text, such as `2*(3+4)`.

Expression bar — The calculator's text box for full expressions, variables,
functions and calculus.

Variable — A name that holds a value, set with `name = value`, such as `r =
4`.

User-defined function — A function you create with `name(x) = expression`,
such as `f(x) = x^2 + 1`.

Constant — A fixed named value, such as `pi`, `e` or the speed of light `c`.

Radians (RAD) and degrees (DEG) — Two units for angles. A full turn is 2π
radians or 360 degrees.

Remainder (modulo) — What is left after whole division. `10 % 3` is `1`.

Factorial — The product of all whole numbers from 1 to n, written `n!`. `5!`
is `120`.

Gamma function — An extension of the factorial to non-whole numbers.
`gamma(n)` equals `(n-1)!` for whole numbers.

Derivative — The rate of change, or slope, of an expression at a point. `diff`
estimates it.

Second derivative — The rate of change of the slope. `diff2` estimates it.

Integral — The signed area under a curve between two points. `integral`
estimates it.

Root — A value where an expression equals zero. `solve` finds one.

Numerical method — A way of computing an answer by repeated approximation
rather than by exact algebra. The calculator's calculus functions use
numerical methods.

Sample and population standard deviation — Measures of spread. Sample
(`stdev`) divides by one less than the number of values; population (`stdevp`)
divides by the number of values.

Geometric mean — The nth root of the product of n values.

Root mean square (RMS) — The square root of the mean of the squared values.

Greatest common divisor (GCD) — The largest whole number that divides all the
given numbers.

Least common multiple (LCM) — The smallest whole number that all the given
numbers divide.

Prime — A whole number above 1 divisible only by 1 and itself.

Fibonacci number — A number in the sequence 0, 1, 1, 2, 3, 5, 8, where each is
the sum of the two before.

Hexadecimal and binary — Base-16 (digits 0–9 and A–F, written with `0x`) and
base-2 (digits 0 and 1, written with `0b`).

Bitwise operation — An operation that works on each binary digit of a number
separately, such as AND, OR, XOR and NOT.

Metric prefix — A word or letter before a unit that multiplies it by a power
of ten, such as kilo (k, 1,000) or micro (μ, one millionth).

Markdown — A plain-text way to write formatting, such as `**bold**` or `#
Heading`.

ISO 8601 — The international date format `YYYY-MM-DD`, with an optional time
after a `T`.

Unix timestamp (epoch) — The number of seconds, or milliseconds, since 1
January 1970 UTC.

ISO week — A week number from 1 to 53, where weeks start on Monday and week 1
contains the year's first Thursday.

Business day — Monday to Friday. The Feature Kit does not account for public
holidays.

UTC — Coordinated Universal Time, the time standard the world's time zones are
defined against.

JSON — A text format for structured data.

Base64 — A way of writing any data using 64 safe text characters.

Hash — A fixed-length fingerprint of some text. The same text always gives the
same hash.

HMAC — A hash that also depends on a secret key, used to check that data came
from someone who knows the key.

CRC32 — A short checksum for spotting accidental changes. Not for security.

UUID — A 128-bit identifier. Version 4 is random; version 7 starts with a
timestamp so values sort by creation time.

JWT (JSON Web Token) — A signed token in three parts: header, payload and
signature.

Regular expression (regex) — A pattern that describes text to find.

Cron expression — Five fields (minute, hour, day of month, month, day of week)
that describe a repeating schedule.

Slug — A lower-case, hyphen-separated version of text suitable for a web
address.

HTML entity — A code such as `&amp;` that stands for a character with special
meaning in HTML.

Focus mode — The Feature Kit setting that keeps the kit open across pages and
stops it dimming the page.
