==============================================================================
ADVANCED KIT FAQ
==============================================================================
Short answers to common questions about the Advanced Kit and the tool
visibility modes.
Area: Website › Kits › Advanced Kit   Updated: 2026-09-25

DOES BASIC MODE LOCK THE ADVANCED TOOLS?
========================================

No. It only hides them from the menus and collections. Every tool page opens
from its address in every mode.

IS THE ADVANCED KIT A PAID FEATURE?
===================================

No. All modes are available to everyone, signed in or not.

WHICH MODE DO NEW VISITORS GET?
===============================

Basic, which the kit marks as Recommended.

IS MY MODE SAVED TO MY ACCOUNT?
===============================

No. It is stored in your browser. Each browser and device keeps its own mode.

DO MY CUSTOM TICKS SURVIVE IF I SWITCH TO ANOTHER MODE?
=======================================================

Yes. They apply again whenever you select Custom. Reset is the only thing that
clears them.

WHAT DOES EVERYTHING BRING BACK THAT BASIC AND ADVANCED DO NOT?
===============================================================

Every tool, plus collection cards that were hidden earlier, whether you hid
them or the collection hid them because you had not used them yet.

WHY DOES THE CALCULATOR LOSE ITS SCIENTIFIC KEYPAD IN BASIC MODE?
=================================================================

The Feature Kit calculator follows the mode: Basic shows only the Basic
keypad. Choose Everything to see all three. The expression bar still accepts
every function in any mode.

WHAT IS THE "UX KIT"?
=====================

The name the changelog uses for the part of the site that changes page wording
when you switch mode. It has no panel; you control it from the Advanced Kit.
See What each mode changes [what-each-mode-changes.txt].

DOES THE MODE AFFECT THE SITE-WIDE SEARCH?
==========================================

No. The site-wide search shows results for every tool whatever the mode.
