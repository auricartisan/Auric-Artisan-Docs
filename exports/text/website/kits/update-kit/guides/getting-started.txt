==============================================================================
GETTING STARTED WITH THE UPDATE KIT
==============================================================================
Recognise the Update available notice and the Update website command, and
update the site for the first time.
Area: Website › Kits › Update Kit   Updated: 2026-09-25

WHEN THE SITE CHECKS
====================

Each time a page loads, the site waits until the page is ready and then checks
which release is the newest. This takes a moment and does not slow the page.

  - On your first visit, the site simply notes the current release. You see
    nothing.
  - On later visits, if a newer release has come out since you last updated,
    the Update available notice appears.
  - If the check cannot reach the release information, for example offline,
    nothing is shown.

THE NOTICE
==========

The notice appears centred at the top of the page (across the top on a phone).
It shows:

  - Update available and the version, for example Update available v0.9.11;
  - a line such as New update found: 0.9.11;
  - an Update now button;
  - a small x button labelled Hide update notice.

Select Update now to update. Select x to put the notice away; it comes back on
your next page load until you update.

THE COMMAND
===========

You can update at any time, even when no notice is showing:

  - Right-click anywhere on the page (not in a text box) and choose Update
    website. The menu shows the shortcut next to it, Ctrl+⇧+U.
  - Or press `Ctrl` + `Shift` + `U`.

When an update is available, the right-click menu shows the same entry as
Update available with the version and Ready, also at the top of the menu under
Website update.

The right-click menu itself is described in Site features
[../../../site-features/README.txt].

YOUR FIRST UPDATE
=================

  1. Save anything you are working on in the current page.
  2. Press `Ctrl` + `Shift` + `U`.
  3. Messages read Checking for updates… and Updating website..., then Update
     ready. Reloading....
  4. The page reloads.

You are now on the newest release, and the notice will not appear again until
the next one.
