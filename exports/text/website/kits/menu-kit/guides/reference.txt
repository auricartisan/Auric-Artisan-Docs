Every control, tab, section, state and message in the Menu Kit.

LAUNCHER
========

  Control:      Menu launcher (four-square icon)
  What it does: Opens or closes the kit. Announces itself as Open start menu
                or Close start menu
  Default:      Closed

  Control:      `Ctrl` + `M`
  What it does: Same as the launcher
  Default:      —

  Control:      Tooltip
  What it does: "Open site navigation, grouped pages, and quick search."
  Default:      —

TITLE BAR
=========

  Control:      Menu Kit title
  What it does: Drag the title bar to move the kit
  Values:       —
  Default:      Bottom-left corner

  Control:      Status chip
  What it does: The site's release status; tooltip "Auric Artisan is
                [status]."
  Values:       For example Beta
  Default:      Beta at the time of writing

  Control:      Focus mode
  What it does: Keeps the kit open across pages and when other kits open
  Values:       On or off; remembered
  Default:      Off

  Control:      Theme
  What it does: Switches the menu between light and dark ("Switch this menu
                between light and dark mode.")
  Values:       Light or dark; remembered
  Default:      Follows the site

  Control:      Resize
  What it does: Normal (680 px wide) or expanded (up to 820 px wide)
  Values:       Remembered
  Default:      Normal

  Control:      Minimize
  What it does: Collapses the kit to its title bar; select the bar to restore
  Values:       —
  Default:      —

  Control:      Close
  What it does: Closes the kit ("Close Menu Kit.")
  Values:       —
  Default:      —

SEARCH BAR
==========

  Control               | What it does
  ----------------------+-----------------------------------------------------------------
  Search Auric Artisan… | Type to switch to the results list; has focus when the kit opens
  ESC hint              | Shown while the box is empty
  Clear button (cross)  | Shown while the box has text; clears it ("Clear search")
  Result count          | N results while searching

TABS
====

  Tab     | Tooltip
  --------+--------------------
  Tools   | Show Tools pages.
  Design  | Show Design pages.
  Analyze | Show Analyze pages.
  Account | Show Account pages.
  Library | Show Library pages.
  Company | Show Company pages.
  Trust   | Show Trust pages.

The tab row shows text labels; it scrolls sideways when it does not fit. The
last tab used is remembered. Tabs with no visible pages in the current mode
are hidden.

TILES
=====

  Part                 | Meaning
  ---------------------+--------------------------------------------------
  Illustration or icon | The page's artwork
  Name                 | The page's name
  Tooltip              | The page's description
  Small dot            | This is the page you are on; tooltip You are here

RESULTS LIST (WHILE SEARCHING)
==============================

  Part                 | Meaning
  ---------------------+------------------------------------------------
  Icon or illustration | The page or action
  Name                 | Page name or action name
  Second line          | The page's section, or the action's description
  Open ↵               | A page; `Enter` opens it
  Action ↵             | A quick action; `Enter` runs it

Quick actions: Copy current URL, Scroll to top, Go home, Go back, Reload page,
Open a random tool, Toggle menu theme. See Search and quick actions
[search-and-quick-actions.txt].

STATES AND MESSAGES
===================

  Message: Loading menu — "Reframing tools by intent."
  When:    The list of pages is loading

  Message: Menu unavailable — "Failed to load menu data." and Failed to load
           menu.
  When:    The list of pages could not be downloaded

  Message: No matching pages — "Try a different search, or switch to another
           category." with Clear search
  When:    Nothing to show in the current tab

  Message: No matches for "…"
  When:    A search found nothing
