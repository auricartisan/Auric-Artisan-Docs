==============================================================================
IMAGE AND FILE TOOLS
==============================================================================
What the six image and file tools on auricartisan.com are for, where to find
them, and which one to open for each job.
Area: Website › Tools › Image and file tools   Updated: 2026-09-25

These six tools work on files you already have: photographs, SVG artwork,
colour profiles and colour lookup tables. Each one reads your file in the
browser, shows you what is in it, lets you change or measure it, and gives you
a file or a report to take away. Nothing you load is uploaded; the reading and
the arithmetic happen on the page.

The tools share a layout. A row of tabs runs across the top of each tool. The
first tab is the working area, and later tabs explain the method, list where
every number comes from (the Data tab), offer the exports (the Export or
Actions tab) and cite the published sources (the Reference tab). The Image
Picker is the exception: it has three tabs, Workbench, Analysis and Actions.

WHERE TO FIND THEM
==================

The group's own address is https://auricartisan.com/tool/general/tools/.
Opening it takes you to the Collections page at
https://auricartisan.com/collections/, which lists every tool on the site
under All tools. Use the category filter or the Sort menu there, or open a
tool directly from the table below. The Collections page is described in
Collections [../../library/collections/README.txt].

THE TOOLS
=========

  Tool:      Collage Maker [collage-maker/README.txt]
  Address:   https://auricartisan.com/tool/general/tools/collage-maker/
  Use it to: Place pictures on a canvas, arrange them, measure coverage and
             export PNG or JPEG

  Tool:      ICC Profile Parser [icc-profile-parser/README.txt]
  Address:   https://auricartisan.com/tool/general/tools/icc-profile-parser/
  Use it to: Read an .icc or .icm profile: header, tags, primaries, tone
             curves and conformance

  Tool:      Image Picker [image-picker/README.txt]
  Address:   https://auricartisan.com/tool/general/tools/image-picker/
  Use it to: Extract a palette from a picture, pin exact pixels and export the
             colours

  Tool:      LUT Lab [lut-lab/README.txt]
  Address:   https://auricartisan.com/tool/general/tools/lut-lab/
  Use it to: Apply a look or a .cube file, see what it moved, and write a
             .cube

  Tool:      M-Gradient Palette [m-gradient-palette/README.txt]
  Address:   https://auricartisan.com/tool/general/tools/m-gradient-palette/
  Use it to: Build a colour ramp in OKLCH, sRGB, linear RGB or HSL and check
             its steps and contrast

  Tool:      SVG Recolour [svg-recolour/README.txt]
  Address:   https://auricartisan.com/tool/general/tools/svg-recolor/
  Use it to: Remap every colour in an SVG, check contrast and colour vision,
             and export the file

The page titles differ slightly from the names in the Collections list:
Collage Maker opens as Collage Studio, the ICC Profile Parser as ICC Profile
Reading, the Image Picker as Image Color Picker & Palette Tool, the M-Gradient
Palette as Gradient Ramp, and SVG Recolor as SVG Recolour.

WHICH TOOL FOR WHICH JOB
========================

  - You have photographs and want one image made of several: use the Collage
    Maker [collage-maker/README.txt].
  - You have a colour profile from a monitor, printer or camera and want to
    know what it says: use the ICC Profile Parser
    [icc-profile-parser/README.txt].
  - You have a picture and want its colours as a palette: use the Image Picker
    [image-picker/README.txt].
  - You have a .cube grading file, or want to make one: use the LUT Lab
    [lut-lab/README.txt].
  - You want a smooth, evenly stepped colour scale between two colours: use
    the M-Gradient Palette [m-gradient-palette/README.txt].
  - You have an icon or illustration as SVG and want it in different colours:
    use SVG Recolour [svg-recolour/README.txt].

All six tools are free to use, like every tool on the site.

IN THIS FOLDER
==============

  Folder:         collage-maker/ [collage-maker/README.txt]
  What it covers: Canvas shapes, pictures, arrangements, measurements, undo,
                  and PNG, JPEG and session exports

  Folder:         icc-profile-parser/ [icc-profile-parser/README.txt]
  What it covers: Loading profiles, every header field and tag shown,
                  identification, gamut, conformance rules and exports

  Folder:         image-picker/ [image-picker/README.txt]
  What it covers: Palette extraction, the eyedropper and pins, contrast pairs,
                  harmony, charts, exports and batch analysis

  Folder:         lut-lab/ [lut-lab/README.txt]
  What it covers: LUT concepts, the looks, loading and writing .cube files,
                  the before and after readouts and round trips

  Folder:         m-gradient-palette/ [m-gradient-palette/README.txt]
  What it covers: Ramps, interpolation spaces and hue routes, evenness, gamut
                  mapping, contrast and colour-vision checks, exports

  Folder:         svg-recolour/ [svg-recolour/README.txt]
  What it covers: Loading SVGs, mapping colours, harmonies, previews, contrast
                  and colour-vision checks, exports
