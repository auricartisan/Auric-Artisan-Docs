==============================================================================
SVG RECOLOUR GLOSSARY
==============================================================================
Definitions of the terms used in SVG Recolour.
Area: Website › Tools › Image and file tools › SVG Recolour   Updated: 2026-09-25

  Term:    Active content
  Meaning: Parts of an SVG that run code: scripts, event handlers and
           `javascript:` links

  Term:    APCA
  Meaning: Advanced Perceptual Contrast Algorithm; lightness contrast in Lc
           units, signed by polarity

  Term:    CIEDE2000 (ΔE₀₀)
  Meaning: The CIE's standard formula for how different two colours look

  Term:    Closest pair
  Meaning: The two colours in the file with the smallest CIEDE2000 difference

  Term:    Contrast ratio
  Meaning: The WCAG 2 measure of luminance difference, from 1:1 to 21:1

  Term:    CSS colour name
  Meaning: One of the 148 named colours of CSS, such as `red` or
           `rebeccapurple`

  Term:    `currentColor`
  Meaning: A value that takes the colour from the page the SVG is placed in

  Term:    Custom property
  Meaning: A CSS variable, such as `--colour-01`, holding a colour

  Term:    Dichromacy
  Meaning: Colour vision with one of the three cone types missing

  Term:    Harmony
  Meaning: A set of colours at fixed angles round the colour wheel

  Term:    Left alone
  Meaning: A value with no colour the tool can change, listed but not written

  Term:    OKLCH
  Meaning: A perceptual colour space of lightness, chroma and hue, used for
           the harmonies

  Term:    Occurrence
  Meaning: One place in the file where a colour value is written

  Term:    Paint property
  Meaning: A property that sets colour, such as `fill` or `stroke`

  Term:    Presentation attribute
  Meaning: An SVG attribute that sets a style directly, such as
           `fill="#E5484D"`

  Term:    Protanopia, deuteranopia, tritanopia
  Meaning: Colour vision missing the long (red), medium (green) or short
           (blue) wavelength cones

  Term:    Source form
  Meaning: The way a colour was written: hex, shorthand, `rgb()`, `hsl()` or a
           name

  Term:    Style attribute
  Meaning: An SVG `style="…"` attribute holding CSS declarations

  Term:    Style sheet
  Meaning: CSS inside a `<style>` element in the SVG

  Term:    SVG
  Meaning: Scalable Vector Graphics: an XML format for drawings

  Term:    Target
  Meaning: The colour an original colour will become

  Term:    WCAG
  Meaning: The Web Content Accessibility Guidelines; version 2.2 defines the
           contrast ratio used here

  Term:    Well-formed
  Meaning: XML that follows the syntax rules, so it can be parsed

  Term:    Written
  Meaning: An occurrence the tool actually rewrote
