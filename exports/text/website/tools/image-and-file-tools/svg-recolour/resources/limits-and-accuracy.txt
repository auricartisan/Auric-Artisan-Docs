==============================================================================
LIMITS AND ACCURACY
==============================================================================
What SVG Recolour finds and writes, how precise its figures are, and what it
does not hold.
Area: Website › Tools › Image and file tools › SVG Recolour   Updated: 2026-09-25

WHAT IS FOUND AND WRITTEN
=========================

  - Eight paint properties: `fill`, `stroke`, `stop-color`, `flood-color`,
    `lighting-color`, `color`, `solid-color` and `text-decoration-color`.
  - In presentation attributes, style attributes and `<style>` elements.
  - Colours written as hex (with or without alpha), shorthand hex, `rgb()`,
    `rgba()`, `hsl()`, `hsla()` and all 148 CSS names.
  - The count beside each colour is the number of occurrences, and the written
    count is the number actually rewritten. The colour list, the Mapping tab,
    the report and the exported file all use the same list, so they always
    agree.
  - Every change is planned from the original file before anything is written,
    so no change can be caught by another.

WHAT IS NOT FOUND OR NOT CHANGED
================================

  Item:         `currentColor` and other inherited keywords
  What happens: Counted and left alone; the colour comes from outside the file

  Item:         `none`, `transparent`, `url()` references
  What happens: Counted and left alone

  Item:         Colours in other CSS functions or variables (`oklch()`,
                `lab()`, `var()`)
  What happens: Not recognised, not counted, not changed

  Item:         Embedded raster images
  What happens: Not read; their pixels are not changed

  Item:         Colours set by CSS outside the file
  What happens: Not visible to the tool

PRECISION AND CHOICES
=====================

  Item:   Colour values
  Detail: Parsed to 8-bit sRGB; an unrecognised value is never guessed as
          black

  Item:   Alpha
  Detail: Kept for `rgba()` and `hsla()` with Keep the source form; lost for
          hex with alpha when changed

  Item:   Three-digit hex
  Detail: Written back as six digits

  Item:   Grouping
  Detail: Only identical colours share a row; near-identical colours are kept
          apart

  Item:   Colour names
  Detail: The nearest CSS name by CIEDE2000, prefixed "near"; a label, not a
          classification

  Item:   Harmony angles
  Detail: A colour-wheel convention, applied in OKLCH with lightness and
          chroma kept

  Item:   Contrast
  Detail: WCAG 2.2 ratio, exact; APCA-W3 0.1.9 with all its constants

  Item:   CIEDE2000
  Detail: ISO/CIE 11664-6:2014, agreeing with published test data to within
          0.00004

  Item:   Colour-vision simulation
  Detail: Machado, Oliveira and Fernandes (2009), full severity, in linear
          light; no milder forms

LIMITS
======

  - One file at a time; there is no batch mode.
  - The previews have active content removed; the exported file does not.
  - Only the `<svg>` element is exported: anything before it, such as an XML
    declaration or DOCTYPE, is not carried across, and the browser may
    normalise small formatting details.
  - Nothing is stored between visits.

WHAT IT IS NOT
==============

SVG Recolour changes colour values in the markup. It does not edit shapes,
text or structure, does not sanitise files for publishing, and does not judge
whether a palette is attractive.
