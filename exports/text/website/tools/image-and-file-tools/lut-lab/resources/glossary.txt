==============================================================================
LUT LAB GLOSSARY
==============================================================================
Definitions of the terms used in LUT Lab.
Area: Website › Tools › Image and file tools › LUT Lab   Updated: 2026-09-25

  Term:    1D LUT
  Meaning: A table mapping each channel on its own, one row per input level

  Term:    3D LUT
  Meaning: A cube of grid points mapping every combination of red, green and
           blue to a new colour

  Term:    8-bit
  Meaning: 256 levels per channel, 0 to 255; the precision LUT Lab works in

  Term:    ACEScct / ACEScg
  Meaning: Encodings from the Academy Color Encoding System for film work; not
           offered, because they need values above 1

  Term:    .cube
  Meaning: A plain-text LUT format defined by the Adobe / IRIDAS Cube LUT
           Specification 1.0

  Term:    CIEDE2000 (ΔE₀₀)
  Meaning: The CIE's standard formula for the size of a colour difference

  Term:    CIELAB
  Meaning: A colour space of lightness L* and colour axes a* and b*, used here
           with a D65 white

  Term:    Chroma (C*)
  Meaning: How colourful a colour is in CIELAB, its distance from grey

  Term:    Clipped
  Meaning: A pixel with a channel driven by the transform to 0 or 255 that was
           not there before

  Term:    Domain
  Meaning: The input range a `.cube` table covers, set by `DOMAIN_MIN` and
           `DOMAIN_MAX`; 0 to 1 by default

  Term:    Exposure
  Meaning: In the tone-map, the factor the linear scene light is multiplied by
           before compression

  Term:    Grid point
  Meaning: One of the sampled inputs of a LUT, at which the output is stored

  Term:    Hue sweep
  Meaning: The ring of 72 test colours at L* 60, C* 40 used to measure hue,
           lightness and chroma shifts

  Term:    Identity
  Meaning: A LUT that changes nothing

  Term:    Interpolation
  Meaning: Estimating the output between grid points by blending the
           neighbouring points

  Term:    Linear light
  Meaning: Values proportional to physical light, before the sRGB curve is
           applied

  Term:    Look
  Meaning: A built-in transform in LUT Lab: a stylisation or a defined
           transform

  Term:    LUT
  Meaning: Lookup table: a list of what each input colour should become

  Term:    Reachable
  Meaning: The share of a table's domain that an 8-bit sRGB input can reach

  Term:    Reinhard tone-map
  Meaning: A tone-mapping operator, L ÷ (1 + L), that compresses bright light
           smoothly

  Term:    Round trip
  Meaning: Writing a table to a file and reading it back, to check nothing was
           lost

  Term:    Sample order
  Meaning: The order of rows in a 3D `.cube`: red changes fastest, then green,
           then blue

  Term:    Size
  Meaning: The number of grid points along each axis of a LUT

  Term:    sRGB
  Meaning: The standard colour space for web and consumer images

  Term:    Strength
  Meaning: How much of a look is blended with the original, 0% to 100%

  Term:    Stylisation
  Meaning: A look designed because it looks good, with no definition to check
           against

  Term:    Transform
  Meaning: A conversion between two defined things, which can be checked
           against its definition

  Term:    Trilinear interpolation
  Meaning: Blending the eight grid points around an input along red, then
           green, then blue
