THE PUBLIC API
==============

The same job is available as a REST call, `POST /v1/palette/from-image`,
documented at
https://auricartisan.com/library/documentation/api/#ep-post-palette-from-image.
See Public API [../../../../../services/public-api/README.txt] for keys,
credits and limits.
