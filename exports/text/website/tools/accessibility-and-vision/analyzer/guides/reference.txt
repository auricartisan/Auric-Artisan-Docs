ANALYZER REFERENCE
==============================================================================
Every control, option, section, input and output of the Analyzer in one place.
Area: Website › Tools › Accessibility and vision   Updated: 2026-09-25

A complete list of the Analyzer's controls and outputs. Each entry links to
the guide that explains it in more depth.

PAGE ELEMENTS
=============

  Element:      Masthead
  What it does: The headline "One URL, audited seven ways.", a lede, and a
                rail with Read the API reference

  Element:      API hint
  What it does: The REST API equivalent and its price in API credits;
                dismissing it hides it on every tool page

  Element:      Save this run
  What it does: The site-wide library button, fixed at the bottom right

THE STRIP
=========

  Control:      URL field
  What it does: The address to audit
  Values:       Any http or https address, a bare host name, or a path on
                auricartisan.com
  Default:      Empty

  Control:      Analyze
  What it does: Starts a single-page audit. `Enter` in the URL field does the
                same.
  Values:       Button
  Default:      —

  Control:      Cancel
  What it does: Stops the running audit or site scan
  Values:       Shown only while running
  Default:      —

  Control:      Share
  What it does: Opens the share dialog with a link that re-runs the audit
  Values:       Button
  Default:      —

  Control:      Sections
  What it does: Opens the Sections picker. Shows `Ctrl` + `P`.
  Values:       Advanced only
  Default:      —

  Control:      Layouts
  What it does: Opens the layout menu
  Values:       Advanced only
  Default:      —

  Control:      Simple / Advanced
  What it does: Switches mode; remembered in this browser
  Values:       Simple, Advanced
  Default:      Simple

URL field placeholder: "Enter a URL to analyze…" (Simple) or "Enter a URL for
deep DOM, SEO, contrast & accessibility audit…" (Advanced). See Run an
analysis [run-an-analysis.txt].

WHAT TO SCAN (ADVANCED)
=======================

The row's heading reads "What to scan · N of 13 · N tokens". See Choose what
to scan [choose-what-to-scan.txt].

  Control        | What it does                                                    | Default
  ---------------+-----------------------------------------------------------------+--------
  13 check boxes | One per switchable check (listed below)                         | All on
  Everything     | Turns every check on                                            | —
  The fast three | Keeps only Page structure, Colour contrast and SEO and metadata | —

The 13 checks are Project model, Colour contrast, Before / After,
Accessibility, Palette, Vision simulation, SEO and metadata, Media,
Performance, Responsive behaviour, Deep DOM and framework, Security and
reliability, and Site map.

Page structure always runs. Simple mode always runs Page structure, Project
model, Colour contrast, SEO and metadata, Site map, Accessibility and
Responsive behaviour.

SCORES AND THRESHOLDS
=====================

  Item:  Overall and section grade bands
  Value: A+ 90–100, A 80–89, B 70–79, C 55–69, D 40–54, F 0–39

  Item:  A11y+ engine grade bands
  Value: A+ 95–100, A 90–94, B 80–89, C 70–79, D 55–69, F 0–54

  Item:  Category weights, first five
  Value: Accessibility 20%, contrast 16%, performance 13%, deep analysis 10%,
         metadata 9%

  Item:  Category weights, last five
  Value: Responsive 8%, visual quality 8%, reliability 7%, security 7%, media
         2%

  Item:  Contrast thresholds
  Value: 4.5:1 normal text, 3:1 large text and UI, 7:1 and 4.5:1 enhanced

  Item:  Large text
  Value: 24px, or 18.66px bold

  Item:  Target size
  Value: 24 × 24 CSS px (AA), 44 × 44 CSS px (AAA)

  Item:  Core Web Vitals, good
  Value: LCP ≤ 2,500 ms, CLS ≤ 0.10, INP ≤ 200 ms, FCP ≤ 1,800 ms, TTFB ≤ 800
         ms, TBT ≤ 200 ms

LINKS YOU CAN BUILD
===================

  Link:   `https://auricartisan.com/tool/analyzer/?url=<address>`
  Effect: Opens the Analyzer and audits the address

  Link:   A Share or Share Link link
  Effect: Opens the Analyzer and re-runs the audit of the shared address

REMEMBERED IN THIS BROWSER
==========================

  - Simple or Advanced mode, and each mode's panel arrangement
  - Saved layouts and the three newest automatic ones
  - Which checks are ticked in What to scan
  - Fix Mode (Safe or Aggressive)
  - The Public proxy choice
  - The Network Simulation profile
  - Issue statuses (Open, Fixed, Ignore, Recheck)
  - Custom rules
  - Every run's report, versions, palettes and history (see Save, reopen and
    compare [save-reopen-and-compare.txt])
  - A copy of each audited page for up to 7 days, used as a last-resort
    fallback
  - Whether you dismissed the API hint

For exports and file names, see Export and share [export-and-share.txt].
