The list of Analyzer guides, from a first audit to exports, with one line on

Area: Website › Tools › Accessibility and vision   Updated: 2026-09-25

These guides explain how to use the Analyzer at
https://auricartisan.com/tool/analyzer/. Start with Getting started, then open
the guide for the job in front of you. The reference page lists every control
and output in one place.

  Guide:          Getting started [getting-started.txt]
  What it covers: Open the Analyzer, learn the screen, and run your first
                  audit

  Guide:          Run an analysis [run-an-analysis.txt]

                  reached, and the progress card

  Guide:          Choose what to scan [choose-what-to-scan.txt]
  What it covers: The 13 checks, the What to scan picker in Advanced, and how
                  a run is priced

  Guide:          Scan a whole site [scan-a-whole-site.txt]
  What it covers: Site scan settings, the live progress console and paged
                  per-page results

  Guide:          Arrange the workspace [arrange-the-workspace.txt]
  What it covers: Panels, the Sections picker, width, Focus, Collapse, and
                  saved Layouts

  Guide:          Read the Overview and scores
                  [read-the-overview-and-scores.txt]
  What it covers: The overall score, grade bands, category weights and issue
                  cards

  Guide:          The accessibility engine [accessibility-engine.txt]
  What it covers: Every view of the A11y+ panel: findings, fixes, widgets,

  Guide:          Accessibility rules [accessibility-rules.txt]
  What it covers: All 126 accessibility rules, grouped by category, with

  Guide:          Colour, contrast and vision [colour-contrast-and-vision.txt]

  Guide:          Performance, SEO and page health

  Guide:          Fix and preview [fix-and-preview.txt]
  What it covers: The Fixes, Playground, Rules and CSP Setup panels

  Guide:          Save, reopen and compare [save-reopen-and-compare.txt]
  What it covers: How runs are kept, the Workspace panel, Compare, and keeping

  Guide:          Export and share [export-and-share.txt]
  What it covers: Every export, its format and file name, and the share links

  Guide:          Reference [reference.txt]
  What it covers: Every control, option, input and output

  Guide:          Troubleshooting [troubleshooting.txt]
