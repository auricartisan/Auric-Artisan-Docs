==============================================================================
ILLUMINANTS SHORTCUTS
==============================================================================
Keyboard and mouse shortcuts in the Standard Illuminants lab.
Area: Website › Tools › Colorimetry and rendering   Updated: 2026-09-25

  Shortcut:     `Ctrl` + `Enter`
  Where:        Console, in the Query box
  What it does: Runs the query

  Shortcut:     `Esc`
  Where:        Reference, in the Filter box
  What it does: Clears the filter

  Shortcut:     `Esc`
  Where:        A full-screen chart
  What it does: Closes the full-screen view

  Shortcut:     Double-click
  Where:        SPD or CRI chart
  What it does: Opens the chart full screen

  Shortcut:     Click
  Where:        SPD chart
  What it does: Probes the nearest wavelength and shows its relative power

On macOS, `Cmd` + `Enter` also runs a console query.

ABOUT THE S, R, C AND E HINT
============================

The Lab rail shows a Keyboard shortcuts hint: S swap adaptation, R reset D65,
C toggle compare, E export CSV. These single-key shortcuts are not active in
the current version of the page. Use the buttons instead:

  Hint | Button to use
  -----+---------------------------------
  S    | Swap under Chromatic adaptation
  R    | Reset to D65
  C    | Enable comparison
  E    | Export SPD CSV on the Export tab

The site's own shortcuts (such as the search palette) also work on this page;
see the site features documentation.
