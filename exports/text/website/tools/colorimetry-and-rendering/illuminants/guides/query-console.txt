==============================================================================
QUERY MANY ILLUMINANTS AT ONCE
==============================================================================
Use the Console tab's query language to tabulate, sort, plot and export
readings for many illuminants.
Area: Website › Tools › Colorimetry and rendering   Updated: 2026-09-25

The Console tab answers questions such as "which of these lights is furthest
from the Planckian locus?" in one table. You type a short query; the lab
computes every requested column with the same engine the other tabs use, so a
console row and a Lab reading cannot disagree. The query is parsed, never run
as code.

STEPS
=====

  1. Open the Console tab. The Query box already holds an example.
  2. Edit the query, or select one of the Recipes to load a ready-made one.
  3. Select Run, or press `Ctrl` + `Enter` in the query box.
  4. Read the Results table. Its heading shows the number of rows. The status
     line beside the buttons shows rows, time taken and the interval and
     interpolation used.
  5. Under Any two columns, plotted, choose a Horizontal axis and a Vertical
     axis. The scatter plot labels each point with the illuminant name.
  6. Select CSV or JSON to download the results.

THE GRAMMAR
===========

A query is a few lines, each starting with a keyword. Anything after `//` on a
line is a comment.

  Line:         `select`
  What it does: The illuminants to include, separated by commas or spaces.
                Names are case-insensitive. A range such as `F1..F12` expands
                to every name in between.
  Example:      `select A, D50, D65, F1..F12`

  Line:         `with`
  What it does: Pipeline settings as `name=value` pairs.
  Example:      `with interval=1nm, interpolation=sprague`

  Line:         `report`
  What it does: The columns to show, in order.
  Example:      `report x, y, CCT, Duv`

  Line:         `order by`
  What it does: Sort by one reported column, `asc` (default) or `desc`.
  Example:      `order by Duv desc`

  Line:         `limit`
  What it does: Keep only the first n rows after sorting.
  Example:      `limit 8`

Names you can select
--------------------

A, D50, D55, D65, D75, E and F1 to F12.

Settings for `with`
-------------------

  Setting: `interval`
  Values:  `1nm`, `5nm`, `10nm`
  Notes:   Any other value falls back to the interval set on the Methods tab.

  Setting: `interpolation`
  Values:  `linear`, `sprague`, `pchip`
  Notes:   Any other value falls back to the Methods tab setting.

  Setting: `observer`
  Values:  `2deg`
  Notes:   Accepted for readability. Only the CIE 1931 2° observer is held.

Columns for `report`
--------------------

  Column:   `x`, `y`
  Shown as: x, y
  Meaning:  CIE 1931 chromaticity
  Decimals: 5

  Column:   `u`, `v`
  Shown as: u′, v′
  Meaning:  CIE 1976 chromaticity
  Decimals: 5

  Column:   `cct`
  Shown as: CCT
  Meaning:  Correlated colour temperature (Ohno); blank when not valid
  Decimals: 0

  Column:   `duv` (also `d_uv`)
  Shown as: Duv
  Meaning:  Signed distance from the Planckian locus
  Decimals: 5

  Column:   `efficacy` (also `eff`)
  Shown as: lm/W
  Meaning:  Luminous efficacy of radiation
  Decimals: 1

  Column:   `entropy`
  Shown as: Entropy
  Meaning:  A measure of how spread out the spectrum is
  Decimals: 3

  Column:   `peak`
  Shown as: Peak nm
  Meaning:  Wavelength of the highest power
  Decimals: 0

If you leave out `report`, the table shows x, y, CCT and Duv.

THE RECIPES
===========

  Recipe:       The whole catalogue by CCT
  What it asks: All 18 illuminants at 5 nm: x, y, CCT, Duv and efficacy,
                sorted by CCT

  Recipe:       Which sources are furthest off the locus
  What it asks: CCT, Duv and entropy, sorted by Duv descending, top 8

  Recipe:       Luminous efficacy against spectral spread
  What it asks: Efficacy, entropy and peak, sorted by efficacy descending

  Recipe:       The D series at 1 nm
  What it asks: D50, D55, D65 and D75 at 1 nm with Sprague interpolation

STAND-IN ROWS
=============

Fluorescent illuminants F1 to F12 are built from stand-in spectra, not the CIE
tables. Their rows carry a stand-in tag in the table, "(stand-in)" after the
name in the CSV, and `"synthetic": true` in the JSON. Do not quote them as CIE
values.

THE EXPORT FILES
================

  - CSV downloads `illuminants.csv`. The first line is a comment recording the
    observer, interval and interpolation; then a header row (`source` and your
    columns) and one row per illuminant.
  - JSON downloads `illuminants.json` with the generation time, the pipeline
    settings, the column list and one entry per row (name, synthetic flag and
    values).

The buttons do nothing until a query has returned rows.

RESULT
======

You have a sorted table of readings for the lights you chose, a scatter plot
of any two columns, and a file you can open in a spreadsheet.
