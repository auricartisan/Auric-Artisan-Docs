RELATED TOOLS AND READING

Tools, services and Learn articles that go with the Personalization Generator.
Area: Website › Tools › Colour workspace   Updated: 2026-09-25

TOOLS
=====

  - Design System Generator [../../design-engine/README.txt]: build a full
    design system from a brief, with more control over ramps and token export.
  - Basic Color Tools [../../basic-colour-tools/README.txt]: palettes,
    gradients, a colour picker and the Colour Tools workbench.
  - Color Science Lab [../../colour-science-lab/README.txt]: look closely at
    any colour the generator produces.
  - Contrast Checker
    [../../../accessibility-and-vision/contrast-checker/README.txt]: test a
    final text and background pair.
  - Vision Lab
    [../../../accessibility-and-vision/vision-simulation/README.txt]: see a
    palette through colour-vision and other vision conditions.

LIBRARY
=======

  - Colour libraries [../../../../library/colour-libraries/README.txt]: browse
    palettes, gradients and shades, save them, and open them here to seed your
    pool.
  - Library Kit [../../../../kits/library-kit/README.txt]: find and manage the
    items you saved from the generator.

SERVICES
========

  - Public API [../../../../../services/public-api/README.txt]: the same
    generation as a REST call.
