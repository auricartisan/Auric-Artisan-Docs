==============================================================================
PANEL TOOLS
==============================================================================
The seven tools that open as panels in the Basic Color Tools workspace, with a
guide for each.
Area: Website › Tools › Colour workspace   Updated: 2026-09-25

These are the seven tools you open from the Basic Color Tools workspace. Each
opens as a floating panel with a controls sidebar and a main area. The level
column shows whether the tool appears under Basic or Advanced in the
Catalogue's level switch.

  Guide:       palette-studio.md [palette-studio.txt]
  Category:    Generate
  Level:       Basic
  In one line: Live palette generator with harmony, WCAG and accessibility
               modes, locking, OKLCH editing, image extraction and eight
               exports.

  Guide:       palette-remix.md [palette-remix.txt]
  Category:    Generate
  Level:       Advanced
  In one line: Turns seed colours into four styled variant palettes; copy CSS,
               JSON or all HEX codes.

  Guide:       gradient-maker.md [gradient-maker.txt]
  Category:    Generate
  Level:       Basic
  In one line: Linear, radial and conic gradients with any number of stops,
               perceptual interpolation, easing and CSS, SVG, PNG, JSON and
               Tailwind export.

  Guide:       colour-picker.md [colour-picker.txt]
  Category:    Pick
  Level:       Basic
  In one line: One colour in eight formats, with harmonies, colour-vision
               previews, chromaticity and contrast notes.

  Guide:       colour-battle.md [colour-battle.txt]
  Category:    Pick
  Level:       Advanced
  In one line: Scores two palettes against each other for contrast, separation
               and colour-vision resilience.

  Guide:       collage-maker.md [collage-maker.txt]
  Category:    Compose
  Level:       Advanced
  In one line: Arranges your images in one of 29 layouts and exports a 4K PNG.

  Guide:       quick-converter.md [quick-converter.txt]
  Category:    Convert
  Level:       Basic
  In one line: Converts one colour into fourteen notations and compares two
               colours.

For how panels open, move and close, see Workspace and panels
[../workspace-and-panels.txt]. Every control is also listed in the Reference
[../reference.txt].
