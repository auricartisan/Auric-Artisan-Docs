==============================================================================
DYE IN SOLUTION SHORTCUTS
==============================================================================
Keyboard and pointer actions in the Dye in Solution tool.
Area: Website › Tools › Perception and spectral › Industrial Dye Chemistry   Updated: 2026-09-25

The tool has no keyboard shortcuts of its own beyond these. Site-wide
shortcuts are described in Site features
[../../../../site-features/README.txt].

  Action: Drop a file
  Where:  The spectrum plot on the Lab tab, or Drop a spectrum on the Data tab
  Result: Loads a measured spectrum into the form chosen on the Data tab

  Action: Click
  Where:  The spectrum plot or Drop a spectrum
  Result: Opens a file chooser

  Action: `Enter` or `Space`
  Where:  Focused Drop a spectrum area
  Result: Opens a file chooser

  Action: `Enter` or `Space`
  Where:  A focused row on the Data tab
  Result: Expands or collapses the row

  Action: Click a tab name in the page text
  Where:  Note strip and hints
  Result: Switches to that tab

  Action: `Tab`
  Where:  Anywhere
  Result: Moves between controls; sliders then respond to the arrow keys
