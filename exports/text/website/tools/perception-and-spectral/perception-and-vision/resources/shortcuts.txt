==============================================================================
PERCEPTION AND VISION SHORTCUTS
==============================================================================
Keyboard and pointer actions in the Perception Vision tool.
Area: Website › Tools › Perception and spectral › Perception and Vision   Updated: 2026-09-25

The tool has no keyboard shortcuts of its own beyond these. Site-wide
shortcuts are described in Site features
[../../../../site-features/README.txt].

  Action: Press or drag
  Where:  The frame, with Compare set to Split
  Result: Moves the divider to the pointer

  Action: Double-click
  Where:  The frame
  Result: Opens the frame enlarged, filling the window

  Action: `Esc`
  Where:  Enlarged view
  Result: Closes it

  Action: Select the × button or the dark area around the image
  Where:  Enlarged view
  Result: Closes it

  Action: `Enter` or `Space`
  Where:  A focused row on the Data tab
  Result: Expands or collapses the row

  Action: `Tab`
  Where:  Anywhere
  Result: Moves between controls; sliders then respond to the arrow keys
