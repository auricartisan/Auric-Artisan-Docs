==============================================================================
PSYCHOPHYSICS BENCH GLOSSARY
==============================================================================
Psychophysics and display terms used in the Psychophysics Bench, each
explained briefly.
Area: Website › Tools › Perception and spectral › Psychophysical Experiment Engine   Updated: 2026-09-25

  Term:    2AFC (two-interval forced choice)
  Meaning: A task with two intervals, one holding the stimulus; the observer
           must pick one, so chance is 50%

  Term:    Adaptive staircase
  Meaning: A procedure that sets each trial's stimulus from the previous
           answers so trials cluster near threshold

  Term:    Alias
  Meaning: A false pattern that appears when a screen is asked to draw a
           frequency above its Nyquist limit

  Term:    Background (mean luminance)
  Meaning: The grey the contrast swings around; given as an 8-bit code and
           converted to relative luminance

  Term:    Bayesian tracker
  Meaning: A procedure that keeps a probability distribution over the
           threshold and updates it after each answer

  Term:    Bootstrap
  Meaning: Estimating the uncertainty of a result by refitting many resampled
           copies of the data

  Term:    Constant stimuli
  Meaning: A method that tests at fixed contrasts rather than adapting; here,
           at the starting contrast only

  Term:    Criterion (c) and β
  Meaning: Signal-detection measures of an observer's willingness to say "yes"

  Term:    d′ (d-prime)
  Meaning: A signal-detection measure of sensitivity that separates seeing
           from willingness to say "yes"; needs stimulus-absent trials

  Term:    Decibel step
  Meaning: A step size given as a ratio: 20 × log₁₀(ratio); 2 dB multiplies or
           divides contrast by about 1.26

  Term:    Degrees per pixel
  Meaning: The visual angle one pixel covers: atan(pixel pitch ÷ viewing
           distance)

  Term:    Envelope σ
  Meaning: The width of a Gabor's Gaussian envelope, in degrees of visual
           angle

  Term:    Gabor patch
  Meaning: A sine-wave grating multiplied by a Gaussian, fading smoothly into
           the background

  Term:    Geometric mean
  Meaning: The average of values on a logarithmic scale; used because the
           staircase steps by ratios

  Term:    Guess rate
  Meaning: The proportion correct expected by chance: 50% in two-interval
           forced choice

  Term:    Lapse rate
  Meaning: The small proportion of errors an observer makes even on easy
           trials

  Term:    Michelson contrast
  Meaning: (Lmax − Lmin) ÷ (Lmax + Lmin), where L is luminance

  Term:    Nyquist limit
  Meaning: The finest frequency a pixel grid can show: half a cycle per pixel

  Term:    Orientation
  Meaning: The angle of the grating's stripes, in degrees

  Term:    Psychometric function
  Meaning: The curve relating stimulus strength to the probability of a
           correct or "yes" response

  Term:    Relative luminance
  Meaning: The lightness-related quantity Y from 0 (black) to 1 (white),
           obtained from a screen value through the sRGB curve

  Term:    Reversal
  Meaning: A trial at which the staircase changes direction

  Term:    Spatial frequency
  Meaning: How many stripe cycles fall within one degree of visual angle
           (c/deg)

  Term:    sRGB transfer curve (EOTF)
  Meaning: The standard curve relating a screen code value to light output

  Term:    Threshold
  Meaning: The stimulus strength at which the observer is correct a stated
           proportion of the time

  Term:    Transformed up-down (Levitt)
  Meaning: Staircases that step down after n correct in a row and up after an
           error, converging at p where pⁿ = 0.5

  Term:    Warm-up reversals
  Meaning: The first two reversals, discarded because the staircase is still
           approaching threshold

  Term:    Yes / no detection
  Meaning: A task with one interval, stimulus present on some trials, where
           the observer says whether it was seen
