KEY POINTS
==========

  - Auric Artisan provides colour tools, colour-science resources, web
    analysis, theme generation and visual simulations, including more than 70
    vision simulation models.
  - Web analysis is for sites and assets you own or are authorised to test.
  - Accounts are live. One-time purchases go through Razorpay; recurring
    subscriptions are not offered.
  - API access is metered in API credits against a published monthly
    allowance; overage is opt-in, prepaid and never invoiced afterwards.
  - API credits and tokens are separate balances, and neither pays for the
    other.
  - Outputs are exploratory and informational — not certified professional,
    medical, legal, security or accessibility advice.
  - The Ishihara-style generator does not replace medical-grade Ishihara
    plates.
