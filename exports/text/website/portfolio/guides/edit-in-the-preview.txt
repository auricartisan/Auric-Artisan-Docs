==============================================================================
EDIT IN THE PREVIEW
==============================================================================
Type directly into the live preview, use the section rail and row controls,
and add sections in place.
Area: Website › Portfolio   Updated: 2026-09-25

The live preview is not only a picture of your page: you can write in it.
Click a heading and type; the change is saved and appears everywhere the
portfolio goes.

TYPE INTO THE PAGE
==================

  1. Hover over text in the preview. Editable text shows a faint outline.
  2. Click it. A coloured outline shows you are editing.
  3. Type. Empty fields show grey example text until you fill them.
  4. Finish:
     - `Enter` finishes a one-line field (a heading, a name, a button label).
     - In longer fields (quotes, descriptions, code, Markdown), `Enter` starts
       a new line; click elsewhere to finish.
     - `Escape` finishes too.

Pasting into a plain field pastes text only, without formatting.

What can be typed in the page
-----------------------------

  Section         | Editable in the page
  ----------------+------------------------------------------------------------------
  Heading         | The heading text
  Text / Markdown | The whole text (kept as Markdown)
  Two columns     | Each column (kept as Markdown)
  Quote           | The quote and the attribution
  Testimonial     | The quote, name and role
  Callout         | The text (kept as Markdown)
  Button          | The label
  Call to action  | The heading, text and button label
  Image           | The caption
  Code            | The code
  Skills / Tags   | The title
  Timeline        | The title, and each entry's date, title, subtitle and description
  Stats           | The title, and each metric's value and label
  Feature list    | The title, and each feature's title and description
  Steps           | The title, and each step's title and description
  FAQ / Accordion | The title, and each question and answer

Everything else — image addresses, embeds, tables, links, alignment, tone,
columns, which palettes to show — is a choice rather than words, so it lives
on the section's card. Clicking such a section in the preview selects it and
opens its card in the Content column, ready to edit.

Buttons and links in the preview do not navigate while you are building;
clicking one means "edit this".

THE SECTION RAIL
================

When you select a section in the preview, a small rail of buttons appears
beside it:

  Button:       Add a section below
  What it does: Opens a searchable list of section types and inserts your
                choice after this section.

  Button:       Open this section in the panel
  What it does: Opens its card in the Content column.

  Button:       Move this section up / Move this section down
  What it does: Reorders it.

  Button:       Hide from the page
  What it does: Hides the section (it stays in your draft).

  Button:       Remove this section
  What it does: Deletes it (undoable).

ROW CONTROLS
============

In Timeline, Stats, Feature list, Steps and FAQ sections, selecting a row
shows row controls instead:

  Button                                    | What it does
  ------------------------------------------+-------------------------
  Add an entry after this one               | Inserts a new row below.
  Move this entry up / Move this entry down | Reorders the row.
  Remove this entry                         | Deletes the row.

In a timeline sorted Newest first or grouped by year, rows appear in the
displayed order; moving and adding still act on the entry you selected.

ADD A SECTION AT THE END
========================

At the bottom of the page, a dashed Add a section button opens the same
searchable list. Type to narrow it, press `Enter` to add the first match, or
`Escape` to close.

RESULT
======

You can build most of the page by typing into it, and reach every other option
through the section's card.
