==============================================================================
MANAGE SECTIONS
==============================================================================
Add, open, reorder, hide, duplicate and delete sections, and use the bulk
actions.
Area: Website › Portfolio   Updated: 2026-09-25

A portfolio is a stack of sections, shown top to bottom in the order you set.
Each section has a card in the Content column.

ADD A SECTION
=============

Any of these adds one:

  - Add a section at the foot of the Content column: type in Search sections…
    to narrow the 25 types, then select a tile. Each tile shows the type's
    name and a short hint; hover for the hint. If nothing matches, it says No
    sections match that search. The builder confirms, for example, Added a
    Timeline section.
  - In the preview, the add control at the end of the page, or Add a section
    below on a section's rail (see Edit in the preview
    [edit-in-the-preview.txt]).
  - The command field: type "add" and choose, for example, Add a Gallery
    section.

New sections start empty; grey example text (placeholders) shows what goes
where, and disappears as you type. With no sections yet, the column says No
sections yet — add one below to start building.

THE SECTION CARD
================

  Control:      Drag handle (⠿)
  What it does: Drag to reorder ("Drag to reorder").

  Control:      Chevron (▾)
  What it does: Expand or collapse the card's fields.

  Control:      Type icon and name
  What it does: Which kind of section it is.

  Control:      Hidden badge
  What it does: Shown when the section is hidden from the portfolio.

  Control:      Eye button
  What it does: Hide from portfolio / Show in portfolio. Hidden sections stay
                in your draft but are left out of the page, exports and
                publishing.

  Control:      ↑ / ↓
  What it does: Move up / Move down.

  Control:      More actions (⋯)
  What it does: Move to top, Move to bottom, Duplicate, Delete.

Messages confirm actions, such as Section duplicated. and Section removed —
Ctrl+Z to undo.

BULK ACTIONS
============

Above the cards, a bar shows the section count, Collapse all (or Expand all)
and Bulk actions ▾:

  Action             | Effect                  | Message
  -------------------+-------------------------+----------------------------------------
  Expand all         | Opens every card.       | All sections expanded.
  Collapse all       | Closes every card.      | All sections collapsed.
  Show all sections  | Un-hides every section. | All sections shown in the portfolio.
  Hide all sections  | Hides every section.    | All sections hidden from the portfolio.
  Reverse order      | Flips the order.        | Section order reversed.
  Clear all sections | Deletes every section.  | All sections cleared — Ctrl+Z to undo.

Every bulk action can be undone.

TIPS
====

  - Hide a section instead of deleting it when you might want it back later.
  - A page where every section is hidden cannot be meaningfully published; the
    publish dialog warns Every section is hidden — the page would be empty.
  - The section count in the top bar and in the preview bar counts all
    sections, hidden or not.

RESULT
======

Your sections are in the order you want, with the ones you are not ready to
show hidden.
