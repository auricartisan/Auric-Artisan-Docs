# Published reading editions

Auric Artisan documentation in formats for offline reading, printing, sharing and editing.

| Folder | Format | Best for |
| --- | --- | --- |
| [html/](html/README.md) | Offline website with navigation and search | Reading in a browser without a server or internet connection. Open [index.html](html/index.html) or [search.html](html/search.html). |
| [text/](text/README.md) | Plain text, one file per document | Text editors, terminals and screen readers. |
| [pdf/](pdf/README.md) | A4 PDFs with contents, bookmarks and page numbers | Printing and sharing individual areas of the documentation. |
| [epub/](epub/README.md) | Complete EPUB 3 e-book | Phones, tablets and e-readers. |
| [word/](word/README.md) | Editable Word documents, one per area | Annotating, editing and preparing handouts. |

These are published snapshots. They retain the product content and publication dates of their original editions and may lag the [current Markdown source](../docs/README.md). Text and HTML navigation follows the current `guides/` and `resources/` hierarchy. PDF, EPUB and Word files retain their original contents.

The HTML stylesheet and search scripts stay in [html/assets/](html/assets/README.md); keep them with the HTML pages when copying the offline site.

Machine-readable JSON and CSV catalogs live separately in [data/](../data/README.md). See [CONTRIBUTING.md](../CONTRIBUTING.md) for maintenance and publishing instructions.
