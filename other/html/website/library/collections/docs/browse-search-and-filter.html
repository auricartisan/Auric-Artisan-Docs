Browse, search and filter

Narrow the tool catalogue with search, category and topic filters, sort orders and layout options.

The All tools section of https://auricartisan.com/collections/ gives you four ways to narrow the catalogue: a search box, category filters, topic filters and a sort order. They work together, and the grid updates as soon as you change any of them.

Search

The search box sits above the grid and reads Search tools....

  1. Select the box and start typing.
  2. The grid updates on every keystroke; you do not need to press Enter.
  3. To clear the search, delete the text.

How matching works:

  • Matching ignores upper and lower case.
  • Each word you type must appear somewhere in the tool's details. colour vision finds tools that mention both "colour" and "vision", in any order.
  • A word can match part of a longer word. grad finds "gradient" and "gradients".
  • The details searched are the tool's name, its one-line description, its category, its address on the site, and its topic tags.

Tip: The catalogue uses both spellings in places — some descriptions say "colour" and some tags say "color". If a search finds less than you expect, try the other spelling. Search does not treat them as the same word.

Filter by category

Open Category in the Filter and sort panel. Each category is a tick box with the number of tools in it. The categories are:

Accessibility, Color Science, Colorimetry, Design Systems, Gamut & Rendering, Generators, Iconography, Perception, Publish, Spectral, Typography and Utilities.

A Pinned box appears at the top of the list as soon as you pin at least one tool (see Pin tools and use recommendations).

Rules:

  • With no boxes ticked, every category is shown.
  • Tick one box to show only that category.
  • Tick several boxes to show tools in any of them. Ticking Generators and Utilities shows both groups together.
  • Untick a box to remove it again.

Categories list only the tools your tool-visibility setting allows. If a category you expect is missing, see Show basic or advanced tools.

Filter by topic

Open Topics (it starts closed). Topics are the short tags each tool carries, such as palette, accessibility or hdr. The list shows up to 14 topics — the most common ones among the tools currently in view — each with a count.

  • With no topics ticked, all topics are allowed.
  • Tick one or more topics to show tools that carry any of them.

How the filters combine

A tool is shown only when it passes all three checks at once:

  1. its category is one of the ticked categories (or none are ticked), and
  2. it carries one of the ticked topics (or none are ticked), and
  3. every word in the search box appears in its details.

The line above the grid shows the result, for example 4 of 14 tools. When nothing matches, the grid is replaced by No matching tools with the advice to try a shorter search, clear the topic chip, or switch the category back to all tools.

Sort the grid

Open Sort by and choose an order from the Sort list:

OptionOrder
Title A to ZAlphabetical by tool name.
Category A to ZAlphabetical by category.
Newest firstNewest first by date. Tools carry no dates, so this keeps the catalogue's own order.
Oldest firstOldest first by date. Tools carry no dates, so this also keeps the catalogue's own order.
RecommendedTools most likely to be useful to you first (see Pin tools and use recommendations).
Most usedTools you open most often, and most recently, first.
Pinned firstYour pinned tools first, then the rest.
Most metadataTools with the fullest descriptions and most tags first.

You can also change the order from the right-click card menu (see Use the card menu).

Grid or list

The Grid and List buttons beside the search box switch the layout:

  • Grid shows cards side by side with large artwork.
  • List shows one tool per row with a smaller picture beside the text, which is easier to scan.

Your choice is remembered in this browser.

Loading more tools

The grid shows 12 tools at first. As you scroll to the bottom of the grid, the next 12 load automatically. A line under the grid says where you are, for example Showing 12 of 14 tools, and then All 14 tools shown. A thin bar fills up as more of the list comes into view.

If automatic loading is not available in your browser, a Load 2 more tools button (the number changes) appears instead; select it to show the next batch.

Search and sort while scrolled down

Once you scroll past the search box and filters, a round search button appears on the right-hand side of the screen, towards the bottom. Select it (its label is "Search and sort tools") to open a small panel with:

  • a Search tools... box;
  • a Sort list;
  • Category and Topics sections with the same tick boxes as the main panel.

Everything in this panel stays in step with the main controls. Press Escape, or select anywhere outside the panel, to close it. The button hides again when you scroll back up to the main controls.

Result

You see only the tools that match your search, ticked categories and ticked topics, in the order you chose, laid out as a grid or a list.
