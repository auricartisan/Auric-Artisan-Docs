# Learn documentation — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | The guides, catalogue, reference, troubleshooting and FAQ for the Learn library. |
| [getting-started.html](getting-started.html) | Use the Learn page to browse the course, filter by category, search, and pick up where you left off. |
| [article-catalog.html](article-catalog.html) | Every published Learn article, grouped by topic, with its number in the course, reading time, link and a one-line summary. |
| [continue-your-journey.html](continue-your-journey.html) | How the recommendations at the end of each Learn article are chosen, and how to pin articles and see more suggestions. |
| [read-an-article.html](read-an-article.html) | Find your way around a Learn article: header actions, facts, table of contents, live demos, the quiz, printing and downloading. |
| [reference.html](reference.html) | Every control and label on the Learn page and on Learn article pages. |
| [troubleshooting.html](troubleshooting.html) | Symptoms, causes and fixes for problems on the Learn page and in Learn articles. |
| [faq.html](faq.html) | Short answers to common questions about the Learn library. |
