Filters

FilterOptionsTest
Dominant hueAll hues, Red (340° to under 20°), Orange (20–50°), Yellow (50–80°), Green (80–160°), Cyan (160–200°), Blue (200–260°), Purple (260–300°), Pink (300–340°)Chroma-weighted average of the five OKLCH hues.
ChromaAny chroma, Muted (< 0.07)**, **Balanced** (0.07 to 0.15), **Vivid (> 0.15)Average OKLCH chroma.
LightnessAny lightness, Dark (below 0.40), Mid (0.40 to 0.70), Light (above 0.70)Average OKLCH lightness.
MethodAll methods, complementary, triadic, analogous, tetradic, golden_ratio, random, monochromaticThe palette's method label.

Sort by

OptionOrder
Sort: originalPalette number (default). Streams through the whole collection.
Lightness ↑ / Lightness ↓Average OKLCH lightness.
Chroma ↑ / Chroma ↓Average OKLCH chroma.
Hue (rainbow)Dominant hue.
RandomShuffled.

Any sort other than Sort: original orders a first stretch of 1,500 derived palettes (or the matches among them).

Inspect tab

BlockContents
Colour stripFive columns with a three-word name and hex; select to copy.
