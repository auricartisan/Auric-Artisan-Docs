# Palette Library documentation — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | The task guides, reference, troubleshooting and FAQ for the Palette Library. |
| [getting-started.html](getting-started.html) | Open the Palette Library, learn what each part of the screen does, and find, inspect and export a first palette. |
| [analyse-the-collection.html](analyse-the-collection.html) | Use the Harmony, Accessibility and Stats tabs to see how methods, hues, contrast and lightness are distributed across a sample of palettes. |
| [browse-search-and-filter.html](browse-search-and-filter.html) | Scroll five million palettes, jump to a palette by id, search, filter and sort, and read the counter that says how far a scan went. |
| [copy-export-and-share.html](copy-export-and-share.html) | Copy a palette as hex, CSS, SCSS or Tailwind, download it as JSON, ASE, SVG or PNG, export design tokens, share a link, and download many palettes at once. |
| [inspect-a-palette.html](inspect-a-palette.html) | Read everything on the Inspect tab: the colour strip, the palette summary, pair-by-pair contrast and each colour's values. |
| [save-palettes.html](save-palettes.html) | Save palettes, find them on the Saved tab, and reach them from your Library. |
| [reference.html](reference.html) | Every control, filter, sort order, tab, output, file name and message in the Palette Library. |
| [troubleshooting.html](troubleshooting.html) | Symptoms, causes and fixes for problems in the Palette Library. |
| [faq.html](faq.html) | Short answers to common questions about the Palette Library. |
