Browse, search and filter

Search and filter 8,192 shade scales by base hue, chroma, lightness and method, and sort the results.

Search

Search by id, hex, token or method… filters as you type. Every word must appear in the scale's id, its name, its base colour, its method, its base hue name (red, orange, yellow, green, cyan, blue, purple, pink), its token names, or any of its hex codes. The Filter inside results box adds more words; Clear empties it. Press / outside a text field to jump to the search box.

Examples:

  • ff724c — scales based on, or containing, that colour.
  • tailwind blue — Tailwind-like scales with a blue base.
  • 950 — scales that have a 950 token.

Buttons

  • Shuffle — sort Random.
  • Open a random scale — opens any scale on Inspect.
  • Reset — clears searches, filters and sort.
  • Export visible — opens Export.
  • Back to top — scrolls to the first card.

The grid

The counter reads, for example, 1–24 of 1,148 scales, or Nothing to show; the grid then says No shade systems match — Try clearing a filter, or searching a broader method, hex or token.

Cards: select a swatch to copy its hex; Copy copies all hex codes, comma-separated (Shade hexes copied); Save saves or unsaves (Shade saved / Shade removed); Inspect, or anywhere else on the card, opens it. With the keyboard, Enter or Space on a focused swatch opens the scale.

A note on evenness

The page's introduction points to evenness — whether a scale's steps are equally spaced — as the property that matters most, and reports that 8.2% of scales are genuinely even. The current filter row does not include an evenness filter. To judge evenness for one scale, open it on Inspect and read Min adjacent contrast and the Token contrast ladder: large jumps between neighbouring steps show up there.
