# Shade Library documentation — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | The task guides, reference, troubleshooting and FAQ for the Shade Library. |
| [getting-started.html](getting-started.html) | Open the Shade Library, learn the screen, and find, check and export a first shade scale. |
| [analyse-the-collection.html](analyse-the-collection.html) | Use the Harmony, Accessibility and Stats tabs to see how methods, profiles, text safety and token counts are distributed across your filtered scales. |
| [browse-search-and-filter.html](browse-search-and-filter.html) | Search and filter 8,192 shade scales by base hue, chroma, lightness and method, and sort the results. |
| [copy-export-and-share.html](copy-export-and-share.html) | Copy a shade scale as hex, token-named CSS, SCSS or Tailwind, download JSON, SVG or PNG, export design tokens, share a link, and export many scales. |
| [inspect-a-scale.html](inspect-a-scale.html) | Read the Inspect tab: token strip, shade summary, token contrast ladder and each token's values. |
| [save-scales.html](save-scales.html) | Save shade scales, find them on the Saved tab, and reach them from your Library. |
| [reference.html](reference.html) | Every control, filter, sort order, tab, output and message in the Shade Library. |
| [troubleshooting.html](troubleshooting.html) | Symptoms, causes and fixes for problems in the Shade Library. |
| [faq.html](faq.html) | Short answers to common questions about the Shade Library. |
