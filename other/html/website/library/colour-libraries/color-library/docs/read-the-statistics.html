Read the statistics

Use the four histograms on the Stats tab to see how hue, lightness, chroma and contrast are spread across the colours you have filtered.

The Stats tab draws four histograms of the colours that currently match your chips, searches and filters. A histogram splits a range of values into equal bands and counts how many colours fall in each band, so you can see at a glance where a set is crowded and where it is thin.

Steps

  1. Narrow the grid on the Library tab, or leave it unfiltered to see the whole atlas.
  2. Select the Stats tab.
  3. Read the four cards. Each card's heading carries a badge with the number of colours it describes.
  4. Select a card's heading to fold it away, and again to unfold it.

Result: four bar charts that describe the set you filtered.

The four histograms

CardRangeBandsWhat it tells you
Hue (HSL)0° to 360°12 bands of 30°Which hue families the set contains.
Lightness (Lab L*)0 to 10010 bands of 10How dark or light the set is.
Chroma0 to 0.4010 bands of 0.04How muted or colourful the set is.
Contrast on white1:1 to 21:110 bands of 2How much of the set can be used as text on white.

Each row shows the band's range, a bar scaled to the fullest band, and the count. Values beyond the last band are counted in it.

Keeping it up to date

The histograms are drawn when you open the tab. If you change a search or a chip while the tab is open, select the Stats tab again to redraw them.

If nothing matches your filters, the tab shows No colors and Adjust filters to populate histograms.

Example

Select the chip Readable on white, then open Stats. The Contrast on white card shows no colours below 4.5:1, and the Lightness (Lab L*) card shows every colour in the bands below 50 — a colour has to be fairly dark to carry text on white.
