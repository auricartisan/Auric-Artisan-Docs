Color Library shortcuts

Keyboard and pointer actions in the Color Library.

Keyboard

KeysWhereResult
/Anywhere, when you are not typing in a fieldMoves the cursor to Search by hex (#a6e223) or id….
Enter or SpaceA focused tile in the gridOpens the colour on The colour tab.
TabAnywhereMoves between controls, chips and tiles.

Pointer

ActionResult
Select a tileOpens the colour.
Select a tile's starSaves or unsaves the colour without opening it.
Select a neighbour under Start from a colour you already haveOpens that colour.
Select a card heading on StatsFolds or unfolds the card.
Pause typing in the colour fieldUpdates the nearest matches without pressing Find its neighbours.

The site-wide shortcuts also work on this page. See Site features.
