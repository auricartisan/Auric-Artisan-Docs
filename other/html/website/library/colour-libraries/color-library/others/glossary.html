Color Library glossary

Definitions of the colour terms used in the Color Library.

TermMeaning
AA, AAAWCAG contrast levels. For normal-size text, AA needs a contrast ratio of at least 4.5:1 and AAA at least 7:1.
AtlasThe fixed set of 8,192 colours the Color Library holds.
Atlas idA colour's number in the atlas, from 0 to 8,191.
ChromaHow colourful a colour is, compared with a grey of the same lightness. The page uses OKLCH chroma, which runs from 0 (grey) to about 0.4 for the most vivid screen colours.
CIE L*a*b* (Lab)A colour space designed so that equal distances look roughly like equal differences. L is lightness (0 to 100); a runs from green to red; b from blue to yellow.
CIE76The simplest ΔE formula: the straight-line distance between two colours in Lab.
CMYKCyan, magenta, yellow and black: the four inks of process printing. The values are a simple conversion, not a print profile.
Colour vision deficiency (CVD)Reduced ability to tell some colours apart, often called colour blindness.
Contrast ratioThe WCAG 2 measure of how much two colours differ in brightness, from 1:1 (none) to 21:1 (black on white).
DeuteranopiaA form of colour blindness with no working green-sensitive cones ("green-blind").
ΔE (delta E)A number for how different two colours look. Under about 2.3 is usually invisible.
HueThe kind of colour — red, yellow, blue and so on — given as an angle from 0° to 360°.
HSLHue, saturation and lightness: a simple rearrangement of RGB used in CSS.
LightnessHow light or dark a colour looks. The page uses CIE L* (0 to 100) for the Lightness filter and OKLCH L (0 to 1) for sorting.
OKLab, OKLCHA modern perceptual colour space (2020). OKLCH expresses OKLab as lightness, chroma and hue, and is supported in CSS as oklch().
ProtanopiaA form of colour blindness with no working red-sensitive cones ("red-blind").
Relative luminanceHow much light a colour gives off, from 0 (black) to 1 (white), weighted for human vision. Contrast ratios are built from it.
Requirement chipOne of the seven buttons under Or from what it has to do, such as Readable on white.
sRGBThe standard colour space of the web and most screens. Every atlas colour is inside it.
TritanopiaA rare form of colour blindness with no working blue-sensitive cones ("blue-blind").
WCAGThe Web Content Accessibility Guidelines, the international standard for accessible web content.
