Release notes

User-facing history of the Color Library.

0.9.9 — 5 June 2026

The Color Library was added to the site as part of the library expansion in release 0.9.9, alongside the Palette, Gradient, Harmony, Shade and Accessibility libraries and the Font and Icon libraries. See the release entry on the Changelog.

The current page

The page as documented here opens with three routes into the atlas — Start from a colour you already have, Or from what it has to do and Browse the atlas — and gathers everything about one colour on a single tab, The colour. The changelog does not list these changes as a separate release.
