Release notes

User-facing history of the Gradient Library.

0.9.9 — 5 June 2026

The Gradient Library was added in release 0.9.9 as part of the library expansion. See the Changelog.

The current page

The page now opens with Will your gradient band?, which measures any stops you give it, shows a banding chip on every card, and puts every tab on screen at once. These changes are not listed as a separate changelog release.
