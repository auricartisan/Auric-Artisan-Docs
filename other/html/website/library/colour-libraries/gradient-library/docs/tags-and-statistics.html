Tags and statistics

Browse the collection by tag on the Tags tab, and read distributions for your filtered set on the Stats tab.

Tags tab

The Tags tab lists every value in six groups, each with the number of gradients in the whole collection, most common first:

GroupValues
MethodsAnalogous, Aurora, Chaotic, Complementary, Duotone, Golden, Monochrome, Nebula, Prismatic, Spectral, Terrain, Thermal
SchemesThe same twelve scheme names
ComplexityDetailed, Simple, Extreme
InterpolationLch Short, Linear Rgb, Oklab, Oklch Long, Oklch Short
EasingCubic In Out, Linear, Quart In Out, Sine In Out, Smootherstep
BandingSmooth, Visible Step Risk, Subtle Compression

Select a value in Methods, Schemes, Complexity, Interpolation or Easing to set that filter and return to the Library tab with the grid narrowed. The Banding values are shown for information; filter by banding with the Banding filter on the Library tab.

The counts on this tab always describe the whole collection, whatever filters are set.

Stats tab

The Stats tab describes the gradients that currently match your search and filters (or the whole collection when nothing matches). Seven cards, each a bar chart with counts:

CardGroups
BandingSmooth, Compresses, Steps
MethodsOne bar per method
ComplexitySimple, Detailed, Extreme
Stop Counts2–4, 5–8, 9–16, 17–32, 33+
InterpolationOne bar per space
EasingOne bar per easing
Score Bands0.70+, 0.55–0.69, under 0.55

Select a card heading to fold or unfold it. The tab redraws after you change a filter; if it looks out of date, select the tab again.

Example

Set Interpolation to Linear Rgb and open Stats; then set it to Oklch Short and open Stats again. Compare the Banding cards to see how often each blending space produced a smooth ramp in this collection.
