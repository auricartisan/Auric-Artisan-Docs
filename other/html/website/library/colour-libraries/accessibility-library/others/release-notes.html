Release notes

User-facing history of the Accessibility Library.

0.9.9 — 5 June 2026

The Accessibility Library was added in release 0.9.9 as part of the library expansion. See the Changelog.

The current page

The page has since been rebuilt around the question "What may I write on this?": a contrast map for any ground, twelve passing picks, a palette audit, and the five-million-pair index for lookup and browsing. The earlier version was a catalogue of pair cards with tabs for inspecting, auditing and exporting; the existing Accessibility Library user guide in the documentation library still describes that version. These changes are not listed as a separate changelog release.
