Changelog

What the Auric Artisan changelog contains, how to search it, and where to find a summary of each release.

The changelog is the versioned record of Auric Artisan's releases: "Every release, what was in it, and what it touched." It lists eleven entries, from v0.9.0 on 31 December 2025 to v0.9.11 on 12 August 2026, as a timeline, newest first. Each entry opens in place to show what changed and which parts of the platform it touched, with a link to the full release note.

Its search reads the changes themselves, not just the headings, so you can ask it questions such as "when did overage arrive?" and it will find the release and highlight the words where they appear.

Who it is for

  • Users who want to know what is new, or when something changed.
  • Teams who need to check when a feature, plan change or fix arrived.

Where to find it

  • The changelog: https://auricartisan.com/library/changelog/
  • From the site header: Learn menu › Changelog ("Releases & improvements").
  • RSS feed: https://auricartisan.com/library/changelog/rss.xml
  • A single release: add its version after #, for example https://auricartisan.com/library/changelog/#0.9.10

Quick start

  1. Open https://auricartisan.com/library/changelog/. The newest release is already open.
  2. Type a word into the search box, for example recorder. Matching releases stay, with the matches marked.
  3. Select Releases or Patches to show only that kind of entry.
  4. Select a release's header to open or close it.
  5. Under Touched, select a tag to see every release that touched the same part.
  6. Select Read the full release note for the complete write-up.

What you can do

  • Read every release, newest first, with its version, type and date.
  • Search every change and see matches highlighted.
  • Filter by type and by the part of the platform touched.
  • Open and close releases one by one, or all at once.
  • Link straight to a release by its version.
  • Follow new releases by RSS.
