ICC Profile Parser background material

The contents of the ICC Profile Parser's others folder: glossary, limits, related pages, release notes and privacy.

This folder holds reference material that supports the guides: the terms the tool uses, what it can and cannot read and how precisely, related tools and reading, its history, and what happens to your files. The tool has no keyboard shortcuts of its own beyond standard keyboard access, so there is no shortcuts page.
