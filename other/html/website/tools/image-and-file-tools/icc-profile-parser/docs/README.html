ICC Profile Parser documentation

The list of guides, the reference, troubleshooting and FAQ for the ICC Profile Parser.

This folder holds the task guides for the ICC Profile Parser, a concept page on how ICC profiles are organised, the full reference of every field and rule the tool shows, and the troubleshooting and FAQ pages. If ICC profiles are new to you, read Understand ICC profiles before the other guides.
