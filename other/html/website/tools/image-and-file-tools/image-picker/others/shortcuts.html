Image Picker shortcuts

Keyboard shortcuts and pointer actions in the Image Picker.

Keyboard

KeyAction
ERe-extract the palette with the current settings
HCopy the palette's hex values
JCopy the full analysis as JSON
RReset: clear the picture, palette and pins
Enter in the address fieldLoad the image at that address
EscapeClose a full-screen chart

The letter keys work anywhere on the page when focus is not in a text field, slider, switch or menu. Because a single R resets the workbench, click into a field before typing if you do not want to reset.

Pointer

ActionResult
Hover the previewRead the pixel under the pointer
Click the previewPin that pixel's colour
Click a palette swatchCopy its hex value
Click a pinCopy its hex value
Double-click a chartOpen it full screen
Click outside a full-screen chartClose it
