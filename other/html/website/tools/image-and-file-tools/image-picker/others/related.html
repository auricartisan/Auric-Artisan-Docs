Related tools and reading

Other Auric Artisan tools, the public API and Learn articles that go with the Image Picker.

Tools on the site

ToolWhy you might use it with the Image Picker
Contrast CheckerTest the exact text and background pair you chose from the palette
Vision SimulationSee how the picture and palette look with different kinds of colour vision
M-Gradient PaletteBuild an evenly stepped ramp between two colours taken from the picture
SVG RecolourApply colours from the palette to SVG artwork
Collage MakerCombine several pictures into one before extracting a palette from all of them
Basic ToolsQuick palette, gradient and conversion utilities

The public API

The same job is available as a REST call, POST /v1/palette/from-image, documented at https://auricartisan.com/library/documentation/api/#ep-post-palette-from-image. See Public API for keys, credits and limits.
