Collage Maker documentation

The list of how-to guides, the reference, troubleshooting and FAQ for the Collage Maker.

This folder holds the task guides for the Collage Maker, the full reference of its controls and outputs, and the troubleshooting and FAQ pages. Start with Getting started if you have not used the tool before; go to the Reference when you need the exact range or default of a control.

export-and-sessions.mdSaving PNG and JPEG, export scale and quality, the clipboard, session files and the reading
reference.mdEvery tab, control, button, message and file format, with ranges and defaults
troubleshooting.mdWhat to do when pictures will not load, exports look wrong, or undo behaves unexpectedly
