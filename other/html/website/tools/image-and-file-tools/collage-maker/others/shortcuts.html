Collage Maker shortcuts

Keyboard shortcuts and pointer actions in the Collage Maker.

Keyboard

KeysActionWorks when
Ctrl + ZUndoFocus is not in a slider, menu or text box
Ctrl + Shift + ZRedoAs above
Ctrl + YRedoAs above
Arrow keysNudge the selected picture 1 pxThe canvas has focus (click it first)
Shift + arrow keysNudge the selected picture 10 pxThe canvas has focus
Delete or BackspaceRemove the selected pictureThe canvas has focus
Enter or SpaceOpen the file chooserThe Drop pictures box has focus

On a Mac, Cmd works in place of Ctrl. With the canvas focused, one press of the undo or redo shortcut can move two steps; use the Undo and Redo buttons when you want exactly one.

Every control on the page can be reached with Tab. Each tab button, slider, switch and button responds to the keyboard in the usual way.

Pointer

ActionResult
Click a pictureSelect it (the top one where pictures overlap)
Click empty canvasClear the selection
Drag a pictureMove it; snapped to 10 px when snapping is on
Drag a corner handleResize the selected picture around its centre, from 2% to 800%
Click a row in Layers · top firstSelect that picture, including a hidden one
Drop image files on the canvas or the drop boxAdd them as pictures
