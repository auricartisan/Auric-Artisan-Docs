LUT Lab background material

The contents of LUT Lab's others folder: glossary, limits, related pages, release notes and privacy.

This folder holds reference material that supports the guides: the terms the tool uses, the limits of its 8-bit path and what it does not hold, related tools and reading, its history, and what happens to your files. LUT Lab has no keyboard shortcuts of its own beyond standard keyboard access, so there is no shortcuts page.
