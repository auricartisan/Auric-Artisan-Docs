Image and file tools

What the six image and file tools on auricartisan.com are for, where to find them, and which one to open for each job.

These six tools work on files you already have: photographs, SVG artwork, colour profiles and colour lookup tables. Each one reads your file in the browser, shows you what is in it, lets you change or measure it, and gives you a file or a report to take away. Nothing you load is uploaded; the reading and the arithmetic happen on the page.

The tools share a layout. A row of tabs runs across the top of each tool. The first tab is the working area, and later tabs explain the method, list where every number comes from (the Data tab), offer the exports (the Export or Actions tab) and cite the published sources (the Reference tab). The Image Picker is the exception: it has three tabs, Workbench, Analysis and Actions.

Where to find them

The group's own address is https://auricartisan.com/tool/general/tools/. Opening it takes you to the Collections page at https://auricartisan.com/collections/, which lists every tool on the site under All tools. Use the category filter or the Sort menu there, or open a tool directly from the table below. The Collections page is described in Collections.

The tools

Collage Makerhttps://auricartisan.com/tool/general/tools/collage-maker/Place pictures on a canvas, arrange them, measure coverage and export PNG or JPEG

The page titles differ slightly from the names in the Collections list: Collage Maker opens as Collage Studio, the ICC Profile Parser as ICC Profile Reading, the Image Picker as Image Color Picker & Palette Tool, the M-Gradient Palette as Gradient Ramp, and SVG Recolor as SVG Recolour.

Which tool for which job

  • You have photographs and want one image made of several: use the Collage Maker.
  • You have a colour profile from a monitor, printer or camera and want to know what it says: use the ICC Profile Parser.
  • You have a picture and want its colours as a palette: use the Image Picker.
  • You have a .cube grading file, or want to make one: use the LUT Lab.
  • You want a smooth, evenly stepped colour scale between two colours: use the M-Gradient Palette.
  • You have an icon or illustration as SVG and want it in different colours: use SVG Recolour.

All six tools are free to use, like every tool on the site.
