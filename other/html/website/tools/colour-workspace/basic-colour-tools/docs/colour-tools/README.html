Colour Tools workbench

The fourteen floating Colour Tools you can open on any page of Auric Artisan, how to open them, and a guide for each.

The Colour Tools are fourteen floating colour tools that open over whatever page you are on: right-click and use the Colour tools group, press Ctrl + Shift + C, right-click a colour value, or add ?color= to a page address. They share one launcher, one kind of panel window and a control bar for arranging panels. Basic Color Tools is their home page, and this folder documents them.

Start with launcher-and-panels.md, then open the guide for the tool you need.
