Basic Color Tools reference

Every control, option, range, default and output of the Basic Color Tools page, its views and its seven panel tools, with pointers to the Colour Tools references.

This page lists every control on the Basic Color Tools page. Defaults are given only where the page sets one. For the fourteen Colour Tools, each tool's guide ends with its own full controls table; see Colour Tools at the end.
