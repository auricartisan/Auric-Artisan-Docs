Basic Color Tools FAQ

Short answers to common questions about Basic Color Tools and the Colour Tools workbench.

Do I need an account?

No. All seven tools and the Colour Tools work without signing in. Saving to your Library uses the site's Library; see the Library Kit and Account and billing.

Does it cost anything or use tokens?

The seven tools compute everything in your browser and do not call the server for their results, so they do not spend tool tokens. See Account and billing for plans.

Are my images uploaded?

No. Images you add to Palette Studio (From Image) or Collage Maker are read by your browser on your device. See Privacy.

How many panels can I have open?

Five. Opening a sixth closes the oldest one. See Workspace and panels.

Why are some tools missing from the list?

The Catalogue's Level switch or search is filtering them, and the Workspace list follows the Catalogue. Set Level to Both, clear the search and choose All Tools.

Will my work still be there tomorrow?

Open panels are not saved. Your favourites, level, category and last view are remembered in your browser. To keep results, export them or use Save to Library.

Can I open the same tool twice?

Yes. Select Open another instance on the panel's title bar, or hold Shift, Ctrl or Cmd while selecting the tool's card in the Catalogue. Each copy has its own state.

What is the difference between Color Picker and Quick Converter?

Color Picker is built around choosing a colour by eye (plane, hue slider, eyedropper) and shows harmonies, colour-vision previews and contrast tiles. Quick Converter is built around typing or pasting a value; it shows fourteen notations, compares two colours and lists wide-gamut values.

What is the difference between Basic Color Tools and the Colour Tools?

Basic Color Tools is a page with seven panel tools. The Colour Tools are fourteen further floating tools you can open on any page of the site from the right-click menu, with Ctrl + Shift + C, or with a ?color= address parameter. See Colour Tools.

Which contrast standard do the tools use?

The seven panel tools use the WCAG 2.x contrast ratio: 4.5:1 for AA normal text, 7:1 for AAA, 3:1 for large text and non-text interface parts. Some Colour Tools, such as Contrast System, also report APCA.

Is the ASE export an Adobe swatch file?

No. It copies tab-separated text. Use CSS, SCSS, Tailwind, JSON, SVG or PNG for other tools.

Where are the palette, shade and gradient collections?

Large browsable collections of palettes, shades, gradients, harmonies and colours live in the site's library area. See Colour libraries.
