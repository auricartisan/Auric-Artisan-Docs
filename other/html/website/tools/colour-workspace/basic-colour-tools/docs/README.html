Basic Color Tools documentation

The list of every guide for Basic Color Tools and the Colour Tools workbench.

This folder explains how to use the Basic Color Tools page and everything on it: the three views, the panel windows, the seven workspace tools, and the fourteen site-wide Colour Tools. Start with the getting-started guide, then open the guide for the tool you need. The reference lists every control in one place.

Guides in this folder

FileWhat it covers
