Shortcuts

Every keyboard shortcut and mouse gesture in Basic Color Tools, its panel tools and the Colour Tools workbench.

Cmd applies on a Mac where the table lists it. Shortcuts that act on "the panel" act on the focused panel, the one you selected last.

Basic Color Tools page

Keys or gestureWhereWhat it does
SpacePalette Studio, panel focused, not typingGenerates a new palette (locked colours stay).
EscapeFocus inside a panelRestores a maximised panel; otherwise closes the panel.
Double-click the title barAny panelMaximises or restores.
Drag the title barAny panel (not maximised)Moves the panel.
Drag the bottom-right cornerAny panel (not maximised)Resizes the panel.
Shift, Ctrl or Cmd + select a tool cardCatalogueOpens another instance of the tool.
Drag a colour stripPalette StudioReorders the palette.
Shift + right-click a filled cellCollage MakerCycles that cell's filter.
Enter or leave the boxColor Picker HEX box; Quick Converter Compare HEX boxesApplies the typed HEX code.
Ctrl + Enter (Cmd + Enter)Save to Library windowSaves.

Colour Tools workbench

Keys or gestureWhereWhat it does
Ctrl + Shift + CAny page that loads the Colour ToolsOpens the Colour Tools launcher. If the selected text is a HEX code, the tool you pick opens with that colour.
Right-clickAny pageOpens the site menu with the Colour tools group.
Shift + right-clickAny pageOpens the browser's own menu instead.
Type while the right-click menu is openSite menuFilters the menu items.
Tab, Shift + TabLauncherMoves between the search box, tool rows, links and the close button.
Enter or SpaceLauncherOpens the focused tool.
EscLauncher search boxClears the search; press again to close the launcher.
EscLauncher, elsewhereCloses the launcher.
EscColour Tools panelLeaves full-window view if maximised; otherwise closes the panel.
Double-click the title barColour Tools panelMaximises or restores.

Individual Colour Tools may have their own keys; each tool's guide lists them. See Colour Tools.
