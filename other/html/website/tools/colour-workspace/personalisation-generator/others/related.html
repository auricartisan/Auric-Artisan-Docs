Related tools and reading

Tools, services and Learn articles that go with the Personalization Generator.

Tools

  • Design System Generator: build a full design system from a brief, with more control over ramps and token export.
  • Basic Color Tools: palettes, gradients, a colour picker and the Colour Tools workbench.
  • Color Science Lab: look closely at any colour the generator produces.
  • Contrast Checker: test a final text and background pair.
  • Vision Lab: see a palette through colour-vision and other vision conditions.

Library

  • Colour libraries: browse palettes, gradients and shades, save them, and open them here to seed your pool.
  • Library Kit: find and manage the items you saved from the generator.

Services

  • Public API: the same generation as a REST call.
