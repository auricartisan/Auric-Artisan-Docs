Glossary

Type and font terms used in the Font Library and its documentation.

TermMeaning
AxisOne dimension a variable font can change along, such as weight (wght) or width (wdth).
Character variantAn OpenType feature (cv01 to cv99) that swaps the design of one particular character.
Code pointThe number Unicode gives a character, written like U+0041.
FamilyAll the styles of one typeface, such as Regular, Bold and Italic.
Fallback stackThe fonts listed after the one you want, used if it is missing.
@font-faceThe CSS rule that tells a browser where a font file is and which style it provides.
FoundryThe company or person that publishes a typeface.
GlyphA single drawn shape in a font, usually a character.
Heading and bodyThe two roles in a type pairing: a display face for titles and a text face for reading.
InstalledA family listed from system fonts, shown only if you have it installed, and not served.
InstanceA named point on a variable font's axes, such as Light or Condensed Bold.
LigatureTwo or more characters drawn as one glyph, such as fi, or => in coding fonts.
Modular type scaleA set of sizes where each step is the previous one times a fixed ratio.
OpenType featureA switchable behaviour inside a font, named by a four-letter tag such as liga or tnum.
PangramA sentence using every letter of the alphabet.
Self-hostingServing font files from your own website instead of a font service.
SpecimenA sample of text set in a typeface, used to judge it.
Stroke contrastThe difference between thick and thin parts of letters.
Stylistic setAn OpenType feature (ss01 to ss20) that swaps a group of alternative designs.
Super-familyRelated typefaces designed to work together, such as a sans and a serif sharing a name.
Tabular figuresDigits of equal width, so numbers line up in columns.
Variable fontOne font file that holds a continuous range of styles along one or more axes.
WeightHow heavy the strokes are, from 100 (Thin) to 900 (Black); 400 is Regular and 700 Bold.
x-heightThe height of lowercase letters such as x, as a share of the font's size (em).
