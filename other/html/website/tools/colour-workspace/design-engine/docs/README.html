Design System Generator documentation

The list of guides for the Design System Generator.

These guides explain how to use the Design System Generator: setting the brief, reading each tab, using the component playground and the contrast audit, comparing systems, exporting tokens, and saving and sharing. The reference lists every control.

FileWhat it covers
getting-started.mdOpen the tool, tour the screen, generate and export a first system.
set-the-brief.mdIndustry, style, contrast target, density, seed, harmony, colour mode, corners, type ratio, ramp shape and token naming.
read-the-system.mdThe Overview, Colour, Type, Icons and Scales tabs.
component-playground.mdThe live component gallery and its preview controls.
contrast-audit.mdThe audit rail, the score, the full audit view and suggested fixes.
compare.mdRunning the same brief through every style or every industry.
export-tokens.mdThe Tokens tab, the twelve export formats and what each contains.
share-save-and-connect.mdShare links, saving to the Library, the Workspace view and sending the palette to other tools.
reference.mdEvery control, option, default and output.
troubleshooting.mdSymptoms, causes and fixes.
faq.mdShort answers to common questions.
