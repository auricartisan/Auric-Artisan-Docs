# Color Science Lab documentation — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | The list of guides for the Color Science Lab. |
| [getting-started.html](getting-started.html) | Open the Color Science Lab, learn its five views, and make your first measurements. |
| [arrange-link-save-export.html](arrange-link-save-export.html) | Move, resize, pin, dock and link Color Science Lab panels, arrange them with the Color Control centre, export a combined image, and save panels to your Library. |
| [catalogue-and-panels.html](catalogue-and-panels.html) | Find tools in the Catalogue, and use every control and tab of a Color Science Lab tool panel. |
| [catalogue-compare-and-analytics.html](catalogue-compare-and-analytics.html) | Preview up to eight tools on a six-colour test palette, and explore the lab's heat map, mind map, statistics and catalogue, with JSON and CSV export. |
| [compare-two-colours.html](compare-two-colours.html) | Measure the difference between a reference and a candidate colour with ΔE 2000, ΔE 1994, ΔE 1976 and Oklab distance, and see whether the gap is lightness, chroma or hue. |
| [gamut-audit.html](gamut-audit.html) | Check a palette against sRGB, Display P3, Adobe RGB and Rec. 2020, see how much headroom its tightest colour has, and what clipping would cost. |
| [illuminants.html](illuminants.html) | See one colour adapted to seven CIE illuminants with the Bradford transform, and how far it shifts under each. |
| [tool-list.html](tool-list.html) | Every Color Science Lab panel tool by domain, with its level, what it is for and its default model. |
| [workbench.html](workbench.html) | Resolve one colour into CIE XYZ, xyY, Lab, LCh, Oklab, Oklch, sRGB, HSL and CMYK under a chosen illuminant, standard observer and adaptation transform, and see its gamut and how it shifts under other lights. |
| [reference.html](reference.html) | Every view, control, option, default, output and file of the Color Science Lab in one place. |
| [troubleshooting.html](troubleshooting.html) | Symptoms you may meet in the Color Science Lab, why they happen, and what to do. |
| [faq.html](faq.html) | Short answers to common questions about the Color Science Lab. |
