# ASCII Art Generator documentation — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | The list of guides for the ASCII Art Generator. |
| [getting-started.html](getting-started.html) | Open the ASCII Art Generator, learn its layout, and make and copy your first piece of character art. |
| [charts-and-compare.html](charts-and-compare.html) | The measurements, charts and benchmark in the Analysis tab, and the character set comparison in the Compare tab. |
| [export.html](export.html) | Copy the art, download it as TXT, PNG, SVG, HTML, JSON, CSV or ANSI, export several files at once, and render a list of words in one go. |
| [fine-tuning.html](fine-tuning.html) | Every setting behind the Fine tuning button — character set and custom ramp, shape, tone, sampling and dithering, edges, type, filters and advanced options. |
| [looks-colour-and-detail.html](looks-colour-and-detail.html) | The five named looks, mono or colour art, ink and paper, the Detail slider and Invert for dark paper. |
| [render-modes.html](render-modes.html) | The Text, HTML, Canvas and SVG renders, the readouts under the art, and the full-screen view. |
| [sources.html](sources.html) | Convert an image, a line of text or a webcam frame, and every way to get a picture into the ASCII Art Generator. |
| [reference.html](reference.html) | Every control, range, default, file and message in the ASCII Art Generator in one place. |
| [troubleshooting.html](troubleshooting.html) | Fixes for common problems in the ASCII Art Generator, from files that will not load to downloads that do not match the art. |
| [faq.html](faq.html) | Short answers to common questions about the ASCII Art Generator. |
