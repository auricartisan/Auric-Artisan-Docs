Glossary

Icon and SVG terms used in the Icon Library and its documentation.

TermMeaning
currentColorA CSS keyword meaning the current text colour. Icons drawn with it take the colour of the text around them.
Data URIA way to put a whole file inside a link or src attribute, so no separate file is needed.
DuotoneA style with two tones: a solid shape and a lighter fill behind it.
Filled and outlineTwo ways of drawing icons: solid shapes, or lines of a set width.
IdentifierAn icon's unique name, beginning with its set, such as lucide-bell.
JSXThe HTML-like syntax used to write React components.
SetA family of icons drawn to one design, such as Lucide or Material.
SpriteOne SVG file holding many icons as symbols, each shown with a <use> reference.
Stroke widthThe thickness of the lines in an outline icon.
StyleOne drawing of a set, such as Outline, Fill or 16 · Solid.
SVGScalable Vector Graphics: an image format made of shapes, sharp at any size.
SymbolA reusable piece of an SVG sprite, identified by an id.
VariantOne icon in one style. 12,896 icons come in 32,803 variants.
WebfontA font whose characters are icons, used for the Material set.
