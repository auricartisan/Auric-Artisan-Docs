# Icon Library documentation — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | The list of guides for the Icon Library. |
| [getting-started.html](getting-started.html) | Open the Icon Library, learn its layout, and find, restyle and copy your first icon. |
| [browse-and-filter.html](browse-and-filter.html) | Search, sort, choose a set and style, filter by category and licence, and preview every icon at your size, stroke and colour. |
| [icon-panel.html](icon-panel.html) | Preview an icon large, switch its style, size, colour and stroke, copy it as SVG, JSX, a data URI or a CDN tag, download it, and read its details. |
| [kit-and-export.html](kit-and-export.html) | Select icons into Your kit, and take them away as a ZIP of SVG files or a single SVG sprite. |
| [sets-and-finder.html](sets-and-finder.html) | The Sets view, the featured collections, the Find your icon panel and the Recently viewed strip. |
| [reference.html](reference.html) | Every view, control, set, style, file and message in the Icon Library in one place. |
| [troubleshooting.html](troubleshooting.html) | Fixes for common problems in the Icon Library, from an empty page to filters and exports that do not behave as expected. |
| [faq.html](faq.html) | Short answers to common questions about the Icon Library. |
