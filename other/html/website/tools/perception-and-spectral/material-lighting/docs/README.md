# Using Material Under Light — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | Contents of the how-to documentation for the Material Under Light tool. |
| [getting-started.html](getting-started.html) | Open Material Under Light, learn the layout of the Lab tab and read the default gold-under-daylight scene. |
| [compare-with-the-reference.html](compare-with-the-reference.html) | Read the measured colour temperature and its error band, understand how the reference light is chosen, and interpret the colour difference between a material under its source and under that reference. |
| [export-and-share.html](export-and-share.html) | Download the 81-row spectrum CSV and the whole-scene JSON, and copy a link that rebuilds the scene. |
| [run-a-sensitivity-sweep.html](run-a-sensitivity-sweep.html) | Use the Metrics tab to see how far the colour moves when the reflectance curve is perturbed, and read why the CRI and TM-30 figures were withdrawn. |
| [set-up-a-scene.html](set-up-a-scene.html) | Choose the light, the material, the surface model and the viewing geometry, and understand what each does to the spectrum and the colour. |
| [use-a-measured-reflectance.html](use-a-measured-reflectance.html) | Load a spectrophotometer reflectance file in place of the synthesised presets, and go back to the presets. |
| [reference.html](reference.html) | Every tab, control, readout, message and file format in Material Under Light, with ranges and defaults. |
| [troubleshooting.html](troubleshooting.html) | Symptoms, causes and fixes for Material Under Light: black samples, disabled controls, clipping, refused files and links. |
| [faq.html](faq.html) | Short answers to common questions about Material Under Light. |
