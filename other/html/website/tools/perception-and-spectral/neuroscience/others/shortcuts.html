Visual Pathway shortcuts

Keyboard and pointer actions in the Visual Pathway tool.

The tool has no keyboard shortcuts of its own beyond these. Site-wide shortcuts, such as the search palette, are described in Site features.

ActionWhereResult
Double-clickStimulus or map canvas on the Lab tabOpens the canvas enlarged, filling the window
EscEnlarged viewCloses it
Select the × button or the dark area around the imageEnlarged viewCloses it
Enter or SpaceA focused row on the Data tabExpands or collapses the row
TabAnywhereMoves between controls; sliders then respond to the arrow keys
Drag a fileDrop a CSV or JSON on the Data tabInstalls a cone table
