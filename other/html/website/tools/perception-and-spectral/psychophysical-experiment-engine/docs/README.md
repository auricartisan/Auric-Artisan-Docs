# Using the Psychophysics Bench — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | Contents of the how-to documentation for the Psychophysics Bench. |
| [getting-started.html](getting-started.html) | Open the Psychophysics Bench, learn the Lab tab and measure a first contrast threshold with the default two-interval task. |
| [design-an-experiment.html](design-an-experiment.html) | Choose a task, build the stimulus, state the viewing geometry, pick a staircase procedure and set its parameters and the timing. |
| [export-your-data.html](export-your-data.html) | The trials CSV, the session JSON and setup links on the Export tab, their exact contents, and what to do while the Export tab does not open. |
| [read-the-results.html](read-the-results.html) | Understand the threshold readouts, the staircase trace and the explanation tabs of the Psychophysics Bench. |
| [run-a-session.html](run-a-session.html) | Practise, run a measured session, respond with keys or buttons, and understand when and how a run stops. |
| [reference.html](reference.html) | Every tab, control, readout, message, file format and link parameter in the Psychophysics Bench, with ranges and defaults. |
| [troubleshooting.html](troubleshooting.html) | Symptoms, causes, fixes and workarounds for the Psychophysics Bench, including tabs that do not open. |
| [faq.html](faq.html) | Short answers to common questions about the Psychophysics Bench. |
