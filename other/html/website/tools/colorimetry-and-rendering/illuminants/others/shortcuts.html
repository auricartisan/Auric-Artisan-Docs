Illuminants shortcuts

Keyboard and mouse shortcuts in the Standard Illuminants lab.

ShortcutWhereWhat it does
Ctrl + EnterConsole, in the Query boxRuns the query
EscReference, in the Filter boxClears the filter
EscA full-screen chartCloses the full-screen view
Double-clickSPD or CRI chartOpens the chart full screen
ClickSPD chartProbes the nearest wavelength and shows its relative power

On macOS, Cmd + Enter also runs a console query.

About the S, R, C and E hint

The Lab rail shows a Keyboard shortcuts hint: S swap adaptation, R reset D65, C toggle compare, E export CSV. These single-key shortcuts are not active in the current version of the page. Use the buttons instead:

HintButton to use
SSwap under Chromatic adaptation
RReset to D65
CEnable comparison
EExport SPD CSV on the Export tab

The site's own shortcuts (such as the search palette) also work on this page; see the site features documentation.
