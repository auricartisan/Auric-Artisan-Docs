# Gamut Mapping documentation — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | The guides, reference and help pages for the Gamut Mapping lab. |
| [getting-started.html](getting-started.html) | Open the Gamut Mapping lab, learn its tabs, and read a CIELAB gamut slice. |
| [compare-spaces-and-methods.html](compare-spaces-and-methods.html) | Use the Boundary and Methods tabs and the ΔE Playground to compare colour spaces, gamut volumes, mapping methods and colour differences. |
| [map-a-colour-list.html](map-a-colour-list.html) | Map up to 50 HEX colours at once and export images, settings and a link. |
| [map-a-colour.html](map-a-colour.html) | Check whether a colour fits a target space, choose a mapping method and strength, and read the result. |
| [reference.html](reference.html) | Every control, readout, option and export in the Gamut Mapping lab. |
| [troubleshooting.html](troubleshooting.html) | Fixes for common problems in the Gamut Mapping lab. |
| [faq.html](faq.html) | Short answers to common questions about the Gamut Mapping lab. |
