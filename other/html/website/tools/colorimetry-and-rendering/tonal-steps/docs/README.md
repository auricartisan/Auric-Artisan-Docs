# Tonal Steps documentation — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | The guides, reference and help pages for Tonal Steps, Tints and Shades. |
| [getting-started.html](getting-started.html) | Open Tonal Steps, learn its tabs, and build and read your first ramp. |
| [build-a-ramp.html](build-a-ramp.html) | Choose a ramp engine, step count and easing, and judge how even the ramp is. |
| [check-contrast.html](check-contrast.html) | Read every ramp step's WCAG 2.2 ratio and rating and its APCA-W3 Lc against white, black or the base colour. |
| [export-tokens.html](export-tokens.html) | Export the ramp, key set or contrast table as CSS, SCSS, JSON or CSV, share a link, and analyse a list of colours. |
| [tints-shades-tones.html](tints-shades-tones.html) | Build tints, shades, tones, a neutral ladder and 50–950 or 50–900 key sets, and choose the space they are mixed in. |
| [reference.html](reference.html) | Every control, readout, option and export in Tonal Steps, Tints and Shades. |
| [troubleshooting.html](troubleshooting.html) | Fixes for common problems in Tonal Steps, Tints and Shades. |
| [faq.html](faq.html) | Short answers to common questions about Tonal Steps, Tints and Shades. |
