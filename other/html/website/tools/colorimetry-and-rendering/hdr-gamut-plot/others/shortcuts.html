HDR Gamut Plot shortcuts

Keyboard and mouse shortcuts in the HDR Gamut Plot.

These keys work when the focus is not in a text box, slider or list. The Lab tab's rail lists them as "1-4 cycle curves" and "A toggle axes".

KeyWhat it does
1Tone curve: Gamma 2.2 (SDR)
2Tone curve: Gamma 2.4 (BT.1886, zero black)
3Tone curve: PQ (ST.2084)
4Tone curve: HLG (BT.2100)
ASwitches the chromaticity axes between CIE 1931 xy and CIE 1976 u′v′
EscCloses a full-screen chart; clears the Reference filter
MouseWhat it does
Move over the diagramUpdates the hover readout
Double-click a chartOpens it full screen
