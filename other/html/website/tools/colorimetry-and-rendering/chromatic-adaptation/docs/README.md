# Chromatic Adaptation documentation — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | The guides, reference and help pages for the Chromatic Adaptation lab. |
| [getting-started.html](getting-started.html) | Open the Chromatic Adaptation lab, learn its tabs and controls, and adapt your first image. |
| [adapt-a-colour-list.html](adapt-a-colour-list.html) | Paste up to 50 HEX colours and get their adapted values, colour shift and L*C*h° at the current adaptation state. |
| [adapt-an-image.html](adapt-an-image.html) | Load a photo, adapt it between two illuminants with a chosen transform and degree of adaptation, and export the frame. |
| [compare-transforms-and-copy-matrices.html](compare-transforms-and-copy-matrices.html) | Read the adaptation matrix, check its round trip, copy it as code, and compare all eight transforms on your illuminant pair. |
| [explore-the-time-course.html](explore-the-time-course.html) | Use the Dynamics tab to see how quickly the eye adapts to a new light, with the two-phase model and its single-exponential predecessor side by side. |
| [reference.html](reference.html) | Every control, readout, option and export in the Chromatic Adaptation lab. |
| [troubleshooting.html](troubleshooting.html) | Fixes for common problems in the Chromatic Adaptation lab. |
| [faq.html](faq.html) | Short answers to common questions about the Chromatic Adaptation lab. |
