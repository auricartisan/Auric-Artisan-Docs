Chromatic Adaptation shortcuts

Keyboard and mouse shortcuts in the Chromatic Adaptation lab.

These keys work when the focus is not in a text box, slider or list. Click an empty part of the page first if a key does nothing.

KeyWhat it does
SpacePlays or pauses the 0–5 s animation
RResets the time to 0 s
CRuns Compare All Methods (results on the Export tab)
GToggles the GPU checkbox (which has no effect on processing)
EscClears the Reference filter; closes a full-screen chart
MouseWhat it does
Double-click a chart or imageOpens it full screen
