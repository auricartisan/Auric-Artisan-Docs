# Vision Lab documentation — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | The list of Vision Lab guides with one line on each. |
| [getting-started.html](getting-started.html) | Open the Vision Lab, learn the five views, and run your first simulation. |
| [audit-a-palette.html](audit-a-palette.html) | Check every pair of colours in your palette under all 17 colour conditions, see which pairs merge, and get a lightness fix for each. |
| [browse-the-catalogue-and-panels.html](browse-the-catalogue-and-panels.html) | Find conditions in the Catalogue, open them as floating panels, arrange panels with Vision Control, and feed them an image. |
| [compare-conditions.html](compare-conditions.html) | Lay one source out under many vision conditions at once on the Compare contact sheet, and find the condition that costs the most. |
| [explore-analytics.html](explore-analytics.html) | See the whole collection of vision conditions by category and severity, and export the catalogue as JSON or CSV. |
| [links-saving-and-exports.html](links-saving-and-exports.html) | Share a Vision Lab view as a link, see what the lab remembers in your browser, and export results. |
| [the-78-conditions.html](the-78-conditions.html) | Every condition the Vision Lab simulates, by category, with its kind, severity score, summary and prevalence as the cards show them. |
| [use-the-workbench.html](use-the-workbench.html) | Take one condition apart in the Workbench: choose a specimen, set the base colour, severity and model, and read what collapses. |
| [reference.html](reference.html) | Every control, option and output of the Vision Lab in one place. |
| [troubleshooting.html](troubleshooting.html) | Common problems in the Vision Lab, why they happen, and what to do. |
| [faq.html](faq.html) | Short answers to common questions about the Vision Lab. |
