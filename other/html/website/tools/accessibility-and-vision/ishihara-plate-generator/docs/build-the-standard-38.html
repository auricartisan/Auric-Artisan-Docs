Build the standard 38

Generate the fixed 38-plate set, the composition a printed plate book uses, from a single seed.

The Set 38 tab builds "The standard thirty-eight": "Twenty-four numbers, six letters, four symbols, two shapes and two traceable paths — the composition a printed book uses, built from a single seed so it is the same every time."

Build it

  1. Open the Set 38 tab.
  2. Select Generate the set. The button reads "Building…" while it works.
  3. When it finishes, the tab shows every plate in a grid, and a summary with Plates (38), Seed (42) and Built (how long it took, a few seconds).

The Lab is left alone: "The set is built and shown here; nothing on the bench is cleared or replaced. Thirty-eight plates take a moment and a quarter of a million dots."

You can also start the set from the empty Lab with Or build the standard 38.

What the set contains

KindCountPlates (content and difficulty)
Number240 to 23; each block of eight runs easy, easy, medium, medium, medium, hard, hard, extreme
Letter6A and B (easy), C, D and E (medium), F (hard)
Symbol4star (hard), arrow (extreme), triangle (easy), heart (easy)
Shape2circle and square (medium)
Path2two paths, medium and hard

Because the set is built from one seed (42) in a fixed composition, "the same call gives the same book every time".

Use the set

  • Show it to a class to explain how plates grade from easy to extreme.
  • Compare how each plate behaves under the three deficiencies in the Lab, using CVD Preview.
  • Keep the seed: 42 always rebuilds the same set.
