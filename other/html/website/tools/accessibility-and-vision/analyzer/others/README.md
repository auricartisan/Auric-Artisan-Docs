# Analyzer: supporting material — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| --- | --- |

| [shortcuts.html](shortcuts.html) | The keys the Analyzer responds to, in the URL field, the Sections picker, the workspace panels and the token meter. |
| [glossary.html](glossary.html) | Plain-language definitions of the terms used in the Analyzer and its documentation. |
| [limits-and-accuracy.html](limits-and-accuracy.html) | What the Analyzer measures, how precisely, which pages it can reach, and what its results are not. |
| [privacy.html](privacy.html) | What the Analyzer keeps in your browser, what it sends to Auric Artisan's servers or third parties, and how to delete it. |
| [release-notes.html](release-notes.html) | User-facing history of the Analyzer, from the public changelog and the current page. |
| [related.html](related.html) | Other Auric Artisan tools, extensions and articles that work well with the Analyzer. |
