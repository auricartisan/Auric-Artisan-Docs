# Contrast Checker documentation — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | The list of Contrast Checker guides with one line on each. |

| [check-a-colour-pair.html](check-a-colour-pair.html) | Enter a text and background colour, read the WCAG 2.1 ratio, and work out which of the five grades applies to what you are colouring. |
| [make-a-pair-pass.html](make-a-pair-pass.html) | Use Make it pass AA to find a passing text colour, understand how it chooses, and keep your brand hue. |
| [share-a-pair.html](share-a-pair.html) | Share or bookmark a colour pair as a link, and the ways other parts of the site open the checker. |
| [reference.html](reference.html) | Every control, input, threshold, output, message and keyboard behaviour of the Contrast Checker. |
| [troubleshooting.html](troubleshooting.html) | Odd results in the Contrast Checker, why they happen, and what to do. |
| [faq.html](faq.html) | Short answers to common questions about the Contrast Checker and colour contrast. |
