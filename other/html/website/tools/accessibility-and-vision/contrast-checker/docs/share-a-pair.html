Share a pair

Share or bookmark a colour pair as a link, and the ways other parts of the site open the checker.

The Contrast Checker keeps no history. The page address is the only place a pair is kept, and it is always up to date.

The address is the state

Each time the checker re-grades, it rewrites the address with the current pair, without the #:

https://auricartisan.com/tool/contrast-checker/?fg=1A1400&bg=F7F3E6

fg is the text colour and bg the background. Open that address and the checker restores both colours and grades them at once. Bookmark it, or paste it into a pull request, a bug report or a design review.

Copy link

  1. Set up the pair you want to share.
  2. Select Copy link.
  3. The status line says "Share link copied." Paste the link where you need it.

If your browser does not allow clipboard access (for example on an insecure connection, or after you declined the permission), the full address is printed in the status line instead, so you can select and copy it by hand.

Partial links

Only values that are valid hex are used. A link with ?fg=D3AF37 and nothing else sets the text colour and leaves the background at the default. Site search uses exactly this when its answer is about a single colour, and sends both values when its answer is about a pair.

Two things the address does not do

  • It does not add history entries. The address is replaced, not added to, so your browser's Back button will not step through the colours you tried. Copy a link at the time if you want a pair back later.
  • It does not reload the page. The update is silent and happens a moment after you stop typing.

Ways into the checker

FromWhat it opens

Your dashboardThe Contrast entry in the launcher row
Learn articles about contrastThe checker from the article's call to action

What is kept

Nothing. There is no saved history, no library of pairs and no account state. If a result matters, copy its link before you move on. There is nothing to clear, and nothing leaves your device.
