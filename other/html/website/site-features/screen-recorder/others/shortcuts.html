Screen recorder shortcuts

Keyboard shortcuts for the screen recorder.

KeysAction
Alt + Shift + ROpen the recorder; while recording, stop and save
Alt + Shift + PPause or resume a recording
EscClose the dialog, recordings list or player; cancel the region picker
Arrow keys on the dialog gripMove the dialog; hold Shift for finer steps

Alt + Shift was chosen to avoid browser shortcuts: Ctrl + Shift + R is your browser's hard reload. The full list is in Keyboard shortcuts.
