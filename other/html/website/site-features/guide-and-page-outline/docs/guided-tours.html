Guided tours

Take a guided tour of any page, move through its stops, leave, resume, replay and skip.

A guided tour walks through the important areas of the page you are on. Each stop highlights one area and explains it in a small card beside it.

Start a tour

  1. Press ? to open the guide.
  2. The tour card at the top reads Take the guided tour, with the number of stops, for example "11 stops · leave at any point".
  3. Select it (its action reads Start the tour).

To start at a particular stop, select that stop under On this page or Getting around.

The tour card

What it showsWhen
Take the guided tour — "N stops · leave at any point"You have not taken this page's tour
Pick up where you left off — "You stopped at X of N · leave at any point", action Resume at stop XYou left this page's tour part-way
Replay the tour — "N stops on this page · you have finished this one"You finished this page's tour
Start over from stop 1 (below the card)You left part-way and want the whole tour again

A progress bar on the card shows how much of the tour you have seen. Progress is kept for each page separately.

If a page has nothing to tour, the guide says "This page has no tourable sections yet, but the paths below will still help you move around."

Move through a tour

The highlighted area is outlined on the page, which scrolls to bring it into view. The card beside it shows:

  • a rail of dots, one per stop;
  • the position, for example "3 of 11", and whether the stop is about this page or the whole site;
  • the stop's title and explanation;
  • sometimes a note;
  • What to look for: a list of details you can open.

Controls:

ControlKeyWhat it does
NextRightNext stop
BackLeftPrevious stop (unavailable on the first stop)
Finish—On the last stop, ends the tour and marks it finished
X (Leave the tour)EscLeaves the tour; your place is remembered
Skip to this page’s N stops—Shown on the site-wide stops at the start, to jump to the stops about this page

While the tour is running, Tab stays inside the tour card.

The stops every page shares

Every tour includes a few stops about the site itself, the same everywhere:

  • Start from the top — the header;
  • Search when the path is unclear — search and Ctrl + K;
  • Keep useful work close — your library and workspace;
  • Match the viewing mode — the theme button;
  • Use footer links for trust and support — the footer.

Once you have seen them, the guide folds them away under Getting around, and Skip to this page’s N stops lets you pass them.

When an eye rest appears

A tour is hidden while an eye rest is on screen, and reappears afterwards.
