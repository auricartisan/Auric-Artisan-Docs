Get started with the guide

Open the page guide, learn its sections, and filter it.

Open and close the guide

  • Open: press ?, select Guide in the header, tap Guide in the mobile drawer, or choose Open the page guide in Spotlight's commands.
  • Close: press Esc, select the X (Close guide) or the ESC button beside the filter box, or click outside the panel.

The guide opens only when you ask for it. It never opens by itself when you visit a page.

While the guide is open, Tab stays inside it.

The panel

From top to bottom:

  1. What this page is. A kicker naming the kind of guide (for example Home guide, Analyzer guide, Collections guide, Search guide, Workspace guide, Library guide, Tool guide, Company guide, Policy guide or Site guide), the page's title, and a one-sentence summary.
  2. Filter box. Type to narrow everything below. The placeholder reads "Filter this guide…".
  3. Tabs. All, Tour, Tools, Pages, Learn and Help. Each shows only that kind of item. With a tab focused, Left and Right move between tabs.
  4. Tour card. Starts, resumes or replays the guided tour of this page, with a progress bar (see Guided tours).
  5. On this page. The tour's stops for this page, numbered. A tick marks stops you have already seen. Select a stop to start the tour there.
  6. Getting around. The stops that are the same on every page (the header, search, your library, the theme button), folded under "The same stops on every page" with a count such as "2/4 seen". Once you have seen them all, the group starts folded.
  7. Elsewhere. Quick links: Full Search, Analyze a website, Find the right tool, Open saved work, Read documentation, Learn color concepts, Install the PWA and Install the extension.
  8. Recommended paths. Short recipes for common jobs: Run a quick audit, Build color assets, Check accessibility and Find a feature fast, most with numbered steps.
  9. Footer hints. Type to filter, ↑ ↓ navigate, ↵ open, ESC close.

Find something in the guide

  1. Open the guide and type a word, for example export.
  2. Only matching items remain. If nothing matches: "Nothing in the guide matches that. Try a shorter word, another tab, or clear the box."
  3. Press Down to move to the first result, then Enter to open it. Pressing Enter in the filter box opens the top match directly.

Home and End jump to the first and last item (when the filter box is not focused).
