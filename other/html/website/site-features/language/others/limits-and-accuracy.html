Language limits and accuracy

How complete the Hindi translation is and what to expect from it.

  • Coverage. The site's interface and page text are translated across the site. A small number of strings stay in English: terms that are international (such as CIELAB or OKLCH-style colour notations), third-party names, code, and some messages built from several live values.
  • Emphasis. Where an English heading has part of it styled differently (for example in italics), the Hindi heading may show it as plain text.
  • Layout. Hindi text can be longer or shorter than English. Lines use slightly taller spacing to keep Devanagari marks clear.
  • Search. Page search matches English text.
  • Technical terms. Names used internationally, such as CIELAB, xyY or Bradford, are kept in Latin letters so they match the literature and other tools.
