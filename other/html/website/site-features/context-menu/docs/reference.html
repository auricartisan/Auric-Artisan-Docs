Right-click menu reference

Every part, action, shortcut, preference and message of the site's right-click menu.

Ways to open

MethodOpens
Right-click (not in a text field)The menu for what is under the pointer
Shift + right-clickThe browser's menu (or the site menu, if you made the browser's menu the default)
Rest the pointer on the gold line at the right edgeThe menu for the page, beside the line
Menu key or Shift + F10The same as a right-click

Browser’s own menuBrowser—⇧ + right-click

The shortcut column shows what the menu displays on each row. The navigation shortcuts, Ctrl + P, F5, F11, Ctrl + C and the click combinations are your browser's own; the menu shows them as reminders.

Footer hints

↑↓ move · ↵ run · → submenu · star pin. After an action, the hints are replaced for about two seconds by a confirmation with a tick.
