Get started with the right-click menu

Open the site's right-click menu, learn its parts, and run your first actions.

Open the menu

  • Right-click anywhere on a page, except inside a text field, a drop-down or an editable area. Those keep your browser's menu so that spelling suggestions, paste and similar options still work.
  • Hover the right edge. A short, thin gold line sits halfway down the right edge of the window. Rest your pointer on it for a moment and the menu opens beside it, showing the actions for the page. Move away and it closes.
  • Keyboard. The menu key, or Shift + F10 on many keyboards, sends a right-click to the page and opens the same menu.

To get your browser's menu instead, hold Shift while you right-click.

The parts of the menu

From top to bottom:

  1. Header. An icon and two lines that describe what you clicked:
    • the kind (Page, Link, Image, Selection or Colour) and a detail, such as the page address, "This site" or "Another site" for a link, the pixel size and file type of an image, the word and character count of a selection, or the RGB value of a colour;
    • a label: the page title, the link address, the image file name, the quoted selection, or the colour's hex code. For a colour, the icon is a swatch of that colour.
  2. Quick bar. A row of one-click buttons, each with an icon and a short label. By default: Back, Forward, Reload, Home and Copy URL. Hover a button to see its full name and shortcut.
  3. Filter field. It reads "Type to filter N actions", where N is the number of actions available for what you clicked. It has keyboard focus as soon as the menu opens.
  4. Website update banner (only sometimes). When a newer version of the site is ready, a highlighted row such as Update available appears here.
  5. The list.
    • First, the actions for what you clicked, under This page for a page (the group heading is hidden in the default layout).
    • Then More: one row per group — Page (not shown when you clicked the page itself, whose actions are already listed), Colour tools, View and Site. Each row shows how many actions it holds. Hover it, or press the Right arrow, to open its submenu.
    • Last, Browser’s own menu.
  6. Footer. Hints for the keys (↑↓ move, ↵ run, → submenu, the star to pin) and the gear button, Customise this menu. After an action such as pinning, the hints briefly give way to a confirmation.

Every action row has a star at its right-hand end. Select it to pin that action to the quick bar.

Try it

  1. Right-click an empty part of the homepage. The header reads Page with the page's address and title.
  2. Hover View under More. The View submenu opens to the side.
  3. Select Scroll to bottom. The menu closes and the page scrolls to the end.
  4. Right-click a link in the footer, such as Privacy. The header reads Link · This site with the link's address.
  5. Select Copy as Markdown. A message confirms "Markdown link copied". Paste it into a document: it reads [Privacy](https://auricartisan.com/legal/privacy/).

Close the menu

The menu closes when you run an action, press Esc, click anywhere outside it, scroll the page, resize the window or switch to another window. Scrolling inside the menu does not close it.
