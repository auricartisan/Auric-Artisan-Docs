Right-click menu FAQ

Short answers to common questions about the site's right-click menu.

Can I turn the site menu off?

Yes. Right-click, select the gear, and under Right-click on this site choose The browser’s menu. The site menu is then available only with Shift + right-click or from the line at the right edge of the window.

Does the menu work on phones and tablets?

A long press on a touch screen is handled by the browser and usually opens the browser's own menu or text selection. The site menu is designed for a mouse, trackpad or keyboard.

Where do Search the web and Translate send my text?

Only where you ask. Search the web opens the search engine you pick in a new tab with the selected text in the address. Translate opens Google Translate in a new tab. Nothing is sent until you choose one of them.

Is my quick bar the same in every browser?

No. Pins and preferences are kept in the browser you set them in.

Why does the same menu look shorter on some pages?

Some rows depend on what the page loads. Published portfolio pages, for example, have no colour tools and remove some site actions, so their menu is shorter.

Is the browser extension's menu the same thing?

No. The Auric Artisan browser extension has its own right-click menu for other websites. On auricartisan.com the extension steps aside and the site's own menu is the one you see. See Browser extension.

Can I see the colour formats before copying?

Yes. Each colour copy row shows the exact value it will copy.
