Filter and keyboard

Find any action by typing, and use the right-click menu entirely from the keyboard.

Find an action by typing

The filter field below the quick bar has keyboard focus as soon as the menu opens, so you can start typing straight away.

  1. Right-click the page.
  2. Type part of an action's name, for example mark.
  3. The list is replaced by matching actions from every group, submenus included, each tagged with the group it belongs to (for example Page or Link). The field shows how many matched, for example "2 of 27".
  4. The first match is highlighted. Press Enter to run it, or use the arrow keys to choose another.

How matches are found:

  • The filter matches the action's name, the name of its group, and a few extra words for some actions. For example, dark or light finds Switch theme, audit or seo finds Analyze this page, and colors finds Copy its palette.
  • Names that start with what you typed are listed first, then names that contain it, then matches on the extra words.
  • Up to 12 results are shown.
  • If nothing matches, the list reads "No actions match" followed by your text.

Typing works from anywhere in the menu: if a row has focus and you type a letter, it goes into the filter. Press Esc once to clear the filter.

Keyboard reference

KeysWhat they do
Letters and digitsType into the filter
Down from the filterMove to the highlighted result or the first action
Up / DownMove between rows and quick-bar buttons; the list wraps round
Up from a quick-bar buttonReturn to the filter field
Right on a group rowOpen its submenu and move into it
Right on an action rowMove to that row's pin star
Left on a pin starMove back to its row
Left or Esc in a submenuClose the submenu and return to its group row
Enter or SpaceRun the focused action, open a focused group, or toggle a focused star
Enter in the filterRun the highlighted result
EscClose a submenu; otherwise clear the filter; otherwise close the menu
Esc in the preferences viewReturn to the action list

When the menu closes, keyboard focus goes back to where it was before you opened it.

Mouse behaviour

  • Hovering a group row opens its submenu after a short pause. Moving to another row closes it.
  • Submenus open to the right of the menu, or to the left when there is no room.
  • Selecting a group row also opens its submenu.
