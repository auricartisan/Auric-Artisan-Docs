Split view shortcuts

Keyboard shortcuts for split view.

KeysAction
Ctrl + Shift + DOpen or close split view
EscClose an open More menu; otherwise close split view
Alt + 1Focus the live pane
Alt + 2Focus the companion pane
Alt + VSide by side or stacked
Alt + SSwap panes
Alt + EEqual split
Alt + click on a linkOpen the link in the other pane; with split view closed, open split view with it
Enter in an address barLoad the address or highlighted destination
Ctrl + Enter in an address barOpen the typed address in a new browser tab
Esc in an address barClose the destination list, then restore the address

See Keyboard shortcuts for the whole site.
