The desktop header

Use the Company, Tools and Learn menus and the quick-tools icons in the header on wide screens.

On windows 960 pixels wide or more, the header shows everything in one row: the brand, three menus, the quick-tools icons and Sign in.

The brand

Auric Artisan with the tagline Colour intelligence studio. Select it to return to the homepage.

The three menus

Select Company, Tools or Learn to open a menu below it. Each entry has a picture or icon, a name and a one-line description. Only one menu is open at a time.

How the menus behave

  • A menu opens below its button, or above it if there is not enough room below. It lines up with the right edge of its button, or the left edge near the side of the window.
  • A tall menu scrolls inside itself. A SCROLL DOWN hint shows while there is more to see.
  • Selecting an entry opens that page. Clicking anywhere outside the menu, or moving keyboard focus out of it, closes it.

With the keyboard

Home / End inside a menuFirst or last entry
EscClose the menu and return focus to its button

The theme button shows a moon while the page is light (select it to go dark) and a sun while the page is dark. Its behaviour is explained in Theme. The globe is explained in Language.

Sign in

Sign in opens the sign-in page, where you can also create a free account. Once you are signed in, the button is replaced by your account menu. Accounts are covered in Account and billing.

When the header scrolls

The header stays pinned to the top of the window as you scroll. In reading mode it scrolls away with the page, to leave more room for text.
