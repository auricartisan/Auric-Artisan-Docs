Header and navigation shortcuts

Keyboard shortcuts for the header menus, the drawer and the tools the header opens.

Menus and drawer

KeysAction
Enter / Space on a menu buttonOpen or close the menu
Down / Up on a menu buttonOpen the menu at its first or last entry
Down / Up in a menuNext or previous entry
Home / End in a menuFirst or last entry
EscClose the open menu, or else the drawer

Tools the header opens

KeysOpens
Ctrl + K (Cmd + K on a Mac)Spotlight search
?The page guide
Ctrl + Shift + LThe Library Kit
Alt + TSwitch theme (Light, Dark, System)
Ctrl + ,The Settings panel
EscClose the page utilities bar

See Keyboard shortcuts for the full list.
