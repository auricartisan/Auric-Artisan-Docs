Custom cursor glossary

Terms used in the custom cursor guides.

TermMeaning
System pointerThe mouse pointer drawn by your operating system.
RingThe outer part of the custom cursor that changes shape.
DotThe small inner point of the custom cursor, where clicks land.
HoverResting the pointer over something without clicking.
Reduced motionA device setting that asks apps and websites to limit animation.
Adaptive colourThe ring's colour, chosen from the surface under it so it stays visible.
