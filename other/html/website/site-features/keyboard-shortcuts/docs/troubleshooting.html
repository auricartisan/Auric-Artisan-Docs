Troubleshooting keyboard shortcuts

Why a site shortcut might not work, and what to do.

A shortcut does nothing

Possible causes and fixes:

  • You are typing in a field. Alt letter shortcuts and ? are ignored in text fields. Click an empty part of the page, or press Esc to leave the field, then try again.
  • The page is still loading. Most panels load a moment after the page. Wait, then try again.
  • The feature is not on this page. A few simple pages (for example sign-in pages) do not load every panel.
  • Another panel has focus. Some panels use keys for themselves while open; close the panel first.

The browser did something else instead

Why: browsers and operating systems reserve some combinations. For example, Ctrl + Shift + D can bookmark all tabs, Ctrl + Shift + A can search tabs, and Cmd + M minimises a window on a Mac. The site claims its shortcuts where the browser allows it, but some browsers keep certain combinations for themselves.

What to do: use the on-screen control instead (the navigation dock for split view, the page utilities bar for kits and Settings).

? does not open the guide

Why: on some keyboard layouts, ? needs a modifier the site does not accept, such as Alt Gr.

What to do: use the Guide button in the header.

Alt shortcuts open the browser's menu bar

Why: in some browsers on Windows, pressing and releasing Alt alone moves focus to the menu bar.

What to do: hold Alt while pressing the second key; the site's shortcut takes effect.

Alt + + does not enlarge text

Why: on many keyboards + needs Shift.

What to do: press Alt + = instead, which does the same.
