Keyboard shortcut reference

Every keyboard shortcut on the Auric Artisan website, grouped by where it works.

"Ctrl or Cmd" means Ctrl on Windows, Linux and ChromeOS, and Cmd on a Mac. On a Mac, Alt is the Option key.

Anywhere on the site

KeysActionNotes
Ctrl + K (Ctrl or Cmd)Open or close Spotlight searchSearch and Spotlight
Ctrl + , (Ctrl or Cmd)Open or close SettingsSettings panel
?Open the page guideGuide and page outline
Alt + RReading mode on or offNot while typing
Alt + TTheme: Light, Dark, SystemNot while typing
Alt + + (or Alt + =)Text one size largerNot while typing
Alt + -Text one size smallerNot while typing
Alt + 0Default text sizeNot while typing
Alt + MReduced motion on or offNot while typing
Ctrl + Shift + DOpen or close split viewSplit view
Alt + click a site linkOpen split view with that page—
Alt + Shift + ROpen the recorder; while recording, stop and saveScreen recorder
Alt + Shift + PPause or resume a recording—
Ctrl + Shift + UCheck for and apply a website updateKits (Update Kit)
Ctrl + Shift + COpen the colour tools menu (with a selected hex code, if any)Uses Shift, so it is not the browser's copy
Shift + right-clickYour browser's right-click menu (or the site's, if you swapped them)Context menu
EscClose the open panel, menu, dialog or bar—

Kits

KeysAction
Ctrl + Shift + K (Ctrl or Cmd)Open or close the Feature Kit
Ctrl + 1 to Ctrl + 6 inside the Feature KitCalculator, Converter, Feedback, Notes, Date and time, Developer tools
Ctrl + M (Ctrl or Cmd)Open the Menu Kit
Ctrl + Shift + A (Ctrl or Cmd)Open or close the Advanced Kit
Ctrl + Shift + L (Ctrl or Cmd)Open or close the Library Kit
Ctrl + K inside an open Menu Kit or Status KitJump to the kit's own search field

EscClose the page utilities bar

Header menus and drawer

KeysAction
Enter / Space on Company, Tools or LearnOpen or close the menu
Down / Up on a menu buttonOpen at the first or last entry
Down / Up / Home / End in a menuMove between entries
EscClose the menu, then the drawer
First Tab on a pageShow Skip to main content

Spotlight

KeysAction
Up / DownMove through results

Settings panel

KeysAction

Right-click menu

KeysAction
TypeFilter actions
Up / DownMove

Guide and tours

KeysAction
Up / Down / Home / EndMove through the guide
EnterOpen the focused item or top match
Left / Right on a tabChange tab
Right / Left in a tourNext or previous stop

Split view

KeysAction
Alt + 1 / Alt + 2Focus the live or companion pane
Alt + VSide by side or stacked
Alt + SSwap panes
Alt + EEqual split
Enter / Ctrl + Enter in an address barLoad, or open in a new tab

KeysAction
