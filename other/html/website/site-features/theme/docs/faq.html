Theme FAQ

Short answers about the site's themes.

Is there a high-contrast theme?

There is no separate theme, but Settings › Comfort › Boost contrast strengthens text and borders in both themes. See Accessibility aids.

Does the theme change colours in the tools?

No. The theme changes the site's interface. Colours you are working with, swatches and images are shown as they are.

Does my account remember my theme?

The site theme is kept in your browser, not in your account. Your account dashboard has its own theme preference; see Account and billing.

Can I set a different theme for one kit?

Yes. Use the sun or moon button in that kit's title bar. It affects only that kit.

Why does the page not flash when it loads?

The site reads your saved theme before it draws the page, so it starts in the right theme.
