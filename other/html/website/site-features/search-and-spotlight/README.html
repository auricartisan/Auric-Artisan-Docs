Search and Spotlight

Spotlight, the site-wide search palette opened with Ctrl + K, with scopes, colour answers, filters and commands.

Spotlight is the search box that floats over any page when you press Ctrl + K (Cmd + K on a Mac) or select Search in the header. Type a few letters and it lists matching pages, tools, documentation and Learn articles from across the site, with a preview of the highlighted result and the reasons it ranked there. Tabs narrow the search to Pages, Tools, Docs or Learn, and a Web tab searches trusted sources beyond the site.

Spotlight also answers some questions directly. Type a hex colour such as #2f5eaa and it shows that colour's values and its contrast on black and white. Type two hex colours and it judges them as a text-and-background pair against WCAG. Type > and it becomes a command palette that can switch the theme, open the guide, the library or Settings, switch language, and more.

For a larger results page with filters, Spotlight hands your query to the full search page at https://auricartisan.com/search/, which is documented in Search.

Who it is for

  • Anyone looking for a tool, article or page without browsing the menus.
  • Keyboard users who want to reach site actions without the mouse.
  • Designers who want a quick reading of a colour or a colour pair.

Where to find it

  • Press Ctrl + K (Cmd + K) on any page.
  • Select the magnifier (Search) in the header, or Search on a narrow screen.
  • In the mobile drawer, tap Search tools, colours and pages.
  • Right-click the page and choose Site, then Search the site.

Quick start

  1. Press Ctrl + K. Spotlight opens with your recent searches and a list of Quick Actions.
  2. Type gamut. Results appear as you type, with matching words highlighted.
  3. Press Down to move through the results. The preview on the right shows each one.
  4. Press Enter to open the highlighted result, or Ctrl + Enter to open it in a new tab.
  5. Press Ctrl + K again and type #d3af37. The preview shows the colour, its RGB value and its contrast on black and white.
  6. Clear the box, type >, and choose Toggle light and dark.
  7. Press Esc to clear the box, and Esc again to close Spotlight.

What you can do

  • Search the whole site, or only pages, tools, documentation or Learn articles.
  • Search trusted sources on the wider web.
  • Re-run recent searches.
  • Read a colour's values and contrast, or check a colour pair against WCAG, straight from the search box.
  • Use field filters such as title: and path:.
  • Run site commands with >.
  • Open the full search page for more results and filters.
