Spotlight glossary

Terms used in the Spotlight search guides.

TermMeaning
SpotlightThe floating search box opened with Ctrl + K.
ScopeThe part of the site a search covers: All, Pages, Tools, Docs, Learn or Web.
LauncherA shortcut row shown when the search box is empty.
IndexThe list of the site's pages and their words that Spotlight searches.
Preview paneThe panel beside the results showing details of the highlighted result or a colour answer.
Field filterA prefix such as title: that limits a search to one part of each page.
ExclusionA word with a minus sign in front, such as -gradient, which removes matching pages.
Command modeThe mode entered by typing >, which lists actions instead of pages.
Contrast ratioThe WCAG measure of lightness difference between two colours, from 1:1 to 21:1.
AA, AAAWCAG contrast levels: AA body text needs 4.5:1, AAA needs 7:1, AA large text needs 3:1.
OKLCHA way of writing a colour as lightness, chroma and hue that follows human perception closely.
