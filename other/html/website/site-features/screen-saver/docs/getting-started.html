Get started with the screen saver

Turn the screen saver on, choose when it starts, and return to the page.

Turn it on

  1. Press Ctrl + , to open Settings, then select Comfort.
  2. Switch on Screen saver ("Ambient animation after long periods of inactivity.").
  3. Under Start after (minutes of inactivity), select 1m, 5m, 10m, 20m or 30m. The default is 10m.

When it starts

The screen saver starts when the page has had no mouse movement, click, key press, scroll, touch or wheel movement for the time you chose. The site checks every ten seconds, so it can start up to about ten seconds after the time is reached.

It counts activity on this page only. Time spent in other tabs or apps counts as idle time for this page, so the screen saver may already be showing when you come back to the tab.

Return to the page

Do any of these: move the mouse, click, press a key, scroll, use the wheel, or touch the screen. The page comes back as you left it.

A hint, Move to return, shows at the bottom of the screen saver for its first minute, then fades.

Turn it off

Switch off Screen saver in Settings › Comfort. If it is showing at that moment (for example in another window you can see), it closes at once.
