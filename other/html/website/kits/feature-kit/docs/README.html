Feature Kit guides

Contents of the Feature Kit guides, one per tool, plus the full reference, troubleshooting and FAQ.

These guides cover each of the Feature Kit's six tools, the calculator's complete function list, and every control in the kit. Start with Getting started if you have not opened the kit before.

FileWhat it covers
getting-started.mdOpen the kit, tour the menu and the title bar, and run a first calculation
calculator.mdKeypad modes, the expression bar, results, RAD and DEG, memory and history
calculator-functions.mdEvery operator, function and constant, variables, your own functions, calculus, statistics and programmer features
graphing.mdPlot a function, pan, zoom and reset the graph
unit-converter.mdConvert values between units and search the unit list
notes.mdWrite, preview, copy, export and delete Markdown notes
date-and-time.mdCalendar readouts, date differences, adding and subtracting, and world clocks
developer-tools.mdJSON, Base64, URL, Hash, UUID, JWT, Epoch, Regex, Cron, Text and HTML tools
feedback.mdSend quick or detailed feedback, and what happens if sending fails
reference.mdEvery button, tab, field and message in the kit
troubleshooting.mdProblems and how to fix them
faq.mdShort answers to common questions

Shared controls such as moving, Focus mode and theme are explained in Panel controls.
