Feature Kit shortcuts

Every keyboard shortcut the Feature Kit responds to, from opening the kit to typing on the calculator keypad.

The kit's menu shows ⌘ instead of Ctrl on a Mac. Where a shortcut below uses Ctrl, use Cmd on a Mac.

Open, close and move around

ShortcutWhereWhat it does
Ctrl + Shift + KAnywhereOpens or closes the kit. With Focus mode on, moves focus into the open kit instead of closing it
EscKit openIn a tool, returns to the menu. On the menu, closes the kit
1 to 6MenuOpens Scientific Calculator, Unit Converter, Feedback, Notes, Date & Time, Developer Tools
Ctrl + 1 to Ctrl + 6Focus inside the kitSwitches straight to that tool, even from inside another tool or a text box
Arrow keys, Home, EndMenuMove between the six cards
Enter or SpaceA focused cardOpens that tool
Left arrow, Right arrow, Home, EndA focused title-bar buttonMove between the title-bar buttons
Tab, Shift + TabKit open, Focus mode offMove between the kit's controls; focus stays inside the kit
Enter or SpaceMinimised kit iconReopens the kit

Browsers commonly use Ctrl + a number to switch browser tabs and may act on it before the Feature Kit does. If that happens, use the plain number keys on the menu instead.
