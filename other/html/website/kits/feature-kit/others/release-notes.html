Feature Kit release notes

What the public changelog records about the Feature Kit, and what the kit contains as of September 2026.

The website's public release history is at https://auricartisan.com/library/changelog/ and https://auricartisan.com/company/timeline/. It records site releases as a whole and does not list the Feature Kit by name. This page lists the entries that concern the kits, and describes the Feature Kit as it is today.

The Feature Kit as of 24 September 2026

  • Six tools behind one menu: Scientific Calculator, Unit Converter, Feedback, Notes, Date & Time and Developer Tools.
  • A calculator with Basic, Scientific and Programmer keypads, an expression bar with variables, user-defined functions, statistics, number theory, physical constants and numerical calculus (diff, diff2, integral, solve, sum, product), exact-fraction hints, a function reference panel, a graph and a 100-entry history.
  • A Unit Converter with 70 categories and 1,344 units.
  • Notes with several Markdown notes, preview, copy and .md export.
  • Date & Time with Calendar, Difference, Add / Subtract and Timezones tabs.
  • Developer Tools with JSON, Base64, URL, Hash, UUID, JWT, Epoch, Regex, Cron, Text and HTML tabs.
  • Quick and detailed feedback that is kept on your device until it has been delivered.
  • Shared kit controls: Focus mode, per-kit theme, Resize, Minimize and Close, and a labelled Feature launcher in the page utilities bar.

Changes not recorded in the public history are not listed here.
