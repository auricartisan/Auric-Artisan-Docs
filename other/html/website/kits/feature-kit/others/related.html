Related to the Feature Kit

Kits, tools and pages related to the Feature Kit.

Other kits

  • Advanced Kit — its mode decides which calculator keypads you see.
  • Library Kit — for palettes, gradients and reports you save from the site's tools. (Feature Kit notes and calculations are not saved there.)
  • Menu Kit — jump to any tool on the site.
  • All kits and Panel controls.

Tools with related features

  • Basic Colour Tools — colour format conversion, which the Unit Converter does not cover.
  • Colour Science Lab — colour maths such as colour-space conversion and colour difference.
  • Design Engine — spacing, type and colour tokens, if you are converting units for a design system.

Site features

  • The site-wide search (Ctrl + K), settings (Ctrl + ,) and the site-wide feedback prompt: Site features.

  • Help — contact and support.
