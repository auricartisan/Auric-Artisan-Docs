Build a custom tool set

Use Custom mode in the Advanced Kit to tick exactly the tools you want the site to list.

In Custom mode you decide tool by tool what the site lists. Unticked tools disappear from the Menu Kit and from the tool collections, on every page of the site.

Open the checklist

  1. Open the Advanced Kit.
  2. Select the Custom card under Default visibility.

A section called Choose your tools appears below the cards. The first time, it shows Loading tools… while it gathers the list. Every tool starts ticked.

The checklist

  • Tools are grouped by category, for example Accessibility, Colorimetry, Generators, Perception, Spectral and Utilities, with categories in alphabetical order and tools in alphabetical order within each.
  • The list covers the site's tool pages only. Account, library, company and legal pages are not in it and always stay visible.
  • Some names differ slightly from the Menu Kit, because the checklist uses the collections' names where it can. For example the URL Analyzer appears as Analyze URLs and the Ishihara plate tool as Generate Ishihara Plates.

Turn tools on or off

  1. Untick a tool to hide it. The change applies at once, across the site.
  2. Tick it again to show it.

There is no save button.

Find a tool in the list

Type part of a name in Filter tools…. Rows that do not match hide, and categories with no matching rows hide too. Clear the box to see the whole list.

Change many tools at once

ButtonWhat it does
Enable allTicks every tool in the list
Disable allUnticks every tool in the list
ResetForgets all your custom choices, so every tool is ticked again

Enable all and Disable all act on the whole list, not only the rows a filter is showing.

Where your custom set applies

In Custom mode, unticked tools are hidden from:

  • the Menu Kit's tiles and search results;
  • tool collections, such as https://auricartisan.com/collections/.

The tool pages themselves still open if you visit them directly or follow a link from elsewhere.

In Custom mode the Feature Kit calculator shows all three keypads, and page wording follows the Basic wording. See What each mode changes.

Your ticks are kept when you switch mode

Switching to Basic, Advanced or Everything does not delete your ticks. They take effect only while Custom is the current mode. Select Custom again to bring your set back.

Example: a palette-only set

  1. Select Custom.
  2. Select Disable all.
  3. Type basic in Filter tools… and tick Basic Tools.
  4. Clear the filter, type gradient and tick M-Gradient Palette.
  5. Clear the filter, type picker and tick Image Picker.
  6. Open the Menu Kit. The Tools tab shows Basic Color Tools alongside pages that are not individual tools, such as All Tools, Collections, Search and the portfolio pages. Image Picker and M-Gradient Palette appear under Utility Labs in the Design tab.
