Choose a mode

What the Basic, Advanced, Everything and Custom tool visibility modes mean, and how to switch between them.

The tool visibility mode is one site-wide setting with four values. It decides which tools the site lists for you. Every tool can still be opened from its own address in any mode.

The four modes

ModeCard descriptionSummary shown when active
Basic (Recommended)Beginner-friendly tools stay visible while deeper scientific tools are hidden.Advanced tools are hidden — "Science, research, and precision tools stay tucked away until you need them."
AdvancedScientific, diagnostic, and power-user tools stay visible while simple tools are hidden.Advanced tools are on — "Keep the scientific set visible, or open the full platform when you want more."
EverythingEvery tool stays available, including removed or not-yet-used cards.Everything is available — "Removed and not-yet-used tools come back while Everything is active."
CustomTurn individual tools on or off — your picks apply across the whole site.Your custom tool set is active — "Tick the tools you want — your picks apply across the menu and every tool grid, site-wide."

How tools are sorted into Basic and Advanced

Each tool is treated as basic, advanced or both:

  • Both tools show in every mode. They include the URL Analyzer, the Vision Deficiency Simulator, the Design System Generator, and all account, library, company and legal pages.
  • Basic tools are the everyday colour tools, such as Basic Color Tools, ASCII Art, Icon Library and the general colour tools.
  • Advanced tools are the scientific and diagnostic ones, such as the Color Science Lab, Colorimetry, Gamut and Rendering, Perception and Neuroscience, Spectral and Material tools, and the Utility Labs.

Basic mode shows basic and both tools. Advanced mode shows advanced and both tools. Everything shows all tools. Custom shows every tool except the ones you untick.

The full effect on each part of the site is in What each mode changes.

Switch mode

Select a card under Default visibility. The change is immediate and site-wide.

Or use the buttons in the mode summary, which offer the natural next step:

Current modeButtons
BasicSwitch to Advanced
AdvancedShow everything
EverythingUse Basic, Use Advanced
CustomShow everything

Which mode to pick

  • Start with Basic if you are new to the site or want palettes, gradients and pickers without the scientific tools.
  • Choose Advanced if you work with colorimetry, gamuts, spectral data or perception experiments.
  • Choose Everything when you are exploring, or cannot find a tool you know exists.
  • Choose Custom if you use a handful of tools regularly and want the menus to show only those. See Build a custom tool set.

Where the mode is stored

The mode is stored in your browser, not in your account. Each browser and device starts in Basic until you choose. Changing the mode in one tab updates your other open tabs of the site.

Other places that change the same setting

A few tools have their own mode switch that changes this same site-wide setting:

  • The URL Analyzer's Simple and Advanced modes set the site to Basic and Advanced. Opening the URL Analyzer also sets the site to one of these two to match its own mode.
  • The Vision Simulation lab's mode buttons, and resetting its filters, which sets Everything.
  • The Colour Science Lab's mode buttons.

After using one of them, the Advanced Kit shows the new mode.
