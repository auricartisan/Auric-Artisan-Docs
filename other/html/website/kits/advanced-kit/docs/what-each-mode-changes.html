What each mode changes

Every part of auricartisan.com that follows the tool visibility mode, from the Menu Kit and collections to page wording and the Feature Kit calculator.

The mode you pick in the Advanced Kit is read by several parts of the site. This page lists each one and what it does in each mode.

Menu Kit

The Menu Kit shows only the tools the mode allows, in its tiles and in its search results. A tab with nothing to show is hidden:

  • Basic: the Design tab disappears.
  • Advanced: the Design tab appears, and the General Color Tools section of the Tools tab is hidden.
  • Everything: every tab and page.
  • Custom: every page except unticked tools.

See Find a page.

Tool collections

Tool collection grids, such as the one at https://auricartisan.com/collections/, show only the tools the mode allows. In Everything mode they also bring back cards that were hidden, whether you hid them or the grid hid them because you had not used them. While you search a collection, every matching tool shows, whatever the mode.

See Collections.

Feature Kit calculator

The calculator's keypad tabs follow the mode:

  • Basic: only the Basic keypad.
  • Advanced: the Scientific and Programmer keypads; the Basic keypad is hidden.
  • Everything and Custom: all three.

The expression bar works the same in every mode. See Calculator.

In Custom mode, pages use the Basic wording.

When you switch mode, the wording changes on the page you are on straight away, with a short transition.

Note: The public changelog calls the part of the site that makes these wording changes the "UX Kit". It has no panel of its own; the Advanced Kit is how you control it.

What the mode never changes

  • No tool is locked. Every tool page opens from its address in every mode.
  • Your saved items in the Library Kit, your settings and your account are not affected.
  • The site-wide search is not filtered by the mode.
