Advanced Kit shortcuts

Keyboard shortcuts for the Advanced Kit.

ShortcutWhereWhat it does
Ctrl + Shift + AAnywhereOpens or closes the Advanced Kit
EscKit openCloses the kit
Tab, Shift + TabKit openMove between the mode cards, buttons, filter box and checkboxes
Enter or SpaceA mode cardSelects that mode
SpaceA tool checkboxTicks or unticks the tool

When the kit opens, keyboard focus goes to the card of the current mode.

See Kit keyboard shortcuts for the other kits.
