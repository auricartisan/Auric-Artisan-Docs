Library Kit troubleshooting

Fixes for Library Kit problems, from missing items and full storage to share links that are too large and sync failures.

For problems shared by every kit, see Troubleshooting kits.

My saved items are missing

Why: The library lives in your browser on this device. It is not in your account, so items saved in another browser, on another device, or in a private window are not here. Clearing this site's data in your browser also deletes the library.

What to do: Open the library in the browser where you saved the items. To move items, export them there (Export in the footer) and import the file here. There is no way to recover a library that was cleared without an export.

An item is not on the All tab

Why: It is archived, a filter is active, or you are searching.

What to do: Check the Archive tab, select Clear all under the toolbar, and clear the search box.

Saving is refused because of my plan

Why: Each plan allows a number of active saved items (archived items do not count): 20 on Apprentice, 500 on Artisan, 2,500 on Specialist and 10,000 on Industrial Pro. The message reads "Your plan keeps N saved projects, and you have M. Archive or delete one to make room, or upgrade for more."

What to do: Archive or delete items you no longer need, or change plan. See Account and billing.

"This browser has run out of room for saved projects"

Why: Browsers limit how much each site can store, whatever your plan. Images and plates take the most space.

What to do: Export the library as a backup, then delete or archive large items, or select Purge expired drafts in Settings > Storage. The Status Kit's Memory tab shows how full the site's storage is.

"Library storage is full. Some image data couldn't be saved."

Why: The item was saved, but its image did not fit in the remaining space.

What to do: Free space as above. For Ishihara plates saved with their settings, use Re-render & save image in the item's details, or Repair empty Ishihara plates in Settings > Storage, once there is room.

Selecting a tile opens the details instead of the tool

Why: The site cannot find a tool page that can load this item, so the kit shows its details instead.

What to do: Use the details to download the item, or try Open in another tool from its right-click menu.

"Too large to share"

Why: Share links carry the item inside the address and are limited to 6 KB of packed data. Audits, images and large presets exceed it.

What to do: Export the item as a file and send the file instead.

Only one file downloaded when I exported several items

Why: Browsers often ask before letting a page download several files, or block the extra downloads.

What to do: Allow multiple downloads for auricartisan.com when your browser asks, or export items one at a time. To get everything in one file, use Export in the footer.

"That file could not be imported."

Why: The file is not a Library Kit export, or it is damaged. Individual item files (from Export JSON) are not library backups.

What to do: Import a file made with Export in the footer or Export library in Settings, such as auric-library-backup.json.

Sync reports "Push failed"

Why: Common causes: the URL is wrong; the server rejected the method or token; or the server does not accept requests from other websites, which browsers require for sync to work.

What to do: Check the URL, Method and Auth bearer token; make sure the server allows cross-origin requests from https://auricartisan.com; then select Test now. The error text in Recent sync activity shows the server's reply.

"Sync is switched off"

What to do: Open Settings > Sync & auto-update and turn on Sync enabled.

Show archived items does nothing in the kit

Why: In the Library Kit, archived items always appear on the Archive tab only. The setting affects other library views.

What to do: Use the Archive tab.

A comparison shows "Couldn't load the image"

Why: The image could not be read, for example because it points to another website that does not allow it.

What to do: Compare items whose images were saved in the library itself.

Ctrl + Shift + L does nothing

Why: Another program or extension uses that combination.

What to do: Use Page utilities > Library or the Library button in the site header.
