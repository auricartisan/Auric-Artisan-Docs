Library Kit shortcuts

Every keyboard shortcut the Library Kit responds to.

The kit's own shortcut sheet (Keys in the footer) shows ⌘ for Mac. Where a shortcut below uses Ctrl, use Cmd on a Mac.

Open and close

ShortcutWhat it does
Ctrl + Shift + LOpens or closes the Library Kit, from anywhere on the site
EscCloses, in this order: an open menu or dialog, the Panel options menu, multi-select, the search text, then the panel

Search box

ShortcutWhat it does
> at the startSwitches to the command palette
Up arrow, Down arrowMove through commands (command palette)
EnterRuns the highlighted command (command palette)
Down arrowMoves to the first tile (normal search)
EscClears the search

Tiles

ShortcutWhat it does
Left arrow, Right arrowPrevious or next tile
Up arrow, Down arrowTile above or below; up from the first row returns to the search box
Home, EndFirst or last tile
Enter or SpaceRestores the item (selects it in multi-select)
DeleteAsks to delete the item
Ctrl + ASelects all items, while multi-select is on

Moving the panel

ShortcutWhereWhat it does
Arrow keysThe six-dot grip has focusMove the panel 12 pixels
Shift + arrow keysThe six-dot grip has focusMove the panel 1 pixel

Menus and dialogs

ShortcutWhereWhat it does
Up arrow, Down arrow, Home, EndPanel options menuMove between options
EnterName dialogs (rename, new collection, new project)Confirms
EscAny library dialog or menuCancels or closes it
Ctrl + EnterThe Save to Library dialog in a toolSaves
