Library Kit glossary

Terms used in the Library Kit guides.

Universal Library — Everything you have saved from the site's tools, kept in your browser.

Item (asset) — One saved thing, such as a palette, gradient, image, preset or audit. The kit's dialogs sometimes say "asset".

Type — What kind of item it is, such as Palette, Gradient, Plate or Analysis. Each type you have saved gets a tab.

Restore — Reopen an item in the tool that made it, with its data and settings.

Open in — Load an item into a different tool that accepts its type.

Collection — A folder of items. An item belongs to at most one collection.

Unfiled — Not in any collection.

Project — A type of saved item. The kit can create empty projects; some tools save their own.

Favourite — An item marked with a star; listed on the Favorites tab.

Archive — A holding area for items you want out of the way without deleting them.

Draft — Unsaved work a tool keeps in the library while autosave is on. Drafts expire after the Keep drafts for period.

Snapshot (backup) — A single JSON file containing your whole library, made with Export.

Share link — A web address that carries a copy of an item inside it, so anyone with the link can open it.

Sync destination — A web address you configure to receive copies of your library.

Transport — How a sync destination sends: webhook or http (to your URL), console or local (testing only).

Bearer token — A secret sent in the Authorization header so your server knows the request is yours.

Cross-origin request (CORS) — A request from one website to another. Your server must allow requests from auricartisan.com for sync to work.

NDJSON — Newline-delimited JSON: one JSON record per line.

ΔE2000 (Delta E 2000) — A standard measure of how different two colours look. Around 1 is barely noticeable.

Contrast ratio — How distinct two colours are in lightness, from 1:1 (identical) to 21:1 (black on white).

Heatmap — An image that colours each pixel by how much two images differ there.

Command palette — The list of commands you get by typing > in the search box.
