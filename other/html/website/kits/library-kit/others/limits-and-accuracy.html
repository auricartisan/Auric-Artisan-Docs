Library Kit limits

Storage, plan, sharing, sync, report and comparison limits of the Library Kit.

Storage

  • The library is kept in your browser's storage for auricartisan.com. Browsers typically allow a site only a few megabytes of this kind of storage, whatever your plan, and images use it fastest.
  • Images saved from some tools are reduced before storing, so what you download from the library can be smaller than what the tool produced. Export from the tool itself for full-size output.
  • The storage figure in the footer and in Settings > Storage is an estimate of the library's own use.

Plan allowance

PlanActive saved items
Apprentice20
Artisan500
Specialist2,500
Industrial Pro10,000

Archived items do not count. Editing an existing item is always allowed, even at the limit. The figures are from https://auricartisan.com/company/pricing/, which is authoritative if they differ.

Share links

  • Limited to 6 KB of packed data per link.
  • The link contains a copy of the item at the moment you shared it; later changes are not reflected.

Sync

  • Runs only in an open page of the site; nothing is sent while the site is closed.
  • Automatic pushes run no more often than every 15 seconds, whatever interval you choose.
  • The receiving server must accept cross-origin requests from auricartisan.com.
  • The console and local transports are for testing and do not send anything off your device. The local log is lost when the page reloads.

Reports

  • Reports describe the library at the moment you download them.
  • The tool report covers one tool at a time.

Comparisons

  • Palette matching pairs each colour with its closest counterpart, so reordering colours does not count as a change.
  • ΔE2000 values are computed from the stored colour values in sRGB; they indicate visible difference under standard viewing conditions and are not a certified measurement.
  • Contrast ratios follow the usual relative-luminance formula used by accessibility guidelines.
  • The image heatmap compares copies scaled to at most 800 pixels a side, and only the overlapping area of different-sized images.

Details and downloads

  • Saved option values lists up to 120 settings.
  • Formats an item cannot provide are marked unavailable.
