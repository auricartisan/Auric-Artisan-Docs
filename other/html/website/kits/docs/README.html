Guides for all kits

Contents of the shared kit guides, which cover the launcher bar and the panel controls every kit uses.

This folder covers what the kits have in common: how to open them, the page utilities bar that launches them, and the title-bar controls that move, resize, minimise, theme and close every panel. Guides for a single kit live in that kit's own folder.
