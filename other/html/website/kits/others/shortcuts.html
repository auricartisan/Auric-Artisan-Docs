Kit keyboard shortcuts

Every keyboard shortcut for opening, closing and using the kits, in one table.

Shortcuts that open a kit work on any page. Shortcuts that act inside a kit work only while that kit is open. Each kit's own shortcuts page has the full detail.

Open and close kits

ShortcutWhat it does
Ctrl + Shift + K (Cmd + Shift + K on a Mac)Open or close the Feature Kit
Ctrl + MOpen or close the Menu Kit
Ctrl + Shift + AOpen or close the Advanced Kit
Ctrl + Shift + L (Cmd + Shift + L on a Mac)Open or close the Library Kit
Ctrl + Shift + UUpdate the website (Update Kit)
EscClose the page utilities bar, or close the open kit

The Status Kit has no shortcut to open it. Use the Status launcher.

Inside the Feature Kit

ShortcutWhat it does
1 to 6On the Feature Kit menu, open Scientific Calculator, Unit Converter, Feedback, Notes, Date & Time or Developer Tools
Ctrl + 1 to Ctrl + 6Switch straight to one of the six tools while the kit has focus
EscIn a tool, go back to the menu. On the menu, close the kit
Digits, +, -, *, /, ., (, ), ^, %, !Type on the calculator keypad when the cursor is not in a text box
Enter or =Work out the calculator expression
BackspaceDelete the last character on the keypad
DeleteClear the keypad
/In the Unit Converter, jump to the unit search box

See Feature Kit shortcuts.

Inside the Menu Kit

ShortcutWhat it does
/Put the cursor in the search box
Down arrowFrom the search box or tabs, move into the list of pages
Left arrow, Right arrow, Home, EndOn the tabs, switch tab
Arrow keys, Home, EndMove between pages and section headings
Enter or SpaceOn a section heading, collapse or expand it
Up arrow, Down arrow, EnterWhile searching, move through results and open one
EscClear the search, then close the kit

See Menu Kit shortcuts.

Inside the Status Kit

ShortcutWhat it does
/Put the cursor in the path box, or in the results search after a scan
EnterIn the path box, run the scan
Down arrowFrom the path or search box, move into the results
Up arrow, Down arrow, Home, EndMove through the results
EscClose the kit

See Status Kit shortcuts.

Inside the Library Kit

ShortcutWhat it does
EscClear the search, then close the panel
Arrow keysMove between items
EnterRestore the focused item into its tool
DeleteDelete the focused item
Ctrl + A (Cmd + A on a Mac)Select all, while multi-select is on
> then a command nameRun a library command from the search box

See Library Kit shortcuts.

Site-wide shortcuts that interact with kits

Ctrl + K opens the site-wide search on every page, even while a kit is open. The site settings panel has its own shortcuts, such as Ctrl + , to open settings. Both are covered in Site features.
