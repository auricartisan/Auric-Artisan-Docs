Status Kit shortcuts

Keys the Status Kit responds to.

The Status Kit has no shortcut to open it. Open it from Page utilities > Status. While it is open:

KeyWhereWhat it does
/Cursor not in a text boxPuts the cursor in the path box, or in Search pages... after a scan
EnterPath boxRuns the scan
Down arrowPath box or Search pages...Moves into the results
Up arrow, Down arrowResultsPrevious or next item
Home, EndResultsFirst or last item
EnterA result rowOpens the page in a new tab
Enter or SpaceSystem status headingCollapses or expands the panel
EscAnywhereCloses the kit

Ctrl + K opens the site-wide search, not the Status Kit's boxes.

See Kit keyboard shortcuts for the other kits.
