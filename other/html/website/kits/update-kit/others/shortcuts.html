Update Kit shortcuts

The keyboard shortcut for updating the website.

ShortcutWhereWhat it does
Ctrl + Shift + UAny pageRuns Update website: clears the site's cached files, re-downloads the page's files and reloads
Tab, EnterUpdate noticeReach and select Update now or x

The right-click menu shows this shortcut as Ctrl+⇧+U next to Update website.
