Menu Kit shortcuts

Every keyboard shortcut the Menu Kit responds to.

ShortcutWhereWhat it does
Ctrl + MAnywhereOpens or closes the Menu Kit
/Kit open, cursor not in a text boxPuts the cursor in the search box
EscSearch box with textClears the search
EscKit openCloses the kit
Down arrowSearch box (not searching) or tab rowMoves into the tiles
Left arrow, Right arrowTab rowPrevious or next tab
Home, EndTab rowFirst or last tab
Arrow keysTiles and section headingsMove to the previous or next item
Home, EndTiles and section headingsFirst or last item
Enter or SpaceSection headingCollapses or expands the section
EnterTileOpens the page
Up arrow, Down arrowSearch box while searchingMoves the highlight through the results
EnterSearch box while searchingOpens the highlighted page or runs the highlighted action

Ctrl + K, shown in the footer, opens the site-wide search rather than the Menu Kit's search box. See Site features.
