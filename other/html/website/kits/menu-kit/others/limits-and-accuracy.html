Menu Kit limits

What the Menu Kit includes, how its search matches and ranks, and what it does not do.

What the menu covers

  • The Menu Kit lists 83 pages in 14 sections across seven tabs, plus the Recommended and Most Used sections built from the Tools tab.
  • It does not list individual Learn articles, blog posts, documentation articles, changelog entries or library items. Use the site-wide search for those.
  • The Projects tile links to an external site.

Search

  • The results list shows at most 16 results.
  • Matching is by letters in order, then by section and name together, then by an exact phrase in the description.
  • It does not correct wrong or swapped letters, and it does not search the text of pages.
  • Results respect the tool visibility mode, so hidden tools cannot be found through the Menu Kit.
  • Ranking gives a modest boost to pages you open often, capped so a single much-used page does not always come first.

Most Used

  • Counts only visits started from the Menu Kit, in this browser.
  • Covers pages in the Tools tab only.
  • Is not shared between browsers or devices and cannot be reset from the kit.

Status chip

The chip shows one status for the whole site, not the status of the page you are on. For per-page status, use the Status Kit.
