Getting started with the Menu Kit

Open the Menu Kit, learn the parts of its screen, and open your first page from it.

Open the kit

Use either:

  • Page utilities (bottom-left corner) > Menu, or
  • Ctrl + M from anywhere on the page.

The launcher's tooltip reads "Open site navigation, grouped pages, and quick search." The first time you open the kit on a page it shows Loading menu with the line "Reframing tools by intent." while it fetches the list of pages.

The screen, top to bottom

  1. Title bar. Menu Kit, a status chip showing the site's release status (for example Beta), and the buttons Focus mode, Theme, Resize, Minimize and Close.
  2. Search bar. A magnifier, the box Search Auric Artisan…, and an ESC hint to its right. Once you type, a clear button (a cross) replaces the hint.
  3. Tabs. Tools, Design, Analyze, Account, Library, Company, Trust. The row scrolls sideways if it does not fit.
  4. Body. Section headings and tiles for the selected tab.
  5. Footer. Key hints (Ctrl K Search · Esc Close, with ⌘ on a Mac) and a home icon that goes to the Auric Artisan home page.

Tiles

Each tile shows an illustration (or an icon) and the page's name. Hover over a tile to see its description in a tooltip. The tile for the page you are on has a small dot; its tooltip reads You are here.

Select a tile to go to that page. The kit remembers how often you open each page, which feeds the Most Used section.

Open your first page

  1. Open the Menu Kit.
  2. Select the Tools tab if it is not already selected.
  3. Under Recommended, select Basic Color Tools.

The Basic Color Tools page opens. The Menu Kit closes, because you have loaded a new page; turn on Focus mode if you want it to open again on every page.

The status chip

The chip next to the title shows the release status of the site as a whole. Its tooltip reads, for example, "Auric Artisan is Beta." For the status of an individual page, use the Status Kit.

Close the kit

  • Press Esc. If the search box has text, the first Esc clears it and the second closes the kit.
  • Select Close in the title bar.
  • Select the Menu launcher again.
