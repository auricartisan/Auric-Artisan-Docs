Find a page by browsing

Browse the Menu Kit's tabs and sections, use Recommended and Most Used, and collapse sections you do not need.

The Menu Kit groups every page it knows into seven tabs, and each tab into sections. This guide shows how to move around them.

Switch tabs

Select a tab, or with a tab focused press Left arrow, Right arrow, Home or End. Each tab's tooltip reads "Show [tab] pages." The kit remembers the last tab you used and opens on it next time.

The number in each section heading is the total in that section. Fewer tiles can show if the site's tool visibility mode hides some of them.

The Projects tile in the Company tab opens an external site, https://leacb.com/projects.

Recommended

The Tools tab opens with Recommended: eight entry points picked for first-time visitors.

  • All Tools
  • Collections
  • URL Analyzer
  • Basic Color Tools
  • ASCII Art
  • Icon Library
  • Design System Generator
  • Color Foundations

Most Used

Most Used follows Recommended. It lists up to eight pages from the Tools tab, ordered by how often you have opened them from the Menu Kit, and never repeats a page already in Recommended. On your first visit, before you have opened anything, it lists pages alphabetically.

The counts are kept in your browser. Opening a page any other way does not count.

Collapse and expand sections

Select a section heading to collapse it; select it again to expand it. The chevron at the right of the heading turns to show the state. With the keyboard, focus the heading and press Enter or Space.

The kit remembers which sections you collapsed.

Move with the keyboard

  1. Press Down arrow from the search box or the tab row to move into the body.
  2. Use the arrow keys to move between section headings and tiles, and Home or End to jump to the first or last.
  3. Press Enter on a tile to open it.

How the tool visibility mode changes the menu

The Menu Kit shows only the tools that fit the site's mode, set in the Advanced Kit. A tab with nothing to show disappears.

ModeWhat changes in the Menu Kit
Basic (the default)The Design tab is hidden. The Tools tab shows every section
AdvancedThe Design tab appears. The Tools tab keeps Start Here and Search but hides General Color Tools
EverythingEvery tab and every page
CustomEvery page except the tools you have unticked in the Advanced Kit

Account, Library, Company and Trust pages, the URL Analyzer and the Vision Deficiency Simulator show in every mode. If the tab you were on has nothing to show in the new mode, the kit switches to the first tab that does.
