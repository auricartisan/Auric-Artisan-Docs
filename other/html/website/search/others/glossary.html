Search glossary

Terms used on the Auric Artisan search page and in the Search Console.

TermMeaning
AuricBotThe name Auric Artisan's crawler uses when it fetches pages.
BM25FThe ranking method site search uses: it scores word matches, weighting each field of a page differently.
Canonical addressThe address a page names as its preferred version, with a rel=canonical link.
ClickIn the Search Console, a searcher opening your page from a web-search result.
Click-through (CTR)Clicks divided by impressions.
CoverageWhich of a site's addresses are in the index, and why the others are not.
CrawlFetching a page so it can be indexed.
Crawled indexAuric Artisan's own index of the web, searched with the globe.
Crawl-delayA robots.txt line asking crawlers to wait between requests.
ExclusionA -word in a query, which leaves out pages containing the word.
Field filterAn operator such as type: or tag: that narrows results by one field.
ImpressionIn the Search Console, one appearance of your page in a web-search result.
IndexThe collection of pages a search looks through.
Index buildThe step that makes crawled pages searchable.
InspectionThe Search Console panel that explains one address.
LOCAL, GLOBALThe mode label: site search or web search.
noindexA robots meta tag or header asking search engines not to index a page.
PaceHow long the crawler waits between requests to one site.
PhraseWords in quotes, which must appear together and in order.
PositionWhere a result appeared in the list; 1 is the top.
PropertyA site you have added to the Search Console.
Rank (static rank)A page's or site's weight from links between sites, out of 255.
Related wordA word linked to yours, such as swatch for palette, matched at reduced weight.
robots.txtA file at the root of a site that tells crawlers what they may fetch.
Section tabA filter on the search page for one kind of page, such as Learn.
SitemapA file listing a site's addresses for crawlers.
VerificationProving to the Search Console that you own a site.
WCAG 2.1The Web Content Accessibility Guidelines version whose contrast formula the answer cards use.
