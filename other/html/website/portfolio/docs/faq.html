Portfolio FAQ

Short answers about the Portfolio Builder, publishing and the Portfolio Index.

Is the Portfolio Builder free?

Yes. Building, publishing and exporting are free on every plan. Paid plans can remove the "Made with Auric Artisan" credit from exported files.

Do I need an account?

To build and publish, yes. To view portfolios and the Portfolio Index, no.

Can I change my address later?

Unpublish and publish again at a new address. Taking a page down frees its address for others, so your old link stops working.

Does publishing again change the address?

No. Publish these changes updates the same address.

Can I keep my portfolio private?

Choose Only people I send the link to to share a snapshot link that is not stored on the site and never seen by search engines. Or publish with Let search engines list it and List it in the Portfolio Index switched off.

Who can see my email address?

Only if you switch on Show next to Email. It is off by default.

Is the view count tracking visitors?

No. It is "Counted as a number and nothing else — no visitor records, no addresses."

Can I host the portfolio myself?

Yes. Download HTML gives you a single file to put on any web host. You can then add that address to the Portfolio Index through the Search Console.

What does "Verified" mean in the Portfolio Index?

The owner proved, in the Search Console, that the site hosting the portfolio is theirs. Other external portfolios are reviewed by a person before they appear, and are marked Reviewed.

Can I import a portfolio from another tool?

Only files exported from this builder with Export JSON.
