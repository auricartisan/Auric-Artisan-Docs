Export your data

Download your Auric Artisan account details, preferences, portfolio draft and saved library as one JSON file from the dashboard.

The dashboard can put your account details and the work saved in this browser into one JSON file (a plain-text data format that most tools can read). Nothing secret is included.

Download the export

  1. Open the dashboard and select Security & Privacy.
  2. Find the row Export everything.
  3. Select Export.

Result: "Export downloaded." and a file named like auric-artisan-export-2026-09-25.json (the date of the export) is saved by your browser.

What the file contains

SectionContents
exported_atWhen you made the export
profileYour account details as the site holds them: display name, username, email address, bio, website, location, photo and related account fields
preferencesYour dashboard preferences
portfolioYour Portfolio Builder draft as saved in this browser
portfolio_statsThe view, download and share counters kept in this browser
libraryEverything in My Library in this browser — palettes, gradients, collections and other saved items

What it does not contain

  • Secrets. Passwords, two-step verification material and API keys are never included.
  • Work saved in other browsers. The library and portfolio sections come from the browser you are using. Export from each browser you use.
  • Receipts. The on-screen description mentions receipts, but your invoices are not written into this file. View, print or save them as PDF from Plan & Usage › Invoices & Payment History — see Invoices and receipts.

A complete copy of what Auric Artisan holds

The Privacy Policy lists a right to portability — "a portable copy of applicable data where technically feasible" — and a right of access. For a copy of data held on Auric Artisan's servers beyond this export (for example order and payment records, or contact messages), write through the contact page with the topic Privacy or data (reply time: within 30 days). See Contact and support.

Keep the file safe

The export holds your email address and profile details. Store it somewhere private.
