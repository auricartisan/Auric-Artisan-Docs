Account and billing

Everything about your Auric Artisan account — signing up and in, the dashboard, security, plans, tokens, payments, invoices, refunds, API keys and deleting your account.

An Auric Artisan account is optional. Every tool on the website is free to use without one. The account exists for the things that have to belong to a person rather than to one browser: a paid plan pass, a token balance for server-backed tool work, API keys, a published portfolio, and the security controls that protect them.

The account lives at https://auricartisan.com/auth/. Signing in opens the account dashboard, which has four sections: Overview, Profile, Plan & Usage, and Security & Privacy. From there you manage your profile and username, see your plan and usage, buy and review plan passes, view invoices, create API keys, see every device that is signed in, turn on two-step verification, export your data and, if you choose, delete the account.

Billing is deliberately simple. A paid plan is a one-time pass for one month or twelve months, paid through Razorpay. Nothing renews automatically, no card is stored, and there is no subscription to cancel; when a pass ends the account returns to the free Apprentice plan. Plan purchases have a 7-day money-back window.

Who it is for

  • Anyone who wants to run server-backed tool work, such as whole-site accessibility crawls in the Analyzer.
  • People who want the conveniences of a paid plan: ad-free browsing, watermark-free exports and higher limits.
  • Developers who want to call the REST API with their own API keys (Specialist plan and above).
  • Anyone publishing a portfolio page at their own address.

Quick start

  1. Open https://auricartisan.com/auth/ and select Create Account, or select Google or GitHub to sign up with one of those accounts.
  2. Complete the form, tick the Terms box, select Create Account and complete the Auric human check.
  3. Open the verification email and select the link, then select Confirm email ownership.
  4. Open the dashboard. In Finish setting up, add your name, choose a username and add a profile photo.
  5. Open Security & Privacy and select Enable 2FA to add two-step verification. Save the backup codes.
  6. If you want a paid plan, open Plans and pricing, choose a term and currency, and select Get Artisan.
  7. Your receipts appear under Plan & Usage › Invoices & Payment History.

What you can do

  • Sign up with email, Google or GitHub; sign in with your email or your username.
  • Verify your email, reset a forgotten password, and change your password.
  • Protect the account with an authenticator app and single-use backup codes.
  • Approve the Auric command-line tool from a browser.
  • Edit your display name, username, bio, website, location and profile photo, or pick an avatar from the Auric gallery.
  • See your plan, usage meters, tool token balance and invoices.
  • Buy a plan pass, request a refund, and print or save any invoice as PDF.
  • Create, view and revoke API keys; buy prepaid API credits; set paid overage and a monthly spend cap (plans with API access).
  • See every signed-in device, revoke any of them, or sign out everywhere else.
  • Export your account data as JSON, erase this browser's workspace, or delete the account.
