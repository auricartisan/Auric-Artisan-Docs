Get started with the app and offline use

A tour of the Download page and the three steps to a working offline copy.

Two separate things

  • Installing puts Auric Artisan in its own window with an icon. Whether a browser offers this is the browser's decision.
  • Preparing the offline version stores the site in your browser so it works without a connection. This works in any modern browser with a secure connection, installed or not.

You can do either, or both. For reliable offline use, prepare the offline version even if you install.

A tour of the Download page

Open https://auricartisan.com/download/. From top to bottom:

  1. The head. "Auric Artisan · Browser PWA", the title Install it. Then lose the connection, one paragraph, and the actions:

    • Install app (only when your browser offers installation);
    • Update app (only when an update is waiting);
    • Prepare offline version;
    • Download full offline;
    • Open in browser (to the homepage).

    Below them, a status line says what is happening, with a progress bar.

  2. Readiness — Is this browser ready. A badge (Checking, Preparing, Shell ready or Offline ready) and six checks: Shell, Full cache, Persistent storage, Local capabilities, Install and Update. Buttons: Check readiness, Audit cache, Repair cache, Reset cache.

  3. Live metrics — What is actually on this device. Cache entries, storage used, CPU threads, graphics, offline profile, cache target, missing assets and the app version, then a list of Browser capabilities, and Check local hardware.

  4. Profile — How much to keep. Auto, Lite, Balanced and Full, a switch to limit background work on low-power hardware, a summary, Configure profile, and a table of what each profile keeps.

  5. Offline workflow — Three steps, then you can close the Wi-Fi. Prepare, Confirm, Work offline.

  6. Where it runs. Windows, macOS, Linux, Android, iOS and iPadOS, and other devices, with your current platform marked "current".

The three steps

  1. Prepare. While online, select Prepare offline version. The browser fills its offline store in the background; you can keep working.
  2. Confirm. Check the readiness badge and the storage checks. Persistent storage matters: without it, the browser may clear the offline copy when the device runs short of space.
  3. Work offline. Open cached tools and libraries from this browser, or from the installed app. Palettes and exports you make stay on the device.
