Services

The Auric Artisan services you can use from your own sites and code — the Font CDN, the Icon CDN and the public REST API.

Besides the website, the browser extension and the editor extensions, Auric Artisan offers services you use from your own projects: two content delivery networks that serve fonts and icons to your web pages, and a REST API that exposes its colour science and accessibility checks to your code.
