# Font CDN documentation — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | The contents of the Font CDN documentation, from a first embed to the loader API and self-hosting. |
| [getting-started.html](getting-started.html) | How the Font CDN is organised — family ids, stylesheets and font files — and how to put a first family on a page. |
| [embed-a-family.html](embed-a-family.html) | Every way to embed a Font CDN family — link tag, CSS @import, @font-face rules and usage CSS — plus weights, italics, variable axes and several families at once. |
| [find-a-family.html](find-a-family.html) | Find a family and its id for the Font CDN, on the Font Library page or from JavaScript, and read what the catalogue records about it. |
| [self-host-a-family.html](self-host-a-family.html) | Download a font kit from the Font Library, understand what it contains, and serve the family from your own site. |
| [use-the-loader.html](use-the-loader.html) | Load Font CDN families with the font-cdn.js script tag or its AuricFonts JavaScript API, and configure where it loads from. |
| [reference.html](reference.html) | Every URL pattern, file, loader attribute, method and snippet of the Auric Artisan Font CDN. |
| [troubleshooting.html](troubleshooting.html) | Why a Font CDN family might not appear or look right, and what to do. |
| [faq.html](faq.html) | Short answers to common questions about the Auric Artisan Font CDN. |
