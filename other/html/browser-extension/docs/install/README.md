# Install the extension — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | Which browsers the extension supports and how to install it on each one, from a store or from a ZIP package. |
| [chrome-and-chromium.html](chrome-and-chromium.html) | Install Auric Artisan from the Chrome Web Store in Chrome, Brave, Vivaldi or Arc, pin it and open it. |
| [edge.html](edge.html) | Install Auric Artisan in Microsoft Edge from the Chrome Web Store listing, or load the Edge package from a ZIP. |
| [firefox.html](firefox.html) | Install Auric Artisan from Firefox Add-ons, open the sidebar, and understand what differs in Firefox. |
| [load-from-a-zip.html](load-from-a-zip.html) | Load an unpacked copy of Auric Artisan from the ZIP packages on the product page, in a Chromium browser or in Firefox. |
| [opera.html](opera.html) | Install Auric Artisan in Opera from the Chrome Web Store listing, or load the Opera package from a ZIP. |
| [safari.html](safari.html) | Auric Artisan is not published for Safari; how to convert the Chromium package yourself on macOS, and what to expect. |
| [update-and-remove.html](update-and-remove.html) | How Auric Artisan updates, how to update a copy loaded from a ZIP, how to keep your data across a reinstall, and how to uninstall. |
