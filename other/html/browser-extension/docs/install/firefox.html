Install on Firefox

Install Auric Artisan from Firefox Add-ons, open the sidebar, and understand what differs in Firefox.

Firefox has its own package of Auric Artisan, published on Firefox Add-ons (AMO). It needs Firefox 115 or later. Because Mozilla signs it, it installs permanently like any other add-on and updates itself.

Install from Firefox Add-ons

  1. Open https://addons.mozilla.org/en-US/firefox/addon/auric-artisan/
  2. Choose Add to Firefox.
  3. Read the permission prompt and choose Add.
  4. Firefox confirms the add-on is installed and opens auricartisan.com once in a new tab.
  5. Pin the extension to the toolbar from Firefox's extensions menu if it is not already shown.
  6. Open a normal web page and click the icon, or press Alt + Shift + A.

Open the sidebar

In Firefox the docked workspace is a sidebar, titled Auric Artisan workspace.

  • Choose Open the side panel in the popup's header, or
  • open it from Firefox's own sidebar menu, where Auric Artisan appears with the other sidebars.

See Side panel.

What differs in Firefox

  • Screen eyedropper (Pick from page, Pick a colour): Not available: Firefox does not offer the eyedropper interface extensions use. The Picker shows a hint instead. Use Page palette, which reads every colour the page uses.
  • Side panel: A sidebar instead, with the same workspace
  • Pick colour in the right-click menu: Shows a message that the eyedropper needs a Chromium browser
  • Permissions: The same list, minus the side-panel permission, which Firefox does not need
  • Data collection: The package declares to Mozilla that it collects no data

Keyboard shortcuts

The defaults are the same as in Chromium browsers: Alt + Shift + A, C, E and V. To change them:

  1. Open about:addons.
  2. Choose the gear menu, then Manage Extension Shortcuts.

Settings › Shortcuts › Change them in the browser opens about:addons for you.

Temporary install from a ZIP

You can also load the Firefox package from https://auricartisan.com/extension through about:debugging#/runtime/this-firefox › Load Temporary Add-on. A temporary add-on is removed when you quit Firefox, because Firefox keeps only signed add-ons across restarts. If you find yourself reinstalling it every day, use the Add-ons listing instead. Steps are in Load from a ZIP.
