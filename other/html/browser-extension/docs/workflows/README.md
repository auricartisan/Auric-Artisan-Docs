# Workflows — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | End-to-end tasks that combine several of the extension's tools, step by step. |
| [audit-a-page-and-fix-contrast.html](audit-a-page-and-fix-contrast.html) | Run the audit on a page, see its contrast problems on the page, fix a failing colour pair, review the other findings and export a record. |
| [back-up-and-move-your-data.html](back-up-and-move-your-data.html) | Back up your settings, colour history, library and snippets to a file, restore them, and move them to another browser or computer. |
| [build-a-colour-scale-for-tailwind.html](build-a-colour-scale-for-tailwind.html) | Turn one colour into a named, perceptually even Tailwind v4 scale from 50 to 950, check it, and keep it as a snippet. |
| [check-and-fix-a-brand-colour.html](check-and-fix-a-brand-colour.html) | Test a brand colour as text and as a background in WCAG and APCA, see it through colour-vision simulations, and find accessible variants that keep its hue. |
| [extract-a-sites-design-system.html](extract-a-sites-design-system.html) | Read a website's colours, CSS variables, fonts and type scale, and export them as W3C design tokens, Tailwind or CSS. |
| [inspect-and-debug-an-element.html](inspect-and-debug-an-element.html) | Find why an element looks the way it does, check its accessibility, try a CSS fix live on the page, and copy the result. |
| [review-a-page-for-colour-blindness.html](review-a-page-for-colour-blindness.html) | Check that a page does not rely on colour alone, using the vision simulations, side-by-side comparison and the contrast checker. |
