# Settings — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | How to open the extension's Settings view, how it saves, and what each of its six sections holds. |
| [appearance.html](appearance.html) | Choose the extension's theme, accent colour, popup size and interface language. |
| [data.html](data.html) | See how much the extension stores, back up and restore everything, move settings through the clipboard, and clear or reset data. |
| [pickers.html](pickers.html) | Turn the website pickers on or off, choose which control types they enhance, respect designed controls, and list sites where they never run. |
| [right-click.html](right-click.html) | Turn the custom right-click menu on or off, let sites keep their own menus, control the browser menu entries, and set the quick bar, layout, row height, excluded sites and permissions. |
| [tools.html](tools.html) | Set how colours are copied and named, whether APCA is shown, history and sound, and how deep the page audit goes. |
| [shortcuts.html](shortcuts.html) | The keyboard map in Settings, how to change the browser-level shortcuts, and how to replay the tour. |
