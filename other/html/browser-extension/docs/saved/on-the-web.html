On the web

The links from the extension to the full-size tools and libraries on auricartisan.com.

On the web ("Open on the Web") lists the full-size tools on auricartisan.com, each opening in a new tab. Open it by searching for "web" or "On the web"; it belongs to the Saved space.

Other links to auricartisan.com

  • The Auric Artisan wordmark in the header opens the home page.
  • Home › On auricartisan.com: Collections, Accessibility Library, Learning Library and Documentation.
  • Search results under On the web: Full Search, Collections, URL Analyzer, Tools, Color Science Lab, Accessibility Library, Documentation, API Reference and Learning Library.
  • Page palette › Open opens the palette on auricartisan.com with its colours in the address.

Each link is an ordinary page visit that you start. The extension sends nothing else to the site. See Privacy.
