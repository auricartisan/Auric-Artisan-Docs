Browser extension › Colour

Convert

Type a colour in any of ten formats and read it in all the others at once, with random, invert and complement helpers.

Convert (the Colour converter, "every format at once") shows one colour in ten formats. Type into any field and the others follow. Open it from the Picker's Specs pane (Open the converter →) or search for "Convert".

Fields

FieldExample input
HEX#d3af37
RGBrgb(211,175,55)
HSLhsl(43,65%,52%)
HSVhsv(43,74%,83%)
CMYKcmyk(0,17,74,17)
LABlab(72 5 60)
LCHlch(72 60 85)
OKLCHoklch(76% 0.13 85)
HWBhwb(43 22% 17%)
Namegoldenrod

Commas or spaces both work as separators. A swatch shows the current colour.

Helpers

ButtonWhat it does
RandomA random colour
InvertThe colour's inverse
ComplementThe colour opposite on the hue wheel

Picker at the top returns to the Picker.

Note: CMYK here is a simple conversion from RGB, not a colour-managed print profile. Use it as a starting point for print, not a proof.
