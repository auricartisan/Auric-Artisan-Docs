# Colour tools — HTML edition

Web pages for this folder. Open `README.html` in a browser; every page links to its neighbours, and `search.html` at the top of the HTML edition searches everything.

| Page | What it covers |
| --- | --- |
| [README.html](README.html) | The tools in the Colour space — Picker, Page palette, Image, Gradient, Mix, and the Harmony, Scale and Convert tools behind the Picker. |
| [convert.html](convert.html) | Type a colour in any of ten formats and read it in all the others at once, with random, invert and complement helpers. |
| [gradient.html](gradient.html) | Build a linear, radial or conic CSS gradient from two or more stops, choose the interpolation space, and copy or save the CSS. |
| [harmony.html](harmony.html) | Build a colour harmony from a base colour in nine schemes on a wheel you can drag, then copy, send or save it. |
| [image.html](image.html) | Build a palette from an image you drop, paste or choose, or from a capture of the visible tab, entirely on your device. |
| [mix.html](mix.html) | Mix two colours at any percentage in sRGB, linear RGB, LAB, OKLAB or HSL, or blend them with a blend mode, and copy the result. |
| [page-palette.html](page-palette.html) | Read every colour a web page uses, switch between views and sorting modes, inspect a colour, and copy or export the palette. |
| [picker.html](picker.html) | Sample a colour from the screen or set one by hand, read it in twelve formats, and use the Picker's Specs, Harmony, Scale, Contrast, Vision and Code panes. |
| [scale.html](scale.html) | Generate Tailwind and Material colour scales, tints, shades and tones from one colour, inspect each step, and export the scale. |
