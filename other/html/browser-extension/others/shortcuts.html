Browser extension

Keyboard shortcuts

Every keyboard shortcut in the Auric Artisan browser extension — browser-level shortcuts, the popup, the element inspector and the right-click menu.

Browser-level shortcuts

These work from any page. Change them on the browser's shortcuts page: chrome://extensions/shortcuts in Chromium browsers, or about:addons › gear › Manage Extension Shortcuts in Firefox. Settings › Shortcuts › Change them in the browser opens it.

KeysActionName on the shortcuts page
Alt + Shift + AOpen the extension on the active tabOpen Auric Artisan
Alt + Shift + COpen the contrast checkerOpen contrast checker
Alt + Shift + EOpen Page palette and read the page's coloursExtract page palette
Alt + Shift + VTurn the deuteranopia simulation on or offToggle deuteranopia simulation
UnassignedStart the element inspectorInspect an element on the page
UnassignedOpen Audit and run itRun a full accessibility audit

No macOS-specific keys are documented; use your browser's shortcuts page to check or change them.

In the popup and side panel

KeysAction
/Focus search (when not typing in a field)
Ctrl + KFocus search from anywhere; closes Settings
Up / DownMove through search results
EnterRun the selected search result
EscClose an open colour picker, then Settings, then clear the search, then return to Home
Left / Right, Home / EndMove between spaces, or between Settings sections (Up and Down also work there)
Delete or BackspaceRemove the focused colour in Library

Custom right-click menu (on the page)

KeysAction
TypeFilter every action
