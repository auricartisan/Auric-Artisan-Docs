Auric Icons: Modern guides

Contents of the Auric Icons: Modern guides folder, with one line on each guide.

This folder holds the task guides and the complete reference for Auric Icons: Modern. The extension has two parts, the Explorer file icon theme and the Icon Library, and each has its own guide.

FileWhat it covers
getting-started.mdInstall, turn on the file icon theme, open the Icon Library and insert a first icon.
file-icon-theme.mdFolder colour, framework packs, saturation, opacity, arrows, associations and workspace detection.
icon-library.mdSearch, filters, variants, preview surfaces, the smart guide and recommendations.
insert-copy-and-save.mdInsert and smart insert, nine copy formats, save, open source and hover previews.
merged-icon-studio.mdHow Modern, Drawn, Playful and Icon Studio share one library.
reference.mdEvery command, setting, keybinding, icon ID and control.
