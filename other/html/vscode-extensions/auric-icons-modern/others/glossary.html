Glossary

Definitions of the terms used in Auric Icons: Modern.

TermMeaning
AssociationA rule that maps a file extension, filename or folder name to an icon.
Auto variantA variant choice that follows the language of the file you are editing.
Catalog pathThe relative location of an icon file inside the bundled catalog.
Data URIText that embeds a file directly, starting data:image/svg+xml,.
DuotoneA variant drawn in two tones.
Explorer arrowsThe chevrons beside folders in the Explorer that expand and collapse them.
File icon themeThe set of icons VS Code shows beside files and folders. Only one is active at a time.
Framework packExtra file icons for one framework's file types, such as Angular components or Vue composables.
HostThe one extension that shows the shared library when several Auric collections are installed.
Icon IDThe unique name of an icon. Library IDs end in a four-digit number, such as analytics-bar-chart-0042; theme IDs are short names such as typescript.
Icon StudioThe heading of the shared library view, and also the name of the separate Auric Artisan Icon Studio extension.
MonoA single-colour variant.
Preview surfaceThe light, dark or automatic backdrop behind library cards.
Semantic colourA colour that identifies a file type, such as the TypeScript blue.
Sharp ModernOne of the two style families in the library (300 icons), shown as Sharp in the Style filter.
Simple ModernThe other style family (420 icons), shown as Modern in the Style filter.
Smart guideTip cards at the top of the library that react to your file and usage.
Smart insertChoosing the output format from the language of the file you are editing.
VariantOne rendering of an icon: Color, Mono, Outline or Duotone.
