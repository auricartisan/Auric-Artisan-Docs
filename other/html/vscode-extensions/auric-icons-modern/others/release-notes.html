Release notes

User-facing history of Auric Icons: Modern, from its first release to 0.12.1.

0.12.1

The current Marketplace version.

  • Now covered by the Auric Artisan Free Use Licence 2.0 instead of MIT. The extension stays free to install and use for any purpose, personal or commercial. Redistribution, republishing to any marketplace, resale and derivative releases are no longer permitted.

0.12.0

  • Marketplace README images now display correctly on the Marketplace page and in VS Code's extension view.
  • Future Auric icon collections can join the shared library without every extension being updated.
  • The library view, palette entries and shared shortcuts are disabled while another icon collection or Auric Artisan Icon Studio hosts the library.

0.11.0

  • New Marketplace artwork.
  • The shared library gained keyboard and pointer enlargement and a remembered Auto, Light or Dark preview surface.
  • Verified the file theme alone and in every co-install combination.

0.4.0

  • Display name changed to Auric Icons: Modern. Extension ID, command IDs, settings and theme ID are unchanged.
  • The library now carries the 720 modern icons (Simple Modern and Sharp Modern). The 480 hand-drawn icons moved to Auric Icons: Drawn.
  • Co-install cooperation: with Drawn or Playful installed, one library appears, with a Library filter and source badges. Likes and recents stay with the extension that owns each icon, and the merge updates without a reload.
  • Each collection now declares its own variants, and the variant switcher shows the union, falling back to Color where a collection lacks the selected variant.
  • Auric Icons: Playful joined the family.
  • Fixed a start-up crash when the retired "Auric Artisan Drawing Icon" extension was still installed.

0.3.0

  • The extension combined the file and folder icon theme with the Icon Library, absorbing the retired "Auric Artisan Drawing Icon" and "Auric Artisan Icons" extensions.
  • Added hover previews for icon IDs, the self-contained image tag, icon name and catalog path copy formats, and multi-cursor insert.
  • Old auricArtisanIcons.* commands and settings keep working as fallbacks.

0.2.0

  • Renamed the extension; the theme ID became auric-artisan-modern-icon, so anyone using the earlier ID had to pick the theme again.
  • Added Auric Artisan workspace icons, workspace auto-detection, the four framework packs (26 icons), runtime folder colour, saturation, opacity, arrows and custom associations, and seven new glyphs.
  • Fixed the missing extension icon.
  • Improved legibility of folder badges and the darkest slate colour.

0.1.0

  • Initial release: the chamfered-plate icon language, complete open and closed folder pairs, light-theme variants for monochrome marks and a built-in contrast check.
