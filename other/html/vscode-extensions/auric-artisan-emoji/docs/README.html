Auric Artisan Emoji guides

Contents of the Auric Artisan Emoji guides folder, with one line on each guide.

This folder holds the task guides and the complete reference for Auric Artisan Emoji. Start with Getting started, then use the guide for how you prefer to work: from the editor, or from Emoji Studio.

FileWhat it covers
