Options reference

All 391 Auric Artisan Formatter formatting options in 17 categories, with type, default, allowed values and effect.

Auric Artisan Formatter has 391 formatting options in 17 categories. This page lists every one. The eleven settings that control how the extension works in VS Code (preset, format on save, the workspace scan and so on) are in the reference.

How to use this page

Each option can be set in four places. The same name works in all of them:

WhereHow it is written
VS Code settings"auricFormatter.printWidth": 100
A configuration file such as .auricformatrc"printWidth": 100 (no prefix)
The command line--print-width 100 (the name in kebab case; booleans also take a --no- form)
An inline directive in a file// @auric printWidth=100

The defaults shown are the extension's own defaults. A preset changes many of them; "preset": "prettier", for example, switches every Auric-only enhancement off. Anything you set yourself wins over the preset. See Configuration and Presets.

Options that only apply to some languages only affect files in those languages. Formatter Studio's Affects this file filter shows which options change the file you are looking at.

Options marked "Experimental" are still settling; Formatter Studio hides them unless you tick Experimental.
