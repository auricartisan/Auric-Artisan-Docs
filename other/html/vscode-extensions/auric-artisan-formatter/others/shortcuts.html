Shortcuts

The keyboard shortcuts Auric Artisan Formatter provides in VS Code and inside Formatter Studio.

VS Code

Windows and LinuxmacOSCommandWhen
Ctrl + Alt + Shift + FCmd + Alt + Shift + FPreview Formatting as a DiffAn editor has focus
Ctrl + Alt + Shift + PCmd + Alt + Shift + POpen Formatter StudioAny time
Ctrl + Alt + Shift + UCmd + Alt + Shift + UShow Files That Need FormattingAny time

There is deliberately no shortcut for formatting every file. VS Code's own Format Document (Shift + Alt + F on Windows) and Format Selection use Auric once it is the default formatter. Assign shortcuts to other commands in Preferences: Open Keyboard Shortcuts by searching for auricFormatter.

Formatter Studio

KeysWhat they do
Ctrl + KOpen the Studio command palette
Left and right arrows on the tabsSwitch between 01 Studio and 02 Workspace
Arrow keys, type-ahead, Enter in drop-downsChoose a language, preset, category or view
EscapeClose the command palette or an open drop-down
