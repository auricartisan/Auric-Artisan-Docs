Privacy

What Auric Artisan Formatter does with your code and settings.

  • Everything runs locally. Formatting, the workspace scan, Formatter Studio and the command line run on your machine (or next to the files in a remote setup). The engine has no runtime dependencies and makes no network requests.
  • No telemetry and no account.
  • The workspace scan only reads. It formats in memory; nothing is written until you choose a Format action.
  • Configuration stays in your project files and VS Code settings.
  • Report a Formatting Problem only opens a local document for you to review; nothing is sent until you choose to share it. It contains the formatter version, VS Code version, language, tier and the explanation for the active file, not the file itself.
  • In an untrusted workspace, JavaScript configuration files and formatter plugins are not run.
  • Links to auricartisan.com open your browser only when you select them.
