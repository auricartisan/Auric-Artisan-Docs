Install and setup guides

Contents of the installation and setup guides for the Auric Artisan VS Code extensions.

These guides apply to every Auric Artisan extension for VS Code. Start with the getting-started guide if you have never installed an extension before. The reference lists all seventeen extension IDs and the minimum VS Code version each one needs.
