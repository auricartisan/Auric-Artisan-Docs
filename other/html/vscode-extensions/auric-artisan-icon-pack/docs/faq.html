Frequently asked questions

Short answers to common questions about Auric Artisan Icon Pack.

Is the pack another icon browser?

No. It only tells VS Code which four extensions to install. It adds no commands, views or settings.

Does it work offline?

The members work offline once installed. Installing the pack needs marketplace access.

Does it include Icon Studio or File Icons?

No. Install them separately if you need them. See the reference.

Do the members update with the pack?

Each member updates on its own schedule through the marketplace.

Can I uninstall one member?

Yes. Manage each member individually in the Extensions view.

Why are Modern, Drawn and Playful shown as one library?

They are designed to merge into one library when installed together. See The merged Icon Studio.
