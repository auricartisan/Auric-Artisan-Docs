Release notes

User-facing history of Auric Artisan Icon Pack.

0.1.0 — 22 September 2026

The first Auric Artisan Icon Pack, and the current Marketplace version.

  • Groups Auric Icons: Modern, Auric Icons: Playful, Auric Artisan Emoji and Auric Icons: Drawn into one standard VS Code extension pack.
  • Uses the active Playful and Drawn extension IDs instead of retired ones.
  • Adds a gold Auric bundle icon, installation guidance and marketplace troubleshooting.
  • Contains metadata only: no runtime code, background service or custom downloader.
