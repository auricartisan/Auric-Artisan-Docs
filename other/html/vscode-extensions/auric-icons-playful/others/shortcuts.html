Shortcuts and commands

Keybindings, in-view keys and every command in Auric Icons: Playful.

Keybindings

ActionWindows and LinuxmacOS
Smart Insert IconCtrl + Alt + ICmd + Alt + I
Insert from RecentCtrl + Alt + RCmd + Alt + R

Both need a focused text editor and are active only while Playful hosts the library.

Keys in the Icon Library

KeyAction
/Focus search
EscapeClear search; close a dropdown
Arrow Up / Arrow DownMove between dropdown options

Commands

Type "Auric Icons: Playful" in the Command Palette: Open Icon Library, Search Icons, Insert SVG at Cursor, Smart Insert Icon (matches active language), Copy Icon As… (JSX, CSS, Markdown, Data URI, Image tag), Insert from Likes, Insert from Recent, Toggle Like for an Icon, Clear Likes, Recents and Learned Recommendations, Copy SVG, Save SVG As…, Open SVG Source.

See the reference for IDs and details.
