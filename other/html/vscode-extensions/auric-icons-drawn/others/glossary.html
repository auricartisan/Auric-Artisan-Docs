Glossary

Definitions of the terms used in Auric Icons: Drawn.

TermMeaning
Auto variantA variant choice that follows the language of the file you are editing.
Catalog pathThe relative location of an icon file inside the bundled catalog.
Data URIText that embeds a file directly, starting data:image/svg+xml,.
DuotoneA variant drawn in two tones.
HostThe one extension that shows the shared library when several Auric collections are installed.
Icon IDThe unique name of an icon, such as files-blank-document-drawn-0001.
Icon StudioThe heading of the shared library view, and also the name of the separate Auric Artisan Icon Studio extension.
MonoA single-colour variant.
Preview surfaceThe light, dark or automatic backdrop behind library cards.
Smart guideTip cards at the top of the library that react to your file and usage.
Smart insertChoosing the output format from the language of the file you are editing.
VariantOne rendering of an icon: Color, Mono, Outline or Duotone.
Warm DrawnThe hand-drawn style of this collection: organic geometry with friendly imperfections.
