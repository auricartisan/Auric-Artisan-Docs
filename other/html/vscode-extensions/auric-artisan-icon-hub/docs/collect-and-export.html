Collect and export

Build a selection of icons in Icon Hub and export it as an SVG sprite or a ZIP with licence notices.

Build a selection

  1. Select the check button (Add to the selection) on each icon you want.
  2. The selection tray at the bottom shows "{n} selected".
  3. Switch to the Selected view to see only your selection.

Selections are kept when you search, refine or reset filters, and when catalog metadata updates arrive.

Export

ButtonResult
Copy spriteCopies the selected SVG icons as one SVG symbol sprite sheet.
Export ZIPSaves a ZIP of the selected artwork with licence notices.
ClearEmpties the selection. Favorites are not changed.

What the ZIP contains

  • One SVG file per selected SVG icon, named after its set and name.
  • MATERIAL_ICONS.txt, if you selected Material icons: they are font-backed, so they are listed by name and style instead of being exported as SVG.
  • README.txt explaining that each icon remains under its upstream licence.
  • THIRD_PARTY_LICENSES.md and a licence file for each selected set.

Limits

  • Each export handles up to 200 icons.
  • Output uses your current Shape the output size, colour and stroke.
  • Each collection keeps its own licence (MIT, ISC, Remix v1.0 or Apache-2.0). Follow the attribution requirements when you use exported artwork.

Result

You have one sprite or ZIP containing exactly the icons you need, with their licences.
