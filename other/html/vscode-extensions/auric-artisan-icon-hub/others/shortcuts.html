Shortcuts and commands

Keybindings, keys inside the Hub and every command in Auric Artisan Icon Hub.

Keys inside the Hub

KeyAction
Ctrl + K / Cmd + KFocus search
Arrow keysMove between cards or dropdown options
EnterOpen the inspector for the focused card
FStar the focused card
Home / EndFirst or last dropdown option
EscapeClose a dropdown or the inspector

Commands

Type "Auric Icon Hub" in the Command Palette: Open Icon Hub, Quick Search Icons, Smart Insert Icon, Copy Icon As…, Save Icon As…, Show Favorite Icons, Show Recent Icons, Refresh Icon Catalog, Clear Downloaded Icon Catalog, Open Auric Icon Tool, Clear Icon Favorites and Recents.

The editor right-click menu has Smart Insert Icon and Copy Icon As….
