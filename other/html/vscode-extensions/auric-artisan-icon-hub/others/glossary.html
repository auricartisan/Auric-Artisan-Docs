Glossary

Definitions of the terms used in Auric Artisan Icon Hub.

TermMeaning
BridgeThe small icons.auricartisan.com.js loader file Icon Hub creates next to your source on the first CDN Insert.
Catalog metadataThe data describing icons (names, terms, counts), separate from the artwork itself.
CDNA content delivery network: a web service that serves icon data and fonts to your pages.
CDN placeholderAn element such as <span data-icon="set:name" …> that the CDN script turns into an icon.
Content security policyA website rule listing which sources may load scripts, fonts and data.
currentColorA CSS keyword meaning "use the surrounding text colour".
Data URIText that embeds a file directly, starting data:.
Font-backed iconAn icon drawn from a font glyph (Material), not an SVG file.
Indexed variantOne style of one icon. Icon Hub indexes 32,802.
SelectionIcons you ticked for export. Up to 200 per export.
Smart FinderA local panel of recent icons and a rotating sample of the catalog.
SVG spriteOne SVG file containing several icons as reusable symbols.
