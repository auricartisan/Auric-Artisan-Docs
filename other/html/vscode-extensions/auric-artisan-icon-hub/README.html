Auric Artisan Icon Hub

What the Auric Artisan Icon Hub extension is, who it is for, how to install it and where to find each guide.

Auric Artisan Icon Hub is an icon workspace for Visual Studio Code, connected to the Auric icon tool at https://icons.auricartisan.com. It searches 12,895 icons (32,802 indexed style variants) across seven open-source collections: Phosphor, Tabler, Lucide, Remix, Heroicons, Feather and Material. All artwork and preview fonts are bundled, so browsing, previewing and exporting work offline.

You can refine results by set, style, category and licence, shape the output with size, colour and stroke controls (including a full custom colour picker with contrast tools), and insert code that suits your file. In HTML and web-framework files, Insert uses the Auric icon CDN and connects a small loader file for you. You can also copy or save an icon in SVG, JSX, React component, HTML, data URI, CSS or CDN form, and export a selection of icons as an SVG sprite or a ZIP with licence notices.

Icon Hub can check the website for updated catalog metadata in the background. This is optional, limited to five public JSON files, and never sends your code, searches or usage.

Who it is for

  • Front-end developers who use popular open-source icon sets and want them tuned and inserted from the editor.
  • Designers who want to recolour and restroke icons, then export sprites or ZIPs with correct licences.
  • Teams that want pages to load icons from the Auric CDN.

Quick start

  1. Install the extension.
  2. Select Auric Icon Hub in the Activity Bar, or run Auric Icon Hub: Open Icon Hub for a full panel.
  3. Open a writable file and place the cursor.
  4. Type in Search your library, for example arrow.
  5. Expand Refine library to choose a set, style, category or licence.
  6. Expand Shape the output to set size, colour and stroke.
  7. Select Insert on a card, or select the preview to open the inspector and choose another format.

What you can do

  • Search 12,895 icons in seven collections, and refine by set, style, category and licence, sorted by relevance, name or set.
  • Keep Favorites, Recent icons and a Selected working set.
  • Set output size, colour (with contrast checks, shade ramps and harmonies) and stroke width.
  • Insert code that suits the editor language, or copy and save in seven formats.
  • Connect pages to the Auric icon CDN automatically on Insert.
  • Export selected icons as an SVG sprite or a ZIP with licence notices.
  • Use the native Quick Search with Ctrl + Alt + Shift + I.
  • Keep catalog metadata up to date from the website, or turn that off.
