Auric Artisan Theme guides

Contents of the Auric Artisan Theme guides folder, with one line on each guide.

This folder holds the task guides and the complete reference for the Auric Artisan Theme extension. Start with Getting started if you are new, then use the task guides for each workflow. The reference lists every command, setting, keybinding, dial, colour slot and option.

FileWhat it covers
getting-started.mdInstall, switch to an Auric theme, tour Theme Studio and make a first change.
choose-a-theme.mdThe six families, 54 variants, high-contrast builds and every way to switch.
looks-and-dials.mdThe 11 looks and the 37 dials, with search, filters and resets.
edit-colours.mdOverride any of the 107 colour slots with the custom colour picker.
check-contrast.mdRead the Audit tab and contrast report; tune the contrast guard.
compare-and-preview.mdCompare shipped and current palettes; copy colours as CSS.
save-share-and-export.mdPresets, customisation JSON, clipboard and standalone theme files.
theme-sidebar.mdEvery part of the Auric Theme view in the Activity Bar.
interface-language.mdSwitch Theme Studio and the sidebar between English and Hindi.
reference.mdEvery command, setting, keybinding, dial, slot, look, accent and palette.
troubleshooting.mdSymptoms, causes and fixes.
faq.mdShort answers to common questions.
