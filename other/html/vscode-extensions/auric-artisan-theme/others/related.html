Other Auric Artisan VS Code extensions, website tools and guides that work well with Auric Artisan Theme.

Other Auric Artisan VS Code extensions

ExtensionHow it relates
Auric Artisan File IconsFile and folder icons for the Explorer, in Facet, Playful and Modern styles. Pairs with the theme for a complete look.
Auric Artisan Icon StudioSearch and insert icons and emoji into code.
Auric Artisan EmojiEmoji Studio with the same English and Hindi interface switch.
Auric Artisan StudioColour, accessibility and code-health tools for your project files.
Auric Artisan LiveLive server and preview; Theme Studio's layout follows the same workspace design.

For installing and managing any of these, see Install and set up.
