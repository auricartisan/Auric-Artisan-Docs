Full Pack FAQ

Short answers about the Auric Artisan Studio Full Pack.

What is the difference between the pack and installing the three extensions myself?

None in what you get. The pack installs the same three extensions in one step and gives you one ID to recommend or install.

Does the pack add anything of its own?

No. It has no commands, views, settings or code.

Does it install the Auric icon themes or icon libraries?

No. It installs only Auric Color, Auric Accessibility and Auric Code Health. The Open Unified Icon Studio command works when you install an Auric icon extension separately. See The Icon Studio bridge.

Can I disable one member for one project?

Yes. In the Extensions view, choose Disable (Workspace) on that member. See Manage the pack's members.

Will three extensions slow VS Code down?

They coordinate so that each piece of work is done once: one extension draws colour swatches, one publishes each kind of diagnostic, and one runs live re-grading and background scans. Heavy parts load only when first used.

Is it free?

Yes, like every Studio extension. No account, API key or paid tier.

Does it need the internet?

Only to download and update from the Marketplace. The extensions run entirely offline. See Privacy.
