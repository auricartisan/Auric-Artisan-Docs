Auric Artisan Studio docs

The shared guides and reference pages that apply to every Auric Artisan Studio extension.

This folder holds the guides that apply to the Studio as a whole: the screens every extension shares, how installed extensions combine into one Workstation, scanning, scores, reports and the CI gate. Features that belong to one extension are documented in that extension's folder: Auric Color, Auric Accessibility and Auric Code Health.

Start with Getting started. If you are deciding what to install, read Choose what to install first.
