The browser extension

The Auric Artisan browser extension brings colour and accessibility tools to web pages in your browser, where you can check what is actually rendered rather than the source.

Tools on auricartisan.com

ToolUse it to
Contrast CheckerCheck a colour pair in the browser
AnalyzerAnalyse a web page
Accessibility ChecklistWork through WCAG criteria by hand
Accessibility ComplianceReview accessibility compliance
Vision SimulationSimulate colour-vision deficiencies
Basic Colour ToolsEveryday colour tools
Design EngineGenerate a design system
Tonal StepsBuild tonal scales

The Learn library has articles on colour, contrast and accessibility.

Standards the Studio refers to

  • Web Content Accessibility Guidelines (WCAG) 2.2: https://www.w3.org/TR/WCAG22/
  • Understanding WCAG 2.2 (linked from every WCAG finding): https://www.w3.org/WAI/WCAG22/Understanding/
  • WAI-ARIA 1.2: https://www.w3.org/TR/wai-aria-1.2/
  • HTML Accessibility API Mappings: https://www.w3.org/TR/html-aam-1.0/
  • ACT Rules Format 1.1: https://www.w3.org/TR/act-rules-format/
  • OWASP Top 10:2025: https://owasp.org/Top10/2025/0x00_2025-Introduction/
  • CWE-798, Use of Hard-coded Credentials: https://cwe.mitre.org/data/definitions/798.html
  • SARIF 2.1.0: https://docs.oasis-open.org/sarif/sarif/v2.1.0/sarif-v2.1.0.html
