Glossary

Definitions of the terms used in Auric Artisan File Icons.

TermMeaning
AssociationA rule mapping an extension, filename, folder name or pattern to an icon ID.
BadgeUp to two characters shown beside a resource in the Explorer by smart detection.
DecorationA badge, colour or tooltip VS Code adds to an Explorer item.
Direct parentThe folder immediately containing a file or folder; parent/name patterns only match this.
ExclusionA folder name or pattern that smart detection never inspects.
FacetThe faceted Explorer style with 500 SVGs.
File icon themeThe set of icons VS Code shows beside files and folders. One is active at a time.
Folder pairThe closed and open versions of one folder icon.
Framework packExtra Modern associations for Angular, NestJS, React or Vue.
Hover tokenText such as :icon-file-typescript: that a code hover can replace with artwork.
Icon IDThe name of a shipped icon, such as test or database, used as an association value.
InspectorThe dialog showing a card's exact code output.
ModernThe Explorer style with 464 SVGs, shared with Auric Icons: Modern's theme ID.
PlayfulThe Explorer style with 500 SVGs and its own palette. Not the Auric Icons: Playful library.
ProfileA named, portable set of appearance, association and smart detection settings.
Root associationAn icon for a workspace root folder, by name.
Smart detectionContent-aware classification of folders and small files, shown as decorations.
