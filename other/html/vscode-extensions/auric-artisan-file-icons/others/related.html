Which should I install?

  • Change the Explorer's file and folder icons: File Icons (three styles, smart detection, profiles) or Auric Icons: Modern (the Modern theme with its library).
  • Insert general-purpose icons into code: Icon Studio, Icon Hub, or one of the Auric collections.
  • Insert file-type artwork into code: File Icons' Library.

Icon Studio and the Icon Pack do not include File Icons, and installing them does not change your Explorer.

How the Auric collections merge

Auric Icons: Modern, Drawn and Playful share one library view when co-installed, with a Library filter and collection badges. Icon Studio hosts all three by default. This merging does not involve File Icons. See The merged Icon Studio.
