Shortcuts

The keyboard shortcuts Auric Artisan Font Hub provides in VS Code and inside its panels.

VS Code

Windows and LinuxmacOSCommand
Ctrl + Alt + FCmd + Alt + FAuric Artisan Font Hub: Open Font Hub
Ctrl + Alt + TCmd + Alt + TAuric Artisan Font Hub: Quick Pick Font

Other commands have no default shortcut. Assign one in Preferences: Open Keyboard Shortcuts by searching for auricFontLib.

Inside the sidebar and studio

KeysWhat they do
/ (when not typing in a field)Focus and select the search box
Ctrl + K (Cmd + K on macOS)Focus and select the search box
EscapeClose the comparison, details panel or tray; otherwise clear the search
Arrow keys on a font cardMove to the next or previous card, or the card above or below
Tab, Shift + TabMove through controls; focus stays inside an open details panel, tray or comparison
Arrow keys, type-ahead, Enter in drop-downsChoose a category, sort order, intent or industry
