Glossary

Definitions of the terms used in Auric Artisan Icon Studio.

TermMeaning
Catalog entryOne icon or emoji in the bundled catalog. Its styles or tones are not counted separately.
CollectionA set of icons from one source, such as Auric Drawn or Tabler. Icon Studio has 11.
currentColorA CSS keyword meaning "use the surrounding text colour", so an icon follows light and dark themes.
Data URIA way to embed a file's content directly in text, starting data:image/svg+xml,.
Font-backed iconAn icon drawn from a font glyph (Material), not an SVG file. It needs the font loaded to display.
For youA view of icons ranked for the file you are editing and your likes and use.
Host (collections)The one extension that shows the shared library when several Auric collection extensions, or Icon Studio, are installed.
Icon IDThe unique catalog name of an icon, such as tabler-rocket or files-blank-document-drawn-0001.
JSXThe HTML-like syntax used in React components.
Ligature nameThe word that a Material icon font turns into a glyph, such as home.
LikesIcons you marked with the heart.
Quick PickVS Code's searchable pop-up list at the top of the window.
RecentIcons you inserted, copied or saved, newest first.
ShortcodeA text name for an emoji between colons, such as :rocket:.
Skin toneA modifier that changes the skin colour of emoji that support it.
Smart insertChoosing the output format from the language of the file you are editing.
StyleA visual variant of an icon, such as Outline or Filled. Also called a variant.
SVGScalable Vector Graphics, a text format for vector images.
