Shortcuts

Every keyboard shortcut Auric Artisan Live provides in VS Code, the control panel, the preview and the in-page dashboard.

VS Code

These work whenever a folder is open. Change them in Preferences: Open Keyboard Shortcuts by searching for auricLive.

Windows and LinuxmacOSCommand
Ctrl + Alt + LCmd + Alt + LAuric Live: Go Live
Ctrl + Alt + Shift + LCmd + Alt + Shift + LAuric Live: Stop All Servers
Ctrl + Alt + KCmd + Alt + KAuric Live: Open Preview Beside
Ctrl + Alt + Shift + KCmd + Alt + Shift + KAuric Live: Open Live Menu
Ctrl + Alt + JCmd + Alt + JAuric Live: Select Run Target…
Ctrl + Alt + UCmd + Alt + UAuric Live: Reload Connected Pages
Ctrl + Alt + Shift + ICmd + Alt + Shift + IAuric Live: Open Control Panel

The other 47 commands have no default shortcut. Assign one in the Keyboard Shortcuts editor if you use them often.

Control panel

KeysWhat they do
Ctrl + F (Cmd + F)Focus the search box in the Requests section
EscapeClose request details and return focus, or close an open menu
Arrow keys, type-ahead, EnterMove through and choose from drop-down menus

Preview

KeysWhat they do

In a served page

KeysWhat they do
Alt + Shift + DOpen the developer dashboard (change with auricLive.dashboard.shortcut)
EscapeClose an open dashboard menu, then the dashboard
Left and right arrows, Home, End (tab focused)Move between dashboard tabs
Up and down arrows, Page Up, Page Down, Home, EndScroll the dashboard
Space, Shift + Space (content focused)Page down and up
