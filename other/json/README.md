# JSON edition

Machine-readable indexes of the documentation, for search tools, chat assistants or your own scripts.

| File | What it contains |
| --- | --- |
| [docs-index.json](docs-index.json) | One entry per document: area, path, title, summary, product, sections, word count and the path of each edition. |
| [tree.json](tree.json) | The folder tree with every folder's title and summary and the documents inside it. |
| [sections.json](sections.json) | Every document split into its sections (by level-2 heading) with the section's text, ready for full-text search. |

Updated 2026-09-25.
