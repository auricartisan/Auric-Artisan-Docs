# VS Code extensions

Auric Artisan publishes seventeen free extensions for Visual Studio Code under the publisher **auric-artisan**. They bring the same design system as the website into your editor: colour and accessibility linting, a theme with a live Theme Studio, icon and emoji libraries, file icon themes, a live server, a file workspace, a font hub and a formatter. None of them sends telemetry.

Two of them are packs that install a set in one step: the **Icon Pack** installs Modern, Drawn, Playful and Emoji, and the **Studio Full Pack** installs Color, Accessibility and Code Health. Every member stays its own extension that you can disable on its own.

New to installing extensions? Start with [Install and set up](install-and-setup/README.md).

## Install in one line

Run this in a terminal, replacing the ID with any from the tables above:

```text
code --install-extension auric-artisan.auric-artisan-icon-pack
code --install-extension auric-artisan.auric-artisan
```

Those two lines install both packs — five extensions. The [install guide](install-and-setup/README.md) covers the Extensions view, VSIX files, forks such as Cursor, Windsurf and VSCodium, updating, and removing extensions.
