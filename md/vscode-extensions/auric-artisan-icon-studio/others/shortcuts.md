# Shortcuts and commands

## Keybindings

| Action | Windows and Linux | macOS |
| --- | --- | --- |
| Smart Insert Icon | `Ctrl` + `Alt` + `I` | `Cmd` + `Alt` + `I` |
| Insert from Recent | `Ctrl` + `Alt` + `R` | `Cmd` + `Alt` + `R` |

Both need editor focus. They are active when Icon Studio hosts the Auric collections (the default) or when no collection extension is installed. The Auric collection extensions use the same keys, so only one extension claims them at a time.

## Keys inside Icon Studio

| Key | Action |
| --- | --- |
| `/` | Focus search |
| `Escape` | Clear search, or close an open dropdown |
| `Arrow Up` / `Arrow Down` | Open a dropdown; move between its options |
| `Home` / `End` | First or last option |
| `Enter` | Choose the focused option or button |
| `Tab` | Move on and close open dropdowns |

`auricIconStudio.insertIcon` (Insert Icon by ID) is available for keybindings and macros only. See [Commands and keybindings](../docs/commands-and-keybindings.md#insert-a-specific-icon-from-a-keybinding).
