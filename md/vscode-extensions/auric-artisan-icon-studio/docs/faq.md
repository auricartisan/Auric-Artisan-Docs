# Frequently asked questions

## Do I need Auric Icons: Modern, Drawn or Playful as well?

No. Icon Studio bundles all three collections. Install the separate extensions only if you want their own interfaces, or Modern's Explorer file icon theme.

## Does Icon Studio change my Explorer file icons?

No. It is an artwork browser and insertion tool. For Explorer file and folder icons, use [Auric Artisan File Icons](../../auric-artisan-file-icons/README.md).

## Does it need an internet connection?

No. The catalog, artwork and Material preview fonts are bundled. Icon Studio makes no network requests.

## Is it the same as Icon Hub?

No. [Icon Hub](../../auric-artisan-icon-hub/README.md) covers the seven open-source sets only, adds colour and stroke controls, sprite and ZIP export and CDN insertion, and can check the website for catalog updates. Icon Studio adds the Auric artwork and emoji and works entirely offline. See the [comparison](../others/related.md).

## Can I change the size or colour of inserted icons?

Yes, through settings: `auricIconStudio.size`, `auricIconStudio.color` and `auricIconStudio.strokeWidth`. See [Insert, copy and save](insert-copy-and-save.md#control-the-output).

## Can I search in Hindi?

Many entries have Hindi search aliases. The interface itself is in English.

## Why do Material icons not export as SVG?

Material icons in this catalog are glyphs in a font, not SVG files. Icon Studio offers HTML, JSX, React, JavaScript, CSS and ligature-name output instead.

## Can I use the artwork in my own projects?

Auric artwork is covered by the Auric Artisan Free Use Licence, which restricts extracting and redistributing artwork. Third-party icons keep their own licences (MIT, ISC, Remix v1.0, Apache-2.0). Check the licence for your use.

## Where are my likes stored?

In VS Code's extension storage on this machine. See [Privacy](../others/privacy.md).
