# Glossary

| Term | Meaning |
| --- | --- |
| Bridge | The small `icons.auricartisan.com.js` loader file Icon Hub creates next to your source on the first CDN Insert. |
| Catalog metadata | The data describing icons (names, terms, counts), separate from the artwork itself. |
| CDN | A content delivery network: a web service that serves icon data and fonts to your pages. |
| CDN placeholder | An element such as `<span data-icon="set:name" …>` that the CDN script turns into an icon. |
| Content security policy | A website rule listing which sources may load scripts, fonts and data. |
| `currentColor` | A CSS keyword meaning "use the surrounding text colour". |
| Data URI | Text that embeds a file directly, starting `data:`. |
| Font-backed icon | An icon drawn from a font glyph (Material), not an SVG file. |
| Indexed variant | One style of one icon. Icon Hub indexes 32,802. |
| Selection | Icons you ticked for export. Up to 200 per export. |
| Smart Finder | A local panel of recent icons and a rotating sample of the catalog. |
| SVG sprite | One SVG file containing several icons as reusable symbols. |
