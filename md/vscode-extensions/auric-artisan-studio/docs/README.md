# Auric Artisan Studio docs

This folder holds the guides that apply to the Studio as a whole: the screens every extension shares, how installed extensions combine into one Workstation, scanning, scores, reports and the CI gate. Features that belong to one extension are documented in that extension's folder: [Auric Color](../color/README.md), [Auric Accessibility](../accessibility/README.md) and [Auric Code Health](../code-health/README.md).

Start with [Getting started](getting-started.md). If you are deciding what to install, read [Choose what to install](choosing-an-install.md) first.
