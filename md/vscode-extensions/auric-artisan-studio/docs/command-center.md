# The Command Center

The **Command Center** is a searchable list of everything the installed Studio extensions can do right now: suggested next steps, actions, recent colours, the worst findings and the files the Studio has written. It is a native VS Code quick pick, so it looks and behaves like the Command Palette.

## Open it

- Press `Ctrl` + `Alt` + `.` (`Cmd` + `Alt` + `.` on macOS). The shortcut works anywhere in VS Code.
- Or run **Auric Artisan: Workstation: Command Center** from the Command Palette (`Ctrl` + `Shift` + `P`).

The list is titled **Auric Artisan — Command Center**. Type to filter; the filter matches titles and their descriptions. Press `Enter` to run the highlighted item, or `Escape` to close.

When several Studio extensions are installed, the shortcut opens the host's Command Center, which covers every installed capability. See [The Workstation](workstation.md).

## Sections

Sections appear in this order, and only when they have something in them.

### Suggested

The same deterministic suggestions the Overview shows, up to three. Each shows its title and, as its description, the reason it fired. See [The suggestion rules](#the-suggestion-rules).

### Actions

Only actions for installed capabilities are listed.

| Action | Description shown | Needs |
| --- | --- | --- |
| **Scan project** | WCAG + contrast + CVD (uses cache) | Auric Accessibility |
| **Rescan project** | force-refresh the scan cache | Auric Accessibility |
| **Open Studio: …** | none; one entry per Studio tool (listed below) | The tool's extension |
| **Open rulebook & knowledge database** | rules, standards, manual checks, policies, and articles | Any |
| **Build workspace knowledge database** | knowledge.json + rulebook.md + validated team overrides | Any |
| **Open unified Icon Studio** | how many icon collections are installed and through which provider, or install an Auric Icons provider to enable the combined library | Any |
| **Pick / edit color** | inline picker on the token under the cursor | Auric Color |
| **Check contrast of selection** | | Auric Color |
| **Fix all contrast in file** | recolor every failing pair (one undo) | Auric Color |
| **Project health report** | Markdown + JSON, written locally | Auric Code Health |
| **Write health record** | health.json + SARIF for CI | Auric Code Health |
| **Open data folder** | .auric-artisan workspace store | Auric Code Health |
| **Generate AI remediation plan** | agent-ready fix plan with a design-token draft | Auric Accessibility or Auric Code Health |

The **Open Studio** entries are, in order and for installed capabilities only: **Scan** (the Studio's **Home** space), **Code Health**, **Preview**, **Contrast**, **Brand**, **Palette**, **Shades**, **Vision** and **Settings**.

### Recent colors

Up to eight colours you applied recently with a Studio picker (Auric Color). Select one to open the colour picker on that value. If an editor is open, a colour you then apply from the picker is inserted at the cursor.

### Findings

Up to eight of the worst findings from the last scan, each with its file name and line. Select one to open the file at that line. Contrast rows read like `#999999 on #FFFFFF · 2.32:1`; other rows show the finding's message.

### Artifacts

Files the Studio has written to the workspace's `.auric-artisan` folder. Only files that exist are listed.

| File | Description shown |
| --- | --- |
| `health.json` (or the name set in `health.fileName`) | unified health record |
| `knowledge.json` | searchable rules and guidance database |
| `rulebook.md` | generated engineering rulebooks |
| `knowledge-overrides.json` | reviewed workspace knowledge overrides |
| `ai-remediation-plan.md` | agent-ready remediation plan |
| `project-health.md` | project health report |

## The suggestion rules

Suggestions are produced by a fixed set of six rules. They are **not** generated by AI or machine learning, and nothing is sent anywhere: each rule checks one fact from your last scan or your open file. Rules are checked in the order below, at most three suggestions are shown, and a suggestion you dismiss is never offered again.

| # | Suggestion | Pill | Shown when | Action |
| --- | --- | --- | --- | --- |
| 1 | **N possible secrets detected** | Critical | The last scan found at least one possible hardcoded secret | **Open health report** (with Auric Code Health), otherwise **Review in Studio** |
| 2 | **N fixable contrast pairs in this file** | High | Auric Color is installed and the active file has at least two contrast pairs that can be fixed automatically | **Fix all in file**, plus **Review**, which opens the first pair in the Contrast Studio |
| 3 | **"rule-id" appears in N files** | High | Auric Accessibility is installed and one WCAG rule fires in three or more files | **Open the findings** (Check › Findings) |
| 4 | **Scan is N hours old** | Workflow | Auric Accessibility is installed and the loaded scan is older than `scan.cache.maxAgeMinutes` | **Rescan** |
| 5 | **Scanned X of Y files** | Workflow | Auric Accessibility or Auric Color is installed and the last scan stopped at the `scan.maxFiles` limit | **Scan settings** (Studio › Settings) |
| 6 | **N color values repeat 4+ times** | Tip | At least six colour values are each used four or more times, and Auric Accessibility or Auric Code Health is installed | **Draft tokens** (generates the remediation plan, which includes a design-token draft) |

Each suggestion states a detected fact in its title and gives a one-line reason, for example **the code-health scan found hardcoded credentials** or **one rule firing across files usually shares a single fix**.

### Dismissing suggestions

- In the Overview, select **✕** on a suggestion card. It disappears and is not offered again, even after later scans.
- VS Code remembers the dismissal across sessions. The Studio keeps the 40 most recent dismissals.
- There is no command to bring a dismissed suggestion back.

The Colour workbench layout of the Overview shows only suggestion 2, because it has no project score. The Command Center itself always evaluates all six rules for the installed capabilities.
