# Auric Code Health shortcuts

## Keyboard shortcuts

| Windows and Linux | macOS | Command |
| --- | --- | --- |
| `Ctrl` + `Alt` + `.` | `Cmd` + `Alt` + `.` | Workstation: Command Center |
| `Ctrl` + `.` | `Cmd` + `.` | VS Code's quick fixes, including **Ignore this … finding here** |

## Command Palette titles

Type `Auric Artisan` in the Command Palette:

- Auric Artisan: Open Code Health Studio
- Auric Artisan: Workstation: Command Center
- Auric Artisan: Open Rulebook & Knowledge Database
- Auric Artisan: Build Workspace Knowledge Database (JSON + Markdown)
- Auric Artisan: Open Unified Icon Studio
- Auric Artisan: Generate Agent-Ready Remediation Plan
- Auric Artisan: Generate Project Health Report (Color, A11y & Code Health)
- Auric Artisan: Write Health Record (health.json + SARIF)
- Auric Artisan: Clear Workspace Scan Cache
- Auric Artisan: Open Workspace Data Folder

## In the Studio's Health space

| Keys | What it does |
| --- | --- |
| `/` | Focus the findings search box |
| `Escape` | Close pop-ups, then clear the search |
| `Enter`, `Space` | Open the selected finding's file at its line |
