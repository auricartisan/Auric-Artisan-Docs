# Full Pack release notes

The pack shares one version number with its members. The full history of what changed in the members is in the [Studio release notes](../../others/release-notes.md).

## 0.1.0 — Initial Studio release

- The first public release of the Full Pack.
- Installs only the three Studio extensions: Auric Color, Auric Accessibility and Auric Code Health. Icon themes and icon libraries are not part of the pack.
- Each member stays independently installable, updatable and removable.

## Unreleased

The changelog lists no changes to the pack itself under **Unreleased**. The upcoming changes to its members are listed in the [Studio release notes](../../others/release-notes.md#unreleased).
