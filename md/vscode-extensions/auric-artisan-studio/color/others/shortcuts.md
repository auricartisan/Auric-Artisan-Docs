# Auric Color shortcuts

## Keyboard shortcuts

| Windows and Linux | macOS | Command |
| --- | --- | --- |
| `Ctrl` + `Alt` + `C` | `Cmd` + `Alt` + `C` | Pick / edit color (editor focused) |
| `Ctrl` + `Alt` + `.` | `Cmd` + `Alt` + `.` | Workstation: Command Center |
| `Ctrl` + `.` | `Cmd` + `.` | VS Code's quick fixes, including **Fix contrast** |

## Command Palette titles

Type `Auric Artisan` in the Command Palette (`Ctrl` + `Shift` + `P`):

- Auric Artisan: Open Color Studio
- Auric Artisan: Workstation: Command Center
- Auric Artisan: Open Rulebook & Knowledge Database
- Auric Artisan: Build Workspace Knowledge Database (JSON + Markdown)
- Auric Artisan: Open Unified Icon Studio
- Auric Artisan: Generate Accessible Palette
- Auric Artisan: Check Contrast of Selection
- Auric Artisan: Fix All Contrast Issues in File
- Auric Artisan: Pick / edit color
- Auric Artisan: Choose Color Picker Mode
- Auric Artisan: Disable native color picker (use Auric Artisan)
- Auric Artisan: Restore native color picker (use VS Code's)
- Auric Artisan: Refresh Contrast Diagnostics
- Auric Artisan: Change Accent Color (Theme the Studio)
- Auric Artisan: Mark Line as Intentional Branding (Toggle)

## Picker keys

| Keys | What they do |
| --- | --- |
| Arrow keys on the hue or opacity bar | Change the value by 1 (`Shift` for 10) |
| `Page Up`, `Page Down` | Change the value by 10 |
| `Home`, `End` | Jump to the minimum or maximum |
| `Left`, `Right` on the spectrum | Change saturation |
| `Up`, `Down` on the spectrum | Change brightness |
| `Escape` | Close the picker panel |

For every Studio key, see the [Studio shortcuts](../../others/shortcuts.md).
