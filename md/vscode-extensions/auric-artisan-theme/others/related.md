# Related extensions and tools

## Other Auric Artisan VS Code extensions

| Extension | How it relates |
| --- | --- |
| [Auric Artisan File Icons](../../auric-artisan-file-icons/README.md) | File and folder icons for the Explorer, in Facet, Playful and Modern styles. Pairs with the theme for a complete look. |
| [Auric Artisan Icon Studio](../../auric-artisan-icon-studio/README.md) | Search and insert icons and emoji into code. |
| [Auric Artisan Emoji](../../auric-artisan-emoji/README.md) | Emoji Studio with the same English and Hindi interface switch. |
| [Auric Artisan Studio](../../auric-artisan-studio/README.md) | Colour, accessibility and code-health tools for your project files. |
| [Auric Artisan Live](../../auric-artisan-live/README.md) | Live server and preview; Theme Studio's layout follows the same workspace design. |

For installing and managing any of these, see [Install and set up](../../install-and-setup/README.md).

## Website tools

| Tool | Why it is useful with the theme |
| --- | --- |
| [Contrast Checker](../../../website/tools/accessibility-and-vision/contrast-checker/README.md) | Check a single colour pair in detail, including WCAG and APCA values. |
| [Design Engine](../../../website/tools/colour-workspace/design-engine/README.md) | Build a design system palette in OKLCH that you can mirror in your editor. |
| [Colour Science Lab](../../../website/tools/colour-workspace/colour-science-lab/README.md) | Explore colour models such as OKLCH in depth. |
