# Shortcuts

## VS Code

| Windows and Linux | macOS | Command |
| --- | --- | --- |
| `Ctrl` + `Alt` + `F` | `Cmd` + `Alt` + `F` | **Auric Artisan Font Hub: Open Font Hub** |
| `Ctrl` + `Alt` + `T` | `Cmd` + `Alt` + `T` | **Auric Artisan Font Hub: Quick Pick Font** |

Other commands have no default shortcut. Assign one in **Preferences: Open Keyboard Shortcuts** by searching for `auricFontLib`.

## Inside the sidebar and studio

| Keys | What they do |
| --- | --- |
| `/` (when not typing in a field) | Focus and select the search box |
| `Ctrl` + `K` (`Cmd` + `K` on macOS) | Focus and select the search box |
| `Escape` | Close the comparison, details panel or tray; otherwise clear the search |
| Arrow keys on a font card | Move to the next or previous card, or the card above or below |
| `Tab`, `Shift` + `Tab` | Move through controls; focus stays inside an open details panel, tray or comparison |
| Arrow keys, type-ahead, `Enter` in drop-downs | Choose a category, sort order, intent or industry |
