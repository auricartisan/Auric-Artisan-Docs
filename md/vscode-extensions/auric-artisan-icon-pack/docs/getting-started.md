# Getting started with the Icon Pack

## Before you begin

- You need Visual Studio Code 1.85 or later.
- You need access to the extension marketplace. The pack downloads its members from it.

## 1. Install the pack

1. Open the Extensions view (`Ctrl` + `Shift` + `X`).
2. Search for **Auric Artisan Icon Pack** and select **Install**.

Or run `code --install-extension auric-artisan.auric-artisan-icon-pack` in a terminal, or use **Extensions: Install from VSIX…** with an official pack download.

## 2. Check the members

1. Select the pack in the Extensions view.
2. Open its **Extension Pack** section. It lists:
   - **Auric Icons: Modern** (`auric-artisan.auric-artisan-modern-icon`)
   - **Auric Icons: Playful** (`auric-artisan.auric-icons-playful`)
   - **Auric Artisan Emoji** (`auric-artisan.auric-artisan-emoji`)
   - **Auric Icons: Drawn** (`auric-artisan.auric-icons-drawn`)
3. Each should show as installed.

## 3. Start using them

| To | Do this |
| --- | --- |
| Browse Modern, Drawn and Playful icons | Select the Auric icon library in the Activity Bar: one merged library with a **Library** filter. |
| Insert an icon from the keyboard | Press `Ctrl` + `Alt` + `I` in a text editor. |
| Insert an emoji | Press `Ctrl` + `Alt` + `J`, or open **Auric Emoji** in the Activity Bar. |
| Change your Explorer icons | Run **Preferences: File Icon Theme** and choose **Auric Icons: Modern**. |

How the three icon libraries share one view is explained in [The merged Icon Studio](../../auric-icons-modern/docs/merged-icon-studio.md).
