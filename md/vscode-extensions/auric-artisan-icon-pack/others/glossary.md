# Glossary

| Term | Meaning |
| --- | --- |
| Extension pack | A VS Code extension whose only job is to install a list of other extensions. |
| Member | One of the extensions an extension pack installs. |
| Extension ID | The unique publisher-and-name identifier of an extension, such as `auric-artisan.auric-icons-drawn`. |
| Marketplace | The online registry VS Code installs extensions from. |
| VSIX | A packaged extension file that can be installed with **Extensions: Install from VSIX…**. |
| Merged library | The single icon library view shown when Modern, Drawn and Playful are installed together. |
