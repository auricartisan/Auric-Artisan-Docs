# Privacy

The pack itself runs no code. It adds no telemetry, background service or workspace edits, and stores nothing.

VS Code contacts the extension marketplace to download the four members, as it does for any extension.

Each member has its own privacy behaviour:

- [Auric Icons: Modern — Privacy](../../auric-icons-modern/others/privacy.md)
- [Auric Icons: Playful — Privacy](../../auric-icons-playful/others/privacy.md)
- [Auric Artisan Emoji — Privacy](../../auric-artisan-emoji/others/privacy.md)
- [Auric Icons: Drawn — Privacy](../../auric-icons-drawn/others/privacy.md)
