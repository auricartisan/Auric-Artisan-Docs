# Frequently asked questions

## Do I need another icon extension?

No. All three styles and their artwork are included.

## Can I use two styles at once?

No. VS Code allows one file icon theme at a time. Switch whenever you like.

## Why do changes need a reload?

VS Code caches icon themes. The extension rebuilds the theme when you change appearance or associations; a reload shows the new icons.

## Does smart detection change the icon itself?

No. It adds a badge, colour and explanation on top. Use **Apply Detected Folder Icon** or **Scan Workspace for Folder Icons** to make a detected icon permanent.

## Does it run my project's code?

No. Smart detection reads a bounded number of names and the start of small text files. It never executes anything.

## Can I use the icons in my own projects?

You can insert them into code from the Studio. The artwork is covered by the Auric Artisan Free Use Licence, which restricts redistribution, resale, republishing and extracting bundled artwork. Review it before reusing artwork outside the extension.

## Is the Playful style the same as Auric Icons: Playful?

No. They are different artwork. See [Modern and older Playful settings](modern-and-legacy.md#not-the-same-playful).

## How is this different from Icon Studio?

File Icons changes your Explorer and offers its own file-type artwork for code. Auric Artisan Icon Studio is a general icon and emoji browser and does not change the Explorer. See the [comparison](../others/related.md).
