# Related extensions and comparison

| Extension | Main job | Emoji | Network |

| [Auric Artisan Emoji](../README.md) | The full emoji workflow: Studio, sequences, completions, hovers, shortcode replacement, six formats, Hindi interface. | 1,914 | None |
| [Icon Studio](../../auric-artisan-icon-studio/README.md) | One offline studio for Auric icons, emoji and seven open-source sets. Emoji copy as character, shortcode, code points or HTML entities. | 1,914 | None |
