# Glossary

| Term | Meaning |
| --- | --- |
| Click action | What happens when you select an emoji or press `Enter` on it: insert, copy, or both. |
| Code point | The Unicode number of a character, written like `U+1F680`. |
| Copy format | The text form used when copying: emoji, shortcode, Unicode, HTML, JavaScript or CSS. |
| CSS escape | A backslash form such as `\1F680`, valid inside CSS strings. |
| Curated | A hand-picked selection of commonly useful emoji. |
| HTML entity | A form such as `&#x1F680;` that HTML turns into the character. |
| Inspector | The panel showing an emoji's details and every output format. |
| JavaScript escape | A form such as `\u{1F680}`, valid inside JavaScript and TypeScript strings. |
| Sequence | A list of up to 50 emoji collected to insert or copy together. |
| Shortcode | A text name between colons, such as `:rocket:`. |
| Skin tone | A modifier changing the skin colour of emoji that support it. |
| Yellow | The standard, unmodified appearance of tone-capable emoji. |
