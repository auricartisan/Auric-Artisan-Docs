# Shortcuts

## VS Code

| Windows and Linux | macOS | Command | When |
| --- | --- | --- | --- |
| `Ctrl` + `Alt` + `Shift` + `F` | `Cmd` + `Alt` + `Shift` + `F` | **Preview Formatting as a Diff** | An editor has focus |
| `Ctrl` + `Alt` + `Shift` + `P` | `Cmd` + `Alt` + `Shift` + `P` | **Open Formatter Studio** | Any time |
| `Ctrl` + `Alt` + `Shift` + `U` | `Cmd` + `Alt` + `Shift` + `U` | **Show Files That Need Formatting** | Any time |

There is deliberately no shortcut for formatting every file. VS Code's own **Format Document** (`Shift` + `Alt` + `F` on Windows) and **Format Selection** use Auric once it is the default formatter. Assign shortcuts to other commands in **Preferences: Open Keyboard Shortcuts** by searching for `auricFormatter`.

## Formatter Studio

| Keys | What they do |
| --- | --- |
| `Ctrl` + `K` | Open the Studio command palette |
| Left and right arrows on the tabs | Switch between **01 Studio** and **02 Workspace** |
| Arrow keys, type-ahead, `Enter` in drop-downs | Choose a language, preset, category or view |
| `Escape` | Close the command palette or an open drop-down |
