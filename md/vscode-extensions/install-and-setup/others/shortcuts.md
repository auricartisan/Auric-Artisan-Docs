# Shortcuts and commands

These are VS Code's own default keys on Windows and Linux. On macOS, use `Cmd` in place of `Ctrl`. Each extension's own shortcuts are listed in that extension's folder.

## Keys

| Keys | What they do |
| --- | --- |
| `Ctrl` + `Shift` + `X` | Open the Extensions view |
| `Ctrl` + `Shift` + `P` | Open the Command Palette |
| `Ctrl` + `,` | Open the Settings editor |

## Commands

| Command | Use it to |
| --- | --- |
| **Extensions: Install from VSIX…** | Install from a downloaded `.vsix` file |
| **Extensions: Check for Extension Updates** | Check for new versions now |
| **Developer: Reload Window** | Reload after installing, updating or changing a language |
| **Configure Display Language** | Change VS Code's own display language |
| **Workspaces: Manage Workspace Trust** | Trust or restrict the open folder |
| **Preferences: Open User Settings (JSON)** | Edit user settings directly |
| **Preferences: Open Workspace Settings (JSON)** | Edit workspace settings directly |
| **Preferences: Open Keyboard Shortcuts** | Find and change shortcuts, and spot conflicts |

## Extension shortcuts at a glance

These are the default shortcuts the four workspace-tool extensions declare. The full lists are in each extension's folder.

| Extension | Keys (Windows and Linux) | Command |
| --- | --- | --- |
| Auric Artisan Live | `Ctrl` + `Alt` + `L` | **Auric Live: Go Live** |
| Auric Artisan Live | `Ctrl` + `Alt` + `K` | **Auric Live: Open Preview Beside** |
| Auric Artisan File System | `Alt` + `Enter` (Explorer focused) | **Auric Files: File Properties** |
| Auric Artisan Font Hub | `Ctrl` + `Alt` + `F` | **Auric Artisan Font Hub: Open Font Hub** |
| Auric Artisan Font Hub | `Ctrl` + `Alt` + `T` | **Auric Artisan Font Hub: Quick Pick Font** |
| Auric Artisan Formatter | `Ctrl` + `Alt` + `Shift` + `F` (editor focused) | **Auric Formatter: Preview Formatting as a Diff** |
| Auric Artisan Formatter | `Ctrl` + `Alt` + `Shift` + `P` | **Auric Formatter: Open Formatter Studio** |

These four extensions document `Cmd` in place of `Ctrl` on macOS for the combinations above.
