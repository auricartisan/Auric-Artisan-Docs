# Getting started with Auric Icons: Drawn

## Before you begin

- You need Visual Studio Code 1.85 or later, or an editor that keeps VS Code's extension features.
- Everything works offline. There is no telemetry and no network access.

## 1. Install

Open the Extensions view (`Ctrl` + `Shift` + `X`), search for **Auric Icons: Drawn** and select **Install**, or run:

```text
code --install-extension auric-artisan.auric-icons-drawn
```

## 2. Open the Icon Library

- Select **Auric Icons: Drawn** in the Activity Bar to open the **Icon Library** view, or
- Run **Auric Icons: Drawn: Open Icon Library** to open the larger **Icon Studio — Library** editor tab.

If Auric Artisan Icon Studio or Auric Icons: Modern is also installed, the Drawn view may be hidden because the other extension shows a merged library that already contains Drawn. See [Use Drawn with Modern and Playful](merged-icon-studio.md).

## 3. Look around

The view shows a header with the icon count, up to four smart guide tips, a **Search** box, **Category** and **Style** filters, **Variant** buttons (**Auto**, **Color**, **Mono**, **Outline**, **Duotone**), **Preview surface** buttons (**Auto**, **Light**, **Dark**), the **All**, **✦ For you**, **♥ Likes** and **↺ Recent** chips, a **✦ Recommended for this file** rail and the icon grid.

## 4. Insert your first icon

1. Open a file and place the cursor.
2. Type `calendar` in **Search**.
3. Select **Insert** on a card. With smart insert on (the default), a React file receives a JSX element, an HTML file receives SVG markup and a stylesheet receives a CSS background.

Or press `Ctrl` + `Alt` + `I` (`Cmd` + `Alt` + `I` on macOS) in the editor, search, and choose an icon.

## 5. Like the icons you reuse

Select the heart on a card. Liked icons appear under **♥ Likes** and in **Insert from Likes**, and they improve your recommendations.

## Result

You have inserted a Warm Drawn icon into your file in a format that suits it.
