# Frequently asked questions

## Why is there no file icon theme?

Drawn's icons are 64-pixel illustrations. They do not have the paired 16-pixel folder shapes and file associations a good Explorer theme needs. Install Auric Icons: Modern for the family's Explorer theme.

## Do I need Modern or Playful too?

No. Drawn works alone. Installing them together gives you one merged library.

## Is Drawn included in Icon Studio?

Yes. Auric Artisan Icon Studio bundles the Drawn collection, so you do not need this extension to use Drawn artwork there.

## Is it free?

Yes, free to use for any purpose. Redistribution and resale are not permitted.

## Does it work offline?

Yes. There is no network access or telemetry.

## Can I change icon size or colour on insert?

Not in this extension; icons are inserted as drawn. Auric Artisan Icon Studio has size and colour output settings.

## Where are my likes kept?

In VS Code's storage for this extension on your machine. They stay with Drawn even when another extension hosts the merged library.
