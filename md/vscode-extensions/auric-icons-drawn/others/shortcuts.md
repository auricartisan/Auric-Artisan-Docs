# Shortcuts and commands

## Keybindings

| Action | Windows and Linux | macOS |
| --- | --- | --- |
| Smart Insert Icon | `Ctrl` + `Alt` + `I` | `Cmd` + `Alt` + `I` |
| Insert from Recent | `Ctrl` + `Alt` + `R` | `Cmd` + `Alt` + `R` |

Both need a focused text editor and are active only while Drawn hosts the library.

## Keys in the Icon Library

| Key | Action |
| --- | --- |
| `/` | Focus search |
| `Escape` | Clear search; close a dropdown |
| `Arrow Up` / `Arrow Down` | Move between dropdown options |

## Commands

Type "Auric Icons: Drawn" in the Command Palette: **Open Icon Library**, **Search Icons**, **Insert SVG at Cursor**, **Smart Insert Icon (matches active language)**, **Copy Icon As… (JSX, CSS, Markdown, Data URI, Image tag)**, **Insert from Likes**, **Insert from Recent**, **Toggle Like for an Icon**, **Clear Likes, Recents and Learned Recommendations**, **Copy SVG**, **Save SVG As…**, **Open SVG Source**.

See the [reference](../docs/reference.md#commands) for IDs and details.
