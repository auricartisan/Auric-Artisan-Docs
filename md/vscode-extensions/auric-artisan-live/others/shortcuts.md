# Shortcuts

## VS Code

These work whenever a folder is open. Change them in **Preferences: Open Keyboard Shortcuts** by searching for `auricLive`.

| Windows and Linux | macOS | Command |
| --- | --- | --- |
| `Ctrl` + `Alt` + `L` | `Cmd` + `Alt` + `L` | **Auric Live: Go Live** |
| `Ctrl` + `Alt` + `Shift` + `L` | `Cmd` + `Alt` + `Shift` + `L` | **Auric Live: Stop All Servers** |
| `Ctrl` + `Alt` + `K` | `Cmd` + `Alt` + `K` | **Auric Live: Open Preview Beside** |
| `Ctrl` + `Alt` + `Shift` + `K` | `Cmd` + `Alt` + `Shift` + `K` | **Auric Live: Open Live Menu** |
| `Ctrl` + `Alt` + `J` | `Cmd` + `Alt` + `J` | **Auric Live: Select Run Target…** |
| `Ctrl` + `Alt` + `U` | `Cmd` + `Alt` + `U` | **Auric Live: Reload Connected Pages** |
| `Ctrl` + `Alt` + `Shift` + `I` | `Cmd` + `Alt` + `Shift` + `I` | **Auric Live: Open Control Panel** |

The other 47 commands have no default shortcut. Assign one in the Keyboard Shortcuts editor if you use them often.

## Control panel

| Keys | What they do |
| --- | --- |
| `Ctrl` + `F` (`Cmd` + `F`) | Focus the search box in the Requests section |
| `Escape` | Close request details and return focus, or close an open menu |
| Arrow keys, type-ahead, `Enter` | Move through and choose from drop-down menus |

## Preview

| Keys | What they do |
| --- | --- |
| `Enter` in the address box | Load the typed address |

## In a served page

| Keys | What they do |
| --- | --- |
| `Alt` + `Shift` + `D` | Open the developer dashboard (change with `auricLive.dashboard.shortcut`) |
| `Escape` | Close an open dashboard menu, then the dashboard |
| Left and right arrows, `Home`, `End` (tab focused) | Move between dashboard tabs |
| Up and down arrows, `Page Up`, `Page Down`, `Home`, `End` | Scroll the dashboard |
| `Space`, `Shift` + `Space` (content focused) | Page down and up |
