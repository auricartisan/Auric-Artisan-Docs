# Auric Icons: Modern

Auric Icons: Modern is two things in one VS Code extension. First, it is an original library of 720 modern SVG icons in two families, **Simple Modern** and **Sharp Modern**, each available in **Color**, **Mono**, **Outline** and **Duotone** variants. You search the library in an **Icon Library** view and insert icons into your code in a format that suits the file.

Second, it is a file and folder icon theme for the VS Code Explorer, also called **Auric Icons: Modern**. The theme has 408 icons with a distinct file silhouette, true open and closed folder pairs, semantic colours, four framework packs (Angular, NestJS, React and Redux, Vue and Pinia) and custom associations. You can re-tint folders, adjust saturation and opacity, and hide the Explorer arrows.

Modern can be installed alone or alongside its sibling extensions **Auric Icons: Drawn** and **Auric Icons: Playful**. When they are installed together they show one shared library, labelled **Icon Studio**, with a **Library** filter and a badge on each card showing where it comes from.

## Who it is for

- Developers who want a crisp, consistent Explorer icon theme that works at the 16-pixel Explorer size.
- Front-end developers and designers who insert SVG icons into components, pages, stylesheets and documentation.
- Teams using Angular, NestJS, React or Vue who want framework-specific file icons.

## Quick start

1. Install the extension.
2. Run **Preferences: File Icon Theme** and choose **Auric Icons: Modern**, or run **Auric Icons: Modern: Activate Icon Theme**. Your Explorer now uses Modern icons.
3. Run **Auric Icons: Modern: Configure…** to choose a folder colour or a framework pack.
4. Open a file you are working on and place the cursor where an icon should go.
5. Select **Auric Icons: Modern** in the Activity Bar to open the **Icon Library**.
6. Search for an icon, for example `chart`.
7. Select **Insert** on a card, or press `Ctrl` + `Alt` + `I` in the editor to pick an icon from a list.

## What you can do

- Use a 408-icon Explorer theme covering 265 file extensions, 462 exact filenames and 265 folder names.
- Re-tint folders with a preset or any hex colour, without changing the semantic colours of file icons.
- Layer one framework pack over the base icons: Angular, NestJS, React and Redux, or Vue and Pinia.
- Map your own file extensions, filenames and folder names to icons.
- Search 720 library icons by name, concept or synonym, filter by category and style, and preview on light or dark surfaces.
- Insert with language-aware output, copy in nine formats, save an SVG file or open its source.
- Keep likes and recent icons, and see recommendations for the file you are editing.
- Hover over an icon ID in code to preview it.
- Merge with Drawn and Playful into one library when co-installed.
