# Frequently asked questions

## Is it free?

Yes. It is free to install and use for any purpose, personal or commercial. Redistribution, republishing and resale are not permitted.

## Do I have to use both the theme and the library?

No. The file icon theme and the Icon Library are independent. Use either or both.

## Why does changing a setting need a reload?

VS Code reads icon themes once and caches them. The extension rebuilds the theme files when you change a setting, and a window reload shows the result.

## Does folder colour change file icons too?

No. It re-tints folders only. File icons keep the semantic colours that identify them. Use saturation and opacity to tone down all icons.

## Can I use two framework packs at once?

No. One pack is active at a time.

## What is the difference between Modern and Sharp?

They are the two style families in the 720-icon library: 420 Simple Modern icons and 300 Sharp Modern icons. Filter by **Style** to see one family.

## How is this different from Auric Artisan File Icons?

File Icons offers three Explorer styles (Facet, Playful and Modern) with its own studio, smart decorations and profiles. This extension offers the Modern Explorer theme plus the 720-icon library. See the [comparison](../others/related.md).

## Does Modern need the internet?

No. It has no network access and no telemetry at runtime.

## Where did the hand-drawn icons go?

Since version 0.4.0 the hand-drawn (Warm Drawn) icons live in **Auric Icons: Drawn**. Install it alongside Modern to browse both in one library.
