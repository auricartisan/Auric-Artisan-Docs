# Licences

Auric Artisan does not claim ownership of any font on the CDN. Each typeface remains the property of its authors and is redistributed under its original licence. The collection's licence reference, at https://fonts.auricartisan.com/LICENSE.md, lists the licences and reproduces their texts.

## The licences in the collection

The reference describes the served collection as follows:

| Licence | Commercial use | Redistribute | Modify | Main condition |
|---|---|---|---|---|
| SIL Open Font License 1.1 (the default) | Yes | Yes | Yes | Keep the licence; never sell the font alone; rename modified versions that use a Reserved Font Name |
| Apache License 2.0 | Yes | Yes | Yes | Keep the licence and notices; state significant changes |
| CC0 1.0 / public domain | Yes | Yes | Yes | None |
| Bitstream Vera Fonts License | Yes | Yes | Yes | A modified version must be renamed without "Bitstream" or "Vera" |

The catalogue's own statistics also count a few families under MIT and one under a custom licence, and some with no licence text found. The Font Library marks those **Unspecified** or **Custom**.

## Where to find a family's licence

- **The License tab** in the Font Library shows the licence name, a **License URL** where known, the original licence file, the copyright, a permissions summary and the **Full license** text.
- **The stylesheet's header comment** names the licence and copyright, for example "SIL Open Font License 1.1 · Copyright 2011 The Alegreya Project Authors".
- **Download kits** include `LICENSE.txt` when the library has the text, and `README.txt` names the licence.
- **Use & Embed** ends with a note naming the family's licence.

## The permissions summary

For each family, the License tab marks each of these as allowed, not allowed or unknown:

- Commercial use
- Modification
- Redistribution
- Private / personal use
- Web embedding
- Sell font on its own

The summary is a guide. The licence text is what counts.

## Complying

1. Read the family's licence before you ship.
2. When you self-host, keep the licence file with the font files; the kit is organised to make this easy.
3. Do not sell OFL fonts on their own. Selling a product that uses them, such as a website, an app or a printed piece, is allowed.
4. If you modify an OFL font that has a Reserved Font Name, rename your version.
5. For **Unspecified** or **Custom** licences, check with the foundry first.
6. **Installed** families are not licensed for redistribution through the CDN; license them from their makers.
