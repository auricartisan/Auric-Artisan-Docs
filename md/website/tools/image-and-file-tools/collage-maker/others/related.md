| Tool | Why you might use it with the Collage Maker |
|---|---|
| [Image Picker](../../image-picker/README.md) | Take a palette from a finished collage exported as PNG or JPEG |
| [SVG Recolour](../../svg-recolour/README.md) | Recolour vector artwork before exporting it as a picture for a collage |
| [LUT Lab](../../lut-lab/README.md) | Check what a colour grade does to your photographs |
