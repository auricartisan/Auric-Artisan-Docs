# Collage Maker shortcuts

## Keyboard

| Keys | Action | Works when |
|---|---|---|
| `Ctrl` + `Z` | Undo | Focus is not in a slider, menu or text box |
| `Ctrl` + `Shift` + `Z` | Redo | As above |
| `Ctrl` + `Y` | Redo | As above |
| Arrow keys | Nudge the selected picture 1 px | The canvas has focus (click it first) |
| `Shift` + arrow keys | Nudge the selected picture 10 px | The canvas has focus |
| `Delete` or `Backspace` | Remove the selected picture | The canvas has focus |
| `Enter` or `Space` | Open the file chooser | The **Drop pictures** box has focus |

On a Mac, `Cmd` works in place of `Ctrl`. With the canvas focused, one press of the undo or redo shortcut can move two steps; use the **Undo** and **Redo** buttons when you want exactly one.

Every control on the page can be reached with `Tab`. Each tab button, slider, switch and button responds to the keyboard in the usual way.

## Pointer

| Action | Result |
|---|---|
| Click a picture | Select it (the top one where pictures overlap) |
| Click empty canvas | Clear the selection |
| Drag a picture | Move it; snapped to 10 px when snapping is on |
| Drag a corner handle | Resize the selected picture around its centre, from 2% to 800% |
| Click a row in **Layers · top first** | Select that picture, including a hidden one |
| Drop image files on the canvas or the drop box | Add them as pictures |
