# Collage Maker glossary

| Term | Meaning |
|---|---|
| Arrangement | A grid of equal cells, given as columns × rows, into which the visible pictures are placed in stacking order |
| Canvas | The rectangle the collage is drawn on; always 1200 pixels wide, with a height set by the shape |
| Canvas covered | The share of canvas pixels that pictures paint, found by drawing with and without them and counting differences |
| Cell | One rectangle of a grid arrangement, sized from the canvas, padding, gap and grid |
| Chequerboard | The on-screen pattern behind the canvas that shows transparency; never exported |
| Corner radius | How far the canvas corners are rounded, in pixels; exports are clipped to the rounded shape |
| Export scale | The factor, 0.25× to 4×, by which the canvas size is multiplied when an image is saved or copied |
| Fill | Scaling a picture so it covers its whole cell; in this tool the excess is not trimmed away |
| Fit | Scaling a picture so all of it lies inside its cell, leaving part of the cell empty if the shapes differ |
| Gap | The space between neighbouring cells of a grid arrangement |
| Guides | The thirds lines across the canvas and the dashed lines through the selected picture's centre; screen only |
| History step | One recorded change that **Undo** can reverse; the history holds up to 60 |
| JPEG | A lossy image format that makes small files from photographs and cannot store transparency |
| Layer | One picture in the stack; the layers list shows them top first |
| Off-canvas area | The share of total picture area outside the canvas, which will not appear in an export |
| Opacity | How solid a picture is drawn, from 0% (invisible) to 100% (solid) |
| Overlap | The share of the canvas painted by two or more pictures |
| Padding | The margin between the canvas edge and the block of grid cells |
| PNG | A lossless image format that can store transparency |
| Reading | A small JSON file recording what was measured about the collage |
| Rule of thirds | A composition guide dividing the canvas into three equal parts across and down |
| Session file | A JSON file with the canvas settings and each picture's placement, but no image data |
| Snap | Rounding a dragged picture's centre to the nearest multiple of 10 px |
