# Image Picker shortcuts

## Keyboard

| Key | Action |
|---|---|
| `E` | Re-extract the palette with the current settings |
| `H` | Copy the palette's hex values |
| `J` | Copy the full analysis as JSON |
| `R` | Reset: clear the picture, palette and pins |
| `Enter` in the address field | Load the image at that address |
| `Escape` | Close a full-screen chart |

The letter keys work anywhere on the page when focus is not in a text field, slider, switch or menu. Because a single `R` resets the workbench, click into a field before typing if you do not want to reset.

## Pointer

| Action | Result |
|---|---|
| Hover the preview | Read the pixel under the pointer |
| Click the preview | Pin that pixel's colour |
| Click a palette swatch | Copy its hex value |
| Click a pin | Copy its hex value |
| Double-click a chart | Open it full screen |
| Click outside a full-screen chart | Close it |
