# Image Picker glossary

| Term | Meaning |
|---|---|
| CIELAB | A colour space with lightness L* and two colour axes, a* and b*, designed so distances track perceived difference |
| Cluster | A group of similar sampled pixels, represented in the palette by their average colour |
| Contrast ratio | The WCAG 2 measure of brightness difference between two colours, from 1:1 to 21:1 |
| CORS | Cross-origin resource sharing: a server's permission for other sites to read its images' pixels |
| D65 | A standard daylight white at about 6500 K, used here as the white for CIELAB |
| Eyedropper | The live readout of the pixel under the pointer on the preview |
| Harmony | A pair of colours whose hues sit at a classic colour-wheel angle |
| Hex | A colour written as `#RRGGBB`, two hexadecimal digits each for red, green and blue |
| HSL | Hue (0° to 360°), saturation and lightness (0% to 100%): a cylindrical form of RGB |
| k-means++ | A clustering method that picks well-spread starting colours, then moves each cluster to the average of its nearest pixels |
| LCH | CIELAB written as lightness, chroma (colourfulness) and hue angle |
| Merge threshold | The RGB distance below which two clusters are combined |
| Palette | The extracted colours, sorted by their share of the picture |
| Pin | An exact pixel colour kept by clicking the preview; up to 24 |
| Population | A cluster's share of the sampled pixels |
| Quality | How densely the picture is sampled, from Fast to Max detail |
| Relative luminance | The WCAG measure of a colour's brightness, from 0 for black to 1 for white |
| Sample | One pixel read from the working copy for the extraction |
| Tone band | Shadows, Midtones or Highlights, by relative luminance |
| WCAG | The Web Content Accessibility Guidelines, which define the contrast ratio and its ratings |
| Working copy | The picture shrunk to fit 800 × 500 pixels, which the tool samples and the eyedropper reads |
