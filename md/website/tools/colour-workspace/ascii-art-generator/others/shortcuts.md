# Shortcuts

| Shortcut | Where | What it does |
| --- | --- | --- |
| `Ctrl` + `V` (`Cmd` + `V` on a Mac) | Anywhere on the page, when not typing in a field | Loads an image from the clipboard. |
| Drag a file onto the tool | **Lab** | Loads the image. |
| `Enter` or `Space` | On a group heading in the rail | Folds or opens the group. |
| Double-click a chart | **Analysis** | Opens the chart full screen. |
| `Esc` | Full-screen chart | Closes it. |

The full-screen view of the art closes with **×** only.
