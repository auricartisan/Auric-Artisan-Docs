# Glossary

| Term | Meaning |
| --- | --- |
| ACES | Academy Color Encoding System, a family of colour spaces for film and visual effects (AP0, AP1, ACEScg). |
| Appearance model | A model that predicts how a colour looks under given viewing conditions, such as CIECAM02 or CAM16. |
| Bradford transform | A widely used chromatic adaptation transform from the von Kries family. |
| CAT02, CAT16 | Chromatic adaptation transforms from the CIECAM02 and CAM16 appearance models. |
| CCT | Correlated colour temperature, in kelvin. |
| Chromatic adaptation | The eye's adjustment to the colour of the light, and the formulas that predict it. |
| Chromaticity (x, y) | The colour of a stimulus apart from its brightness, plotted on the CIE 1931 diagram. |
| CIEDE2000 (ΔE 2000) | The CIE's current formula for perceived colour difference. |
| CIE XYZ | The tristimulus values that other colour spaces are defined from. |
| CIELAB / LCh | A perceptual space (lightness, a, b) and its polar form (lightness, chroma, hue). |
| Dossier | The panel's detailed description of a colour space for the current sample. |
| Gamut | The range of colours a space or device can hold. |
| Headroom (margin) | How far a colour sits from the edge of a gamut. |
| Illuminant | A standard light defined by its spectrum or white point, such as D65 or A. |
| Linked panels | Panels that copy each other's control changes. |
| Metamerism | Two colours that match under one light and differ under another. |
| Oklab / Oklch | A modern perceptual space and its polar form, used in CSS colour. |
| Planckian locus | The path of blackbody colours on the chromaticity diagram as temperature changes. |
| Standard observer | The CIE model of average human colour matching: 2° (1931) or 10° (1964). |
| Von Kries | The principle of scaling each cone response independently to model adaptation. |
| White point | The colour treated as white in a space or under a light. |
