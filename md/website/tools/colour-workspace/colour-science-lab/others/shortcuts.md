# Shortcuts

The single-key shortcuts work anywhere on the page when the cursor is not in a text box, list or text area, and when `Ctrl`, `Cmd` and `Alt` are not held. The letter shortcuts act on the Catalogue, even if another view is showing.

| Keys | What it does |
| --- | --- |
| `/` | Focus the Catalogue search. |
| `Esc` | In the search box: clear the search. Also closes the shortcuts overlay. |
| `?` | Show or hide the keyboard shortcuts overlay. |
| `F` | Show Favorites in the Catalogue. |
| `A` | Show Analytics in the Catalogue. |
| `C` | Show Compare in the Catalogue. |
| `R` | Open a random tool from those visible. |
| `T` | Tile all panels. |
| `1` to `5` | Bring panel 1 to 5 (in opening order) to the front. |
| `Shift` or `Ctrl` + select a card | Open another copy of a tool. |
| `Esc` inside a panel | Restore a maximised panel; otherwise close the panel. |
| Double-click a title bar | Maximise or restore. |
| `Enter` in a panel HEX box | Apply the typed colour. |
| `Arrow Down`, `Enter` or `Space` on a panel list | Open the list; `Esc` closes it. |
