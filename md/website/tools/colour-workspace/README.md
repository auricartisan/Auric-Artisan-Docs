# Colour workspace

The colour workspace is the group of Auric Artisan website tools you use to make things with colour: palettes, gradients, harmonies and whole design systems, plus the fonts and icons that go with them. It also includes the site-wide Colour Tools, fourteen floating colour tools you can open over any page.

Every tool runs in your browser. Most work without an account; saving to your Library and some account features need you to sign in. Each tool has its own folder with an overview, task guides, a full reference, troubleshooting, a glossary and notes on accuracy and privacy.

## Which tool should I use?

- **I need a palette quickly**: Palette Studio in [Basic Color Tools](basic-colour-tools/docs/panel-tools/palette-studio.md).
- **I need a whole design system with tokens**: [Design System Generator](design-engine/README.md) or [Personalization Generator](personalisation-generator/README.md).
- **I need to check contrast while reading another page**: the [Colour Tools](basic-colour-tools/docs/colour-tools/README.md), opened with the right-click menu.
- **I need colour science detail**: [Color Science Lab](colour-science-lab/README.md), or [Color Space Converter](basic-colour-tools/docs/colour-tools/colour-space-converter.md) for one colour.
- **I need a typeface or icons**: [Font Library](font-library/README.md) and [Icon Library](icon-library/README.md).
