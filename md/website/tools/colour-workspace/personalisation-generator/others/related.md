# Related tools and reading

## Tools

- [Design System Generator](../../design-engine/README.md): build a full design system from a brief, with more control over ramps and token export.
- [Basic Color Tools](../../basic-colour-tools/README.md): palettes, gradients, a colour picker and the Colour Tools workbench.
- [Color Science Lab](../../colour-science-lab/README.md): look closely at any colour the generator produces.
- [Contrast Checker](../../../accessibility-and-vision/contrast-checker/README.md): test a final text and background pair.
- [Vision Lab](../../../accessibility-and-vision/vision-simulation/README.md): see a palette through colour-vision and other vision conditions.

## Library

- [Colour libraries](../../../../library/colour-libraries/README.md): browse palettes, gradients and shades, save them, and open them here to seed your pool.
- [Library Kit](../../../../kits/library-kit/README.md): find and manage the items you saved from the generator.

## Services

- [Public API](../../../../../services/public-api/README.md): the same generation as a REST call.
