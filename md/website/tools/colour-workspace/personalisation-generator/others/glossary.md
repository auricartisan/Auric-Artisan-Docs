# Glossary

| Term | Meaning |
| --- | --- |
| Accent | The most colourful colour in a palette once the background and text are chosen. Accent 2 is the next most colourful. |
| APCA Lc | A contrast value from the Accessible Perceptual Contrast Algorithm. Higher means easier to read. The generator shows its size without the sign. |
| Brief | The text box at the top of the left column; the same setting as Preference note in Tune. Its words are matched against reference palette names. |
| Candidate | One palette generated during a sweep, before it is scored. |
| CIEDE2000 | A formula for the perceived difference between two colours. |
| CVD | Colour vision deficiency. The generator simulates protanopia, deuteranopia and tritanopia. |
| Endless | A mode that runs sweep after sweep and merges the results until stopped. |
| Leader | The highest-scoring palette of the last sweep. It feeds the Tokens tab and opens first in the Studio. |
| OKLCH | A colour model of lightness, chroma and hue in which equal steps look roughly equal. |
| Pool | Your own set of colours, up to 240. Palettes are scored on how close they stay to it. |
| Pool target | The size Build fills the pool to. |
| Preset | A starting point of five colours, two style chips and a use case. |
| Reference palette | One of about 80 built-in named palettes the generator draws on, such as Clay Garden. |
| Relationship | The hue pattern a palette is built on, such as Analogous or Triadic. |
| Semantic role | A named job for a colour: primary, secondary, accent, neutral, success, warning, danger or info. |
| Style chip | A mood word, such as Calm or Neon, with preferred ranges of saturation, lightness, chroma, warmth and contrast. |
| Sweep | One run: sample candidates, score them, keep the best. |
| Tonal ramp | One colour from very light (50) to very dark (950) in eleven steps. |
| Use case | What the system is for: Ui, Brand, Poster, Editorial or Dashboard. |
| WCAG contrast ratio | The Web Content Accessibility Guidelines contrast measure, from 1:1 to 21:1. Body text needs 4.5:1 for AA and 7:1 for AAA; large text 3:1 for AA. |
