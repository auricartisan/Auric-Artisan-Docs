# Glossary

| Term | Meaning |
| --- | --- |
| Axis | One dimension a variable font can change along, such as weight (wght) or width (wdth). |
| Character variant | An OpenType feature (cv01 to cv99) that swaps the design of one particular character. |
| Code point | The number Unicode gives a character, written like U+0041. |
| Family | All the styles of one typeface, such as Regular, Bold and Italic. |
| Fallback stack | The fonts listed after the one you want, used if it is missing. |
| @font-face | The CSS rule that tells a browser where a font file is and which style it provides. |
| Foundry | The company or person that publishes a typeface. |
| Glyph | A single drawn shape in a font, usually a character. |
| Heading and body | The two roles in a type pairing: a display face for titles and a text face for reading. |
| Installed | A family listed from system fonts, shown only if you have it installed, and not served. |
| Instance | A named point on a variable font's axes, such as Light or Condensed Bold. |
| Ligature | Two or more characters drawn as one glyph, such as fi, or => in coding fonts. |
| Modular type scale | A set of sizes where each step is the previous one times a fixed ratio. |
| OpenType feature | A switchable behaviour inside a font, named by a four-letter tag such as liga or tnum. |
| Pangram | A sentence using every letter of the alphabet. |
| Self-hosting | Serving font files from your own website instead of a font service. |
| Specimen | A sample of text set in a typeface, used to judge it. |
| Stroke contrast | The difference between thick and thin parts of letters. |
| Stylistic set | An OpenType feature (ss01 to ss20) that swaps a group of alternative designs. |
| Super-family | Related typefaces designed to work together, such as a sans and a serif sharing a name. |
| Tabular figures | Digits of equal width, so numbers line up in columns. |
| Variable font | One font file that holds a continuous range of styles along one or more axes. |
| Weight | How heavy the strokes are, from 100 (Thin) to 900 (Black); 400 is Regular and 700 Bold. |
| x-height | The height of lowercase letters such as x, as a share of the font's size (em). |
