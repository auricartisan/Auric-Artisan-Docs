# Shortcuts

Shortcuts work when you are not typing in a field. They do not use `Ctrl`, `Cmd` or `Alt`: `Ctrl` + `K` belongs to the site-wide search.

| Key | What it does |
| --- | --- |
| `?` | Opens the library command palette |
| `/` | Focuses the search box |
| `S` | Shuffles the results into a random order |
| `G` | Grid view |
| `L` | List view |
| `T` | Opens the **Your kit** tray (close it with **Hide**) |
| `[` | Makes card specimens smaller |
| `]` | Makes card specimens larger |
| `C` | Compares your kit (two or more families) |
| `Esc` | Closes the command palette or the family panel |
| `F` | Meant to show or hide filters; see below |
| `R` | Meant to open the recommender; see below |

At the time of writing, `F` and `R` switch their panel twice, so nothing appears to change. Use the **Filters** and **Recommend** buttons, or the command palette.

## The command palette

Press `?` to open a search box of commands. Type to narrow the list (for example *shuffle*, *filters* or *size*), move with `↑` and `↓`, run a command with `Enter`, and close with `Esc`.

Commands include **Focus search**, **Shuffle results**, **Grid view**, **List view**, **Toggle filters**, **Find your font**, **Open selected tray**, **Download selected**, **Increase preview size**, **Decrease preview size**, **Scroll to top**, **Toggle light / dark theme** and **Focus preview text**, plus a **Category ·** command for each category. Each shows its key, if it has one.

## In the family panel

| Key | Where | What it does |
| --- | --- | --- |
| `Enter` | A focused card | Opens the family |
| `←`, `→` | The panel grip, wide screens | Makes the panel wider or narrower; add `Shift` for bigger steps |
| `↑`, `↓` | The panel grip, narrow screens | Raises or lowers the sheet |
| `Tab`, then `Enter` or `Space` | Filter chips | Switches a chip |
