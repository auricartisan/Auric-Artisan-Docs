# Basic Color Tools documentation

This folder explains how to use the Basic Color Tools page and everything on it: the three views, the panel windows, the seven workspace tools, and the fourteen site-wide Colour Tools. Start with the getting-started guide, then open the guide for the tool you need. The reference lists every control in one place.

| File | What it covers |
| --- | --- |
| [getting-started.md](getting-started.md) | Open the page, tour the screen, make and export a first palette. |
| [workspace-and-panels.md](workspace-and-panels.md) | Workspace, Catalogue and Panels views; search, level and favourites; moving, docking and closing panels. |
| [import-export-and-library.md](import-export-and-library.md) | Every copy and download format, the palette share link, Save to Library and reopening saved items. |
| [reference.md](reference.md) | Every control, option, range, default and output format of the workspace and its seven tools. |
| [troubleshooting.md](troubleshooting.md) | Symptoms, why they happen and what to do. |
| [faq.md](faq.md) | Short answers to common questions. |
