# Colour Tools workbench

The Colour Tools are fourteen colour tools that open in floating panels over whatever page you are on. Open them from the launcher (`Ctrl` + `Shift` + `C`, or right-click and use the **Colour tools** group), by right-clicking a colour value, or with a link: `?color=` opens the Color Inspector, and `?ctool=` opens any tool with its settings. Tools opened from the launcher start with your working colour; all of them share one kind of panel and can hand their colours to each other. The Colour Tools dashboard gathers your working colour, a set of colours and your recent work in one place.

Basic Color Tools is their home page, and this folder documents them. Start with [launcher-and-panels.md](launcher-and-panels.md), then open the guide for the tool you need.
