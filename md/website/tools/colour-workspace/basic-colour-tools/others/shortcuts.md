# Shortcuts

`Cmd` applies on a Mac where the table lists it. Shortcuts that act on "the panel" act on the focused panel, the one you selected last.

## Basic Color Tools page

| Keys or gesture | Where | What it does |
| --- | --- | --- |
| `Space` | Palette Studio, panel focused, not typing | Generates a new palette (locked colours stay). |
| `Escape` | Focus inside a panel | Restores a maximised panel; otherwise closes the panel. |
| Double-click the title bar | Any panel | Maximises or restores. |
| Drag the title bar | Any panel (not maximised) | Moves the panel. |
| Drag the bottom-right corner | Any panel (not maximised) | Resizes the panel. |
| `Shift`, `Ctrl` or `Cmd` + select a tool card | Catalogue | Opens another instance of the tool. |
| Drag a colour strip | Palette Studio | Reorders the palette. |
| `Shift` + right-click a filled cell | Collage Maker | Cycles that cell's filter. |
| `Enter` or leave the box | Color Picker HEX box; Quick Converter Compare HEX boxes | Applies the typed HEX code. |
| `Ctrl` + `Enter` (`Cmd` + `Enter`) | Save to Library window | Saves. |

## Colour Tools workbench

| Keys or gesture | Where | What it does |
| --- | --- | --- |
| `Ctrl` + `Shift` + `C` | Any page that loads the Colour Tools | Opens the Colour Tools launcher. If the selected text is a HEX code, the tool you pick opens with that colour. |
| Right-click | Any page | Opens the site menu with the **Colour tools** group. |
| `Shift` + right-click | Any page | Opens the browser's own menu instead. |
| Type while the right-click menu is open | Site menu | Filters the menu items. |
| `Tab`, `Shift` + `Tab` | Launcher | Moves between the search box, tool rows, links and the close button. |
| `Enter` or `Space` | Launcher | Opens the focused tool. |
| `Esc` | Launcher search box | Clears the search; press again to close the launcher. |
| `Esc` | Launcher, elsewhere | Closes the launcher. |
| `Esc` | Colour Tools panel | Leaves full-window view if maximised; otherwise closes the panel. |
| Double-click the title bar | Colour Tools panel | Maximises or restores. |

Individual Colour Tools may have their own keys; each tool's guide lists them. See [Colour Tools](../docs/colour-tools/README.md).
