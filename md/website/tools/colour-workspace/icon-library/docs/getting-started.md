# Getting started with the Icon Library

## Open the page

Go to https://auricartisan.com/tool/icon/. The masthead reads *Twelve thousand icons, one line to serve them* and its labels give the live counts of icons, variants, sets and styles.

The catalogue loads from the Icon CDN. If it cannot be reached, a notice explains that the library is temporarily unavailable; see [Troubleshooting](troubleshooting.md).

## The layout

Two views sit in a row at the top: **Icons** (with the number of icons shown) and **Sets** (7).

The **Icons** view has two columns:

- **The rail** on the left, which stays in view as you scroll:
  - **Find**: the search box, the sort menu, **Recommend**, **Shuffle**, **Filters** and the number of matching icons;
  - **Applied**: what is switched on, when anything is;
  - **Set**: **All** and the seven sets with their counts, and a style switch when the chosen set has more than one style;
  - **Narrow it**: the **Category** and **License** chips;
  - at the foot, **Reset filters** and **Download selected**.
- **The stage** on the right: **Size**, **Stroke** and **Colour** controls, then the grid of icons with their names, which loads more as you scroll.

Once you have opened an icon, a **Recently viewed** strip appears under the two views.

On screens narrower than about 1,180 pixels the rail sits above the grid and its filter groups start folded.

## Your first icon

1. Type *bell* in *Name, tag or set*.
2. Under **Set**, select **Phosphor**, then the **Duotone** style.
3. Drag **Size** to 64 and pick a colour with **Colour**. Every icon in the grid changes.
4. Select an icon. The panel opens on the right with a large preview.
5. Select **Copy SVG**. The message **SVG copied** confirms it; paste it into your HTML or design tool.
6. Select **＋ Select** to keep it in **Your kit** for later.

Result: an SVG in your chosen style and colour, ready to use.
