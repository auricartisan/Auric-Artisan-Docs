## Rail

| Control | Values | Default |
| --- | --- | --- |
| Search | Name, identifier or keyword | empty |
| Sort | Alphabetical, Group by set, Surprise me | Alphabetical |
| **Recommend** | Opens Find your icon | closed |
| **Shuffle** | Random order | button |
| **Filters** | Shows or hides the chip groups | shown |
| Set | All and seven sets | All |
| Style | The chosen set's styles | The set's default |
| Category | Up to 40 for the current set | off |
| License | MIT, ISC, Remix v1.0, Apache-2.0 | off |
| **Reset filters** | Clears category, licence and search | button |
| **Download selected** | Downloads Your kit as a ZIP | disabled when empty |

## Grid controls

## Messages

| Message | Meaning |
| --- | --- |
| **SVG copied**, **JSX copied**, **data-URI copied**, **CDN tag copied**, **Copied** | Code was copied. |
| **Glyph entity copied** | A Material icon's character reference was copied. |
| **Material is a webfont — use the embed code** | Material icons cannot be downloaded as SVG. |
| **Select some icons first** | Download ZIP or Copy sprite with an empty kit. |
| **Downloaded** *n* **icons** | The ZIP is ready. |
| **SVG sprite copied** | The sprite is on the clipboard. |
| **No categories for this set.** | The chosen set has no categories. |
| **No option matches that.** | No chip matches the text in Filter these options. |
| **Icon library is temporarily unavailable** | The catalogue could not be reached. |
| **The live icon engine didn’t load** | The page's icon engine did not start; **Retry** reloads. |
