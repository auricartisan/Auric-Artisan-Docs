# Glossary

| Term | Meaning |
| --- | --- |
| currentColor | A CSS keyword meaning the current text colour. Icons drawn with it take the colour of the text around them. |
| Data URI | A way to put a whole file inside a link or `src` attribute, so no separate file is needed. |
| Duotone | A style with two tones: a solid shape and a lighter fill behind it. |
| Filled and outline | Two ways of drawing icons: solid shapes, or lines of a set width. |
| Identifier | An icon's unique name, beginning with its set, such as lucide-bell. |
| JSX | The HTML-like syntax used to write React components. |
| Set | A family of icons drawn to one design, such as Lucide or Material. |
| Sprite | One SVG file holding many icons as symbols, each shown with a `<use>` reference. |
| Stroke width | The thickness of the lines in an outline icon. |
| Style | One drawing of a set, such as Outline, Fill or 16 · Solid. |
| SVG | Scalable Vector Graphics: an image format made of shapes, sharp at any size. |
| Symbol | A reusable piece of an SVG sprite, identified by an `id`. |
| Variant | One icon in one style. 12,896 icons come in 32,803 variants. |
| Webfont | A font whose characters are icons, used for the Material set. |
