# Shortcuts

Shortcuts work when you are not typing in a field. They do not use `Ctrl`, `Cmd` or `Alt`: `Ctrl` + `K` belongs to the site-wide search.

| Key | What it does |
| --- | --- |
| `?` | Opens the library command palette |
| `/` | Focuses the search box |
| `S` | Shuffles the icons into a random order |
| `F` | Shows or hides the filter chips |
| `R` | Opens or closes **Find your icon** |
| `T` | Opens or closes the **Your kit** tray |
| `[` | Makes the icons smaller |
| `]` | Makes the icons larger |
| `Esc` | Closes the command palette or the icon panel |

## The command palette

Press `?` to open a search box of commands. Type to narrow the list, move with `↑` and `↓`, run a command with `Enter`, and close with `Esc`.

Commands include **Focus search**, **Shuffle results**, **Toggle filters**, **Find your icon**, **Open selected tray**, **Download selected**, **Increase preview size**, **Decrease preview size**, **Scroll to top**, **Toggle light / dark theme**, **Pick icon color**, **Thicker stroke** and **Thinner stroke**, plus a **Category ·** command for each set. Each shows its key, if it has one.

## In the icon panel

| Key | Where | What it does |
| --- | --- | --- |
| `←`, `→` | The panel grip, wide screens | Makes the panel wider or narrower; add `Shift` for bigger steps |
| `↑`, `↓` | The panel grip, narrow screens | Raises or lowers the sheet |
