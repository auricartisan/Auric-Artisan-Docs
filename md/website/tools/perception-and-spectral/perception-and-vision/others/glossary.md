# Perception and Vision glossary

| Term | Meaning |
|---|---|
| Acuity (Snellen) | Sharpness of vision written as a fraction such as 20/40: the viewer sees at 20 feet what a typical eye sees at 40 |
| Anomalous trichromacy | Colour vision with all three cone types but one of them shifted, giving weaker colour discrimination than normal |
| Bradford transform | A published method for predicting how colours shift when the light source changes, used here to relight the scene |
| Cataract | Clouding of the eye's lens, which scatters light and lowers contrast |
| CIEDE2000 (ΔE00) | The CIE's current formula for how different two colours look; larger is more different |
| Clamped | A colour pushed back inside the sRGB range because the simulation produced a value a screen cannot show |
| Cone signals (L, M, S) | The responses of the long-, medium- and short-wavelength-sensitive cones |
| Daltonising | Recolouring an image to move information into colour differences a dichromat can see |
| Deutan | Relating to the M (medium-wavelength) cones; deuteranopia is the absence of M cones |
| Dichromacy | Colour vision with only two working cone types |
| Illuminant (D65, D50, A) | A standard light source: D65 and D50 are daylights, A is tungsten (incandescent) light |
| Mesopic vision | Vision in twilight, when both rods and cones contribute |
| Neutral drift | How far the simulation pulls a grey away from grey, in code values |
| Projection | The operation that removes one colour axis, replacing the missing cone's signal with a combination of the others |
| Protan | Relating to the L (long-wavelength) cones; protanopia is the absence of L cones |
| Relative luminance | The lightness-related quantity Y of CIE XYZ, from 0 (black) to 1 (white) |
| Rods | Photoreceptors that work in dim light and do not distinguish colour |
| Scotoma | An area of lost vision in the visual field |
| Scotopic vision | Night vision with rods only |
| Severity | How strongly a simulation is applied, from 0 (none) to 1 (full) |
| Spatial simulation | A simulation that depends on neighbouring pixels or position (Cataract, Central loss, Acuity) |
| sRGB | The standard colour space of web content, with a defined transfer curve and primaries |
| Tritan | Relating to the S (short-wavelength) cones; tritanopia is the absence of S cones |
| WebGL2 | A browser graphics interface that lets the page compute on the graphics card |
