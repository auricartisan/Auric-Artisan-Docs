# Psychophysics Bench shortcuts

Keys work while the page is waiting for an answer. Site-wide shortcuts are described in [Site features](../../../../site-features/README.md).

| Key or action | Two-interval forced choice | Yes / no detection |
|---|---|---|
| `←` | First interval | Yes, I saw it |
| `→` | Second interval | No, I did not |
| `Esc` | Stops the run | Stops the run |

| Action | Where | Result |
|---|---|---|
| Double-click | The stimulus stage or the staircase trace | Opens it enlarged, filling the window |
| `Esc` | Enlarged view | Closes it |
| Select the **×** button or the dark area around the image | Enlarged view | Closes it |
| `Tab` | Anywhere | Moves between controls; sliders then respond to the arrow keys |

Between runs the arrow keys are not used by the bench, so a focused slider responds to them instead. Click an empty part of the page before a run so the response keys are not also moving a slider.
