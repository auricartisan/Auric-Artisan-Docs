# Material Under Light shortcuts

The tool has no keyboard shortcuts of its own beyond these. Site-wide shortcuts are described in [Site features](../../../../site-features/README.md).

| Action | Where | Result |
|---|---|---|
| Select a card | The five lobe cards under the sample | Chooses that lobe |
| Drop a file | The spectrum plot on the Lab tab, or **Drop a reflectance file** on the Data tab | Loads a measured reflectance |
| Click | The spectrum plot or **Drop a reflectance file** | Opens a file chooser |
| `Enter` or `Space` | Focused **Drop a reflectance file** area | Opens a file chooser |
| `Enter` or `Space` | A focused row on the **Data** tab | Expands or collapses the row |
| Click a tab name in the page text | Note strip and hints | Switches to that tab |
| `Tab` | Anywhere | Moves between controls; sliders then respond to the arrow keys |
