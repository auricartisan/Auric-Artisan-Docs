# Compare conditions

**Compare** is a contact sheet: the same source shown under several conditions side by side, each tile measured the same way. Use it to answer "which of these conditions hurts my design most?"

## Open the sheet

- Select **Compare** in the view bar.
- From the Workbench, select **Compare this** to add the current condition.
- Press `C` (outside text fields) to jump to Compare.

## The tiles

The first tile is **Normal vision**, marked "control", so you always have the original to compare against. Every other tile shows:

- the source under that condition;
- "N pairs lost of 45", the number of reference colour pairs that stop being distinguishable;
- "CTA" and a contrast ratio: the contrast of the mock-up's call-to-action button label on its fill, under the condition;
- the condition's severity score and name;
- a grip to reorder it ("Reorder … — drag, or use the arrow keys") and **×** to remove it.

Select **Add a condition** (it says how many are available to choose from) to add another tile.

## The controls

| Control | What it does | Options or range | Default |
| --- | --- | --- | --- |
| **Severity for every tile** | One severity for all tiles | 0–100% | 100% |
| **Order** | How tiles are sorted | **By impact**, **By severity**, **As arranged** | — |
| **Columns** | Tiles per row | **3**, **4**, **5** | — |
| **Copy link to this sheet** | Copies a link that reopens this sheet | — | — |
| **Send the worst to the workbench** | Opens the most damaging condition in the Workbench | — | — |

**Order** and **Columns** are under **Sheet options**. A heading names the set, for example "Colour vision · 8 conditions", and a sentence names the condition that costs the most, for example "Achromatopsia costs the most: 23 of 45 reference pairs stop being tellable apart."

## Reorder with the keyboard

Focus a tile's grip, then press `Left` or `Up` to move it one place earlier, `Right` or `Down` to move it later, and `Home` or `End` to send it to the start or end.

## A way to use it

1. Put your design's colours in the Workbench as the base colour, or load your screenshot as the Image specimen.
2. Open **Compare** and set **Order** to **By impact**.
3. Read the first few tiles: these are the conditions to design for.
4. Select **Send the worst to the workbench** to study the worst one in detail.
5. Select **Copy link to this sheet** to share the comparison.

The sheet is remembered in this browser between visits.
