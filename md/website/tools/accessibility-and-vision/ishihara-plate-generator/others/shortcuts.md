# Ishihara Plate Generator keyboard shortcuts

| Keys | Where | Action |
| --- | --- | --- |
| `Enter` or `Space` | A focused plate | Open it full size |
| Double-click | A plate | Open it full size |
| `Right` | Full-size view | Next plate |
| `Left` | Full-size view | Previous plate |
| `Esc` | Full-size view | Close it |

All other controls are standard buttons and menus: move between them with `Tab` and `Shift` + `Tab`, and use them with `Enter` or `Space`.

For shortcuts that work across the whole site, see [Keyboard shortcuts](../../../../site-features/keyboard-shortcuts/README.md).
