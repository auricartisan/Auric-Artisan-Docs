# Illuminants shortcuts

| Shortcut | Where | What it does |
| --- | --- | --- |
| `Ctrl` + `Enter` | Console, in the Query box | Runs the query |
| `Esc` | Reference, in the Filter box | Clears the filter |
| `Esc` | A full-screen chart | Closes the full-screen view |
| Double-click | SPD or CRI chart | Opens the chart full screen |
| Click | SPD chart | Probes the nearest wavelength and shows its relative power |

On macOS, `Cmd` + `Enter` also runs a console query.

## About the S, R, C and E hint

The Lab rail shows a **Keyboard shortcuts** hint: S swap adaptation, R reset D65, C toggle compare, E export CSV. These single-key shortcuts are not active in the current version of the page. Use the buttons instead:

| Hint | Button to use |
| --- | --- |
| S | **Swap** under Chromatic adaptation |
| R | **Reset to D65** |
| C | **Enable comparison** |
| E | **Export SPD CSV** on the Export tab |

The site's own shortcuts (such as the search palette) also work on this page; see the site features documentation.
