# Gamut Mapping shortcuts

The lab has no single-key shortcuts of its own.

| Shortcut | Where | What it does |
| --- | --- | --- |
| Click | Source Slice or Mapped to Target | Probes that a*b* point at the current L* |
| Double-click | A slice or the Before / After strip | Opens it full screen |
| `Esc` | Full-screen view | Closes it |
| `Esc` | Reference › Filter | Clears the filter |
| `Enter` | A ΔE Playground HEX field | Applies the typed colour |
