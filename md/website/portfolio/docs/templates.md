# Templates

A template replaces your sections with a ready-made set of example sections for a kind of portfolio. It does not change your header or your style.

## Use a template

1. Select **Templates** in the top bar, or type "template" in the command field and choose **Start from a template**.
2. The **Start from a template** dialog shows eight tiles. Select one; a tick marks it.
3. Select **Use this template**, or **Cancel** (or `Escape`, or click outside the dialog) to leave without changing anything.

The builder confirms, for example, **Designer template applied.** Your previous sections are replaced, but you can bring them back with Undo.

## The eight templates

| Template | Description (as shown) | Main sections |
| --- | --- | --- |
| **Designer** | Work-first — selected projects, an about section, skills and links. | Selected Work heading, your library work (up to 9), About heading and text, skills, Elsewhere links (Dribbble, Instagram). |
| **Developer** | Intro, tech stack, a projects grid and a code snippet. | Intro text, Stack skills, Projects heading and your library work, a code snippet, links (GitHub, Email). |
| **Photographer** | Visual-first — a portfolio grid, stats and a booking call-to-action. | Intro text, Portfolio work grid (up to 12), stats (shoots, countries, clients), a Book a session call to action. |
| **Freelancer** | Services, a how-we-work process, a testimonial and a CTA. | Intro text, Services features, How we work steps, a testimonial, a Have a project? call to action. |
| **Founder** | Startup one-pager — traction stats, features, milestones and contact. | Intro text, Traction stats, What we do features, Milestones timeline, a Want to talk? call to action. |
| **Writer** | Selected writing, an about, a pulled quote and links. | Intro text, Selected writing links, About text, a quote, Elsewhere links (Newsletter, Twitter). |
| **Resume** | A formal CV — experience, skills, education and contact. | Summary text, Experience timeline, skills, Education timeline, Contact links (Email, LinkedIn). |
| **Minimal** | Just a short intro line and a couple of links. Nothing else. | One line of text and links (Email, Twitter). |

The example words are placeholders: replace them by typing into the preview or the section cards.

## Result

Your page has a full, sensible structure in one step, ready to fill in.
