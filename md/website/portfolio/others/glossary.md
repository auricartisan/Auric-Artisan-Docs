# Portfolio glossary

| Term | Meaning |
| --- | --- |
| Accent | The colour used for links, headings and buttons, picked from your saved palettes. |
| Address (handle) | The name after `auricartisan.com/p/` in your published address. |
| Alt text | A written description of an image for people using screen readers. |
| Blocking finding | A **Check** result that must be fixed before you can publish. |
| Credit line | The small "Made with Auric Artisan" line on exported HTML and PDF files. |
| Draft | Your portfolio as it is in the builder, saved automatically; not what visitors see until you publish. |
| External portfolio | A portfolio on your own website, added to the Portfolio Index through the Search Console. |
| Markdown | A plain-text way of writing formatted text, such as `**bold**` and `# Heading`. |
| Paper | The page's background and text colour: Cream, White, Sand, Ink or No background. |
| Placeholder | Grey example text in an empty field; it is not published. |
| Portfolio Index | The directory of portfolios at https://auricartisan.com/portfolios/. |
| Publish | Put the current draft online at your address. |
| Raw HTML | A section that accepts your own HTML and CSS, cleaned for safety. |
| Rhythm | The page's spacing and corner roundness: Tight, Even or Airy. |
| Reviewed | An external portfolio a person has checked and approved. |
| Search Console | Auric Artisan's tool for site owners at https://auricartisan.com/search/console/, where external portfolios are added. |
| Section | One building block of the page, such as a Heading or a Timeline. |
| Share card | The preview (name, headline, avatar) shown when your address is shared in apps. |
| Snapshot link | A link that contains the whole portfolio in the address itself. |
| Verified | An external portfolio on a site whose owner proved it is theirs. |
| WCAG | Web Content Accessibility Guidelines; the **Check** pane tests against WCAG 2.2 AA. |
