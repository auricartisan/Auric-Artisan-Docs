# Download and offline glossary

| Term | Meaning |
|---|---|
| PWA | Progressive web app: a website a browser can install like an app and run offline. |
| Install | Adding the site to your device as an app with its own window and icon. |
| Standalone | Running in its own window without the browser's toolbar. |
| Service worker | A part of the site that runs in your browser and serves stored files when you are offline. |
| Cache | The browser's store of site files kept for offline use. |
| App shell | The small core of pages, styles and scripts stored automatically on your first visit. |
| Offline profile | How much of the site to store: Auto, Lite, Balanced or Full. |
| Persistent storage | Browser storage that is not cleared automatically when space runs low. |
| Best-effort storage | Browser storage that the browser may clear when space runs low. |
| Quota | The amount of storage the browser allows the site to use. |
| Audit | A check of which files of your profile are stored and which are missing. |
| Background sync | A browser feature that finishes a task, such as a download, when you are next online. |
| Share target | An app that appears in your device's share menu. |
