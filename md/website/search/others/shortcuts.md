# Search shortcuts

## Getting to search

| Keys or action | What it does |
| --- | --- |
| `Ctrl`+`K` | Opens Spotlight from any page. Choose **View all results for** your query to open the search page. |
| Right-click selected text, **Search this site** | Searches the site for the selected text in a new tab. |

## In the search field

| Keys | What it does |
| --- | --- |
| `↓` / `↑` | Moves through the suggestions, or through the results when no suggestions are open. Wraps round at the ends. |
| `Home` / `End` | Jumps to the first or last suggestion or result, once one is highlighted. Otherwise they move the text cursor. |
| `Enter` | Opens the highlighted suggestion or result. With nothing highlighted, runs the search and saves it as recent. |
| `Escape` | Closes the suggestions. Pressed again, clears the query. |

## Outside the search field

| Keys | What it does |
| --- | --- |
| `↓` / `↑` | Selects the next or previous result and shows why it ranks there. |
| `Enter` | Opens the selected result. |
| `End` | Goes to the bottom of the page once every result is shown. |

These keys do nothing while you are typing in another field, or when `Ctrl`, `Alt` or a command key is held.

## Search Console

| Keys | What it does |
| --- | --- |
| `↓` / `→` and `↑` / `←` | Move between sections in the side rail when it has focus. |
| `Home` / `End` | The first or last section in the side rail. |
| `Enter` | Adds the site in **Domain or URL prefix**, or submits the address in **Add a page or a sitemap**. |
| `Escape` | Closes the inspection panel or the remove dialog. |
