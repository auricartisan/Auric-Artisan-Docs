# Library

The Auric Artisan library is the reading and reference side of the site. It brings together six searchable colour libraries, the catalogue of every tool, a course of articles on colour science and accessibility, a user guide for each tool, the blog and the changelog.

The colour libraries are large, browsable collections of generated colour data: 8,192 measured colours, five million palettes, 8,192 gradients, 8,192 colour harmonies, 8,192 shade scales and five million foreground and background pairs scored for contrast. Each one lets you search, filter, inspect and copy or export values for use in your own work.

The rest of the library is for learning and finding your way: Collections lists every tool, Learn teaches the ideas behind them with interactive labs, Documentation explains each tool step by step, and the blog and changelog record what has been built and when.

## Who it is for

- Designers and front-end developers who need ready-made, measured colour values.
- Accessibility specialists who need contrast-checked colour pairs.
- Students and colour enthusiasts learning colour science.
- Anyone who wants to find the right Auric Artisan tool, or learn how to use it.

> **Note:** "Your library" — the palettes, gradients and other items you save from the tools — is a different thing. It lives in the Library Kit, a floating panel you can open from any page with `Ctrl` + `Shift` + `L`. See the [Library Kit docs](../kits/library-kit/README.md).

## Quick start

1. Open https://auricartisan.com/collections/ to see every tool in one place.
2. Open a colour library, for example https://auricartisan.com/library/palette/, to browse ready-made colour data.
3. Use the library's search and filters to narrow the collection.
4. Open an item to inspect its values, then copy or export them.
5. To learn the ideas behind the values, open https://auricartisan.com/library/learn/ and pick an article.
6. To learn a tool, find its guide at https://auricartisan.com/library/documentation/.
7. To see what changed recently, read https://auricartisan.com/library/changelog/.

## What you can do

- Browse and filter tens of thousands of colours, gradients, harmonies and shade scales, and millions of palettes and contrast pairs.
- Copy colour values and export palettes, gradients and scales in formats ready for code and design tools.
- Find, pin and open any of the site's 30 tools.
- Work through the Learn course, with interactive labs inside the articles.
- Read a user guide for a tool before or while you use it.
- Follow the blog and the changelog, including by RSS.
