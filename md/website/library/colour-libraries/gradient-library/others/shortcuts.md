# Gradient Library shortcuts

## Keyboard

| Keys | Where | Result |
| --- | --- | --- |
| `/` | Anywhere, when not typing | Focuses **Search by name, hex or scheme…**. |
| `Tab` | Grid | Moves between cards and their buttons. |
| `Enter` or `Space` | A focused card | Opens it on **Inspect**. |
| `Escape` | Share link or design tokens dialog | Closes it. |

## Pointer

| Action | Result |
| --- | --- |
| Select a card | Opens it on **Inspect**. |
| Select **CSS** on a card | Copies its CSS. |
| Select a stop's hex on **Inspect** | Copies the hex. |
| Select a value on **Tags** | Filters the **Library** by it (except **Banding**). |
| Select a card heading on **Vision**, **Accessibility**, **Pair**, **Tags**, **Stats** or **Export** | Folds or unfolds the card. |

The site-wide shortcuts also work here. See [Site features](../../../../site-features/README.md).
