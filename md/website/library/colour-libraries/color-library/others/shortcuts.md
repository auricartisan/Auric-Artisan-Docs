# Color Library shortcuts

## Keyboard

| Keys | Where | Result |
| --- | --- | --- |
| `/` | Anywhere, when you are not typing in a field | Moves the cursor to **Search by hex (#a6e223) or id…**. |
| `Enter` or `Space` | A focused tile in the grid | Opens the colour on **The colour** tab. |
| `Tab` | Anywhere | Moves between controls, chips and tiles. |

## Pointer

| Action | Result |
| --- | --- |
| Select a tile | Opens the colour. |
| Select a tile's star | Saves or unsaves the colour without opening it. |
| Select a neighbour under **Start from a colour you already have** | Opens that colour. |
| Select a card heading on **Stats** | Folds or unfolds the card. |
| Pause typing in the colour field | Updates the nearest matches without pressing **Find its neighbours**. |

The site-wide shortcuts also work on this page. See [Site features](../../../../site-features/README.md).
