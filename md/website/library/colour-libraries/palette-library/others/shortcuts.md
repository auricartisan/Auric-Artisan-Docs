# Palette Library shortcuts

## Keyboard

| Keys | Where | Result |
| --- | --- | --- |
| `/` | Anywhere, when not typing in a field | Focuses **Search by id or hex…**. |
| `Tab` | Grid | Moves between swatches and buttons. |
| `Enter` or `Space` | A focused swatch | Opens its palette on **Inspect**. |
| `Escape` | Share link or design tokens dialog | Closes the dialog. |

## Pointer

| Action | Result |
| --- | --- |
| Select a swatch in the grid | Copies its hex code. |
| Select a column on **Inspect** | Copies its hex code. |
| Select a card outside its buttons | Opens the palette on **Inspect**. |
| Select a card heading on **Inspect** | Folds or unfolds the card. |
| Select outside a dialog | Closes it. |

The site-wide shortcuts also work here. See [Site features](../../../../site-features/README.md).
