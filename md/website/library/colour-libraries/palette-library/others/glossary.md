# Palette Library glossary

| Term | Meaning |
| --- | --- |
| ASE | Adobe Swatch Exchange, a swatch file format read by Adobe apps and other design tools. |
| Base 36 | Writing numbers with the digits 0–9 and the letters a–z. Palette ids use it: `pal_a` is palette 10. |
| Chroma | How colourful a colour is compared with a grey of the same lightness. The page uses OKLCH chroma. |
| Contrast ratio | The WCAG 2 measure of the lightness difference between two colours, from 1:1 to 21:1. 4.5:1 is the AA level for body text; 7:1 is AAA. |
| Derived | Worked out on the spot from the palette's number rather than read from storage. |
| Design tokens | Named colour values in a format a design system or platform reads, such as CSS variables, a Tailwind config or an Android `colors.xml`. |
| Dominant hue | A palette's overall hue: the average of its five hues, weighted towards the more colourful colours. |
| Entropy | On **Inspect**: how many 36° hue bands the five colours fall in, divided by 5. 1.00 means five different hue families. |
| Hue span | The widest angle between any two of a palette's five hues, from 0° to 180°. |
| Method | The generation-method label a palette carries, such as `triadic`. |
| Mutually legible | A set of colours that all reach a contrast threshold against each other, so any one can be text on any other. |
| OKLCH | A modern perceptual colour space: lightness (0 to 1), chroma and hue angle. |
| Palette id | `pal_` followed by the palette's number in base 36, for example `pal_abc`. |
| Sample | The set of palettes the analysis tabs and the bulk export use: up to 2,000 palettes. |
| Scan | Looking through the collection from the start, in chunks, to find palettes that match a filter. |
| Seed | The fixed starting number from which every palette is worked out. It is why palettes never change. |
| WCAG | Web Content Accessibility Guidelines, the international standard for accessible web content. |
