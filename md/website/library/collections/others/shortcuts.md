# Collections shortcuts

## Mouse

| Action | Result |
| --- | --- |
| Select a card | Opens the tool and counts one open towards **Most used**. |
| Select a card's pin button | Pins or unpins the tool. |
| Right-click a card | Opens the card menu. |
| Right-click elsewhere | Opens the site's usual right-click menu. |
| Hover a card | Shows a tooltip with category, mode, address and tags. |
| Hover the **Start here** slider | Pauses autoplay. |

## Keyboard

| Keys | Where | Result |
| --- | --- | --- |
| `Tab` | Anywhere | Moves between links, buttons and filter boxes. |
| `Left` / `Right` | **Start here** slider, when focused | Previous or next featured tool. |
| Context-menu key, or `Shift` + `F10` | A focused card | Opens the card menu. |
| `Escape` | Card menu | Closes the menu. |
| `Escape` | Floating search panel | Closes the panel and returns focus to its button. |
| `Space` | A focused tick box | Ticks or unticks a category or topic. |

The site-wide shortcuts, such as `Alt` + `R` for reading mode and `Alt` + `T` to switch theme, also work here. See [Site features](../../../site-features/README.md).
