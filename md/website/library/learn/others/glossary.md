# Learn glossary

Each article also ends with its own glossary, **The terms, defined**, for the colour-science terms it teaches. This page covers the terms of the Learn library itself.

| Term | Meaning |
| --- | --- |
| Article number | An article's place in the course, from 1 to 113. |
| Category | One of seven groups used to filter the course: Foundations, Physics, Vision, Colorimetry, Digital, Design, Print. |
| Course order | The order the articles were written to be read in, from what light is to printing. |
| Continue your journey | The personalised suggestions at the end of each article. |
| Docked | A demo panel placed beside the article so both can be seen. |
| Lab, live demo | An interactive demonstration inside an article, opened with **Live demo**. |
| Pin | A mark that keeps an article at the front of **Continue your journey**. |
| Quick check | The short quiz at the end of an article. |
| Read | An article you have scrolled at least 55% of the way through, in this browser. |
| RSS | A feed format that lets a news reader show new articles automatically. |
