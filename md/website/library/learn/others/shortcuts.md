# Learn shortcuts

| Keys or action | Where | Effect |
| --- | --- | --- |
| Type in **Search titles and topics** | Learn page | Filters the course as you type. |
| Select a category chip again | Learn page | Clears the category. |
| `Escape` | Demo panel | Closes the panel. |
| `Escape` | **Download** menu | Closes the menu. |
| Select **Dock panel** / **Full screen** | Demo panel | Docks or enlarges the demo. |
| Select **More like this** | End of article | Shows the next seven suggestions. |

Your browser's own print shortcut works on articles as well as **Print**. The site-wide shortcuts also work. See [Site features](../../../site-features/README.md).
