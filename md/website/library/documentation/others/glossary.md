# Documentation glossary

| Term | Meaning |
| --- | --- |
| Subject | A tool or topic in the documentation index, such as "Gamut Map". |
| User guide | A document that explains how to use a tool. |
| Developer reference | A document that explains how a tool works and what it computes. |
| Pair | A subject's user guide and developer reference together. |
| Audience | Which kind of document the index shows: **Both**, **Guides** or **References**. |
| API guide | A guide to getting a tool's results from your own code through the site's REST API. |
| Endpoint reference | The list of the REST API's endpoints and their parameters. |
| RSS | A feed format for following new documents in a news reader. |
