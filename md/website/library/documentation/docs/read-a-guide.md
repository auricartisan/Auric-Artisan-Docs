# Read a guide

Documentation articles share a three-column layout on wide screens: every subject on the left, the article in the middle, and its contents on the right. On narrow screens the columns stack.

## The parts of the page

| Part | What it does |
| --- | --- |
| Subject list (left) | Headed **Documentation**. Every subject, alphabetically; the current one is highlighted and scrolled into view. Select a subject to open its first document. |
| Breadcrumb | **Documentation** › the subject's name. Select **Documentation** to return to the index. |
| Pair switch | **User guide** and **Developer reference**. The current document is highlighted; select the other to switch. If a subject has only one document, the missing half is shown greyed out, with the tooltip "No user guide for this subject yet" or "No developer reference for this subject yet". |
| Title and introduction | The subject's name and a short introduction. |
| Author and dates | Who wrote the document and when it was published or updated, where the article states them. |
| **On this page** (right) | The article's numbered sections. Select one to jump to it. On narrow screens it is a collapsible list. |
| Sections | The article itself. |
| Code blocks | Each has a **Copy** button. After copying it reads **Copied**; if your browser blocks the clipboard it reads **Press Ctrl C** so you can copy by hand. |
| Tables | Wide tables scroll sideways rather than stretching the page. |
| Pager (end) | **The pair** — a link to the other document for this subject — and **Next subject**, the next subject alphabetically. |

## Tips

- Read the user guide first, then the developer reference when you need to know exactly what a figure means.
- Guides were written for the tool as it was on their stated date. If a guide and the tool disagree, trust the tool, and check this documentation set for the current behaviour.
- The API guides include ready-made requests; the full endpoint list is at https://auricartisan.com/library/documentation/api/.

## Result

You can move from any guide to its reference, to the next subject, or back to the index without losing your place.
