# Documentation FAQ

## What is the difference between a user guide and a developer reference?

A user guide shows how to use a tool. A developer reference explains how it works — the methods, formulas and data behind the results.

## Why do some subjects have only one document?

Some tools have only a guide so far, and some subjects (such as a measurement method behind a tool) have only a reference. The pair switch on each article shows which half exists.

## Where is the API documentation?

The API guides are listed as subjects ending in "API", and the full endpoint reference is at https://auricartisan.com/library/documentation/api/. See also [Public API](../../../../services/public-api/README.md).

## Can I follow new documents?

Yes, with the RSS feed at https://auricartisan.com/library/documentation/rss.xml.

## Does the documentation library work without JavaScript?

Yes. The index is a plain list of links; search, the audience filter and the article side list are added on top.
