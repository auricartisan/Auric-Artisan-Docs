# Kit keyboard shortcuts

Shortcuts that open a kit work on any page. Shortcuts that act inside a kit work only while that kit is open. Each kit's own shortcuts page has the full detail.

## Open and close kits

| Shortcut | What it does |
|---|---|
| `Ctrl` + `Shift` + `K` (`Cmd` + `Shift` + `K` on a Mac) | Open or close the Feature Kit |
| `Ctrl` + `M` | Open or close the Menu Kit |
| `Ctrl` + `Shift` + `A` | Open or close the Advanced Kit |
| `Ctrl` + `Shift` + `L` (`Cmd` + `Shift` + `L` on a Mac) | Open or close the Library Kit |
| `Ctrl` + `Shift` + `U` | Update the website (Update Kit) |
| `Esc` | Close the page utilities bar, or close the open kit |

The Status Kit has no shortcut to open it. Use the **Status** launcher.

## Inside the Feature Kit

| Shortcut | What it does |
|---|---|
| `1` to `6` | On the Feature Kit menu, open Scientific Calculator, Unit Converter, Feedback, Notes, Date & Time or Developer Tools |
| `Ctrl` + `1` to `Ctrl` + `6` | Switch straight to one of the six tools while the kit has focus |
| `Esc` | In a tool, go back to the menu. On the menu, close the kit |
| Digits, `+`, `-`, `*`, `/`, `.`, `(`, `)`, `^`, `%`, `!` | Type on the calculator keypad when the cursor is not in a text box |
| `Enter` or `=` | Work out the calculator expression |
| `Backspace` | Delete the last character on the keypad |
| `Delete` | Clear the keypad |
| `/` | In the Unit Converter, jump to the unit search box |

See [Feature Kit shortcuts](../feature-kit/others/shortcuts.md).

## Inside the Menu Kit

| Shortcut | What it does |
|---|---|
| `/` | Put the cursor in the search box |
| `Down arrow` | From the search box or tabs, move into the list of pages |
| `Left arrow`, `Right arrow`, `Home`, `End` | On the tabs, switch tab |
| Arrow keys, `Home`, `End` | Move between pages and section headings |
| `Enter` or `Space` | On a section heading, collapse or expand it |
| `Up arrow`, `Down arrow`, `Enter` | While searching, move through results and open one |
| `Esc` | Clear the search, then close the kit |

See [Menu Kit shortcuts](../menu-kit/others/shortcuts.md).

## Inside the Status Kit

| Shortcut | What it does |
|---|---|
| `/` | Put the cursor in the path box, or in the results search after a scan |
| `Enter` | In the path box, run the scan |
| `Down arrow` | From the path or search box, move into the results |
| `Up arrow`, `Down arrow`, `Home`, `End` | Move through the results |
| `Esc` | Close the kit |

See [Status Kit shortcuts](../status-kit/others/shortcuts.md).

## Inside the Library Kit

| Shortcut | What it does |
|---|---|
| `Esc` | Clear the search, then close the panel |
| Arrow keys | Move between items |
| `Enter` | Restore the focused item into its tool |
| `Delete` | Delete the focused item |
| `Ctrl` + `A` (`Cmd` + `A` on a Mac) | Select all, while multi-select is on |
| `>` then a command name | Run a library command from the search box |

See [Library Kit shortcuts](../library-kit/others/shortcuts.md).

## Site-wide shortcuts that interact with kits

`Ctrl` + `K` opens the site-wide search on every page, even while a kit is open. The site settings panel has its own shortcuts, such as `Ctrl` + `,` to open settings. Both are covered in [Site features](../../site-features/README.md).
