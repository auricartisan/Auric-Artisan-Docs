# Kits and your privacy

The kits run in your browser. Almost everything they remember stays in your browser's storage for auricartisan.com and is never sent anywhere. This page lists what each kit keeps and the few cases where a kit uses the network.

## What every kit keeps in your browser

For each kit separately:

- the panel position after you drag it;
- whether it is expanded;
- whether Focus mode is on;
- its own light or dark theme, once you have used its **Theme** button.

## What each kit keeps, and what it sends

| Kit | Kept in your browser | Uses the network for |
|---|---|---|
| Feature Kit | Calculator history (up to 100 entries), notes, recently picked dates (up to 8), the tool you had open while Focus mode was on, feedback waiting to be sent | Loading the unit list the first time you open the Unit Converter; sending feedback you submit |
| Menu Kit | Last tab, collapsed sections, how often you open each page (for **Most Used**) | Loading the list of pages and the site status |
| Advanced Kit | Your tool visibility mode and your Custom tool ticks | Loading the list of tools for the Custom checklist |
| Status Kit | Your last 8 scans, collapsed result groups | Reading the site map and the pages you scan, all from auricartisan.com |
| Library Kit | Every saved item, collection and library setting, including any sync destinations you add | Only the sync destinations you set up yourself |
| Update Kit | The site version you last updated to | Checking the latest release and re-downloading the site's files when you update |

## Things that are never stored

- Calculator variables, functions you define and calculator memory last only until you leave or reload the page.
- Text you type into the Developer Tools stays on the page and is not kept.
- The Status Kit reads your connection, battery, memory and screen details in your browser to show them to you. It does not send them.

## Private windows and blocked storage

In a private window, or when your browser blocks storage for the site, the kits still work but forget everything when you close the page.

## Clear what the kits have stored

Clear the stored data for auricartisan.com in your browser's settings. This resets every kit and also deletes your Library Kit items, calculator history and notes. Export anything you want to keep first: the Library Kit has **Export**, and Notes has **Export** for each note.
