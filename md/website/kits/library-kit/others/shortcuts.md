# Library Kit shortcuts

The kit's own shortcut sheet (**Keys** in the footer) shows **⌘** for Mac. Where a shortcut below uses `Ctrl`, use `Cmd` on a Mac.

## Open and close

| Shortcut | What it does |
|---|---|
| `Ctrl` + `Shift` + `L` | Opens or closes the Library Kit, from anywhere on the site |
| `Esc` | Closes, in this order: an open menu or dialog, the **Panel options** menu, multi-select, the search text, then the panel |

## Search box

| Shortcut | What it does |
|---|---|
| `>` at the start | Switches to the command palette |
| `Up arrow`, `Down arrow` | Move through commands (command palette) |
| `Enter` | Runs the highlighted command (command palette) |
| `Down arrow` | Moves to the first tile (normal search) |
| `Esc` | Clears the search |

## Tiles

| Shortcut | What it does |
|---|---|
| `Left arrow`, `Right arrow` | Previous or next tile |
| `Up arrow`, `Down arrow` | Tile above or below; up from the first row returns to the search box |
| `Home`, `End` | First or last tile |
| `Enter` or `Space` | Restores the item (selects it in multi-select) |
| `Delete` | Asks to delete the item |
| `Ctrl` + `A` | Selects all items, while multi-select is on |

## Moving the panel

| Shortcut | Where | What it does |
|---|---|---|
| Arrow keys | The six-dot grip has focus | Move the panel 12 pixels |
| `Shift` + arrow keys | The six-dot grip has focus | Move the panel 1 pixel |

## Menus and dialogs

| Shortcut | Where | What it does |
|---|---|---|
| `Up arrow`, `Down arrow`, `Home`, `End` | **Panel options** menu | Move between options |
| `Enter` | Name dialogs (rename, new collection, new project) | Confirms |
| `Esc` | Any library dialog or menu | Cancels or closes it |
| `Ctrl` + `Enter` | The **Save to Library** dialog in a tool | Saves |
