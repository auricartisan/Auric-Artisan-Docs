# Menu Kit shortcuts

| Shortcut | Where | What it does |
|---|---|---|
| `Ctrl` + `M` | Anywhere | Opens or closes the Menu Kit |
| `/` | Kit open, cursor not in a text box | Puts the cursor in the search box |
| `Esc` | Search box with text | Clears the search |
| `Esc` | Kit open | Closes the kit |
| `Down arrow` | Search box (not searching) or tab row | Moves into the tiles |
| `Left arrow`, `Right arrow` | Tab row | Previous or next tab |
| `Home`, `End` | Tab row | First or last tab |
| Arrow keys | Tiles and section headings | Move to the previous or next item |
| `Home`, `End` | Tiles and section headings | First or last item |
| `Enter` or `Space` | Section heading | Collapses or expands the section |
| `Enter` | Tile | Opens the page |
| `Up arrow`, `Down arrow` | Search box while searching | Moves the highlight through the results |
| `Enter` | Search box while searching | Opens the highlighted page or runs the highlighted action |

`Ctrl` + `K`, shown in the footer, opens the site-wide search rather than the Menu Kit's search box. See [Site features](../../../site-features/README.md).
