# Kits

Kits are small floating panels that you can open on any page of auricartisan.com without leaving the page you are on. Each kit does one job: the **Feature Kit** holds a calculator, a unit converter, notes, date tools and developer utilities; the **Menu Kit** is a start menu for the whole site; the **Advanced Kit** decides which tools the site shows you; the **Status Kit** shows the status of pages and your device; the **Library Kit** holds everything you have saved from the tools.

Kits are modeless. A kit floats above the page, and the page underneath stays usable: you can scroll, click and type in a tool while a kit is open. You can drag a kit anywhere in the window, make it larger, shrink it to its title bar, give it its own light or dark theme, and keep it open while you move from page to page.

All kits open from one place: the page utilities bar in the bottom-left corner of the window. A few kits also have keyboard shortcuts, and the Library Kit has a button in the site header.

## Who it is for

- Anyone using the site's tools who wants a quick calculation, conversion or note without opening another tab.
- Designers and developers who save palettes, gradients, reports and presets and want to find, compare and reuse them.
- Visitors who want a simpler or a more technical view of the site's tools.
- Anyone who wants to see how a page or their device is doing: page status, connection, memory, frame rate.

## Where to find it

- On every page of https://auricartisan.com, select the round **Page utilities** button in the bottom-left corner. The bar opens and shows one labelled launcher per kit.
- Keyboard shortcuts open some kits directly. See [Keyboard shortcuts](others/shortcuts.md).
- The Library Kit also opens from the **Library** button in the site header, from a link ending in `#library`, and from https://auricartisan.com/library/workspace/.

## Quick start

1. Open any page on https://auricartisan.com.
2. Select **Page utilities** in the bottom-left corner. The bar opens with the launchers **Feature**, **Menu**, **Advanced**, **Status**, **Library**, **Navigate** and **Settings**, and the hub button now reads **Close**.
3. Select **Menu**. The bar folds away and the Menu Kit opens in the bottom-left corner with its search box ready.
4. Drag the kit by its title bar to move it somewhere convenient.
5. Select the four-arrow **Resize** button in the kit's title bar to make it wider and taller.
6. Select the target-shaped **Focus mode** button if you want the kit to stay open when you go to another page.
7. Select the cross (**Close**) in the title bar, or press `Esc`, to close the kit.

## The kits

| Kit | Launcher | What it is for | Shortcut |
|---|---|---|---|
| [Feature Kit](feature-kit/README.md) | **Feature** | Calculator with graphing, unit converter, feedback, notes, date and time, developer tools | `Ctrl` + `Shift` + `K` |
| [Menu Kit](menu-kit/README.md) | **Menu** | Start menu for the whole site, with tabs, search and quick actions | `Ctrl` + `M` |
| [Advanced Kit](advanced-kit/README.md) | **Advanced** | Choose Basic, Advanced, Everything or a Custom set of tools | `Ctrl` + `Shift` + `A` |
| [Status Kit](status-kit/README.md) | **Status** | Page status, section scans and a live device and connection readout | None |
| [Library Kit](library-kit/README.md) | **Library** | Browse, restore, compare, share and export your saved work | `Ctrl` + `Shift` + `L` |
| [Update Kit](update-kit/README.md) | No launcher | The **Update available** notice and the **Update website** command | `Ctrl` + `Shift` + `U` |

The page utilities bar also holds two launchers that are not kits: **Navigate**, which opens the page navigation dock, and **Settings**, which opens the site settings panel. Both are described in [Site features](../site-features/README.md).

> **Note:** The public changelog mentions a "UX Kit". It is not a panel you can open. It is the part of the site that changes page wording and hides or shows sections when you pick a mode in the Advanced Kit. What it changes is described in [What each mode changes](advanced-kit/docs/what-each-mode-changes.md).

## Controls every kit shares

Each kit panel has a title bar with the kit's name on the left and a row of small buttons on the right.

| Control | What it does |
|---|---|
| Title bar | Drag it to move the panel. The panel stays inside the window and remembers where you left it. |
| **Focus mode** (target icon) | Keeps the kit open when you go to another page and when you open another kit. |
| **Theme** (sun or moon icon) | Switches this kit, and only this kit, between light and dark. |
| **Resize** (four arrows) | Switches between the normal size and a larger expanded size. |
| **Minimize** (dash) | Shrinks the kit to its title bar. Select the bar to restore it. |
| **Close** (cross) | Closes the kit. |

The Library Kit keeps these controls in a **Panel options** menu, and the Feature Kit adds a **Back** button and calculator buttons. [Panel controls](docs/panel-controls.md) explains every control and every difference between kits.

## What you can do

- Open any kit from the page utilities bar on every page, including on a phone.
- Keep one or more kits open while you work in a tool.
- Move, enlarge, shrink and theme each kit independently.
- Keep a kit open across pages with Focus mode.
- Calculate, graph, convert units, take notes, work with dates and run developer utilities in the Feature Kit.
- Find any page on the site from the Menu Kit.
- Choose how much of the site's tool range you see in the Advanced Kit.
- Check page status and live device information in the Status Kit.
- Manage everything you have saved in the Library Kit.
- Update the site to the newest release with the Update Kit.
