# Status Kit release notes

The website's public release history is at https://auricartisan.com/library/changelog/ and https://auricartisan.com/company/timeline/.

## Recorded releases

| Release | Date | What the public history says |
|---|---|---|
| v0.9.75 | 19 April 2026 | Interface fixes to the Menu Kit and the Status Kit, as part of a broad stability release |
| v0.9.9 | 5 June 2026 | The site's release language moved to Beta, the status most pages now show |

## The Status Kit as of 24 September 2026

- A **This page** card with the current page's status and title.
- A collapsible **System status** panel with Network, Hardware, Memory, Display and Runtime tabs, refreshing every two seconds, including a live frame-rate sparkline.
- A page scanner with summary cards, status filters, results search, category groups and the last eight scans.
- Shared kit controls: Focus mode, per-kit theme, Resize, Minimize, Close, and a labelled **Status** launcher in the page utilities bar. The page status is shown only inside the kit, not as a floating badge on the page.

Changes not recorded in the public history are not listed here.
