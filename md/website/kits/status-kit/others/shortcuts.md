# Status Kit shortcuts

The Status Kit has no shortcut to open it. Open it from **Page utilities** > **Status**. While it is open:

| Key | Where | What it does |
|---|---|---|
| `/` | Cursor not in a text box | Puts the cursor in the path box, or in **Search pages...** after a scan |
| `Enter` | Path box | Runs the scan |
| `Down arrow` | Path box or **Search pages...** | Moves into the results |
| `Up arrow`, `Down arrow` | Results | Previous or next item |
| `Home`, `End` | Results | First or last item |
| `Enter` | A result row | Opens the page in a new tab |
| `Enter` or `Space` | **System status** heading | Collapses or expands the panel |
| `Esc` | Anywhere | Closes the kit |

`Ctrl` + `K` opens the site-wide search, not the Status Kit's boxes.

See [Kit keyboard shortcuts](../../others/shortcuts.md) for the other kits.
