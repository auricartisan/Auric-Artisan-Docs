# Update Kit shortcuts

| Shortcut | Where | What it does |
|---|---|---|
| `Ctrl` + `Shift` + `U` | Any page | Runs **Update website**: clears the site's cached files, re-downloads the page's files and reloads |
| `Tab`, `Enter` | Update notice | Reach and select **Update now** or **x** |

The right-click menu shows this shortcut as **Ctrl+⇧+U** next to **Update website**.

See [Kit keyboard shortcuts](../../others/shortcuts.md) for the other kits.
