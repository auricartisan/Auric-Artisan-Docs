# Related to the Feature Kit

## Other kits

- [Advanced Kit](../../advanced-kit/README.md) — its mode decides which calculator keypads you see.
- [Library Kit](../../library-kit/README.md) — for palettes, gradients and reports you save from the site's tools. (Feature Kit notes and calculations are not saved there.)
- [Menu Kit](../../menu-kit/README.md) — jump to any tool on the site.
- [All kits](../../README.md) and [Panel controls](../../docs/panel-controls.md).

## Tools with related features

- [Basic Colour Tools](../../../tools/colour-workspace/basic-colour-tools/README.md) — colour format conversion, which the Unit Converter does not cover.
- [Colour Science Lab](../../../tools/colour-workspace/colour-science-lab/README.md) — colour maths such as colour-space conversion and colour difference.
- [Design Engine](../../../tools/colour-workspace/design-engine/README.md) — spacing, type and colour tokens, if you are converting units for a design system.
