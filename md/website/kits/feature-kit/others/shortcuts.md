# Feature Kit shortcuts

The kit's menu shows **⌘** instead of **Ctrl** on a Mac. Where a shortcut below uses `Ctrl`, use `Cmd` on a Mac.

## Open, close and move around

| Shortcut | Where | What it does |
|---|---|---|
| `Ctrl` + `Shift` + `K` | Anywhere | Opens or closes the kit. With Focus mode on, moves focus into the open kit instead of closing it |
| `Esc` | Kit open | In a tool, returns to the menu. On the menu, closes the kit |
| `1` to `6` | Menu | Opens Scientific Calculator, Unit Converter, Feedback, Notes, Date & Time, Developer Tools |
| `Ctrl` + `1` to `Ctrl` + `6` | Focus inside the kit | Switches straight to that tool, even from inside another tool or a text box |
| Arrow keys, `Home`, `End` | Menu | Move between the six cards |
| `Enter` or `Space` | A focused card | Opens that tool |
| `Left arrow`, `Right arrow`, `Home`, `End` | A focused title-bar button | Move between the title-bar buttons |
| `Tab`, `Shift` + `Tab` | Kit open, Focus mode off | Move between the kit's controls; focus stays inside the kit |
| `Enter` or `Space` | Minimised kit icon | Reopens the kit |

Browsers commonly use `Ctrl` + a number to switch browser tabs and may act on it before the Feature Kit does. If that happens, use the plain number keys on the menu instead.

## Calculator keypad

These work while the Scientific Calculator is open and the cursor is not in a text box.

| Key | Action |
|---|---|
| `0` to `9` | Digit |
| `+` | Add |
| `-` | Subtract |
| `*` | Multiply |
| `/` | Divide |
| `.` | Decimal point |
| `(` and `)` | Brackets |
| `^` | Power |
| `%` | Remainder |
| `!` | Factorial |
| `Enter` or `=` | Work out the expression |
| `Backspace` | Delete the last character |
| `Delete` | Clear the expression |

## Calculator text boxes

| Key | Where | Action |
|---|---|---|
| `Enter` | Expression bar | Works out the expression |
| `Enter` or `Space` | A focused history entry | Loads it into the display |

## Unit Converter

| Key | Action |
|---|---|
| `/` | Puts the cursor in **Search units...** (when the cursor is not in a text box) |

## Developer Tools

| Key | Where | Action |
|---|---|---|
| `Enter` | **Epoch** input | Converts the value |
| `Enter` | **Cron** input | Explains the expression |
