# Getting started with the Feature Kit

The Feature Kit opens on a menu of six tools. This guide opens the kit, explains what you see, and runs a first calculation.

## Open the kit

Use either:

- **Page utilities** (bottom-left corner) > **Feature**, or
- `Ctrl` + `Shift` + `K` (`Cmd` + `Shift` + `K` on a Mac) from anywhere on the page.

The first time you open it on a page, the launcher dims for a moment while the kit loads.

## The menu

The kit opens on its menu: six cards, each with an illustration, a title, a one-line description and a number key.

| Key | Card | Description on the card |
|---|---|---|
| `1` | **Scientific Calculator** | Advanced math, graphing, history |
| `2` | **Unit Converter** | 1000+ conversions across 50+ categories |
| `3` | **Feedback** | Quiet, optional feedback in Feature Kit |
| `4` | **Notes** | Markdown scratchpad with autosave |
| `5` | **Date & Time** | Date math, durations, time zones |
| `6` | **Developer Tools** | JSON, JWT, regex, cron, hash, UUID, text tools |

Below the cards, a hint line reads **1 – 6 Open · Ctrl ⇧ K Toggle** (with **⌘** on a Mac).

To open a tool, select its card, press its number key, or use the arrow keys to reach the card and press `Enter`.

## The title bar

| Button | When you see it | What it does |
|---|---|---|
| **Back** (left arrow) | Inside any tool | Returns to the menu |
| Title | Always | Reads **Feature Kit** on the menu and the tool's name inside a tool. Drag it to move the kit. |
| **Graph** (wave) | Calculator only | Shows or hides the graph |
| **History** (clock) | Calculator only | Shows or hides past calculations |
| **Focus mode** (target) | Always | Keeps the kit open across pages and other kits |
| **Theme** (sun or moon) | Always | Switches the kit between light and dark |
| **Resize** (four arrows) | Always | Switches between normal and full size |
| **Minimize** (dash) | Always | Shrinks the kit into a small restore icon |
| **Close** (cross) | Always | Closes the kit and turns Focus mode off |

## Dimmed page and Focus mode

With Focus mode off, the page behind the Feature Kit is dimmed while the kit is open, `Tab` moves only between the kit's own controls, and clicking the dimmed page closes the kit. Select **Focus mode** to stop dimming the page and keep the kit open while you work. See [Panel controls](../../docs/panel-controls.md).

## Your first calculation

1. Press `1` to open **Scientific Calculator**.
2. Type `12*7` on your keyboard. The top line of the display shows the expression and the large line shows a live result, `84`.
3. Press `Enter`. The result is stored as `ans`.
4. Select the expression bar under the display, type `ans/8` and press `Enter`. The display shows `10.5 = 21/2`: the decimal and the exact fraction.
5. Select the large result. A message reads **Copied!** and the result is on your clipboard.

You have used both ways of entering a calculation: the keypad (or your keyboard) and the expression bar.

## Leave the kit

- Press `Esc` once to go back to the menu from a tool, and again to close the kit.
- Or select **Close** in the title bar.

The kit remembers your calculator history and notes for next time.
