# What each mode changes

The mode you pick in the Advanced Kit is read by several parts of the site. This page lists each one and what it does in each mode.

## Summary

| Part of the site | Basic | Advanced | Everything | Custom |
|---|---|---|---|---|
| Menu Kit tiles and search | Basic and both tools | Advanced and both tools | All | All except unticked tools |
| Tool collections | Basic and both tools | Advanced and both tools | All, including cards hidden earlier | All except unticked tools |
| Feature Kit calculator keypads | **Basic** only | **Scientific**, **Programmer** | All three | All three |
| Page wording (see below) | Basic wording | Advanced wording | Everything wording | Basic wording |

## Menu Kit

The Menu Kit shows only the tools the mode allows, in its tiles and in its search results. A tab with nothing to show is hidden:

- **Basic:** the **Design** tab disappears.
- **Advanced:** the **Design** tab appears, and the **General Color Tools** section of the Tools tab is hidden.
- **Everything:** every tab and page.
- **Custom:** every page except unticked tools.

See [Find a page](../../menu-kit/docs/find-a-page.md).

## Tool collections

Tool collection grids, such as the one at https://auricartisan.com/collections/, show only the tools the mode allows. In **Everything** mode they also bring back cards that were hidden, whether you hid them or the grid hid them because you had not used them. While you search a collection, every matching tool shows, whatever the mode.

See [Collections](../../../library/collections/README.md).

## Feature Kit calculator

The calculator's keypad tabs follow the mode:

- **Basic:** only the **Basic** keypad.
- **Advanced:** the **Scientific** and **Programmer** keypads; the **Basic** keypad is hidden.
- **Everything** and **Custom:** all three.

The expression bar works the same in every mode. See [Calculator](../../feature-kit/docs/calculator.md).

## Page wording

Some pages switch between plainer and more technical wording. Page titles in the browser tab and search-engine descriptions do not change.

| Page | What changes | Basic | Advanced | Everything |
|---|---|---|---|---|
| Home page | The tagline under the welcome heading | Play with color | tools that respect intelligence | Color · Science · Design |
| URL Analyzer | The placeholder in the URL box | Enter a URL to analyze… | Enter a URL for deep DOM, SEO, contrast & accessibility audit… | Enter a URL to analyze colors, contrast, SEO, and accessibility… |
| Vision Simulation | The search box placeholder | Search simulations… | Search models, adaptation… | Search simulations, tools… |
| Colour Science Lab | The search box placeholder | Search color tools… | Search mixers, gamut mapping, spectral tools… | Search color science tools… |
| Colour Science Lab | The subtitle under the heading | A short description of mixers, converters and harmony tools | A technical description of perceptual mixing, spectral simulation and gamut mapping | A description covering both |
| Basic Colour Tools | The subtitle under the heading | Essential tools: palette maker, gradient builder, picker, converters | The advanced workspace: OKLCH gradients, palette battles, remix, precision conversion | All seven tools in one floating-panel workspace |
| Basic Colour Tools | The search box placeholder | Search palette, gradient, picker… | Search palette, remix, battle, gradient, collage, converter… | Search palette, remix, battle, gradient, picker, collage, converter… |
| Basic Colour Tools | The label of the guide note | Quick Start: | Pro Tips: | Quick Start: |
| Ishihara Plate Generation | The subtitle under the heading | A plain explanation of what the plates do | A technical description of seeded plate synthesis, ΔE separation and the 38-plate set | A combined description |

In **Custom** mode, pages use the Basic wording.

When you switch mode, the wording changes on the page you are on straight away, with a short transition.

> **Note:** The public changelog calls the part of the site that makes these wording changes the "UX Kit". It has no panel of its own; the Advanced Kit is how you control it.

## What the mode never changes

- No tool is locked. Every tool page opens from its address in every mode.
- Your saved items in the Library Kit, your settings and your account are not affected.
- The site-wide search is not filtered by the mode.
