# Advanced Kit troubleshooting

For problems shared by every kit, see [Troubleshooting kits](../../docs/troubleshooting.md).

## My mode changed by itself

**Why:** Some tools have their own mode switch that sets the same site-wide mode. Opening the URL Analyzer sets the site to **Basic** or **Advanced** to match the Analyzer's Simple or Advanced mode. The Vision Simulation lab and the Colour Science Lab can also change it, and resetting the Vision Simulation filters sets **Everything**.

**What to do:** Open the Advanced Kit and choose your mode again. If you were in **Custom** mode, your ticks are still there; select **Custom** to use them again.

## A tool I unticked still appears

**Why:** Your ticks only apply while the current mode is **Custom**. Another mode may be active, or a tool may have changed the mode (see above).

**What to do:** Check **Current mode** in the Advanced Kit and select **Custom**.

## A tool I want is missing from the menu

**Why:** The current mode hides it, or you unticked it in Custom mode.

**What to do:** Select **Everything**, or tick the tool in Custom mode. Every tool also opens from its own address.

## The Custom checklist says "No tools found."

**Why:** The tool list could not be downloaded.

**What to do:** Check your connection, reload the page, and open the Advanced Kit again.

## The checklist names do not match the Menu Kit

**Why:** The checklist uses the names from the tool collections where it can, such as **Analyze URLs** for the URL Analyzer and **Basic Tools** for Basic Color Tools.

**What to do:** Search for a word in the tool's name, such as `analy` or `basic`.

## Ctrl + Shift + A does nothing

**Why:** Some browsers use this key combination for their own features and act on it first.

**What to do:** Open the kit from **Page utilities** > **Advanced**.

## The mode is different on my other computer

**Why:** The mode is stored in each browser, not in your account.

**What to do:** Choose the mode once in each browser you use.

## Page wording did not change

**Why:** Only some pages have mode-dependent wording, and the browser tab title and search-engine description never change. See [What each mode changes](what-each-mode-changes.md).

**What to do:** Nothing is wrong. Tool lists, the Menu Kit and the calculator keypads still follow the mode.
