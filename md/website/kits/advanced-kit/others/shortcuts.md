# Advanced Kit shortcuts

| Shortcut | Where | What it does |
|---|---|---|
| `Ctrl` + `Shift` + `A` | Anywhere | Opens or closes the Advanced Kit |
| `Esc` | Kit open | Closes the kit |
| `Tab`, `Shift` + `Tab` | Kit open | Move between the mode cards, buttons, filter box and checkboxes |
| `Enter` or `Space` | A mode card | Selects that mode |
| `Space` | A tool checkbox | Ticks or unticks the tool |

When the kit opens, keyboard focus goes to the card of the current mode.

See [Kit keyboard shortcuts](../../others/shortcuts.md) for the other kits.
