# Advanced Kit limits

## What the modes affect

- The Menu Kit's tiles and search results.
- Tool collection grids, such as https://auricartisan.com/collections/.
- The Feature Kit calculator's keypad tabs.
- Some wording on the home page and on the URL Analyzer, Vision Simulation, Colour Science Lab, Basic Colour Tools and Ishihara Plate Generation pages.

## What they do not affect

- Whether a tool page opens: nothing is locked.
- Browser tab titles and search-engine descriptions.
- The site-wide search.
- Your saved library items, settings and account.

## How tools are classified

- Tools listed in the Menu Kit carry a level of basic, advanced or both, set by the site. Where no level is set, the site decides from the tool's section: tools in the Tools tab count as basic, tools in the Design tab as advanced, and account, library, company and legal pages as both.
- The classification is the site's, not yours. To show or hide a particular tool regardless of its level, use **Custom** mode.

## Custom mode

- The checklist covers tool pages only (addresses starting with `/tool/`), not other pages.
- Custom choices are stored as a list of tools you have turned off. New tools added to the site later start switched on.
- Page wording follows the Basic set while Custom is active.

## Storage

- The mode and your custom choices are stored in this browser only.
- Some tools can change the mode when you use their own mode switch; see [Troubleshooting](../docs/troubleshooting.md).
