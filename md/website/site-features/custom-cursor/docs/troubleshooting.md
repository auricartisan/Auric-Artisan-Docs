# Troubleshooting the custom cursor

## The cursor feels slow or lags behind

**Why:** the ring follows the pointer smoothly on purpose, and on a busy page or a slower computer it can fall further behind.

**What to do:** aim with the dot, which is exact. If the lag bothers you, switch off **Custom cursor** in Settings › Comfort.

## I cannot see the cursor

**Possible causes and fixes:**

- The ring fades when you stop moving. Move the mouse.
- The page is still loading. Wait a moment.
- Switch off **Custom cursor** in Settings to use your system pointer.

## My large or high-contrast system pointer is replaced

**Why:** the custom cursor hides the system pointer.

**What to do:** switch off **Custom cursor** in Settings › Comfort. Your system pointer, with its size and colour, returns everywhere on the site.

## The custom cursor does not appear at all

**Why:** it is off in Settings, your device has no hovering pointer, your device asks for reduced motion, or reading mode is on. This is intended.

## Screen recordings show a ring and dot

**Why:** the custom cursor is part of the page, so recordings of the page include it.

**What to do:** switch it off before recording, or use the recorder's **Highlight the cursor** option with the custom cursor off.
