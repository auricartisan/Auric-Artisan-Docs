# Get started with the screen recorder

## Open the recorder

- Press `Alt` + `Shift` + `R` on any page.
- Or point at the navigation dock and select **Record screen (Alt+Shift+R)**.

The first time, the recorder takes a moment to load. The **Your Recorder** dialog opens. It floats over the page without blocking it.

## A tour of the dialog

1. **Header.** A grip to move the dialog, the title **Your Recorder**, **Reset dialog position** and **Close**.
2. **Recording source** (choose what enters the frame): **Screen or window**, **This tab**, **Region of this page**, **Tool canvas**. Each has a one-line description. A source the page or browser cannot use is greyed out with the reason.
3. **Capture settings** (video output): **Frame rate**, **Quality**, **Resolution cap** and **Countdown**.
4. **Audio & pointer** (optional capture layers): **Microphone**, **Tab audio** and **Highlight the cursor**.
5. **A note** saying which video format this browser records: "Recording to MP4 — plays anywhere." or "Recording to WebM. Export to GIF or frames from My recordings."
6. **Footer.** **My recordings**, **Reset setup**, the `Alt` `Shift` `R` reminder, and **Start recording**.

Your choices are remembered for next time.

## Your first recording

1. Open the recorder.
2. Choose **Screen or window**.
3. Select **Start recording**. Your browser's sharing dialog opens.
4. Pick the window or screen to record and confirm.
5. A large countdown (3, 2, 1) shows on the page. Recording then starts, and the recording bar appears with a timer and the file size so far.
6. Select **Stop and save** on the bar, press `Alt` + `Shift` + `R`, or use your browser's own **Stop sharing** button.

Result: a message such as "Recording saved — 00:42, 6.3 MB." appears, and **My recordings** opens with the new clip highlighted.

## Move or reset the dialog

- Drag the header to move the dialog. With the grip focused, the arrow keys move it; hold `Shift` for finer steps.
- **Reset dialog position**, or a double-click on the grip, returns it to the centre ("Recorder returned to the center.").
- On narrow screens the dialog cannot be dragged.

## Close the dialog

Select **Close** or press `Esc`. If a drop-down list in the dialog is open, the first `Esc` closes the list.
