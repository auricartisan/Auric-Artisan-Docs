# Screen recorder glossary

| Term | Meaning |
|---|---|
| Source | What the recorder captures: a screen or window, this tab, a region, or a tool canvas. |
| Take | One recording, from start to stop. |
| Frame rate (fps) | How many images per second a video holds. Higher is smoother and larger. |
| Resolution cap | The largest width a recording is allowed; bigger sources are scaled down. |
| Canvas | A drawing surface that tools use for graphics and animation. |
| Region | A rectangle of the page, or one element, that a recording is cropped to. |
| MP4, WebM | Video file formats. MP4 plays almost everywhere; WebM is widely supported by browsers. |
| GIF | An animated image format that plays in most apps and web pages without a player. |
| Re-encode | To play a video and record it again, which is how trimming makes a new file. |
| Sharing dialog | The browser's own window asking which screen, window or tab to share. |
