# Screen recorder shortcuts

| Keys | Action |
|---|---|
| `Alt` + `Shift` + `R` | Open the recorder; while recording, stop and save |
| `Alt` + `Shift` + `P` | Pause or resume a recording |
| `Esc` | Close the dialog, recordings list or player; cancel the region picker |
| Arrow keys on the dialog grip | Move the dialog; hold `Shift` for finer steps |

`Alt` + `Shift` was chosen to avoid browser shortcuts: `Ctrl` + `Shift` + `R` is your browser's hard reload. The full list is in [Keyboard shortcuts](../../keyboard-shortcuts/README.md).
