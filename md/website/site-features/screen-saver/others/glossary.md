# Screen saver glossary

| Term | Meaning |
|---|---|
| Idle | No mouse, keyboard, scroll, wheel or touch activity on the page. |
| Colour atlas | The site's collection of 8,192 named colours with mood and movement notes. |
| OKLCH | A way of writing colour as lightness (L), chroma (C) and hue (H) that follows human perception. |
| Lightness step | One of the seven bands, each a fixed OKLCH lightness from 0.22 to 0.94. |
| Chroma | How colourful a colour is, from grey (0) upwards. |
| Contrast on black | The WCAG contrast ratio between the colour and pure black. |
