# Cookie consent glossary

| Term | Meaning |
|---|---|
| Cookie | A small piece of data a website stores in your browser and receives back on later visits. |
| Local storage | Browser storage that a website's pages can read, but which is not sent to the website automatically. |
| First-party | Set by the website you are visiting (here, auricartisan.com), not by another company. |
| Consent | Your recorded choice about which optional categories the site may use. |
| Essential | Needed for the site to work securely; cannot be turned off. |
| Functional | Remembers your preferences. |
| Analytics | Measures how the site is used, in aggregate or pseudonymously. |
| Marketing | Campaign attribution and advertising measurement; not currently used. |
| Do Not Track, Global Privacy Control | Browser settings that ask websites not to track you. |
| Pseudonymous | Linked to a random identifier rather than to your name or account. |
