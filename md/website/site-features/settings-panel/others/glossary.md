# Settings panel glossary

| Term | Meaning |
|---|---|
| Accent | The site's highlight colour for links, buttons, active tabs, focus rings, kit launchers and tooltip borders. Gold by default. |
| Contrast ratio | The WCAG measure of how different two colours are in lightness, from 1:1 (none) to 21:1 (black on white). |
| WCAG | The Web Content Accessibility Guidelines, the international standard for accessible web content. |
| AA, AAA | WCAG contrast levels for body text: AA needs 4.5:1, the stricter AAA needs 7:1. |
| AA Large | A contrast of at least 3:1, accepted by WCAG for large text and interface parts but not body text. |
| Eyedropper | A browser tool that lets you click any pixel on your screen to read its colour. |
| Hex colour | A colour written as `#` and six hexadecimal digits for red, green and blue, for example `#D3AF37`. |
| Local storage | A small store inside your browser where a website keeps data on your device. |
| Modeless | A panel that does not block the page behind it. You can keep using the page while it is open. |
| Reading mode | A distraction-free layout with a narrow text column, larger type and no floating controls. |
| Saved colors | Your own palette of up to 18 accent colours, added only when you select the + button. |
| Section | One of the groups in the panel's list: Appearance, Comfort, Highlights, Clock, Tooltips, Ads, Shortcuts. |
| System theme | A theme setting that follows your device's light or dark preference and changes when it changes. |
| Toast | A short message that appears briefly to confirm an action, such as "Settings exported". |
| Tooltip | The small card that appears when you hover over or focus a control, explaining what it does. |
