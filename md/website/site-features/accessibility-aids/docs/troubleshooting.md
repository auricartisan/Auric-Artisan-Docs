# Troubleshooting the accessibility aids

## The Alt shortcuts do not work

**Why:** they are ignored while you type in a field, and when `Ctrl` or `Cmd` is also held. On some keyboards, `Alt` + `+` needs `Shift` as well; `Alt` + `=` also works.

**What to do:** click an empty part of the page first, or use the Settings panel.

## Text size did not change everywhere

**Why:** the text size setting scales the site's text. Some tools draw text inside images or canvases, which it cannot resize.

**What to do:** use your browser's zoom (`Ctrl` + `+`) for those.

## Something still moves with Reduce motion on

**Why:** Reduce motion stops animations and transitions defined by the site's styles. A tool that animates a canvas as its purpose (for example a live simulation) may keep doing so.

**What to do:** turn on your device's reduced-motion setting as well, which the site also follows.

## My screen reader announces too much or too little

**What to do:** report it with **Report a bug** (see [Feedback](../../feedback/README.md)), naming the page, your screen reader and browser.

## Reading mode did not change a page much

**Why:** reading mode is designed for text pages. On a tool page it hides floating controls and adjusts text, but the tool's own layout stays.
