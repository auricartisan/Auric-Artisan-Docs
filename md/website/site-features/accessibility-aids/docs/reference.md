# Accessibility aids reference

| Aid | Where | Shortcut | Default |
|---|---|---|---|
| Text size (Small, Default, Large, X-Large) | Settings › Appearance › **Text size** | `Alt` + `+` / `Alt` + `-` / `Alt` + `0` | Default |
| Theme (Light, Dark, System) | Settings › Appearance › **Theme**; header button | `Alt` + `T` | System |
| Language (English, Hindi) | Settings › Appearance › **Language**; header globe | — | English |
| Reading mode | Settings › Comfort › **Reading mode** | `Alt` + `R` | Off |
| Reduce motion | Settings › Comfort › **Reduce motion** | `Alt` + `M` | Off |
| Reduce transparency | Settings › Comfort › **Reduce transparency** | — | Off |
| Boost contrast | Settings › Comfort › **Boost contrast** | — | Off |
| Underline links | Settings › Comfort › **Underline links** | — | Off |
| Custom cursor | Settings › Comfort › **Custom cursor** | — | On |
| Eye-rest reminders | Settings › Comfort › **Eye-rest reminders** | — | Off |
| Tooltips (on, detailed, advanced) | Settings › **Tooltips** | `Alt` expands a tooltip's details | On, detailed, not advanced |
| Info bars and notices | Settings › **Highlights**; ✕ on each | — | Homepage only / on |
| Skip link | First `Tab` on every page | — | Always |

## Device settings the site follows

| Device setting | Site behaviour |
|---|---|
| Dark or light mode | Followed when the theme is **System** |
| Reduced motion | Custom cursor off; eye-rest horizon still; shorter welcome; bars swap without fading |
| Touch screen or no hover | Custom cursor off |
| Speech voice | Used by **Read aloud** in the right-click menu |
