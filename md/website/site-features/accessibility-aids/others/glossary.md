# Accessibility aids glossary

| Term | Meaning |
|---|---|
| Reading mode | A distraction-free layout with a narrow, large-text column and no floating controls. |
| Reduced motion | Fewer and shorter animations; also a device setting the site follows. |
| Transparency | See-through, blurred panel backgrounds; turned solid by Reduce transparency. |
| Contrast | The difference in lightness between text and its background. |
| Skip link | A link at the start of the page that jumps past the header to the main content. |
| Focus | The control that keyboard input currently goes to, shown with an outline. |
| Screen reader | Software that reads the screen aloud or in braille. |
| Live announcement | A message a screen reader reads without moving focus. |
| Modal dialog | A panel that keeps keyboard focus inside it until closed. |
