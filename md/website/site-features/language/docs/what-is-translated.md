# What is translated

## Translated into Hindi

- **Site chrome:** the header, drawer, footer, info bars, cookie notice, navigation dock and page utilities bar.
- **Panels:** the Settings panel, the kits, Spotlight, the guide and tours, the right-click menu and the eye-rest reminder.
- **Page content:** the text of company and legal pages, tool pages, Learn articles, documentation, blog posts and library pages.
- **Hidden text:** tooltips, placeholders in empty fields, image descriptions and the labels read out by screen readers.
- **Messages** built from live values, such as labels that include a colour code or a count, for the common kinds of message.
- **The logo:** the Auric Artisan wordmark is shown in Devanagari.
- **Promotional images** with text in them are swapped for Hindi versions where one exists.
- **Dates and times** are written the Hindi (India) way, for example on the clock strip.

Pages that open without the rest of the site around them, such as sign-in, checkout, the offline page and the "page not found" page, are translated too.

## Written in Devanagari rather than translated

The site's own brand and product names are transliterated, not translated: Auric Artisan becomes ऑरिक आर्टिज़न, and names such as Auric Icons and the kit names (फ़ीचर किट, मेन्यू किट and so on) are written the same way.

## Kept as they are

- **Code, keyboard keys and values:** anything shown as code, key caps such as `Ctrl`, hex codes, numbers with units, and file names.
- **Names of other companies and products** that people type or search for: Google, GitHub, VS Code, Open VSX, Figma, Razorpay, Cloudflare and similar.
- **Technical and scientific names** that are used internationally, such as CIELAB, xyY, YCbCr, Von Kries, Bradford, and font names such as Inter.
- **The language buttons** themselves, which always show English and हिन्दी.
- **Web addresses:** a page has the same address in both languages.
- **Your own content:** names you give to saved items, text you type into tools, and portfolio text.
- **Social preview images** (the picture shown when a link is shared) stay in English.

## Not covered by this switch

- **The browser extension** is a separate product with its own language support. See [Browser extension](../../../../browser-extension/README.md).
- **Search results** are matched against the English text of pages, so searching with English words works best.
- A small number of messages assembled from several live values may still appear partly in English.
