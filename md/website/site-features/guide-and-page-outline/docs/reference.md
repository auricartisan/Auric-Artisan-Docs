# Guide and page outline reference

## Ways to open the guide

| Method | Notes |
|---|---|
| `?` | Not while typing in a field, and not with `Ctrl`, `Alt` or `Cmd` held |
| Header **Guide** button | Tooltip: "Search pages, tools, and quick paths, or start a guided tour. Shortcut: ?" |
| Drawer **Guide** tile | "Tours and shortcuts" |
| Spotlight **Open the page guide** | "What this page is, and its tour" |

## Guide panel

| Part | Content |
|---|---|
| Head | Kicker, page title, summary |
| Filter box | "Filter this guide…" |
| Tabs | All, Tour, Tools, Pages, Learn, Help |
| Tour card | Take the guided tour / Pick up where you left off / Replay the tour |
| Start over | **Start over from stop 1** (after leaving part-way) |
| **On this page** | Numbered stops for this page; tick when seen |
| **Getting around** | The site-wide stops, with "x/y seen" |
| **Elsewhere** | Full Search, Analyze a website, Find the right tool, Open saved work, Read documentation, Learn color concepts, Install the PWA, Install the extension |
| **Recommended paths** | Run a quick audit, Build color assets, Check accessibility, Find a feature fast |
| Close | X (**Close guide**), **ESC** button, click outside |

## Guide kinds

Home, Analyzer, Collections, Search, Workspace, Library, Tool, Company, Policy and Site guides, chosen from the page you are on.

## Recommended paths

| Path | Steps |
|---|---|
| **Run a quick audit** | Open Analyzer · Paste a URL · Stay in Simple mode · Check Overview, Fixes and Report |
| **Build color assets** | Start in Collections · Choose a generator · Refine the palette or gradient · Save useful outputs |
| **Check accessibility** | Use Analyzer or the accessibility library to inspect contrast, vision simulation, and readable pairs |
| **Find a feature fast** | Open Search from the header · Type the tool name or task · Open the best match |

## Keys in the guide panel

| Keys | Action |
|---|---|
| Type | Filter |
| `Down` / `Up` | Next or previous item |
| `Home` / `End` | First or last item (not in the filter box) |
| `Enter` | Open the focused item, or the top match from the filter box |
| `Left` / `Right` on a tab | Previous or next tab |
| `Esc` | Close the guide |

## Tour card and controls

| Control | Key |
|---|---|
| **Next** | `Right` |
| **Back** | `Left` |
| **Finish** | — |
| **Leave the tour** (X) | `Esc` |
| **Skip to this page’s N stops** | — |
| **What to look for** | Expands the details |

## Section rail

| Item | Behaviour |
|---|---|
| Label | "On this page" |
| Pages | Company About, Pricing, Accessibility, FAQ; all legal pages; the Trust Center |
| Pinned | Below the header while scrolling |
| Current section | Highlighted |
| Legal pages | Jumping opens folded sections |

## Stored

Per-page tour progress (furthest stop reached and whether you finished) is kept in this browser.
