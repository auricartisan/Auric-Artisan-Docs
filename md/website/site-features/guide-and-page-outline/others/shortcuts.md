# Guide and tour shortcuts

| Keys | Action |
|---|---|
| `?` | Open the guide |
| `Esc` | Close the guide, or leave a tour |
| `Down` / `Up` | Move through the guide's items |
| `Home` / `End` | First or last item |
| `Enter` | Open the focused item, or the top filter match |
| `Left` / `Right` on a tab | Change tab |
| `Right` during a tour | Next stop |
| `Left` during a tour | Previous stop |

See [Keyboard shortcuts](../../keyboard-shortcuts/README.md) for the whole site.
