# Guide and page outline glossary

| Term | Meaning |
|---|---|
| Guide | The help panel for the current page, opened with `?`. |
| Guided tour | A step-by-step walk through a page's important areas. |
| Stop | One step of a tour, highlighting one area of the page. |
| Site-wide stops | Tour stops about the header, search, library, theme and footer, the same on every page. |
| Recommended path | A short recipe in the guide for a common job. |
| Section rail | The pinned "On this page" row of section links on long company, legal and trust pages. |
| Folded section | A section of a legal page that shows only its heading until opened. |
