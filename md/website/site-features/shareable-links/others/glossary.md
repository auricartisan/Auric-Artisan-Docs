# Shareable links glossary

| Term | Meaning |
|---|---|
| Address (URL) | The web address shown in the browser's address bar. |
| Fragment | The part of an address after `#`. Browsers keep it on your device and do not send it to the site. |
| Query parameter | A part of an address after `?`, such as `?lang=hi`, which the page reads. |
| Page state | The scroll position, inputs, selections and open panels of a page. |
| `#p=` | The fragment in which the site keeps a page's state. |
| Restore | Putting a page back into the state its address describes. |
| Clean link | An address without the `#p=` part. |
