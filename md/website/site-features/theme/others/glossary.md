# Theme glossary

| Term | Meaning |
|---|---|
| Theme | The overall colour scheme of the site's interface: light or dark. |
| Light theme | Light backgrounds with dark text. |
| Dark theme | Dark backgrounds with light text. |
| System mode | A setting that follows your device's light or dark preference. Called **Auto** in the drawer. |
| Toggle | A control that switches between two states, here light and dark. |
| Override | A theme set for one panel (a kit or a split-view pane) that differs from the site's theme. |
