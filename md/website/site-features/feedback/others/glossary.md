# Feedback glossary

| Term | Meaning |
|---|---|
| Automatic prompt | The feedback panel the site shows by itself after 20 minutes of active use. |
| Active time | Time with the page visible on screen; time in a background tab does not count. |
| Quiet period | The time after a prompt during which the site does not ask again. |
| Anonymous feedback | Feedback sent without a name or email. |
| Bug report | A description of something that went wrong, sent with details of the page. |
| Severity | How badly a bug affects you: Minor, Normal or Blocking. |
| Draft | Text you have typed but not sent, kept on your device. |
