# Header and navigation shortcuts

## Menus and drawer

| Keys | Action |
|---|---|
| `Enter` / `Space` on a menu button | Open or close the menu |
| `Down` / `Up` on a menu button | Open the menu at its first or last entry |
| `Down` / `Up` in a menu | Next or previous entry |
| `Home` / `End` in a menu | First or last entry |
| `Esc` | Close the open menu, or else the drawer |

## Tools the header opens

| Keys | Opens |
|---|---|
| `Ctrl` + `K` (`Cmd` + `K` on a Mac) | Spotlight search |
| `?` | The page guide |
| `Ctrl` + `Shift` + `L` | The Library Kit |
| `Alt` + `T` | Switch theme (Light, Dark, System) |
| `Ctrl` + `,` | The Settings panel |
| `Esc` | Close the page utilities bar |
