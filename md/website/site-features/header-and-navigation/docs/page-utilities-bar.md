# The page utilities bar

The **page utilities bar** is a single round button at the bottom-left corner of every page. Select it to open a bar of labelled launchers:

| Launcher | Opens |
|---|---|
| **Feature** | The Feature Kit |
| **Menu** | The Menu Kit |
| **Advanced** | The Advanced Kit |
| **Status** | The Status Kit |
| **Library** | The Library Kit |
| **Navigate** | The navigation dock (Back, Forward, Reload, outline, split view and more) |
| **Settings** | The Settings panel |

The kits are documented in [Kits](../../../kits/README.md), which also covers this bar in more depth. The dock is documented in [Navigation dock](../../navigation-dock/README.md), and the panel in [Settings panel](../../settings-panel/README.md).

## Open and close the bar

1. Select the button at the bottom-left. Its tooltip reads **Page utilities**: "Show navigation, settings, and the Feature, Menu, Advanced, Status and Library kits."
2. The bar opens along the bottom of the window. The first button now reads **Close** (**Hide page utilities**).
3. Select a launcher. The bar closes and that kit or panel opens.

To close the bar without choosing, select **Close**, press `Esc`, or click anywhere else on the page. Closing the bar does not close a kit you already opened; an open kit's launcher stays visible so you can close the kit from it.

## On a phone

On screens up to about 580 pixels wide the bar fills the width of the screen in two rows: the five kits, a thin line, then **Navigate**, **Settings** and **Close**. The page leaves room at its end so the bar does not cover the last lines of content.

On a phone, the navigation dock has no button of its own on the screen; **Navigate** in this bar is the way to open it.

## Things to know

- The bar is hidden while the screen saver, an eye rest or the mobile drawer is showing. In reading mode the kit launchers are hidden.
- Each kit also has a keyboard shortcut (for example `Ctrl` + `Shift` + `L` for the Library Kit). See [Keyboard shortcuts](../../keyboard-shortcuts/README.md).
