# The desktop header

On windows 960 pixels wide or more, the header shows everything in one row: the brand, three menus, the quick-tools icons and **Sign in**.

## The brand

**Auric Artisan** with the tagline **Colour intelligence studio**. Select it to return to the homepage.

### How the menus behave

- A menu opens below its button, or above it if there is not enough room below. It lines up with the right edge of its button, or the left edge near the side of the window.
- A tall menu scrolls inside itself. A **SCROLL DOWN** hint shows while there is more to see.
- Selecting an entry opens that page. Clicking anywhere outside the menu, or moving keyboard focus out of it, closes it.

### With the keyboard

| Keys | What they do |
|---|---|
| `Tab` to a menu button, then `Enter` or `Space` | Open or close that menu |
| `Down` on a menu button | Open the menu and move to its first entry |
| `Up` on a menu button | Open the menu and move to its last entry |
| `Down` / `Up` inside a menu | Next or previous entry, wrapping round |
| `Home` / `End` inside a menu | First or last entry |
| `Esc` | Close the menu and return focus to its button |

## The quick-tools row

To the right of the menus is a row of icon buttons. Hover or focus one to see its tooltip.

| Icon | Tooltip | What it does |
|---|---|---|
| Grid with a plus | **Browser PWA** | Opens the Download page to install the site as an app (see [Download and offline](../../../download-and-offline/README.md)) |
| Puzzle piece | **Browser Extension** | Opens the browser extension page |
| Code brackets | **VS Code Extensions** | Opens the VS Code extensions page |
| Magnifier | **Search** | Opens Spotlight search (`Ctrl` + `K`) |
| Question mark | **Guide** | Opens the page guide (`?`) |
| Book and bookmark | **Library** | Opens your saved palettes, gradients, presets and exports |
| Globe | **Language / भाषा** | Switches the site between English and Hindi |
| Sun or moon | **Theme** | Switches between light and dark mode |

The theme button shows a moon while the page is light (select it to go dark) and a sun while the page is dark. Its behaviour is explained in [Theme](../../theme/README.md). The globe is explained in [Language](../../language/README.md).

## Sign in

**Sign in** opens the sign-in page, where you can also create a free account. Once you are signed in, the button is replaced by your account menu. Accounts are covered in [Account and billing](../../../account-and-billing/README.md).

## When the header scrolls

The header stays pinned to the top of the window as you scroll. In reading mode it scrolls away with the page, to leave more room for text.
