# Right-click menu release notes

| When | Change |
|---|---|
| September 2026 | The menu was rebuilt around what you clicked: a header naming the page, link, image, selection or colour; a quick bar of pinnable actions (up to six); groups that open submenus; a filter that searches every action; and preferences for layout, row height and whether a right-click opens this menu or the browser's. |

Earlier site releases are listed in the public changelog at https://auricartisan.com/library/changelog/. The v0.9.10 entry (27 July 2026) refers to a custom right-click menu in the browser extension, which is a separate product.
