# Right-click menu glossary

| Term | Meaning |
|---|---|
| Context | The thing you right-clicked: a page, link, image, selection or colour. |
| Context menu | A menu that opens on right-click and offers actions for what is under the pointer. |
| Quick bar | The row of one-click buttons at the top of the menu. Holds up to six pinned actions. |
| Pin | To add an action to the quick bar with the star on its row. |
| Group | A set of related actions (Page, Colour tools, View, Site) shown as one row that opens a submenu. |
| Submenu | The small panel that opens beside a group row, listing that group's actions. |
| Filter | The field that narrows the menu to actions whose names match what you type. |
| Focused layout | The default layout: your context's actions, then one row per group. |
| Everything layout | A layout that lists every group's actions in full, with no submenus. |
| Markdown link | Text written as `[label](address)`, which many editors turn into a link. |
| HEX, RGB, HSL | Common ways of writing a colour: a hex code, red-green-blue values, or hue-saturation-lightness. |
| OKLCH | A way of writing colour as lightness, chroma and hue that follows human perception closely. |
| Alt text | The text alternative of an image, read by screen readers and shown when the image cannot load. |
| Share sheet | Your device's own panel for sending a link to an app or contact. |
