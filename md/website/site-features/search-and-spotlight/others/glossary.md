# Spotlight glossary

| Term | Meaning |
|---|---|
| Spotlight | The floating search box opened with `Ctrl` + `K`. |
| Scope | The part of the site a search covers: All, Pages, Tools, Docs, Learn or Web. |
| Launcher | A shortcut row shown when the search box is empty. |
| Index | The list of the site's pages and their words that Spotlight searches. |
| Preview pane | The panel beside the results showing details of the highlighted result or a colour answer. |
| Field filter | A prefix such as `title:` that limits a search to one part of each page. |
| Exclusion | A word with a minus sign in front, such as `-gradient`, which removes matching pages. |
| Command mode | The mode entered by typing `>`, which lists actions instead of pages. |
| Contrast ratio | The WCAG measure of lightness difference between two colours, from 1:1 to 21:1. |
| AA, AAA | WCAG contrast levels: AA body text needs 4.5:1, AAA needs 7:1, AA large text needs 3:1. |
| OKLCH | A way of writing a colour as lightness, chroma and hue that follows human perception closely. |
