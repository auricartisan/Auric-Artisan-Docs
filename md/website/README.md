# The website

https://auricartisan.com is the home of Auric Artisan. Its tools, libraries and learning material work in any modern browser, most of them without an account. You can install the site as an app and prepare it to work offline, and a set of site-wide features — a settings panel, a right-click menu, search, themes, English and Hindi, and comfort options such as eye-rest reminders — follow you from page to page.

## Where to start

1. Open https://auricartisan.com and choose **Tools** in the header, or read the [tools catalogue](tools/README.md) to pick one by task.
2. Most tools work straight away with no account. Your settings and saved items are kept in your browser.
3. Open the settings panel to choose your theme, language and comfort options — see [Site features](site-features/README.md).
4. Create an account when you want to sync, publish a portfolio or use the API — see [Account and billing](account-and-billing/README.md).
