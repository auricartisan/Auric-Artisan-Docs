# Advertise glossary

| Term | Meaning |
| --- | --- |
| Ad Library | The public list of every ad that runs on Auric Artisan. |
| ads.txt | A public file that declares who may sell a site's ad space. |
| AdsSense | Auric Artisan's own advertising system. |
| Auto-tagging | Adding UTM parameters to the click address automatically. |
| Booking request | A campaign sent from the builder. It books and charges nothing until confirmed and paid. |
| Call to action | The button text on an ad, such as "LEARN MORE". |
| Campaign | One ad in one format and zone, for one flight. |
| Creative | The ad itself: the artwork people see. |
| CTR (click-through rate) | Clicks divided by impressions. |
| Destination URL | The page a click on the ad opens. |
| Display link | The short form of the destination shown with the ad. |
| eff. CPM | Effective cost per thousand impressions: the price divided by estimated impressions, times 1,000. |
| Final URL | The destination with tracking parameters added. |
| Flight | The period a campaign runs, from its start date. |
| Flight report | The report of delivered impressions, viewable impressions, clicks and effective CPM at the end of a campaign. |
| Format | The shape of an ad: Leaderboard, Medium Rectangle, Native In-Feed Card, or Panels & Search Strip. |
| Frequency cap | The most times one visitor can see your ad in a browsing session. |
| House ad | An ad for Auric Artisan's own products, marked "(house)" in the Ad Library. |
| Impression | One showing of an ad. |
| Macro | A placeholder in the click address, such as `{zone}`, filled in each time the ad is shown. |
| MRC-viewable | Counted as seen: at least 50% of the ad visible for one second. |
| Share of voice | The fraction of eligible ad renders in a zone reserved for your campaign. |
| Sponsored | The label every ad on Auric Artisan carries. |
| Takeover | A 100% share of voice. |
| UTM parameters | Standard tags such as `utm_source` that analytics tools use to attribute visits. |
| Zone | The part of the site a campaign runs on, such as the Homepage or Run of site. |
