# Browser extension documentation

This folder explains how to install the Auric Artisan browser extension and use every part of it: the popup and side panel, each tool in the Colour, Check, Code and Saved spaces, the features that work on websites, and every setting. Start with [Getting started](getting-started.md) if you are new, or go straight to the tool you need.
