# Settings

Settings is a two-pane view inside the popup, side panel or separate window: the section names on the left and the controls on the right.

## Open and close it

- Choose **Settings** (the sliders button) in the header, or
- search for a setting by name and choose it: Settings opens at that section with the control focused.

A plain open always starts at **Appearance**. Move between sections with the arrow keys, `Home` and `End`. "Saved as you change them": every change is stored the moment you make it, and open tabs pick up changes without a reload. Press `Esc` or choose **Back to the tools** to close Settings.

## Sections

| Section | What it holds | Page |
|---|---|---|
| **Appearance** | Theme, accent colour, popup size, language | [Appearance](appearance.md) |
| **Pickers** | The website pickers: master switch, designed controls, 13 types, Never on list | [Pickers](pickers.md) |
| **Right-click** | The custom menu, stepping aside, browser menu items, quick bar, layout, row height, sites, permissions | [Right-click](right-click.md) |
| **Tools** | Copy format, colour names, APCA, history, sound, deep audit, automatic outlines | [Tools](tools.md) |
| **Data** | Storage use, backup and restore, copy and paste settings, clearing and resetting | [Data](data.md) |
| **Shortcuts** | The keyboard map, changing shortcuts in the browser, replaying the tour | [Shortcuts](shortcuts.md) |
