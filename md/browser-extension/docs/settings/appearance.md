# Appearance settings

Settings › **Appearance** controls how the extension looks, in the popup and side panel and in everything it draws on websites.

## Theme

- **System**: Follows your operating system's light or dark mode, and changes when it does. On websites, the pickers and panels match the page they are on.
- **Light**: Always light
- **Dark** (the default): Always dark

The **Switch between light and dark** button in the header flips between Light and Dark.

## Accent

The accent colour tints buttons, focus rings, the website pickers, the right-click menu and the inspector, and sets the starting colour of several tools. Text on the accent turns black or white, whichever reads better.

Twelve presets:

| Preset | Colour |
|---|---|
| Auric gold (the default) | `#d3af37` |
| Champagne | `#d6b56d` |
| Bronze | `#b99355` |
| Copper | `#c57a32` |
| Rose | `#bd707b` |
| Pink | `#e45183` |
| Ruby | `#a3002d` |
| Jade | `#48ae8b` |
| Sapphire | `#3768b3` |
| Amethyst | `#9666ce` |
| Platinum | `#b8bdc6` |
| Graphite | `#9aa0ac` |

For any other colour, use **Custom**: pick with the swatch, which previews while you drag and saves when you let go, or type a six-digit hex value. The heading shows the preset's name, or "Custom" and the hex value.

## Popup size

| Choice | Size |
|---|---|
| **Compact** | 460 × 520 |
| **Standard** (the default) | 560 × 600 |
| **Large** | 760 × 600 |

At Compact, the header hides its tagline and the **Open in its own window** button. The side panel and separate window ignore this setting and fill their space.

## Language

**English** (the default) or **हिन्दी** (Hindi). Each option is written in its own language. Switching changes the popup, the side panel, the website pickers, the right-click menu, the inspector and the accessibility findings; open tabs follow without a reload. Switching back to English reloads the popup. See [Hindi interface](../hindi-interface.md).
