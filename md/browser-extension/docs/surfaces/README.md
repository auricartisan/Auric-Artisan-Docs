# Surfaces

The extension shows one workspace in several places. The popup opens from the toolbar icon. The side panel (the sidebar in Firefox) holds the same workspace beside the page and stays open while you browse. A separate window holds it too. On the page itself, the extension draws only what you ask for: the element inspector, vision filters, audit outlines, and, if you turn them on, website pickers and a right-click menu.
