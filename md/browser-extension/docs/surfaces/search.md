# Search

The search field in the header finds every tool, many settings, a few actions and pages on auricartisan.com. It is the quickest way to reach a tool whose space you do not remember.

## Use it

1. Press `/` or `Ctrl` + `K`, or click the field.
2. Type. Every word you type must match; words can match the name, the description or hidden keywords (for example "right click", "backup" or "colour blind").
3. Use `Up` and `Down` to move through the results, or hover them.
4. Press `Enter`, or click a result, to run it.
5. Press `Esc` to clear the search.

A Hindi interface can be searched in Hindi or English. The Language setting can also be found with "भाषा".

## How results are ordered

Results are grouped under headings:

| Group | What it holds |
|---|---|
| **Best match** | A result whose title is exactly what you typed, so typing "Settings" and pressing `Enter` opens Settings |
| **Tools** | The extension's tools; each result shows its space on the right |
| **Settings** | Individual settings; choosing one opens Settings at that section and focuses the control |
| **Actions** | Settings and **Open in a Window** |
| **On the web** | Pages on auricartisan.com, opened in a new tab |

Within a group, titles that start with your text come first. If nothing matches, the list says so.

## What you can find

### Tools

Colour Picker, Inspect Element, Page Audit, All Findings, Page Palette, Image Colours, Design Tokens, Contrast Checker, Harmony Builder, Scale Generator, Gradient Builder, Colour Mixer, Colour Converter, Vision Simulator, History, Library, Snippets and Open on the Web.

### Settings

Theme, Accent colour, Popup size, Language, Pickers on websites, Sites without pickers, Custom right-click menu, Browser right-click items, Colour history, APCA score, Copy format, Deep page audit, Backup & restore, Reset all settings and Keyboard shortcuts.

### On the web

Full Search, Collections, URL Analyzer, Tools, Color Science Lab, Accessibility Library, Documentation, API Reference and Learning Library.
