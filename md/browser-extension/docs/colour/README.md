# Colour tools

The **Colour** space holds everything for picking, reading and building colours. Its chips are Picker, Page palette, Image, Gradient and Mix. Three deeper tools, Harmony, Scale and Convert, open from links inside the Picker (and from search), and each has a **Picker** back button.

Most tools show a **Recent** strip of your latest colours; choose a swatch to load it into that tool.

## Files in this folder

| Page | What it covers |

| [Picker](picker.md) | Sample from the screen, read twelve formats, and use Specs, Harmony, Scale, Contrast, Vision and Code |
