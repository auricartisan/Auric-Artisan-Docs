# Harmony

Harmony (the Harmony builder) finds colours that go with a base colour, using the standard colour-wheel schemes. Open it from the Picker's Harmony pane (**Open the full harmony builder →**) or search for "Harmony".

## Use it

1. Set the base colour with its swatch or type a HEX value.
2. Choose a scheme (Triadic is the default).
3. Drag on the wheel to change the base colour's hue and saturation; its lightness stays the same.

The wheel marks each colour in the harmony and draws lines between them. A strip below shows the colours.

## Schemes

| Scheme | What it gives |
|---|---|
| **Complementary** | The base and the colour opposite it |
| **Split complement** | The base and the two neighbours of its opposite |
| **Analogous** | The base and its neighbours on the wheel |
| **Triadic** | Three colours evenly spaced around the wheel |
| **Tetradic** | Four colours forming a rectangle on the wheel |
| **Square** | Four colours evenly spaced |
| **Monochromatic** | Variations of the base hue |
| **Double split** | Split complements on both sides |
| **Compound** | A mix of analogous and complementary colours |

## Buttons

| Button | What it does |
|---|---|
| **Copy** | Copies the colours as a comma-separated HEX list |
| **Send** | Loads the colours into Page palette, where every export is available |
| **Save** | Saves them to Saved › Library as a palette labelled with the scheme |

**Picker** at the top returns to the Picker.
