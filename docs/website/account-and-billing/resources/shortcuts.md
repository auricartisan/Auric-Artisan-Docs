# Keyboard shortcuts

The account pages can be used entirely from the keyboard. These are the keys with special behaviour; everything else follows normal browser conventions (`Tab` to move, `Enter` or `Space` to press).

## Sign-in page

| Keys | Where | What it does |
| --- | --- | --- |
| `Left` / `Right` or `Up` / `Down` | **Sign In** and **Create Account** tabs | Switch tab |
| `Home` / `End` | The tabs | First or last tab |
| `Enter` | Any form field | Submits the form |

## Dashboard

| Keys | Where | What it does |
| --- | --- | --- |
| `Left` / `Right` | Section rail | Move to the previous or next section |
| `Home` / `End` | Section rail | Jump to **Overview** or **Security & Privacy** |
| `Enter` or `Space` | **Profile photo** strip in Profile | Choose a photo file |
| `Esc` | Photo viewer | Closes it |
| `Esc` | **Your account is nearly there** panel | Dismisses it for a week |

## Dialogs

| Keys | Where | What it does |
| --- | --- | --- |
| `Esc` | Upgrade dialog | Closes it |
| `Tab` / `Shift` + `Tab` | Upgrade dialog | Cycle through its buttons without leaving it |

## Site-wide keys you may use here

| Keys | What it does |
| --- | --- |
| `Ctrl` + `K` | Opens search |
| `?` | Opens the guide (when you are not typing in a field) |
| `Ctrl` + `,` | Opens or closes Settings |

The full list is in [Keyboard shortcuts](../../site-features/keyboard-shortcuts/README.md) in Site features.
