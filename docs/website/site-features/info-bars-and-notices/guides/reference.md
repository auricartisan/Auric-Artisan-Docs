# Info bars and notices reference

## Items and switches

| Item | Settings › Highlights switch | Default | Hide from the page |
|---|---|---|---|
| Welcome bar | **Welcome bar** | Homepage only | ✕ or right-click › **Hide bar** |
| Announcement bar | **Announcement bar** | Homepage only | ✕ or right-click › **Hide bar** |
| Quick-links bar | **Quick links bar** | Homepage only; also Collections | ✕ or right-click › **Hide bar** |
| Clock strip | **Clock strip** | Off | Switch off in Settings |
| Hero notice | **Hero notice** | On | ✕ |
| Demo chips | **Live demo chips** | On | ✕ on any chip (hides all) |

## Bar behaviour

| Behaviour | Value |
|---|---|
| Message rotation (welcome, announcement) | Every 6 seconds, cross-fade |
| Pause | While the pointer is over the bar, and while the tab is hidden |
| Reduced motion | Messages swap without fading |
| Quick-links bar | Continuous scrolling row of cards |
| Order under the header | Announcement bar, then clock strip, then page content |

## Bar menu (right-click)

| Heading | Buttons |
|---|---|
| Welcome messages / Site announcements / Site tools | **Open**, **Copy link**, **Hide bar**, **Settings** |

## Clock settings menu (right-click the clock strip)

| Control | Options | Default |
|---|---|---|
| **Format** | 12h, 24h | 12h |
| **Date** | Long, D/M/Y, M/D/Y, ISO | Long |
| **Show** › **Seconds** | On, off | On |
| **Show** › **Weekday** | On, off | On |
| **Show** › **Zone** | On, off | On |
| **Time zone** | Auto-detect, or any zone | Auto-detect |
| **Reset** | Restores all of the above | — |
| **All settings →** | Opens Settings › Clock | — |

## First-visit welcome

| Item | Value |
|---|---|
| Shown | Once per browser |
| Length | About 1.1 seconds; about 0.65 seconds with reduced motion |
| Skip | Click, `Esc`, `Enter` or `Space` |
