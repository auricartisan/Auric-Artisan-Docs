# Commands

Type `>` at the start of the Spotlight box to switch to **command mode**. The chip reads **Command**, and the list shows actions you can run on this page instead of pages you can open.

## Run a command

1. Press `Ctrl` + `K` and type `>`.
2. The list shows every command available on this page, under the heading **Commands**. The footer counts them, for example "7 commands".
3. Keep typing to narrow the list, for example `>theme`.
4. Select a command, or highlight it and press `Enter`.

If nothing matches, the list reads "No command matches that on this page."

## The site's commands

| Command | Description | Shows |
|---|---|---|
| **Toggle light and dark** | The header's theme button | The current theme, and `⌥T` |
| **Open the page guide** | What this page is, and its tour | — |
| **Open the library** | Saved palettes, gradients and reports | — |
| **Open settings** | Theme, motion, density, language | `⌘,` |
| **Switch language** | English ⇄ हिन्दी | The current language |
| **Open the full search page** | The whole index, with filters and instant answers | — |
| **Install the app** | Offline cache and an app window | — |

A command appears only when the page has the control it drives. For example, **Open the library** is missing on a page without the library button.

The key hints are shown in Mac notation: `⌥T` is `Alt` + `T`, and `⌘,` is `Ctrl` + `,` on Windows and Linux.

## Commands a page adds

Some tools add their own commands, listed first under their own headings. For example, the Portfolio Builder uses Spotlight as its toolbar and adds commands for its sections, typefaces and publishing. These appear only on that tool's page. See the tool's own documentation for its commands.

## Commands in Hindi

When the site is in Hindi, commands are shown in Hindi, and you can type either the Hindi or the English name to find them.
