# Right-click menu shortcuts

## Opening and switching menus

| Keys | Action |
|---|---|
| Right-click | Open the site menu (or the browser's, if you made it the default) |
| `Shift` + right-click | Open the other menu: the browser's by default |
| Menu key or `Shift` + `F10` | Same as a right-click |

## Inside the menu

| Keys | Action |
|---|---|
| Type any letter | Filter the actions |
| `Up` / `Down` | Move between rows |
| `Right` | Open a group's submenu, or move to a row's pin star |
| `Left` | Leave a pin star, or close a submenu |
| `Enter` / `Space` | Run the focused action |
| `Esc` | Close a submenu, clear the filter, or close the menu, in that order |

## Site-wide shortcuts the menu offers

These work anywhere on the site, with or without the menu open.

| Keys | Action |
|---|---|
| `Ctrl` + `Shift` + `C` | Open the colour tools menu. If you have selected a hex code, it is loaded. |
| `Ctrl` + `Shift` + `U` | Check for and apply a website update |
| `Ctrl` + `Shift` + `D` | Open or close split view |
| `Ctrl` + `K` | Open Spotlight search |
| `Alt` + `R` | Reading mode on or off |

The full list for the site is in [Keyboard shortcuts](../../keyboard-shortcuts/README.md).
