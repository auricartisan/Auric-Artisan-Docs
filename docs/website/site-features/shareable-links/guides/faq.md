# Shareable links FAQ

## Is the `#p=` part sent to Auric Artisan?

No. Browsers do not send the part of an address after `#` to the website. It is read by the page in the browser that opens it.

## Is it encrypted?

No. It is the page's state written compactly. Anyone who has the link can read what it contains.

## Can I turn it off?

There is no switch for it. It only affects the address; it does not store anything elsewhere. Share a clean link if you prefer.

## Does it work offline?

Yes, for pages that are saved on your device: reloading restores the state without a connection.

## Does it include what I saved in my library?

No. It includes what is on the page, not your saved library items.
