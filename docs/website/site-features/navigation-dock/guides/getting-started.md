# Get started with the navigation dock

## Open the dock

When a page loads on a computer, the dock shows fully for a moment and then tucks itself away into a thin gold line at the edge of the window. To bring it back:

- point at the line; or
- click it; or
- move keyboard focus into it with `Tab`.

It tucks away again about half a second after your pointer leaves, unless the page outline is open or a button in the dock has keyboard focus.

On a phone, open the page utilities bar at the bottom-left and select **Navigate**.

## The buttons

From top to bottom (left to right on a phone):

| Button | What it does |
|---|---|
| Grip (six dots) | Drag to move the dock. Tooltip: "Drag to move". Not shown on phones. |
| **Back** | Goes back one page. Greyed out when there is nothing to go back to. |
| **Forward** | Goes forward one page. Greyed out when there is nothing ahead. |
| **Reload** | Reloads the page. |
| **Page outline** | Opens the **On this page** list of headings. |
| **Open split view** | Opens split view with this page (see [Split view](../../split-view/README.md)). |
| **Record screen (Alt+Shift+R)** | Opens the screen recorder (see [Screen recorder](../../screen-recorder/README.md)). |
| **Copy link** | Copies the page's address. The icon briefly becomes a tick. |
| **Share** | Opens your device's share sheet; without one, copies the link and shows a tick. |
| **Scroll to top** | Scrolls smoothly to the top. The ring around it shows how far down you are. |
| **Scroll to bottom** | Scrolls smoothly to the end of the page. |
| **Flip dock side** | Moves the dock to the other edge. Not shown on phones. |

Hover or focus a button to see its name in a tooltip.

> **Note:** **Copy link** and **Share** copy the address exactly as it is in the address bar, which can include the page's remembered state, such as your scroll position and the values you typed into a tool. See [Shareable links](../../shareable-links/README.md).

## Try it

1. Open a long page, such as https://auricartisan.com/company/about/.
2. Scroll halfway down. Point at the dock: the ring around **Scroll to top** is half full.
3. Select **Page outline**. The heading of the section you are reading is highlighted.
4. Select the first heading. The page scrolls up to it.
5. Select **Copy link** and paste the address somewhere. Opening it later returns you to the same place on the page.
