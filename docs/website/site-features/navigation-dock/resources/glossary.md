# Navigation dock glossary

| Term | Meaning |
|---|---|
| Dock | The floating rail of navigation buttons on the edge of the window. |
| Collapsed | The dock's resting state: a thin line at the edge (desktop) or a small round button (phone). |
| Grip | The six-dot handle at the top of the dock, used to drag it. |
| Page outline | The **On this page** panel listing the page's headings. |
| Progress ring | The ring around **Scroll to top** that fills as you scroll down the page. |
| Share sheet | Your device's own panel for sending a link to another app or person. |
| Page state | Details the site keeps in the address after `#p=`, such as your scroll position. |
