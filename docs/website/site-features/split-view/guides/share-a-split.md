# Share a split

While split view is open, the browser's address bar keeps a description of the split after `#split=`. It records:

- the live pane's page and the companion pane's page, including where each is scrolled and what you entered on them;
- side-by-side or stacked layout;
- the divider position;
- each pane's theme, viewport and zoom;
- whether the panes are swapped.

## Share or bookmark a split

1. Set up split view the way you want it.
2. Copy the address from your browser's address bar (or bookmark it).
3. Open the address later, or send it to someone.

Result: the page opens straight into split view, with both panes, the layout and the pane settings restored.

## Things to know

- The address updates as you work, including as you scroll either pane.
- Pane names you typed are not part of the address.
- Closing split view removes the split details from the address.
- **Copy URL** in a pane's More menu copies only that pane's page, without the split.
- A shared split contains the addresses of both pages and the values entered on them. Check it before sending it to someone.
