# Get started with split view

## Open split view

| How | What opens |
|---|---|
| `Ctrl` + `Shift` + `D` | Live pane: this page. Companion: your last companion page, or the homepage |
| Navigation dock › **Open split view** | The same |
| Right-click › **View** › **Split view** | The same |
| `Alt` + click a link to another site page | Live pane: this page. Companion: the page the link points to |

The first time, split view takes a moment to load. The live pane opens scrolled to where you were on the page.

## The screen

Split view covers the whole window:

- **Toolbar** across the top, in three groups:
  - the live pane's controls (its tab, **Back**, **Forward**, **Reload**, address bar and **More** menu);
  - the companion pane's controls (the same set);
  - the global controls: the performance chip, **Toggle layout**, **Swap panes**, **Compare**, **Mirror**, **Route links**, **Scroll sync**, **Equal split** and **Close**.
- **Two panes** below it, with a **divider** between them that you can drag.

On windows narrower than about 900 pixels, the toolbar wraps: each pane's controls take a full row.

Your original page stays behind split view and keeps running; nothing on it is changed.

## Close split view

- Press `Esc` (if a pane's More menu is open, the first `Esc` closes the menu; if you are editing an address bar, the first `Esc` puts back the address).
- Or select **Close** at the right end of the toolbar.
- Or press `Ctrl` + `Shift` + `D` again.

When split view closes:

- if the live pane is still on the page you started from, you return to that page, scrolled to where the live pane was;
- if you moved the live pane to another page, the browser goes to that page.
