# Panes and their controls

Each pane has the same row of controls in the toolbar.

## The pane tab

The tab at the start of each row names the pane: by default the page's own title (for example "Basic Tools"). A dot shows its state: amber and pulsing while the page loads, green when it is ready.

**Rename a pane:** double-click its tab, type a name and press `Enter` (or click elsewhere). Press `Esc` to cancel. An empty name returns to the page title. Your name stays on the pane while you browse in it, until you close split view.

## Back, Forward and Reload

Each pane has its own history. **Back** and **Forward** move through the pages that pane has shown; **Reload** reloads just that pane.

## The address bar

Each pane has an address bar showing its page's address on the site, for example `/library/palette/`.

To load another page:

1. Select the address bar. A list of destinations opens, grouped under **Home**, **Tools**, **Libraries**, **Account**, **Company**, **Legal** and your **Recent** pages.
2. Type to narrow the list: page names, addresses and keywords all match (for example `oklch` finds the Colour Science Lab).
3. Use `Up` and `Down` to choose and `Enter` to load, or click an entry.

You can also type an address that is not in the list: a site path such as `/tool/icon/` (the list offers **Go to** that path) or a full `https://` address (**Open external URL**). Press `Ctrl` + `Enter` to open the typed address in a new browser tab instead. Press `Esc` to close the list, and again to put back the current address.

Loading a new page in the **live** pane means closing split view will take you to that page. The companion's address bar tooltip reads "Edit the companion pane's URL and press Enter to load it."

Pages you load are added to **Recent** (up to 10 site pages), and split view uses your most recent companion page the next time it opens.

## The More menu

Select the three dots (**More pane controls**) at the end of a pane's row:

| Control | What it does |
|---|---|
| **Theme** | Cycles **Auto**, **Light** and **Dark** for this pane only. Light and dark apply instantly. |
| **Viewport** | Cycles **desktop** (full pane width), **tablet** (820 pixels) and **phone** (400 pixels). The page inside reflows to that width. |
| **Zoom** | Cycles **100%**, **125%**, **150%** and **75%** for this pane. |
| **Focus this pane** | Moves keyboard focus into the pane and outlines it (`Alt` + `1` for live, `Alt` + `2` for companion). Select again to clear. |
| **Maximize** | Gives this pane the whole area. Select again to restore. |
| **Open in new tab** | Opens this pane's page in a new browser tab. |
| **Copy URL** | Copies this pane's page address, without the split details. |

Controls that differ from their default (a forced theme, a device width, a zoom other than 100%) are highlighted. The menu stays open while you cycle theme or zoom; click elsewhere or press `Esc` to close it.

Your own site theme setting is not changed by a pane's theme. When you switch a pane back to **Auto**, it reloads to follow your site theme again.

## Keyboard inside a pane

Keyboard shortcuts pressed inside a pane (such as `Esc`, `Alt` + `S` or `Ctrl` + `Shift` + `D`) still reach split view.
