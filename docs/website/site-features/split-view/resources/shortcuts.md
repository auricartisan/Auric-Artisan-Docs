# Split view shortcuts

| Keys | Action |
|---|---|
| `Ctrl` + `Shift` + `D` | Open or close split view |
| `Esc` | Close an open More menu; otherwise close split view |
| `Alt` + `1` | Focus the live pane |
| `Alt` + `2` | Focus the companion pane |
| `Alt` + `V` | Side by side or stacked |
| `Alt` + `S` | Swap panes |
| `Alt` + `E` | Equal split |
| `Alt` + click on a link | Open the link in the other pane; with split view closed, open split view with it |
| `Enter` in an address bar | Load the address or highlighted destination |
| `Ctrl` + `Enter` in an address bar | Open the typed address in a new browser tab |
| `Esc` in an address bar | Close the destination list, then restore the address |
