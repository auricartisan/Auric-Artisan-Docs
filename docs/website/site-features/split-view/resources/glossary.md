# Split view glossary

| Term | Meaning |
|---|---|
| Live pane | The pane that starts with the page you were on. Closing split view follows it. |
| Companion pane | The second pane, for any other page. |
| Divider | The bar between the panes that you drag to resize them. |
| Viewport | The width a pane's page is laid out for: desktop, tablet (820 px) or phone (400 px). |
| Responsive | A page that rearranges itself to fit the width it is given. |
| Compare mode | An overlay of both panes in which identical areas turn black and differences show. |
| Route links | A mode in which links clicked in the live pane open in the companion. |
| Scroll sync | Scrolling one pane scrolls the other to the same relative position. |
| Eco mode | Automatic low-performance mode that turns off decorative effects when the panes run slowly. |
| FPS | Frames per second: how smoothly the screen is updating. |
