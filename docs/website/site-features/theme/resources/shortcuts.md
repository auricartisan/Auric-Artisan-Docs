# Theme shortcuts

| Keys | Action |
|---|---|
| `Alt` + `T` | Cycle Light, Dark, System |
| `Ctrl` + `,` | Open Settings, where **Theme** is in Appearance |
| `Ctrl` + `K`, then `>` | Spotlight commands, including **Toggle light and dark** |

`Alt` + `T` does nothing while you are typing in a field. The full list is in [Keyboard shortcuts](../../keyboard-shortcuts/README.md).
