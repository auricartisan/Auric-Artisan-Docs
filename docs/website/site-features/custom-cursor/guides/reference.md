# Custom cursor reference

## Shapes

| Shape | Looks like | Appears over |
|---|---|---|
| Default | Round ring with a dot | Ordinary page areas |
| Pointer | Larger ring with a soft glow | Links, buttons and other clickable items |
| Text | Tall, narrow I-beam | Text and text fields |
| Grab | Rounded square | Things you can drag |
| Grabbing | Smaller rounded square | While dragging |
| Precision | Small ring | Sliders and vector graphics such as charts and diagrams |
| Canvas | Small dashed, spinning ring | Drawing and graphics areas in tools |
| Resize | Double-headed arrow, turned to the direction | Resize handles and split-view dividers (left-right, up-down or diagonal) |
| Move | Four-way arrow | Things you can move in any direction |
| Zoom in / Zoom out | Plus or minus in the ring | Images and areas you can zoom |
| Help | Question mark in the ring | Abbreviations and help items |
| Copy | Small plus at the ring's corner | Items that copy when clicked |
| Crosshair | Hairline cross in a tight ring | Pickers and crosshair areas |
| Not allowed | Red ring with a slash | Actions that are not allowed |
| Disabled | Faint, grey ring | Disabled controls |
| Loading | Dashed, spinning ring | While the page or a tool is busy |

## Effects

| Effect | When |
|---|---|
| Magnetic glow | Over clickable items and draggable items |
| Shrink | On click |
| Stretch | During fast movement |
| Fade to half | When idle, or when the pointer leaves the window |
| Adaptive colour | Always: the ring takes the hue of the surface under it, lightened or darkened to stand out |
| Accent colour | Over grey and neutral surfaces |
| Dark or light dot | Chosen from the brightness of the surface under it |

## Setting

| Control | Values | Default |
|---|---|---|
| Settings › Comfort › **Custom cursor** | On, off | On |
