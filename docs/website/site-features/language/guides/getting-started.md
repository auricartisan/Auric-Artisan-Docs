# Get started with languages

## Switch to Hindi

Use any one of these:

- **Header:** select the globe button. Its tooltip reads **Language / भाषा** with the description in both languages.
- **Settings:** press `Ctrl` + `,`, and under **Appearance** › **Language** (भाषा — interface and articles) select **हिन्दी**.
- **Drawer (narrow screens):** open the menu, and under **Preferences** › **Language** tap **हिन्दी**.
- **Spotlight:** press `Ctrl` + `K`, type `>`, and choose **Switch language** (English ⇄ हिन्दी).

What happens:

1. The site downloads the Hindi text for the page you are on. On a first switch this can take a moment on a slow connection.
2. The page is translated where it stands. You stay at the same place on the page and nothing you typed is lost.
3. Text that appears later, such as a kit you open or a tool's results, is translated as it appears.
4. Every page you open afterwards loads in Hindi.

## Switch back to English

Use the same controls: the globe, **English** in Settings or the drawer, or **Switch language** in Spotlight.

The page **reloads** in English. Translation changes the page's text in place, so a reload is how the site returns to the original English. If you were typing into a form, finish or copy your text first.

## Share a link that opens in Hindi

Add `?lang=hi` to the end of any page address, for example:

```text
https://auricartisan.com/tool/vision-simulation/?lang=hi
```

Anyone who opens the link sees the page in Hindi, and their browser remembers Hindi for later visits. `?lang=en` does the same for English.

If the address already has a `?`, add `&lang=hi` instead.

## Language buttons are always readable

The language buttons show each language in its own script, **English** and **हिन्दी**, and are never translated. You can find your language even if you cannot read the one on screen.
