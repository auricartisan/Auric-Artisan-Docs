# Language glossary

| Term | Meaning |
|---|---|
| Devanagari | The script used to write Hindi (हिन्दी). |
| Transliteration | Writing a name in another script by its sound, not its meaning, such as ऑरिक आर्टिज़न for Auric Artisan. |
| Translation in place | Replacing the text of a page that is already open, without loading it again. |
| Locale | The language and region conventions used to write dates, times and numbers, such as Hindi (India). |
| Query parameter | A part of a web address after `?`, such as `?lang=hi`, that passes a setting to the page. |
