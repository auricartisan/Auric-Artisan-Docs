# Header and navigation glossary

| Term | Meaning |
|---|---|
| Header | The strip at the top of every page with the brand, menus, quick tools and sign-in. |
| Menu (header) | The Company, Tools or Learn list that opens below its button. |
| Quick tools | The row of icon buttons in the header: app, extension, VS Code, search, guide, library, language, theme. |
| Drawer | The sliding sheet that holds the header's contents on narrow screens. |
| Breakpoint | A window width at which the layout changes. The header's is 960 pixels. |
| Group chip | A button in the drawer's Tools section that shows one group of tools at a time. |
| Page utilities bar | The launcher bar at the bottom-left for the kits, the navigation dock and Settings. |
| Kit | A floating panel of extra tools, such as the Feature Kit or Library Kit. |
| Navigation dock | The slim floating rail with Back, Forward, Reload, outline and scroll controls. |
| Footer | The section at the end of every page with directory links, contact details and social links. |
| PWA | Progressive web app: a website you can install and run like an app, with offline support. |
