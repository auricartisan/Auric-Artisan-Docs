## Quick tools (wide screens)

| Button | Tooltip title | Tooltip description | Action |
|---|---|---|---|
| Get the app | Browser PWA | Use Auric Artisan in a browser tab with offline cache. | Opens `/download/` |
| Browser extension | Browser Extension | Download the Auric Artisan toolbar extension package. | Opens `/extension.html` |
| VS Code extensions | VS Code Extensions | Auric icon collections and colour themes for Visual Studio Code. | Opens `/vscode/` |
| Search | Search | Open site search. Shortcut: Ctrl+K. | Opens Spotlight |
| Open guide | Guide | Search pages, tools, and quick paths, or start a guided tour. Shortcut: ? | Opens the guide |
| Open library | Library | Open your saved palettes, gradients, presets and exports. | Opens the library panel |
| Language | Language / भाषा | Switch the site between English and Hindi. | Toggles English and Hindi |
| Theme | Theme | Switch between light and dark mode. | Toggles light and dark |
| Sign in | Sign in | Sign in or create your free Auric Artisan account to save and sync your work. | Opens `/auth/` |

## Mobile drawer (narrow screens)

| Area | Control | Action |
|---|---|---|
| Bar | **Search** | Opens Spotlight |
| Bar | Menu button (**Open navigation** / **Close navigation**) | Opens or closes the drawer |
| Drawer | **Search tools, colours and pages** | Opens Spotlight |
| Browse | **Company**, **Tools**, **Learn** (with counts) | Open in place |
| Browse › Tools | Group chips with counts | Show one group's tools |
| Your work | **Library** — Saved palettes and exports | Opens the library panel |
| Your work | **Guide** — Tours and shortcuts | Opens the guide |
| Get Auric | **The app** — Works offline in a browser tab | Opens `/download/` |
| Get Auric | **Browser extension** — The Auric toolbar in your browser | Opens `/extension.html` |
| Get Auric | **VS Code** — Icon collections and colour themes | Opens `/vscode/` |
| Preferences | **Theme**: **Auto**, **Light**, **Dark** | Sets the theme mode |
| Preferences | **Language**: **English**, **हिन्दी** | Sets the language |
| Foot | **Sign in**, **Create account** | Open `/auth/` and `/auth/#register` |

Breakpoints: the drawer replaces the desktop header below 960 pixels; it is a 400-pixel side sheet from 600 to 959 pixels, and a full-width sheet below 600 pixels.
