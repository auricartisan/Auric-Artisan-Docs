# Settings panel release notes

The site's changelog at https://auricartisan.com/library/changelog/ records releases. Entries that concern the settings controls:

| Date | Release | Change |
|---|---|---|
| 2026-06-05 | v0.9.9 | Added user settings controls, alongside guide content, PWA app support and the UX Kit. |
| 2026-05-02 | v0.9.8 | Added complexity management, which lets you control how many advanced tools the site shows (through the Advanced Kit). |

The panel as documented here (seven sections, saved colours, the accent contrast readout, the Custom cursor switch, the Highlights section and the panel's right-click menu) reflects the site as of September 2026. Later changes appear in the changelog.
