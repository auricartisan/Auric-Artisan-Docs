# Keyboard shortcut reference

"Ctrl or Cmd" means `Ctrl` on Windows, Linux and ChromeOS, and `Cmd` on a Mac. On a Mac, `Alt` is the `Option` key.

## Anywhere on the site

| Keys | Action | Notes |
|---|---|---|
| `Ctrl` + `K` (Ctrl or Cmd) | Open or close Spotlight search | [Search and Spotlight](../../search-and-spotlight/README.md) |
| `Ctrl` + `,` (Ctrl or Cmd) | Open or close Settings | [Settings panel](../../settings-panel/README.md) |
| `?` | Open the page guide | [Guide and page outline](../../guide-and-page-outline/README.md) |
| `Alt` + `R` | Reading mode on or off | Not while typing |
| `Alt` + `T` | Theme: Light, Dark, System | Not while typing |
| `Alt` + `+` (or `Alt` + `=`) | Text one size larger | Not while typing |
| `Alt` + `-` | Text one size smaller | Not while typing |
| `Alt` + `0` | Default text size | Not while typing |
| `Alt` + `M` | Reduced motion on or off | Not while typing |
| `Ctrl` + `Shift` + `D` | Open or close split view | [Split view](../../split-view/README.md) |
| `Alt` + click a site link | Open split view with that page | — |
| `Alt` + `Shift` + `R` | Open the recorder; while recording, stop and save | [Screen recorder](../../screen-recorder/README.md) |
| `Alt` + `Shift` + `P` | Pause or resume a recording | — |
| `Ctrl` + `Shift` + `U` | Check for and apply a website update | [Kits](../../../kits/README.md) (Update Kit) |
| `Ctrl` + `Shift` + `C` | Open the colour tools menu (with a selected hex code, if any) | Uses `Shift`, so it is not the browser's copy |
| `Shift` + right-click | Your browser's right-click menu (or the site's, if you swapped them) | [Context menu](../../context-menu/README.md) |
| `Esc` | Close the open panel, menu, dialog or bar | — |

## Kits

| Keys | Action |
|---|---|
| `Ctrl` + `Shift` + `K` (Ctrl or Cmd) | Open or close the Feature Kit |
| `Ctrl` + `1` to `Ctrl` + `6` inside the Feature Kit | Calculator, Converter, Feedback, Notes, Date and time, Developer tools |
| `Ctrl` + `M` (Ctrl or Cmd) | Open the Menu Kit |
| `Ctrl` + `Shift` + `A` (Ctrl or Cmd) | Open or close the Advanced Kit |
| `Ctrl` + `Shift` + `L` (Ctrl or Cmd) | Open or close the Library Kit |
| `Ctrl` + `K` inside an open Menu Kit or Status Kit | Jump to the kit's own search field |
| `/` inside an open Menu Kit or Status Kit | Jump to the kit's own search field |
| `Esc` | Close the open kit |
| `Esc` | Close the page utilities bar |

Details are in [Kits](../../../kits/README.md).

## Header menus and drawer

| Keys | Action |
|---|---|
| `Enter` / `Space` on Company, Tools or Learn | Open or close the menu |
| `Down` / `Up` on a menu button | Open at the first or last entry |
| `Down` / `Up` / `Home` / `End` in a menu | Move between entries |
| `Esc` | Close the menu, then the drawer |
| First `Tab` on a page | Show **Skip to main content** |

## Spotlight

| Keys | Action |
|---|---|
| `Up` / `Down` | Move through results |
| `Enter` | Open or run |
| `Ctrl` + `Enter` (Ctrl or Cmd) | Open in a new tab |
| `Tab` / `Shift` + `Tab` | Next or previous scope |
| `>` first | Command mode |
| `Esc` | Clear, then close |

## Settings panel

| Keys | Action |
|---|---|
| `Left` / `Right` on the section list | Previous or next section |
| `Esc` | Close a drop-down, then the confirmation, then the panel |

## Right-click menu

| Keys | Action |
|---|---|
| Type | Filter actions |
| `Up` / `Down` | Move |
| `Right` | Open a submenu, or reach a row's pin star |
| `Left` | Leave the pin star, or close a submenu |
| `Enter` / `Space` | Run |
| `Esc` | Close submenu, clear filter, close menu |

## Guide and tours

| Keys | Action |
|---|---|
| `Up` / `Down` / `Home` / `End` | Move through the guide |
| `Enter` | Open the focused item or top match |
| `Left` / `Right` on a tab | Change tab |
| `Right` / `Left` in a tour | Next or previous stop |
| `Esc` | Close the guide or leave the tour |

## Split view

| Keys | Action |
|---|---|
| `Alt` + `1` / `Alt` + `2` | Focus the live or companion pane |
| `Alt` + `V` | Side by side or stacked |
| `Alt` + `S` | Swap panes |
| `Alt` + `E` | Equal split |
| `Enter` / `Ctrl` + `Enter` in an address bar | Load, or open in a new tab |
| `Esc` | Close a menu, restore an address, or close split view |

## Screen recorder

| Keys | Action |
|---|---|
| Arrow keys on the dialog grip | Move the dialog (`Shift` for finer steps) |
| `Esc` | Close the dialog, list, player or region picker |

## Other places

| Where | Keys | Action |
|---|---|---|
| Any tooltip | `Alt` | Expand its details (when Advanced tooltips is off) |
| Feedback panel | `1` to `5` | Set the star rating |
| First-visit welcome | `Esc`, `Enter`, `Space` | Skip it |
| Site date picker | Arrows, `Page Up` / `Page Down`, `Shift` + those, `Home` / `End`, `Enter` / `Space`, `Esc` | Day and week, month, year, week edges, choose, close |
| Navigation dock | `Tab` into it | Opens the collapsed dock |
