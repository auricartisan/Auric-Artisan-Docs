# Eye rest glossary

| Term | Meaning |
|---|---|
| Reminder interval | How long a page is open before a reminder appears: 20, 35, 45 or 60 minutes. |
| Rest | The few seconds (5 to 30) during which the screen dims and invites you to look away. |
| Reminder card | The small card that appears when the interval ends: "Time to look away". |
| Horizon | The line across the rest screen that shrinks to show how much of the rest is left. |
| Dawn | The brightening of the whole screen that marks the end of a rest. |
| Session | The life of a browser tab; **Not this session** lasts until the tab is closed. |
| 20-20-20 | A common screen habit: every 20 minutes, look about 20 feet away for about 20 seconds. |
