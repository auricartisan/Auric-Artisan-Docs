# Manage sections

A portfolio is a stack of **sections**, shown top to bottom in the order you set. Each section has a card in the **Content** column.

## Add a section

Any of these adds one:

- **Add a section** at the foot of the Content column: type in **Search sections…** to narrow the 25 types, then select a tile. Each tile shows the type's name and a short hint; hover for the hint. If nothing matches, it says **No sections match that search.** The builder confirms, for example, **Added a Timeline section.**
- In the preview, the add control at the end of the page, or **Add a section below** on a section's rail (see [Edit in the preview](edit-in-the-preview.md)).
- The command field: type "add" and choose, for example, **Add a Gallery section**.

New sections start empty; grey example text (placeholders) shows what goes where, and disappears as you type. With no sections yet, the column says **No sections yet — add one below to start building.**

## The section card

| Control | What it does |
| --- | --- |
| Drag handle (⠿) | Drag to reorder ("Drag to reorder"). |
| Chevron (▾) | Expand or collapse the card's fields. |
| Type icon and name | Which kind of section it is. |
| **Hidden** badge | Shown when the section is hidden from the portfolio. |
| Eye button | **Hide from portfolio** / **Show in portfolio**. Hidden sections stay in your draft but are left out of the page, exports and publishing. |
| ↑ / ↓ | **Move up** / **Move down**. |
| **More actions** (⋯) | **Move to top**, **Move to bottom**, **Duplicate**, **Delete**. |

Messages confirm actions, such as **Section duplicated.** and **Section removed — Ctrl+Z to undo.**

## Bulk actions

Above the cards, a bar shows the section count, **Collapse all** (or **Expand all**) and **Bulk actions ▾**:

| Action | Effect | Message |
| --- | --- | --- |
| **Expand all** | Opens every card. | **All sections expanded.** |
| **Collapse all** | Closes every card. | **All sections collapsed.** |
| **Show all sections** | Un-hides every section. | **All sections shown in the portfolio.** |
| **Hide all sections** | Hides every section. | **All sections hidden from the portfolio.** |
| **Reverse order** | Flips the order. | **Section order reversed.** |
| **Clear all sections** | Deletes every section. | **All sections cleared — Ctrl+Z to undo.** |

Every bulk action can be undone.

## Tips

- Hide a section instead of deleting it when you might want it back later.
- A page where every section is hidden cannot be meaningfully published; the publish dialog warns **Every section is hidden — the page would be empty**.
- The section count in the top bar and in the preview bar counts all sections, hidden or not.

## Result

Your sections are in the order you want, with the ones you are not ready to show hidden.
