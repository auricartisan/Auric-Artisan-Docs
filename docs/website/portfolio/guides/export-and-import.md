# Export and import

Select **Export** in the top bar to open the menu. Each item is also a command in the command field.

| Menu item | What you get | Message |
| --- | --- | --- |
| **Download HTML** | A single, self-contained `.html` file of the finished page, including its styles and the live palette swatches. Open it in any browser or host it anywhere. | **HTML downloaded.** |
| **Download PDF** | Opens the page in a new tab and your browser's print dialog; choose **Save as PDF** (or your browser's equivalent) there. | — |
| **Export JSON** | The portfolio document as a `.json` file: header, sections and style. Use it as a backup or to move the portfolio. | **Portfolio JSON exported.** |
| **Import JSON…** | Pick a `.json` file exported from the builder. It replaces your current portfolio (undoable). | **Portfolio imported.** or **That file is not a valid portfolio export.** |
| **Copy snapshot link** | A link that contains the whole portfolio. | **Public link copied** |

File names are based on your name.

## The credit line

At the foot of the menu, the switch **"Made with Auric Artisan" credit** — "On every exported HTML and PDF. Paid plans can drop it." — adds a small "Made with Auric Artisan" line at the end of exported files.

- On a paid plan that includes watermark-free exports, you can switch it off.
- On a free plan, switching it off explains that watermark-free exports are a paid perk; the portfolio, the editor and every export stay free. See [Account and billing](../../account-and-billing/README.md).

The switch affects downloads only, not your published page.

## Printing and PDF

The PDF comes from your browser's print function. The page is set to print its colours and background exactly; if your browser still drops backgrounds, turn on its "Background graphics" option. If nothing opens, the builder says **Allow pop-ups to print.**

## Snapshot links

A snapshot link carries the entire portfolio inside the address itself (after `#`). Opening it shows the page at https://auricartisan.com/portfolio/public/ without any account.

- It is a copy taken at that moment: later edits do not change it.
- It works without a published address, and keeps working offline once opened.
- Portfolios with several embedded images make very long links, which some apps and sites will not accept. A large avatar is left out of snapshot links.
- Nothing is stored on the site.

See [The published page](the-published-page.md) for what a visitor sees.

## Result

You have your portfolio as a file you can host or print, a JSON backup you can restore, or a link that works anywhere.
