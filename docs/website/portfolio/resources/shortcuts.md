# Portfolio shortcuts

## Builder

| Keys or action | Effect |
| --- | --- |
| `Ctrl` + `K` or the command field | Opens the list of builder commands; type, then `Enter`. |
| `Enter` | Finishes a one-line field you are typing in the preview. |
| `Escape` | Finishes editing in the preview; closes the templates dialog, the section picker, full-screen preview and the publish dialog. |
| `Enter` in the section picker's search | Adds the first matching section type. |
| Double-click the avatar | Choose a picture. |
| Drag a card's handle (⠿) | Reorder sections. |

The Undo and Redo buttons show `Ctrl` + `Z` and `Ctrl` + `Shift` + `Z` in their tooltips; if the keys do not respond, use the buttons or the **Undo** and **Redo** commands.

## Published portfolio

| Keys or action | Effect |
| --- | --- |
| Right-click | **Copy link to this portfolio**, **Save this portfolio as PDF**, **Email** the owner, **Reading mode**, **Make your own portfolio**. |
| `Alt` + `R` | Reading mode. |

## Portfolio Index

| Keys | Effect |
| --- | --- |
| `/` | Focus the search box. |
| `Escape` | Clear the search box, or close an open filter menu. |
