# HDR Gamut Plot shortcuts

These keys work when the focus is not in a text box, slider or list. The Lab tab's rail lists them as "1-4 cycle curves" and "A toggle axes".

| Key | What it does |
| --- | --- |
| `1` | Tone curve: Gamma 2.2 (SDR) |
| `2` | Tone curve: Gamma 2.4 (BT.1886, zero black) |
| `3` | Tone curve: PQ (ST.2084) |
| `4` | Tone curve: HLG (BT.2100) |
| `A` | Switches the chromaticity axes between CIE 1931 xy and CIE 1976 u′v′ |
| `Esc` | Closes a full-screen chart; clears the Reference filter |

| Mouse | What it does |
| --- | --- |
| Move over the diagram | Updates the hover readout |
| Double-click a chart | Opens it full screen |
