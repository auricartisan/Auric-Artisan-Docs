# Perception and Vision shortcuts

The tool has no keyboard shortcuts of its own beyond these. Site-wide shortcuts are described in [Site features](../../../../site-features/README.md).

| Action | Where | Result |
|---|---|---|
| Press or drag | The frame, with **Compare** set to **Split** | Moves the divider to the pointer |
| Double-click | The frame | Opens the frame enlarged, filling the window |
| `Esc` | Enlarged view | Closes it |
| Select the **×** button or the dark area around the image | Enlarged view | Closes it |
| `Enter` or `Space` | A focused row on the **Data** tab | Expands or collapses the row |
| `Tab` | Anywhere | Moves between controls; sliders then respond to the arrow keys |
