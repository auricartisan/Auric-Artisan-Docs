# Visual Pathway shortcuts

The tool has no keyboard shortcuts of its own beyond these. Site-wide shortcuts, such as the search palette, are described in [Site features](../../../../site-features/README.md).

| Action | Where | Result |
|---|---|---|
| Double-click | **Stimulus** or map canvas on the Lab tab | Opens the canvas enlarged, filling the window |
| `Esc` | Enlarged view | Closes it |
| Select the **×** button or the dark area around the image | Enlarged view | Closes it |
| `Enter` or `Space` | A focused row on the **Data** tab | Expands or collapses the row |
| `Tab` | Anywhere | Moves between controls; sliders then respond to the arrow keys |
| Drag a file | **Drop a CSV or JSON** on the Data tab | Installs a cone table |
