# Visual Pathway glossary

| Term | Meaning |
|---|---|
| Alias | A false, coarser pattern that appears when a screen is asked to draw stripes finer than its pixels can carry |
| Carrier | What a grating varies: colour at constant L + M (**Chromatic**) or lightness in grey (**Luminance**) |
| Centre-surround | A receptive field that compares a small central region with a larger surrounding one |
| Colourmap | The ramp of colours used to draw a map's values, here Viridis, Inferno or Grayscale |
| Complex-cell energy | The combined response of two filters a quarter-cycle apart; it responds to stripes regardless of their exact position |
| Cone signals (L, M, S) | The responses of the long-, medium- and short-wavelength-sensitive cones to a colour |
| Cone table | A table of cone spectral sensitivities by wavelength; the page's built-in one is its own, and you can install another |
| Cycles per degree (c/deg) | How many light-dark cycles of a pattern fall within one degree of visual angle |
| Degrees per pixel | The angle one screen pixel covers at your viewing distance: atan(pixel pitch ÷ distance) |
| Deuteranopia | Colour vision without M cones |
| Dichromacy | Colour vision with only two of the three cone types working |
| Difference of Gaussians (DoG) | A centre blur minus a weighted surround blur, the standard model of a retinal centre-surround cell |
| Divisive normalisation | Dividing a response by the local average response, so each part of a map is read relative to its neighbourhood |
| DKL space | The Derrington–Krauskopf–Lennie opponent space, built on cone contrast against an adapting white; the tool's axes are not DKL |
| Gabor filter | A sine-wave stripe pattern inside a Gaussian envelope, the standard model of a V1 simple cell |
| Hunt-Pointer-Estévez matrix | A published 3 × 3 matrix that converts CIE XYZ to cone signals, scaled so D65 white gives equal L, M and S |
| Hypercolumn map | A map of the preferred orientation at each point, drawn here as a colour wheel |
| LGN | The lateral geniculate nucleus, the relay between retina and cortex where colour is carried in opponent channels |
| Luminance (relative) | The lightness-related quantity Y of CIE XYZ, from 0 for black to 1 for white; the retina and V1 stages read it |
| Nyquist limit | The finest frequency a sampled grid can carry: half a cycle per pixel, converted here to c/deg |
| Opponent channel | A signal formed by comparing cone signals, such as L − M (red against green) |
| Pixel pitch | The physical width of one screen pixel, in millimetres |
| Protanopia | Colour vision without L cones |
| RMS contrast | The root-mean-square spread of luminance values across an image |
| Scale bar | The bar under the map giving the minimum and maximum the colours stand for |
| Spatial frequency | How finely a pattern repeats across space, here in cycles per degree |
| sRGB | The standard colour space of web content, with a defined transfer curve and primaries (IEC 61966-2-1) |
| Stand-in | A register status: values chosen by the tool to be plausible, not taken from a publication |
| Tritanopia | Colour vision without S cones |
| V1, V2, V4 | Areas of visual cortex: V1 analyses orientation and spatial frequency, V2 boundaries and texture, V4 colour and form |
| Verbatim, Computed, Absent | Register statuses: taken unchanged from a source; derived from verbatim data by stated arithmetic; not held |
| Viewing distance | The distance from your eyes to the screen |
