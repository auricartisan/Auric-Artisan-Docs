# Dye in Solution glossary

| Term | Meaning |
|---|---|
| Absorbance (A) | −log₁₀ of the fraction of light transmitted; A = 1 lets 10% through |
| Acid form (HA) | The protonated form of a dye, holding an extra hydrogen ion |
| Base form (A⁻) | The deprotonated form of a dye |
| Base fraction (f) | The share of a dye in its base form at a given pH, from Henderson–Hasselbalch |
| Beer–Lambert law | A = ε × c × l: absorbance is proportional to molar absorptivity, concentration and path length |
| CIE 1931 2° observer | The standard set of colour-matching functions describing average human colour vision for small fields |
| CIE L\*a\*b\* | A colour space with lightness L\* and opponent axes a\* (red–green) and b\* (yellow–blue) |
| CIEDE2000 (ΔE₀₀) | The CIE's recommended formula for how different two colours look |
| Colour inconstancy | How far one sample's colour changes between two lights |
| Complementary wavelength | For purples, the wavelength on the opposite side of the white point, given instead of a dominant wavelength |
| Concentration (c) | Amount of dye per volume; shown in micromoles per litre (µM) |
| Dominant wavelength | The spectral colour that, mixed with the light's white, matches the sample |
| Excitation purity | How far a colour lies from the white point towards the spectral edge, as a percentage |
| Gaussian band | A bell-shaped absorption curve; the tool draws preset bands this way |
| GHS | The Globally Harmonized System for classifying and labelling chemical hazards, per substance |
| Henderson–Hasselbalch | The relation f = 1 ÷ (1 + 10^(pKa − pH)) between pH, pKa and the base fraction |
| Illuminant | A standard light defined by its spectral power: D65, D50 (daylights), A (tungsten), E (equal energy) |
| Isosbestic point | The wavelength where both forms of a dye absorb equally, so absorbance there does not change with pH |
| Kubelka–Munk | A model of colour in opaque, light-scattering layers such as dyed cloth; not offered in the current interface |
| λmax | The wavelength at which a band absorbs most |
| Metamerism | Two samples with different spectra that match under one light but not under another |
| Molar absorptivity (ε) | How strongly one mole of dye absorbs at a wavelength, in M⁻¹ cm⁻¹ |
| Path length (l) | The distance light travels through the solution, in cm |
| pKa | The pH at which half of a dye is in each form |
| Safety data sheet (SDS) | The supplier's document for a substance, giving its hazards (section 2) and controls (section 8) |
| sRGB | The standard colour space of screens and the web |
| Transmittance (T) | The fraction of light at a wavelength that passes through the solution |
| UV–Vis spectrum | A measurement of absorbance across ultraviolet and visible wavelengths |
