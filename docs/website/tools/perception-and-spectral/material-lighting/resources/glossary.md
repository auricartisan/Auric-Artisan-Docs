# Material Under Light glossary

| Term | Meaning |
|---|---|
| Azimuth | The angle between the light and the eye measured around the surface normal (**Between them**) |
| Blackbody (Planckian radiator) | An ideal hot object whose light depends only on its temperature, given by Planck's law |
| BRDF (lobe) | A model of how a surface spreads reflected light over directions |
| CIE 1931 2° observer | The standard colour-matching functions describing average human colour vision |
| CIE L\*a\*b\* | A colour space with lightness L\* and opponent axes a\* (red–green) and b\* (yellow–blue) |
| CIEDE2000 (ΔE₀₀) | The CIE's recommended formula for how different two colours look |
| Conductor | A metal; its colour comes entirely from specular reflection tinted by its reflectance |
| Correlated colour temperature (CCT) | The temperature of the blackbody whose colour is closest to a light's, in kelvin |
| CRI (colour rendering index) | A CIE score of how faithfully a light renders a set of test colours; withdrawn from this tool |
| D-series daylight (D50, D55, D65, D75) | CIE standard daylights reconstructed from a published basis, named for their temperature |
| Dielectric | A non-metal; a faint colourless highlight plus coloured diffuse reflection |
| Diffuse reflection | Light that enters a material, scatters and leaves in many directions, carrying the material's colour |
| Exposure normalisation | Scaling so a perfect white diffuser in the same light and geometry reads Y = 1 |
| F0 | The reflectance of a surface seen straight on, set here by the refractive index |
| Illuminant A | The CIE standard for incandescent light: a blackbody at 2856 K |
| Illuminant E | A theoretical light with equal power at every wavelength |
| JzAzBz (Jz) | A colour space for high-dynamic-range signals; Jz is its lightness |
| McCamy's formula | A published approximation for computing CCT from chromaticity |
| Metamerism | Two materials with different spectra matching under one light but not under another |
| Microfacet model | A lobe that treats a surface as tiny mirror facets with a spread of tilts |
| Reference illuminant | The light a source is compared with: a blackbody below 5000 K, a CIE daylight at or above |
| Reflectance spectrum | The fraction of light a material reflects at each wavelength, from 0 to 1 |
| Refractive index (n) | How strongly a material bends light; sets a dielectric's F0 |
| Rendering shift | The ΔE₀₀ of one material between a source and its reference light |
| Roughness | How spread out a surface's reflection is; low is glossy, high is matte |
| Specular reflection | Mirror-like reflection from the surface itself |
| Spectral power distribution (SPD) | A light's power at each wavelength |
| sRGB | The standard colour space of screens and the web |
| TM-30 (Rf, Rg) | An IES method scoring colour fidelity (Rf) and gamut (Rg); withdrawn from this tool |
| Un-adapted swatch | A colour shown as the light actually leaving the surface, without compensating for the light's colour |
