# Glossary

Terms are in alphabetical order.

| Term | Meaning |
| --- | --- |
| Achromatopsia | Complete absence of colour vision; everything appears in shades of grey. |
| ACEScg | A linear, wide-gamut RGB space used in film and visual-effects rendering. |
| Adobe RGB (1998) | A wider-gamut RGB space used in photography and print workflows, especially for greens and cyans. |
| APCA | Accessible Perceptual Contrast Algorithm, a contrast method proposed for WCAG 3 that accounts for which colour is text and which is background. |
| APCA Lc | APCA's lightness-contrast value, from about −108 to +106; its size, together with font size and weight, predicts readability. |
| Analogous | A harmony of hues next to each other on the colour wheel, typically about 30° apart. |
| Black point | The darkest colour a printing process can actually produce, which is never a pure black. |
| CCT | Correlated colour temperature, in kelvin; an estimate of how warm or cool a light-like colour appears. |
| Chroma | How colourful a colour is compared with a grey of the same lightness. |
| Chromaticity | The colour quality of a light apart from its brightness, usually given as CIE x and y. |
| CIE 1931 chromaticity diagram | A horseshoe-shaped chart of all colours people can see, used to compare gamuts. |
| CIELAB (Lab) | A CIE colour space with lightness (L) and two opponent axes (a green–red, b blue–yellow), designed for measuring colour difference. |
| CIELuv | A CIE perceptual space often used for lights and displays. |
| CMYK | The four process inks of printing: cyan, magenta, yellow and black (key). |
| Colour harmony | A set of hues chosen by their positions on the colour wheel, such as complementary or triadic. |
| Colour space | A system of numbers for describing colours, such as sRGB, Lab or OKLCH. |
| Colour stop | A colour fixed at a position along a gradient. |
| Complementary | Two hues opposite each other on the colour wheel. |
| Contrast ratio | The WCAG 2.x measure of luminance difference between two colours, from 1:1 to 21:1. |
| CVD | Colour-vision deficiency, often called colour blindness. |
| D50, D65 | Standard white points: D65 is average daylight (used by sRGB and screens); D50 is used in print and for CSS lab() and lch(). |
| Deuteranopia | A red–green colour-vision deficiency caused by missing green-sensitive cones; the most common type. |
| Display P3 | A wide-gamut RGB space used by many modern phones and monitors. |
| Dock | Where a minimised panel is kept, out of view, until you restore it. |
| Dot gain | The darkening of mid-tones in print as ink spreads into the paper. |
| Easing | How the pace of a blend changes along a gradient, such as ease in or ease out. |
| ΔE (delta E) | A number for how different two colours look. ΔE 76 is the simple Lab distance; ΔE2000 (CIEDE2000) is the more accurate modern formula. |
| Focused panel | The panel you selected last; it sits in front and receives keyboard shortcuts and Save to Library. |
| Gamut | The range of colours a colour space, screen or printer can reproduce. |
| Gamut clipping | Replacing a colour that is outside a gamut with the nearest colour inside it. |
| HEX code | A six-digit (or three-digit) hexadecimal way of writing an sRGB colour, such as #D3AF37. |
| HSL, HSV, HWB | Cylindrical versions of RGB: hue with saturation and lightness, saturation and value, or whiteness and blackness. |
| Hue | The attribute that makes a colour red, yellow, green, blue and so on, given as an angle from 0° to 360°. |
| Interpolation | Calculating the colours between two stops; the colour space used changes how the middle looks. |
| JzAzBz | A perceptual colour space designed to work for high dynamic range as well as normal images. |
| k-means | A clustering method used to find the main colours of an image by grouping similar pixels. |
| Level (Basic, Advanced, Both) | The Catalogue filter that shows simpler tools, advanced tools, or all of them. |
| Linear RGB | RGB with the gamma curve removed, so the numbers are proportional to light energy. |
| Luminance (relative) | How bright a colour is on a 0 (black) to 1 (white) scale, used by WCAG contrast. |
| Metamerism | When two colours match under one light and differ under another. |
| Monochromatic | A set of colours with one hue and different lightness. |
| Named colour system | A catalogue of colours with names or codes, such as Pantone, RAL, NCS or the CSS named colours. |
| OKLab, OKLCH | A modern perceptual colour space (and its lightness, chroma, hue form) where equal steps look roughly equal; supported in CSS. |
| Panel | A movable, resizable window inside the page that holds one tool. |
| Protanopia | A red–green colour-vision deficiency caused by missing red-sensitive cones; reds also look darker. |
| Rec.2020 | A very wide-gamut RGB space defined for ultra-high-definition and HDR video. |
| Role palette | A palette where each colour has a job, such as canvas, ink, primary or focus, chosen so pairs meet a contrast target. |
| Saturation | How intense a colour is relative to its brightness, in HSL or HSV terms. |
| Soft-proofing | Previewing on screen how a design is likely to look when printed. |
| sRGB | The standard RGB colour space of the web and most screens. |
| Stage | The surface in the Workspace view where panels open. |
| TAC | Total area coverage: the maximum combined percentage of CMYK inks a press allows. |
| Tetradic, square | Four hues spaced around the colour wheel; in these tools both use four hues 90° apart. |
| Triadic | Three hues 120° apart on the colour wheel. |
| Tritanopia | A rare blue–yellow colour-vision deficiency caused by missing blue-sensitive cones. |
| WCAG | Web Content Accessibility Guidelines. Their contrast levels: AA needs 4.5:1 for normal text and 3:1 for large text and interface parts; AAA needs 7:1 for normal text. |
| XYZ, xyY | CIE tristimulus values that other colour spaces are built on, and the chromaticity-plus-luminance form of them. |
| YCbCr, YUV, YIQ | Luma and colour-difference encodings used in video and broadcast. |
