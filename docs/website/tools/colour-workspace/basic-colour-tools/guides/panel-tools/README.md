# Panel tools

These are the seven tools you open from the Basic Color Tools workspace. Each opens as a floating panel with a controls sidebar and a main area. The level column shows whether the tool appears under **Basic** or **Advanced** in the Catalogue's level switch.

| Guide | Category | Level | In one line |
| --- | --- | --- | --- |
| [palette-studio.md](palette-studio.md) | Generate | Basic | Live palette generator with harmony, WCAG and accessibility modes, locking, OKLCH editing, image extraction and eight exports. |
| [palette-remix.md](palette-remix.md) | Generate | Advanced | Turns seed colours into four styled variant palettes; copy CSS, JSON or all HEX codes. |
| [gradient-maker.md](gradient-maker.md) | Generate | Basic | Linear, radial and conic gradients with any number of stops, perceptual interpolation, easing and CSS, SVG, PNG, JSON and Tailwind export. |
| [colour-picker.md](colour-picker.md) | Pick | Basic | One colour in eight formats, with harmonies, colour-vision previews, chromaticity and contrast notes. |
| [colour-battle.md](colour-battle.md) | Pick | Advanced | Scores two palettes against each other for contrast, separation and colour-vision resilience. |
| [collage-maker.md](collage-maker.md) | Compose | Advanced | Arranges your images in one of 29 layouts and exports a 4K PNG. |
| [quick-converter.md](quick-converter.md) | Convert | Basic | Converts one colour into fourteen notations and compares two colours. |

For how panels open, move and close, see [Workspace and panels](../workspace-and-panels.md). Every control is also listed in the [Reference](../reference.md).
