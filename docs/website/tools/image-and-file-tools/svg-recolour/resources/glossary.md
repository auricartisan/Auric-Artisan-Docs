# SVG Recolour glossary

| Term | Meaning |
|---|---|
| Active content | Parts of an SVG that run code: scripts, event handlers and `javascript:` links |
| APCA | Advanced Perceptual Contrast Algorithm; lightness contrast in Lc units, signed by polarity |
| CIEDE2000 (ΔE₀₀) | The CIE's standard formula for how different two colours look |
| Closest pair | The two colours in the file with the smallest CIEDE2000 difference |
| Contrast ratio | The WCAG 2 measure of luminance difference, from 1:1 to 21:1 |
| CSS colour name | One of the 148 named colours of CSS, such as `red` or `rebeccapurple` |
| `currentColor` | A value that takes the colour from the page the SVG is placed in |
| Custom property | A CSS variable, such as `--colour-01`, holding a colour |
| Dichromacy | Colour vision with one of the three cone types missing |
| Harmony | A set of colours at fixed angles round the colour wheel |
| Left alone | A value with no colour the tool can change, listed but not written |
| OKLCH | A perceptual colour space of lightness, chroma and hue, used for the harmonies |
| Occurrence | One place in the file where a colour value is written |
| Paint property | A property that sets colour, such as `fill` or `stroke` |
| Presentation attribute | An SVG attribute that sets a style directly, such as `fill="#E5484D"` |
| Protanopia, deuteranopia, tritanopia | Colour vision missing the long (red), medium (green) or short (blue) wavelength cones |
| Source form | The way a colour was written: hex, shorthand, `rgb()`, `hsl()` or a name |
| Style attribute | An SVG `style="…"` attribute holding CSS declarations |
| Style sheet | CSS inside a `<style>` element in the SVG |
| SVG | Scalable Vector Graphics: an XML format for drawings |
| Target | The colour an original colour will become |
| WCAG | The Web Content Accessibility Guidelines; version 2.2 defines the contrast ratio used here |
| Well-formed | XML that follows the syntax rules, so it can be parsed |
| Written | An occurrence the tool actually rewrote |
