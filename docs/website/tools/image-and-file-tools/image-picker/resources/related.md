# Related tools and reading

## Tools on the site

| Tool | Why you might use it with the Image Picker |
|---|---|
| [Contrast Checker](../../../accessibility-and-vision/contrast-checker/README.md) | Test the exact text and background pair you chose from the palette |
| [Vision Simulation](../../../accessibility-and-vision/vision-simulation/README.md) | See how the picture and palette look with different kinds of colour vision |
| [M-Gradient Palette](../../m-gradient-palette/README.md) | Build an evenly stepped ramp between two colours taken from the picture |
| [SVG Recolour](../../svg-recolour/README.md) | Apply colours from the palette to SVG artwork |
| [Collage Maker](../../collage-maker/README.md) | Combine several pictures into one before extracting a palette from all of them |
| [Basic Tools](../../../colour-workspace/basic-colour-tools/README.md) | Quick palette, gradient and conversion utilities |

## The public API

The same job is available as a REST call, `POST /v1/palette/from-image`, documented at https://auricartisan.com/library/documentation/api/#ep-post-palette-from-image. See [Public API](../../../../../services/public-api/README.md) for keys, credits and limits.
