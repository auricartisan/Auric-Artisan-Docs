# Image and file tools

These six tools work on files you already have: photographs, SVG artwork, colour profiles and colour lookup tables. Each one reads your file in the browser, shows you what is in it, lets you change or measure it, and gives you a file or a report to take away. Nothing you load is uploaded; the reading and the arithmetic happen on the page.

The tools share a layout. A row of tabs runs across the top of each tool. The first tab is the working area, and later tabs explain the method, list where every number comes from (the **Data** tab), offer the exports (the **Export** or **Actions** tab) and cite the published sources (the **Reference** tab). The Image Picker is the exception: it has three tabs, **Workbench**, **Analysis** and **Actions**.

## Where to find them

The group's own address is https://auricartisan.com/tool/general/tools/. Opening it takes you to the Collections page at https://auricartisan.com/collections/, which lists every tool on the site under **All tools**. Use the category filter or the **Sort** menu there, or open a tool directly from the table below. The Collections page is described in [Collections](../../library/collections/README.md).

## The tools

| Tool | Address | Use it to |
|---|---|---|
| [Collage Maker](collage-maker/README.md) | https://auricartisan.com/tool/general/tools/collage-maker/ | Place pictures on a canvas, arrange them, measure coverage and export PNG or JPEG |
| [ICC Profile Parser](icc-profile-parser/README.md) | https://auricartisan.com/tool/general/tools/icc-profile-parser/ | Read an .icc or .icm profile: header, tags, primaries, tone curves and conformance |
| [Image Picker](image-picker/README.md) | https://auricartisan.com/tool/general/tools/image-picker/ | Extract a palette from a picture, pin exact pixels and export the colours |
| [LUT Lab](lut-lab/README.md) | https://auricartisan.com/tool/general/tools/lut-lab/ | Apply a look or a .cube file, see what it moved, and write a .cube |
| [M-Gradient Palette](m-gradient-palette/README.md) | https://auricartisan.com/tool/general/tools/m-gradient-palette/ | Build a colour ramp in OKLCH, sRGB, linear RGB or HSL and check its steps and contrast |
| [SVG Recolour](svg-recolour/README.md) | https://auricartisan.com/tool/general/tools/svg-recolor/ | Remap every colour in an SVG, check contrast and colour vision, and export the file |

The page titles differ slightly from the names in the Collections list: Collage Maker opens as **Collage Studio**, the ICC Profile Parser as **ICC Profile Reading**, the Image Picker as **Image Color Picker & Palette Tool**, the M-Gradient Palette as **Gradient Ramp**, and SVG Recolor as **SVG Recolour**.

## Which tool for which job

- You have photographs and want one image made of several: use the [Collage Maker](collage-maker/README.md).
- You have a colour profile from a monitor, printer or camera and want to know what it says: use the [ICC Profile Parser](icc-profile-parser/README.md).
- You have a picture and want its colours as a palette: use the [Image Picker](image-picker/README.md).
- You have a .cube grading file, or want to make one: use the [LUT Lab](lut-lab/README.md).
- You want a smooth, evenly stepped colour scale between two colours: use the [M-Gradient Palette](m-gradient-palette/README.md).
- You have an icon or illustration as SVG and want it in different colours: use [SVG Recolour](svg-recolour/README.md).

All six tools are free to use, like every tool on the site.
