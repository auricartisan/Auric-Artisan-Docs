# Privacy

## Your profile stays in your browser

- The profile file is read by the page itself in your browser. The tool does not upload it or send it anywhere.
- Every figure, diagram and finding is worked out on your device.
- **Save the reading** and **Tag table, CSV** create their files in the browser and save them through your browser's normal download.
- **Copy it** writes the reading to your clipboard only when you select it.

## Nothing is kept after you leave

The tool does not store the profile or the reading. **Clear**, reloading, or leaving the page removes them.

## What a reading contains

A reading contains the profile's file name and size, its header values, its tag table, the tool's identification, gamut figures and findings. It does not contain the profile file itself. The file name appears in the reading, so check that it says nothing you would rather not share.

## The page itself

The ICC Profile Parser is a normal page on auricartisan.com. Site-wide features such as sign-in, preferences and any consent-based services follow the site's own privacy policy and your cookie choices; see [Help](../../../../../help/README.md).
