# Website tools

Auric Artisan's tools run in your browser at https://auricartisan.com. Most need no account: what you make is kept in your browser, and you can export it as files. Each tool below has its own folder of documentation with a quick start, task guides, a complete reference, troubleshooting and a glossary.

The tools fall into five groups. If you are not sure which one you need, start with [Which tool for which job](#which-tool-for-which-job).

## Accessibility and vision

Check colour contrast, audit whole websites, work through WCAG, and see colour the way people with different vision do. Group overview: [Accessibility and vision](accessibility-and-vision/README.md).

| Tool | Address | What it does |
| --- | --- | --- |
| [Analyzer](accessibility-and-vision/analyzer/README.md) | /tool/analyzer/ | Audits a website's colours, contrast and accessibility, and keeps the reports. |
| [Contrast Checker](accessibility-and-vision/contrast-checker/README.md) | /tool/contrast-checker/ | Grades a text and background pair with WCAG 2.x ratios and APCA. |
| [Accessibility Checklist](accessibility-and-vision/accessibility-checklist/README.md) | /resources/accessibility-checklist/ | 50 WCAG 2.2 checks with the law by jurisdiction and an inspector. |
| [Accessibility Compliance](accessibility-and-vision/accessibility-compliance/README.md) | /accessibility-compliance/ | Where this address takes you and what it offers. |
| [Vision Lab](accessibility-and-vision/vision-simulation/README.md) | /tool/vision-simulation/ | Shows a colour, palette or image through 78 vision conditions. |
| [Ishihara Plate Generator](accessibility-and-vision/ishihara-plate-generator/README.md) | /tool/ishihara-plate-generation/ | Makes, checks and exports Ishihara-style plates. |

## Which tool for which job

| You want to… | Use |
| --- | --- |
| Check that text is readable on its background | [Contrast Checker](accessibility-and-vision/contrast-checker/README.md) |
| Audit a whole website for colour and accessibility | [Analyzer](accessibility-and-vision/analyzer/README.md) |
| Work through WCAG 2.2 success criteria | [Accessibility Checklist](accessibility-and-vision/accessibility-checklist/README.md) |
| See your design as people with colour-vision deficiencies do | [Vision Lab](accessibility-and-vision/vision-simulation/README.md) |
| Build a palette, shades or a gradient quickly | [Basic Color Tools](colour-workspace/basic-colour-tools/README.md) |
| Generate a whole design system with tokens | [Design System Generator](colour-workspace/design-engine/README.md) |
| Take colours from a photograph | [Image Picker](image-and-file-tools/image-picker/README.md) |
| Make a perceptually even ramp | [M-Gradient Palette](image-and-file-tools/m-gradient-palette/README.md) or [Tonal Steps](colorimetry-and-rendering/tonal-steps/README.md) |
| Understand a colour profile file | [ICC Profile Parser](image-and-file-tools/icc-profile-parser/README.md) |
| Find a font or icon for a project | [Font Library](colour-workspace/font-library/README.md) or [Icon Library](colour-workspace/icon-library/README.md) |
| Learn how light and white points change colour | [Illuminants](colorimetry-and-rendering/illuminants/README.md) and [Chromatic Adaptation](colorimetry-and-rendering/chromatic-adaptation/README.md) |

The floating [kits](../kits/README.md) — a calculator, unit converter, notes and more — and the [colour libraries](../library/README.md) are documented in their own sections.
