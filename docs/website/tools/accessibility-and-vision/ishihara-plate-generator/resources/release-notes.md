# Ishihara Plate Generator release notes

Dated entries come from the public changelog at https://auricartisan.com/library/changelog/. The first section describes the page as it is now.

## Current page (September 2026)

- Four tabs: **Lab**, **Diagnostics**, **Set 38** and **Export**.
- **Diagnostics** shows each plate's quality score taken apart into its four components, with the ΔE through each simulated deficiency.
- **Set 38** builds the standard 38-plate set from seed 42 without touching the plates in the Lab.
- **Export** offers a ZIP of every plate, individual SVGs, and a seeds file.
- **×1**, **×3** and **×6** generate several plates at once; **Plate Size** offers S, M, L and XL.
- Each card has a per-plate **Normal**, **Protan**, **Deutan** and **Tritan** preview, and double-clicking opens a plate full size.

## v0.9.75 — 19 April 2026

- The Ishihara plate generator was added to the tools collection.
