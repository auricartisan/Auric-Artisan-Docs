# Accessibility and vision tools

This group covers the tools on auricartisan.com that help you make a design or a website usable by more people. Some of them measure a live page against the Web Content Accessibility Guidelines (WCAG), the W3C standard that most accessibility laws point at. Others show you how colour looks to people with colour-vision deficiencies or low vision, so you can catch problems that a number alone does not reveal.

The tools range from a one-question checker to a full audit console. Use the small tools when you already know what you are asking, and the Analyzer when you want to find the problems you do not know about yet.

Every tool here is free to use. A few actions that run on Auric Artisan's servers, such as rendering someone else's website or crawling a whole site, need an account and are metered in tokens. Each tool's own docs say exactly which actions those are.

## Which tool should I open?

- You have two colours and want a yes or no: open the [Contrast Checker](contrast-checker/README.md).
- You have a URL and want every problem on the page: open the [Analyzer](analyzer/README.md).
- You are preparing a manual audit or an accessibility statement: open the [Accessibility Checklist](accessibility-checklist/README.md).
- You want to see a palette or an image the way someone with a colour-vision deficiency sees it: open the [Vision Lab](vision-simulation/README.md).
- You are teaching how colour-vision tests work: open the [Ishihara Plate Generator](ishihara-plate-generator/README.md).

> **Important:** None of these tools gives a legal certification or a medical diagnosis. Automated testing finds real problems quickly, but a conformance claim needs manual review as well, and a vision simulation is an approximation, not an eye test.
