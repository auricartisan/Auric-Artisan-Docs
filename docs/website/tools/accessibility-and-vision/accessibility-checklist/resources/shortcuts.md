# Accessibility Checklist keyboard shortcuts

The single-letter keys work only while focus is inside the index (including its filter buttons and area headers) or the pane. They are ignored in text fields, when `Ctrl`, `Alt` or `Cmd` is held, and while the screenshot dialog is open.

## Moving between checks

| Keys | Where | Action |
| --- | --- | --- |
| `Down` / `Up` | On a row | Next or previous visible check; focus moves with it |
| `Home` / `End` | On a row | First or last visible check |
| `J` / `K` | Index or pane | Next or previous check. From the pane, focus stays and the new title is announced. |
| `E` | Index or pane | Open the check: the one-check view on a phone, the pane title on a wide screen |
| `Esc` | Pane | On a phone, back to the list; on a wide screen, back to the check's row |

## Marking

| Key | Action |
| --- | --- |
| `Space` | **Pass** (only on a row, the pane or the check title) |
| `F` | **Fail** |
| `N` | **N/A** |

Pressing the key for the current verdict again clears it.

## Tabs

| Keys | Action |
| --- | --- |
| `Left` / `Right` | Previous or next tab, wrapping round |
| `Home` / `End` | First or last tab |

## In the screenshot evidence dialog

| Keys | Action |
| --- | --- |
| `P` | Pen |
| `H` | Highlighter |
| `A` | Arrow |
| `B` | Box |
| `R` | Redact |
| `C` | Callout |
| `Ctrl` + `V` | Paste a screenshot |
| `Esc` | Close the dialog, like **Done** |

## Printing

`Ctrl` + `P` prints the same report as **Export the report**.

For shortcuts that work across the whole site, see [Keyboard shortcuts](../../../../site-features/keyboard-shortcuts/README.md).
