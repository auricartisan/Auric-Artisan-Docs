# Advanced Kit FAQ

## Does Basic mode lock the advanced tools?

No. It only hides them from the menus and collections. Every tool page opens from its address in every mode.

## Is the Advanced Kit a paid feature?

No. All modes are available to everyone, signed in or not.

## Which mode do new visitors get?

**Basic**, which the kit marks as **Recommended**.

## Is my mode saved to my account?

No. It is stored in your browser. Each browser and device keeps its own mode.

## Do my Custom ticks survive if I switch to another mode?

Yes. They apply again whenever you select **Custom**. **Reset** is the only thing that clears them.

## What does Everything bring back that Basic and Advanced do not?

Every tool, plus collection cards that were hidden earlier, whether you hid them or the collection hid them because you had not used them yet.

## Why does the calculator lose its Scientific keypad in Basic mode?

The Feature Kit calculator follows the mode: Basic shows only the Basic keypad. Choose **Everything** to see all three. The expression bar still accepts every function in any mode.

## What is the "UX Kit"?

The name the changelog uses for the part of the site that changes page wording when you switch mode. It has no panel; you control it from the Advanced Kit. See [What each mode changes](what-each-mode-changes.md).

## Does the mode affect the site-wide search?

No. The site-wide search shows results for every tool whatever the mode.
