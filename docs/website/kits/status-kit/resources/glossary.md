# Status Kit glossary

**Page status** — A label that says how finished a page is, such as **Beta** or **Stable**.

**Site status** — The status of the site as a whole, shown in the Menu Kit. Pages without their own status share it.

**Scan** — A listing of every page whose address starts with a given path, with each page's status.

**Path** — The part of an address after the domain, such as `/library/blog/`.

**Site map** — The site's published list of its pages, which the scanner reads.

**Issues** — Pages with the Alpha, Deprecated or Archived status.

**Target page** — In a scan, the page whose address matches your path exactly.

**Effective connection type** — The browser's classification of your connection speed, such as 4G.

**Round-trip time (latency)** — How long a message takes to reach a server and come back, in milliseconds.

**JS heap** — Memory used by the page's scripts.

**Device pixel ratio** — How many physical screen pixels make up one CSS pixel. 2× is typical of high-density screens.

**CSS pixel** — The unit web pages are laid out in. It may be several physical pixels.

**Colour gamut** — The range of colours a display can show. sRGB is the standard range; P3 is wider.

**Colour depth** — The number of bits used per pixel to store colour, such as 24-bit.

**Frame rate** — How many times per second the page is redrawn.

**Service worker** — A background script that lets the site work offline and load faster.

**Installed app** — The site opened as an app installed from the browser, rather than in a tab.
