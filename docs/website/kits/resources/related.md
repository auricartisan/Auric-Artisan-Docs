# Related to the kits

## Site features next to the kits

The page utilities bar also launches two site features that are not kits:

- **Navigate** opens the page navigation dock (back, forward, reload, outline, split view, jump to top or bottom).
- **Settings** opens the site settings panel (theme, accent colour, text size, motion, ads and more).

Both, along with the site-wide search (`Ctrl` + `K`), the right-click menu and the eye-rest reminder, are documented in [Site features](../../site-features/README.md).

## Tools that work with the kits

- Every tool with a **Save to Library** button saves into the [Library Kit](../library-kit/README.md).
- The [URL Analyzer](../../tools/accessibility-and-vision/analyzer/README.md), the [Vision Simulation](../../tools/accessibility-and-vision/vision-simulation/README.md) lab and the [Colour Science Lab](../../tools/colour-workspace/colour-science-lab/README.md) have mode switches that change the same site-wide setting as the [Advanced Kit](../advanced-kit/README.md).
- The [Basic Colour Tools](../../tools/colour-workspace/basic-colour-tools/README.md) workspace uses floating panels of its own, separate from the kits.
