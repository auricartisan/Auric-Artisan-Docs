# Menu Kit release notes

The website's public release history is at https://auricartisan.com/library/changelog/ and https://auricartisan.com/company/timeline/.

## Recorded releases

| Release | Date | What the public history says |
|---|---|---|
| v0.9.75 | 19 April 2026 | Interface fixes to the Menu Kit and the Status Kit, as part of a broad stability release |
| v0.9.8 | 2 May 2026 | Complexity management added (the tool visibility modes that the Menu Kit follows), with Advanced Kit upgrades |
| v0.9.9 | 5 June 2026 | Interface consistency improvements and shortcut updates across the site |

## The Menu Kit as of 24 September 2026

- Seven tabs (Tools, Design, Analyze, Account, Library, Company, Trust) with collapsible, remembered sections.
- **Recommended** and **Most Used** sections at the top of the Tools tab.
- A search that turns into a ranked results list with quick actions and keyboard navigation.
- A **You are here** marker on the current page's tile.
- The site status chip in the title bar.
- Shared kit controls: Focus mode, per-kit theme, Resize, Minimize, Close, and a labelled **Menu** launcher in the page utilities bar.

Changes not recorded in the public history are not listed here.
