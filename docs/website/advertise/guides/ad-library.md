# The Ad Library

The Ad Library at https://auricartisan.com/advertise/library/ lists every ad that runs on Auric Artisan: **Every ad, in the open**. Each entry shows the creative, the advertiser, the format, where it runs, its flight dates and its landing address. There are no hidden ads and no ads shown only to some people.

An ad is listed for its full run and for at least 90 days after it ends. Anyone can open the library; no account is needed.

## Browse the library

At the top of the page:

- **Search advertiser or text…** — filters the ads by advertiser, ad text or landing address as you type.
- Format chips — **All formats**, **Leaderboard**, **Rectangle**, **In-feed** and **Strip**.
- Status chips — **All**, **Active** and **Ended**.

The count beside the filters says how many ads match, for example **12 ads**. If none match, the page says **No ads match those filters.**

## Read an ad

Each card shows:

| Item | Meaning |
| --- | --- |
| Creative | The ad exactly as it is served. |
| Advertiser | Who runs the ad. Auric Artisan's own promotions are marked **(house)**. |
| Status badge | **Active** or **Ended**. |
| **Format** | For example **Leaderboard · 728×90**. |
| **Runs on** | The zones where it appears, such as **Homepage** or **Learn library (113 articles)**. |
| **Flight** | **since** and the start date, or the start and end dates. |
| **Landing** | Where a click goes. Addresses on Auric Artisan open in the same tab; other sites open in a new tab. |
| **Report this ad** | Opens the contact page. |

## Report an ad

If an ad breaks the creative policy — for example it imitates a button or system dialog, is not labelled **Sponsored**, or misleads — select **Report this ad** on its card, or **Report it** in **About this library**. Both open https://auricartisan.com/company/contact/. Auric Artisan pulls violating creatives within one business day.

## Who may sell these ads

The file https://auricartisan.com/ads.txt declares every authorised seller of Auric Artisan's ad space.
