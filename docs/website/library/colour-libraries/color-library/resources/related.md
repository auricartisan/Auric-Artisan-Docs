# Related

## Other colour libraries

- [Palette Library](../../palette-library/README.md) — sets of colours that work together.
- [Shade Library](../../shade-library/README.md) — one colour taken through lightness, for design-system scales.
- [Accessibility Library](../../accessibility-library/README.md) — foreground and background pairs scored for contrast against any ground, not only white and black.
- [Harmony Library](../../harmony-library/README.md) and [Gradient Library](../../gradient-library/README.md).
