# Accessibility Library glossary

| Term | Meaning |
| --- | --- |
| AA, AAA | WCAG conformance levels. For normal text, AA needs 4.5:1 and AAA needs 7:1. |
| APCA (Lc) | Advanced Perceptual Contrast Algorithm; its lightness contrast value Lc runs from about −108 to 106. Larger absolute values are more readable. |
| Auric SD | Auric Artisan's combined 0–100 score for a pair (WCAG, APCA, vision separation, lightness gap, hue gap), graded S, A, B, C, D or F. |
| Caret | The marker on the map showing the current foreground. |
| Contrast ratio | The WCAG 2 measure of the luminance difference between two colours, from 1:1 to 21:1. |
| Corpus | The five million scored pairs behind the index. |
| Foreground | The text or icon colour. |
| Gamut | The range of colours a colour space or screen can show. The map shows the sRGB gamut. |
| Ground | The background colour you are testing against. |
| Large text | At least 18 point (24 CSS pixels), or 14 point (about 18.7 CSS pixels) bold. |
| OKLCH | A perceptual colour space: lightness (0 to 1), chroma and hue. |
| Pick | One of up to twelve suggested passing foregrounds. |
| Record id | `acc_` followed by a record's number in base 36. |
| Seed | The fixed number (9001) from which every record is derived. |
| Target | The contrast threshold you are testing: 3:1, 4.5:1 or 7:1. |
| Territory | The share of the map that clears the target on the current ground. |
| Vision margin | Worst-case separation of the two colours under ten simulated vision conditions, 0 to 1. |
| WCAG | Web Content Accessibility Guidelines. |
