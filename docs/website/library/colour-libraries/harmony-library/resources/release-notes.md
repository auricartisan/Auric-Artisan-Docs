# Release notes

## 0.9.9 — 5 June 2026

The Harmony Library was added in release 0.9.9 as part of the library expansion. See the [Changelog](../../../changelog/README.md).

## The current page

The page now calculates all 8,192 harmonies when it opens, so filters and the analysis tabs cover the whole collection rather than one page of it, and **What harmony is this?** identifies the scheme behind your own colours. Every tab is shown at once (an earlier Simple/Advanced switch has gone). These changes are not listed as a separate changelog release.
