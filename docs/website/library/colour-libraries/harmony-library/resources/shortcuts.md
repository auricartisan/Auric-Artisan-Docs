# Harmony Library shortcuts

| Keys or action | Where | Result |
| --- | --- | --- |
| `/` | Anywhere, when not typing | Focuses **Search by id, hex or method…**. |
| `Enter` or `Space` | A focused swatch in the grid | Opens its harmony on **Inspect**. |
| `Escape` | Share link or design tokens dialog | Closes it. |
| Select a swatch | Grid | Copies its hex. |
| Select a column | **Inspect** strip | Copies its hex. |
| Select a card heading | **Inspect** | Folds or unfolds the card. |

The site-wide shortcuts also work here. See [Site features](../../../../site-features/README.md).
