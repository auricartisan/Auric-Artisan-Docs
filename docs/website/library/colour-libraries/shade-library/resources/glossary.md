# Shade Library glossary

| Term | Meaning |
| --- | --- |
| Auto text | The better of near-black (`#111111`) or white text for a token: near-black on tokens with luminance above 0.5, white otherwise. |
| Base | The colour a scale is built around, usually near its middle. |
| Contrast ratio | The WCAG 2 lightness-difference measure, 1:1 to 21:1. 4.5:1 is AA for body text; 3:1 for large text. |
| Even steps | A scale in which no step between neighbouring tokens is much larger than the average step. |
| Min adjacent contrast | The contrast between the two most similar neighbouring tokens. |
| OKLCH | A perceptual colour space: lightness (0 to 1), chroma (colourfulness) and hue angle. |
| Profile | The **Shade summary** badge: Neutral, Hue Shift, Light, Deep or Balanced. |
| Scale (shade system, ramp) | One colour taken through lightness in named steps. |
| Shade | A darker version of a colour, towards black. |
| Tint | A lighter version of a colour, towards white. |
| Token | A named step in a scale, such as `500`. |
