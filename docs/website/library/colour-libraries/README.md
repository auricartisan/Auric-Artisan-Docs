# Colour libraries

Auric Artisan has six colour libraries. Each is a large, searchable collection of generated colour data that you can browse, filter, inspect and copy or export. They share one idea: every item carries its measurements with it, so you can choose colours by what they do — how they contrast, how they step, how they read to people with colour vision deficiencies — and not only by how they look in a thumbnail.

The libraries are free to use and need no account. They open in any modern browser.

## The six libraries

| Library | What it holds | Address |
| --- | --- | --- |
| [Color Library](color-library/README.md) | 8,192 measured colours, each in seven colour spaces with contrast and colour-blindness data. | https://auricartisan.com/library/color/ |
| [Palette Library](palette-library/README.md) | 5,000,000 generated palettes, filterable by hue, lightness, chroma, harmony method and WCAG. | https://auricartisan.com/library/palette/ |
| [Gradient Library](gradient-library/README.md) | 8,192 gradients with OKLCH metadata, 2 to 46 stops, and a measured verdict on banding. | https://auricartisan.com/library/gradient/ |
| [Harmony Library](harmony-library/README.md) | 8,192 colour harmonies across 23 colour-theory schemes, plus a tool that names the scheme your own colours form. | https://auricartisan.com/library/harmony/ |
| [Shade Library](shade-library/README.md) | 8,192 OKLCH shade scales with tint and shade tokens and contrast checks. | https://auricartisan.com/library/shades/ |
| [Accessibility Library](accessibility-library/README.md) | 5,000,000 foreground and background pairs scored against WCAG, APCA and colour vision deficiency. | https://auricartisan.com/library/accessibility/ |

## Which library do I need?

- **One colour, with its numbers:** the Color Library.
- **A set of colours that work together:** the Palette Library, or the Harmony Library if you want a named colour-theory scheme.
- **A smooth blend between colours:** the Gradient Library.
- **One colour taken from light to dark for a design system:** the Shade Library.
- **Text and background colours that pass contrast rules:** the Accessibility Library.
