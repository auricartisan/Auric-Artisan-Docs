# Collections glossary

| Term | Meaning |
| --- | --- |
| Card | One tool's tile in the grid: artwork, category, name, description and a pin button. |
| Catalogue order | The fixed order in which tools are listed in the catalogue. The Reference lists all 30 tools in this order. |
| Category | The broad group a tool belongs to, such as Colorimetry or Utilities. Each tool has exactly one. |
| Card menu | The menu that opens when you right-click a card, with card actions and grid settings. |
| Columns | How many cards sit side by side in grid view. **Auto** fits the screen; **2**, **3** or **4** force a number. |
| Density | The spacing between cards. **Cozy** is normal; **Compact** is tighter. |
| Everything | The tool-visibility setting that shows all 30 tools. |
| Frecency | A mix of frequency and recency: how often you opened a tool, weighted towards recent opens. The **Most used** order is based on it. |
| Mode | A tool's level: **Basic** (everyday), **Advanced** (scientific or power-user) or **Both** (shown in every setting). |
| Open | Selecting a card to go to the tool. Each open is counted towards **Most used**. |
| Pin | A mark you put on a tool so it is grouped under **Pinned** and comes first in **Start here** and **Pinned first**. |
| Reading mode | A site setting that makes pages calmer and easier to read. The card menu's **Reading** switch turns it on and off. |
| Start here | The slider of three featured tools near the top of the page. |
| Tool visibility | The site-wide setting, chosen in the Advanced Kit, that decides which tools appear: Basic, Advanced, Everything or Custom. |
| Topic | A short tag on a tool, such as `palette` or `hdr`. A tool can have several. The **Topics** filter lists up to 14 of the most common. |
