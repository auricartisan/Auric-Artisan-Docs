# Limits and accuracy

Collections is a catalogue, not a measurement tool. Its numbers and orders are simple, local and predictable. This page says what they mean.

## Counts

- The hero counters and category counts cover only the tools your tool-visibility setting shows. With the default **Basic** setting, **Tools** reads 14, not 30.
- **Topics** counts different tags among the tools in view. The **Topics** filter lists only the 14 most common of them, so a rarer tag cannot be chosen as a filter; type it into the search box instead.

## Search

- Search is a plain text match. It does not correct typing mistakes and does not know that "color" and "colour" mean the same thing.
- Every word you type must match. Adding a word can only narrow the results.

## Sort orders

- **Newest first** and **Oldest first** have no effect, because tools carry no dates.
- **Most used** counts only opens from the Collections page itself, in this browser. It knows nothing about how you use the tools elsewhere, or on other devices.
- **Recommended** is a fixed recipe, not a learning system. It adds points for your pins and opens, for mentions of core subjects (such as accessibility, WCAG, contrast, gamut, HDR and ICC) and for how fully a tool is described. It is a starting point, not advice about which tool is right for a job.
- The boost from your opens is capped, so heavy use of one tool cannot push every other tool to the bottom of **Recommended**.

## What Collections is not

- It is not a record of your work. Pins and usage are conveniences that can be lost when browser data is cleared.
- It does not sync. Nothing you do on this page follows your account to another browser.
- It does not rate tools. The order of the catalogue and of **Start here** is not a ranking of quality.
