# Learn reference

## The Learn page (https://auricartisan.com/library/learn/)

| Element | What it does or shows |
| --- | --- |
| Heading line | Number of articles and total reading time. |
| **Pick up where you left off** / **Next in the course** | Your most recent unfinished article, or the first unread one; with number, title, category, minutes. Shown only after you have opened an article. |
| Progress bar | **N of 113 read ·** time left. |
| **Search titles and topics** | Filters as you type; every word must match the number, title, summary or category. |
| Category chips | **All**, **Foundations**, **Physics**, **Vision**, **Colorimetry**, **Digital**, **Design**, **Print**, each with a count. Select again to clear. |
| Count line | **N of 113 ·** time, shown only when filtered. |
| Course row | Number, title (link), category, minutes, tick when read, summary. |
| **Nothing in the course matches that.** | No results; **Show all articles** clears the search and category. |
| Foot | Links to the blog and changelog. |

If the course list cannot be built (for example, offline), the page shows a plain list of **All articles** instead.

## An article page

| Element | What it does |
| --- | --- |
| **Auric Artisan · Learn** | Label above the title. |
| Facts row | Category and number, demos, reading time, subject. |
| **Download** › **Markdown** / **Plain text** | Saves the article text as `.md` or `.txt`. |
| **Print** | Prints the article. |
| **← All Articles** | Back to the Learn page. |
| **Table of Contents** | Jump to a section. |
| Reading-progress bar | Fills as you scroll. |
| **Live demo** button (**Expand**) | Opens the demo panel. |
| Demo panel | Chips **Live**, **Article**, **Dockable**; **Dock panel**, **Full screen**, **Close**. |
| **Quick check** | Multiple-choice quiz; **Question N of 6**; **Next →**. |
| **Continue your journey** | Seven personalised suggestions; pin buttons; **More like this**. |
| **Article N of 113** | Place in the course. |

## Keys

| Key | Where | Effect |
| --- | --- | --- |
| `Escape` | Demo panel | Closes it. |
| `Escape` | **Download** menu | Closes it. |
| `Tab` | Anywhere | Moves between links and controls. |
