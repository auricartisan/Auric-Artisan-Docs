# Changelog FAQ

## Why are there two v0.9.6 entries?

Two entries share version 0.9.6: "System Integration & Validation" (8 April 2026) and "Vision Simulation & Color Model Lab Advancement" (13 April 2026). A link to `#0.9.6` opens the newer one.

## What is the difference between a release and a patch?

Releases add features; patches fix and tidy. One entry, v0.9.75, is labelled **Changelog** rather than either.

## Where do I report a problem with a release?

Release notes ask for steps to reproduce, your browser and operating system, the page or tool affected, and screenshots — and, for API problems, the `x-request-id` header from the response. See [Help](../../../../help/README.md) for how to get in touch.

## Is every change listed?

The changelog lists the notable changes in each release. Smaller changes between releases, and improvements to individual tools, may appear only on the tool's own pages and guides.
