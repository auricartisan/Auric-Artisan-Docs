# Documentation reference

## Index page (https://auricartisan.com/library/documentation/)

| Control | What it does | Values | Default |
| --- | --- | --- | --- |
| **Search 54 subjects…** | Shows subjects whose name or description contains the text. | Any text | Empty |
| Audience switch | Shows both kinds of document, or only one. | **Both**, **Guides**, **References** | **Both** |
| Count | Subjects and documents currently shown. | For example **54 subjects · 89 documents** | — |
| Subject row | Name (link), description, **Guide** and/or **Reference** buttons. | — | — |
| **No subject matches that. Try a tool name.** | Shown when nothing matches. | — | — |

| Address | Effect |
| --- | --- |
| `?audience=guide` | Opens the index showing guides only. |
| `?audience=reference` | Opens the index showing references only. |

## Article pages

| Element | What it does |
| --- | --- |
| **Documentation** (side list) | All subjects; current one highlighted. |
| Breadcrumb | **Documentation** › subject. |
| **User guide** / **Developer reference** | Switch between the pair; a missing half is greyed out. |
| **On this page** | Section links. |
| **Copy** on code blocks | Copies the code; shows **Copied** or **Press Ctrl C**. |
| **The pair** | Link to the other document for the subject. |
| **Next subject** | Link to the next subject alphabetically. |
