# Search glossary

| Term | Meaning |
| --- | --- |
| AuricBot | The name Auric Artisan's crawler uses when it fetches pages. |
| BM25F | The ranking method site search uses: it scores word matches, weighting each field of a page differently. |
| Canonical address | The address a page names as its preferred version, with a `rel=canonical` link. |
| Click | In the Search Console, a searcher opening your page from a web-search result. |
| Click-through (CTR) | Clicks divided by impressions. |
| Coverage | Which of a site's addresses are in the index, and why the others are not. |
| Crawl | Fetching a page so it can be indexed. |
| Crawled index | Auric Artisan's own index of the web, searched with the globe. |
| Crawl-delay | A robots.txt line asking crawlers to wait between requests. |
| Exclusion | A `-word` in a query, which leaves out pages containing the word. |
| Field filter | An operator such as `type:` or `tag:` that narrows results by one field. |
| Impression | In the Search Console, one appearance of your page in a web-search result. |
| Index | The collection of pages a search looks through. |
| Index build | The step that makes crawled pages searchable. |
| Inspection | The Search Console panel that explains one address. |
| LOCAL, GLOBAL | The mode label: site search or web search. |
| noindex | A robots meta tag or header asking search engines not to index a page. |
| Pace | How long the crawler waits between requests to one site. |
| Phrase | Words in quotes, which must appear together and in order. |
| Position | Where a result appeared in the list; 1 is the top. |
| Property | A site you have added to the Search Console. |
| Rank (static rank) | A page's or site's weight from links between sites, out of 255. |
| Related word | A word linked to yours, such as swatch for palette, matched at reduced weight. |
| robots.txt | A file at the root of a site that tells crawlers what they may fetch. |
| Section tab | A filter on the search page for one kind of page, such as **Learn**. |
| Sitemap | A file listing a site's addresses for crawlers. |
| Verification | Proving to the Search Console that you own a site. |
| WCAG 2.1 | The Web Content Accessibility Guidelines version whose contrast formula the answer cards use. |
