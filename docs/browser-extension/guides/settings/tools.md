# Tools settings

Settings › **Tools** changes how the tools behave.

| Control | Choices | Default | What it does |
|---|---|---|---|
| **Copy colours as** | HEX, RGB, HSL, OKLCH | HEX | The format used when you click a colour in History or Library, and the Picker's starting format |
| **Colour names** | CSS names, XKCD, Off | CSS names | The nearest colour name shown in colour details. Off hides names. XKCD currently gives the same names as CSS names. |
| **Show APCA beside WCAG** | On or off | On | Shows the APCA Lc score, tiers and readable sizes in Contrast |
| **Keep a colour history** | On or off | On | "The last 50 colours you picked or copied." Off stops recording new colours. |
| **Sound on pick** | On or off | Off | "A short tick when the eyedropper lands." Also plays on copy. |
| **Deep page audit** | On or off | On | Contrast scan limits: 3 500 elements and 160 issues on; 1 800 and 80 off. Slower on large pages. |
| **Outline issues after an audit** | On or off | Off | "Marks failing elements on the page as soon as the audit finishes." |
