# Related tools

The browser extension brings the most frequent checks to any page. The full-size tools on auricartisan.com go deeper, and the VS Code extensions bring the same checks to your code.

## Website tools

| Tool | Use it when | Docs |
|---|---|---|
| Analyzer | You want a full report on any URL, not just the tab you have open | [Analyzer](../../website/tools/accessibility-and-vision/analyzer/README.md) |
| Contrast Checker | You need more contrast detail than the popup offers | [Contrast Checker](../../website/tools/accessibility-and-vision/contrast-checker/README.md) |
| Vision Simulation | You want to simulate vision on images and designs, with more controls | [Vision Simulation](../../website/tools/accessibility-and-vision/vision-simulation/README.md) |
| Accessibility Checklist | You need the manual checks an automated audit cannot make | [Accessibility Checklist](../../website/tools/accessibility-and-vision/accessibility-checklist/README.md) |
| Ishihara Plate Generator | You want colour-vision test plates | [Ishihara plates](../../website/tools/accessibility-and-vision/ishihara-plate-generator/README.md) |
| Basic Colour Tools | You want the colour tools in a larger workspace | [Basic Colour Tools](../../website/tools/colour-workspace/basic-colour-tools/README.md) |
| Colour Science Lab | You want to explore colour spaces and models | [Colour Science Lab](../../website/tools/colour-workspace/colour-science-lab/README.md) |
| Image Picker | You want to pick colours from images in detail | [Image Picker](../../website/tools/image-and-file-tools/image-picker/README.md) |

The extension's **On the web** list and Home links open these and other pages directly.

## Libraries and learning

## VS Code

The [Auric Artisan Studio](../../vscode-extensions/auric-artisan-studio/README.md) extensions bring colour and accessibility checks to your source code, so you can fix what the browser extension finds where the code lives.

## Services

- [Font CDN](../../services/font-cdn/README.md) and [Icon CDN](../../services/icon-cdn/README.md), for fonts and icons on your own sites.
