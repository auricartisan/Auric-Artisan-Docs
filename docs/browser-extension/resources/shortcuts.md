# Keyboard shortcuts

## Browser-level shortcuts

These work from any page. Change them on the browser's shortcuts page: `chrome://extensions/shortcuts` in Chromium browsers, or `about:addons` › gear › **Manage Extension Shortcuts** in Firefox. Settings › Shortcuts › **Change them in the browser** opens it.

| Keys | Action | Name on the shortcuts page |
|---|---|---|
| `Alt` + `Shift` + `A` | Open the extension on the active tab | Open Auric Artisan |
| `Alt` + `Shift` + `C` | Open the contrast checker | Open contrast checker |
| `Alt` + `Shift` + `E` | Open Page palette and read the page's colours | Extract page palette |
| `Alt` + `Shift` + `V` | Turn the deuteranopia simulation on or off | Toggle deuteranopia simulation |
| Unassigned | Start the element inspector | Inspect an element on the page |
| Unassigned | Open Audit and run it | Run a full accessibility audit |

No macOS-specific keys are documented; use your browser's shortcuts page to check or change them.

## In the popup and side panel

| Keys | Action |
|---|---|
| `/` | Focus search (when not typing in a field) |
| `Ctrl` + `K` | Focus search from anywhere; closes Settings |
| `Up` / `Down` | Move through search results |
| `Enter` | Run the selected search result |
| `Esc` | Close an open colour picker, then Settings, then clear the search, then return to Home |
| `Left` / `Right`, `Home` / `End` | Move between spaces, or between Settings sections (`Up` and `Down` also work there) |
| `Delete` or `Backspace` | Remove the focused colour in Library |

## Element inspector (on the page)

| Keys | Action |
|---|---|
| `Up` | Parent element |
| `Down` | First child |
| `Left` / `Right` | Previous / next sibling |
| `P` | Pin or unpin |
| `C` or `Enter` | Copy CSS |
| `S` | Copy the selector |
| `J` | Copy JSON |
| `Esc` | Unpin; press again to stop |
| Arrow keys on the grip | Move the pinned card |

## Custom right-click menu (on the page)

| Keys | Action |
|---|---|
| Type | Filter every action |
| `Up` / `Down` | Move between the quick bar and the rows |
| `Right` | Open a group, or reach a row's star |
| `Left` | Close a group, or leave the star |
| `Enter` | Run the row; in the field, run the first result |
| `1` to `6` | Choose a search engine in Search the web |
| `Esc` | Clear the filter, then close a submenu, then close the menu |
| **Shift** + right-click | Open the browser's own menu |

## Screen eyedropper

| Keys | Action |
|---|---|
| Click | Sample the pixel |
| `Esc` | Cancel |
