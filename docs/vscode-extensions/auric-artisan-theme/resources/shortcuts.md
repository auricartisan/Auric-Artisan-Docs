# Shortcuts and commands

## Global keybindings

| Action | Windows and Linux | macOS |
| --- | --- | --- |
| Open Theme Studio | `Ctrl` + `Alt` + `;` | `Cmd` + `Alt` + `;` |
| Cycle Variant | `Ctrl` + `Alt` + `'` | `Cmd` + `Alt` + `'` |

To change them, open **Preferences: Open Keyboard Shortcuts** and search for "Auric Theme".

## Keys inside Theme Studio

| Key | Action |
| --- | --- |
| `1` | Looks tab |
| `2` | Dials tab |
| `3` | Colours tab |
| `4` | Audit tab |
| `5` | Share tab |
| `6` | Preview tab |
| `/` | Colours tab, focus the filter |
| `Escape` | Close a dropdown or picker; clear the colour filter |
| Arrow keys, `Home`, `End` | Move between tabs, dropdown options, swatches; adjust sliders |
| `Shift` + arrow keys | Larger slider and picker steps |
| `Page Up`, `Page Down` | Larger slider steps |
| Double-click a slider | Reset it |
| `Enter` in the preset name box | Save the preset |

## Commands

Open the Command Palette (`Ctrl` + `Shift` + `P`) and type "Auric Theme".

| Command | Notes |
| --- | --- |
| Auric Theme: Open Theme Studio | Also on the status bar item and the sidebar. |
| Auric Theme: Switch Variant… | All 54 themes. |
| Auric Theme: Cycle Variant | Next variant. |
| Auric Theme: Choose Accent Colour… | 17 named accents. |
| Auric Theme: Choose Look… | 11 looks. |
| Auric Theme: Choose Syntax Palette… | 9 palettes. |
| Auric Theme: Choose Interface Language… | Auto, English or Hindi. |
| Auric Theme: Toggle Italics | Off or standard. |
| Auric Theme: Surprise Me | Random curated combination. |
| Auric Theme: Reset Everything | Asks for confirmation. |
| Auric Theme: Show Contrast Report | Opens the text report. |
| Auric Theme: Copy Customisation to Clipboard | JSON. |
| Auric Theme: Apply Customisation from Clipboard | JSON import. |
| Auric Theme: Export as Theme File… | Standalone theme JSON. |
| Auric Theme: Save Current as Preset… | Named preset. |
| Auric Theme: Load Preset… | Choose a saved preset. |

**Apply Now** (`auricTheme.applyNow`) exists but is hidden from the Command Palette. Bind it to a key if you want to force an immediate re-apply.

With VS Code's display language set to Hindi, these titles appear in Hindi under the category "ऑरिक थीम".
