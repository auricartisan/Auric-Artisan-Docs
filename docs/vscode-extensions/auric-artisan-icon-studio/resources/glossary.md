# Glossary

| Term | Meaning |
| --- | --- |
| Catalog entry | One icon or emoji in the bundled catalog. Its styles or tones are not counted separately. |
| Collection | A set of icons from one source, such as Auric Drawn or Tabler. Icon Studio has 11. |
| `currentColor` | A CSS keyword meaning "use the surrounding text colour", so an icon follows light and dark themes. |
| Data URI | A way to embed a file's content directly in text, starting `data:image/svg+xml,`. |
| Font-backed icon | An icon drawn from a font glyph (Material), not an SVG file. It needs the font loaded to display. |
| For you | A view of icons ranked for the file you are editing and your likes and use. |
| Host (collections) | The one extension that shows the shared library when several Auric collection extensions, or Icon Studio, are installed. |
| Icon ID | The unique catalog name of an icon, such as `tabler-rocket` or `files-blank-document-drawn-0001`. |
| JSX | The HTML-like syntax used in React components. |
| Ligature name | The word that a Material icon font turns into a glyph, such as `home`. |
| Likes | Icons you marked with the heart. |
| Quick Pick | VS Code's searchable pop-up list at the top of the window. |
| Recent | Icons you inserted, copied or saved, newest first. |
| Shortcode | A text name for an emoji between colons, such as `:rocket:`. |
| Skin tone | A modifier that changes the skin colour of emoji that support it. |
| Smart insert | Choosing the output format from the language of the file you are editing. |
| Style | A visual variant of an icon, such as Outline or Filled. Also called a variant. |
| SVG | Scalable Vector Graphics, a text format for vector images. |
