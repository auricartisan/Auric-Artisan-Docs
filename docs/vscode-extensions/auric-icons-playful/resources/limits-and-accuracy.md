# Limits and accuracy

- The library contains 1,225 validated icons at the installed version; new icons come with updates.
- There is no Mono or Duotone variant, and no Explorer file icon theme.
- Icons are inserted as drawn: there are no size, colour or stroke controls for output.
- Smart insert picks a format from the file's language, not the exact cursor position. Check quotes and surrounding code.
- Recommendations are local rankings from the file you are editing and your likes and use, not an AI service.
- Hover previews recognise only Playful icon IDs (a hyphenated name ending in four digits).
- Some copy formats from the retired "Auric Artisan Icons" gallery (Vue single-file component, web component, CSS class and sprite) are not offered, because they depend on runtime files an extension cannot ship.
