# Frequently asked questions

## Are these emoji?

No. They are emoji-style SVG icons: real vector artwork you can insert, style and ship, not Unicode emoji characters. For Unicode emoji, see [Auric Artisan Emoji](../../auric-artisan-emoji/README.md).

## What is the Small variant for?

Small is a separate, simplified drawing for 16 to 24 pixels. Details that would blur at small sizes are removed.

## Is this the same as the Playful style in File Icons?

No. File Icons' Playful style is a set of 500 Explorer file and folder icons. This extension is a 1,225-icon library for your code and has no Explorer theme.

## Why is there no file icon theme?

Playful's earlier gallery theme did not meet the 16-pixel silhouette, folder-pair and mapping standards of Auric Icons: Modern, which is the family theme. Install Modern alongside Playful for the Explorer theme.

## Do I need Modern or Drawn too?

No. Playful works alone. Installing them together gives you one merged library.

## Is it free and offline?

Yes. Free to use for any purpose (redistribution and resale are not permitted), with no network access or telemetry.

## Can I change icon size or colour on insert?

Not in this extension. Auric Artisan Icon Studio has size and colour output settings and includes the Playful collection.
