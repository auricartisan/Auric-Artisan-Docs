# Frequently asked questions

## Does it need the internet?

No. The catalog and Studio are bundled. There is no telemetry and no account.

## Why do emoji look different on another computer?

Emoji are drawn by each system's emoji font. The characters are the same; the artwork differs.

## Does clearing history remove favorites?

No. **Clear Emoji History** removes recent emoji and last-emoji recall only.

## Can I change the default skin tone?

Yes: the **Skin tone** filter, **Make {tone} my default** in the inspector, or `auricEmoji.preferredSkinTone`.

## What is the difference between Insert and the click action?

The card's **Insert** button always inserts. Selecting the emoji itself (or pressing `Enter`) runs your click action, which can be Insert, Copy, or Insert and copy.

## Is this the same as the emoji in Icon Studio?

Icon Studio also includes 1,914 emoji for browsing alongside icons. This extension adds the full emoji workflow: sequences, completions, shortcode replacement, code hovers, six copy formats and a Hindi interface.

## Are Auric Icons: Playful icons emoji?

No. Playful is a library of emoji-style SVG artwork, not Unicode emoji characters.
