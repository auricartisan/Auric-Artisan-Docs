# Glossary

| Term | Meaning |
| --- | --- |
| Association | A rule that maps a file extension, filename or folder name to an icon. |
| Auto variant | A variant choice that follows the language of the file you are editing. |
| Catalog path | The relative location of an icon file inside the bundled catalog. |
| Data URI | Text that embeds a file directly, starting `data:image/svg+xml,`. |
| Duotone | A variant drawn in two tones. |
| Explorer arrows | The chevrons beside folders in the Explorer that expand and collapse them. |
| File icon theme | The set of icons VS Code shows beside files and folders. Only one is active at a time. |
| Framework pack | Extra file icons for one framework's file types, such as Angular components or Vue composables. |
| Host | The one extension that shows the shared library when several Auric collections are installed. |
| Icon ID | The unique name of an icon. Library IDs end in a four-digit number, such as `analytics-bar-chart-0042`; theme IDs are short names such as `typescript`. |
| Icon Studio | The heading of the shared library view, and also the name of the separate Auric Artisan Icon Studio extension. |
| Mono | A single-colour variant. |
| Preview surface | The light, dark or automatic backdrop behind library cards. |
| Semantic colour | A colour that identifies a file type, such as the TypeScript blue. |
| Sharp Modern | One of the two style families in the library (300 icons), shown as **Sharp** in the Style filter. |
| Simple Modern | The other style family (420 icons), shown as **Modern** in the Style filter. |
| Smart guide | Tip cards at the top of the library that react to your file and usage. |
| Smart insert | Choosing the output format from the language of the file you are editing. |
| Variant | One rendering of an icon: Color, Mono, Outline or Duotone. |
