# Glossary

| Term | Meaning |
| --- | --- |
| Association | A rule mapping an extension, filename, folder name or pattern to an icon ID. |
| Badge | Up to two characters shown beside a resource in the Explorer by smart detection. |
| Decoration | A badge, colour or tooltip VS Code adds to an Explorer item. |
| Direct parent | The folder immediately containing a file or folder; `parent/name` patterns only match this. |
| Exclusion | A folder name or pattern that smart detection never inspects. |
| Facet | The faceted Explorer style with 500 SVGs. |
| File icon theme | The set of icons VS Code shows beside files and folders. One is active at a time. |
| Folder pair | The closed and open versions of one folder icon. |
| Framework pack | Extra Modern associations for Angular, NestJS, React or Vue. |
| Hover token | Text such as `:icon-file-typescript:` that a code hover can replace with artwork. |
| Icon ID | The name of a shipped icon, such as `test` or `database`, used as an association value. |
| Inspector | The dialog showing a card's exact code output. |
| Modern | The Explorer style with 464 SVGs, shared with Auric Icons: Modern's theme ID. |
| Playful | The Explorer style with 500 SVGs and its own palette. Not the Auric Icons: Playful library. |
| Profile | A named, portable set of appearance, association and smart detection settings. |
| Root association | An icon for a workspace root folder, by name. |
| Smart detection | Content-aware classification of folders and small files, shown as decorations. |
