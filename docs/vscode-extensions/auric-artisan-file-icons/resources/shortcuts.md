# Shortcuts and commands

File Icons has no default keybindings. Open **Preferences: Open Keyboard Shortcuts**, search for "Auric Artisan File Icons" and assign keys to the commands you use most, such as **Insert Icon into Code…** or **Open File Icon Studio**.

## Keys inside File Icon Studio

| Key | Action |
| --- | --- |
| `/` | Focus the icon search |
| `Arrow Up` / `Arrow Down` | Move through picker options |
| `Home` / `End` | First or last option |
| `Escape` | Close an open picker or the inspector |

## Commands

Type "Auric Artisan File Icons" in the Command Palette.

| Group | Commands |
| --- | --- |
| Themes | Activate Facet Icon Theme; Activate Playful Icon Theme; Activate Modern Icon Theme |
| Studio | Open File Icon Studio; Open File Icon Studio Settings; Insert Icon into Code… |
| Appearance | Choose Folder Color; Toggle Explorer Arrows; Restore Icon Defaults |
| Associations | Set File or Folder Icon; Clear Custom File or Folder Icon |
| Smart detection | Configure Smart Icon Detection; Refresh Smart Icon Matches; Explain Smart Icon Match; Toggle Smart Icon Detection; Apply Detected Folder Icon; Scan Workspace for Folder Icons |
| Profiles | Apply Icon Profile; Save Current Icon Profile; Delete Saved Icon Profile; Export Icon Profile to Clipboard; Import Icon Profile from Clipboard |
| Other | Show Icon Theme Diagnostics; Import Legacy Playful Settings…; Import Modern File Icon Settings… |

## Context menus

- **Explorer:** right-click › **Auric File Icons** submenu.
- **Editor:** right-click › **Insert Icon into Code…**.
