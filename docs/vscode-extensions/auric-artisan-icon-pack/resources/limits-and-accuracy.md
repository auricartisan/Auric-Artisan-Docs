# Limits and accuracy

- The pack is metadata only. It does not embed its members' VSIX files, duplicate their artwork or run an installer.
- A pack VSIX is not an offline bundle; installing needs marketplace access.
- If a member is unavailable in your marketplace or blocked by policy, the pack cannot install it.
- The exact interface you get depends on the member versions VS Code installs.
- Icon Studio and File Icons are not included.
