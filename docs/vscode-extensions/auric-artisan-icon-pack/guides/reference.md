# Icon Pack reference

This reference describes version 0.1.0 as published on the Visual Studio Marketplace.

## Included extensions

| Extension | ID | What it adds |
| --- | --- | --- |
| Auric Icons: Modern | `auric-artisan.auric-artisan-modern-icon` | 720 Modern and Sharp library icons, plus the Modern Explorer file icon theme. |
| Auric Icons: Playful | `auric-artisan.auric-icons-playful` | 1,225 emoji-style icons in Color, Outline, Filled and Small. |
| Auric Artisan Emoji | `auric-artisan.auric-artisan-emoji` | Emoji Studio: 1,914 emoji, skin tones, shortcodes and editor insertion. |
| Auric Icons: Drawn | `auric-artisan.auric-icons-drawn` | 480 hand-drawn icons in Color, Mono, Outline and Duotone. |

The pack uses the current publishing IDs. It does not install the retired `auric-artisan-icons` or `auric-artisan-svg-icons` extensions.

## What the pack itself contains

| Item | Present |
| --- | --- |
| Commands | None |
| Settings | None |
| Views or keybindings | None |
| Background service or installer | None |
| Telemetry or workspace edits | None |
| Embedded copies of member extensions | No; members are downloaded from the marketplace |

## Requirements

| Requirement | Value |
| --- | --- |
| VS Code | 1.85 or later |
| Network | Marketplace access to download members |
| Category | Extension Packs |

## Not included

| Extension | Why you might want it |
| --- | --- |
| [Auric Artisan Icon Studio](../../auric-artisan-icon-studio/README.md) | The separate all-in-one catalog: the three Auric collections, emoji and seven open-source sets. |
| [Auric Artisan File Icons](../../auric-artisan-file-icons/README.md) | Explorer file and folder themes in Facet, Playful and Modern styles. |
| [Auric Artisan Icon Hub](../../auric-artisan-icon-hub/README.md) | Seven open-source sets with colour controls and export. |
