==============================================================================
SHORTCUTS
==============================================================================
The keyboard shortcuts Auric Artisan Font Hub provides in VS Code and inside
its panels.
Area: VS Code extensions › Auric Artisan Font Hub   Updated: 2026-09-25

VS CODE
=======

  Windows and Linux    | macOS               | Command
  ---------------------+---------------------+----------------------------------------
  `Ctrl` + `Alt` + `F` | `Cmd` + `Alt` + `F` | Auric Artisan Font Hub: Open Font Hub
  `Ctrl` + `Alt` + `T` | `Cmd` + `Alt` + `T` | Auric Artisan Font Hub: Quick Pick Font

Other commands have no default shortcut. Assign one in Preferences: Open
Keyboard Shortcuts by searching for `auricFontLib`.

INSIDE THE SIDEBAR AND STUDIO
=============================

  Keys:         `/` (when not typing in a field)
  What they do: Focus and select the search box

  Keys:         `Ctrl` + `K` (`Cmd` + `K` on macOS)
  What they do: Focus and select the search box

  Keys:         `Escape`
  What they do: Close the comparison, details panel or tray; otherwise clear
                the search

  Keys:         Arrow keys on a font card
  What they do: Move to the next or previous card, or the card above or below

  Keys:         `Tab`, `Shift` + `Tab`
  What they do: Move through controls; focus stays inside an open details
                panel, tray or comparison

  Keys:         Arrow keys, type-ahead, `Enter` in drop-downs
  What they do: Choose a category, sort order, intent or industry
