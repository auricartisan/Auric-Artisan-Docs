Keybindings, in-view keys and every command in Auric Icons: Playful.
Area: VS Code extensions › Auric Icons: Playful   Updated: 2026-09-25

KEYBINDINGS
===========

  Action             | Windows and Linux    | macOS
  -------------------+----------------------+--------------------
  Smart Insert Icon  | `Ctrl` + `Alt` + `I` | `Cmd` + `Alt` + `I`
  Insert from Recent | `Ctrl` + `Alt` + `R` | `Cmd` + `Alt` + `R`

Both need a focused text editor and are active only while Playful hosts the
library.

KEYS IN THE ICON LIBRARY
========================

  Key                       | Action
  --------------------------+-------------------------------
  `/`                       | Focus search
  `Escape`                  | Clear search; close a dropdown
  `Arrow Up` / `Arrow Down` | Move between dropdown options

COMMANDS
========

Type "Auric Icons: Playful" in the Command Palette: Open Icon Library, Search
Icons, Insert SVG at Cursor, Smart Insert Icon (matches active language), Copy
Icon As… (JSX, CSS, Markdown, Data URI, Image tag), Insert from Likes, Insert
from Recent, Toggle Like for an Icon, Clear Likes, Recents and Learned
Recommendations, Copy SVG, Save SVG As…, Open SVG Source.

See the reference [../docs/reference.txt] for IDs and details.
