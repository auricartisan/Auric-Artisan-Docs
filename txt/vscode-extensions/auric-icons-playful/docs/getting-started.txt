==============================================================================
GETTING STARTED WITH AURIC ICONS: PLAYFUL
==============================================================================
Install Auric Icons: Playful, open the Icon Library and insert your first
emoji-style icon.
Area: VS Code extensions › Auric Icons: Playful   Updated: 2026-09-25

BEFORE YOU BEGIN
================

  - You need Visual Studio Code 1.85 or later, or an editor that keeps VS
    Code's extension features.
  - Everything works offline. There is no telemetry and no network access.

1. INSTALL
==========

Open the Extensions view (`Ctrl` + `Shift` + `X`), search for Auric Icons:
Playful and select Install, or run:

    code --install-extension auric-artisan.auric-icons-playful

2. OPEN THE ICON LIBRARY
========================

  - Select Auric Icons: Playful in the Activity Bar to open the Icon Library
    view, or
  - Run Auric Icons: Playful: Open Icon Library to open the larger Icon Studio
    — Library editor tab.

If Auric Artisan Icon Studio, Auric Icons: Modern or Auric Icons: Drawn is
also installed, the Playful view may be hidden because another extension shows
a merged library that already contains Playful. See Use Playful with Modern
and Drawn [merged-icon-studio.txt].

3. LOOK AROUND
==============

The view shows the icon count, up to four smart guide tips, Search, Category
and Style filters, the Variant buttons (Auto, Color, Outline, Filled, Small),
Preview surface (Auto, Light, Dark), the All, ✦ For you, ♥ Likes and ↺ Recent
chips, a ✦ Recommended for this file rail and the grid.

4. INSERT YOUR FIRST ICON
=========================

  1. Open a file and place the cursor.
  2. Choose Category › Reactions, or search for a word such as `celebrate`.
  3. Select Small if the icon will be shown at 16 to 24 pixels.
  4. Select Insert on a card. With smart insert on, the output suits your
     file: a JSX element in React, SVG markup in HTML, a CSS background in
     stylesheets.

Or press `Ctrl` + `Alt` + `I` (`Cmd` + `Alt` + `I` on macOS) in the editor,
search and choose.

RESULT
======

You have inserted a Playful icon, in the variant you chose, in a format that
suits your file.
