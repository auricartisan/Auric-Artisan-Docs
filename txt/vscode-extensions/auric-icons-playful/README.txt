==============================================================================
AURIC ICONS: PLAYFUL
==============================================================================
What the Auric Icons: Playful extension is, who it is for, how to install it
and where to find each guide.
Area: VS Code extensions › Auric Icons: Playful   Updated: 2026-09-25

Auric Icons: Playful is a library of 1,225 emoji-style SVG icons for VS Code:
warm, expressive artwork in 24 categories, from Reactions and Status to
Dashboard and Form Elements. Every icon comes in four variants: Color,
Outline, Filled and Small. The Small variant is a redrawing with simplified
detail for use at 16 to 24 pixels, not a scaled-down copy.

You browse the icons in an Icon Library view, search by name, concept,
description or synonym, and insert them into your code in a format that suits
the file. You can also copy icons in nine formats, save SVG files and preview
icon IDs by hovering over them in code.

Playful is a library only; it has no Explorer file icon theme. This collection
is different from the Playful Explorer style in Auric Artisan File Icons,
which is a separate set of 500 file and folder icons.

WHO IT IS FOR
=============

  - Designers and front-end developers building friendly, expressive
    interfaces, dashboards and admin panels.
  - Anyone who wants emoji-like artwork as real SVG they can style and ship.
  - Users of Auric Icons: Modern or Drawn who want a third style in the same
    library.

  Item:  Extension ID
  Value: `auric-artisan.auric-icons-playful`

  Item:  Requires
  Value: Visual Studio Code 1.85 or later, or a compatible editor built on it

  Value: Free to install and use

Playful is also installed by the Auric Artisan Icon Pack
[../auric-artisan-icon-pack/README.txt], and its artwork is included in Auric
Artisan Icon Studio [../auric-artisan-icon-studio/README.txt].

QUICK START
===========

  1. Install the extension.
  2. Open a file and place the cursor where an icon should go.
  3. Select Auric Icons: Playful in the Activity Bar to open the Icon Library.
  4. Search, for example `thumbs up`, or choose a category.
  5. Choose a variant: Auto, Color, Outline, Filled or Small.
  6. Select Insert on a card.

WHAT YOU CAN DO
===============

  - Search 1,225 icons in 24 categories with synonym-aware, fuzzy and
    personalised ranking.
  - Preview each icon in four variants on light or dark surfaces.
  - Insert with language-aware output at multiple cursors.
  - Copy in nine formats: raw SVG, JSX element, React component, Markdown
    image, CSS background, data URI, self-contained image tag, icon name and
    catalog path.
  - Save SVG files and open the SVG source.
  - Keep likes and recent icons, and get recommendations for the file you are
    editing.
  - Preview icon IDs on hover.
  - Merge with Modern and Drawn into one library when co-installed.
