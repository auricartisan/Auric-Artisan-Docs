User-facing history of Auric Artisan Icon Studio.
Area: VS Code extensions › Auric Artisan Icon Studio   Updated: 2026-09-25

0.1.0
=====

The first unified Icon Studio, and the current Marketplace version: Auric
artwork, third-party icon collections and emoji in one offline workspace.

Browse and discover
-------------------

  - Search 17,234 bundled entries across 11 collections: Auric Modern, Drawn
    and Playful, Emoji, Phosphor, Tabler, Lucide, Remix, Heroicons, Feather
    and Material.
  - Work in a compact sidebar or a full editor-tab Studio, with a sticky
    header, Library, For you, Likes and Recent chips, and a collapsible Refine
    library section with Reset filters.
  - Filter by collection, category, style and supported emoji skin tone.
  - Search by synonyms, including Hindi aliases, with progressive loading as
    you scroll.
  - Keep likes and recent items, with locally ranked For you recommendations.

Insert and export
-----------------

  - Language-aware output for JSX, JavaScript, markup, CSS, Markdown and data
    URIs.
  - Insert at multiple cursors, keeping continuation-line indentation.
  - Explicit copy formats and saving SVG artwork through a file dialog.
  - Emoji as characters, shortcodes, Unicode code points or HTML entities.
  - Font-backed Material glyphs through markup and CSS; no SVG output for
    them.

Editor workflow
---------------

  - Hover previews for Auric icon IDs, deferring to an installed owning
    collection extension.
  - Smart Insert with `Ctrl` + `Alt` + `I` and Insert from Recent with `Ctrl`
    + `Alt` + `R`.
  - `auricIconStudio.insertIcon` for a specific icon in a keybinding or macro.
  - Hosting of the Modern, Drawn and Playful libraries through
    `auricIconStudio.hostFamilyLibraries`, with the option to keep their
    separate views.

Offline and licensing
---------------------

  - Catalog, artwork and preview fonts bundled for offline use, with no
    network requests or telemetry.
  - Third-party attribution and licence texts included with their collections.
