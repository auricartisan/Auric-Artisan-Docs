==============================================================================
FREQUENTLY ASKED QUESTIONS
==============================================================================
Short answers to common questions about Auric Artisan Icon Studio.
Area: VS Code extensions › Auric Artisan Icon Studio   Updated: 2026-09-25

DO I NEED AURIC ICONS: MODERN, DRAWN OR PLAYFUL AS WELL?
========================================================

No. Icon Studio bundles all three collections. Install the separate extensions
only if you want their own interfaces, or Modern's Explorer file icon theme.

DOES ICON STUDIO CHANGE MY EXPLORER FILE ICONS?
===============================================

No. It is an artwork browser and insertion tool. For Explorer file and folder
icons, use Auric Artisan File Icons
[../../auric-artisan-file-icons/README.txt].

DOES IT NEED AN INTERNET CONNECTION?
====================================

No. The catalog, artwork and Material preview fonts are bundled. Icon Studio
makes no network requests.

IS IT THE SAME AS ICON HUB?
===========================

No. Icon Hub [../../auric-artisan-icon-hub/README.txt] covers the seven
open-source sets only, adds colour and stroke controls, sprite and ZIP export
and CDN insertion, and can check the website for catalog updates. Icon Studio
adds the Auric artwork and emoji and works entirely offline. See the
comparison [../others/related.txt].

CAN I CHANGE THE SIZE OR COLOUR OF INSERTED ICONS?
==================================================

Yes, through settings: `auricIconStudio.size`, `auricIconStudio.color` and
`auricIconStudio.strokeWidth`. See Insert, copy and save
[insert-copy-and-save.txt].

CAN I SEARCH IN HINDI?
======================

Many entries have Hindi search aliases. The interface itself is in English.

WHY DO MATERIAL ICONS NOT EXPORT AS SVG?
========================================

Material icons in this catalog are glyphs in a font, not SVG files. Icon
Studio offers HTML, JSX, React, JavaScript, CSS and ligature-name output
instead.

CAN I USE THE ARTWORK IN MY OWN PROJECTS?
=========================================

Auric artwork is covered by the Auric Artisan Free Use Licence, which
restricts extracting and redistributing artwork. Third-party icons keep their
own licences (MIT, ISC, Remix v1.0, Apache-2.0). Check the licence for your
use.

WHERE ARE MY LIKES STORED?
==========================

In VS Code's extension storage on this machine. See Privacy
[../others/privacy.txt].
