==============================================================================
SHORTCUTS AND COMMANDS
==============================================================================
Commands, context menus and in-Studio keys in Auric Artisan File Icons.
Area: VS Code extensions › Auric Artisan File Icons   Updated: 2026-09-25

File Icons has no default keybindings. Open Preferences: Open Keyboard
Shortcuts, search for "Auric Artisan File Icons" and assign keys to the
commands you use most, such as Insert Icon into Code… or Open File Icon
Studio.

KEYS INSIDE FILE ICON STUDIO
============================

  Key                       | Action
  --------------------------+--------------------------------------
  `/`                       | Focus the icon search
  `Arrow Up` / `Arrow Down` | Move through picker options
  `Home` / `End`            | First or last option
  `Escape`                  | Close an open picker or the inspector

COMMANDS
========

Type "Auric Artisan File Icons" in the Command Palette.

  Group:    Themes
  Commands: Activate Facet Icon Theme; Activate Playful Icon Theme; Activate
            Modern Icon Theme

  Group:    Studio
  Commands: Open File Icon Studio; Open File Icon Studio Settings; Insert Icon
            into Code…

  Group:    Appearance
  Commands: Choose Folder Color; Toggle Explorer Arrows; Restore Icon Defaults

  Group:    Associations
  Commands: Set File or Folder Icon; Clear Custom File or Folder Icon

  Group:    Smart detection
  Commands: Configure Smart Icon Detection; Refresh Smart Icon Matches;
            Explain Smart Icon Match; Toggle Smart Icon Detection; Apply
            Detected Folder Icon; Scan Workspace for Folder Icons

  Group:    Profiles
  Commands: Apply Icon Profile; Save Current Icon Profile; Delete Saved Icon
            Profile; Export Icon Profile to Clipboard; Import Icon Profile
            from Clipboard

  Group:    Other
  Commands: Show Icon Theme Diagnostics; Import Legacy Playful Settings…;
            Import Modern File Icon Settings…

CONTEXT MENUS
=============

  - Explorer: right-click › Auric File Icons submenu.
  - Editor: right-click › Insert Icon into Code….
