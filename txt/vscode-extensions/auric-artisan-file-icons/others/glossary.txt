==============================================================================
GLOSSARY
==============================================================================
Definitions of the terms used in Auric Artisan File Icons.
Area: VS Code extensions › Auric Artisan File Icons   Updated: 2026-09-25

  Term:    Association
  Meaning: A rule mapping an extension, filename, folder name or pattern to an
           icon ID.

  Term:    Badge
  Meaning: Up to two characters shown beside a resource in the Explorer by
           smart detection.

  Term:    Decoration
  Meaning: A badge, colour or tooltip VS Code adds to an Explorer item.

  Term:    Direct parent
  Meaning: The folder immediately containing a file or folder; `parent/name`
           patterns only match this.

  Term:    Exclusion
  Meaning: A folder name or pattern that smart detection never inspects.

  Term:    Facet
  Meaning: The faceted Explorer style with 500 SVGs.

  Term:    File icon theme
  Meaning: The set of icons VS Code shows beside files and folders. One is
           active at a time.

  Term:    Folder pair
  Meaning: The closed and open versions of one folder icon.

  Term:    Framework pack
  Meaning: Extra Modern associations for Angular, NestJS, React or Vue.

  Term:    Hover token
  Meaning: Text such as `:icon-file-typescript:` that a code hover can replace
           with artwork.

  Term:    Icon ID
  Meaning: The name of a shipped icon, such as `test` or `database`, used as
           an association value.

  Term:    Inspector
  Meaning: The dialog showing a card's exact code output.

  Term:    Modern
  Meaning: The Explorer style with 464 SVGs, shared with Auric Icons: Modern's
           theme ID.

  Term:    Playful
  Meaning: The Explorer style with 500 SVGs and its own palette. Not the Auric
           Icons: Playful library.

  Term:    Profile
  Meaning: A named, portable set of appearance, association and smart
           detection settings.

  Term:    Root association
  Meaning: An icon for a workspace root folder, by name.

  Term:    Smart detection
  Meaning: Content-aware classification of folders and small files, shown as
           decorations.
