==============================================================================
FREQUENTLY ASKED QUESTIONS
==============================================================================
Short answers to common questions about Auric Artisan File Icons.
Area: VS Code extensions › Auric Artisan File Icons   Updated: 2026-09-25

DO I NEED ANOTHER ICON EXTENSION?
=================================

No. All three styles and their artwork are included.

CAN I USE TWO STYLES AT ONCE?
=============================

No. VS Code allows one file icon theme at a time. Switch whenever you like.

WHY DO CHANGES NEED A RELOAD?
=============================

VS Code caches icon themes. The extension rebuilds the theme when you change
appearance or associations; a reload shows the new icons.

DOES SMART DETECTION CHANGE THE ICON ITSELF?
============================================

No. It adds a badge, colour and explanation on top. Use Apply Detected Folder
Icon or Scan Workspace for Folder Icons to make a detected icon permanent.

DOES IT RUN MY PROJECT'S CODE?
==============================

No. Smart detection reads a bounded number of names and the start of small
text files. It never executes anything.

CAN I USE THE ICONS IN MY OWN PROJECTS?
=======================================

You can insert them into code from the Studio. The artwork is covered by the
Auric Artisan Free Use Licence, which restricts redistribution, resale,
republishing and extracting bundled artwork. Review it before reusing artwork
outside the extension.

IS THE PLAYFUL STYLE THE SAME AS AURIC ICONS: PLAYFUL?
======================================================

No. They are different artwork. See Modern and older Playful settings
[modern-and-legacy.txt].

HOW IS THIS DIFFERENT FROM ICON STUDIO?
=======================================

File Icons changes your Explorer and offers its own file-type artwork for
code. Auric Artisan Icon Studio is a general icon and emoji browser and does
not change the Explorer. See the comparison [../others/related.txt].
