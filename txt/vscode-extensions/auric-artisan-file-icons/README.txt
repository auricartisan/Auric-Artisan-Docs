==============================================================================
AURIC ARTISAN FILE ICONS
==============================================================================
What the Auric Artisan File Icons extension is, who it is for, how to install
it and where to find each guide.
Area: VS Code extensions › Auric Artisan File Icons   Updated: 2026-09-25

Auric Artisan File Icons gives the VS Code Explorer a consistent set of file
and folder icons in three styles: Facet, Playful and Modern. Each style is a
separate VS Code file icon theme, so you choose one for your Explorer and can
switch at any time. Together they contain 1,464 SVG assets.

The extension adds File Icon Studio, available as a sidebar and as an editor
tab. In its Library you search the artwork of all three styles and insert an
icon into your code as inline SVG, JSX, an HTML image or a CSS background. In
Appearance you recolour files and folders, adjust saturation, brightness and
opacity, hide the Explorer arrows and choose a framework pack for Modern. In
Workspace you manage smart detection, profiles, code hovers and settings
imports.

Smart detection adds a small badge, a category colour and an explanation to
recognised folders and files, for example a React project folder or a
generated file. You can also assign any icon to a specific file or folder from
the Explorer's right-click menu, and insert icons into code by hovering over
tokens such as `:icon-file-typescript:`.

WHO IT IS FOR
=============

  - Developers who want a distinctive, consistent Explorer and control over
    its colours.
  - Teams who want project folders marked by type (framework, language,
    infrastructure, tests, docs).
  - Front-end developers who want to reuse file-type artwork in their own
    code.

QUICK START
===========

  1. Install the extension.
  2. Run Auric Artisan File Icons: Open File Icon Studio, or select Auric File
     Icons in the Activity Bar.
  3. In Artwork style, choose Facet, Playful or Modern. The Library shows that
     style's artwork.
  4. Select Use Facet in Explorer (the button names the style you chose). Your
     Explorer switches to that theme.
  5. Open the Appearance tab, pick a Folder color, and select Apply
     appearance. Reload the window if asked.
  6. Right-click a folder in the Explorer, open Auric File Icons and choose
     Set File or Folder Icon to give it a specific icon.
  7. To use an icon in code, open a writable file, search in Library, choose a
     Code format and select Insert on a card.

WHAT YOU CAN DO
===============

  - Choose one of three Explorer themes: Auric Artisan File Icons: Facet,
    Playful or Modern.
  - Recolour file and folder icons independently and adjust saturation,
    brightness and opacity.
  - Apply a ready-made profile (Classic Facet, Vivid Studio, Focused Explorer,
    Graphite Mono, High Visibility, Minimal) or save your own.
  - Map extensions, filenames, folder names, parent-scoped names and workspace
    roots to icons.
  - See smart badges, colours and explanations on recognised project folders
    and files, and turn a detected folder type into a permanent icon.
  - Insert or copy artwork as inline SVG, JSX, an HTML image or a CSS
    background, from the Studio, a native picker or a code hover.
  - Choose a Modern framework pack: Angular, NestJS, React or Vue.
  - Import settings from the older standalone Playful extension or from Auric
    Icons: Modern.
