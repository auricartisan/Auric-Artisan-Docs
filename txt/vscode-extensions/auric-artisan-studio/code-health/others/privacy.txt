==============================================================================
AURIC CODE HEALTH PRIVACY
==============================================================================
What Auric Code Health stores and writes, how it protects secrets, and when it
uses the network.
Area: VS Code extensions › Auric Artisan Studio › Auric Code Health   Updated: 2026-09-25

Auric Code Health analyses your code on your machine. It sends no code,
findings or telemetry anywhere and needs no account. The bundled command-line
scanner makes no network requests either.

SECRETS ARE NEVER STORED
========================

When it finds a secret, only a note with its length (`[redacted secret; 40
characters]`) is kept. The secret itself never reaches the editor hover, the
Problems panel, the Studio, the scan cache, `health.json`, SARIF, the history,
the project health report or the remediation plan. See Secrets and redaction
[../docs/secrets-and-redaction.txt].

WHAT IT WRITES
==============

  Where: `.auric-artisan/` in your workspace
  What:  The scan cache, a settings copy, `health.json`, `health.sarif`,
         `health-history.json`, the project health report, the remediation
         plan and the knowledge files

  Where: Your settings
  What:  The accent colour (user settings) and values you save in Studio ›
         Settings (workspace settings)

  Where: VS Code's storage for the extension
  What:  Dismissed suggestions and collapsed Studio sections

The health record includes your current Git branch and commit, read from the
`.git` folder. Review records before sharing them outside your team: they
contain file paths and messages, never secret values.

WHEN THE NETWORK IS USED
========================

Only when you open a link yourself, such as auricartisan.com or an official
source in the knowledge database.

See the Studio privacy page [../../others/privacy.txt] for details.
