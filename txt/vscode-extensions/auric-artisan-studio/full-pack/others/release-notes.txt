0.1.0 — INITIAL STUDIO RELEASE
==============================

  - The first public release of the Full Pack.
  - Installs only the three Studio extensions: Auric Color, Auric
    Accessibility and Auric Code Health. Icon themes and icon libraries are
    not part of the pack.
  - Each member stays independently installable, updatable and removable.
