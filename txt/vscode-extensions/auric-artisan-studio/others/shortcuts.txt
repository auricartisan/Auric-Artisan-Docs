KEYBOARD SHORTCUTS
==================

  Windows and Linux: `Ctrl` + `Alt` + `.`
  macOS:             `Cmd` + `Alt` + `.`
  Command:           Workstation: Command Center
  Extension:         All three code extensions

  Windows and Linux: `Ctrl` + `Alt` + `C`
  macOS:             `Cmd` + `Alt` + `C`
  Command:           Pick / edit color (editor focused)
  Extension:         Auric Color

  Windows and Linux: `Ctrl` + `Alt` + `A`
  macOS:             `Cmd` + `Alt` + `A`
  Command:           Inspect Accessibility of Element (editor focused)
  Extension:         Auric Accessibility

These VS Code shortcuts are useful with the Studio:

  Keys:         `Ctrl` + `.`
  What it does: Show quick fixes for the underline at the cursor

  Keys:         `Ctrl` + `Shift` + `P`
  What it does: Open the Command Palette; type `Auric Artisan` to list every
                Studio command

  Keys:         `Ctrl` + `Shift` + `M`
  What it does: Open the Problems panel

  Keys:         `Ctrl` + `Z`
  What it does: Undo a fix, including a whole Fix All Contrast Issues in File

KEYS INSIDE THE STUDIO
======================

  Keys:         Arrow keys, `Home`, `End`
  Where:        Studio rail and tab rows
  What it does: Move between spaces or tools

  Keys:         `/`
  Where:        Findings and Health
  What it does: Focus the search box

  Keys:         `Escape`
  Where:        Studio
  What it does: Close a picker, menu or tooltip, then clear the search

  Keys:         `Enter`, `Space`
  Where:        Swatches, rows, tiles
  What it does: Activate

  Keys:         Arrow keys, `Shift` + arrows, `Page Up`, `Page Down`, `Home`,
                `End`
  Where:        Colour picker bars and spectrum
  What it does: Adjust the colour

  Keys:         `Escape`
  Where:        Colour picker
  What it does: Close it

See Accessibility of the Studio [../docs/studio-accessibility.txt] for more.

CHANGE A SHORTCUT
=================

  1. Open File › Preferences › Keyboard Shortcuts (`Ctrl` + `K`, `Ctrl` +
     `S`).
  2. Search for the command title, for example Workstation: Command Center.
  3. Double-click the entry and press the new keys.

When several Studio extensions are installed, only the host's Command Center
shortcut is active; the others are switched off automatically.
