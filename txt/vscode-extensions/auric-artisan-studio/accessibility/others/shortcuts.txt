KEYBOARD SHORTCUTS
==================

  Windows and Linux: `Ctrl` + `Alt` + `A`
  macOS:             `Cmd` + `Alt` + `A`
  Command:           Inspect Accessibility of Element (editor focused)

  Windows and Linux: `Ctrl` + `Alt` + `.`
  macOS:             `Cmd` + `Alt` + `.`
  Command:           Workstation: Command Center

  Windows and Linux: `Ctrl` + `.`
  macOS:             `Cmd` + `.`
  Command:           VS Code's quick fixes, including Ignore this WCAG …
                     finding here

  Windows and Linux: `Ctrl` + `Shift` + `M`
  macOS:             `Cmd` + `Shift` + `M`
  Command:           VS Code's Problems panel

COMMAND PALETTE TITLES
======================

Type `Auric Artisan` in the Command Palette:

  - Auric Artisan: Open Accessibility Studio
  - Auric Artisan: Workstation: Command Center
  - Auric Artisan: Open Rulebook & Knowledge Database
  - Auric Artisan: Build Workspace Knowledge Database (JSON + Markdown)
  - Auric Artisan: Open Unified Icon Studio
  - Auric Artisan: Scan Project for Accessibility (Use Cache)
  - Auric Artisan: Force Rescan Project and Refresh Cache
  - Auric Artisan: Generate Agent-Ready Remediation Plan
  - Auric Artisan: Clear Workspace Scan Cache
  - Auric Artisan: Search Accessibility Issues
  - Auric Artisan: Group Accessibility Issues (Type / File / Severity)
  - Auric Artisan: Clear Accessibility Issue Search
  - Auric Artisan: Check Contrast of Selection
  - Auric Artisan: Inspect Accessibility of Element
  - Auric Artisan: Mark Line as Intentional Branding (Toggle)

Open WCAG Documentation and Open Issue in Contrast Studio are row buttons in
the Project Issues view, not palette commands.

IN THE STUDIO
=============

  Keys             | Where             | What it does
  -----------------+-------------------+-------------------------------------
  `/`              | Findings          | Focus the search box
  `Escape`         | Findings          | Close pop-ups, then clear the search
  `Enter`, `Space` | A finding row     | Open the file at that line
  Arrow keys       | Rail and tab rows | Move between spaces and tools

For every Studio key, see the Studio shortcuts [../../others/shortcuts.txt].
