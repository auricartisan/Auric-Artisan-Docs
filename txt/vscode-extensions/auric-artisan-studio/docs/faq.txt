==============================================================================
FAQ
==============================================================================
Short answers to common questions about Auric Artisan Studio as a whole.
Area: VS Code extensions › Auric Artisan Studio   Updated: 2026-09-25

Is Auric Artisan Studio free?
-----------------------------

Yes. There is no account, API key or paid tier; every feature is included. The
extensions are licensed under the Auric Artisan Free Use Licence 2.0: free to
use for any purpose, personal or commercial, but not to redistribute,
republish or resell.

Does it send my code anywhere?
------------------------------

No. All analysis runs on your machine, the extensions make no network requests
and collect no telemetry. The only links that leave VS Code are ones you
choose to open, such as auricartisan.com or a W3C documentation page. See
Privacy [../others/privacy.txt].

Do I need all three extensions?
-------------------------------

No. Each works on its own. Install the Full Pack if you want colour,
accessibility and code health together; otherwise pick the one you need. See
Choose what to install [choosing-an-install.txt].

Why is there only one sidebar when I install several?
-----------------------------------------------------

The extensions combine into one Workstation, so you get one Overview, one
Command Center and one Studio instead of three copies. See The Workstation
[workstation.txt].

Is the remediation plan made by AI?
-----------------------------------

No. It is generated by fixed rules from your scan, on your machine, with no
model call. It contains a prompt you can give to a coding agent of your own,
if you want to. See The remediation plan [remediation-plan.txt].

Are the suggestions AI-powered?
-------------------------------

No. They come from six fixed rules, each checking one fact from your scan or
open file. See The suggestion rules [command-center.txt].

Does a score of 100 mean my site is accessible?
-----------------------------------------------

No. The score covers only what static analysis can see in source code. Many
WCAG requirements need a person to test with a keyboard, a screen reader, zoom
and real content. Use the score to prioritise, and the manual checks
[../accessibility/docs/manual-evidence.txt] for the rest.

Does it run my code or render my pages?
---------------------------------------

No. It reads source text. It does not execute scripts, run a browser or
compute the final CSS cascade. See Limits and accuracy
[../others/limits-and-accuracy.txt].

Which languages are supported?
------------------------------

Colour hovers and code-health checks cover more than 40 languages. Contrast
checks run in CSS-family, markup, JavaScript, TypeScript and Markdown files.
WCAG rules run in HTML, JSX, TSX, Vue, Svelte, Astro, PHP, XML, template
dialects and CSS-family files. See Scanning [scanning.txt].

Can I use it in CI?
-------------------

Yes. The bundled `auric-artisan` command-line scanner produces the same
findings, writes `health.json` and SARIF, and fails a build on new issues
against a baseline. See The CI gate [ci-gate.txt].

Where does it store data?
-------------------------

In a `.auric-artisan` folder at the root of your workspace, plus your VS Code
settings. See The .auric-artisan folder [scanning.txt].

Should I commit the .auric-artisan folder?
------------------------------------------

Commit `settings.json` if you want to share team defaults and
`knowledge-overrides.json` for reviewed team guidance. The bundled
`.gitignore` keeps everything else out, because it is regenerated.

Does it work in multi-root workspaces?
--------------------------------------

Yes. Every folder is scanned and can have its own `.auricignore`. The
`.auric-artisan` folder is created in the first folder of the workspace.

Does it work over Remote SSH, WSL or dev containers?
----------------------------------------------------

The extensions run wherever VS Code runs your workspace's extensions, so they
can read the remote files. They do not run in VS Code for the Web.

Can I turn off one kind of check?
---------------------------------

Yes: `contrast.enabled`, `a11y.enabled`, `codeHealth.enabled` and each
`codeHealth.<category>` switch. The first two control the in-editor
diagnostics; project scans still grade contrast and WCAG. See Reference
[reference.txt].

Can I ignore a finding?
-----------------------

Yes, with an `auric-disable-…` comment or the Ignore quick fix. Deliberate
brand colours can be marked with `auric-brand-…` instead. See Suppression and
branding [suppression-and-branding.txt].

How do I change the gold colour?
--------------------------------

Studio › Settings › Appearance, or Auric Artisan: Change Accent Color (Theme
the Studio). See Appearance [appearance.txt].

Where are the release notes?
----------------------------

In Release notes [../others/release-notes.txt], taken from the changelog that
ships with the extensions.
