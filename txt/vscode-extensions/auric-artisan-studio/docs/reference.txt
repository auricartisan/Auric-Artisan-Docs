KEYBINDINGS
===========

  Keys (Windows, Linux): `Ctrl` + `Alt` + `.`
  Keys (macOS):          `Cmd` + `Alt` + `.`
  Command:               Workstation: Command Center
  Extensions:            All three
  Active when:           The extension is not suppressed by a Workstation host

  Keys (Windows, Linux): `Ctrl` + `Alt` + `C`
  Keys (macOS):          `Cmd` + `Alt` + `C`
  Command:               Pick / edit color
  Extensions:            Auric Color
  Active when:           The editor has focus

  Keys (Windows, Linux): `Ctrl` + `Alt` + `A`
  Keys (macOS):          `Cmd` + `Alt` + `A`
  Command:               Inspect Accessibility of Element
  Extensions:            Auric Accessibility
  Active when:           The editor has focus

To rebind them, open File › Preferences › Keyboard Shortcuts and search for
the command title.

What each command does:

  Command:      Workstation: Command Center
  What it does: Opens the Command Center list. See The Command Center
                [command-center.txt].

  Command:      Open … Studio
  What it does: Opens the Studio tab, or the Workstation host's Studio. See
                The Studio [studio.txt].

  Command:      Open Rulebook & Knowledge Database
  What it does: Searches the local knowledge database.

  Command:      Build Workspace Knowledge Database (JSON + Markdown)
  What it does: Writes `knowledge.json`, `rulebook.md` and an overrides
                template.

  Command:      Open Unified Icon Studio
  What it does: Opens the combined Auric icon library.

  Command:      Pick / edit color
  What it does: Opens the colour picker on the colour under the cursor, or
                inserts a new colour.

  Command:      Generate Accessible Palette
  What it does: Opens Studio › Color › Palette seeded with the selected
                colour.

  Command:      Check Contrast of Selection
  What it does: Opens the Contrast Studio with the selected colour as the text
                colour.

  Command:      Fix All Contrast Issues in File
  What it does: Previews and applies a fix for every failing pair in the file,
                as one undoable edit.

  Command:      Choose Color Picker Mode
  What it does: Chooses between the Auric picker and VS Code's native picker.

  Command:      Disable native color picker (use Auric Artisan)
  What it does: Switches to the Auric picker and turns VS Code's colour
                decorators off.

  Command:      Restore native color picker (use VS Code's)
  What it does: Hands colour picking back to VS Code's native picker.

  Command:      Refresh Contrast Diagnostics
  What it does: Re-checks every open file.

  Command:      Change Accent Color (Theme the Studio)
  What it does: Picks the Studio's accent colour.

  Command:      Mark Line as Intentional Branding (Toggle)
  What it does: Adds or removes an `auric-brand-line` comment on the current
                lines.

  Command:      Inspect Accessibility of Element
  What it does: Shows the Inspect card for the element or CSS rule at the
                cursor.

  Command:      Scan Project for Accessibility (Use Cache)
  What it does: Scans the workspace, reusing a fresh cache.

  Command:      Force Rescan Project and Refresh Cache
  What it does: Scans the workspace from disk and rewrites the cache.

  Command:      Generate Agent-Ready Remediation Plan
  What it does: Writes the local, deterministic remediation plan.

  Command:      Clear Workspace Scan Cache
  What it does: Deletes `scan-cache.json`.

  Command:      Search Accessibility Issues
  What it does: Filters the Project Issues view by text.

  Command:      Group Accessibility Issues (Type / File / Severity)
  What it does: Changes how the Project Issues view is grouped.

  Command:      Clear Accessibility Issue Search
  What it does: Removes the Project Issues filter.

  Command:      Open WCAG Documentation
  What it does: Opens the W3C Understanding page for a finding's success
                criterion.

  Command:      Open Issue in Contrast Studio
  What it does: Opens a contrast or colour-vision finding in the Contrast
                Studio, linked to its line.

  Command:      Generate Project Health Report (Color, A11y & Code Health)
  What it does: Writes the Markdown, JSON and HTML project health report.

  Command:      Write Health Record (health.json + SARIF)
  What it does: Writes `health.json`, SARIF and history.

  Command:      Open Workspace Data Folder
  What it does: Shows the `.auric-artisan` folder in your file manager.

Shared settings
---------------

The installed extensions share one `.auric-artisan` folder, so settings that
shape it must mean the same thing to every extension. For these keys, each
extension reads the first value it finds set (in any scope: user, workspace or
folder), looking first under `auricCodeHealth.`, then `auricA11y.`, then
`auricColor.`:

  - `data.enabled`, `data.folderName`
  - `scan.cache.enabled`, `scan.cache.maxAgeMinutes`, `scan.autoScan`,
    `scan.autoScanOnStartup`, `scan.autoScanDelayMs`, `scan.maxFiles`,
    `scan.exclude`, `scan.live`
  - every `codeHealth.` key
  - `health.formats`, `health.fileName`, `health.historyLimit`,
    `health.writeOnScan`

The simplest approach is to set each of these once, under one prefix. The
Studio's Settings space writes a shared key to wherever its current value is
set, so its edits always take effect.

The other settings are read by the extension that owns the feature: colour
picker and hover settings by Auric Color; Inspect and profile settings by
Auric Accessibility; contrast settings by Auric Accessibility when it is
installed, otherwise by Auric Color; and the accent by the extension that
hosts the Studio.

In a multi-root workspace, scan and data settings can be set per workspace
folder; the accent is always stored in your user settings.

DIAGNOSTICS
===========

All findings in the Problems panel have the source `auric-artisan`.

  Finding:           Low contrast
  Problems severity: `contrast.severity` (warning by default); information
                     when the background was assumed
  Code shown:        `low-contrast`

  Finding:           Low APCA contrast
  Problems severity: Same as low contrast
  Code shown:        `apca-low`

  Finding:           Colour-vision risk
  Problems severity: Hint
  Code shown:        `cvd-risk`

  Finding:           Branding
  Problems severity: Information
  Code shown:        `branding:contrast`, `branding:apca` or `branding:cvd`

  Finding:           WCAG, critical or serious
  Problems severity: Warning
