==============================================================================
FREQUENTLY ASKED QUESTIONS
==============================================================================
Short answers to common questions about Auric Icons: Drawn.
Area: VS Code extensions › Auric Icons: Drawn   Updated: 2026-09-25

WHY IS THERE NO FILE ICON THEME?
================================

Drawn's icons are 64-pixel illustrations. They do not have the paired 16-pixel
folder shapes and file associations a good Explorer theme needs. Install Auric
Icons: Modern for the family's Explorer theme.

DO I NEED MODERN OR PLAYFUL TOO?
================================

No. Drawn works alone. Installing them together gives you one merged library.

IS DRAWN INCLUDED IN ICON STUDIO?
=================================

Yes. Auric Artisan Icon Studio bundles the Drawn collection, so you do not
need this extension to use Drawn artwork there.

IS IT FREE?
===========

Yes, free to use for any purpose. Redistribution and resale are not permitted.

DOES IT WORK OFFLINE?
=====================

Yes. There is no network access or telemetry.

CAN I CHANGE ICON SIZE OR COLOUR ON INSERT?
===========================================

Not in this extension; icons are inserted as drawn. Auric Artisan Icon Studio
has size and colour output settings.

WHERE ARE MY LIKES KEPT?
========================

In VS Code's storage for this extension on your machine. They stay with Drawn
even when another extension hosts the merged library.
