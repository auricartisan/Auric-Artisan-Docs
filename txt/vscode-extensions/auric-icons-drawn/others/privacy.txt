What Auric Icons: Drawn stores, where, and confirmation that it makes no
network requests.
Area: VS Code extensions › Auric Icons: Drawn   Updated: 2026-09-25

Auric Icons: Drawn runs entirely inside VS Code. It has no telemetry, no
account and no network access at runtime.

  Data:  Settings
  Where: Your VS Code settings under `auricIconsDrawn.library.*`.

  Data:  Likes (up to 500), recent icons (up to 60), learned preferences,
         dismissed tips
  Where: VS Code's extension storage on this machine.

  Data:  Search, filters, variant and preview surface
  Where: The view's saved state in VS Code.

For recommendations and smart insert, the extension reads the language, file
name and up to about 60 lines around the cursor of the active editor. This
stays in memory and is never stored or sent.

Inserting changes your editor content, copying writes to the clipboard, and
saving writes a file only where you choose in a save dialog.
