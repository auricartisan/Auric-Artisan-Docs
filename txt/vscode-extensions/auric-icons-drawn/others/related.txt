HOW THE THREE COLLECTIONS MERGE
===============================

  - Install Drawn with Modern and/or Playful and one extension hosts a single
    merged library, with a Library filter, collection badges and every
    collection's variants. See Use Drawn with Modern and Playful
    [../docs/merged-icon-studio.txt].
  - Install Auric Artisan Icon Studio and, by default, it hosts all three
    instead.
  - Likes and recent icons stay with the extension that owns each icon.
