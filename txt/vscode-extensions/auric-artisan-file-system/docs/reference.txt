REFERENCE: COMMANDS, KEYS AND SETTINGS
==============================================================================
Every Auric Artisan File System command grouped as the product groups them,
every keyboard shortcut, menu and setting, with types, defaults and ranges.
Area: VS Code extensions › Auric Artisan File System   Updated: 2026-09-25

This page covers Auric Artisan File System 0.1.0: 81 commands, 69 keyboard
shortcut declarations, one Explorer view and 48 settings. Commands appear in
the Command Palette with the Auric Files: prefix.

COMMANDS
========

Commands are grouped as the workspace panel groups them. The Keys column gives
Windows and Linux keys. (Explorer) keys work whenever the Explorer has focus.
(deck) keys need `auricFiles.keyboard.enableDefaultShortcuts`. On macOS, `Cmd`
replaces `Ctrl` in every shortcut, except Redo File Operation, which is `Cmd`
+ `Alt` + `Shift` + `Z`. "Then" means press the first combination, release,
then press the second.

Commands marked "not in the Command Palette" act on a selection and run from
the panel, context menus or shortcuts.

EXPLORER BADGES
===============

  Badge       | Meaning
  ------------+----------------------------------------------
  ●           | Highlighted
  ★           | Favourite
  P           | Pinned
  H           | Hidden (excluded from the native Explorer)
  Two letters | The first two letters of the item's first tag
  W           | A member of a group

When an item has several marks, the first in this list is shown.

SETTINGS
========

All 48 settings, grouped by area. They can be set in user or workspace
settings.

Explorer, sorting and indexing
------------------------------

  Setting:         `auricFiles.explorer.sort`
  Type:            string
  Default:         `name`
  Values or range: `name`, `path`, `type`, `size`, `modified`, `created`,
                   `extension`, `status`, `custom`
  What it does:    Primary order for Auric's indexed pickers. Orders VS Code
                   supports are also applied to its Explorer.

  Setting:         `auricFiles.explorer.sortDirection`
  Type:            string
  Default:         `asc`
  Values or range: `asc`, `desc`
  What it does:    Direction the chosen sort runs in — ascending puts A, the
                   smallest and the oldest first.

  Setting:         `auricFiles.explorer.secondarySort`
  Type:            string
  Default:         `none`
  Values or range: `none`, `name`, `path`, `type`, `size`, `modified`,
                   `created`, `extension`, `status`, `custom`
  What it does:    Optional second sort key used when two entries have the
                   same primary value.

  Setting:         `auricFiles.explorer.secondarySortDirection`
  Type:            string
  Default:         `asc`
  Values or range: `asc`, `desc`
  What it does:    Direction for the secondary sort key.

  Setting:         `auricFiles.explorer.grouping`
  Type:            string
  Default:         `none`
  Values or range: `none`, `type`, `extension`, `folder`, `tag`, `modified`,
                   `status`
  What it does:    Headings used by Auric's indexed grouped-file picker.

  Setting:         `auricFiles.explorer.foldersFirst`
  Type:            boolean
  Default:         `true`
  Values or range: -
  What it does:    Keep directories above files no matter which sort is
                   active.

  Setting:         `auricFiles.explorer.showHiddenFiles`
  Type:            boolean
  Default:         `false`
  Values or range: -
  What it does:    Include dot-files and metadata-hidden entries in Auric
                   search and filter results.

  Setting:         `auricFiles.explorer.showFileSize`
  Type:            boolean
  Default:         `false`
  Values or range: -
  What it does:    Show a size beside each file in Auric's file lists. Costs
                   one file check per entry on large trees.

  Setting:         `auricFiles.explorer.showGitStatus`
  Type:            boolean
  Default:         `true`
  Values or range: -
  What it does:    Read Git state for filtering and Git-aware safety warnings.

  Setting:         `auricFiles.explorer.previewOnSingleClick`
  Type:            boolean
  Default:         `true`
  Values or range: -
  What it does:    Open a single click in a reusable preview tab. Off, a
                   double click is needed to open anything.

  Setting:         `auricFiles.explorer.maxNodes`
  Type:            number
  Default:         `20000`
  Values or range: 500–200000
  What it does:    Most entries held in one scan. Reaching it stops the scan
                   and marks the index as truncated.

  Setting:         `auricFiles.explorer.excludePatterns`
  Type:            array
  Default:         see "Long default values"
  Values or range: -
  What it does:    Globs skipped while scanning. Matches are never indexed,
                   searched, compared or batch-processed.

  Setting:         `auricFiles.explorer.respectGitignore`
  Type:            boolean
  Default:         `true`
  Values or range: -
  What it does:    Read the workspace .gitignore and skip whatever it
                   excludes, on top of the patterns above.

  Setting:         `auricFiles.create.testFramework`

Safety, trash and history
-------------------------

  Setting:         `auricFiles.safety.confirmDelete`
  Type:            boolean
  Default:         `true`
  Values or range: -
  What it does:    Ask before anything is deleted, listing what goes and where
                   it lands.

  Setting:         `auricFiles.safety.confirmBulk`
  Type:            number
  Default:         `5`
  Values or range: 0–no maximum
  What it does:    Ask for confirmation once an operation touches this many
                   paths. `0` asks every time.

  Setting:         `auricFiles.safety.useWorkspaceTrash`
  Type:            boolean
  Default:         `true`
  Values or range: -
  What it does:    Move deleted items to `.auric/trash` in the workspace so
                   they can be restored.

  Setting:         `auricFiles.safety.trashRetentionDays`
  Type:            number
  Default:         `14`
  Values or range: 1–365
  What it does:    How long a trashed entry survives before it is purged
                   automatically.

  Setting:         `auricFiles.safety.trashMaxBytes`
  Type:            number
  Default:         `268435456`
  Values or range: 0–no maximum
  What it does:    Size limit for the workspace trash in bytes (256 MiB). The
                   oldest entries are purged first.

  Setting:         `auricFiles.safety.protectedPaths`
  Type:            array
  Default:         see "Long default values"
  Values or range: -
  What it does:    Globs no Auric operation may rename, move or delete. A plan
                   touching one is blocked before any change.

  Setting:         `auricFiles.safety.warnOnGitTracked`
  Type:            boolean
  Default:         `true`
  Values or range: -
  What it does:    Warn when a file about to be deleted or moved is tracked by
                   Git.

  Setting:         `auricFiles.safety.warnOnUncommittedChanges`
  Type:            boolean
  Default:         `true`
  Values or range: -
  What it does:    Warn when a file about to be deleted or moved has
                   uncommitted edits.

  Setting:         `auricFiles.safety.previewBeforeApply`
  Type:            boolean
  Default:         `true`
  Values or range: -
  What it does:    Show the full before-and-after list of a batch rename or
                   move, with conflicts, and require approval.

  Setting:         `auricFiles.safety.historyLimit`
  Type:            number
  Default:         `200`
  Values or range: 10–2000
  What it does:    How many past operations stay undoable. Older entries drop
                   off the end of the stack.

Search and duplicates
---------------------

  Setting:         `auricFiles.search.defaultMode`
  Type:            string
  Default:         `glob`
  Values or range: `glob`, `regex`, `fuzzy`
  What it does:    How a filter's search text is read: `glob` wildcards,
                   `regex` regular expression, or `fuzzy` matching.

  Setting:         `auricFiles.search.caseSensitive`
  Type:            boolean
  Default:         `false`
  Values or range: -
  What it does:    Match letter case exactly. Off, a search for button also
                   finds Button.tsx.

  Setting:         `auricFiles.search.maxResults`
  Type:            number
  Default:         `2000`
  Values or range: 50–50000
  What it does:    Matches kept by one search before it stops and reports a
                   partial result.

  Setting:         `auricFiles.search.duplicateStrategy`
  Type:            string
  Default:         `content`
  Values or range: `content`, `name`, `size`
  What it does:    What counts as a duplicate: `content` (same bytes), `name`
                   (same file name) or `size` (same length).

Performance
-----------

  Setting:         `auricFiles.performance.watchWorkspace`
  Type:            boolean
  Default:         `true`
  Values or range: -
  What it does:    After the first indexed command, follow file changes and
                   update the index. Turn off on slow network shares.

  Setting:         `auricFiles.performance.scanConcurrency`
  Type:            number
  Default:         `8`
  Values or range: 1–64
  What it does:    Folders read at once while indexing. Raise on a fast local
                   disk, lower on a remote file system.

  Setting:         `auricFiles.performance.debounceMs`
  Type:            number
  Default:         `120`
  Values or range: 0–2000
  What it does:    Quiet period after the last file change before the index
                   updates.

Enumerated values explained
---------------------------

  Setting: `auricFiles.explorer.sort`
  Value:   `name`
  Meaning: Alphabetical, natural order, so `file10` follows `file9`

  Setting: `auricFiles.explorer.sort`
  Value:   `path`
  Meaning: By the full workspace-relative path

  Setting: `auricFiles.explorer.sort`
  Value:   `type`
  Meaning: Folders, files and links in that order, then by name

  Setting: `auricFiles.explorer.sort`
  Value:   `size`
  Meaning: Largest first when descending; folders keep name order

  Setting: `auricFiles.explorer.sort`
  Value:   `modified`
  Meaning: Most recently written first when descending

  Setting: `auricFiles.explorer.sort`
  Value:   `created`
  Meaning: Creation time, where recorded

  Setting: `auricFiles.explorer.sort`
  Value:   `extension`
  Meaning: By extension, then by name

  Setting: `auricFiles.explorer.sort`
  Value:   `status`
  Meaning: Conflicts and changed Git files first, then clean and ignored

  Setting: `auricFiles.explorer.sort`
  Value:   `custom`
  Meaning: A stored custom rank; unranked items follow by name

  Setting: `auricFiles.explorer.grouping`
  Value:   `none`
  Meaning: One continuous list

  Setting: `auricFiles.explorer.grouping`
  Value:   `type`
  Meaning: Folders, files and links under separate headings

  Setting: `auricFiles.explorer.grouping`
  Value:   `extension`
  Meaning: One heading per extension

  Setting: `auricFiles.explorer.grouping`
  Value:   `folder`
  Meaning: One heading per parent folder

  Setting: `auricFiles.explorer.grouping`
  Value:   `tag`
  Meaning: One heading per tag; untagged last

  Setting: `auricFiles.explorer.grouping`
  Value:   `modified`
  Meaning: Today, this week, this month and older

  Setting: `auricFiles.explorer.grouping`
  Value:   `status`
  Meaning: Changed, untracked, conflicted, clean and ignored

  Setting: `auricFiles.search.defaultMode`
  Value:   `glob`
  Meaning: Wildcards over the path

  Setting: `auricFiles.search.defaultMode`
  Value:   `regex`
  Meaning: A regular expression tested against the path

  Setting: `auricFiles.search.defaultMode`
  Value:   `fuzzy`
  Meaning: Loose matching ranking the closest paths first

  Setting: `auricFiles.search.duplicateStrategy`
  Value:   `content`
  Meaning: Same bytes; files are bucketed by size first

  Setting: `auricFiles.search.duplicateStrategy`
  Value:   `name`
  Meaning: Same file name in different folders

  Setting: `auricFiles.search.duplicateStrategy`
  Value:   `size`
  Meaning: Same length; fastest and loosest

  Setting: `auricFiles.logLevel`
  Value:   `off`, `error`, `warn`, `info`, `debug`
  Meaning: Nothing, failures, skips too, one line per operation, per-step
           detail

Settings restricted in untrusted workspaces
-------------------------------------------

Workspace values of these settings are ignored until you trust the folder:
`auricFiles.safety.confirmDelete`, `auricFiles.safety.confirmBulk`,
`auricFiles.safety.useWorkspaceTrash`, `auricFiles.safety.protectedPaths`,
`auricFiles.safety.warnOnGitTracked`,
`auricFiles.safety.warnOnUncommittedChanges`,
`auricFiles.safety.previewBeforeApply`, `auricFiles.related.rules`,
`auricFiles.templates.directories`, `auricFiles.templates.global` and
`auricFiles.templates.variables`.

FILES AND SETTINGS AURIC FILES WRITES
=====================================

  What:       Workspace trash
  Where:      `.auric/trash/` in the workspace folder, with `index.json`
  Written by: Delete (Workspace Trash)

  What:       Workspace templates
  Where:      `.auric/templates/`, `.vscode/templates/` (read, not written)
  Written by: You

  What:       Selection manifest
  Where:      Where you choose; default `auric-selection.json`
  Written by: Export Selected Items…

  What:       `files.exclude`
  Where:      Workspace or folder settings
  Written by: Toggle Native Explorer Exclusion

  What:       `explorer.sortOrder` and its direction
  Where:      Workspace settings
  Written by: The Sort commands

  What:       Tags, groups, virtual folders, flags, filters, profiles, history
  Where:      VS Code's storage for this workspace
  Written by: The Organise, Find & filter and history commands
