User-facing history of Auric Artisan Icon Hub.
Area: VS Code extensions › Auric Artisan Icon Hub   Updated: 2026-09-25

0.1.0 — 23 SEPTEMBER 2026
=========================

The first release of Auric Artisan Icon Hub, and the current Marketplace
version.

Library and workspace
---------------------

  - 12,895 icons and 32,802 indexed variants across Phosphor, Tabler, Lucide,
    Remix, Heroicons, Feather and Material.
  - A full editor panel and a compact Activity Bar sidebar, with sticky
    navigation and responsive cards.
  - Search and refine by collection, style, category and licence, with sorting
    and a one-click filter reset.
  - Favorites, recent icons and a working selection.
  - Collapsible filter and appearance sections, compact by default in the
    sidebar.

Controls and accessibility
--------------------------

  - Custom dropdowns for filters and the inspector's format chooser, with full
    keyboard support.
  - The Auric colour picker: spectrum, colour-space inputs, eyedropper where
    supported, named colours, recent choices, shade ramps, harmonies, and WCAG
    and APCA contrast checks with AA and AAA adjustment.
  - `currentColor` kept until you pick a colour.
  - Keyboard and hover tooltips, announced actions, focus kept on cards during
    updates, and support for narrow layouts, light themes, high contrast and
    reduced motion.

Insertion and export
--------------------

  - CDN insertion for HTML and supported frameworks across all seven
    collections, including Material fonts, through a small reusable bridge
    created only on explicit Insert.
  - Language-appropriate insertion, including JSX for React and named markup
    constants for plain JavaScript and TypeScript.
  - Multi-selection insertion, read-only and rejected-edit reporting, and a
    clipboard fallback with a notification.
  - SVG, JSX, React component, HTML, data URI, CSS and CDN output; SVG sprite
    and ZIP export with upstream licences.

Website and metadata
--------------------

  - Open Auric Icon Tool opens https://icons.auricartisan.com.
  - Automatic metadata checks on activation with a configurable 24-hour
    cooldown, manual refresh and a command to clear downloaded metadata.
  - Strictly limited, validated requests; the local catalog is kept when a
    check fails.
