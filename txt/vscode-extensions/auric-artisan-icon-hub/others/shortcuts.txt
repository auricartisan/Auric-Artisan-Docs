SHORTCUTS AND COMMANDS

Keybindings, keys inside the Hub and every command in Auric Artisan Icon Hub.
Area: VS Code extensions › Auric Artisan Icon Hub   Updated: 2026-09-25

KEYBINDINGS
===========

  Action             | Windows and Linux              | macOS
  -------------------+--------------------------------+------------------------------
  Quick Search Icons | `Ctrl` + `Alt` + `Shift` + `I` | `Cmd` + `Alt` + `Shift` + `I`

KEYS INSIDE THE HUB
===================

  Key                        | Action
  ---------------------------+----------------------------------------
  `Ctrl` + `K` / `Cmd` + `K` | Focus search
  Arrow keys                 | Move between cards or dropdown options
  `Enter`                    | Open the inspector for the focused card
  `F`                        | Star the focused card
  `Home` / `End`             | First or last dropdown option
  `Escape`                   | Close a dropdown or the inspector

COMMANDS
========

Type "Auric Icon Hub" in the Command Palette: Open Icon Hub, Quick Search
Icons, Smart Insert Icon, Copy Icon As…, Save Icon As…, Show Favorite Icons,
Show Recent Icons, Refresh Icon Catalog, Clear Downloaded Icon Catalog, Open
Auric Icon Tool, Clear Icon Favorites and Recents.

The editor right-click menu has Smart Insert Icon and Copy Icon As….
