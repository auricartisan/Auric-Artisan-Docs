==============================================================================
REFERENCE: COMMANDS, KEYS AND SETTINGS
==============================================================================
Every Auric Artisan Live command, keyboard shortcut, menu entry, view and
setting, with types, defaults and ranges.
Area: VS Code extensions › Auric Artisan Live   Updated: 2026-09-25

This page lists everything Auric Artisan Live 0.2.1 contributes to VS Code: 54
commands, 7 keyboard shortcuts, 3 sidebar views and 103 settings. Command
titles appear in the Command Palette with the Auric Live: prefix.

KEYBOARD SHORTCUTS
==================

All seven shortcuts work whenever a folder is open. On macOS, `Cmd` replaces
`Ctrl`.

  Keys (Windows and Linux)       | Keys (macOS)                  | Command
  -------------------------------+-------------------------------+-----------------------
  `Ctrl` + `Alt` + `L`           | `Cmd` + `Alt` + `L`           | Go Live
  `Ctrl` + `Alt` + `Shift` + `L` | `Cmd` + `Alt` + `Shift` + `L` | Stop All Servers
  `Ctrl` + `Alt` + `K`           | `Cmd` + `Alt` + `K`           | Open Preview Beside
  `Ctrl` + `Alt` + `Shift` + `K` | `Cmd` + `Alt` + `Shift` + `K` | Open Live Menu
  `Ctrl` + `Alt` + `J`           | `Cmd` + `Alt` + `J`           | Select Run Target…
  `Ctrl` + `Alt` + `U`           | `Cmd` + `Alt` + `U`           | Reload Connected Pages
  `Ctrl` + `Alt` + `Shift` + `I` | `Cmd` + `Alt` + `Shift` + `I` | Open Control Panel

Inside other surfaces:

  Where:        A served page
  Keys:         `Alt` + `Shift` + `D` (set by `auricLive.dashboard.shortcut`)
  What they do: Open the in-page dashboard

  Where:        Control panel, Requests section
  Keys:         `Ctrl` + `F` (`Cmd` + `F` on macOS)
  What they do: Focus the request search

  Where:        Control panel
  Keys:         `Escape`
  What they do: Close request details or an open menu

  Where:        Dashboard tabs
  Keys:         Arrow keys, `Home`, `End`
  What they do: Move between tabs

  Where:        Dashboard content
  Keys:         Arrow keys, `Page Up`, `Page Down`, `Home`, `End`, `Space`,
                `Shift` + `Space`
  What they do: Scroll

WHERE COMMANDS APPEAR
=====================

  - Status bar: Go Live when stopped; the port (opens the Live menu) when
    running
  - Servers view title: Go Live, Select Run Target…, Stop All Servers, Open
    Control Panel; … menu: Refresh, Open Settings, Show Log
  - A running server in Servers: Inline: Open in Default Browser, Stop Server.
    Right-click: Restart Server, Open Preview Beside, Copy Local URL, Copy
    Network URL, Show Phone QR Code
  - A stopped server in Servers: Inline: Go Live
  - Requests view title: Clear Request Log, Export Requests as HAR
  - A request in Requests: Inline: Show Request Detail. Right-click: Replay
    Request, Copy Request as curl, Copy Request as fetch
  - Routes and Mocks view title: Add API Proxy Route…, Add Mock API Route…,
    Find a Running Backend; … menu: Open Mock Database, Open Project Config
    File, Restart Framework Dev Server, Show Dev Server Output
  - Explorer, on a folder: Serve This Folder, and the Auric Live submenu
  - Explorer, on `.html`, `.htm`, `.php`, `.xhtml` or `.md`: Open with Auric
    Live
  - Editor and editor tab, for `.html`, `.htm`, `.php` or `.xhtml`: Open with
    Auric Live
  - Editor title Run menu › Auric Live: Go Live, Select Run Target…, Add
    Custom Run Command…, Open Preview Beside, Open in Default Browser, Show
    Phone QR Code, Restart Framework Dev Server, Stop Server, Open Live Menu

The Auric Live menu
-------------------

Open Live Menu lists, when a server is running: Open in browser, Open preview
beside, Show phone QR code, Reload connected pages, Open control panel,
Restart server and Stop server. When stopped: Go Live and Open control panel.
Then always: Add an API proxy route, Add a mock API route, Open the mock
database, Change the run target…, Add a custom command…, the run target's
Restart the run target, Show its output and Stop it (or Start the framework
dev server when none is running), Find a backend that is already running,
Simulate a network profile, Select active server, Toggle browser console
capture, Diagnose configuration and runtimes, Import an HTTPS certificate,
Toggle HTTPS, Toggle live reload, Change the port, Change the served folder,
Open the project config file, Open .auricignore-live, Open recorded session,
Export requests as HAR, Open settings and Show log. Each shows its current
value where it has one.

VIEWS
=====

  View:     Servers
  Where:    Auric Live sidebar
  Contents: One entry per workspace folder; expand for root, run target, dev
            server, upstreams, addresses, live reload, requests, certificate
            and config file

  View:     Requests
  Where:    Auric Live sidebar
  Contents: Recent requests with status, handler and time

  View:     Routes and Mocks
  Where:    Auric Live sidebar
  Contents: Proxy rules, mock routes, REST collections and CGI handlers

  View:     Control panel
  Where:    Editor tab
  Contents: Overview, Requests, Runtime, Routing, Settings

  View:     Auric Live Preview
  Where:    Editor tab beside the code
  Contents: The served site at a chosen device size

Output channels: Auric Artisan Live (server log) and Auric Live: Run Target
(run target output).

SETTINGS
========

All 103 settings, grouped by area. A project file sets the same values with
the names shown here minus the `auricLive.` prefix. "Values or range" lists
the allowed values, or the minimum and maximum for numbers.

Server and address
------------------

  Setting:         `auricLive.root`
  Type:            string
  Default:         empty
  Values or range: -
  What it does:    Folder to serve, relative to the workspace folder. Empty
                   serves the workspace folder; use `dist` or `public` for a
                   build output.

  Setting:         `auricLive.port`
  Type:            number
  Default:         `5500`
  Values or range: 0–65535
  What it does:    Port to listen on. Set 0 to let the operating system pick a
                   free one, which is useful when several projects run at
                   once.

  Setting:         `auricLive.portStrategy`
  Type:            string
  Default:         `increment`
  Values or range: `increment`, `fail`, `random`
  What it does:    What to do when the chosen port is already in use.

  Setting:         `auricLive.host`
  Type:            string
  Default:         `0.0.0.0`
  Values or range: -
  What it does:    Address to bind. `0.0.0.0` also answers devices on your
                   network (phone testing); `127.0.0.1` keeps it on this
                   machine.

  Setting:         `auricLive.open`
  Type:            string
  Default:         `default`
  Values or range: `default`, `preview`, `none`
  What it does:    What to open once the server starts.

  Setting:         `auricLive.openPath`
  Type:            string
  Default:         empty
  Values or range: -
  What it does:    Path appended to the URL that is opened, for a site whose
                   entry point is not the root — /docs/index.html, for
                   example.

  Setting:         `auricLive.startOnOpen`
  Type:            boolean
  Default:         `false`
  Values or range: -
  What it does:    Start the server automatically when a folder is opened.

  Setting:         `auricLive.showStatusBar`
  Type:            boolean
  Default:         `true`
  Values or range: -
  What it does:    Show the Go Live control in the status bar.

  Setting:         `auricLive.suggestFrameworkSetup`
  Type:            boolean
  Default:         `true`
  Values or range: -
  What it does:    Once per folder, offer the matching setup when the project
                   is a framework with its own dev server, or a PHP site.

  Setting:         `auricLive.configFile`
  Type:            string
  Default:         `auric.live.json`
  Values or range: -
  What it does:    Name of the project file, looked for in the workspace
                   folder, then `.auric/`. It overrides these settings.

  Setting:         `auricLive.interfaceLanguage`
  Type:            string
  Default:         `auto`
  Values or range: `auto`, `en`, `hi`
  What it does:    Language of the Auric Live panel and supported messages.
                   `auto` follows VS Code. Changing it does not restart
                   servers.

HTTPS
-----

  Setting:         `auricLive.https.enabled`
  Type:            boolean
  Default:         `false`
  Values or range: -
  What it does:    Serve over HTTPS, which service workers, clipboard, camera,
                   microphone and geolocation need on a phone.

  Setting:         `auricLive.https.certPath`
  Type:            string
  Default:         empty
  Values or range: -
  What it does:    Certificate file. Empty generates and reuses a self-signed
                   one for `localhost` and your network addresses.

  Setting:         `auricLive.https.keyPath`
  Type:            string
  Default:         empty
  Values or range: -
  What it does:    Private key matching `auricLive.https.certPath`.

Static files and responses
--------------------------

  Setting:         `auricLive.index`
  Type:            array
  Default:         `["index.html","index.htm"]`
  Values or range: -
  What it does:    File names tried, in order, when a directory is requested.

  Setting:         `auricLive.directoryListing`
  Type:            boolean
  Default:         `true`
  Values or range: -
  What it does:    Render a browsable index for a directory that has no index
                   file.

  Setting:         `auricLive.cleanUrls`
  Type:            boolean
  Default:         `false`
  Values or range: -
  What it does:    Serve /about from about.html, so links can drop the
                   extension the way most static hosts do.

  Setting:         `auricLive.dotfiles`
  Type:            string
  Default:         `ignore`
  Values or range: `ignore`, `allow`, `deny`
  What it does:    How paths with a dot-file or dot-folder are treated. The
                   default hides them, keeping `.env` and `.git` unserved.

  Setting:         `auricLive.notFoundPage`
  Type:            string
  Default:         empty
  Values or range: -
  What it does:    Page served for a missing file, relative to the served
                   root. Leave empty for the built-in 404.

  Setting:         `auricLive.spa.enabled`
  Type:            boolean
  Default:         `false`
  Values or range: -
  What it does:    Answer unknown paths with the fallback document, so a
                   client-side router keeps working on a deep link and a hard
                   refresh.

  Setting:         `auricLive.spa.fallback`
  Type:            string
  Default:         `/index.html`
  Values or range: -
  What it does:    Document served for unknown paths when the single-page
                   fallback is on.

  Setting:         `auricLive.spa.ignore`
  Type:            array
  Default:         `["/api/**","**/*.*"]`
  Values or range: -
  What it does:    Paths the fallback must not answer. The default keeps
                   `/api` and anything with a file extension returning honest
                   404s.

  Setting:         `auricLive.compression`
  Type:            string
  Default:         `auto`
  Values or range: `auto`, `gzip`, `brotli`, `off`
  What it does:    Compression for text responses over one kilobyte. Turn it
                   off when measuring uncompressed transfer sizes.

  Setting:         `auricLive.cache`
  Type:            string
  Default:         `no-store`
  Values or range: `no-store`, `no-cache`, `short`, `immutable-assets`
  What it does:    Caching policy sent with served files.

  Setting:         `auricLive.etag`
  Type:            boolean
  Default:         `true`
  Values or range: -
  What it does:    Send a validator so an unchanged file can answer 304
                   instead of being sent again.

  Setting:         `auricLive.mimeTypes`
  Type:            object
  Default:         `{}`
  Values or range: -
  What it does:    Extra content types, keyed by extension — `{ ".data":
                   "application/json" }`. Overrides the built-in table.

  Setting:         `auricLive.headers`
  Type:            array
  Default:         `[]`
  Values or range: -
  What it does:    Extra response headers, applied to the paths each rule
                   matches.

Cross-origin and access
-----------------------

  Setting:         `auricLive.cors.enabled`
  Type:            boolean
  Default:         `true`
  Values or range: -
  What it does:    Answer cross-origin requests, so a page served from another
                   port can call this one during development.

  Setting:         `auricLive.cors.origin`
  Type:            string
  Default:         `*`
  Values or range: -
  What it does:    Origin allowed by the CORS headers. Use a specific origin
                   when credentials are involved.

  Setting:         `auricLive.cors.credentials`
  Type:            boolean
  Default:         `false`
  Values or range: -
  What it does:    Allow cookies and authorization headers on cross-origin
                   requests.

  Setting:         `auricLive.crossOriginIsolation`
  Type:            boolean
  Default:         `false`
  Values or range: -
  What it does:    Send COOP and COEP headers, needed for `SharedArrayBuffer`,
                   WebAssembly threads and precise timers.

  Setting:         `auricLive.auth.enabled`
  Type:            boolean
  Default:         `false`
  Values or range: -
  What it does:    Require a username and password before anything is served.
                   Useful when bound to a shared network.

  Setting:         `auricLive.auth.username`
  Type:            string
  Default:         empty
  Values or range: -
  What it does:    Username for basic authentication.

  Setting:         `auricLive.auth.password`
  Type:            string
  Default:         empty
  Values or range: -
  What it does:    Password for basic authentication. Stored in plain
                   settings; a development convenience, not a secret store.

Request limits
--------------

  Setting:         `auricLive.maxRequestBodyBytes`
  Type:            number
  Default:         `8388608`
  Values or range: 0–1073741824
  What it does:    Maximum buffered request size in bytes. Larger bodies
                   receive HTTP 413. Zero rejects all non-empty bodies.

  Setting:         `auricLive.requestBodyTimeoutMs`
  Type:            number
  Default:         `30000`
  Values or range: 0–3600000
  What it does:    Deadline for receiving a request body; 0 disables it.
                   Simulated transfer time is excluded.

Network simulation
------------------

  Setting:         `auricLive.throttle.profile`
  Type:            string
  Default:         `off`
  Values or range: `off`, `slow-3g`, `3g`, `4g`, `cable`, `custom`
  What it does:    Simulate a slower network for every client, including a
                   phone on your LAN where browser devtools are not available.

  Setting:         `auricLive.throttle.latencyMs`
  Type:            number
  Default:         `0`
  Values or range: 0–60000
  What it does:    Delay added before each response when the custom profile is
                   selected.

  Setting:         `auricLive.throttle.downloadKbps`
  Type:            number
  Default:         `0`
  Values or range: 0–no maximum
  What it does:    Download ceiling in kilobits per second when the custom
                   profile is selected. 0 means unlimited.

  Setting:         `auricLive.throttle.uploadKbps`
  Type:            number
  Default:         `0`
  Values or range: 0–1000000
  What it does:    Upload bandwidth in kilobits per second; 0 uses unlimited
                   bandwidth.

Live reload and watching
------------------------

  Setting:         `auricLive.liveReload.enabled`
  Type:            boolean
  Default:         `true`
  Values or range: -
  What it does:    Inject the reload client into served HTML and update open
                   pages when the configured save/change trigger fires.

  Setting:         `auricLive.liveReload.reloadOnSave`
  Type:            string
  Default:         `save`
  Values or range: `save`, `change`, `off`
  What it does:    What may refresh the page: `save` (explicit VS Code saves),
                   `change` (any file change) or `off` (manual only).

  Setting:         `auricLive.liveReload.injectTo`
  Type:            string
  Default:         `body`
  Values or range: `body`, `head`
  What it does:    Where the reload client is inserted: end of `body` (out of
                   the critical path) or `head` (earlier).

  Setting:         `auricLive.liveReload.cssHotSwap`
  Type:            boolean
  Default:         `true`
  Values or range: -
  What it does:    Swap a changed stylesheet in place, keeping scroll

Settings restricted in untrusted workspaces
-------------------------------------------

`auricLive.cgi.enabled`, `auricLive.cgi.handlers`, `auricLive.cgi.indexes`,
`auricLive.proxy`, `auricLive.host`, `auricLive.auth.username`,
`auricLive.auth.password`, `auricLive.https.certPath`,
`auricLive.https.keyPath` and `auricLive.mock.rest.persist` are ignored until
you trust the workspace, whether they come from settings or the project file.

Setting scope
-------------

Most settings have resource scope, so each folder of a multi-root workspace
can differ. `auricLive.showStatusBar`, `auricLive.etag`,
`auricLive.inspector.enabled`, `auricLive.inspector.maxEntries`,
`auricLive.inspector.captureBodies`, `auricLive.logLevel`,
`auricLive.requestLogging` and `auricLive.interfaceLanguage` have window
scope: they can be set for the user or the workspace, but not per folder.

FILES AURIC LIVE READS AND WRITES
=================================

  File:       `auric.live.json` (or the name in `auricLive.configFile`), in
              the workspace folder or `.auric/`
  Written by: You, Create Project Config File or Save to config file
  Purpose:    Project configuration

  File:       `.auricignore-live`, in the served folder
  Written by: You, Open .auricignore-live or Ignore folder/
  Purpose:    Paths never served, watched or recorded

  File:       `.auric-live/latest.json` and `.auric-live/sessions/`
  Written by: Auric Live
  Purpose:    Local session records

  File:       `db.json` (or `auricLive.mock.rest.database`)
  Written by: You, or Open Mock Database › Create
  Purpose:    REST database; written back only with `mock.rest.persist`

  File:       A `.har` file
  Written by: Export Requests as HAR
  Purpose:    Request export

  File:       Generated certificate
  Written by: Auric Live, in its own extension storage
  Purpose:    Self-signed HTTPS certificate

  File:       Workspace settings
  Written by: Add Custom Run Command…
  Purpose:    Saves `auricLive.runProfiles`
