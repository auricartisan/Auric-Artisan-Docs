AURIC ICONS: MODERN REFERENCE
==============================================================================
Every command, keybinding, setting, view, icon ID, pack, category and library
control in Auric Icons: Modern 0.12.1.
Area: VS Code extensions › Auric Icons: Modern   Updated: 2026-09-25

This reference describes version 0.12.1 as published on the Visual Studio
Marketplace.

COMMANDS
========

Category in the Command Palette: Auric Icons: Modern.

File icon theme
---------------

  Command:      Configure…
  ID:           `auricIcons.configure`
  What it does: Menu for folder colour, icon pack, arrows, saturation,
                opacity, detection and restore.

  Command:      Select Icon Pack
  ID:           `auricIcons.selectIconPack`
  What it does: Choose None, Angular, NestJS, React / Redux or Vue / Pinia.

  Command:      Select Folder Colour
  ID:           `auricIcons.selectFolderColor`
  What it does: Choose a preset or custom hex folder colour.

  Command:      Toggle Explorer Arrows
  ID:           `auricIcons.toggleExplorerArrows`
  What it does: Show or hide the Explorer chevrons.

  Command:      Detect Auric Artisan Workspace
  ID:           `auricIcons.detectWorkspace`
  What it does: Report whether the workspace has `.auric-artisan/` or
                `.auricignore`.

  Command:      Restore Default Settings
  ID:           `auricIcons.restoreDefaults`
  What it does: Clear all Modern theme settings.

  Command:      Activate Icon Theme
  ID:           `auricIcons.activate`
  What it does: Set Auric Icons: Modern as the file icon theme.

Icon Library
------------

  Command:      Open Icon Library
  ID:           `auricIcons.library.openExplorer`
  What it does: Opens the Icon Studio — Library editor tab.

  Command:      Search Icons
  ID:           `auricIcons.library.searchIcons`
  What it does: Choose an icon, then an action.

  Command:      Insert SVG at Cursor
  ID:           `auricIcons.library.insertSvg`
  What it does: Choose an icon and insert it.

  Command:      Smart Insert Icon (matches active language)
  ID:           `auricIcons.library.smartInsert`
  What it does: Choose an icon and insert it with language-aware output.

  Command:      Copy Icon As… (JSX, CSS, Markdown, Data URI, Image tag)
  ID:           `auricIcons.library.copyAs`
  What it does: Choose an icon and one of nine formats.

  Command:      Insert from Likes
  ID:           `auricIcons.library.showFavorites`
  What it does: Choose a liked icon and insert it.

  Command:      Insert from Recent
  ID:           `auricIcons.library.showRecents`
  What it does: Choose a recent icon and insert it.

  Command:      Toggle Like for an Icon
  ID:           `auricIcons.library.toggleFavorite`
  What it does: Like or unlike an icon.

  Command:      Clear Likes, Recents and Learned Recommendations
  ID:           `auricIcons.library.resetPersonalization`
  What it does: Asks for confirmation, then resets personalisation.

  Command:      Copy SVG
  ID:           `auricIcons.library.copySvg`
  What it does: Choose an icon and copy raw SVG.

  Command:      Save SVG As…
  ID:           `auricIcons.library.saveSvg`
  What it does: Choose an icon and save it as a file.

  Command:      Open SVG Source
  ID:           `auricIcons.library.openSource`
  What it does: Choose an icon and open its SVG.

Icon Library commands are hidden from the Command Palette while another
extension hosts the shared library. They still work from keybindings and
forward to the host.

KEYBINDINGS
===========

  Keys (Windows and Linux):`Ctrl` + `Alt` + `I`
  Keys (macOS):            `Cmd` + `Alt` + `I`
  Command:                 Smart Insert Icon
  When:                    Editor focused and Modern hosts the library

  Keys (Windows and Linux):`Ctrl` + `Alt` + `R`
  Keys (macOS):            `Cmd` + `Alt` + `R`
  Command:                 Insert from Recent
  When:                    Editor focused and Modern hosts the library

In the Icon Library view: `/` focuses search; `Escape` clears it; in
dropdowns, arrow keys move and `Escape` closes.

SETTINGS
========

File icon theme
---------------

  Setting:         `auricIcons.folderColor`
  Type:            string
  Values or range: `default` or a hex colour
  Default:         `default`
  What it does:    Folder colour. `default` is the Auric gold. Folders only.

  Setting:         `auricIcons.activeIconPack`
  Type:            string
  Values or range: `none`, `angular`, `nest`, `react`, `vue`
  Default:         `none`
  What it does:    Framework pack layered over the base set.

  Setting:         `auricIcons.autoDetect`
  Type:            boolean
  Values or range: `true`, `false`
  Default:         `true`
  What it does:    Offer the theme once in Auric Artisan workspaces.

  Setting:         `auricIcons.hidesExplorerArrows`
  Type:            boolean
  Values or range: `true`, `false`
  Default:         `false`
  What it does:    Hide Explorer chevrons.

  Setting:         `auricIcons.saturation`
  Type:            number
  Values or range: 0 to 2
  Default:         1
  What it does:    Colour saturation multiplier; 0 is greyscale.

  Setting:         `auricIcons.opacity`
  Type:            number
  Values or range: 0.1 to 1
  Default:         1
  What it does:    Icon opacity.

  Setting:         `auricIcons.files.associations`
  Type:            object
  Values or range: `{ "*.ext" or filename: icon ID }`
  Default:         `{}`
  What it does:    Map files to icons; `none` removes a mapping.

  Setting:         `auricIcons.folders.associations`
  Type:            object
  Values or range: `{ folder name: icon ID }`
  Default:         `{}`
  What it does:    Map folders to icons; open and closed applied together.

Icon Library
------------

  Setting:         `auricIcons.library.defaultVariant`
  Type:            string
  Values or range: `auto`, `color`, `mono`, `outline`, `duotone`
  Default:         `auto`
  What it does:    Variant for Command Palette actions; `auto` follows the
                   file.

  Setting:         `auricIcons.library.pageSize`
  Type:            number
  Values or range: 24 to 240
  Default:         72
  What it does:    Cards streamed per batch.

  Setting:         `auricIcons.library.smartInsert`
  Type:            boolean
  Values or range: `true`, `false`
  Default:         `true`
  What it does:    Language-aware output for Insert.

  Setting:         `auricIcons.library.recommendations.enabled`
  Type:            boolean
  Values or range: `true`, `false`
  Default:         `true`
  What it does:    Recommendations for the file you are editing.

  Setting:         `auricIcons.library.recommendations.limit`
  Type:            number
  Values or range: 4 to 24
  Default:         12
  What it does:    Icons in the recommendation rail.

  Setting:         `auricIcons.library.showGuide`
  Type:            boolean
  Values or range: `true`, `false`
  Default:         `true`
  What it does:    Smart guide tips at the top of the library.

  Setting:         `auricIcons.library.density`
  Type:            string
  Values or range: `comfortable`, `compact`
  Default:         `comfortable`
  What it does:    Card size.

  Setting:         `auricIcons.library.hoverPreview`
  Type:            boolean
  Values or range: `true`, `false`
  Default:         `true`
  What it does:    Hover previews for icon IDs in code.

Values set under the retired `auricArtisanIcons.*` names are still honoured as
fallbacks for library settings.

  Control: Search
  Options: Free text, synonyms, fuzzy ranking.

  Control: Library
  Options: All libraries or one collection (only when merged).

  Control: Category
  Options: All categories or one of 33.

  Control: Style
  Options: All styles, Modern, Sharp (plus other collections' styles when
           merged).

  Control: Preview surface
  Options: Auto, Light, Dark.

  Control: Card buttons
  Options: Artwork (open source), heart, Insert, Copy, Save, JSX, URI, Source.

  Control: Rail
  Options: ✦ Recommended for this file with Refresh; selecting a rail card

MESSAGES YOU MAY SEE
====================

  Message: Auric Icons: Modern updated — … Reload to apply?
  Meaning: Theme settings changed; reload to see them.

  Message: Auric Icons: Modern: could not apply customisation — … The default
           icons remain active.
  Meaning: A setting could not be applied; the original icons stay in place.

  Message: Open a text editor before inserting an SVG.
  Meaning: No text editor was available for insertion.

  Message: … like an icon first — open the library and press the heart.
  Meaning: Insert from Likes found no likes.

  Message: … no recent icons yet.
  Meaning: Insert from Recent found none.

  Message: This workspace uses Auric Artisan (found …).
  Meaning: Workspace detection offer.
