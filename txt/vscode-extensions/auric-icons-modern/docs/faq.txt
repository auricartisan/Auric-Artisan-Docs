==============================================================================
FREQUENTLY ASKED QUESTIONS
==============================================================================
Short answers to common questions about Auric Icons: Modern.
Area: VS Code extensions › Auric Icons: Modern   Updated: 2026-09-25

IS IT FREE?
===========

Yes. It is free to install and use for any purpose, personal or commercial.
Redistribution, republishing and resale are not permitted.

DO I HAVE TO USE BOTH THE THEME AND THE LIBRARY?
================================================

No. The file icon theme and the Icon Library are independent. Use either or
both.

WHY DOES CHANGING A SETTING NEED A RELOAD?
==========================================

VS Code reads icon themes once and caches them. The extension rebuilds the
theme files when you change a setting, and a window reload shows the result.

DOES FOLDER COLOUR CHANGE FILE ICONS TOO?
=========================================

No. It re-tints folders only. File icons keep the semantic colours that
identify them. Use saturation and opacity to tone down all icons.

CAN I USE TWO FRAMEWORK PACKS AT ONCE?
======================================

No. One pack is active at a time.

WHAT IS THE DIFFERENCE BETWEEN MODERN AND SHARP?
================================================

They are the two style families in the 720-icon library: 420 Simple Modern
icons and 300 Sharp Modern icons. Filter by Style to see one family.

HOW IS THIS DIFFERENT FROM AURIC ARTISAN FILE ICONS?
====================================================

File Icons offers three Explorer styles (Facet, Playful and Modern) with its
own studio, smart decorations and profiles. This extension offers the Modern
Explorer theme plus the 720-icon library. See the comparison
[../others/related.txt].

DOES MODERN NEED THE INTERNET?
==============================

No. It has no network access and no telemetry at runtime.

WHERE DID THE HAND-DRAWN ICONS GO?
==================================

Since version 0.4.0 the hand-drawn (Warm Drawn) icons live in Auric Icons:
Drawn. Install it alongside Modern to browse both in one library.
