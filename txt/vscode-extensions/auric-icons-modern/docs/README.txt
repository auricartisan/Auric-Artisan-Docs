AURIC ICONS: MODERN GUIDES

Contents of the Auric Icons: Modern guides folder, with one line on each

Area: VS Code extensions › Auric Icons: Modern   Updated: 2026-09-25

This folder holds the task guides and the complete reference for Auric Icons:
Modern. The extension has two parts, the Explorer file icon theme and the Icon
Library, and each has its own guide.

  File:           getting-started.md [getting-started.txt]
  What it covers: Install, turn on the file icon theme, open the Icon Library
                  and insert a first icon.

  File:           file-icon-theme.md [file-icon-theme.txt]
  What it covers: Folder colour, framework packs, saturation, opacity, arrows,
                  associations and workspace detection.

  File:           icon-library.md [icon-library.txt]
  What it covers: Search, filters, variants, preview surfaces, the smart guide
                  and recommendations.

  File:           insert-copy-and-save.md [insert-copy-and-save.txt]
  What it covers: Insert and smart insert, nine copy formats, save, open
                  source and hover previews.

  File:           merged-icon-studio.md [merged-icon-studio.txt]
  What it covers: How Modern, Drawn, Playful and Icon Studio share one
                  library.

  File:           reference.md [reference.txt]
  What it covers: Every command, setting, keybinding, icon ID and control.

  File:           troubleshooting.md [troubleshooting.txt]
  What it covers: Symptoms, causes and fixes.

  File:           faq.md [faq.txt]
  What it covers: Short answers to common questions.
