==============================================================================
GLOSSARY
==============================================================================
Definitions of the terms used in Auric Artisan Emoji.
Area: VS Code extensions › Auric Artisan Emoji   Updated: 2026-09-25

  Term:    Click action
  Meaning: What happens when you select an emoji or press `Enter` on it:
           insert, copy, or both.

  Term:    Code point
  Meaning: The Unicode number of a character, written like `U+1F680`.

  Term:    Copy format
  Meaning: The text form used when copying: emoji, shortcode, Unicode, HTML,
           JavaScript or CSS.

  Term:    CSS escape
  Meaning: A backslash form such as `\1F680`, valid inside CSS strings.

  Term:    Curated
  Meaning: A hand-picked selection of commonly useful emoji.

  Term:    HTML entity
  Meaning: A form such as `&#x1F680;` that HTML turns into the character.

  Term:    Inspector
  Meaning: The panel showing an emoji's details and every output format.

  Term:    JavaScript escape
  Meaning: A form such as `\u{1F680}`, valid inside JavaScript and TypeScript
           strings.

  Term:    Sequence
  Meaning: A list of up to 50 emoji collected to insert or copy together.

  Term:    Shortcode
  Meaning: A text name between colons, such as `:rocket:`.

  Term:    Skin tone
  Meaning: A modifier changing the skin colour of emoji that support it.

  Term:    Yellow
  Meaning: The standard, unmodified appearance of tone-capable emoji.
