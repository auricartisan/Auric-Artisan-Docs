==============================================================================
INTERFACE LANGUAGE (ENGLISH AND हिन्दी)
==============================================================================
Show Emoji Studio in English or Hindi and search with Hindi words.
Area: VS Code extensions › Auric Artisan Emoji   Updated: 2026-09-25

CHOOSE A LANGUAGE
=================

  - In Emoji Studio's brand bar, use the Language switch: Auto, EN or हिं.
  - Run Auric Artisan Emoji: Choose Interface Language… (also in the sidebar's
    title-bar … menu).
  - Set `auricEmoji.interfaceLanguage` to `auto`, `en` or `hi`.

  Value:     `auto` (default)
  Behaviour: Follows VS Code's display language: Hindi locales use Hindi;
             others use English.

  Value:     `en`
  Behaviour: Always English in Emoji Studio.

  Value:     `hi`
  Behaviour: Always Hindi in Emoji Studio.

Changing the language keeps your search, filters and sequence.

WHAT CHANGES
============

  Part:     Emoji Studio controls, categories, tones, formats and
            announcements
  Language: Your `auricEmoji.interfaceLanguage` choice.

  Part:     Command Palette titles, Settings descriptions and notifications
  Language: VS Code's display language (Hindi versions are included).

  Part:     Emoji names, shortcodes and code points
  Language: Their catalog spelling, always.

HINDI SEARCH
============

Common Hindi words find emoji whatever the interface language, for example
`दिल` (heart), `रॉकेट` (rocket) and `धन्यवाद` (thanks).

RESULT
======

Emoji Studio appears in your chosen language, and Hindi words help you find
emoji.
