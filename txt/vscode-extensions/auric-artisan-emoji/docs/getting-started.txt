==============================================================================
GETTING STARTED WITH AURIC ARTISAN EMOJI
==============================================================================
Install Auric Artisan Emoji, insert a first emoji, open Emoji Studio and tour
its screen.
Area: VS Code extensions › Auric Artisan Emoji   Updated: 2026-09-25

BEFORE YOU BEGIN
================

  - You need Visual Studio Code 1.85 or later.
  - The extension works offline and in untrusted and virtual workspaces. It
    never runs workspace code.

1. INSTALL
==========

Open the Extensions view (`Ctrl` + `Shift` + `X`), search for Auric Artisan
Emoji and select Install, or run:

    code --install-extension auric-artisan.auric-artisan-emoji

For a local `.vsix`, use Extensions › … › Install from VSIX….

2. INSERT YOUR FIRST EMOJI
==========================

  1. Open a text file and place the cursor.
  2. Press `Ctrl` + `Alt` + `J` (`Cmd` + `Alt` + `J` on macOS), or right-click
     and choose Quick Insert Emoji.
  3. Type `rocket` and press `Enter`. The rocket emoji is inserted.

3. OPEN EMOJI STUDIO
====================

  - Sidebar: select Auric Emoji in the Activity Bar (view name Emoji Studio).
  - Editor tab: press `Ctrl` + `Alt` + `E` (`Cmd` + `Alt` + `E`), run Auric
    Artisan Emoji: Open Emoji Studio, or select the Emoji item in the status
    bar.

The editor tab opens beside your code. The sidebar is compact, with visible
card actions.

4. TOUR THE STUDIO
==================

  Area:     Brand bar
  Contents: "Auric Artisan / Emoji Studio", the website link, Language (Auto,
            EN, हिं) and Offline · private.

  Area:     Brand bar buttons
  Contents: Customize Emoji Studio (gear) and, in the sidebar, Open Emoji
            Studio in an editor tab.

  Area:     Tabs
  Contents: 01 Library, 02 For you, 03 Favorites, 04 Recent, with counts.

  Area:     Workspace overview
  Contents: Collapsed by default. Quick tools (Quick insert, Replace
            shortcodes, Keyboard map →), the Active file card and library
            statistics.

  Area:     Section heading
  Contents: For example "01 / Library — Find the feeling fast." with a hint.

  Area:     Filters
  Contents: Search, Category chips, Skin tone, and in the full Studio Quick
            filter and Density.

  Area:     Results
  Contents: A count, Clear filters, the Compose switch, the Grid / List layout
            and the emoji cards.

  Area:     Suggested for you
  Contents: A rail of suggestions with Refresh.

  Area:     Footer
  Contents: The website link, "Offline · no telemetry · Unicode Emoji …",
            Keyboard map and Settings.

5. INSERT FROM THE STUDIO
=========================

  1. Keep your file open with the cursor in place.
  2. In the Studio, type `party` in Search.
  3. Hover over or focus a card and select Insert. The status line confirms,
     for example, "Inserted … party popper.", showing the emoji and its name.

If no editor is available, the Studio copies the emoji instead and tells you.

RESULT
======

You have inserted emoji from the Quick Pick and from Emoji Studio.
