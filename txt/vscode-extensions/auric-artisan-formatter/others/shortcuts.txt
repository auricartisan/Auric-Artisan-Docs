==============================================================================
SHORTCUTS
==============================================================================
The keyboard shortcuts Auric Artisan Formatter provides in VS Code and inside
Formatter Studio.
Area: VS Code extensions › Auric Artisan Formatter   Updated: 2026-09-25

VS CODE
=======

  Windows and Linux: `Ctrl` + `Alt` + `Shift` + `F`
  macOS:             `Cmd` + `Alt` + `Shift` + `F`
  Command:           Preview Formatting as a Diff
  When:              An editor has focus

  Windows and Linux: `Ctrl` + `Alt` + `Shift` + `P`
  macOS:             `Cmd` + `Alt` + `Shift` + `P`
  Command:           Open Formatter Studio
  When:              Any time

  Windows and Linux: `Ctrl` + `Alt` + `Shift` + `U`
  macOS:             `Cmd` + `Alt` + `Shift` + `U`
  Command:           Show Files That Need Formatting
  When:              Any time

There is deliberately no shortcut for formatting every file. VS Code's own
Format Document (`Shift` + `Alt` + `F` on Windows) and Format Selection use
Auric once it is the default formatter. Assign shortcuts to other commands in
Preferences: Open Keyboard Shortcuts by searching for `auricFormatter`.

FORMATTER STUDIO
================

  Keys                                          | What they do
  ----------------------------------------------+-----------------------------------------------
  `Ctrl` + `K`                                  | Open the Studio command palette
  Left and right arrows on the tabs             | Switch between 01 Studio and 02 Workspace
  Arrow keys, type-ahead, `Enter` in drop-downs | Choose a language, preset, category or view
  `Escape`                                      | Close the command palette or an open drop-down
