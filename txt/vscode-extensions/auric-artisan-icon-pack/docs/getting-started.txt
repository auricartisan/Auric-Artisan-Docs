==============================================================================
GETTING STARTED WITH THE ICON PACK
==============================================================================
Install the Icon Pack, confirm its four member extensions and start using
them.
Area: VS Code extensions › Auric Artisan Icon Pack   Updated: 2026-09-25

BEFORE YOU BEGIN
================

  - You need Visual Studio Code 1.85 or later.
  - You need access to the extension marketplace. The pack downloads its
    members from it.

1. INSTALL THE PACK
===================

  1. Open the Extensions view (`Ctrl` + `Shift` + `X`).
  2. Search for Auric Artisan Icon Pack and select Install.

Or run `code --install-extension auric-artisan.auric-artisan-icon-pack` in a
terminal, or use Extensions: Install from VSIX… with an official pack
download.

2. CHECK THE MEMBERS
====================

  1. Select the pack in the Extensions view.
  2. Open its Extension Pack section. It lists:
     - Auric Icons: Modern (`auric-artisan.auric-artisan-modern-icon`)
     - Auric Icons: Playful (`auric-artisan.auric-icons-playful`)
     - Auric Artisan Emoji (`auric-artisan.auric-artisan-emoji`)
     - Auric Icons: Drawn (`auric-artisan.auric-icons-drawn`)
  3. Each should show as installed.

3. START USING THEM
===================

  To:      Browse Modern, Drawn and Playful icons
  Do this: Select the Auric icon library in the Activity Bar: one merged
           library with a Library filter.

  To:      Insert an icon from the keyboard
  Do this: Press `Ctrl` + `Alt` + `I` in a text editor.

  To:      Insert an emoji
  Do this: Press `Ctrl` + `Alt` + `J`, or open Auric Emoji in the Activity
           Bar.

  To:      Change your Explorer icons
  Do this: Run Preferences: File Icon Theme and choose Auric Icons: Modern.

How the three icon libraries share one view is explained in The merged Icon
Studio [../../auric-icons-modern/docs/merged-icon-studio.txt].

RESULT
======

The four Auric creative libraries are installed and ready. Each member's own
documentation explains its features:

  - Auric Icons: Modern [../../auric-icons-modern/README.txt]
  - Auric Icons: Playful [../../auric-icons-playful/README.txt]
  - Auric Artisan Emoji [../../auric-artisan-emoji/README.txt]
  - Auric Icons: Drawn [../../auric-icons-drawn/README.txt]
