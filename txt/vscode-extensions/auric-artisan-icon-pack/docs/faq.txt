==============================================================================
FREQUENTLY ASKED QUESTIONS
==============================================================================
Short answers to common questions about Auric Artisan Icon Pack.
Area: VS Code extensions › Auric Artisan Icon Pack   Updated: 2026-09-25

IS THE PACK ANOTHER ICON BROWSER?
=================================

No. It only tells VS Code which four extensions to install. It adds no
commands, views or settings.

DOES IT WORK OFFLINE?
=====================

The members work offline once installed. Installing the pack needs marketplace
access.

DOES IT INCLUDE ICON STUDIO OR FILE ICONS?
==========================================

No. Install them separately if you need them. See the reference
[reference.txt].

DO THE MEMBERS UPDATE WITH THE PACK?
====================================

Each member updates on its own schedule through the marketplace.

CAN I UNINSTALL ONE MEMBER?
===========================

Yes. Manage each member individually in the Extensions view.

WHY ARE MODERN, DRAWN AND PLAYFUL SHOWN AS ONE LIBRARY?
=======================================================

They are designed to merge into one library when installed together. See The
merged Icon Studio [../../auric-icons-modern/docs/merged-icon-studio.txt].
