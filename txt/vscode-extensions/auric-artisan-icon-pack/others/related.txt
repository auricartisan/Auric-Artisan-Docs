HOW THE PACK'S ICON LIBRARIES MERGE
===================================

With Modern, Drawn and Playful installed together, one of them hosts a single
library with a Library filter and collection badges; the others hide their
views. If you later install Icon Studio, it hosts all three by default. See
The merged Icon Studio [../../auric-icons-modern/docs/merged-icon-studio.txt].

See also Install and set up [../../install-and-setup/README.txt].
