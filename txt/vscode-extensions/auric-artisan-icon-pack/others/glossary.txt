==============================================================================
GLOSSARY
==============================================================================
Terms used in the Auric Artisan Icon Pack documentation.
Area: VS Code extensions › Auric Artisan Icon Pack   Updated: 2026-09-25

  Term:    Extension pack
  Meaning: A VS Code extension whose only job is to install a list of other
           extensions.

  Term:    Member
  Meaning: One of the extensions an extension pack installs.

  Term:    Extension ID
  Meaning: The unique publisher-and-name identifier of an extension, such as
           `auric-artisan.auric-icons-drawn`.

  Term:    Marketplace
  Meaning: The online registry VS Code installs extensions from.

  Term:    VSIX
  Meaning: A packaged extension file that can be installed with Extensions:
           Install from VSIX….

  Term:    Merged library
  Meaning: The single icon library view shown when Modern, Drawn and Playful
           are installed together.
