==============================================================================
AURIC ARTISAN ICON PACK
==============================================================================
What the Auric Artisan Icon Pack is, what it installs, how to get it and where
to find each guide.
Area: VS Code extensions › Auric Artisan Icon Pack   Updated: 2026-09-25

Auric Artisan Icon Pack is a standard VS Code extension pack: a single
Marketplace entry that installs four Auric Artisan extensions together. It has
no interface, commands or settings of its own.

Installing the pack adds Auric Icons: Modern, Auric Icons: Playful, Auric
Artisan Emoji and Auric Icons: Drawn. Once installed, Modern, Drawn and
Playful share one icon library view, and Emoji keeps its own Emoji Studio.
Each member keeps its own version, settings, licence and update cycle, and you
can manage, disable or remove each one separately in the Extensions view.

The pack does not include Auric Artisan Icon Studio (the all-in-one catalog)
or Auric Artisan File Icons (Explorer file and folder themes).

WHO IT IS FOR
=============

  - Anyone who wants the four Auric creative libraries in one step.
  - Teams who want to recommend one install to colleagues.

WHERE TO FIND IT
================

  Item:  Marketplace listing
  Value: https://marketplace.visualstudio.com/items?itemName=auric-artisan.auric-artisan-icon-pack

  Item:  Extension ID
  Value: `auric-artisan.auric-artisan-icon-pack`

  Item:  Current version
  Value: 0.1.0

  Item:  Requires
  Value: Visual Studio Code 1.85 or later, and access to the extension
         marketplace

  Item:  Price
  Value: Free

    code --install-extension auric-artisan.auric-artisan-icon-pack

QUICK START
===========

  1. Open the Extensions view (`Ctrl` + `Shift` + `X`).
  2. Search for Auric Artisan Icon Pack and select Install.
  3. Let VS Code install the four included extensions.
  4. Select an Auric icon library view or Auric Emoji in the Activity Bar, or
     type "Auric" in the Command Palette.
  5. Search for artwork and use the chosen extension's insert or copy actions.

WHAT YOU CAN DO
===============

  - Install Auric Icons: Modern, Playful and Drawn and Auric Artisan Emoji
    together.
  - Browse Modern, Drawn and Playful in one merged library.
  - Manage each included extension individually afterwards.
