REFERENCE

Every screen, control, field, rule and status in the Auric Artisan account
area, from the sign-in page to the dashboard, pricing, checkout and invoices.
Area: Website › Account and billing   Updated: 2026-09-25

This page lists every control in the account area, screen by screen. Labels
are as they appear on screen. For step-by-step instructions, follow the links
to the task guides.

SIGN-IN PAGE
============

Address: https://auricartisan.com/auth/ (add `#register` to open Create
Account, `#forgot` to open password recovery).

Tabs
----

  Control                   | What it does
  --------------------------+-------------------------------------------------
  Sign In tab               | Shows the sign-in form ("Welcome back.")
  Create Account tab        | Shows the sign-up form ("Create your identity.")
  Exit                      | Returns to the home page
  Arrow keys, `Home`, `End` | Move between the two tabs

Sign In form
------------

  Control:         Email or username
  What it does:    Who you are
  Values or rules: An email address (checked as an address if it contains @)
                   or a username of 3–30 letters, numbers and underscores

  Control:         Password
  What it does:    Your password
  Values or rules: Required

  Control:         Eye button ("Show password")
  What it does:    Shows or hides the password
  Values or rules: Toggle

  Control:         Remember me
  What it does:    Keeps you signed in on this browser
  Values or rules: Up to 30 days; ends after seven days unused. Off: ends when
                   the browser closes, 24 hours at most.

  Control:         Forgot password?
  What it does:    Opens Recover access.
  Values or rules: Copies an email address you typed

  Control:         Sign In
  What it does:    Submits; shows the human check on first use
  Values or rules: —

  Control:         Google, GitHub
  What it does:    Sign in with that provider
  Values or rules: —

Create Account form
-------------------

  Control: Display Name
  Rules:   Required, 2–64 characters

  Control: Username
  Rules:   Required, 3–30 characters, letters, numbers and underscores; live
           availability tick or cross

  Control: Email
  Rules:   Required, valid address

  Control: Password
  Rules:   12–128 characters; upper and lower case; a number; a symbol; no
           character four times in a row; not a common password. Strength
           label Weak, Fair, Good or Strong.

  Control: Confirm Password
  Rules:   Must match

  Control: I agree to the Terms of Service and Privacy Policy
  Rules:   Required

  Control: Create Account
  Rules:   Submits; shows the human check on first use

  Control: Google, GitHub
  Rules:   Sign up with that provider

Auric human check
-----------------

  Control                | What it does
  -----------------------+---------------------------------------------------
  Sequence and countdown | Three marks to repeat, and the time left
  Choice buttons         | Add a mark to the next answer slot
  Answer slots           | Select one to remove that mark
  Verify sequence        | Checks your answer (enabled when three are chosen)
  New sequence           | Loads a fresh sequence

Recover access
--------------

  Control:      Email
  What it does: The account's email address

  Control:      Send Reset Link
  What it does: Sends a one-hour link if the address has an account; the reply
                is the same either way

  Control:      ← Back to Sign In
  What it does: Returns to the sign-in form

Second factor and backup code
-----------------------------

  Control              | What it does
  ---------------------+--------------------------------------------------------------------------
  Verification Code    | Six digits from your authenticator app; the sign-in expires in 10 minutes
  Verify               | Checks the code
  Use a backup code    | Switches to Backup Code (`XXXX-XXXX-XXXX-XXXX`, single use)
  ← Back to code entry | Returns to the six-digit code
  Cancel sign-in       | Abandons this sign-in

Confirm your inbox
------------------

  Control:      Verification window
  What it does: Counts down 24 hours

  Control:      Resend verification email
  What it does: Sends a fresh link; shows Resend in seconds while waiting

  Control:      Continue to limited workspace
  What it does: Opens the dashboard before verifying (reads Return to sign in
                if the address already had an account)

Full guides: Sign up [sign-up.txt], Sign in and sign out [sign-in.txt],
Passwords [passwords.txt].

UPGRADE DIALOG
==============

Some paid conveniences open a dialog instead of a page. Its title is "Do more
with" a plan, "You're on a roll" (when a free allowance is used up), or "Not
available yet" (when the feature belongs only to a tier not on sale). It lists
up to four perks and the monthly price, with Upgrade to the plan and Not now
(or See the roadmap and Close). Its footer reads "Every tool stays free",
"One-time — never auto-renews" and "7-day money-back". Close it with ×, Not
now, `Esc` or by clicking outside.
