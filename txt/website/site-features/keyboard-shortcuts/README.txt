==============================================================================
KEYBOARD SHORTCUTS
==============================================================================
The master list of keyboard shortcuts for the whole Auric Artisan website.
Area: Website › Site features › Keyboard shortcuts   Updated: 2026-09-25

Almost everything on auricartisan.com can be reached from the keyboard. This
section gathers every site-wide shortcut in one place: search, settings, the
guide, reading mode, theme, text size, split view, the recorder, the kits and
the right-click menu, followed by the keys that work inside each panel.

On a Mac, use `Cmd` where this list says `Ctrl` for the shortcuts marked "Ctrl
or Cmd". Shortcuts that use `Alt` use the `Option` key on a Mac.

Letter shortcuts are ignored while you are typing in a text field, so they
never interfere with what you type.

WHO IT IS FOR
=============

Keyboard users, power users, and anyone who wants to move faster around the
site.

WHERE TO FIND IT
================

  - The full list: docs/reference.md [docs/reference.txt].
  - Inside the site: Settings (`Ctrl` + `,`) › Shortcuts lists the Settings
    panel's own shortcuts, and right-click › Site › Keyboard shortcuts opens
    it.

QUICK START
===========

  1. Press `Ctrl` + `K` and search for anything.
  2. Press `Ctrl` + `,` to open Settings.
  3. Press `?` for the page guide.
  4. Press `Alt` + `R` for reading mode, and again to leave it.
  5. Press `Ctrl` + `Shift` + `D` for split view, and `Esc` to close it.

THE TEN MOST USEFUL
===================

  Keys                                    | Action
  ----------------------------------------+------------------------------------
  `Ctrl` + `K`                            | Search the site (Spotlight)
  `Ctrl` + `,`                            | Settings
  `?`                                     | Page guide and tour
  `Alt` + `R`                             | Reading mode
  `Alt` + `T`                             | Switch theme
  `Alt` + `+` / `Alt` + `-` / `Alt` + `0` | Text size
  `Ctrl` + `Shift` + `D`                  | Split view
  `Alt` + `Shift` + `R`                   | Screen recorder
  `Shift` + right-click                   | Your browser's own right-click menu
  `Esc`                                   | Close the open panel or menu
