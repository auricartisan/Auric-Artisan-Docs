==============================================================================
LANGUAGE GLOSSARY
==============================================================================
Terms used in the language guides.
Area: Website › Site features › Language   Updated: 2026-09-25

  Term:    Devanagari
  Meaning: The script used to write Hindi (हिन्दी).

  Term:    Transliteration
  Meaning: Writing a name in another script by its sound, not its meaning,
           such as ऑरिक आर्टिज़न for Auric Artisan.

  Term:    Translation in place
  Meaning: Replacing the text of a page that is already open, without loading
           it again.

  Term:    Locale
  Meaning: The language and region conventions used to write dates, times and
           numbers, such as Hindi (India).

  Term:    Query parameter
  Meaning: A part of a web address after `?`, such as `?lang=hi`, that passes
           a setting to the page.
