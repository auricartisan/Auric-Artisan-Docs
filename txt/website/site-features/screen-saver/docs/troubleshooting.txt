==============================================================================
TROUBLESHOOTING THE SCREEN SAVER
==============================================================================
Fixes for common screen saver problems.
Area: Website › Site features › Screen saver   Updated: 2026-09-25

THE SCREEN SAVER NEVER STARTS
=============================

Possible causes and fixes:

  - It is off. Switch on Screen saver in Settings › Comfort.
  - Something keeps registering as activity, for example a mouse that drifts
    slightly or a page that scrolls itself. Keep the mouse still.
  - A few pages do not include the screen saver. Try another page.
  - The idle check runs every ten seconds, so allow a few seconds beyond your
    chosen time.

IT STARTS TOO SOON OR TOO LATE
==============================

What to do: change Start after in Settings › Comfort. The new time applies at
the next check.

MY COMPUTER'S OWN SCREEN SAVER OR SLEEP TAKES OVER FIRST
========================================================

Why: your operating system's power settings are separate from the site. If the
system dims or sleeps sooner than the site's delay, you will not see the
site's screen saver.

What to do: choose a shorter Start after, or a longer delay in your system
settings.

THE COLOUR READOUT IS MISSING AND ONLY A PLAIN COLOUR SHOWS
===========================================================

Why: the colour list is downloaded the first time the screen saver starts. If
that fails, the screen saver uses a small built-in set of colours instead.

What to do: nothing is needed; it still works. Check your connection if you
want the full atlas.
