DEVICE SETTINGS THE SITE FOLLOWS
================================

  Device setting: Dark or light mode
  Site behaviour: Followed when the theme is System

  Device setting: Reduced motion
  Site behaviour: Custom cursor off; eye-rest horizon still; shorter welcome;
                  bars swap without fading

  Device setting: Touch screen or no hover
  Site behaviour: Custom cursor off

  Device setting: Speech voice
  Site behaviour: Used by Read aloud in the right-click menu
