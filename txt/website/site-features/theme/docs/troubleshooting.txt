==============================================================================
TROUBLESHOOTING THEMES
==============================================================================
Fixes for common theme problems.
Area: Website › Site features › Theme   Updated: 2026-09-25

THE SITE DOES NOT FOLLOW MY DEVICE ANY MORE
===========================================

Why: a light/dark toggle (the header button, the right-click menu, Spotlight
or the card menu) fixes the theme and leaves System mode.

What to do: choose System in Settings › Appearance, or Auto in the mobile
drawer.

THE SITE IS DARK BUT MY DEVICE IS LIGHT (OR THE OTHER WAY ROUND)
================================================================

Possible causes:

  - You chose Light or Dark at some point, so System mode is off. Open
    Settings and check Theme.
  - Your browser has its own theme setting that overrides the device. In some
    browsers you can set the website appearance separately from the operating
    system.

ONE PANEL IS IN A DIFFERENT THEME FROM THE PAGE
===============================================

Why: kits remember their own theme once you use their theme button, and
split-view panes can be forced light or dark.

What to do: use the kit's own theme button to match the page. For split view,
set the pane's theme back to Auto.

MY THEME CHANGED AFTER I OPENED A LINK SOMEONE SENT ME
======================================================

Why: page links copied from the site can carry the sender's appearance
settings, including the theme mode. See Shareable links
[../../shareable-links/README.txt].

What to do: set your theme again in Settings.

THE THEME RESETS EVERY TIME I CLOSE THE BROWSER
===============================================

Why: you are using a private window, or your browser clears site data on exit.

What to do: use a normal window, or allow auricartisan.com to keep site data.
