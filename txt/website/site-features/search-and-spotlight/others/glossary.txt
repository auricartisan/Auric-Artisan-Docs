==============================================================================
SPOTLIGHT GLOSSARY
==============================================================================
Terms used in the Spotlight search guides.
Area: Website › Site features › Search and Spotlight   Updated: 2026-09-25

  Term:    Spotlight
  Meaning: The floating search box opened with `Ctrl` + `K`.

  Term:    Scope
  Meaning: The part of the site a search covers: All, Pages, Tools, Docs,
           Learn or Web.

  Term:    Launcher
  Meaning: A shortcut row shown when the search box is empty.

  Term:    Index
  Meaning: The list of the site's pages and their words that Spotlight
           searches.

  Term:    Preview pane
  Meaning: The panel beside the results showing details of the highlighted
           result or a colour answer.

  Term:    Field filter
  Meaning: A prefix such as `title:` that limits a search to one part of each
           page.

  Term:    Exclusion
  Meaning: A word with a minus sign in front, such as `-gradient`, which
           removes matching pages.

  Term:    Command mode
  Meaning: The mode entered by typing `>`, which lists actions instead of
           pages.

  Term:    Contrast ratio
  Meaning: The WCAG measure of lightness difference between two colours, from
           1:1 to 21:1.

  Term:    AA, AAA
  Meaning: WCAG contrast levels: AA body text needs 4.5:1, AAA needs 7:1, AA
           large text needs 3:1.

  Term:    OKLCH
  Meaning: A way of writing a colour as lightness, chroma and hue that follows
           human perception closely.
