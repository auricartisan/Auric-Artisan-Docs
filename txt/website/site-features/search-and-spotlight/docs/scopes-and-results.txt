SCOPE TABS
==========

The tabs under the search box decide where Spotlight looks. The box's
placeholder changes to match.

  Tab:         All
  Searches:    Everything on the site
  Placeholder: Search Auric Artisan…

  Tab:         Pages
  Searches:    Site pages such as home, collections, company and security (not
               tools, documentation or Learn)
  Placeholder: Search pages…

  Tab:         Tools
  Searches:    Every tool page
  Placeholder: Search tools…

  Tab:         Docs
  Searches:    Documentation and developer references
  Placeholder: Search documentation…

  Tab:         Learn
  Searches:    Learn colour-science guides
  Placeholder: Search learn guides…

  Tab:         Web
  Searches:    Trusted sources on the wider web
  Placeholder: Search the web…

Switch scope by selecting a tab, or press `Tab` (next) and `Shift` + `Tab`
(previous) while the search box has focus. Your query re-runs in the new scope
at once. Spotlight remembers the scope you chose until you reload the page.

With an empty box, each scope shows its own launch points:

  Scope:     All
  Heading:   Quick Actions
  Launchers: Full Search, Collections, URL Analyzer, Color Science Lab,
             Documentation, Learn Color, Vision Simulations, Install the PWA,
             Install Extension

  Scope:     Pages
  Heading:   Jump to Pages
  Launchers: Home, Collections, About, Pricing, FAQ, Contact, Security

  Scope:     Tools
  Heading:   Jump to Tools
  Launchers: URL Analyzer, Color Science Lab, Vision Simulations, ASCII,
             Ishihara Plates, General Tools

  Scope:     Docs
  Heading:   Jump to Docs
  Launchers: Documentation Home, Changelog

  Scope:     Learn
  Heading:   Jump to Learn
  Launchers: Learn Color, Blog

  Scope:     Web
  Heading:   Web search
  Launchers: A hint: "Type at least 2 characters to search trusted sources
             across the web."

READING THE RESULTS
===================

  - Searching starts once you have typed two characters.
  - Up to 8 results are listed, under Results. The footer shows the total and
    how long the search took, for example "23 results · 2ms".
  - Each result shows an icon for its kind (page, documentation, tool, article
    and so on), the title with your words highlighted, an excerpt, and the
    page address.
  - The last row, View all results for "…", opens
    https://auricartisan.com/search/ with your query, where you can see every
    result with filters and previews.

THE PREVIEW PANE
================

When a result is highlighted (by the arrow keys or by pointing at it), the
pane on the right shows:

  - the kind of page, its title, address and description;
  - Why it ranks here: up to four bars, one for each part of the page your
    words matched (such as its title, tags, description or body text), each
    labelled with how heavily that part counts, for example ×6 for the title.
    Longer bars contributed more.

WHEN NOTHING IS FOUND
=====================

The list reads "No results for "…"", with "in Pages" (or the scope you chose)
when a scope is active. Under Try instead:

  - Show all N results — shown when the query matches elsewhere on the site
    but not in this scope. Selecting it switches to All.
  - Search the web for "…" — switches to the Web tab.
  - Open full search page — opens the full search page with your query.

SEARCHING THE WEB
=================

The Web tab searches a curated set of trusted sources beyond auricartisan.com.

  1. Select Web (or Search the web for "…" under Try instead).
  2. Type at least two characters. The list reads "Searching trusted
     sources…".
  3. Up to 8 results appear, each with its title, an excerpt and the source's
     name. The footer shows the count, the time taken and how many pages were
     checked.
  4. Select a result. It opens in a new tab.

If the web search service cannot be reached, the list reads "Global search is
unavailable right now". If no trusted source matches, it reads "No trusted web
results for "…"". Web search needs a network connection.

RECENT SEARCHES
===============

  - When you open a result, the query that found it (if at least two
    characters) is added to Recent, most recent first. Up to six are kept,
    without duplicates.
  - Recent shows whenever the box is empty. Select an entry to run it again.
  - Select Clear beside the heading to remove them all.

Recent searches are kept in this browser only.

HOW RESULTS ARE RANKED
======================

Results are ranked by how well your words match, with more weight for matches
in the title and tags than in the body text. Pages whose title starts with or
contains your whole query rank higher, and pages that you have opened from
search before get a small boost in this browser. Close spelling mistakes are
still matched, and common alternative words are understood: for example
`color` finds "colour", `a11y` finds accessibility pages, and `audit` finds
the Analyzer.
