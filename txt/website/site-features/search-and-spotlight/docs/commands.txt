==============================================================================
COMMANDS
==============================================================================
Use Spotlight as a command palette by typing > to switch theme, open the
guide, library or settings, change language and more.
Area: Website › Site features › Search and Spotlight   Updated: 2026-09-25

Type `>` at the start of the Spotlight box to switch to command mode. The chip
reads Command, and the list shows actions you can run on this page instead of
pages you can open.

RUN A COMMAND
=============

  1. Press `Ctrl` + `K` and type `>`.
  2. The list shows every command available on this page, under the heading
     Commands. The footer counts them, for example "7 commands".
  3. Keep typing to narrow the list, for example `>theme`.
  4. Select a command, or highlight it and press `Enter`.

If nothing matches, the list reads "No command matches that on this page."

THE SITE'S COMMANDS
===================

  Command:     Toggle light and dark
  Description: The header's theme button
  Shows:       The current theme, and `⌥T`

  Command:     Open the page guide
  Description: What this page is, and its tour
  Shows:       —

  Command:     Open the library
  Description: Saved palettes, gradients and reports
  Shows:       —

  Command:     Open settings
  Description: Theme, motion, density, language
  Shows:       `⌘,`

  Command:     Switch language
  Description: English ⇄ हिन्दी
  Shows:       The current language

  Command:     Open the full search page
  Description: The whole index, with filters and instant answers
  Shows:       —

  Command:     Install the app
  Description: Offline cache and an app window
  Shows:       —

A command appears only when the page has the control it drives. For example,
Open the library is missing on a page without the library button.

The key hints are shown in Mac notation: `⌥T` is `Alt` + `T`, and `⌘,` is
`Ctrl` + `,` on Windows and Linux.

COMMANDS A PAGE ADDS
====================

Some tools add their own commands, listed first under their own headings. For
example, the Portfolio Builder uses Spotlight as its toolbar and adds commands
for its sections, typefaces and publishing. These appear only on that tool's
page. See the tool's own documentation for its commands.

COMMANDS IN HINDI
=================

When the site is in Hindi, commands are shown in Hindi, and you can type
either the Hindi or the English name to find them.
