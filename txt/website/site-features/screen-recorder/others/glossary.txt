==============================================================================
SCREEN RECORDER GLOSSARY
==============================================================================
Terms used in the screen recorder guides.
Area: Website › Site features › Screen recorder   Updated: 2026-09-25

  Term:    Source
  Meaning: What the recorder captures: a screen or window, this tab, a region,
           or a tool canvas.

  Term:    Take
  Meaning: One recording, from start to stop.

  Term:    Frame rate (fps)
  Meaning: How many images per second a video holds. Higher is smoother and
           larger.

  Term:    Resolution cap
  Meaning: The largest width a recording is allowed; bigger sources are scaled
           down.

  Term:    Canvas
  Meaning: A drawing surface that tools use for graphics and animation.

  Term:    Region
  Meaning: A rectangle of the page, or one element, that a recording is
           cropped to.

  Term:    MP4, WebM
  Meaning: Video file formats. MP4 plays almost everywhere; WebM is widely
           supported by browsers.

  Term:    GIF
  Meaning: An animated image format that plays in most apps and web pages
           without a player.

  Term:    Re-encode
  Meaning: To play a video and record it again, which is how trimming makes a
           new file.

  Term:    Sharing dialog
  Meaning: The browser's own window asking which screen, window or tab to
           share.
