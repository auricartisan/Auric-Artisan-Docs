==============================================================================
SITE FEATURES
==============================================================================
An overview of the controls, panels and helpers that appear on every page of
auricartisan.com, with links to each feature's guide.
Area: Website › Site features   Updated: 2026-09-25

Every page on https://auricartisan.com shares the same set of controls around
its content: the header and its menus, a floating navigation dock, site
search, a settings panel, a right-click menu, comfort helpers such as eye-rest
reminders and reading mode, and a few quieter pieces such as the info bars and
the cookie notice. They behave the same way on a tool, an article or a policy
page, so you only learn them once.

Most of these features keep their choices in your browser, not in an account.
They work signed out, and many of them keep working offline once the site is
installed as an app (see Download and offline
[../download-and-offline/README.txt]).

The floating kits (Feature Kit, Library Kit, UX Kit, Menu Kit, Status Kit,
Update Kit and Advanced Kit) also appear on every page. They have their own
section: see Kits [../kits/README.txt].

WHO THIS SECTION IS FOR
=======================

  - Anyone using the site for the first time and wondering what a button or
    panel does.
  - People who want the site to look or behave differently: larger text, less
    motion, a different accent colour, Hindi instead of English, no custom
    cursor.
  - Keyboard users who want the full list of shortcuts.

QUICK START
===========

  1. Open any page on https://auricartisan.com.
  2. Press `Ctrl` + `K` (or `Cmd` + `K` on a Mac) to search the site from
     anywhere.
  3. Press `Ctrl` + `,` to open the Settings panel and choose a theme, an
     accent colour and a text size.
  4. Right-click anywhere on the page to see the site's own menu. Hold `Shift`
     while you right-click to get your browser's menu instead.
  5. Press `?` to open the guide for the page you are on.
  6. Select the globe button in the header to switch the site to Hindi, and
     select it again to switch back.

IN THIS FOLDER
==============

Each feature folder follows the same layout: a `README.md` overview, a `docs/`
folder with task guides and a full reference, and an `others/` folder with the
glossary, related links and privacy notes. Start with the feature's
`README.md`.
