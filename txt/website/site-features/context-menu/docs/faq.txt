==============================================================================
RIGHT-CLICK MENU FAQ
==============================================================================
Short answers to common questions about the site's right-click menu.
Area: Website › Site features › Right-click menu   Updated: 2026-09-25

CAN I TURN THE SITE MENU OFF?
=============================

Yes. Right-click, select the gear, and under Right-click on this site choose
The browser’s menu. The site menu is then available only with `Shift` +
right-click or from the line at the right edge of the window.

DOES THE MENU WORK ON PHONES AND TABLETS?
=========================================

A long press on a touch screen is handled by the browser and usually opens the
browser's own menu or text selection. The site menu is designed for a mouse,
trackpad or keyboard.

WHERE DO SEARCH THE WEB AND TRANSLATE SEND MY TEXT?
===================================================

Only where you ask. Search the web opens the search engine you pick in a new
tab with the selected text in the address. Translate opens Google Translate in
a new tab. Nothing is sent until you choose one of them.

IS MY QUICK BAR THE SAME IN EVERY BROWSER?
==========================================

No. Pins and preferences are kept in the browser you set them in.

WHY DOES THE SAME MENU LOOK SHORTER ON SOME PAGES?
==================================================

Some rows depend on what the page loads. Published portfolio pages, for
example, have no colour tools and remove some site actions, so their menu is
shorter.

IS THE BROWSER EXTENSION'S MENU THE SAME THING?
===============================================

No. The Auric Artisan browser extension has its own right-click menu for other
websites. On auricartisan.com the extension steps aside and the site's own
menu is the one you see. See Browser extension
[../../../../browser-extension/README.txt].

CAN I SEE THE COLOUR FORMATS BEFORE COPYING?
============================================

Yes. Each colour copy row shows the exact value it will copy.
