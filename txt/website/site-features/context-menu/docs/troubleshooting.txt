==============================================================================
TROUBLESHOOTING THE RIGHT-CLICK MENU
==============================================================================
Fixes for common problems with the site's right-click menu.
Area: Website › Site features › Right-click menu   Updated: 2026-09-25

I GET MY BROWSER'S MENU INSTEAD OF THE SITE MENU
================================================

Possible causes and fixes:

  - You right-clicked inside a text field, drop-down or editable area. These
    always keep the browser's menu. Right-click outside the field.
  - You held `Shift`. Right-click again without it.
  - You chose Browser’s own menu on your previous right-click. That lasts for
    one right-click only; try again.
  - You set Right-click on this site to The browser’s menu. Hold `Shift` and
    right-click to reach the site menu, then change it back under the gear.
  - The page has only just loaded. The menu arrives a moment after the page;
    wait and try again.
  - You right-clicked something with its own menu, such as the clock strip or
    a card. See Other right-click menus [other-right-click-menus.txt].

I CANNOT GET MY BROWSER'S MENU
==============================

Hold `Shift` while you right-click. If you often need it, make it the default
under the gear (Right-click on this site › The browser’s menu).

A COPY ACTION SAYS "COULD NOT COPY"
===================================

Why: the browser blocked access to the clipboard. This can happen in some
embedded views, when the page is not in focus, or when a browser setting
blocks clipboard access.

What to do: click the page once so it has focus and try again, or select the
text and use `Ctrl` + `C`.

COPY IMAGE COPIES THE ADDRESS INSTEAD OF THE PICTURE
====================================================

Why: some browsers do not let web pages put images on the clipboard, and
images from other websites often cannot be read by the page.

What to do: use Open image in new tab and copy it from there, or Save image.

COPY ITS PALETTE IS MISSING
===========================

Why: the browser does not allow the page to read that image's pixels (usually
an image from another website), or the image has not finished loading.

What to do: wait for the image to load and right-click again. For images from
elsewhere, save the image and use the site's Image Picker tool.

THE COLOUR TOOLS GROUP IS MISSING
=================================

Why: the colour tools are not loaded on this page, for example on a published
portfolio.

What to do: open a tool page such as Basic Tools, or use `Ctrl` + `Shift` +
`C` where the tools are available.

RIGHT-CLICKING A WORD GAVE ME A COLOUR
======================================

Why: the word is also a valid hex code and contains a digit (for example
`a1b2c3`), or the element you clicked carries a colour.

What to do: use the Page row under More for the page actions, or select the
text and choose from the Selection actions if you right-click on the
selection.

A PINNED ACTION DOES NOT SHOW IN THE QUICK BAR
==============================================

Why: the action only applies to certain things, such as a colour or a link. It
appears when you right-click one.

THE MENU CLOSED WHILE I WAS USING IT
====================================

Why: scrolling the page, resizing the window, switching windows or clicking
outside the menu closes it.

What to do: keep the pointer inside the menu while scrolling its list.

READ ALOUD DOES NOTHING
=======================

Why: your device has no speech voice for the page's language, or speech is
turned off in the browser.

What to do: check your operating system's text-to-speech settings. If speech
fails, the menu shows "Reading aloud is not available".
