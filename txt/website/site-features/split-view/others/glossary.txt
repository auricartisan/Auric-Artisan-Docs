==============================================================================
SPLIT VIEW GLOSSARY
==============================================================================
Terms used in the split view guides.
Area: Website › Site features › Split view   Updated: 2026-09-25

  Term:    Live pane
  Meaning: The pane that starts with the page you were on. Closing split view
           follows it.

  Term:    Companion pane
  Meaning: The second pane, for any other page.

  Term:    Divider
  Meaning: The bar between the panes that you drag to resize them.

  Term:    Viewport
  Meaning: The width a pane's page is laid out for: desktop, tablet (820 px)
           or phone (400 px).

  Term:    Responsive
  Meaning: A page that rearranges itself to fit the width it is given.

  Term:    Compare mode
  Meaning: An overlay of both panes in which identical areas turn black and
           differences show.

  Term:    Route links
  Meaning: A mode in which links clicked in the live pane open in the
           companion.

  Term:    Scroll sync
  Meaning: Scrolling one pane scrolls the other to the same relative position.

  Term:    Eco mode
  Meaning: Automatic low-performance mode that turns off decorative effects
           when the panes run slowly.

  Term:    FPS
  Meaning: Frames per second: how smoothly the screen is updating.
