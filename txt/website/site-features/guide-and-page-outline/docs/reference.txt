WAYS TO OPEN THE GUIDE
======================

  Method: `?`
  Notes:  Not while typing in a field, and not with `Ctrl`, `Alt` or `Cmd`
          held

  Method: Header Guide button
  Notes:  Tooltip: "Search pages, tools, and quick paths, or start a guided
          tour. Shortcut: ?"

  Method: Drawer Guide tile
  Notes:  "Tours and shortcuts"

  Method: Spotlight Open the page guide
  Notes:  "What this page is, and its tour"

GUIDE PANEL
===========

  Part:    Head
  Content: Kicker, page title, summary

  Part:    Filter box
  Content: "Filter this guide…"

  Part:    Tabs
  Content: All, Tour, Tools, Pages, Learn, Help

  Part:    Tour card
  Content: Take the guided tour / Pick up where you left off / Replay the tour

  Part:    Start over
  Content: Start over from stop 1 (after leaving part-way)

  Part:    On this page
  Content: Numbered stops for this page; tick when seen

  Part:    Getting around
  Content: The site-wide stops, with "x/y seen"

  Part:    Elsewhere
  Content: Full Search, Analyze a website, Find the right tool, Open saved
           work, Read documentation, Learn color concepts, Install the PWA,
           Install the extension

  Part:    Recommended paths
  Content: Run a quick audit, Build color assets, Check accessibility, Find a
           feature fast

  Part:    Close
  Content: X (Close guide), ESC button, click outside

GUIDE KINDS
===========

Home, Analyzer, Collections, Search, Workspace, Library, Tool, Company, Policy
and Site guides, chosen from the page you are on.

RECOMMENDED PATHS
=================

  Path:  Run a quick audit
  Steps: Open Analyzer · Paste a URL · Stay in Simple mode · Check Overview,
         Fixes and Report

  Path:  Build color assets
  Steps: Start in Collections · Choose a generator · Refine the palette or
         gradient · Save useful outputs

  Path:  Check accessibility
  Steps: Use Analyzer or the accessibility library to inspect contrast, vision
         simulation, and readable pairs

  Path:  Find a feature fast
  Steps: Open Search from the header · Type the tool name or task · Open the
         best match

KEYS IN THE GUIDE PANEL
=======================

  Keys                      | Action
  --------------------------+------------------------------------------------------------
  Type                      | Filter
  `Down` / `Up`             | Next or previous item
  `Home` / `End`            | First or last item (not in the filter box)
  `Enter`                   | Open the focused item, or the top match from the filter box
  `Left` / `Right` on a tab | Previous or next tab
  `Esc`                     | Close the guide

TOUR CARD AND CONTROLS
======================

  Control                     | Key
  ----------------------------+--------------------
  Next                        | `Right`
  Back                        | `Left`
  Finish                      | —
  Leave the tour (X)          | `Esc`
  Skip to this page’s N stops | —
  What to look for            | Expands the details

SECTION RAIL
============

  Item            | Behaviour
  ----------------+------------------------------------------------------------------------------
  Label           | "On this page"
  Pages           | Company About, Pricing, Accessibility, FAQ; all legal pages; the Trust Center
  Pinned          | Below the header while scrolling
  Current section | Highlighted
  Legal pages     | Jumping opens folded sections

STORED
