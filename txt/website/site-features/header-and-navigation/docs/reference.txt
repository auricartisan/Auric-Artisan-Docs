QUICK TOOLS (WIDE SCREENS)
==========================

  Button:              Get the app
  Tooltip title:       Browser PWA
  Tooltip description: Use Auric Artisan in a browser tab with offline cache.
  Action:              Opens `/download/`

  Button:              Browser extension
  Tooltip title:       Browser Extension
  Tooltip description: Download the Auric Artisan toolbar extension package.
  Action:              Opens `/extension.html`

  Button:              VS Code extensions
  Tooltip title:       VS Code Extensions
  Tooltip description: Auric icon collections and colour themes for Visual
                       Studio Code.
  Action:              Opens `/vscode/`

  Button:              Search
  Tooltip title:       Search
  Tooltip description: Open site search. Shortcut: Ctrl+K.
  Action:              Opens Spotlight

  Button:              Open guide
  Tooltip title:       Guide
  Tooltip description: Search pages, tools, and quick paths, or start a guided
                       tour. Shortcut: ?
  Action:              Opens the guide

  Button:              Open library
  Tooltip title:       Library
  Tooltip description: Open your saved palettes, gradients, presets and
                       exports.
  Action:              Opens the library panel

  Button:              Language
  Tooltip title:       Language / भाषा
  Tooltip description: Switch the site between English and Hindi.
  Action:              Toggles English and Hindi

  Button:              Theme
  Tooltip title:       Theme
  Tooltip description: Switch between light and dark mode.
  Action:              Toggles light and dark

  Button:              Sign in
  Tooltip title:       Sign in
  Tooltip description: Sign in or create your free Auric Artisan account to
                       save and sync your work.
  Action:              Opens `/auth/`

MOBILE DRAWER (NARROW SCREENS)
==============================

  Area:    Bar
  Control: Search
  Action:  Opens Spotlight

  Area:    Bar
  Control: Menu button (Open navigation / Close navigation)
  Action:  Opens or closes the drawer

  Area:    Drawer
  Control: Search tools, colours and pages
  Action:  Opens Spotlight

  Area:    Browse
  Control: Company, Tools, Learn (with counts)
  Action:  Open in place

  Area:    Browse › Tools
  Control: Group chips with counts
  Action:  Show one group's tools

  Area:    Your work
  Control: Library — Saved palettes and exports
  Action:  Opens the library panel

  Area:    Your work
  Control: Guide — Tours and shortcuts
  Action:  Opens the guide

  Area:    Get Auric
  Control: The app — Works offline in a browser tab
  Action:  Opens `/download/`

  Area:    Get Auric
  Control: Browser extension — The Auric toolbar in your browser
  Action:  Opens `/extension.html`

  Area:    Get Auric
  Control: VS Code — Icon collections and colour themes
  Action:  Opens `/vscode/`

  Area:    Preferences
  Control: Theme: Auto, Light, Dark
  Action:  Sets the theme mode

  Area:    Preferences
  Control: Language: English, हिन्दी
  Action:  Sets the language

  Area:    Foot
  Control: Sign in, Create account
  Action:  Open `/auth/` and `/auth/#register`

Breakpoints: the drawer replaces the desktop header below 960 pixels; it is a
400-pixel side sheet from 600 to 959 pixels, and a full-width sheet below 600
pixels.
