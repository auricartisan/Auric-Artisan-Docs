==============================================================================
SEARCH GLOSSARY
==============================================================================
Terms used on the Auric Artisan search page and in the Search Console.
Area: Website › Search   Updated: 2026-09-25

  Term:    AuricBot
  Meaning: The name Auric Artisan's crawler uses when it fetches pages.

  Term:    BM25F
  Meaning: The ranking method site search uses: it scores word matches,
           weighting each field of a page differently.

  Term:    Canonical address
  Meaning: The address a page names as its preferred version, with a
           `rel=canonical` link.

  Term:    Click
  Meaning: In the Search Console, a searcher opening your page from a
           web-search result.

  Term:    Click-through (CTR)
  Meaning: Clicks divided by impressions.

  Term:    Coverage
  Meaning: Which of a site's addresses are in the index, and why the others
           are not.

  Term:    Crawl
  Meaning: Fetching a page so it can be indexed.

  Term:    Crawled index
  Meaning: Auric Artisan's own index of the web, searched with the globe.

  Term:    Crawl-delay
  Meaning: A robots.txt line asking crawlers to wait between requests.

  Term:    Exclusion
  Meaning: A `-word` in a query, which leaves out pages containing the word.

  Term:    Field filter
  Meaning: An operator such as `type:` or `tag:` that narrows results by one
           field.

  Term:    Impression
  Meaning: In the Search Console, one appearance of your page in a web-search
           result.

  Term:    Index
  Meaning: The collection of pages a search looks through.

  Term:    Index build
  Meaning: The step that makes crawled pages searchable.

  Term:    Inspection
  Meaning: The Search Console panel that explains one address.

  Term:    LOCAL, GLOBAL
  Meaning: The mode label: site search or web search.

  Term:    noindex
  Meaning: A robots meta tag or header asking search engines not to index a
           page.

  Term:    Pace
  Meaning: How long the crawler waits between requests to one site.

  Term:    Phrase
  Meaning: Words in quotes, which must appear together and in order.

  Term:    Position
  Meaning: Where a result appeared in the list; 1 is the top.

  Term:    Property
  Meaning: A site you have added to the Search Console.

  Term:    Rank (static rank)
  Meaning: A page's or site's weight from links between sites, out of 255.

  Term:    Related word
  Meaning: A word linked to yours, such as swatch for palette, matched at
           reduced weight.

  Term:    robots.txt
  Meaning: A file at the root of a site that tells crawlers what they may
           fetch.

  Term:    Section tab
  Meaning: A filter on the search page for one kind of page, such as Learn.

  Term:    Sitemap
  Meaning: A file listing a site's addresses for crawlers.

  Term:    Verification
  Meaning: Proving to the Search Console that you own a site.

  Term:    WCAG 2.1
  Meaning: The Web Content Accessibility Guidelines version whose contrast
           formula the answer cards use.
