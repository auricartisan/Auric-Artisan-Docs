==============================================================================
TEMPLATES
==============================================================================
Start a portfolio from one of eight templates, and what each template
contains.
Area: Website › Portfolio   Updated: 2026-09-25

A template replaces your sections with a ready-made set of example sections
for a kind of portfolio. It does not change your header or your style.

USE A TEMPLATE
==============

  1. Select Templates in the top bar, or type "template" in the command field
     and choose Start from a template.
  2. The Start from a template dialog shows eight tiles. Select one; a tick
     marks it.
  3. Select Use this template, or Cancel (or `Escape`, or click outside the
     dialog) to leave without changing anything.

The builder confirms, for example, Designer template applied. Your previous
sections are replaced, but you can bring them back with Undo.

THE EIGHT TEMPLATES
===================

  Template:               Designer
  Description (as shown): Work-first — selected projects, an about section,
                          skills and links.
  Main sections:          Selected Work heading, your library work (up to 9),
                          About heading and text, skills, Elsewhere links
                          (Dribbble, Instagram).

  Template:               Developer
  Description (as shown): Intro, tech stack, a projects grid and a code
                          snippet.
  Main sections:          Intro text, Stack skills, Projects heading and your
                          library work, a code snippet, links (GitHub, Email).

  Template:               Photographer
  Description (as shown): Visual-first — a portfolio grid, stats and a booking
                          call-to-action.
  Main sections:          Intro text, Portfolio work grid (up to 12), stats
                          (shoots, countries, clients), a Book a session call
                          to action.

  Template:               Freelancer
  Description (as shown): Services, a how-we-work process, a testimonial and a
                          CTA.
  Main sections:          Intro text, Services features, How we work steps, a
                          testimonial, a Have a project? call to action.

  Template:               Founder
  Description (as shown): Startup one-pager — traction stats, features,
                          milestones and contact.
  Main sections:          Intro text, Traction stats, What we do features,
                          Milestones timeline, a Want to talk? call to action.

  Template:               Writer
  Description (as shown): Selected writing, an about, a pulled quote and
                          links.
  Main sections:          Intro text, Selected writing links, About text, a
                          quote, Elsewhere links (Newsletter, Twitter).

  Template:               Resume
  Description (as shown): A formal CV — experience, skills, education and
                          contact.
  Main sections:          Summary text, Experience timeline, skills, Education
                          timeline, Contact links (Email, LinkedIn).

  Template:               Minimal
  Description (as shown): Just a short intro line and a couple of links.
                          Nothing else.
  Main sections:          One line of text and links (Email, Twitter).

The example words are placeholders: replace them by typing into the preview or
the section cards.

RESULT
======

Your page has a full, sensible structure in one step, ready to fill in.
