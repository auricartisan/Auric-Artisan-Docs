==============================================================================
WHAT EACH MODE CHANGES
==============================================================================
Every part of auricartisan.com that follows the tool visibility mode, from the
Menu Kit and collections to page wording and the Feature Kit calculator.
Area: Website › Kits › Advanced Kit   Updated: 2026-09-25

The mode you pick in the Advanced Kit is read by several parts of the site.
This page lists each one and what it does in each mode.

SUMMARY
=======

  Part of the site: Menu Kit tiles and search
  Basic:            Basic and both tools
  Advanced:         Advanced and both tools
  Everything:       All
  Custom:           All except unticked tools

  Part of the site: Tool collections
  Basic:            Basic and both tools
  Advanced:         Advanced and both tools
  Everything:       All, including cards hidden earlier
  Custom:           All except unticked tools

  Part of the site: Feature Kit calculator keypads
  Basic:            Basic only
  Advanced:         Scientific, Programmer
  Everything:       All three
  Custom:           All three

  Part of the site: Page wording (see below)
  Basic:            Basic wording
  Advanced:         Advanced wording
  Everything:       Everything wording
  Custom:           Basic wording

MENU KIT
========

The Menu Kit shows only the tools the mode allows, in its tiles and in its
search results. A tab with nothing to show is hidden:

  - Basic: the Design tab disappears.
  - Advanced: the Design tab appears, and the General Color Tools section of
    the Tools tab is hidden.
  - Everything: every tab and page.
  - Custom: every page except unticked tools.

See Find a page [../../menu-kit/docs/find-a-page.txt].

TOOL COLLECTIONS
================

Tool collection grids, such as the one at
https://auricartisan.com/collections/, show only the tools the mode allows. In
Everything mode they also bring back cards that were hidden, whether you hid
them or the grid hid them because you had not used them. While you search a
collection, every matching tool shows, whatever the mode.

See Collections [../../../library/collections/README.txt].

FEATURE KIT CALCULATOR
======================

The calculator's keypad tabs follow the mode:

  - Basic: only the Basic keypad.
  - Advanced: the Scientific and Programmer keypads; the Basic keypad is
    hidden.
  - Everything and Custom: all three.

The expression bar works the same in every mode. See Calculator
[../../feature-kit/docs/calculator.txt].

PAGE WORDING
============

Some pages switch between plainer and more technical wording. Page titles in
the browser tab and search-engine descriptions do not change.

  Page:         Home page
  What changes: The tagline under the welcome heading
  Basic:        Play with color
  Advanced:     tools that respect intelligence
  Everything:   Color · Science · Design

  Page:         URL Analyzer
  What changes: The placeholder in the URL box
  Basic:        Enter a URL to analyze…
  Advanced:     Enter a URL for deep DOM, SEO, contrast & accessibility audit…
  Everything:   Enter a URL to analyze colors, contrast, SEO, and
                accessibility…

  Page:         Vision Simulation
  What changes: The search box placeholder
  Basic:        Search simulations…
  Advanced:     Search models, adaptation…
  Everything:   Search simulations, tools…

  Page:         Colour Science Lab
  What changes: The search box placeholder
  Basic:        Search color tools…
  Advanced:     Search mixers, gamut mapping, spectral tools…
  Everything:   Search color science tools…

  Page:         Colour Science Lab
  What changes: The subtitle under the heading
  Basic:        A short description of mixers, converters and harmony tools
  Advanced:     A technical description of perceptual mixing, spectral
                simulation and gamut mapping
  Everything:   A description covering both

  Page:         Basic Colour Tools
  What changes: The subtitle under the heading
  Basic:        Essential tools: palette maker, gradient builder, picker,
                converters
  Advanced:     The advanced workspace: OKLCH gradients, palette battles,
                remix, precision conversion
  Everything:   All seven tools in one floating-panel workspace

  Page:         Basic Colour Tools
  What changes: The search box placeholder
  Basic:        Search palette, gradient, picker…
  Advanced:     Search palette, remix, battle, gradient, collage, converter…
  Everything:   Search palette, remix, battle, gradient, picker, collage,
                converter…

  Page:         Basic Colour Tools
  What changes: The label of the guide note
  Basic:        Quick Start:
  Advanced:     Pro Tips:
  Everything:   Quick Start:

  Page:         Ishihara Plate Generation
  What changes: The subtitle under the heading
  Basic:        A plain explanation of what the plates do
  Advanced:     A technical description of seeded plate synthesis, ΔE
                separation and the 38-plate set
  Everything:   A combined description

In Custom mode, pages use the Basic wording.

When you switch mode, the wording changes on the page you are on straight
away, with a short transition.

  | Note: The public changelog calls the part of the site that makes these wording
  | changes the "UX Kit". It has no panel of its own; the Advanced Kit is how you
  | control it.

WHAT THE MODE NEVER CHANGES
===========================

  - No tool is locked. Every tool page opens from its address in every mode.
  - Your saved items in the Library Kit, your settings and your account are
    not affected.
  - The site-wide search is not filtered by the mode.
