==============================================================================
ADVANCED KIT TROUBLESHOOTING
==============================================================================
Fixes for Advanced Kit problems, such as a mode that changes by itself or a
tool that will not reappear.
Area: Website › Kits › Advanced Kit   Updated: 2026-09-25

For problems shared by every kit, see Troubleshooting kits
[../../docs/troubleshooting.txt].

MY MODE CHANGED BY ITSELF
=========================

Why: Some tools have their own mode switch that sets the same site-wide mode.
Opening the URL Analyzer sets the site to Basic or Advanced to match the
Analyzer's Simple or Advanced mode. The Vision Simulation lab and the Colour
Science Lab can also change it, and resetting the Vision Simulation filters
sets Everything.

What to do: Open the Advanced Kit and choose your mode again. If you were in
Custom mode, your ticks are still there; select Custom to use them again.

A TOOL I UNTICKED STILL APPEARS
===============================

Why: Your ticks only apply while the current mode is Custom. Another mode may
be active, or a tool may have changed the mode (see above).

What to do: Check Current mode in the Advanced Kit and select Custom.

A TOOL I WANT IS MISSING FROM THE MENU
======================================

Why: The current mode hides it, or you unticked it in Custom mode.

What to do: Select Everything, or tick the tool in Custom mode. Every tool
also opens from its own address.

THE CUSTOM CHECKLIST SAYS "NO TOOLS FOUND."
===========================================

Why: The tool list could not be downloaded.

What to do: Check your connection, reload the page, and open the Advanced Kit
again.

THE CHECKLIST NAMES DO NOT MATCH THE MENU KIT
=============================================

Why: The checklist uses the names from the tool collections where it can, such
as Analyze URLs for the URL Analyzer and Basic Tools for Basic Color Tools.

What to do: Search for a word in the tool's name, such as `analy` or `basic`.

CTRL + SHIFT + A DOES NOTHING
=============================

Why: Some browsers use this key combination for their own features and act on
it first.

What to do: Open the kit from Page utilities > Advanced.

THE MODE IS DIFFERENT ON MY OTHER COMPUTER
==========================================

Why: The mode is stored in each browser, not in your account.

What to do: Choose the mode once in each browser you use.

PAGE WORDING DID NOT CHANGE
===========================

Why: Only some pages have mode-dependent wording, and the browser tab title
and search-engine description never change. See What each mode changes
[what-each-mode-changes.txt].

What to do: Nothing is wrong. Tool lists, the Menu Kit and the calculator
keypads still follow the mode.
