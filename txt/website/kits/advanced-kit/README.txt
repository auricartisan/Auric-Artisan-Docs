==============================================================================
ADVANCED KIT
==============================================================================
Choose which of the site's tools you see, site-wide: Basic, Advanced,
Everything, or a Custom set you tick yourself.
Area: Website › Kits › Advanced Kit   Updated: 2026-09-25

Auric Artisan has tools for everyday colour work and tools for colour science,
vision research and diagnostics. The Advanced Kit decides which of them the
site puts in front of you. You choose one of four modes: Basic, Advanced,
Everything or Custom.

The choice applies across the whole site and is remembered in your browser. It
changes which tools appear in the Menu Kit and in the tool collections, which
keypads the Feature Kit calculator offers, and some of the wording on the home
page and on several tool pages. In Custom mode you tick individual tools on or
off from a searchable checklist.

No tool is ever locked or removed: every tool page still opens from its
address, and Everything mode shows all of them.

WHO IT IS FOR
=============

  - New visitors who want a short, friendly list of tools (Basic, the
    default).
  - Scientists, researchers and specialists who want the diagnostic and
    scientific tools up front (Advanced).
  - People who want to see the full range (Everything).
  - Regular users who want exactly their own set of tools (Custom).

WHERE TO FIND IT
================

  - On any page of https://auricartisan.com, select Page utilities in the
    bottom-left corner, then Advanced.
  - Or press `Ctrl` + `Shift` + `A`.

QUICK START
===========

  1. Press `Ctrl` + `Shift` + `A`. The Advanced Kit opens, showing Tool
     visibility and your Current mode.
  2. Under Default visibility, select the Everything card. A tick appears on
     it and Current mode changes to Everything.
  3. Open the Menu Kit (`Ctrl` + `M`). A Design tab is now present with the
     scientific tools.
  4. Back in the Advanced Kit, select the Custom card. The Choose your tools
     checklist appears.
  5. Type `lut` in Filter tools… and untick LUT Lab.
  6. Open the Menu Kit again: LUT Lab is no longer listed.
  7. Select Basic in the Advanced Kit to return to the default.

WHAT YOU CAN DO
===============

  - Switch the whole site between Basic, Advanced and Everything tool sets in
    one click.
  - Build a Custom tool set by ticking tools, with Enable all, Disable all and
    Reset.
  - Filter the checklist by name.
  - Open three example tools from quick cards: Analyze URLs, Image Color
    Picker and Generate Ishihara Plates.
