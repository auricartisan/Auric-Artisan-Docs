==============================================================================
FEATURE KIT SHORTCUTS
==============================================================================
Every keyboard shortcut the Feature Kit responds to, from opening the kit to
typing on the calculator keypad.
Area: Website › Kits › Feature Kit   Updated: 2026-09-25

The kit's menu shows ⌘ instead of Ctrl on a Mac. Where a shortcut below uses
`Ctrl`, use `Cmd` on a Mac.

OPEN, CLOSE AND MOVE AROUND
===========================

  Shortcut:     `Ctrl` + `Shift` + `K`
  Where:        Anywhere
  What it does: Opens or closes the kit. With Focus mode on, moves focus into
                the open kit instead of closing it

  Shortcut:     `Esc`
  Where:        Kit open
  What it does: In a tool, returns to the menu. On the menu, closes the kit

  Shortcut:     `1` to `6`
  Where:        Menu
  What it does: Opens Scientific Calculator, Unit Converter, Feedback, Notes,
                Date & Time, Developer Tools

  Shortcut:     `Ctrl` + `1` to `Ctrl` + `6`
  Where:        Focus inside the kit
  What it does: Switches straight to that tool, even from inside another tool
                or a text box

  Shortcut:     Arrow keys, `Home`, `End`
  Where:        Menu
  What it does: Move between the six cards

  Shortcut:     `Enter` or `Space`
  Where:        A focused card
  What it does: Opens that tool

  Shortcut:     `Left arrow`, `Right arrow`, `Home`, `End`
  Where:        A focused title-bar button
  What it does: Move between the title-bar buttons

  Shortcut:     `Tab`, `Shift` + `Tab`
  Where:        Kit open, Focus mode off
  What it does: Move between the kit's controls; focus stays inside the kit

  Shortcut:     `Enter` or `Space`
  Where:        Minimised kit icon
  What it does: Reopens the kit

Browsers commonly use `Ctrl` + a number to switch browser tabs and may act on
it before the Feature Kit does. If that happens, use the plain number keys on
the menu instead.

CALCULATOR KEYPAD
=================

These work while the Scientific Calculator is open and the cursor is not in a
text box.

  Key            | Action
  ---------------+--------------------------
  `0` to `9`     | Digit
  `+`            | Add
  `-`            | Subtract
  `*`            | Multiply
  `/`            | Divide
  `.`            | Decimal point
  `(` and `)`    | Brackets
  `^`            | Power
  `%`            | Remainder
  `!`            | Factorial
  `Enter` or `=` | Work out the expression
  `Backspace`    | Delete the last character
  `Delete`       | Clear the expression

CALCULATOR TEXT BOXES
=====================

  Key                | Where                   | Action
  -------------------+-------------------------+--------------------------
  `Enter`            | Expression bar          | Works out the expression
  `Enter` or `Space` | A focused history entry | Loads it into the display

UNIT CONVERTER
==============

  Key | Action
  ----+--------------------------------------------------------------------------
  `/` | Puts the cursor in Search units... (when the cursor is not in a text box)

DEVELOPER TOOLS
===============

  Key     | Where       | Action
  --------+-------------+------------------------
  `Enter` | Epoch input | Converts the value
  `Enter` | Cron input  | Explains the expression
