OTHER KITS
==========

  - Advanced Kit [../../advanced-kit/README.txt] — its mode decides which
    calculator keypads you see.
  - Library Kit [../../library-kit/README.txt] — for palettes, gradients and
    reports you save from the site's tools. (Feature Kit notes and
    calculations are not saved there.)
  - Menu Kit [../../menu-kit/README.txt] — jump to any tool on the site.
  - All kits [../../README.txt] and Panel controls
    [../../docs/panel-controls.txt].

TOOLS WITH RELATED FEATURES
===========================

  - Basic Colour Tools
    [../../../tools/colour-workspace/basic-colour-tools/README.txt] — colour
    format conversion, which the Unit Converter does not cover.
  - Colour Science Lab
    [../../../tools/colour-workspace/colour-science-lab/README.txt] — colour
    maths such as colour-space conversion and colour difference.
  - Design Engine [../../../tools/colour-workspace/design-engine/README.txt] —
    spacing, type and colour tokens, if you are converting units for a design
    system.
