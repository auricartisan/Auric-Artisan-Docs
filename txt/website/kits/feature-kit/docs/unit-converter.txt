==============================================================================
CONVERT UNITS
==============================================================================
Convert values between 1,344 units in 70 categories with the Feature Kit's
Unit Converter.
Area: Website › Kits › Feature Kit   Updated: 2026-09-25

The Unit Converter converts a value from one unit to another within a
category, such as metres to feet or Celsius to Fahrenheit. It has 70
categories and 1,344 units, including every metric prefix from yocto to yotta
for the units that take them.

OPEN THE CONVERTER
==================

Select the Unit Converter card on the Feature Kit menu, or press `2` on the
menu.

The first time you open it on a page, the kit downloads the unit list. A
loading message reads Loading units — Preparing the converter. It takes a
moment on a slow connection.

CONVERT A VALUE
===============

  1. Select a category pill, for example Temperature. The converter starts on
     Length.
  2. Type a number in the From box (placeholder Enter value).
  3. Choose the unit you have in the From unit list, for example celsius (°C).
  4. Choose the unit you want in the To unit list, for example fahrenheit
     (°F).

The result appears in the To row as you type, for example `98.6`, with a
sentence under it: `37 celsius = 98.6 fahrenheit`.

When you pick a category, the converter preselects its first two units.

SWAP THE UNITS
==============

Select the swap button (two opposing arrows) between From and To. The two
units change places and the result updates.

COPY THE RESULT
===============

Select the result value. A Copied! message confirms it is on your clipboard.

FIND A UNIT
===========

  1. Type part of a unit's name or symbol in Search units..., for example
     `psi` or `parsec`.
  2. The category pills narrow to the categories that contain a matching unit.
     If nothing matches, you see No matches.
  3. Select a category pill to switch to it, then pick the unit from the list.

The search finds categories; it does not choose the unit for you. Clear the
search box to see every category again.

With the cursor outside a text box, pressing `/` puts the cursor in the search
box.

==============

The converter's 70 categories, in the order the pills appear:

Flux, Inductance, Torque, Angular Velocity, Angular Acceleration, Momentum,
Impulse, Digital Storage, Data Transfer Rate, Typography, Astronomy,
Concentration, Radiation Dose, Radiation Equivalent, Radioactivity, Dynamic
Viscosity, Kinematic Viscosity, Volumetric Flow Rate, Mass Flow Rate, Luminous
Flux, Illuminance, Luminance, Luminous Intensity, Sound Level, Cooking Volume,
Angle, Specific Heat Capacity, Thermal Conductivity, Electric Conductance,
Surface Tension, Amount of Substance, Permeability, Permittivity, Electric

The number of units available shows at the bottom of the converter: 1344 units
available.

Categories with special rules
-----------------------------

Most categories convert by a fixed factor. Three do not:

  - Temperature converts through kelvin and handles offsets correctly. Units:
    kelvin (K), celsius (°C), fahrenheit (°F), rankine (°R), delisle (°De),
    newton (temp) (°N), réaumur (°Ré), rømer (°Rø).
  - Fuel Economy handles units that run in opposite directions. Units:
    kilometer per liter (km/L), miles per gallon (US) (mpg), miles per gallon
    (UK) (mpg_uk), liters per 100 km (L/100km), miles per liter (mi/L),
    gallons per 100 miles (gal/100mi). A value of 0 in a per-distance unit
    converts to `∞`.
  - Sound Level uses approximate relationships. Units: decibel (dB), bel (B),
    neper (Np), decibel (milliwatt) (dBm), decibel (watt) (dBW), sone (sone),
    phon (phon). See Limits and accuracy [../others/limits-and-accuracy.txt].

HOW RESULTS ARE SHOWN
=====================

  - Whole-number results show with thousands separators, for example
    `1,000,000`.
  - Very small (under 10^-10) or very large (over 10^12) results show in
    scientific notation with 8 decimal places.
  - Other results show up to 12 significant digits.

THINGS TO KNOW
==============

  - Use a dot for decimals. The box reads a number from the start of what you
    type, so `1,5` is read as `1`.
  - Scientific notation works in the From box: `1e3` is 1,000.
  - Unit names appear as the converter lists them, with US spellings such as
    "meter" and "liter".

IF THE UNITS DO NOT LOAD
========================

If the unit list cannot be downloaded, you see Units could not be loaded.
Check your connection, then try again. with a Try again button. Reconnect and
select Try again.
