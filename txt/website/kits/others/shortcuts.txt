==============================================================================
KIT KEYBOARD SHORTCUTS
==============================================================================
Every keyboard shortcut for opening, closing and using the kits, in one table.
Area: Website › Kits   Updated: 2026-09-25

Shortcuts that open a kit work on any page. Shortcuts that act inside a kit
work only while that kit is open. Each kit's own shortcuts page has the full
detail.

OPEN AND CLOSE KITS
===================

  Shortcut:     `Ctrl` + `Shift` + `K` (`Cmd` + `Shift` + `K` on a Mac)
  What it does: Open or close the Feature Kit

  Shortcut:     `Ctrl` + `M`
  What it does: Open or close the Menu Kit

  Shortcut:     `Ctrl` + `Shift` + `A`
  What it does: Open or close the Advanced Kit

  Shortcut:     `Ctrl` + `Shift` + `L` (`Cmd` + `Shift` + `L` on a Mac)
  What it does: Open or close the Library Kit

  Shortcut:     `Ctrl` + `Shift` + `U`
  What it does: Update the website (Update Kit)

  Shortcut:     `Esc`
  What it does: Close the page utilities bar, or close the open kit

The Status Kit has no shortcut to open it. Use the Status launcher.

INSIDE THE FEATURE KIT
======================

  Shortcut:     `1` to `6`
  What it does: On the Feature Kit menu, open Scientific Calculator, Unit
                Converter, Feedback, Notes, Date & Time or Developer Tools

  Shortcut:     `Ctrl` + `1` to `Ctrl` + `6`
  What it does: Switch straight to one of the six tools while the kit has
                focus

  Shortcut:     `Esc`
  What it does: In a tool, go back to the menu. On the menu, close the kit

  Shortcut:     Digits, `+`, `-`, `*`, `/`, `.`, `(`, `)`, `^`, `%`, `!`
  What it does: Type on the calculator keypad when the cursor is not in a text
                box

  Shortcut:     `Enter` or `=`
  What it does: Work out the calculator expression

  Shortcut:     `Backspace`
  What it does: Delete the last character on the keypad

  Shortcut:     `Delete`
  What it does: Clear the keypad

  Shortcut:     `/`
  What it does: In the Unit Converter, jump to the unit search box

See Feature Kit shortcuts [../feature-kit/others/shortcuts.txt].

INSIDE THE MENU KIT
===================

  Shortcut:     `/`
  What it does: Put the cursor in the search box

  Shortcut:     `Down arrow`
  What it does: From the search box or tabs, move into the list of pages

  Shortcut:     `Left arrow`, `Right arrow`, `Home`, `End`
  What it does: On the tabs, switch tab

  Shortcut:     Arrow keys, `Home`, `End`
  What it does: Move between pages and section headings

  Shortcut:     `Enter` or `Space`
  What it does: On a section heading, collapse or expand it

  Shortcut:     `Up arrow`, `Down arrow`, `Enter`
  What it does: While searching, move through results and open one

  Shortcut:     `Esc`
  What it does: Clear the search, then close the kit

See Menu Kit shortcuts [../menu-kit/others/shortcuts.txt].

INSIDE THE STATUS KIT
=====================

  Shortcut:     `/`
  What it does: Put the cursor in the path box, or in the results search after
                a scan

  Shortcut:     `Enter`
  What it does: In the path box, run the scan

  Shortcut:     `Down arrow`
  What it does: From the path or search box, move into the results

  Shortcut:     `Up arrow`, `Down arrow`, `Home`, `End`
  What it does: Move through the results

  Shortcut:     `Esc`
  What it does: Close the kit

See Status Kit shortcuts [../status-kit/others/shortcuts.txt].

INSIDE THE LIBRARY KIT
======================

  Shortcut                            | What it does
  ------------------------------------+------------------------------------------
  `Esc`                               | Clear the search, then close the panel
  Arrow keys                          | Move between items
  `Enter`                             | Restore the focused item into its tool
  `Delete`                            | Delete the focused item
  `Ctrl` + `A` (`Cmd` + `A` on a Mac) | Select all, while multi-select is on
  `>` then a command name             | Run a library command from the search box

See Library Kit shortcuts [../library-kit/others/shortcuts.txt].

SITE-WIDE SHORTCUTS THAT INTERACT WITH KITS
===========================================

`Ctrl` + `K` opens the site-wide search on every page, even while a kit is
open. The site settings panel has its own shortcuts, such as `Ctrl` + `,` to
open settings. Both are covered in Site features
[../../site-features/README.txt].
