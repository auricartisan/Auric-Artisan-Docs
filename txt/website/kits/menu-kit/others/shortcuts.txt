==============================================================================
MENU KIT SHORTCUTS
==============================================================================
Every keyboard shortcut the Menu Kit responds to.
Area: Website › Kits › Menu Kit   Updated: 2026-09-25

  Shortcut:     `Ctrl` + `M`
  Where:        Anywhere
  What it does: Opens or closes the Menu Kit

  Shortcut:     `/`
  Where:        Kit open, cursor not in a text box
  What it does: Puts the cursor in the search box

  Shortcut:     `Esc`
  Where:        Search box with text
  What it does: Clears the search

  Shortcut:     `Esc`
  Where:        Kit open
  What it does: Closes the kit

  Shortcut:     `Down arrow`
  Where:        Search box (not searching) or tab row
  What it does: Moves into the tiles

  Shortcut:     `Left arrow`, `Right arrow`
  Where:        Tab row
  What it does: Previous or next tab

  Shortcut:     `Home`, `End`
  Where:        Tab row
  What it does: First or last tab

  Shortcut:     Arrow keys
  Where:        Tiles and section headings
  What it does: Move to the previous or next item

  Shortcut:     `Home`, `End`
  Where:        Tiles and section headings
  What it does: First or last item

  Shortcut:     `Enter` or `Space`
  Where:        Section heading
  What it does: Collapses or expands the section

  Shortcut:     `Enter`
  Where:        Tile
  What it does: Opens the page

  Shortcut:     `Up arrow`, `Down arrow`
  Where:        Search box while searching
  What it does: Moves the highlight through the results

  Shortcut:     `Enter`
  Where:        Search box while searching
  What it does: Opens the highlighted page or runs the highlighted action

`Ctrl` + `K`, shown in the footer, opens the site-wide search rather than the
Menu Kit's search box. See Site features [../../../site-features/README.txt].

See Kit keyboard shortcuts [../../others/shortcuts.txt] for the other kits.
