==============================================================================
STATUS KIT SHORTCUTS
==============================================================================
Keys the Status Kit responds to.
Area: Website › Kits › Status Kit   Updated: 2026-09-25

The Status Kit has no shortcut to open it. Open it from Page utilities >
Status. While it is open:

  Key:          `/`
  Where:        Cursor not in a text box
  What it does: Puts the cursor in the path box, or in Search pages... after a
                scan

  Key:          `Enter`
  Where:        Path box
  What it does: Runs the scan

  Key:          `Down arrow`
  Where:        Path box or Search pages...
  What it does: Moves into the results

  Key:          `Up arrow`, `Down arrow`
  Where:        Results
  What it does: Previous or next item

  Key:          `Home`, `End`
  Where:        Results
  What it does: First or last item

  Key:          `Enter`
  Where:        A result row
  What it does: Opens the page in a new tab

  Key:          `Enter` or `Space`
  Where:        System status heading
  What it does: Collapses or expands the panel

  Key:          `Esc`
  Where:        Anywhere
  What it does: Closes the kit

`Ctrl` + `K` opens the site-wide search, not the Status Kit's boxes.

See Kit keyboard shortcuts [../../others/shortcuts.txt] for the other kits.
