==============================================================================
UPDATE KIT SHORTCUTS
==============================================================================
The keyboard shortcut for updating the website.
Area: Website › Kits › Update Kit   Updated: 2026-09-25

  Shortcut:     `Ctrl` + `Shift` + `U`
  Where:        Any page
  What it does: Runs Update website: clears the site's cached files,
                re-downloads the page's files and reloads

  Shortcut:     `Tab`, `Enter`
  Where:        Update notice
  What it does: Reach and select Update now or x

The right-click menu shows this shortcut as Ctrl+⇧+U next to Update website.

See Kit keyboard shortcuts [../../others/shortcuts.txt] for the other kits.
