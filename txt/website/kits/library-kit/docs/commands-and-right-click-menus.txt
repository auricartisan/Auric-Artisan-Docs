==============================================================================
COMMANDS AND RIGHT-CLICK MENUS
==============================================================================
Run any Library Kit action from the > command palette or from the right-click
menus for items and for the panel.
Area: Website › Kits › Library Kit   Updated: 2026-09-25

Two shortcuts put every Library Kit action within reach: a command palette in
the search box, and right-click menus.

THE COMMAND PALETTE
===================

  1. Select the search box.
  2. Type `>`. The tiles are replaced by a list of commands, each with a short
     hint.
  3. Type more to narrow the list, for example `> export`. Commands match on
     their name or hint.
  4. Press `Up arrow` or `Down arrow` to move the highlight, and `Enter` to
     run the command, or select it with the pointer.

The search box clears when a command runs. If nothing matches you see No
matching command — "Type part of a command name, or clear the > to search
items instead."

Commands
--------

  Command:    New project
  Hint shown: Bundle several saved items into one project

  Command:    New collection
  Hint shown: Group saved items into a folder

  Command:    Import library file
  Hint shown: Merge a previously exported .json

  Command:    Export library snapshot
  Hint shown: Download everything as a single .json

  Command:    Sync now
  Hint shown: Push to every configured destination

  Command:    Library settings
  Hint shown: Storage, sync, defaults and data controls

  Command:    Compare items
  Hint shown: Open two saved items side by side

  Command:    Switch to list view or Switch to grid view
  Hint shown: Change how items are laid out

  Command:    Group by type or Stop grouping by type
  Hint shown: Collapsible sections per asset type

  Command:    Compact density or Comfortable density
  Hint shown: Fit more items on screen

  Command:    Multi-select items or Leave multi-select
  Hint shown: Act on several items at once

  Command:    Show archived items or Hide archived items
  Hint shown: Include archived items in normal views

  Command:    Empty the archive
  Hint shown: Permanently delete every archived item

  Command:    Show favorites
  Hint shown: Jump to the starred items

  Command:    Show archive
  Hint shown: Items you archived rather than deleted

  Command:    Browse collections
  Hint shown: Folders that group saved items

  Command:    Keyboard shortcuts
  Hint shown: Every key the panel understands

  Command:    Clear filters
  Hint shown: Back to every item, unfiltered

  Command:    Filter: and a tool name
  Hint shown: The number of items saved from that tool (up to 8 tools)

  Command:    Filter: # and a tag
  Hint shown: The number of items with that tag (up to 8 tags)

Notes:

  - New project creates an empty project item; see Organise your library
    [organise-your-library.txt].
  - Show archived items changes the library preference; in the Library Kit,
    archived items remain on the Archive tab.
  - Group by type moves grouping to the next setting in the Group button's
    cycle.

RIGHT-CLICK AN ITEM
===================

Right-click a tile. The menu is headed with the item's name, a strip of its
colours if it has any, and a line with its type, tool and age.

  Group:   Open
  Entries: Restore into its tool (`Enter`), Open details, up to three Open in
           [tool] entries, Compare with…

  Group:   Organise
  Entries: Favourite or Remove favourite, Rename…, Add to collection…,
           Duplicate, Archive or Restore from archive

  Group:   Share & export
  Entries: Copy N colours (for items with colours), Copy item name, Share a
           link…, Export JSON

  Group:   (below a line)
  Entries: Select this item, Delete (`Del`)

When several items are selected and you right-click one of them, the menu is
headed N selected and offers Favourite all, Archive all, Add all to
collection…, Export all and Delete all.

RIGHT-CLICK THE PANEL
=====================

Right-click empty space in the panel. The menu is headed Library with a line
such as "12 items · 3 favourite · 2 collections".

  Group:   Create
  Entries: New project, New collection, Import, Export all

  Group:   View
  Entries: Switch to list or Switch to grid, Multi-select items or Leave
           multi-select, Show archived or Hide archived, Clear search &
           filters (disabled when nothing is filtered)

  Group:   Library
  Entries: Sync now, Compare items…, Settings, sync & reports, Empty the
           archive (disabled when the archive is empty)

HOW THE MENUS BEHAVE
====================

  - Right-clicking inside a text box (such as the search box) shows your
    browser's normal menu, so copy and paste still work.
  - The menu closes when you choose an entry, click elsewhere, press `Esc`,
    scroll or resize the window. `Esc` closes only the menu, not the panel.
  - The menu follows the panel's light or dark theme.

KEYBOARD SHORTCUTS SHEET
========================

Select Keys in the footer, or run the Keyboard shortcuts command, to see:

  Keys                 | Action
  ---------------------+--------------------------------------
  Ctrl / ⌘ + Shift + L | Open or close the library
  Esc                  | Clear the search, then close
  ↑ ↓ ← →              | Move between items
  Enter                | Restore the item into its tool
  Delete               | Delete the focused item
  Ctrl / ⌘ + A         | Select all (in multi-select)
  Right-click          | Full actions for an item or the panel
  > …                  | Run a library command

Close the sheet with its close button, `Esc`, or a click outside it.
