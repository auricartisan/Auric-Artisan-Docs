==============================================================================
BROWSE AND FIND ITEMS
==============================================================================
Find saved items in the Library Kit with tabs, search, sorting, grouping, grid
or list view, density and filters.
Area: Website › Kits › Library Kit   Updated: 2026-09-25

TABS
====

  Tab:   All
  Shows: Every item that is not archived
  Count: Yes

  Tab:   Recent
  Shows: Items changed in the last 7 days
  Count: Yes

  Tab:   Favorites
  Shows: Items you starred
  Count: Yes

  Tab:   Projects
  Shows: Items of the Project type
  Count: Yes

  Tab:   Collections
  Shows: Your collections, as folders
  Count: Number of collections

  Tab:   Archive
  Shows: Items you archived
  Count: Yes

  Tab:   Compare
  Shows: The comparison workspace; see Compare items [compare-items.txt]
  Count: No

  Tab:   Settings
  Shows: Library settings; see Settings, sync and reports
         [settings-sync-and-reports.txt]
  Count: No

  Tab:   One tab per type
  Shows: Items of that type, such as Palette, Gradient, Plate, Analysis
  Count: Yes

Type tabs appear only for types you have saved. Possible types include Color,
Palette, Shade, Gradient, Typography, Component, Template, Preset, Effect,
Image, LUT, Plate, ASCII, Simulation, Spectral, Export and Analysis; tools can
add their own, such as design systems.

The kit remembers the last tab you used.

SEARCH
======

Type in Search your library…. After a short pause the view shows only items
whose name, description, tool name, type or tags contain your text. Search
works within the current tab.

  - Select the cross in the box, or press `Esc`, to clear the search. A second
    `Esc` closes the kit.
  - Press `Down arrow` in the box to jump to the first tile.
  - Start with `>` to search commands instead of items; see Commands and
    right-click menus [commands-and-right-click-menus.txt].

If nothing matches, you see Nothing matched with a Clear search button.

SORT
====

Choose from the Sort list:

  Option   | Order
  ---------+------------------------------------------
  Newest   | Most recently changed first (the default)
  Oldest   | Earliest created first
  Name A–Z | Alphabetical
  Name Z–A | Reverse alphabetical
  Type     | Grouped alphabetically by type

Your choice is remembered.

GROUP
=====

The Group button cycles through three settings. Its tooltip tells you which is
on:

  1. By project (the default) — items under a heading for the collection they
     belong to. Items in no collection come last under Unfiled. "Grouped by
     project — press for type".
  2. By type — items under a heading per type, such as Palette. "Grouped by
     type — press for none".
  3. None — one list. "Not grouped — press for project".

Headings show a count and can be collapsed; the kit remembers which you
collapsed. Grouping applies in grid view only. A single group that says
nothing new is not given a heading.

GRID OR LIST
============

Select View to switch between a grid of tiles and a list of rows. List rows
are wider and show two extra actions: Duplicate and Export JSON. The choice is
remembered.

DENSITY
=======

Type `>` in the search box and choose Compact density to fit more items on
screen, or Comfortable density to go back. The choice is remembered.

FILTER BY COLLECTION, TOOL OR TAG
=================================

  - Collection: on the Collections tab, select a collection. The All tab opens
    filtered to it, with a chip Collection: and its name.
  - Tool: type `>` and choose Filter: followed by a tool name. The command
    palette offers up to eight tools you have saved from, with counts.
  - Tag: type `>` and choose Filter: # followed by a tag. Up to eight of your
    most-used tags are offered.

Active filters appear as chips under the toolbar. Select a chip to remove that
filter, or Clear all to remove every filter and return to All.

MOVE WITH THE KEYBOARD
======================

  - `Down arrow` from the search box moves to the first tile.
  - Arrow keys move between tiles: left and right by one, up and down by a
    row.
  - `Home` and `End` jump to the first and last tile. Moving up from the first
    row returns to the search box.
  - `Enter` or `Space` restores the focused item (or selects it in
    multi-select mode); `Delete` asks to delete it.

THE ITEM COUNT
==============

The count in the title bar (such as 12 items) is the number of items that are
not archived. The same number shows as a small badge on the Library launcher,
up to 99+.
