==============================================================================
GETTING STARTED WITH THE LIBRARY KIT
==============================================================================
Save your first item from a tool, open the Library Kit, and learn the parts of
its screen.
Area: Website › Kits › Library Kit   Updated: 2026-09-25

SAVE SOMETHING FIRST
====================

Items reach your library from the tools:

  1. Open a tool, make something (a palette, a gradient, a plate, a report)
     and select Save to Library.
  2. In the dialog, type a name (the box says Name your save), and optionally
     a description, a collection (or ＋ New collection…) and tags separated by
     commas.
  3. Select Save to Library, or press `Ctrl` + `Enter` (`Cmd` + `Enter` on a
     Mac).

The item is saved in your browser and appears in the Library Kit straight
away, even if the kit is already open.

OPEN THE KIT
============

Use any of:

  - Page utilities > Library;
  - the Library button in the site header ("Open your saved palettes,
    gradients, presets and exports.");
  - `Ctrl` + `Shift` + `L`;
  - a page address ending in `#library`;
  - https://auricartisan.com/library/workspace/. That page shows Opening your
    library… and opens the panel. If it cannot, it shows an Open library panel
    button and the hint "Or press Ctrl Shift L anywhere on the site."

The kit opens with the cursor in the search box. When you close it, keyboard
focus returns to where it was before.

THE SCREEN, TOP TO BOTTOM
=========================

  1. Title bar. A six-dot grip (drag it, or use the arrow keys, to move the
     panel), the title Your Library, an item count such as 12 items, the Panel
     options button and Close.
  2. Tabs. All, Recent, Favorites, Projects, Collections, Archive, Compare,
     Settings, then one tab per type of item you have saved, such as Palette
     or Gradient. Each tab except Compare and Settings shows a count. The row
     scrolls sideways.
  3. Search. Labelled Search library with the hint "type > for commands"; the
     box reads Search your library… (> for commands).
  4. Toolbar. A count such as 12 items in All, a Sort list, and three buttons:
     Group, View and Select.
  5. Filter chips. Shown when a collection, tool or tag filter is active.
  6. Body. Your items as tiles, in a grid or a list.
  7. Bulk bar. Shown while multi-select is on.
  8. Footer. New project, Import, Export, the storage used (such as 84 KB),
     Settings and Keys.

A TILE
======

Each tile shows:

  - a preview: the image, the gradient, up to eight colour swatches, a text
    sample, or a coloured plate with the item's initials when there is nothing
    to draw;
  - a star if it is a favourite;
  - the item's name;
  - its type (such as Palette), the tool it came from, and when it was last
    changed (such as 3m ago, 2h ago, 5d ago, or a date for anything older than
    a week).

Hovering over a tile shows small action buttons: Favourite, Open details,
Share and Delete (in list view also Duplicate and Export JSON). Right-click a
tile for every action.

YOUR FIRST ACTIONS
==================

  1. Select a tile to reopen the item in its tool. See Restore and reuse
     [restore-and-reuse.txt].
  2. Right-click a tile and choose Rename… to give it a better name.
  3. Select Recent to see what you changed in the last seven days.
  4. Select Keys in the footer to see the keyboard shortcuts.

PANEL OPTIONS
=============

The Panel options button (two sliders) opens a small menu with:

  Option         | Description shown
  ---------------+-----------------------------------------
  Keep open      | Stay visible while opening other kits
  Theme          | Switch this panel between light and dark
  Panel size     | Toggle the wider workspace view
  Minimize       | Collapse the library to its title bar
  Reset position | Return the panel to its default corner

These are the shared kit controls; see Panel controls
[../../docs/panel-controls.txt].

CLOSE THE KIT
=============

Press `Esc` (the first press clears the search if it has text), select Close,
or select the Library launcher again.
