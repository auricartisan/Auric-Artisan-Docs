==============================================================================
LIBRARY KIT SHORTCUTS
==============================================================================
Every keyboard shortcut the Library Kit responds to.
Area: Website › Kits › Library Kit   Updated: 2026-09-25

The kit's own shortcut sheet (Keys in the footer) shows ⌘ for Mac. Where a
shortcut below uses `Ctrl`, use `Cmd` on a Mac.

OPEN AND CLOSE
==============

  Shortcut:     `Ctrl` + `Shift` + `L`
  What it does: Opens or closes the Library Kit, from anywhere on the site

  Shortcut:     `Esc`
  What it does: Closes, in this order: an open menu or dialog, the Panel
                options menu, multi-select, the search text, then the panel

SEARCH BOX
==========

  Shortcut                 | What it does
  -------------------------+-----------------------------------------------
  `>` at the start         | Switches to the command palette
  `Up arrow`, `Down arrow` | Move through commands (command palette)
  `Enter`                  | Runs the highlighted command (command palette)
  `Down arrow`             | Moves to the first tile (normal search)
  `Esc`                    | Clears the search

TILES
=====

  Shortcut:     `Left arrow`, `Right arrow`
  What it does: Previous or next tile

  Shortcut:     `Up arrow`, `Down arrow`
  What it does: Tile above or below; up from the first row returns to the
                search box

  Shortcut:     `Home`, `End`
  What it does: First or last tile

  Shortcut:     `Enter` or `Space`
  What it does: Restores the item (selects it in multi-select)

  Shortcut:     `Delete`
  What it does: Asks to delete the item

  Shortcut:     `Ctrl` + `A`
  What it does: Selects all items, while multi-select is on

MOVING THE PANEL
================

  Shortcut             | Where                      | What it does
  ---------------------+----------------------------+-------------------------
  Arrow keys           | The six-dot grip has focus | Move the panel 12 pixels
  `Shift` + arrow keys | The six-dot grip has focus | Move the panel 1 pixel

MENUS AND DIALOGS
=================

  Shortcut:     `Up arrow`, `Down arrow`, `Home`, `End`
  Where:        Panel options menu
  What it does: Move between options

  Shortcut:     `Enter`
  Where:        Name dialogs (rename, new collection, new project)
  What it does: Confirms

  Shortcut:     `Esc`
  Where:        Any library dialog or menu
  What it does: Cancels or closes it

  Shortcut:     `Ctrl` + `Enter`
  Where:        The Save to Library dialog in a tool
  What it does: Saves
