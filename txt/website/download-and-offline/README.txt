==============================================================================
DOWNLOAD AND OFFLINE
==============================================================================
Install Auric Artisan as an app, prepare it to work offline, keep it up to
date, manage its storage, and remove it.
Area: Website › Download and offline   Updated: 2026-09-25

Auric Artisan is a progressive web app (PWA): a website that your browser can
install like an app and keep working without an internet connection. There is
nothing to download from an app store. You install it from the browser you
already use, and it opens in its own window with its own icon.

The Download page at https://auricartisan.com/download/ ("Install it. Then
lose the connection") is where you install the app and, more importantly,
prepare the offline version. Preparing it copies the site's pages, tools,
libraries, palettes and data into your browser's storage while you are online,
so that the workspace keeps working when you are not. You choose how much to
keep with an offline profile: Auto, Lite, Balanced or Full. The page then
shows exactly what is on your device: readiness checks, storage used, cached
files and missing files, with buttons to audit, repair or reset the offline
copy.

Nothing large is downloaded unless you ask. On a first visit, the browser
keeps only a small core of the site (the app shell) so that an offline visit
can still show something useful.

WHO IT IS FOR
=============

  - People who work on trains, planes or unreliable connections.
  - Anyone who wants Auric Artisan in its own window, on the dock, taskbar or
    home screen.
  - Classrooms and studios that want tools available without depending on the
    network.

WHERE TO FIND IT
================

  - https://auricartisan.com/download/
  - Header: the Browser PWA icon (grid with a plus). Drawer: The app (Works
    offline in a browser tab).
  - Spotlight: Install the PWA launcher, or the Install the app command.

QUICK START
===========

  1. Open https://auricartisan.com/download/ in Chrome, Edge or Safari while
     you are online.
  2. Select Prepare offline version. The status line shows the download's
     progress, and a message reads "Saving for offline — N%".
  3. When it finishes (the status line reads, for example, "Balanced offline
     download finished: A/B assets ready.", with real numbers), check that the
     Readiness badge reads Offline ready.
  4. If an Install app button appears, select it and confirm your browser's
     install dialog. On an iPhone or iPad, use Safari's Share › Add to Home
     Screen instead.
  5. Open the installed app from its icon. It opens in its own window.
  6. Turn off your connection and open a tool. It still works.

WHAT YOU CAN DO
===============

  - Install the site as an app on Windows, macOS, Linux, ChromeOS, Android,
    iOS and iPadOS, where the browser offers it.
  - Prepare an offline copy sized for your device, from the app shell up to
    the whole site.
  - See what is cached, audit it, repair missing files, or reset it.
  - Keep Hindi available offline.
  - Get notified when an update is ready, and apply it.
  - Open files and shared links with the installed app, and use its shortcuts.
  - Remove the app and its offline data.
