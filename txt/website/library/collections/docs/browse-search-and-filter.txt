==============================================================================
BROWSE, SEARCH AND FILTER
==============================================================================
Narrow the tool catalogue with search, category and topic filters, sort orders
and layout options.
Area: Website › Library › Collections   Updated: 2026-09-25

The All tools section of https://auricartisan.com/collections/ gives you four
ways to narrow the catalogue: a search box, category filters, topic filters
and a sort order. They work together, and the grid updates as soon as you
change any of them.

SEARCH
======

The search box sits above the grid and reads Search tools....

  1. Select the box and start typing.
  2. The grid updates on every keystroke; you do not need to press `Enter`.
  3. To clear the search, delete the text.

How matching works:

  - Matching ignores upper and lower case.
  - Each word you type must appear somewhere in the tool's details. `colour
    vision` finds tools that mention both "colour" and "vision", in any order.
  - A word can match part of a longer word. `grad` finds "gradient" and
    "gradients".
  - The details searched are the tool's name, its one-line description, its
    category, its address on the site, and its topic tags.

  | Tip: The catalogue uses both spellings in places — some descriptions say
  | "colour" and some tags say "color". If a search finds less than you expect,
  | try the other spelling. Search does not treat them as the same word.

FILTER BY CATEGORY
==================

Open Category in the Filter and sort panel. Each category is a tick box with
the number of tools in it. The categories are:

Accessibility, Color Science, Colorimetry, Design Systems, Gamut & Rendering,
Generators, Iconography, Perception, Publish, Spectral, Typography and
Utilities.

A Pinned box appears at the top of the list as soon as you pin at least one
tool (see Pin tools and use recommendations [pin-and-recommendations.txt]).

Rules:

  - With no boxes ticked, every category is shown.
  - Tick one box to show only that category.
  - Tick several boxes to show tools in any of them. Ticking Generators and
    Utilities shows both groups together.
  - Untick a box to remove it again.

Categories list only the tools your tool-visibility setting allows. If a
category you expect is missing, see Show basic or advanced tools
[show-basic-or-advanced-tools.txt].

FILTER BY TOPIC
===============

Open Topics (it starts closed). Topics are the short tags each tool carries,
such as `palette`, `accessibility` or `hdr`. The list shows up to 14 topics —
the most common ones among the tools currently in view — each with a count.

  - With no topics ticked, all topics are allowed.
  - Tick one or more topics to show tools that carry any of them.

HOW THE FILTERS COMBINE
=======================

A tool is shown only when it passes all three checks at once:

  1. its category is one of the ticked categories (or none are ticked), and
  2. it carries one of the ticked topics (or none are ticked), and
  3. every word in the search box appears in its details.

The line above the grid shows the result, for example `4 of 14 tools`. When
nothing matches, the grid is replaced by No matching tools with the advice to
try a shorter search, clear the topic chip, or switch the category back to all
tools.

SORT THE GRID
=============

Open Sort by and choose an order from the Sort list:

  Option: Title A to Z
  Order:  Alphabetical by tool name.

  Option: Category A to Z
  Order:  Alphabetical by category.

  Option: Newest first
  Order:  Newest first by date. Tools carry no dates, so this keeps the
          catalogue's own order.

  Option: Oldest first
  Order:  Oldest first by date. Tools carry no dates, so this also keeps the
          catalogue's own order.

  Option: Recommended
  Order:  Tools most likely to be useful to you first (see Pin tools and use
          recommendations [pin-and-recommendations.txt]).

  Option: Most used
  Order:  Tools you open most often, and most recently, first.

  Option: Pinned first
  Order:  Your pinned tools first, then the rest.

  Option: Most metadata
  Order:  Tools with the fullest descriptions and most tags first.

You can also change the order from the right-click card menu (see Use the card
menu [card-menu.txt]).

GRID OR LIST
============

The Grid and List buttons beside the search box switch the layout:

  - Grid shows cards side by side with large artwork.
  - List shows one tool per row with a smaller picture beside the text, which
    is easier to scan.

Your choice is remembered in this browser.

LOADING MORE TOOLS
==================

The grid shows 12 tools at first. As you scroll to the bottom of the grid, the
next 12 load automatically. A line under the grid says where you are, for
example `Showing 12 of 14 tools`, and then `All 14 tools shown`. A thin bar
fills up as more of the list comes into view.

If automatic loading is not available in your browser, a Load 2 more tools
button (the number changes) appears instead; select it to show the next batch.

SEARCH AND SORT WHILE SCROLLED DOWN
===================================

Once you scroll past the search box and filters, a round search button appears
on the right-hand side of the screen, towards the bottom. Select it (its label
is "Search and sort tools") to open a small panel with:

  - a Search tools... box;
  - a Sort list;
  - Category and Topics sections with the same tick boxes as the main panel.

Everything in this panel stays in step with the main controls. Press `Escape`,
or select anywhere outside the panel, to close it. The button hides again when
you scroll back up to the main controls.

RESULT
======

You see only the tools that match your search, ticked categories and ticked
topics, in the order you chose, laid out as a grid or a list.
