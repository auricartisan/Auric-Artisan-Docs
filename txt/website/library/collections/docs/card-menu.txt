==============================================================================
USE THE CARD MENU
==============================================================================
Right-click any tool card to pin, open or copy it, and to change the grid's
view, density, columns and sort order.
Area: Website › Library › Collections   Updated: 2026-09-25

Every card in the All tools grid has its own menu. It gathers the actions for
that one tool together with the settings for the whole grid, so you can change
the layout without scrolling back to the controls.

OPEN THE MENU
=============

  1. Scroll to All tools on https://auricartisan.com/collections/.
  2. Right-click any card. On a keyboard, move focus to a card and press the
     context-menu key or `Shift` + `F10`.
  3. The menu opens at the pointer. If there is not enough room, it moves so
     it stays on screen.

The menu replaces the site's usual right-click menu while you are over a card.
Right-click anywhere else on the page to get the site's usual menu (see Site
features [../../../site-features/README.txt]).

The top line of the menu shows the card's title. A small pin mark appears
before the title when that tool is pinned.

CLOSE THE MENU
==============

Any of these closes it:

  - select anywhere outside the menu;
  - press `Escape`;
  - scroll the page;
  - resize the window;
  - choose Open, New tab or Copy link.

The layout settings (View, Density, Columns, Sort) keep the menu open so you
can try several in a row.

CARD
====

Four buttons act on the card you right-clicked:

  Button:       Pin / Unpin
  What it does: Pins or unpins the tool, exactly like the pin button on the
                card. The button is highlighted while the tool is pinned.

  Button:       Open
  What it does: Opens the tool in the current tab.

  Button:       New tab
  What it does: Opens the tool in a new browser tab.

  Button:       Copy link
  What it does: Copies the tool's full web address to your clipboard.

VIEW
====

  - Grid — cards side by side with large artwork.
  - List — one tool per row, easier to scan.

This is the same setting as the Grid and List buttons above the results, and
it is remembered in this browser.

DENSITY
=======

  - Cozy — the normal spacing between cards.
  - Compact — tighter spacing, so more cards fit on screen.

Remembered in this browser for the Collections page.

COLUMNS
=======

  - Auto — the grid decides how many columns fit your screen width.
  - 2, 3 or 4 — forces that many columns at every screen width.

Columns apply to the grid view; the list view always shows one tool per row.
Your choice is remembered in this browser for the Collections page.

  | Tip: On a phone, Auto is usually the right choice. Forcing 4 columns on a
  | narrow screen makes each card very small.

SORT
====

A row of buttons repeats the page's sort orders. Each shows the first word of
the order's name, with a second word added where two would look the same.
Hover a button to see its full name.

  Button        | Sort order
  --------------+----------------
  Title         | Title A to Z
  Category      | Category A to Z
  Newest        | Newest first
  Oldest        | Oldest first
  Recommended   | Recommended
  Most          | Most used
  Pinned        | Pinned first
  Most metadata | Most metadata

The highlighted button is the current order. Choosing one here also changes
the Sort list in the Filter and sort panel. See Browse, search and filter
[browse-search-and-filter.txt] for what each order does.

SYSTEM
======

Two switches for the whole site:

  - Theme — switches between the site's dark and light themes. It is
    highlighted while the dark theme is on.
  - Reading — turns reading mode on or off. It is highlighted while reading
    mode is on.

FOOTER
======

  - Reset — returns the grid to Grid view, Cozy density, Auto columns and the
    first sort order, Title A to Z. It does not unpin tools or clear your
    usage history.
  - All settings → — opens the site's settings panel.

RESULT
======

From one right-click you can act on a single tool and reshape the whole grid,
and the grid keeps your view, density and column choices the next time you
visit in this browser.
