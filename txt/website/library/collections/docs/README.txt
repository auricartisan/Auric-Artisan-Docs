The task guides and reference pages for the Collections tool catalogue.
Area: Website › Library › Collections   Updated: 2026-09-25

This folder holds the working guides for the Collections page at
https://auricartisan.com/collections/. Start with the getting-started tour,
then use the task guides for specific jobs. The reference lists every control
and every tool in the catalogue.

  File:           Getting started [getting-started.txt]
  What it covers: A tour of the page from top to bottom and a first search.

  File:           Browse, search and filter [browse-search-and-filter.txt]
  What it covers: Searching, category and topic filters, sorting, grid or
                  list, loading more.

  File:           Pin tools and use recommendations
                  [pin-and-recommendations.txt]
  What it covers: Pinning, the Pinned category, Most used, Recommended, and
                  resetting them.

  File:           Use the card menu [card-menu.txt]
  What it covers: The right-click menu on a card: card actions, view, density,
                  columns, sort, system toggles.

  File:           Show basic or advanced tools
                  [show-basic-or-advanced-tools.txt]
  What it covers: Why the catalogue may show fewer than 30 tools, and how to
                  change that.

  File:           Reference [reference.txt]
  What it covers: Every control, sort order, filter and the full list of 30
                  tools.

  File:           Troubleshooting [troubleshooting.txt]
  What it covers: Missing tools, lost pins, the menu not opening and other
                  problems.

  File:           FAQ [faq.txt]
  What it covers: Short answers to common questions.
