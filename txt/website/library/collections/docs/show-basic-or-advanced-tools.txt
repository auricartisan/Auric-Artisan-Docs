==============================================================================
SHOW BASIC OR ADVANCED TOOLS
==============================================================================
Understand why Collections may show fewer than 30 tools, and switch between
Basic, Advanced, Everything and a custom set.
Area: Website › Library › Collections   Updated: 2026-09-25

Auric Artisan has 30 tools. Some are everyday tools, such as the Image Picker
and the Font Library; others are scientific tools, such as Illuminants, Tone
Mapping and the Psychophysics Engine. The site lets you choose which of these
you see, and Collections follows that choice.

WHY YOU MIGHT SEE FEWER THAN 30 TOOLS
=====================================

Every tool in the catalogue is labelled with a mode:

  - Basic — beginner-friendly, everyday tools.
  - Advanced — scientific, diagnostic and power-user tools.
  - Both — tools that belong to every set. The URL Analyzer and the Portfolio
    Builder are the two tools marked this way.

The site-wide tool visibility setting decides which modes are shown. Until you
choose otherwise, the site uses Basic, so a first visit to Collections shows
the basic tools and the two tools marked Both. The hero counters, the category
counts and the result count all reflect the tools in view, not the full
catalogue.

You can see any card's mode in its tooltip: hover over the card and read the
Mode line.

TOOLS SHOWN IN EACH SETTING
===========================

  Setting             | What Collections shows                           | Number of tools
  --------------------+--------------------------------------------------+----------------
  Basic (the default) | Basic tools plus the two tools marked Both.      | 14
  Advanced            | Advanced tools plus the two tools marked Both.   | 18
  Everything          | Every tool.                                      | 30
  Custom              | Only the tools you have switched on, one by one. | Your choice

The full list, with each tool's mode, is in the Reference [reference.txt],
under Tool catalogue.

CHANGE THE SETTING
==================

The setting lives in the Advanced Kit, one of the site's floating kits. Its
button carries the tooltip "Choose Basic, Advanced, or Everything tool
visibility."

  1. Open the Advanced Kit.
  2. Under the tool-visibility choices, select Basic, Advanced, Everything or
     Custom.
  3. For Custom, use Choose your tools to tick the tools you want. You can
     type in Filter tools… to find a tool, or use Enable all, Disable all and
     Reset.
  4. Close the kit.

Collections updates straight away: the grid, the counters, the category list
and the Start here shortlist all redraw with the tools the new setting allows.
You do not need to reload the page.

The setting applies across the site, not only on Collections, and is
remembered in this browser. For everything else the Advanced Kit can do, see
the Advanced Kit docs [../../../kits/advanced-kit/README.txt].

RESULT
======

Collections shows exactly the set of tools you asked for: the basic set, the
advanced set, all 30 tools, or your own custom selection.
