==============================================================================
SAVE SCALES
==============================================================================
Save shade scales, find them on the Saved tab, and reach them from your
Library.
Area: Website › Library › Colour libraries › Shade Library   Updated: 2026-09-25

SAVE
====

Select Save on a card, or Save to library under Quick export on Inspect. The
page confirms Shade saved, and the Saved tab's badge goes up.

FIND SAVED SCALES
=================

Open the Saved tab. Scales appear as cards, most recently saved first, with a
note that they are Also saved to your Library workspace with image previews.
With nothing saved: No saved shade systems yet.

UNSAVE
======

Select Saved on the card, or Unsave on Inspect. The page confirms Shade
removed, and the scale leaves your Library too.

IN YOUR LIBRARY
===============

Each saved scale is added to your Library under its name (for example Material
Like #FF724C #00001), described by method, base colour and token count. Open
your Library with `Ctrl` + `Shift` + `L`. See the Library Kit docs
[../../../../kits/library-kit/README.txt].

LIMITS
======

Up to 500 scales are kept; saving more drops the oldest. Saves are kept in
this browser only.
