==============================================================================
SHADE LIBRARY SHORTCUTS
==============================================================================
Keyboard and pointer actions in the Shade Library.
Area: Website › Library › Colour libraries › Shade Library   Updated: 2026-09-25

  Keys or action     | Where                              | Result
  -------------------+------------------------------------+----------------------------
  `/`                | Anywhere, when not typing          | Focuses the search box.
  `Enter` or `Space` | A focused swatch                   | Opens its scale on Inspect.
  `Escape`           | Share link or design tokens dialog | Closes it.
  Select a swatch    | Grid                               | Copies its hex.
  Select a column    | Inspect strip                      | Copies its hex.

The site-wide shortcuts also work here. See Site features
[../../../../site-features/README.txt].
