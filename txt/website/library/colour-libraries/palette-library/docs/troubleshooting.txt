==============================================================================
TROUBLESHOOTING
==============================================================================
Symptoms, causes and fixes for problems in the Palette Library.
Area: Website › Library › Colour libraries › Palette Library   Updated: 2026-09-25

"COULD NOT LOAD PALETTE DATABASE"
=================================

Why: The page could not download the short description of the collection it
needs to work out palettes, usually because of a dropped connection or a
content blocker.

What to do: Check your connection, allow auricartisan.com in any content
blocker, and reload.

A FILTER SHOWS "NOTHING MATCHED YET"
====================================

Why: A filter starts a scan from the beginning of the collection. A rare
combination, such as Dark lightness with Vivid chroma and one method, may need
to look through many palettes before the first match.

What to do: Scroll down to let the scan continue, or widen the filter. Watch
the counter: N matches from M derived shows how far it has looked.

FILTERING FEELS SLOW
====================

Why: Every palette the scan looks at is worked out on the spot. The page does
this in small steps so it stays responsive, but a rare filter can mean a lot
of work.

What to do: Remove a filter you do not need, or use the search box to jump
straight to a known id.

THE SCROLLBAR STOPS BEFORE THE END OF THE COLLECTION
====================================================

Why: No browser can make a page tall enough for five million palettes. The
counter says scroll reaches N; search an id for the rest.

What to do: Type the id or number of the palette you want into Search by id or
hex…. Every palette can be reached this way.

A SORT DOES NOT SEEM TO COVER THE WHOLE COLLECTION
==================================================

Why: Sorting needs the whole set in hand, and five million palettes cannot be
ordered in a browser. Any sort other than Sort: original orders only a first
stretch of the collection, and the sorted grid does not grow as you scroll.

What to do: Combine the sort with filters so the stretch it orders is the one
you care about. For a full, streaming browse, use Sort: original.

FILTERS SEEM TO BE IGNORED
==========================

Why: The search box contains an id or a plain number. An id always wins, and
the grid shows only that palette (1 palette, by id).

What to do: Remove the id or number from both search boxes.

THE PALETTE'S METHOD DOES NOT MATCH ITS COLOURS
===============================================

Why: The Method is a label each palette carries in the collection. The badge
on Palette summary (Neutral, Triadic, Analogous, Monochrome) is measured from
the actual colours, and the two can disagree.

What to do: When the relationship between hues matters, judge by the badge and
the Hue span, not the method label. See Limits and accuracy
[../others/limits-and-accuracy.txt].

"EXPORT VISIBLE" EXPORTED MORE PALETTES THAN I CAN SEE
======================================================

Why: The Visible page export uses the same sample as the analysis tabs: up to
2,000 palettes, not only the cards on screen.

What to do: To export one palette, open it on Inspect and use the Selection
card or Quick export.

A SHARE LINK OPENS THE PAGE BUT NOT THE PALETTE
===============================================

Why: The link may have been cut short when it was pasted, or edited.

What to do: Ask for the link again, or ask for the palette id and search for
it. If the page says Shared palette not found in current dataset, the id in
the link is not valid.

THE ASE FILE WILL NOT OPEN
==========================

Why: ASE files are read by Adobe apps and some other design tools; not every
app supports them.

What to do: Import it through your app's swatches or palette panel rather than
opening it as a document. If your app does not read ASE, use the JSON, CSS or
design-token exports instead.

SAVED PALETTES HAVE GONE
========================

Why: Saved palettes live in this browser only; clearing site data, a private
window, or another browser or device will not show them. The Saved tab also
keeps only the latest 500.

What to do: Save them again, or keep their ids — an id always gives the same
palette.
