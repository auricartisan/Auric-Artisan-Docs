0.9.9 — 5 JUNE 2026
===================

The Palette Library was added in release 0.9.9 as part of the library
expansion, together with the Color, Gradient, Harmony, Shade and Accessibility
libraries. See the Changelog [../../../changelog/README.txt].

THE CURRENT PAGE
================

The current page streams the whole five-million collection as you scroll,
reports how far every filtered scan has looked, measures the analysis tabs on
a stated sample, and shows every tab at once (earlier versions hid the
analysis tabs behind a Simple/Advanced switch, and paged the grid in fixed
page sizes). These changes are not listed as a separate changelog release.
