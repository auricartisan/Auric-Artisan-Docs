OTHER COLOUR LIBRARIES
======================

  - Palette Library [../../palette-library/README.txt] — sets of colours that
    work together.
  - Shade Library [../../shade-library/README.txt] — one colour taken through
    lightness, for design-system scales.
  - Accessibility Library [../../accessibility-library/README.txt] —
    foreground and background pairs scored for contrast against any ground,
    not only white and black.
  - Harmony Library [../../harmony-library/README.txt] and Gradient Library
    [../../gradient-library/README.txt].

  - Contrast Checker
