==============================================================================
ACCESSIBILITY LIBRARY SHORTCUTS
==============================================================================
Keyboard control of the contrast map and other keys in the Accessibility
Library.
Area: Website › Library › Colour libraries › Accessibility Library   Updated: 2026-09-25

THE MAP (FOCUS IT FIRST)
========================

  Keys                       | Effect
  ---------------------------+-------------------------
  `Left` / `Right`           | Hue −5° / +5°.
  `Shift` + `Left` / `Right` | Hue −25° / +25°.
  `Up` / `Down`              | Lightness +0.02 / −0.02.
  `Shift` + `Up` / `Down`    | Lightness +0.10 / −0.10.
  `Home`                     | Lightness 1 (top).
  `End`                      | Lightness 0 (bottom).

ELSEWHERE
=========

  Keys or action           | Effect
  -------------------------+-----------------------------
  `Enter` in the index box | Looks up the record.
  Select a pick            | Moves the caret to it.
  Select an index card     | Loads its pair into the map.

The site-wide shortcuts also work here. See Site features
[../../../../site-features/README.txt].
