==============================================================================
HARMONY LIBRARY GLOSSARY
==============================================================================
Definitions of the terms and all 23 colour-theory schemes used in the Harmony
Library.
Area: Website › Library › Colour libraries › Harmony Library   Updated: 2026-09-25

TERMS
=====

  Term:    Adherence
  Meaning: How closely a harmony's actual hues keep to its scheme's canonical
           angles, from 0% to 100%.

  Term:    Base
  Meaning: The colour a scheme is built around. Other colours are placed at
           angles from its hue.

  Term:    Canonical angles
  Meaning: A scheme's ideal hue offsets from the base, such as 120° and 240°
           for triadic.

  Term:    Colour wheel
  Meaning: Hues arranged in a circle from 0° to 360° (red, yellow, green,
           cyan, blue, magenta and back to red).

  Term:    Contrast ratio
  Meaning: The WCAG 2 lightness-difference measure between two colours, from
           1:1 to 21:1. 4.5:1 is AA for body text.

  Term:    Family
  Meaning: A group of related schemes: complementary, polyadic, analogous,
           monochromatic or compound.

  Term:    Fit
  Meaning: In What harmony is this?: 1 minus the average angle error divided
           by 60°, never below 0.

  Term:    Harmony id
  Meaning: `har_` followed by the harmony's number in base 36.

  Term:    Hue span
  Meaning: The widest angle between two of a harmony's hues.

  Term:    Role
  Meaning: What a colour does in its scheme: base, complement, ally, accent
           and so on.

  Term:    Scheme (method)
  Meaning: One of the 23 rules for placing hues.

THE 23 SCHEMES
==============

  Scheme:                  complementary
  Family:                  complementary
  Colours:                 2
  Canonical angles:        180°
  Description (as the page gives it):Base hue and its 180° opposite — the
                           strongest possible contrast pair.

  Scheme:                  split_complementary
  Family:                  complementary
  Colours:                 3
  Canonical angles:        150°, 210°
  Description (as the page gives it):Base plus two hues flanking its
                           complement — softer than complementary.

  Scheme:                  double_complementary
  Family:                  complementary
  Colours:                 4
  Canonical angles:        30°, 180°, 210°
  Description (as the page gives it):Two pairs of complements offset by a
                           small angle.

  Scheme:                  triadic
  Family:                  polyadic
  Colours:                 3
  Canonical angles:        120°, 240°
  Description (as the page gives it):Three hues spaced 120° apart — vibrant
                           and well-balanced.

  Scheme:                  triad_shifted
  Family:                  polyadic
  Colours:                 3
  Canonical angles:        120°, 240°
  Description (as the page gives it):Triadic with chroma + lightness shifts
                           for hierarchy.

  Scheme:                  tetradic
  Family:                  polyadic
  Colours:                 4
  Canonical angles:        60°, 180°, 240°
  Description (as the page gives it):Two complementary pairs forming a
                           rectangle on the wheel.

  Scheme:                  square
  Family:                  polyadic
  Colours:                 4
  Canonical angles:        90°, 180°, 270°
  Description (as the page gives it):Four hues spaced 90° apart — bold and
                           evenly weighted.

  Scheme:                  pentadic
  Family:                  polyadic
  Colours:                 5
  Canonical angles:        72°, 144°, 216°, 288°
  Description (as the page gives it):Five hues equally spaced (72°).

  Scheme:                  hexadic
  Family:                  polyadic
  Colours:                 6
  Canonical angles:        60°, 120°, 180°, 240°, 300°
  Description (as the page gives it):Six hues at 60° intervals — full
                           color-wheel coverage.

  Scheme:                  analogous_3
  Family:                  analogous
  Colours:                 3
  Canonical angles:        −24°, 24°
  Description (as the page gives it):Three neighbouring hues — harmonious,
                           low-tension.

  Scheme:                  analogous_5
  Family:                  analogous
  Colours:                 5
  Canonical angles:        −44°, −22°, 22°, 44°
  Description (as the page gives it):Five neighbouring hues for richer
                           analogous palettes.

  Scheme:                  analogous_7
  Family:                  analogous
  Colours:                 7
  Canonical angles:        −54° to 54° in 18° steps
  Description (as the page gives it):Seven analogous hues — long ramp suitable
                           for illustration.

  Scheme:                  accented_analogous
  Family:                  analogous
  Colours:                 4
  Canonical angles:        −24°, 24°, 180°
  Description (as the page gives it):Three analogous hues plus one
                           complementary accent.

  Scheme:                  monochromatic_3
  Family:                  monochromatic
  Colours:                 3
  Canonical angles:        0°
  Description (as the page gives it):Three lightness/saturation steps of one
                           hue.

  Scheme:                  monochromatic_5
  Family:                  monochromatic
  Colours:                 5
  Canonical angles:        0°
  Description (as the page gives it):Five-step single-hue ramp.

  Scheme:                  monochromatic_7
  Family:                  monochromatic
  Colours:                 7
  Canonical angles:        0°
  Description (as the page gives it):Seven-step single-hue ramp — UI-friendly
                           tonal scale.

  Scheme:                  shades
  Family:                  monochromatic
  Colours:                 5
  Canonical angles:        0°
  Description (as the page gives it):Five-step ramp from base toward black.

  Scheme:                  tints
  Family:                  monochromatic
  Colours:                 5
  Canonical angles:        0°
  Description (as the page gives it):Five-step ramp from base toward white.

  Scheme:                  neutral
  Family:                  monochromatic
  Colours:                 5
  Canonical angles:        0°
  Description (as the page gives it):Desaturated greyscale tinted toward the
                           base hue.

  Scheme:                  compound
  Family:                  compound
  Colours:                 5
  Canonical angles:        24°, 180°, 156°, 210°
  Description (as the page gives it):Base + warm/cool shifts + complement +
                           accent.

  Scheme:                  warm_cool
  Family:                  compound
  Colours:                 2
  Canonical angles:        180°
  Description (as the page gives it):Base paired with its temperature-flipped
                           counterpart.

  Scheme:                  golden_ratio
  Family:                  compound
  Colours:                 5
  Canonical angles:        137.5°, 275.01°, 52.51°, 190.01°
  Description (as the page gives it):Hues rotated by the golden angle
                           (137.5°).

  Scheme:                  fibonacci_hue
  Family:                  compound
  Colours:                 5
  Canonical angles:        34.4°, 68.8°, 103.1°, 171.9°
  Description (as the page gives it):Fibonacci-indexed golden-angle
                           distribution.

Analogous angles are measured from the middle colour. Monochromatic schemes
keep one hue and vary lightness and saturation.
