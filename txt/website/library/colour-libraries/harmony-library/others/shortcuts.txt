==============================================================================
HARMONY LIBRARY SHORTCUTS
==============================================================================
Keyboard and pointer actions in the Harmony Library.
Area: Website › Library › Colour libraries › Harmony Library   Updated: 2026-09-25

  Keys or action: `/`
  Where:          Anywhere, when not typing
  Result:         Focuses Search by id, hex or method….

  Keys or action: `Enter` or `Space`
  Where:          A focused swatch in the grid
  Result:         Opens its harmony on Inspect.

  Keys or action: `Escape`
  Where:          Share link or design tokens dialog
  Result:         Closes it.

  Keys or action: Select a swatch
  Where:          Grid
  Result:         Copies its hex.

  Keys or action: Select a column
  Where:          Inspect strip
  Result:         Copies its hex.

  Keys or action: Select a card heading
  Where:          Inspect
  Result:         Folds or unfolds the card.

The site-wide shortcuts also work here. See Site features
[../../../../site-features/README.txt].
