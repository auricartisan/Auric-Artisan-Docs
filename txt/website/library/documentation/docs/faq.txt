WHAT IS THE DIFFERENCE BETWEEN A USER GUIDE AND A DEVELOPER REFERENCE?
======================================================================

A user guide shows how to use a tool. A developer reference explains how it
works — the methods, formulas and data behind the results.

WHY DO SOME SUBJECTS HAVE ONLY ONE DOCUMENT?
============================================

Some tools have only a guide so far, and some subjects (such as a measurement
method behind a tool) have only a reference. The pair switch on each article
shows which half exists.

WHERE IS THE API DOCUMENTATION?
===============================

The API guides are listed as subjects ending in "API", and the full endpoint
reference is at https://auricartisan.com/library/documentation/api/. See also
Public API [../../../../services/public-api/README.txt].

CAN I FOLLOW NEW DOCUMENTS?
===========================

Yes, with the RSS feed at
https://auricartisan.com/library/documentation/rss.xml.

DOES THE DOCUMENTATION LIBRARY WORK WITHOUT JAVASCRIPT?
=======================================================

Yes. The index is a plain list of links; search, the audience filter and the
article side list are added on top.
