INDEX PAGE (HTTPS://AURICARTISAN.COM/LIBRARY/DOCUMENTATION/)
============================================================

  Control:      Search 54 subjects…
  What it does: Shows subjects whose name or description contains the text.
  Values:       Any text
  Default:      Empty

  Control:      Audience switch
  What it does: Shows both kinds of document, or only one.
  Values:       Both, Guides, References
  Default:      Both

  Control:      Count
  What it does: Subjects and documents currently shown.
  Values:       For example 54 subjects · 89 documents
  Default:      —

  Control:      Subject row
  What it does: Name (link), description, Guide and/or Reference buttons.
  Values:       —
  Default:      —

  Control:      No subject matches that. Try a tool name.
  What it does: Shown when nothing matches.
  Values:       —
  Default:      —

  Address               | Effect
  ----------------------+-----------------------------------------
  `?audience=guide`     | Opens the index showing guides only.
  `?audience=reference` | Opens the index showing references only.

ARTICLE PAGES
=============

  Element                          | What it does
  ---------------------------------+-------------------------------------------------------
  Documentation (side list)        | All subjects; current one highlighted.
  Breadcrumb                       | Documentation › subject.
  User guide / Developer reference | Switch between the pair; a missing half is greyed out.
  On this page                     | Section links.
  Copy on code blocks              | Copies the code; shows Copied or Press Ctrl C.
  The pair                         | Link to the other document for the subject.
  Next subject                     | Link to the next subject alphabetically.
