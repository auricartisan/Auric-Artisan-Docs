==============================================================================
DOCUMENTATION
==============================================================================
What the documentation library contains, who it is for, and how to find a
tool's guide.
Area: Website › Library › Documentation   Updated: 2026-09-25

The documentation library is where Auric Artisan publishes the written guide
for each tool. Its heading, "Every tool, twice", describes the idea: most
subjects have two documents — a user guide, which explains how to use the
tool, and a developer reference, which explains how it works and what it
computes. You pick the subject, then pick which of the two you want.

The index lists 54 subjects and 89 documents. 35 subjects have both a guide
and a reference; the others have one. Subjects cover the site's tools (such as
the URL Analyzer, Vision Simulation and the Font Library), the colour
libraries, the browser extension and design-tool plugins, the generators
behind the libraries, and the public REST API, including guides to using the
Palette, Gradient, Harmony, Shade and accessibility collections from your own
code.

WHO IT IS FOR
=============

  - Anyone who wants step-by-step help with a tool: read its user guide.
  - Developers and technical users who want to know exactly what a tool
    measures and how: read its developer reference.
  - Developers automating the site's tools: read the API guides and the
    endpoint reference.

WHERE TO FIND IT
================

  - The index: https://auricartisan.com/library/documentation/
  - From the site header: Learn menu › Documentation ("Technical guides &
    references").
  - The API endpoint reference:
    https://auricartisan.com/library/documentation/api/
  - An RSS feed: https://auricartisan.com/library/documentation/rss.xml

QUICK START
===========

  1. Open https://auricartisan.com/library/documentation/.
  2. Type a tool's name into Search 54 subjects…, for example `contrast`.
  3. Choose Guides if you only want user guides, or References for developer
     references; Both shows everything.
  4. Select Guide or Reference on the subject's row.
  5. On the article, use On this page to jump to a section, and the User guide
     / Developer reference switch to move to the other half of the pair.
  6. Use Next subject at the end, or the list of all subjects at the side, to
     move on.

WHAT YOU CAN DO
===============

  - Search 54 subjects by name and description.
  - Show only user guides or only developer references, with a shareable
    address for each.
  - Move between a subject's guide and reference with one click.
  - Browse every subject from a side list on each article, with a breadcrumb
    back to the index.
  - Copy code examples with one click.
