WHY ARE THERE TWO V0.9.6 ENTRIES?
=================================

Two entries share version 0.9.6: "System Integration & Validation" (8 April
2026) and "Vision Simulation & Color Model Lab Advancement" (13 April 2026). A
link to `#0.9.6` opens the newer one.

WHAT IS THE DIFFERENCE BETWEEN A RELEASE AND A PATCH?
=====================================================

Releases add features; patches fix and tidy. One entry, v0.9.75, is labelled
Changelog rather than either.

WHERE DO I REPORT A PROBLEM WITH A RELEASE?
===========================================

Release notes ask for steps to reproduce, your browser and operating system,
the page or tool affected, and screenshots — and, for API problems, the
`x-request-id` header from the response. See Help
[../../../../help/README.txt] for how to get in touch.

IS EVERY CHANGE LISTED?
=======================

The changelog lists the notable changes in each release. Smaller changes
between releases, and improvements to individual tools, may appear only on the
tool's own pages and guides.
