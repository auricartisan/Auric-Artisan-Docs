STEP 1: BASICS
==============

  Control:         Campaign name
  What it does:    Your own name for the campaign.
  Values or range: 2 to 80 characters
  Default:         Empty

  Control:         Brand / company
  What it does:    Who runs the campaign; also the studio's fallback headline.
  Values or range: 2 to 80 characters
  Default:         Empty

  Control:         Destination URL
  What it does:    Where clicks land.
  Values or range: http or https; the field takes up to 500 characters
  Default:         Empty

  Control:         Display link
  What it does:    Short form of the destination.
  Values or range: —
  Default:         —

  Control:         Test link ↗
  What it does:    Opens the final address with sample macro values.
  Values or range: —
  Default:         —

  Control:         Auto-tagging
  What it does:    Adds UTM parameters.
  Values or range: On, off
  Default:         On

  Control:         `utm_source` … `utm_term`
  What it does:    UTM values.
  Values or range: Up to 60 characters each
  Default:         See below

  Control:         + Add parameter
  What it does:    Adds a custom parameter.
  Values or range: Up to 5; name up to 32, value up to 200 characters
  Default:         None

  Control:         Macro chips
  What it does:    Insert a macro in the last-used tracking field.
  Values or range: `{placement}`, `{zone}`, `{campaign}`, `{clickid}`
  Default:         —

  Control:         Final URL
  What it does:    The complete click address.
  Values or range: —
  Default:         —

  Control:         What should this campaign do?
  What it does:    Sets a goal and applies its recommendations.
  Values or range: Brand awareness, Site traffic, Product launch
  Default:         Brand awareness

Default UTM values: `utm_source=auricartisan`, `utm_medium=adssense`,
`utm_campaign` from the campaign name, `utm_content={placement}`,
`utm_term={zone}`.

QUOTE PANEL
===========

  Item:    Step N/6
  Meaning: The current step.

  Item:    Base run, Flight discount, Promo, Tax, Total
  Meaning: The price lines. Discount, promo and tax lines show only when they
           apply.

  Item:    impressions, est. uniques, est. clicks, eff. CPM
  Meaning: The delivery estimate.

  Item:    Complete campaign to request booking
  Meaning: The button before every step is complete.

  Item:    Request campaign — total (pay on approval)
  Meaning: Sends the booking request.

MESSAGES
========

  Message: Add a campaign name to continue.
  When:    Campaign name under 2 characters.

  Message: Add the brand or company running this campaign.
  When:    Brand under 2 characters.

  Message: Enter a destination URL.
  When:    Destination empty.

  Message: That doesn't parse as a complete URL — include https://.
  When:    Destination incomplete.

  Message: Only http(s) destinations can be served.
  When:    Another scheme.

  Message: Credentials inside the URL are not allowed.
  When:    User name or password in the address.

  Message: That hostname doesn't look reachable.
  When:    Not a full domain.

  Message: Not secure (http) — browsers may warn your visitors. Prefer https.
  When:    Warning for http.

  Message: Link shorteners hide the real destination from the Ad Library — use
           the final URL.
  When:    Warning for a shortener.

  Message: Custom parameter names can only use letters, numbers, dot, dash and
           underscore.
  When:    Bad parameter name.

  Message: Choose an artwork file or switch to the creative studio.
  When:    Upload chosen, no file.

  Message: Choose a PNG, JPG, WebP or SVG image.
  When:    Wrong file type.

  Message: That file is over 300 KB — please compress it.
  When:    File too large.

  Message: That file could not be read as an image.
  When:    Damaged or unreadable file.

  Message: Artwork removed. Choose a new file to continue.
  When:    After Remove.

  Message: Choose a valid campaign start date.
  When:    Start date missing or in the past.

  Message: Enter a valid billing email.
  When:    Billing email not valid.

  Message: Accept the creative and refund policies before checkout.
  When:    Policy box unticked.

  Message: unknown code
  When:    Promo code not recognised.

  Message: Sending booking request…
  When:    Request on its way.

  Message: Request received. We confirm availability and send a Razorpay
           payment link within 1 business day — your campaign goes live after
           payment.
  When:    Request sent.

  Message: Could not send the request — please email ads@auricartisan.com with
           your campaign details.
  When:    Request failed.
