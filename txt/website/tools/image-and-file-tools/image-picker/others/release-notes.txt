User-facing history of the Image Picker.
Area: Website › Tools › Image and file tools › Image Picker   Updated: 2026-09-25

No dated changelog entry for the Image Picker has been published on the site.
This page records what can be confirmed.

CURRENT VERSION
===============

  - Three tabs: Workbench, Analysis and Actions.
  - The whole middle panel is the drop target before a picture is loaded.
  - The four charts live on their own Analysis tab, with full-screen viewing.
  - The keyboard keys are listed on the Workbench before a picture is loaded.
  - A line under the heading points to the equivalent REST endpoint and its
    cost in API credits.

25 MAY 2026 — USER GUIDE PUBLISHED
==================================

The Image Picker User Guide was published in the site's documentation library.
It describes a layout with two tabs, Lab and Actions, with the charts on the
Lab tab. The extraction method, eyedropper, pins, exports and batch analysis
it describes are the same as today.
