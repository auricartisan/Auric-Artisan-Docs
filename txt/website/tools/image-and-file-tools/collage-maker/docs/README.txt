The list of how-to guides, the reference, troubleshooting and FAQ for the

This folder holds the task guides for the Collage Maker, the full reference of
its controls and outputs, and the troubleshooting and FAQ pages. Start with
Getting started if you have not used the tool before; go to the Reference when
you need the exact range or default of a control.

  What it covers: Saving PNG and JPEG, export scale and quality, the

  File:           reference.md [reference.txt]

  File:           troubleshooting.md [troubleshooting.txt]
