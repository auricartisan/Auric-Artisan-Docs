==============================================================================
COLLAGE MAKER SHORTCUTS
==============================================================================
Keyboard shortcuts and pointer actions in the Collage Maker.
Area: Website › Tools › Image and file tools › Collage Maker   Updated: 2026-09-25

KEYBOARD
========

  Keys:       `Ctrl` + `Z`
  Action:     Undo
  Works when: Focus is not in a slider, menu or text box

  Keys:       `Ctrl` + `Shift` + `Z`
  Action:     Redo
  Works when: As above

  Keys:       `Ctrl` + `Y`
  Action:     Redo
  Works when: As above

  Keys:       Arrow keys
  Action:     Nudge the selected picture 1 px
  Works when: The canvas has focus (click it first)

  Keys:       `Shift` + arrow keys
  Action:     Nudge the selected picture 10 px
  Works when: The canvas has focus

  Keys:       `Delete` or `Backspace`
  Action:     Remove the selected picture
  Works when: The canvas has focus

  Keys:       `Enter` or `Space`
  Action:     Open the file chooser
  Works when: The Drop pictures box has focus

On a Mac, `Cmd` works in place of `Ctrl`. With the canvas focused, one press
of the undo or redo shortcut can move two steps; use the Undo and Redo buttons
when you want exactly one.

Every control on the page can be reached with `Tab`. Each tab button, slider,
switch and button responds to the keyboard in the usual way.

POINTER
=======

  Action: Click a picture
  Result: Select it (the top one where pictures overlap)

  Action: Click empty canvas
  Result: Clear the selection

  Action: Drag a picture
  Result: Move it; snapped to 10 px when snapping is on

  Action: Drag a corner handle
  Result: Resize the selected picture around its centre, from 2% to 800%

  Action: Click a row in Layers · top first
  Result: Select that picture, including a hidden one

  Action: Drop image files on the canvas or the drop box
  Result: Add them as pictures
