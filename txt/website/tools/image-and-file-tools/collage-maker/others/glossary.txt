==============================================================================
COLLAGE MAKER GLOSSARY
==============================================================================
Definitions of the terms used in the Collage Maker.
Area: Website › Tools › Image and file tools › Collage Maker   Updated: 2026-09-25

  Term:    Arrangement
  Meaning: A grid of equal cells, given as columns × rows, into which the
           visible pictures are placed in stacking order

  Term:    Canvas
  Meaning: The rectangle the collage is drawn on; always 1200 pixels wide,
           with a height set by the shape

  Term:    Canvas covered
  Meaning: The share of canvas pixels that pictures paint, found by drawing
           with and without them and counting differences

  Term:    Cell
  Meaning: One rectangle of a grid arrangement, sized from the canvas,
           padding, gap and grid

  Term:    Chequerboard
  Meaning: The on-screen pattern behind the canvas that shows transparency;
           never exported

  Term:    Corner radius
  Meaning: How far the canvas corners are rounded, in pixels; exports are
           clipped to the rounded shape

  Term:    Export scale
  Meaning: The factor, 0.25× to 4×, by which the canvas size is multiplied
           when an image is saved or copied

  Term:    Fill
  Meaning: Scaling a picture so it covers its whole cell; in this tool the
           excess is not trimmed away

  Term:    Fit
  Meaning: Scaling a picture so all of it lies inside its cell, leaving part
           of the cell empty if the shapes differ

  Term:    Gap
  Meaning: The space between neighbouring cells of a grid arrangement

  Term:    Guides
  Meaning: The thirds lines across the canvas and the dashed lines through the
           selected picture's centre; screen only

  Term:    History step
  Meaning: One recorded change that Undo can reverse; the history holds up to
           60

  Term:    JPEG
  Meaning: A lossy image format that makes small files from photographs and
           cannot store transparency

  Term:    Layer
  Meaning: One picture in the stack; the layers list shows them top first

  Term:    Off-canvas area
  Meaning: The share of total picture area outside the canvas, which will not
           appear in an export

  Term:    Opacity
  Meaning: How solid a picture is drawn, from 0% (invisible) to 100% (solid)

  Term:    Overlap
  Meaning: The share of the canvas painted by two or more pictures

  Term:    Padding
  Meaning: The margin between the canvas edge and the block of grid cells

  Term:    PNG
  Meaning: A lossless image format that can store transparency

  Term:    Reading
  Meaning: A small JSON file recording what was measured about the collage

  Term:    Rule of thirds
  Meaning: A composition guide dividing the canvas into three equal parts
           across and down

  Term:    Session file
  Meaning: A JSON file with the canvas settings and each picture's placement,
           but no image data

  Term:    Snap
  Meaning: Rounding a dragged picture's centre to the nearest multiple of 10
           px
