This folder holds the task guides for the ICC Profile Parser, a concept page
on how ICC profiles are organised, the full reference of every field and rule
the tool shows, and the troubleshooting and FAQ pages. If ICC profiles are new
to you, read Understand ICC profiles before the other guides.

  File:           export-a-reading.md [export-a-reading.txt]

  File:           reference.md [reference.txt]

  File:           troubleshooting.md [troubleshooting.txt]
