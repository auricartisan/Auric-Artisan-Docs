What the ICC Profile Parser does with your profile files.
Area: Website › Tools › Image and file tools › ICC Profile Parser   Updated: 2026-09-25

YOUR PROFILE STAYS IN YOUR BROWSER
==================================

  - The profile file is read by the page itself in your browser. The tool does
    not upload it or send it anywhere.
  - Every figure, diagram and finding is worked out on your device.
  - Save the reading and Tag table, CSV create their files in the browser and
    save them through your browser's normal download.
  - Copy it writes the reading to your clipboard only when you select it.

NOTHING IS KEPT AFTER YOU LEAVE
===============================

The tool does not store the profile or the reading. Clear, reloading, or
leaving the page removes them.

WHAT A READING CONTAINS
=======================

A reading contains the profile's file name and size, its header values, its
tag table, the tool's identification, gamut figures and findings. It does not
contain the profile file itself. The file name appears in the reading, so
check that it says nothing you would rather not share.

THE PAGE ITSELF
===============

The ICC Profile Parser is a normal page on auricartisan.com. Site-wide
features such as sign-in, preferences and any consent-based services follow
the site's own privacy policy and your cookie choices; see Help
