==============================================================================
PSYCHOPHYSICS BENCH SHORTCUTS
==============================================================================
Response keys and other keyboard and pointer actions in the Psychophysics
Bench.
Area: Website › Tools › Perception and spectral › Psychophysical Experiment Engine   Updated: 2026-09-25

Keys work while the page is waiting for an answer. Site-wide shortcuts are
described in Site features [../../../../site-features/README.txt].

  Key or action | Two-interval forced choice | Yes / no detection
  --------------+----------------------------+-------------------
  `←`           | First interval             | Yes, I saw it
  `→`           | Second interval            | No, I did not
  `Esc`         | Stops the run              | Stops the run

  Action: Double-click
  Where:  The stimulus stage or the staircase trace
  Result: Opens it enlarged, filling the window

  Action: `Esc`
  Where:  Enlarged view
  Result: Closes it

  Action: Select the × button or the dark area around the image
  Where:  Enlarged view
  Result: Closes it

  Action: `Tab`
  Where:  Anywhere
  Result: Moves between controls; sliders then respond to the arrow keys

Between runs the arrow keys are not used by the bench, so a focused slider
responds to them instead. Click an empty part of the page before a run so the
response keys are not also moving a slider.
