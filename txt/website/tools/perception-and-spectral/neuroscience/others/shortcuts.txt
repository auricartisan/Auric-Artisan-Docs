==============================================================================
VISUAL PATHWAY SHORTCUTS
==============================================================================
Keyboard and pointer actions in the Visual Pathway tool.
Area: Website › Tools › Perception and spectral › Neuroscience   Updated: 2026-09-25

The tool has no keyboard shortcuts of its own beyond these. Site-wide
shortcuts, such as the search palette, are described in Site features
[../../../../site-features/README.txt].

  Action: Double-click
  Where:  Stimulus or map canvas on the Lab tab
  Result: Opens the canvas enlarged, filling the window

  Action: `Esc`
  Where:  Enlarged view
  Result: Closes it

  Action: Select the × button or the dark area around the image
  Where:  Enlarged view
  Result: Closes it

  Action: `Enter` or `Space`
  Where:  A focused row on the Data tab
  Result: Expands or collapses the row

  Action: `Tab`
  Where:  Anywhere
  Result: Moves between controls; sliders then respond to the arrow keys

  Action: Drag a file
  Where:  Drop a CSV or JSON on the Data tab
  Result: Installs a cone table
