Contents of the how-to documentation for the Visual Pathway tool.
Area: Website › Tools › Perception and spectral › Neuroscience   Updated: 2026-09-25

These pages explain how to use the Visual Pathway, from the first grating to
exporting cone signals for your own colours. Start with getting started, then
read the task guides in any order. The reference lists every control.
