ASCII ART GENERATOR REFERENCE

Every control, range, default, file and message in the ASCII Art Generator in

Area: Website › Tools › Colour workspace   Updated: 2026-09-25

ADDRESS
=======

  - https://auricartisan.com/tool/ascii/
  - https://auricartisan.com/ascii opens the same page.

TABS
====

  Tab      | Purpose
  ---------+---------------------------------------------------------
  Lab      | Source, look, colour, detail, fine tuning, and the art.
  Analysis | Readouts, benchmark and six charts.
  Compare  | Ink measurements for all seven character sets.
  Export   | Seven download formats, Export all, and batch rendering.

SOURCE
======

  Control: Source
  Values:  Image, Text, Webcam
  Default: Image

  Control: Image file
  Values:  PNG, JPEG, GIF, WebP, BMP, SVG, TIFF; up to 20 MB
  Default: none

  Control: Large images
  Values:  Scaled to at most 4,000 px a side and 12 megapixels
  Default: always

  Control: Text
  Values:  any text
  Default: ASCII

  Control: Text font
  Values:  monospace, Courier New, Consolas, Monaco, Fira Code, Source Code
           Pro
  Default: monospace

  Control: Text size
  Values:  8 to 128 px
  Default: 48

  Control: Text weight
  Values:  Normal, Bold, Black
  Default: Bold

  Control: White on black
  Values:  on or off
  Default: off

  Control: Keep converting every frame
  Values:  on or off
  Default: off

  Control: Smooth between frames
  Values:  on or off
  Default: off

CHARACTER SETS
==============

  Set      | Characters (light to dark)             | Count
  ---------+----------------------------------------+------
  Standard | space `.:-=+*#%@`                      | 10
  Detailed | space and 69 marks, letters and digits | 70
  Blocks   | space `░▒▓█`                           | 5
  Minimal  | space `.:#@`                           | 5
  Symbols  | space `·•●◉⬤`                          | 6
  Lines    | space and box-drawing characters       | 23
  Braille  | space and 255 Braille patterns         | 256

STAGE
=====

  Item         | What it does
  -------------+------------------------------------
  Render chips | Text, HTML, Canvas, SVG

MESSAGES
========

  Message: Rendering…
  Meaning: A conversion is in progress.

  Message: Unsupported file type: …
  Meaning: The file is not one of the accepted image types.

  Message: File too large (… MB). Max 20 MB.
  Meaning: The file is over 20 MB.

  Message: Failed to load image
  Meaning: The browser could not read the file.

  Message: Downscaled from … to …
  Meaning: A large picture was scaled down before conversion.

  Message: Copied!
  Meaning: The art is on the clipboard.

  Message: Nothing to copy
  Meaning: Nothing has been converted yet.

  Message: Nothing to export
  Meaning: Nothing has been converted yet.

  Message: Turn colour on first — ANSI carries the image's colours
  Meaning: ANSI download needs From image.

  Message: Load an image first
  Meaning: The benchmark needs a picture.

  Message: No inputs
  Meaning: The batch box is empty.

  Message: Camera permission denied. …
  Meaning: The camera could not start. See Troubleshooting
           [troubleshooting.txt].
