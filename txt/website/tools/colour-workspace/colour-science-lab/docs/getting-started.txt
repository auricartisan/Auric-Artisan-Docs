==============================================================================
GETTING STARTED WITH THE COLOR SCIENCE LAB
==============================================================================
Open the Color Science Lab, learn its five views, and make your first
measurements.
Area: Website › Tools › Colour workspace   Updated: 2026-09-25

OPEN THE LAB
============

  1. Go to https://auricartisan.com/tool/color-science-lab/ in a current
     desktop browser.
  2. Under the title Color Science Lab you see a short description and labels:
     8 Domains, 45 Tools, 60+ Color Spaces, Von Kries · Newton · Fairchild and
     In-page Floating Panels, then a note about the matching API call, which
     you can dismiss with ×.
  3. A row of five view buttons follows: Workbench, Catalogue, Compare, Gamut
     audit and Illuminants. The lab opens on Workbench the first time and on
     the view you used last after that.

THE FIVE VIEWS
==============

  View:      Workbench
  Use it to: See one colour in every CIE and perceptual notation, under the
             illuminant, observer and adaptation you choose.

  View:      Catalogue
  Use it to: Browse 45 tools and open them as floating panels.

  View:      Compare
  Use it to: Measure the difference between a reference and a candidate
             colour.

  View:      Gamut audit
  Use it to: Check how much room a palette has in sRGB, Display P3, Adobe RGB
             and Rec. 2020.

  View:      Illuminants
  Use it to: See one colour adapted to seven standard lights.

The Workbench and Illuminants views share one colour, the specimen; Compare's
Reference starts from it. The lab remembers the specimen in your browser.

FIRST MEASUREMENT: ONE COLOUR, TWO LIGHTS
=========================================

  1. On Workbench, type `#D3AF37` in the specimen HEX box (include the `#`).
  2. Read Resolved coordinates. For example, the CIE Lab row reads about
     `72.75 0.95 62.79` under D65.
  3. Under Illuminant, select A (incandescent). The Lab row changes, the note
     reads A · 2°, and the table header shows Bradford.
  4. Read Under other light on the right: each illuminant with the ΔE 2000
     shift from the current one.

Result: you can see how the same surface colour reads under daylight and under
tungsten light.

FIRST PANEL
===========

  1. Select Catalogue. The tool cards appear, grouped by domain.
  2. Select Delta E Comparator. It opens as a floating panel over the page.
  3. Set Sample color and Compare color in the panel's left column.
  4. Select the Metrics tab and read dE76 to compare.

Result: a panel you can move, resize and keep open while you try other tools.
A floating Color Control box also appears, for arranging panels.
