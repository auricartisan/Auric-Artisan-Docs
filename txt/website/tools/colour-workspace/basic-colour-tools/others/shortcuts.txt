==============================================================================
SHORTCUTS
==============================================================================
Every keyboard shortcut and mouse gesture in Basic Color Tools, its panel
tools and the Colour Tools workbench.
Area: Website › Tools › Colour workspace   Updated: 2026-09-25

`Cmd` applies on a Mac where the table lists it. Shortcuts that act on "the
panel" act on the focused panel, the one you selected last.

BASIC COLOR TOOLS PAGE
======================

  Keys or gesture: `Space`
  Where:           Palette Studio, panel focused, not typing
  What it does:    Generates a new palette (locked colours stay).

  Keys or gesture: `Escape`
  Where:           Focus inside a panel
  What it does:    Restores a maximised panel; otherwise closes the panel.

  Keys or gesture: Double-click the title bar
  Where:           Any panel
  What it does:    Maximises or restores.

  Keys or gesture: Drag the title bar
  Where:           Any panel (not maximised)
  What it does:    Moves the panel.

  Keys or gesture: Drag the bottom-right corner
  Where:           Any panel (not maximised)
  What it does:    Resizes the panel.

  Keys or gesture: `Shift`, `Ctrl` or `Cmd` + select a tool card
  Where:           Catalogue
  What it does:    Opens another instance of the tool.

  Keys or gesture: Drag a colour strip
  Where:           Palette Studio
  What it does:    Reorders the palette.

  Keys or gesture: `Shift` + right-click a filled cell
  Where:           Collage Maker
  What it does:    Cycles that cell's filter.

  Keys or gesture: `Enter` or leave the box
  Where:           Color Picker HEX box; Quick Converter Compare HEX boxes
  What it does:    Applies the typed HEX code.

  Keys or gesture: `Ctrl` + `Enter` (`Cmd` + `Enter`)
  Where:           Save to Library window
  What it does:    Saves.

COLOUR TOOLS WORKBENCH
======================

  Keys or gesture: `Ctrl` + `Shift` + `C`
  Where:           Any page that loads the Colour Tools
  What it does:    Opens the Colour Tools launcher. If the selected text is a
                   HEX code, the tool you pick opens with that colour.

  Keys or gesture: Right-click
  Where:           Any page
  What it does:    Opens the site menu with the Colour tools group.

  Keys or gesture: `Shift` + right-click
  Where:           Any page
  What it does:    Opens the browser's own menu instead.

  Keys or gesture: Type while the right-click menu is open
  Where:           Site menu
  What it does:    Filters the menu items.

  Keys or gesture: `Tab`, `Shift` + `Tab`
  Where:           Launcher
  What it does:    Moves between the search box, tool rows, links and the
                   close button.

  Keys or gesture: `Enter` or `Space`
  Where:           Launcher
  What it does:    Opens the focused tool.

  Keys or gesture: `Esc`
  Where:           Launcher search box
  What it does:    Clears the search; press again to close the launcher.

  Keys or gesture: `Esc`
  Where:           Launcher, elsewhere
  What it does:    Closes the launcher.

  Keys or gesture: `Esc`
  Where:           Colour Tools panel
  What it does:    Leaves full-window view if maximised; otherwise closes the
                   panel.

  Keys or gesture: Double-click the title bar
  Where:           Colour Tools panel
  What it does:    Maximises or restores.

Individual Colour Tools may have their own keys; each tool's guide lists them.
See Colour Tools [../docs/colour-tools/README.txt].
