==============================================================================
BASIC COLOR TOOLS FAQ
==============================================================================
Short answers to common questions about Basic Color Tools and the Colour Tools
workbench.
Area: Website › Tools › Colour workspace   Updated: 2026-09-25

DO I NEED AN ACCOUNT?
=====================

No. All seven tools and the Colour Tools work without signing in. Saving to
your Library uses the site's Library; see the Library Kit
[../../../../kits/library-kit/README.txt] and Account and billing
[../../../../account-and-billing/README.txt].

DOES IT COST ANYTHING OR USE TOKENS?
====================================

The seven tools compute everything in your browser and do not call the server
for their results, so they do not spend tool tokens. See Account and billing
[../../../../account-and-billing/README.txt] for plans.

ARE MY IMAGES UPLOADED?
=======================

No. Images you add to Palette Studio (From Image) or Collage Maker are read by
your browser on your device. See Privacy [../others/privacy.txt].

HOW MANY PANELS CAN I HAVE OPEN?
================================

Five. Opening a sixth closes the oldest one. See Workspace and panels
[workspace-and-panels.txt].

WHY ARE SOME TOOLS MISSING FROM THE LIST?
=========================================

The Catalogue's Level switch or search is filtering them, and the Workspace
list follows the Catalogue. Set Level to Both, clear the search and choose All
Tools.

WILL MY WORK STILL BE THERE TOMORROW?
=====================================

Open panels are not saved. Your favourites, level, category and last view are
remembered in your browser. To keep results, export them or use Save to
Library.

CAN I OPEN THE SAME TOOL TWICE?
===============================

Yes. Select Open another instance on the panel's title bar, or hold `Shift`,
`Ctrl` or `Cmd` while selecting the tool's card in the Catalogue. Each copy
has its own state.

WHAT IS THE DIFFERENCE BETWEEN COLOR PICKER AND QUICK CONVERTER?
================================================================

Color Picker is built around choosing a colour by eye (plane, hue slider,
eyedropper) and shows harmonies, colour-vision previews and contrast tiles.
Quick Converter is built around typing or pasting a value; it shows fourteen
notations, compares two colours and lists wide-gamut values.

WHAT IS THE DIFFERENCE BETWEEN BASIC COLOR TOOLS AND THE COLOUR TOOLS?
======================================================================

Basic Color Tools is a page with seven panel tools. The Colour Tools are
fourteen further floating tools you can open on any page of the site from the
right-click menu, with `Ctrl` + `Shift` + `C`, or with a `?color=` address
parameter. See Colour Tools [colour-tools/README.txt].

WHICH CONTRAST STANDARD DO THE TOOLS USE?
=========================================

The seven panel tools use the WCAG 2.x contrast ratio: 4.5:1 for AA normal
text, 7:1 for AAA, 3:1 for large text and non-text interface parts. Some
Colour Tools, such as Contrast System [colour-tools/contrast-system.txt], also
report APCA.

IS THE ASE EXPORT AN ADOBE SWATCH FILE?
=======================================

No. It copies tab-separated text. Use CSS, SCSS, Tailwind, JSON, SVG or PNG
for other tools.

WHERE ARE THE PALETTE, SHADE AND GRADIENT COLLECTIONS?
======================================================

Large browsable collections of palettes, shades, gradients, harmonies and
colours live in the site's library area. See Colour libraries
[../../../../library/colour-libraries/README.txt].
