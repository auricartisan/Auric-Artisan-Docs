==============================================================================
BASIC COLOR TOOLS DOCUMENTATION
==============================================================================
The list of every guide for Basic Color Tools and the Colour Tools workbench.
Area: Website › Tools › Colour workspace   Updated: 2026-09-25

This folder explains how to use the Basic Color Tools page and everything on
it: the three views, the panel windows, the seven workspace tools, and the
fourteen site-wide Colour Tools. Start with the getting-started guide, then
open the guide for the tool you need. The reference lists every control in one
place.

GUIDES IN THIS FOLDER
=====================

  File:           getting-started.md [getting-started.txt]
  What it covers: Open the page, tour the screen, make and export a first
                  palette.

  File:           workspace-and-panels.md [workspace-and-panels.txt]
  What it covers: Workspace, Catalogue and Panels views; search, level and
                  favourites; moving, docking and closing panels.

  File:           import-export-and-library.md [import-export-and-library.txt]
  What it covers: Every copy and download format, the palette share link, Save
                  to Library and reopening saved items.

  File:           reference.md [reference.txt]
  What it covers: Every control, option, range, default and output format of
                  the workspace and its seven tools.

  File:           troubleshooting.md [troubleshooting.txt]
  What it covers: Symptoms, why they happen and what to do.

  File:           faq.md [faq.txt]
  What it covers: Short answers to common questions.

SUBFOLDERS
==========

  Folder:         panel-tools/ [panel-tools/README.txt]
  What it covers: One guide per workspace tool: Palette Studio, Palette Remix,
                  Gradient Maker, Color Picker, Color Battle, Collage Maker,
                  Quick Converter.

  Folder:         colour-tools/ [colour-tools/README.txt]
  What it covers: The Colour Tools workbench: how to open it on any page, its
                  launcher and panels, and one guide for each of its fourteen
                  tools.
