==============================================================================
COLOUR TOOLS WORKBENCH
==============================================================================
The fourteen floating Colour Tools you can open on any page of Auric Artisan,
how to open them, and a guide for each.
Area: Website › Tools › Colour workspace   Updated: 2026-09-25

The Colour Tools are fourteen floating colour tools that open over whatever
page you are on: right-click and use the Colour tools group, press `Ctrl` +
`Shift` + `C`, right-click a colour value, or add `?color=` to a page address.
They share one launcher, one kind of panel window and a control bar for
arranging panels. Basic Color Tools is their home page, and this folder
documents them.

Start with launcher-and-panels.md [launcher-and-panels.txt], then open the
guide for the tool you need.

ESSENTIALS
==========

  File:        colour-inspector.md [colour-inspector.txt]
  Tool:        Color Inspector
  In one line: Everything about one colour: formats, contrast, vision,
               harmony, names, psychology, scales, science and code export.

  File:        accessibility-lab.md [accessibility-lab.txt]
  Tool:        Accessibility Lab
  In one line: Two to six colours under WCAG 2.1, 2.2, APCA or ISO 9241-3,
               with a vision-filter grid.

  File:        contrast-system.md [contrast-system.txt]
  Tool:        Contrast System
  In one line: Up to five foregrounds on one background: three measures,
               fixes, APCA size table, contrast curve and interface preview.

  File:        colour-name-finder.md [colour-name-finder.txt]
  Tool:        Color Name Finder
  In one line: The nearest of 1,058 named colours and seventeen similar ones.

  File:        animation-contrast.md [animation-contrast.txt]
  Tool:        Animation Contrast
  In one line: Text contrast across 48 samples of an animated gradient or a
               video, with a safe text colour.

  File:        type-readability-sim.md [type-readability-sim.txt]
  Tool:        Type Readability Sim
  In one line: Reading comfort from colours, font style, size, weight and
               viewing condition.
