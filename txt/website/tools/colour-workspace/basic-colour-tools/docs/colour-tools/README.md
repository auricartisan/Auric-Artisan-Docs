# Colour Tools workbench — plain-text edition

The fourteen floating Colour Tools you can open on any page of Auric Artisan, how to open them, and a guide for each. Every file here is the plain-text edition of the Markdown document with the same name in `md/website/tools/colour-workspace/basic-colour-tools/docs/colour-tools/`; start with `README.txt`.

## Files

| File | What it covers |
| --- | --- |
| [README.txt](README.txt) | The fourteen floating Colour Tools you can open on any page of Auric Artisan, how to open them, and a guide for each. |
| [accessibility-lab.txt](accessibility-lab.txt) | Compare two to six colours under WCAG 2.1, WCAG 2.2, APCA or ISO 9241-3, preview text in them, and see every colour through seven vision filters. |
| [animation-contrast.txt](animation-contrast.txt) | Sample an animated background, from CSS keyframe colours or a video file, at 48 points, check text contrast at each one, find the worst frame and get a text colour that passes throughout. |
| [cmyk-soft-proof.txt](cmyk-soft-proof.txt) | Simulate a screen colour or an image on five press and paper conditions, see the CMYK separation after dot gain and ink limits, spot colours that will shift, and copy CMYK values. |
| [colour-formulation.txt](colour-formulation.txt) | Read one colour as channels, follow it through the conversion pipeline, see a reflectance sketch, and get a two-pigment paint mix that comes close to it. |
| [colour-inspector.txt](colour-inspector.txt) | Use the Color Inspector to read one colour in every format, check it for contrast and colour-vision safety, find its name, build scales and harmonies, and export it as code. |
| [colour-library.txt](colour-library.txt) | Search and filter 1,058 named colours by family, open any colour's detail view with sixteen formats, a triadic harmony and similar colours, and download a swatch as SVG or PNG. |

| [colour-psychology.txt](colour-psychology.txt) | Enter one to six colours and read their combined warmth and energy, emotion words, personality traits, brand-fit notes and cultural meanings by region. |
| [colour-space-converter.txt](colour-space-converter.txt) | Convert one colour into 34 notations across eight groups, from HEX and HSL to Lab, OKLCH, Display P3, Rec.2020, ACEScg, JzAzBz and YCbCr, with gamut badges, two diagrams, channel bars and a JSON export. |
| [contrast-system.txt](contrast-system.txt) | Check up to five foreground colours on one background under WCAG 2.x, APCA and ISO 9241-3, read an APCA font-size table, sweep lightness on a contrast curve, fix colours to AA or AAA, and preview them in a realistic interface. |
| [gradient-library.txt](gradient-library.txt) | Browse and filter 512 curated linear gradients by colour scheme and number of stops, open any gradient's details, and copy it as CSS, a CSS variable, a Tailwind class, SVG or JSON, or download it as SVG or PNG. |
| [harmony-studio.txt](harmony-studio.txt) | Generate eight kinds of colour harmony from one base colour, optionally adjust every swatch to meet a contrast target on your background, preview them and export HEX, CSS, JSON or PNG. |
| [launcher-and-panels.txt](launcher-and-panels.txt) | Every way to open the 14 floating Colour Tools, how the launcher works, and how to move, arrange, pin and close the panels they open in. |
| [pantone-and-named-lookup.txt](pantone-and-named-lookup.txt) | Enter a colour and find its nearest matches in HTML/CSS named colours, a Pantone Solid Coated subset, RAL Classic, NCS and Crayola, ranked by ΔE2000 with a plain-language closeness label. |
| [type-readability-sim.txt](type-readability-sim.txt) | Combine text and background colours with font style, size, weight, letter-spacing and a viewing condition to get an APCA reading, a comfort score, size and weight sweeps, and recommendations. |
