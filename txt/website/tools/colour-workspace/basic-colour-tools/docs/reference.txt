==============================================================================
BASIC COLOR TOOLS REFERENCE
==============================================================================
Every control, option, range, default and output of the Basic Color Tools
page, its views and its seven panel tools, with pointers to the Colour Tools
references.
Area: Website › Tools › Colour workspace   Updated: 2026-09-25

This page lists every control on the Basic Color Tools page. Defaults are
given only where the page sets one. For the fourteen Colour Tools, each tool's
guide ends with its own full controls table; see Colour Tools at the end.

PAGE
====

  Item:  Address
  Value: https://auricartisan.com/tool/basic-tools/ (also
         https://auricartisan.com/basic-tools)

  Item:  Tools
  Value: 7, in 4 categories

  Item:  Maximum open panels
  Value: 5

  Item:  Sign-in
  Value: Not needed to use the tools

  Item:  Works offline
  Value: The tools compute everything in the browser once the page has loaded

WORKSPACE VIEW
==============

  Control:      Open a tool rows
  What it does: Open a tool, or bring its open panel forward (restoring it if
                docked). Rows show Advanced and open labels.

  Control:      Panels meter
  What it does: Shows N of 5 open, a bar, and Room for N more. or the ceiling
                message.

  Control:      Panels entries
  What it does: One per panel with Floating, Docked or Maximised. Select to
                bring it forward.

  Control:      Stage
  What it does: Holds the panels in this view. Shows Nothing open yet. when
                empty.

SAVE TO LIBRARY
===============

  Control:      Save to Library (floating button)
  What it does: Captures the focused panel and opens the save window

  Control:      Name, Description
  What it does: Per item

  Control:      Shared description, Collection, Tags (comma-separated)
  What it does: For all items being saved

  Control:      Save to Library (in the window) or `Ctrl` + `Enter`
  What it does: Saves

  Control:      Cancel
  What it does: Closes without saving
