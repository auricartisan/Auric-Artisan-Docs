The seven tools that open as panels in the Basic Color Tools workspace, with a guide for each. Every file here is the plain-text edition of the Markdown document with the same name in `md/website/tools/colour-workspace/basic-colour-tools/docs/panel-tools/`; start with `README.txt`.
