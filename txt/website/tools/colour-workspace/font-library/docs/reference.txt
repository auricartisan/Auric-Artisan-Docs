MESSAGES
========

  Message: No fonts match these filters.
  Meaning: Nothing fits the search and filters.

  Message: No option matches that.
  Meaning: No filter chip matches the text in Filter these options.

  Message: Copied …
  Meaning: Code, a stack, a glyph or a feature was copied.

  Message: Added both to selection
  Meaning: ＋ Select both worked.

  Message: Select some families first
  Meaning: Embed or Download with an empty kit.

  Message: Select at least 2 families to compare
  Meaning: Compare needs two.

  Message: Preparing download kit...
  Meaning: A ZIP is being built.

  Message: Downloaded …
  Meaning: The ZIP is ready.

  Message: Only bundled library fonts can be downloaded
  Meaning: Every family asked for is Installed only.

  Message: Could not prepare this download
  Meaning: The family's details could not be loaded.

  Message: Font library is temporarily unavailable
  Meaning: The catalogue could not be reached.

  Message: The live font engine didn’t load
  Meaning: The page's font engine did not start; Retry reloads.
