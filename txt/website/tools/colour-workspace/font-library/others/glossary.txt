==============================================================================
GLOSSARY
==============================================================================
Type and font terms used in the Font Library and its documentation.
Area: Website › Tools › Colour workspace   Updated: 2026-09-25

  Term:    Axis
  Meaning: One dimension a variable font can change along, such as weight
           (wght) or width (wdth).

  Term:    Character variant
  Meaning: An OpenType feature (cv01 to cv99) that swaps the design of one
           particular character.

  Term:    Code point
  Meaning: The number Unicode gives a character, written like U+0041.

  Term:    Family
  Meaning: All the styles of one typeface, such as Regular, Bold and Italic.

  Term:    Fallback stack
  Meaning: The fonts listed after the one you want, used if it is missing.

  Term:    @font-face
  Meaning: The CSS rule that tells a browser where a font file is and which
           style it provides.

  Term:    Foundry
  Meaning: The company or person that publishes a typeface.

  Term:    Glyph
  Meaning: A single drawn shape in a font, usually a character.

  Term:    Heading and body
  Meaning: The two roles in a type pairing: a display face for titles and a
           text face for reading.

  Term:    Installed
  Meaning: A family listed from system fonts, shown only if you have it
           installed, and not served.

  Term:    Instance
  Meaning: A named point on a variable font's axes, such as Light or Condensed
           Bold.

  Term:    Ligature
  Meaning: Two or more characters drawn as one glyph, such as fi, or => in
           coding fonts.

  Term:    Modular type scale
  Meaning: A set of sizes where each step is the previous one times a fixed
           ratio.

  Term:    OpenType feature
  Meaning: A switchable behaviour inside a font, named by a four-letter tag
           such as liga or tnum.

  Term:    Pangram
  Meaning: A sentence using every letter of the alphabet.

  Term:    Self-hosting
  Meaning: Serving font files from your own website instead of a font service.

  Term:    Specimen
  Meaning: A sample of text set in a typeface, used to judge it.

  Term:    Stroke contrast
  Meaning: The difference between thick and thin parts of letters.

  Term:    Stylistic set
  Meaning: An OpenType feature (ss01 to ss20) that swaps a group of
           alternative designs.

  Term:    Super-family
  Meaning: Related typefaces designed to work together, such as a sans and a
           serif sharing a name.

  Term:    Tabular figures
  Meaning: Digits of equal width, so numbers line up in columns.

  Term:    Variable font
  Meaning: One font file that holds a continuous range of styles along one or
           more axes.

  Term:    Weight
  Meaning: How heavy the strokes are, from 100 (Thin) to 900 (Black); 400 is
           Regular and 700 Bold.

  Term:    x-height
  Meaning: The height of lowercase letters such as x, as a share of the font's
           size (em).
