==============================================================================
COLOUR WORKSPACE
==============================================================================
The Auric Artisan tools for building palettes and design systems, converting
and studying colours, and choosing fonts and icons.
Area: Website › Tools › Colour workspace   Updated: 2026-09-25

The colour workspace is the group of Auric Artisan website tools you use to
make things with colour: palettes, gradients, harmonies and whole design
systems, plus the fonts and icons that go with them. It also includes the
site-wide Colour Tools, fourteen floating colour tools you can open over any
page.

Every tool runs in your browser. Most work without an account; saving to your
Library and some account features need you to sign in. Each tool has its own
folder with an overview, task guides, a full reference, troubleshooting, a
glossary and notes on accuracy and privacy.

TOOLS IN THIS GROUP
===================

  Tool:           Basic Color Tools
  Address:        https://auricartisan.com/tool/basic-tools/
  What it is for: A panel workspace with seven everyday tools (Palette Studio,
                  Palette Remix, Gradient Maker, Color Picker, Color Battle,
                  Collage Maker, Quick Converter) and the home of the fourteen
                  site-wide Colour Tools.
  Docs:           basic-colour-tools/ [basic-colour-tools/README.txt]

  Tool:           Color Science Lab
  Address:        https://auricartisan.com/tool/color-science-lab/
  What it is for: Colour-science models and analyses in floating panels:
                  colour spaces, conversions, colour difference and more.
  Docs:           colour-science-lab/ [colour-science-lab/README.txt]

  Tool:           Personalization Generator
  Address:        https://auricartisan.com/tool/personalization-gen/
  What it is for: Sweeps thousands of candidate palettes built from your own
                  colour pool and a brief, then derives gradients, type
                  pairings, UI pairs, posters, design tokens and a
                  sixteen-mockup brand Studio.
  Docs:           personalisation-generator/
                  [personalisation-generator/README.txt]

  Tool:           Design System Generator
  Address:        https://auricartisan.com/tool/design-engine/
  What it is for: Builds a complete design system (colour, type, icons,
                  spacing, components, tokens) from an industry, a style and
                  an accessibility target, and exports it.
  Docs:           design-engine/ [design-engine/README.txt]

  Tool:           ASCII Art Generator
  Address:        https://auricartisan.com/tool/ascii/
  What it is for: Turns pictures and text into character art, with five looks,
                  fine tuning, colour, and TXT, PNG, SVG, HTML, JSON, CSV and
                  ANSI exports.
  Docs:           ascii-art-generator/ [ascii-art-generator/README.txt]

  Tool:           Font Library
  Address:        https://auricartisan.com/tool/font/
  What it is for: Browse, test, compare and embed 2,213 font families from the
                  Auric Font CDN, with suitability scores, pairings, licences
                  and self-hosting kits.
  Docs:           font-library/ [font-library/README.txt]

  Tool:           Icon Library
  Address:        https://auricartisan.com/tool/icon/
  What it is for: Search 12,896 icons from seven open-licence sets, restyle
                  them, and copy them as SVG, JSX, a data URI or a CDN tag, or
                  export a ZIP or sprite.
  Docs:           icon-library/ [icon-library/README.txt]

WHICH TOOL SHOULD I USE?
========================

  - I need a palette quickly: Palette Studio in Basic Color Tools
    [basic-colour-tools/docs/panel-tools/palette-studio.txt].
  - I need a whole design system with tokens: Design System Generator
    [design-engine/README.txt] or Personalization Generator
    [personalisation-generator/README.txt].
  - I need to check contrast while reading another page: the Colour Tools
    [basic-colour-tools/docs/colour-tools/README.txt], opened with the
    right-click menu.
  - I need colour science detail: Color Science Lab
    [colour-science-lab/README.txt], or Color Space Converter
    [basic-colour-tools/docs/colour-tools/colour-space-converter.txt] for one
    colour.
  - I need a typeface or icons: Font Library [font-library/README.txt] and
    Icon Library [icon-library/README.txt].
