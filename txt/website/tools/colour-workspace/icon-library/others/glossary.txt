==============================================================================
GLOSSARY
==============================================================================
Icon and SVG terms used in the Icon Library and its documentation.
Area: Website › Tools › Colour workspace   Updated: 2026-09-25

  Term:    currentColor
  Meaning: A CSS keyword meaning the current text colour. Icons drawn with it
           take the colour of the text around them.

  Term:    Data URI
  Meaning: A way to put a whole file inside a link or `src` attribute, so no
           separate file is needed.

  Term:    Duotone
  Meaning: A style with two tones: a solid shape and a lighter fill behind it.

  Term:    Filled and outline
  Meaning: Two ways of drawing icons: solid shapes, or lines of a set width.

  Term:    Identifier
  Meaning: An icon's unique name, beginning with its set, such as lucide-bell.

  Term:    JSX
  Meaning: The HTML-like syntax used to write React components.

  Term:    Set
  Meaning: A family of icons drawn to one design, such as Lucide or Material.

  Term:    Sprite
  Meaning: One SVG file holding many icons as symbols, each shown with a
           `<use>` reference.

  Term:    Stroke width
  Meaning: The thickness of the lines in an outline icon.

  Term:    Style
  Meaning: One drawing of a set, such as Outline, Fill or 16 · Solid.

  Term:    SVG
  Meaning: Scalable Vector Graphics: an image format made of shapes, sharp at
           any size.

  Term:    Symbol
  Meaning: A reusable piece of an SVG sprite, identified by an `id`.

  Term:    Variant
  Meaning: One icon in one style. 12,896 icons come in 32,803 variants.

  Term:    Webfont
  Meaning: A font whose characters are icons, used for the Material set.
