==============================================================================
ICON LIBRARY
==============================================================================
What the Icon Library is, who it is for, where to find it, and how to find,
restyle and take away icons from seven open-licence sets.
Area: Website › Tools › Colour workspace   Updated: 2026-09-25

The Icon Library puts seven open-licence icon sets under one search: Phosphor,
Tabler, Lucide, Remix, Heroicons, Feather and Material. That is 12,896 icons
in 32,803 variants across 21 styles, such as outline, fill, duotone or
16-pixel solid.

Resize, recolour and change the stroke of every icon at once, then open one to
see it large, switch its style, and copy it as SVG, a React (JSX) component,
an image data URI or a one-line CDN tag. Select the icons you need into Your
kit and take them away as a ZIP of SVG files or a single SVG sprite.

The icons are served by the Auric Artisan Icon CDN, so nothing loads from a
third party. The CDN itself (the loader script, embedding, self-hosting and
licences) is documented under Icon CDN
[../../../../services/icon-cdn/README.txt].

WHO IT IS FOR
=============

  - Developers who need an icon as SVG, JSX or an embed tag.
  - Designers comparing how an idea is drawn across several sets.
  - Anyone building a small, consistent icon kit for a project.

WHERE TO FIND IT
================

  - Page: https://auricartisan.com/tool/icon/
  - No sign-in is needed. Your kit and view settings are kept in your browser.

QUICK START
===========

  1. Open https://auricartisan.com/tool/icon/.
  2. Type what you need in Name, tag or set, for example arrow.
  3. Pick a set on the left, such as Lucide, and, if it has several, a style.
  4. Set Size, Stroke and Colour above the grid to preview every icon that
     way.
  5. Select an icon. It opens in the panel on the right.
  6. Select Copy SVG or Copy JSX, or ＋ Select to add it to Your kit.
  7. Open Your kit and select Download ZIP or Copy sprite.

WHAT YOU CAN DO
===============

  - Search 12,896 icons by name, keyword or set; filter by set, style,
    category and licence.
  - Preview every icon at your size, stroke width and colour.
  - Browse the seven sets and popular categories, or use Find your icon for a
    shortlist.
  - Copy an icon as SVG, JSX, an `<img>` data URI or a CDN tag, or download it
    as an SVG file.
  - Collect icons in Your kit and download them as a ZIP or copy them as an
    SVG sprite.
