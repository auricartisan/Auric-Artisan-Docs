MESSAGES
========

  Message: SVG copied, JSX copied, data-URI copied, CDN tag copied, Copied
  Meaning: Code was copied.

  Message: Glyph entity copied
  Meaning: A Material icon's character reference was copied.

  Message: Material is a webfont — use the embed code
  Meaning: Material icons cannot be downloaded as SVG.

  Message: Select some icons first
  Meaning: Download ZIP or Copy sprite with an empty kit.

  Message: Downloaded n icons
  Meaning: The ZIP is ready.

  Message: SVG sprite copied
  Meaning: The sprite is on the clipboard.

  Message: No categories for this set.
  Meaning: The chosen set has no categories.

  Message: No option matches that.
  Meaning: No chip matches the text in Filter these options.

  Message: Icon library is temporarily unavailable
  Meaning: The catalogue could not be reached.

  Message: The live icon engine didn’t load
  Meaning: The page's icon engine did not start; Retry reloads.
