==============================================================================
GETTING STARTED WITH THE PERSONALIZATION GENERATOR
==============================================================================
Open the Personalization Generator, learn its layout, and run your first
sweep.
Area: Website › Tools › Colour workspace   Updated: 2026-09-25

OPEN THE PAGE
=============

Go to https://auricartisan.com/tool/personalization-gen/. The masthead reads
Describe it once, keep what survives., with a short description, a row of
labels and Read the API reference →.

Each time the page opens, a quick sweep of up to 120 candidates runs by
itself, so there are results on screen straight away. Results are not kept
between visits; your pool and settings are. See Privacy
[../others/privacy.txt].

THE LAYOUT
==========

On a wide screen the tool has a row of tabs and three columns under it.

  - Tabs: Overview, Pool, Tune, Palettes, Gradients, Typography, UI Pairs,
    Posters, Tokens, Studio, Presets and Export. Pool and the five result tabs
    show a count.
  - The brief (left column):
    - a text box, Describe the system you want… e.g. calm premium dashboard
      for creators, with Generate, Stop and Endless under it;
    - Search: the Simple and Advanced switch. In Advanced mode it also shows
      the Depth, Pool, Size and Keep boxes, the CVD-safe, Contrast and Unique
      check boxes, and an Advanced Kit note;
    - This run: what the next sweep will do (depth, pool target, palette size,
      top kept, and which of the three filters are on). It shows in both
      modes.
  - The stage (centre): the Search results box with Clear, a status line
    (Idle., Generating (320)…, Done · 24 kept · 812ms and so on), and the open
    tab.
  - The run (right column): the progress bar while a sweep runs, then Where
    the sweep went, Score distribution and The leader, checked. See Run a
    sweep [run-a-sweep.txt].

On medium screens The run moves below the other two columns. On narrow screens
all three stack, and on a phone the status line is hidden.

YOUR FIRST SWEEP
================

  1. Open Pool. The starting pool has eight colours: #D3AF37, #161616,
     #F8F7F1, #7D8A75, #2D6CDF, #C97B84, #0F172A and #14B8A6.
  2. Type one of your own colours in the HEX box, for example `#3C6E71`, and
     select Add.
  3. Open Tune. Under Style chips, select Nordic. Set Use case to Brand.
  4. In the brief box, type nordic studio and press `Enter`.
  5. Watch The run. When the status reads Done, open Palettes.
  6. On the first card, select Open in Studio.

Result: a ranked set of palettes near your colours, in a Nordic direction, and
the leader painted across sixteen mockups.
