THE BRIEF COLUMN
================

  Control: Brief box
  Type:    text
  Notes:   Same setting as Preference note in Tune. `Enter` starts a sweep.

  Control: Generate
  Type:    button
  Notes:   Starts a sweep. Reads Generating… while one runs.

  Control: Stop
  Type:    button
  Notes:   Stops the running sweep and keeps what it found. Also ends Endless.

  Control: Endless
  Type:    toggle
  Notes:   Keeps sweeping and merging results until stopped. Reads Endless ✓
           when on.

  Control: Simple, Advanced
  Type:    switch
  Notes:   Advanced shows the search settings below. Default Simple.

  Control: Depth
  Type:    number, 40 to 4,000
  Notes:   Advanced only. Same as Search depth.

  Control: Pool
  Type:    number, 5 to 240
  Notes:   Advanced only. Same as Pool target.

  Control: Size
  Type:    number, 5 to 12
  Notes:   Advanced only. Same as Palette size.

  Control: Keep
  Type:    number, 6 to 120
  Notes:   Advanced only. Values above 96 act as 96.

  Control: CVD-safe, Contrast, Unique
  Type:    check boxes
  Notes:   Advanced only. All on by default.

  Control: This run
  Type:    summary
  Notes:   Depth, pool target, palette size, top kept and the filters.

  Purpose: Kept palettes, ranked.

  Tab:     Typography
  Purpose: Type systems paired with palettes.

  Tab:     Posters
  Purpose: Poster layouts in the palettes' colours.

  Tab:     Tokens
  Purpose: Roles, themes, ramps, contrast audit and chart scales from the
           leader.

  Tab:     Studio
  Purpose: Sixteen mockups of one palette.

  Tab:     Presets
  Purpose: Seventeen starting points.

  Tab:     Export
  Purpose: CSS and JSON.

POOL
====

  Item:  Maximum pool
  Value: 240 colours

  Item:  Starting pool
  Value: #D3AF37, #161616, #F8F7F1, #7D8A75, #2D6CDF, #C97B84, #0F172A,
         #14B8A6

  Item:  Accepted input
  Value: HEX with 3, 4, 6 or 8 digits, with or without `#`

  Item:  Build
  Value: Fills or trims the pool to the pool target

  Item:  +24 random
  Value: Adds 24 variations

  Item:  Jitter
  Value: Nudges every colour by up to about 6° hue, 0.02 chroma and 0.03
         lightness (OKLCH)

  Item:  Quick seeds
  Value: + 4 UI, + 4 Earthy, + 4 Neon, + 4 Pop, + Grayscale (7 greys)

COLOUR RELATIONSHIPS
====================

Palettes are built on one of nineteen hue relationships: Analogous, Split
complement, Triadic, Tetradic, Mono accent, Editorial pop, UI system, Poster
clash, Natural, Aurora, Duo (warm/cool), Monochrome tonal, Complementary,
Square, Hexadic, Nature spectrum, Sunset burn, Compound, Brand trio.

The Ui and Dashboard use cases favour UI system; Poster favours Poster clash;
Editorial favours Editorial pop.

PALETTE NAMES
=============

A mood word and the relationship, for example Deep Triadic:

  Mood     | When
  ---------+-----------------------------
  Vivid    | average saturation above 70%
  Deep     | average lightness under 38%
  Soft     | average lightness above 72%
  Balanced | anything else

SCORE PARTS
===========

  Part       | Base weight | Grows with
  -----------+-------------+-----------------------------------
  Preference | 26%         | fixed
  Harmony    | 20%         | fixed
  Style      | 16%         | fixed
  Diversity  | 11%         | Diversity, up to a further 13%
  Contrast   | 10%         | Accessibility, up to a further 10%
  CVD / UI   | 5%          | Accessibility, up to a further 12%

The total is scaled to 0 to 100 and capped at 100.

MESSAGES
========

  Message                          | Meaning
  ---------------------------------+------------------------------------------------------
  Idle.                            | No sweep has run since the page opened.
  Generating (320)…                | A sweep of 320 candidates is running.
  Done · 24 kept · 812ms           | The sweep finished.
  Cancelled after 192/320 (140ms). | The sweep was stopped; results so far are kept.
  Use a valid HEX color            | The HEX box could not be read.
  Pool is empty                    | Jitter was selected with no pool colours.
  Defaults restored                | Reset defaults was selected.
  Nothing to save yet              | Save brand system was selected with no palettes.
  Already saved “…”                | That item from this sweep is already in your Library.
  Save failed                      | The Library could not store the item.
