==============================================================================
DESIGN SYSTEM GENERATOR DOCUMENTATION
==============================================================================
The list of guides for the Design System Generator.
Area: Website › Tools › Colour workspace   Updated: 2026-09-25

These guides explain how to use the Design System Generator: setting the
brief, reading each tab, using the component playground and the contrast
audit, comparing systems, exporting tokens, and saving and sharing. The
reference lists every control.

  File:           getting-started.md [getting-started.txt]
  What it covers: Open the tool, tour the screen, generate and export a first
                  system.

  File:           set-the-brief.md [set-the-brief.txt]
  What it covers: Industry, style, contrast target, density, seed, harmony,
                  colour mode, corners, type ratio, ramp shape and token
                  naming.

  File:           read-the-system.md [read-the-system.txt]
  What it covers: The Overview, Colour, Type, Icons and Scales tabs.

  File:           component-playground.md [component-playground.txt]
  What it covers: The live component gallery and its preview controls.

  File:           contrast-audit.md [contrast-audit.txt]
  What it covers: The audit rail, the score, the full audit view and suggested
                  fixes.

  File:           compare.md [compare.txt]
  What it covers: Running the same brief through every style or every
                  industry.

  File:           export-tokens.md [export-tokens.txt]
  What it covers: The Tokens tab, the twelve export formats and what each
                  contains.

  File:           share-save-and-connect.md [share-save-and-connect.txt]
  What it covers: Share links, saving to the Library, the Workspace view and
                  sending the palette to other tools.

  File:           reference.md [reference.txt]
  What it covers: Every control, option, default and output.

  File:           troubleshooting.md [troubleshooting.txt]
  What it covers: Symptoms, causes and fixes.

  File:           faq.md [faq.txt]
  What it covers: Short answers to common questions.
