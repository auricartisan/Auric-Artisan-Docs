==============================================================================
DESIGN SYSTEM GENERATOR FAQ
==============================================================================
Short answers to common questions about the Design System Generator.
Area: Website › Tools › Colour workspace   Updated: 2026-09-25

IS IT THE SAME AS "DESIGN ENGINE"?
==================================

Yes. The page's title is the Design System Generator; its address and some
labels use Design Engine.

DO I NEED AN ACCOUNT?
=====================

No, to generate, share and export. Saving systems uses your Auric Artisan
Library; see the Library Kit [../../../../kits/library-kit/README.txt].

IS ANYTHING GENERATED ON A SERVER?
==================================

No. The system is calculated in your browser. The page downloads fonts and
icons for the previews; see Privacy [../others/privacy.txt]. The same job is
also available through the public REST API, which is billed in API credits.

WILL THE SAME INPUTS ALWAYS GIVE THE SAME SYSTEM?
=================================================

Yes. That is why a share link reproduces a system. The only exceptions are the
ramp shape and token naming, which links and saved systems do not carry; see
Share, save and connect [share-save-and-connect.txt].

WHERE IS THE GENERATE BUTTON?
=============================

There is none. Every change regenerates the system at once.

WHY IS THERE NO DARK-THEME SCORE?
=================================

The score is calculated from the light roles. The dark roles are fully audited
in the audit view under Dark.

WHICH EXPORT SHOULD I USE?
==========================

CSS or JSON if you want everything. Tailwind v4 for Tailwind projects with
roles. Figma / W3C to import into Figma Variables or Tokens Studio (colours,
type, spacing, radius and shadow only). The native formats for Android, iOS,
Flutter or Compose (colours and dimensions). See Export tokens
[export-tokens.txt].

CAN I USE MY OWN FONT OR ICON SET?
==================================

The tool recommends from its own list. After export, replace the font families
and icon set in your project as you like.

ARE THE FONTS FREE TO USE?
==========================

The recommended families are served through the Auric font CDN and Google
Fonts. Check each family's licence in the Font Library
[../../font-library/README.txt] before using it in a product.

DOES PASSING THE AUDIT MAKE MY PRODUCT ACCESSIBLE?
==================================================

No. It shows that the defined colour pairings meet their contrast
requirements. Layout, font size, focus states and many other requirements are
up to you.
