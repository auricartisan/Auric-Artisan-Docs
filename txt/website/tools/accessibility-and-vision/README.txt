==============================================================================
ACCESSIBILITY AND VISION TOOLS
==============================================================================
What the accessibility and vision tools on auricartisan.com are for, and which
one to open for each job.
Area: Website › Tools › Accessibility and vision   Updated: 2026-09-25

This group covers the tools on auricartisan.com that help you make a design or
a website usable by more people. Some of them measure a live page against the
Web Content Accessibility Guidelines (WCAG), the W3C standard that most
accessibility laws point at. Others show you how colour looks to people with
colour-vision deficiencies or low vision, so you can catch problems that a
number alone does not reveal.

The tools range from a one-question checker to a full audit console. Use the
small tools when you already know what you are asking, and the Analyzer when
you want to find the problems you do not know about yet.

Every tool here is free to use. A few actions that run on Auric Artisan's
servers, such as rendering someone else's website or crawling a whole site,
need an account and are metered in tokens. Each tool's own docs say exactly
which actions those are.

THE TOOLS
=========

  Tool:      Analyzer [analyzer/README.txt]
  Address:   https://auricartisan.com/tool/analyzer/
  Use it to: Audit a whole web page: accessibility (126 rules), contrast,
             performance, SEO, security and more

  Tool:      Contrast Checker [contrast-checker/README.txt]
  Address:   https://auricartisan.com/tool/contrast-checker/
  Use it to: Grade one text colour against one background with the WCAG 2.1
             ratio

  Tool:      Accessibility Compliance [accessibility-compliance/README.txt]
  Address:   https://auricartisan.com/accessibility-compliance/
  Use it to: Old address; it now forwards you to the Accessibility Checklist

  Tool:      Accessibility Checklist [accessibility-checklist/README.txt]
  Address:   https://auricartisan.com/resources/accessibility-checklist/
  Use it to: Work through 50 WCAG 2.2 checks, record results with evidence,
             and read the law by country

  Tool:      Vision Lab [vision-simulation/README.txt]
  Address:   https://auricartisan.com/tool/vision-simulation/
  Use it to: Simulate colour-vision deficiencies and other vision conditions
             on colours and images

  Tool:      Ishihara Plate Generator [ishihara-plate-generator/README.txt]
  Address:   https://auricartisan.com/tool/ishihara-plate-generation/
  Use it to: Generate Ishihara-style dot plates for teaching and
             demonstrations

WHICH TOOL SHOULD I OPEN?
=========================

  - You have two colours and want a yes or no: open the Contrast Checker
    [contrast-checker/README.txt].
  - You have a URL and want every problem on the page: open the Analyzer
    [analyzer/README.txt].
  - You are preparing a manual audit or an accessibility statement: open the
    Accessibility Checklist [accessibility-checklist/README.txt].
  - You want to see a palette or an image the way someone with a colour-vision
    deficiency sees it: open the Vision Lab [vision-simulation/README.txt].
  - You are teaching how colour-vision tests work: open the Ishihara Plate
    Generator [ishihara-plate-generator/README.txt].

  | Important: None of these tools gives a legal certification or a medical
  | diagnosis. Automated testing finds real problems quickly, but a conformance
  | claim needs manual review as well, and a vision simulation is an
  | approximation, not an eye test.
