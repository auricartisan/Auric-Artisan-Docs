==============================================================================
ACCESSIBILITY CHECKLIST KEYBOARD SHORTCUTS
==============================================================================
Every key the Accessibility Checklist responds to, and where each one works.
Area: Website › Tools › Accessibility and vision   Updated: 2026-09-25

The single-letter keys work only while focus is inside the index (including
its filter buttons and area headers) or the pane. They are ignored in text
fields, when `Ctrl`, `Alt` or `Cmd` is held, and while the screenshot dialog
is open.

MOVING BETWEEN CHECKS
=====================

  Keys:   `Down` / `Up`
  Where:  On a row
  Action: Next or previous visible check; focus moves with it

  Keys:   `Home` / `End`
  Where:  On a row
  Action: First or last visible check

  Keys:   `J` / `K`
  Where:  Index or pane
  Action: Next or previous check. From the pane, focus stays and the new title
          is announced.

  Keys:   `E`
  Where:  Index or pane
  Action: Open the check: the one-check view on a phone, the pane title on a
          wide screen

  Keys:   `Esc`
  Where:  Pane
  Action: On a phone, back to the list; on a wide screen, back to the check's
          row

MARKING
=======

  Key     | Action
  --------+--------------------------------------------------
  `Space` | Pass (only on a row, the pane or the check title)
  `F`     | Fail
  `N`     | N/A

Pressing the key for the current verdict again clears it.

TABS
====

  Keys             | Action
  -----------------+-------------------------------------
  `Left` / `Right` | Previous or next tab, wrapping round
  `Home` / `End`   | First or last tab

IN THE SCREENSHOT EVIDENCE DIALOG
=================================

  Keys         | Action
  -------------+----------------------------
  `P`          | Pen
  `H`          | Highlighter
  `A`          | Arrow
  `B`          | Box
  `R`          | Redact
  `C`          | Callout
  `Ctrl` + `V` | Paste a screenshot
  `Esc`        | Close the dialog, like Done

PRINTING
========

`Ctrl` + `P` prints the same report as Export the report.

For shortcuts that work across the whole site, see Keyboard shortcuts
