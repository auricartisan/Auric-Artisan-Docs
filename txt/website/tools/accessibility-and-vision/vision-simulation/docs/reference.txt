WORKBENCH
=========

  Control:      Specimen
  What it does: What the stage shows
  Values:       Interface, Palette, Image
  Default:      Interface

  Control:      Base colour
  What it does: The colour to simulate
  Values:       Hex, up to 7 characters
  Default:      `#E53E3E`

  Control:      Reference strip
  What it does: Ten swatches, each with a Use button
  Values:       —
  Default:      —

  Control:      Severity
  What it does: Strength of the condition
  Values:       0–100%
  Default:      The condition's clinical default

  Control:      Model
  What it does: Colour-vision model
  Values:       Brettel, Viénot, Machado
  Default:      Brettel

  Control:      Stage
  What it does: Layout of the stage
  Values:       Split, Simulated only
  Default:      Split

  Control:      Search 78 conditions
  What it does: Filters the condition list
  Values:       Text
  Default:      —

  Control:      List filters
  What it does: Narrow the list
  Values:       All 78, Colour, Field, Basic only
  Default:      All 78

  Control:      Open the full panel
  What it does: Opens the condition as a floating panel
  Values:       —
  Default:      —

  Control:      Compare this
  What it does: Adds the condition to Compare
  Values:       —
  Default:      —

  Control:      Copy link to this view
  What it does: Copies a `?vw=` link
  Values:       —
  Default:      —

Readouts: What collapses (reference pairs that fall under ΔE2000 8 from 12 or
more) and Measured · base colour (ΔE76, ΔE2000, pairs lost / 45, button label
/ fill).
