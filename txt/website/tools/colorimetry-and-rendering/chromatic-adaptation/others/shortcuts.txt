==============================================================================
CHROMATIC ADAPTATION SHORTCUTS
==============================================================================
Keyboard and mouse shortcuts in the Chromatic Adaptation lab.
Area: Website › Tools › Colorimetry and rendering   Updated: 2026-09-25

These keys work when the focus is not in a text box, slider or list. Click an
empty part of the page first if a key does nothing.

  Key     | What it does
  --------+-------------------------------------------------------------
  `Space` | Plays or pauses the 0–5 s animation
  `R`     | Resets the time to 0 s
  `C`     | Runs Compare All Methods (results on the Export tab)
  `G`     | Toggles the GPU checkbox (which has no effect on processing)
  `Esc`   | Clears the Reference filter; closes a full-screen chart

  Mouse                         | What it does
  ------------------------------+---------------------
  Double-click a chart or image | Opens it full screen
