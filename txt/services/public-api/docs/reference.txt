==============================================================================
REFERENCE
==============================================================================
Every customer endpoint of the Auric Artisan REST API with its method,
authentication, credit cost and purpose, plus the headers, input formats,
plans and limits.
Area: Services › Public API   Updated: 2026-09-25

ESSENTIALS
==========

  Item:  Base URL
  Value: https://api.auricartisan.com

  Item:  Version prefix
  Value: `/v1`

  Item:  Format
  Value: JSON over HTTPS

  Item:  Authentication
  Value: `x-api-key` header (or `?key=` query), or `Authorization: Bearer`
         from the CLI

  Item:  Key prefix
  Value: `aa_`

  Item:  Keys per account
  Value: Up to 10 active

  Item:  Revocation
  Value: Takes effect within a minute

  Item:  Specification
  Value: `GET /v1/openapi.yaml` (OpenAPI 3.1); `GET /v1/catalog` (JSON)

  Item:  Interactive reference
  Value: `GET /v1/docs`

COLOUR INPUT
============

Unless a field says otherwise, a colour can be sent as `#rrggbb`, `#rgb`,
`rgb(r,g,b)`, an array `[r,g,b]` or an object `{r,g,b}`. Image fields take
Base64 or a data URL.

ENDPOINTS
=========

Auth "None" means public and unmetered; "Key" needs an API key or bearer
token. Credits are per call; see Plans, credits and quotas
[plans-credits-and-quotas.txt]. The documentation gives some costs as ranges
(2–4, 10–12); the exact cost of every call is returned in `x-credits-cost`.
Endpoints the documentation does not weight separately bill as standard work,
1 credit.

RESPONSE HEADERS
================

  Header:  `x-ratelimit-limit`
  Meaning: Requests allowed per minute

  Header:  `x-ratelimit-remaining`
  Meaning: Requests left this minute

  Header:  `x-ratelimit-reset`
  Meaning: Minute reset, in Unix seconds

  Header:  `x-quota-limit`
  Meaning: Included credits this month

  Header:  `x-quota-used`
  Meaning: Credits used this month

  Header:  `x-quota-remaining`
  Meaning: Included credits left

  Header:  `x-quota-reset`
  Meaning: Monthly reset, in Unix seconds

  Header:  `x-credits-cost`
  Meaning: Credits this call consumed

  Header:  `x-credits-overage`
  Meaning: Overage credits this call used (only when paid from the prepaid
           balance)

  Header:  `x-overage-cost-usd`
  Meaning: 1.00 when the call opened a new 100,000-credit block, otherwise
           0.00

  Header:  `x-credits-ceiling`
  Meaning: The account's hard ceiling

  Header:  `Retry-After`
  Meaning: With 429: when to retry

  Header:  `Allow`
  Meaning: With 405: the accepted methods

LIMITS STATED IN THE DOCUMENTATION
