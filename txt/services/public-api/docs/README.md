# Public API documentation — plain-text edition

The contents of the public API documentation, from creating a key to every endpoint, error and limit. Every file here is the plain-text edition of the Markdown document with the same name in `md/services/public-api/docs/`; start with `README.txt`.

## Files

| File | What it covers |
| --- | --- |
| [README.txt](README.txt) | The contents of the public API documentation, from creating a key to every endpoint, error and limit. |
| [getting-started.txt](getting-started.txt) | Get an API key from your dashboard, make a first request, and read the response and its usage headers. |
| [authentication.txt](authentication.txt) | How to authenticate with the Auric Artisan API — API keys, the CLI's OAuth bearer token, keeping keys safe, and revoking them. |
| [errors.txt](errors.txt) | The Auric Artisan API's error format, every error code with its HTTP status, what each means, and how to respond. |
| [examples.txt](examples.txt) | Ready-to-run requests for common tasks with the Auric Artisan API. |
| [plans-credits-and-quotas.txt](plans-credits-and-quotas.txt) | What each plan includes, how credits are charged per endpoint, rate limits, overage, spend caps, the hard ceiling, and the headers that report usage. |
| [sdks-and-tooling.txt](sdks-and-tooling.txt) | The official clients and integrations for the Auric Artisan API — JavaScript, Python, the CLI, an MCP server, a Postman collection and GraphQL. |
| [reference.txt](reference.txt) | Every customer endpoint of the Auric Artisan REST API with its method, authentication, credit cost and purpose, plus the headers, input formats, plans and limits. |
| [troubleshooting.txt](troubleshooting.txt) | Common problems with the Auric Artisan API — keys, plans, limits, credits, inputs, collections and the analyzer — and how to fix them. |
| [faq.txt](faq.txt) | Short answers to common questions about the Auric Artisan REST API. |
