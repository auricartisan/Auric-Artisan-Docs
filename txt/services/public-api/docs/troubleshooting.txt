==============================================================================
TROUBLESHOOTING
==============================================================================
Common problems with the Auric Artisan API — keys, plans, limits, credits,
inputs, collections and the analyzer — and how to fix them.
Area: Services › Public API   Updated: 2026-09-25

KEYS AND ACCESS
===============

  Symptom:    `401` on every call
  Why:        No key, a mistyped key, or a revoked key
  What to do: Send the key in `x-api-key`; check it starts with `aa_`; create
              a new one if it was revoked or lost

  Symptom:    `401` right after revoking a key
  Why:        Revocation takes effect within a minute
  What to do: Use another key

  Symptom:    `402 PLAN_UPGRADE_REQUIRED`
  Why:        Your plan does not include the API
  What to do: Upgrade to Specialist or Industrial Pro

  Symptom:    I cannot create a key in the dashboard
  Why:        Key creation is available from the Specialist plan
  What to do: Upgrade, or use the public discovery endpoints meanwhile

  Symptom:    I lost a key
  Why:        The full key is shown once and stored only as a hash
  What to do: Create a new key and revoke the old one

  Symptom:    `403 FORBIDDEN`
  Why:        The key has no rights for this route
  What to do: Check the path; use an endpoint listed in the Reference
              [reference.txt]

LIMITS AND CREDITS
==================

  Symptom:    `429 RATE_LIMITED`
  Why:        Too many requests this minute
  What to do: Wait for `Retry-After`; spread calls out

  Symptom:    `429 IP_RATE_LIMITED`
  Why:        Too many requests from one address
  What to do: Slow down, whatever key you use

  Symptom:    `429 QUOTA_EXCEEDED`
  Why:        Included credits used up, overage off
  What to do: Turn on prepaid overage and add credits, or wait for the reset
              in `details.resets_at`

  Symptom:    `402 INSUFFICIENT_CREDITS`
  Why:        Overage on, prepaid balance empty
  What to do: Add credits in the dashboard

  Symptom:    `402 SPEND_CAP_REACHED`
  Why:        Your monthly spend cap was reached
  What to do: Raise the cap in the dashboard

  Symptom:    `429 HARD_CEILING_REACHED`
  Why:        Ten times the included allowance used this month
  What to do: Contact support

  Symptom:    Adding more keys did not raise my limits
  Why:        Limits are pooled per account
  What to do: Upgrade the plan, or use overage

  Symptom:    Credits drain faster than calls
  Why:        Heavier endpoints cost more than 1 credit
  What to do: Read `x-credits-cost`; see Plans, credits and quotas
              [plans-credits-and-quotas.txt]

REQUESTS
========

  Symptom:    `400 INVALID_JSON`
  Why:        The body is not valid JSON
  What to do: Check quoting, especially in shell commands

  Symptom:    `400 INVALID_INPUT`
  Why:        A field is missing or malformed
  What to do: Read the message, which names the field

  Symptom:    `405 METHOD_NOT_ALLOWED`
  Why:        Wrong method, such as `GET` for a `POST` endpoint
  What to do: Use the method in the `Allow` header

  Symptom:    `404 NOT_FOUND`
  Why:        Unknown path or id
  What to do: `GET /v1` lists every endpoint

  Symptom:    `413 PAYLOAD_TOO_LARGE`
  Why:        Image bodies are limited to 4 MB
  What to do: Resize or compress the image

  Symptom:    `/v1/vision/simulate` refuses `deuteranopia`
  Why:        It takes model ids, not condition names
  What to do: Use a model from `/v1/vision/models`, such as `brettel-deutan`,
              or use `/v1/vision/palette`

  Symptom:    A colour is rejected
  Why:        Unsupported format
  What to do: Use `#rrggbb`, `#rgb`, `rgb(r,g,b)`, `[r,g,b]` or `{r,g,b}`

COLLECTIONS
===========

  Symptom:    An empty page with a `next_cursor`
  Why:        The scan budget ran out before any match (`truncated: true`)
  What to do: Follow `next_cursor`, or raise `max_scan`

  Symptom:    Sorted results look out of order across pages
  Why:        In scanned collections, sorting other than by `id` is within
              each scan
  What to do: Check `sorted_within_scan`; sort on your side if you need a
              global order

ANALYZER
========

  Symptom:    `score` is always `null`
  Why:        Deliberate: markup alone cannot measure every category
  What to do: Use `category_scores`, or run the tool for an overall score

  Symptom:    `400 RENDER_REQUIRED`
  Why:        Contrast, accessibility, deep, performance, before-and-after and
              simulation need a browser
  What to do: Remove those stages, or use the tool

  Symptom:    `400 EMPTY_SCOPE`
  Why:        `scope` was `[]`
  What to do: Omit `scope` for everything, or name stages

  Symptom:    `502 FETCH_FAILED`
  Why:        The page could not be read: DNS, TLS, timeout, or a private
              address
  What to do: Check the URL is public and reachable

  Symptom:    Non-Latin text missing from the PDF
  Why:        The PDF uses standard fonts that cover Latin characters
  What to do: Use `format: "html"`

GETTING HELP
============

Quote the `request_id` from the error response when you contact Auric Artisan
about a specific call.
