==============================================================================
AURIC ARTISAN DOCS
==============================================================================
The complete user documentation for Auric Artisan — the website and its tools,
the VS Code extensions, the browser extension and the services.
Area: Auric Artisan   Updated: 2026-09-25

Auric Artisan is a colour and accessibility studio. It lives in three places:
the website at https://auricartisan.com, with its tools, libraries and kits; a
set of extensions for Visual Studio Code; and a browser extension that brings
the colour tools to any web page. A few services — a font CDN, an icon CDN and
a public API — let you use the same data from your own sites and code.

This documentation is written for the people who use those products:
designers, developers, accessibility specialists, students and anyone curious
about colour. It explains what every screen, control, command and setting
does, how to complete real tasks step by step, what each tool measures and how
precisely, and what to do when something does not behave as you expect.

HOW THE DOCS ARE ORGANISED
==========================

Every product and tool has its own folder, laid out the same way:

  - `README.md` — what it is, who it is for, where to find it, a quick start
    and what you can do with it.
  - `docs/` — getting started, one guide per task, a complete reference of
    every control or setting, troubleshooting and frequently asked questions.
  - `others/` — a glossary, shortcuts, limits and accuracy, related tools,
    release notes and privacy.

Every folder has its own `README.md` listing what is inside it, so you can
always find your way down from here.

ABOUT THESE DOCS
================

  - They describe the products as users have them at the date shown on each
    page. Where a product's own screens disagree with each other, the docs
    describe what the product actually does.
  - Legal summaries help you understand the policies; the official pages on
    auricartisan.com are the ones that govern.
  - The same content is available as plain text, a browsable offline HTML site
    with search, PDF, EPUB, Word, JSON and CSV. They are generated from these
    Markdown pages and live alongside them in the repository.
