==============================================================================
CONTACT AND SUPPORT
==============================================================================
How to reach Auric Artisan — choosing the right topic and inbox, reply times,
attaching screenshots, what to include, and what happens after you send.
Area: Help   Updated: 2026-09-25

Every message is read and answered by a person — the contact page says there
is "no ticket queue and no bot in front of it". The contact form is at
https://auricartisan.com/company/contact/.

BEFORE YOU WRITE
================

  - Many questions are answered in the FAQ [faq.txt], the FAQ page
    <https://auricartisan.com/company/faq/> on the site, or Troubleshooting
    [troubleshooting.txt].
  - Inside the site, press `?` for the Guide or `Ctrl` + `K` to search.
  - Each topic on the contact page shows links that might answer your question
    faster.

CHOOSE THE RIGHT TOPIC
======================

The topic decides which inbox receives your message and how quickly you can
expect a reply.

  Topic:                   Using a tool
  Goes to:                 hello@auricartisan.com
  Use it for:              How to do something
  Reference field asks for:Link to the tool or page
  Reply time:              2–3 days

  Topic:                   Billing
  Goes to:                 hello@auricartisan.com
  Use it for:              Payments, refunds, receipts, discounts
  Reference field asks for:Order or invoice ID (starts with `order_`)
  Reply time:              1–2 days

  Topic:                   Something else
  Goes to:                 hello@auricartisan.com
  Use it for:              Anything not listed
  Reference field asks for:Anything that helps place it
  Reply time:              Up to a week

  Topic:                   A bug
  Goes to:                 developer@auricartisan.com
  Use it for:              Something broken, including accessibility barriers
  Reference field asks for:URL where it happened
  Reply time:              2–4 days

  Topic:                   API or integration
  Goes to:                 developer@auricartisan.com
  Use it for:              The REST API, keys, SDKs
  Reference field asks for:Endpoint, or a request ID
  Reply time:              2–4 days

  Topic:                   Security
  Goes to:                 security@auricartisan.com
  Use it for:              A vulnerability
  Reference field asks for:Affected URL or endpoint
  Reply time:              Within 48 hours

  Topic:                   Privacy or data
  Goes to:                 security@auricartisan.com
  Use it for:              Data access, correction or deletion
  Reference field asks for:Account email, if different
  Reply time:              Within 30 days

Reply times are those shown on the contact page; the page notes replies can be
late at weekends or during a release.

SEND A MESSAGE
==============

  1. Open https://auricartisan.com/company/contact/.
  2. Under What is this about?, select a topic. (With the keyboard, the topics
     are one stop: use the arrow keys.)
  3. Fill in Name and Email (both required). Use the email address on your
     account for account or billing questions.
  4. Fill in the reference field — its label changes with the topic.
  5. Write your Message (up to 2,000 characters; a counter shows how many you
     have used). The toolbar offers Bold, Italic, Inline code, Bulleted list,
     Code block and Link; `Ctrl` + `B`, `Ctrl` + `I` and `Ctrl` + `K` work
     too. The message is sent as plain text, and pasted text loses its
     formatting.
  6. Optional: add up to four screenshots (see below).
  7. Select Send.

Result: "Thanks. Your message was sent." You receive a confirmation at the
address you gave. The reply comes from the topic's inbox, in the same email
thread. If your message leads to a change, you get the link when it ships.

If something is missing, the form says so: "Name is required.", "Enter a valid
email address.", "Message cannot be empty." or "Message exceeds 2000
characters." If sending fails: "Something went wrong. Please try again or
email directly."

ATTACH SCREENSHOTS
==================

  - Select Add an image, paste a screenshot with `Ctrl` + `V`, or drag an
    image onto the message.
  - Up to four images; PNG, JPEG, GIF or WebP; up to 12 MB each. Large images
    are shrunk before sending.
  - Select an attached image to mark it up with a Pen, Highlighter or Box in
    red, gold, blue or black, with Undo and Clear all marks, then Save marks.
  - Remove an image with its remove button.

WRITE A MESSAGE THAT GETS A FAST ANSWER
=======================================

  Topic:   A bug
  Include: The page address, your browser and version, what you did, what
           happened, what you expected, and a screenshot

  Topic:   API
  Include: The request (method, endpoint and body), the response, and what you
           expected. Never send a full API key.

  Topic:   Billing
  Include: The order reference, the date, the amount and what you want

  Topic:   Colour-science inaccuracy
  Include: The tool, the input values, the output, what you expected, and the
           standard or paper you are checking against

  Topic:   Accessibility barrier
  Include: The page, the task, your assistive technology, and what stopped you

Never send passwords, backup codes, full card numbers or full API keys.

SECURITY REPORTS
================

Email security@auricartisan.com, or use the Security topic
(https://auricartisan.com/company/contact/?topic=security opens it directly).
Send the location and the impact, not a working exploit; a way to send the
rest will follow. The Security page aims to acknowledge within 24 hours and
states that researchers acting in good faith will not face legal action. See
Security page summary [../website/company-and-legal/docs/security-page.txt].

OPEN THE FORM ON A TOPIC
========================

Add `?topic=` and one of `support`, `billing`, `other`, `bug`, `api`,
`security` or `privacy` to the contact address, for example
https://auricartisan.com/company/contact/?topic=billing.
