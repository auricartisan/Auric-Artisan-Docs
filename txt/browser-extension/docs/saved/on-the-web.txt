==============================================================================
ON THE WEB
==============================================================================
The links from the extension to the full-size tools and libraries on
auricartisan.com.
Area: Browser extension › Saved   Updated: 2026-09-25

On the web ("Open on the Web") lists the full-size tools on auricartisan.com,
each opening in a new tab. Open it by searching for "web" or "On the web"; it
belongs to the Saved space.

LINKS
=====

  Link            | Opens
  ----------------+----------------------------------------------------------
  Analyzer        | The URL analyzer, https://auricartisan.com/tool/analyzer/
  Palettes        | The palette library
  Harmony         | The harmony library
  Gradients       | The gradient library
  Shades          | The shades library
  Colour library  | The colour library
  Vision lab      | The vision simulation tool
  Ishihara plates | The Ishihara plate generator
  Science lab     | The Color Science Lab
  Colour atlas    | The colour atlas generator
  Personalise     | The personalisation generator
  Accessibility   | The accessibility library
  Learn           | The Learn articles
  Workspace       | The library workspace

OTHER LINKS TO AURICARTISAN.COM
===============================

  - The Auric Artisan wordmark in the header opens the home page.
  - Home › On auricartisan.com: Collections, Accessibility Library, Learning
    Library and Documentation.
  - Search results under On the web: Full Search, Collections, URL Analyzer,
    Tools, Color Science Lab, Accessibility Library, Documentation, API
    Reference and Learning Library.
  - Page palette › Open opens the palette on auricartisan.com with its colours
    in the address.

Each link is an ordinary page visit that you start. The extension sends
nothing else to the site. See Privacy [../../others/privacy.txt].
