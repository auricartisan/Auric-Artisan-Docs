==============================================================================
BROWSER MENU ITEMS
==============================================================================
The Auric Artisan entries added to the browser's own right-click menu and
toolbar-icon menu, what each does, and how to turn them off.
Area: Browser extension › On websites   Updated: 2026-09-25

Separately from the optional custom menu, the extension adds a few entries to
the browser's own right-click menu, on pages and on the extension's toolbar
icon. They are on by default.

THE ENTRIES
===========

  Entry:        Inspect element
  What it does: Starts the element inspector on the page

  Entry:        Extract page palette
  What it does: Opens the extension at Page palette and reads the page's
                colours

  Entry:        Audit contrast on page
  What it does: Outlines the page's contrast problems, then opens the
                extension at Audit and runs it

  Entry:        Simulate · Protanopia
  What it does: Filters the page for protanopia

  Entry:        Simulate · Deuteranopia
  What it does: Filters the page for deuteranopia

  Entry:        Simulate · Tritanopia
  What it does: Filters the page for tritanopia

  Entry:        Simulate · Achromatopsia
  What it does: Filters the page for achromatopsia

  Entry:        Clear vision filter
  What it does: Removes the vision filter

The entries are translated when the interface is set to Hindi.

If the extension's popup cannot open by itself, open it within 30 seconds and
it goes straight to the tool you chose. After 30 seconds the request is
dropped, so an old action never runs later on another page.

TURN THEM OFF
=============

Turn off Settings › Right-click › Items in the browser's menu ("Add Auric
Artisan entries to the browser's own right-click menu too."). The entries
disappear at once.
