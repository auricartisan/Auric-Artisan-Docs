==============================================================================
ON WEBSITES
==============================================================================
The optional features that work on websites themselves — Auric pickers for
form controls, the compact colour picker, the custom right-click menu — and
the entries in the browser's own menu.
Area: Browser extension › On websites   Updated: 2026-09-25

Two optional features change how websites behave, and both are off until you
turn them on:

  - Auric pickers on websites give a page's colour, select, date, time,
    number, range, file and other form controls Auric versions. The site still
    receives every value exactly as before.
  - The custom right-click menu replaces the browser's menu with one built
    around what you clicked, while stepping aside for sites that have their
    own.

A third, smaller feature is on by default: a few Auric Artisan entries in the
browser's own right-click menu.

Neither optional feature runs on auricartisan.com, which has its own pickers
and menu.
