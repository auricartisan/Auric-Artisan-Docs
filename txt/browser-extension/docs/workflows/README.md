# Workflows — plain-text edition

End-to-end tasks that combine several of the extension's tools, step by step. Every file here is the plain-text edition of the Markdown document with the same name in `md/browser-extension/docs/workflows/`; start with `README.txt`.

## Files

| File | What it covers |
| --- | --- |
| [README.txt](README.txt) | End-to-end tasks that combine several of the extension's tools, step by step. |
| [audit-a-page-and-fix-contrast.txt](audit-a-page-and-fix-contrast.txt) | Run the audit on a page, see its contrast problems on the page, fix a failing colour pair, review the other findings and export a record. |
| [back-up-and-move-your-data.txt](back-up-and-move-your-data.txt) | Back up your settings, colour history, library and snippets to a file, restore them, and move them to another browser or computer. |

| [check-and-fix-a-brand-colour.txt](check-and-fix-a-brand-colour.txt) | Test a brand colour as text and as a background in WCAG and APCA, see it through colour-vision simulations, and find accessible variants that keep its hue. |
| [extract-a-sites-design-system.txt](extract-a-sites-design-system.txt) | Read a website's colours, CSS variables, fonts and type scale, and export them as W3C design tokens, Tailwind or CSS. |
| [inspect-and-debug-an-element.txt](inspect-and-debug-an-element.txt) | Find why an element looks the way it does, check its accessibility, try a CSS fix live on the page, and copy the result. |
| [review-a-page-for-colour-blindness.txt](review-a-page-for-colour-blindness.txt) | Check that a page does not rely on colour alone, using the vision simulations, side-by-side comparison and the contrast checker. |
