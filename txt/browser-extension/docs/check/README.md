# Check tools — plain-text edition

The tools in the Check space — Contrast, Vision, Audit and Findings — and the rules the audit applies. Every file here is the plain-text edition of the Markdown document with the same name in `md/browser-extension/docs/check/`; start with `README.txt`.

## Files

| File | What it covers |
| --- | --- |
| [README.txt](README.txt) | The tools in the Check space — Contrast, Vision, Audit and Findings — and the rules the audit applies. |
| [all-findings.txt](all-findings.txt) | One list of everything the tools found — accessibility, contrast and inspection problems — ordered by severity, with actions for each. |
| [audit-rules.txt](audit-rules.txt) | Every rule in the extension's accessibility engine, grouped by category, with its impact, WCAG 2.2 success criteria and whether the audit runs it. |
| [audit.txt](audit.txt) | Audit the current page against WCAG 2.2 A and AA, read the contrast results, outline problems on the page, and export the results. |
| [contrast.txt](contrast.txt) | Check a text and background colour pair against WCAG 2.2 and APCA, read the verdict and size guidance, and fix the pair to the nearest passing colour. |
| [vision.txt](vision.txt) | See the live page through eight colour-vision deficiency and four low-vision simulations, compare side by side, and capture the result. |
