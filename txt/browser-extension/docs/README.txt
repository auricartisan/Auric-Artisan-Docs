==============================================================================
BROWSER EXTENSION DOCUMENTATION
==============================================================================
The contents of the browser extension's how-to documentation, from installing
to every tool and setting.
Area: Browser extension   Updated: 2026-09-25

This folder explains how to install the Auric Artisan browser extension and
use every part of it: the popup and side panel, each tool in the Colour,
Check, Code and Saved spaces, the features that work on websites, and every
setting. Start with Getting started [getting-started.txt] if you are new, or
go straight to the tool you need.

FILES
=====

  Page:           Getting started [getting-started.txt]
  What it covers: Open the extension, take the tour, and do a first task in

                  change

  Page:           Reference [reference.txt]

  Page:           FAQ [faq.txt]
  What it covers: Short answers to common questions

FOLDERS
=======

  - install/ [install/README.txt]: Installing on Chrome and other Chromium
    browsers, Edge, Opera, Firefox and Safari; loading from a ZIP; updating
    and removing
  - surfaces/ [surfaces/README.txt]: The popup, Home, search, the side panel,
    what the extension draws on a page, and the element inspector
  - colour/ [colour/README.txt]: Picker, Page palette, Image, Gradient, Mix,
    Harmony, Scale and Convert
  - check/ [check/README.txt]: Contrast, Vision, Audit, the audit's rules, and
    Findings
  - code/ [code/README.txt]: Inspect, Tokens, Snippets, and every code format
    the extension exports
  - saved/ [saved/README.txt]: Library, History and On the web
  - on-websites/ [on-websites/README.txt]: Website pickers, the colour picker
    on pages, the right-click menu, the items in the browser's own menu, and
    notes for site owners
  - workflows/ [workflows/README.txt]: End-to-end tasks that use several tools
    together
  - settings/ [settings/README.txt]: Appearance, Pickers, Right-click, Tools,
    Data and Shortcuts
