# Colour tools — plain-text edition

The tools in the Colour space — Picker, Page palette, Image, Gradient, Mix, and the Harmony, Scale and Convert tools behind the Picker. Every file here is the plain-text edition of the Markdown document with the same name in `md/browser-extension/docs/colour/`; start with `README.txt`.

## Files

| File | What it covers |
| --- | --- |
| [README.txt](README.txt) | The tools in the Colour space — Picker, Page palette, Image, Gradient, Mix, and the Harmony, Scale and Convert tools behind the Picker. |
| [convert.txt](convert.txt) | Type a colour in any of ten formats and read it in all the others at once, with random, invert and complement helpers. |
| [gradient.txt](gradient.txt) | Build a linear, radial or conic CSS gradient from two or more stops, choose the interpolation space, and copy or save the CSS. |
| [harmony.txt](harmony.txt) | Build a colour harmony from a base colour in nine schemes on a wheel you can drag, then copy, send or save it. |
| [image.txt](image.txt) | Build a palette from an image you drop, paste or choose, or from a capture of the visible tab, entirely on your device. |
| [mix.txt](mix.txt) | Mix two colours at any percentage in sRGB, linear RGB, LAB, OKLAB or HSL, or blend them with a blend mode, and copy the result. |
| [page-palette.txt](page-palette.txt) | Read every colour a web page uses, switch between views and sorting modes, inspect a colour, and copy or export the palette. |
| [picker.txt](picker.txt) | Sample a colour from the screen or set one by hand, read it in twelve formats, and use the Picker's Specs, Harmony, Scale, Contrast, Vision and Code panes. |
| [scale.txt](scale.txt) | Generate Tailwind and Material colour scales, tints, shades and tones from one colour, inspect each step, and export the scale. |
